# 测试记录手动升级说明

中心版本 1.0.43，Windows x64 客户端版本 1.0.16。入口为 **模型探索 → 成果与方法 → 测试记录**。

## 文件与数据

| 文件 | 用途 |
| --- | --- |
| ai2050-center-1.0.43.tar.gz 及同名 .sha256 | 中心程序、网页客户端、Goodfire 摘要和受保护的历史索引 |
| upgrade_center.sh | 项目现有的 systemd 中心升级脚本 |
| AI2050-client-1.0.16-windows-x64.zip | 完整免安装 Windows 客户端，未做代码签名 |
| test-records-data.zip | 随中心交付的两份索引和覆盖清单的独立复核副本 |
| SHA256SUMS.txt | 交付文件的 SHA256 |

这份数据包用于复核。正常升级一次中心即可读取两份索引。Goodfire 摘要随客户端离线提供，含六个原有成果库报告的哈希链接。完整历史索引和用户登记的运行经中心管理员会话读取。数据包请与服务器管理材料一同保存。涉及锁箱、原场和逐题输出时，沿用原档案权限。

## 更新中心

1. 按既有部署流程备份当前中心程序、systemd 配置和 `AI2050_DIST_DIR` 下的持久化数据库及对象。保存当前安装路径和旧版本包。
2. 把中心包、同名校验文件和升级脚本上传到服务器同一目录。在该目录执行以下命令。采用自定义 systemd 服务名时依照原配置设置 `SERVICE`。

```sh
sha256sum -c ai2050-center-1.0.43.tar.gz.sha256
sudo bash upgrade_center.sh ai2050-center-1.0.43.tar.gz
```

3. 在原站点查看 `/api/health` 的版本是否为 1.0.43。使用原管理员账户访问 `/api/test-archive/history?limit=1`，核对返回的 `total` 为 4861。浏览器地址栏直接导航不会携带客户端的管理员会话头，可在客户端选择「历史回填」完成同一项核对。
4. 新建测试的查重回执现在会保存当时返回的候选和匹配理由。历史旧回执按当时实际保存的版本回查。此前的 SQLite 运行、回执和原始文件继续沿用现有持久化目录。若升级失败，请保留日志并按旧部署的 systemd 工作目录恢复原程序。回滚时先保留升级之后登记的运行和新增回执。

## 更新 Windows 客户端

关闭原客户端，把 Windows 压缩包解压到有足够空间的 D 盘新目录。运行其中的 `AI2050-client/AI2050 语言机制研究平台.exe`，连接已升级的受信中心。旧客户端目录可用于切回。网页版用户在中心升级后刷新工作台即可使用新版界面。

## 核对显示和查重

- 在「Goodfire 系列」搜索 `2976`，从关联测试打开 `2979`。前一轮报告特定请求位置下的局部削弱，后一轮列出跨句式方向预测输给纯文本基线及对照覆盖不足。
- 搜索 `2981`，查看 4,096 条自然生成、混合答案计数和未执行的 B26/H36 阻断与恢复。打开关联的 `2971` 可查看已执行的四记录选源干预。
- 在「历史回填」搜索 `EXP-C001-WP01-001`，核对冻结合同和其中的实际运行 ID。备忘录、工程、方案、结果文件和复核运行分别保留身份。标题分类用于查找，科学证据以原始运行、协议和审计为准。
- 新建真实测试时，先搜索旧设计或在记录上选择「以此记录新建复测」。导入 `research_test_plan.v1`，查询中心，选择已有采集、独立复现等方式，填写本次新增的验证条件。修改方案后重新查重。登记会保存方案、历史引用、理由和运行 ID。可从「中心运行」读回原始查重回执。
- 登记与模型执行分开。日常自动化运行仍通过 `tests/glm5/run_routine_test.py` 完成预检、登记、执行和归档。已经在客户端领取运行 ID 的任务由执行方使用同一 ID 提交产物；重复的新采集会触发既有采集检查。工程联调在隔离库进行。

## 覆盖范围

本批包含 6 个机制问题、36 条 Goodfire 设计或复盘记录、71 个可下钻的早期 Phase 入口。历史索引有 4,861 条，其中包含 19 个测试设计、16 个冻结合同、420 个结果产物索引、70 个原始报告索引和 4,336 个按来源去重的备忘录条目。16 个合同合计关联 16 个 Research OS 运行。旧材料没有记录的反例、门槛或运行 ID 会显示缺项。没有稳定 Phase 标题或规范产物的旧工作仍可能漏检。索引条数不能用作独立模型实验数或破解率。
