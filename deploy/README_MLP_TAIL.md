# Qwen3-4B 最后四层真实 MLP 图谱

本轮 RUN 为 `MLP-TAIL-GOODFIRE-20261108-v1`，B32—B35（零起始编号，即第33—36层），每层9728个原生MLP单元，共38912个。

客户端保持菜单与配色。在「空间 → 研究成果」选择「Qwen3-4B最后四层」，可旋转查看四层全部单元，输入单元编号，切换G/V/A与正负符号组合，分别查看发现/确认/留出关联、写出—读入权重对齐、已测原模型干预。单元详情包含长文本两极、完整gate行/value行/down列和写出方向的词表参数读出。完整数组均可按坐标查询数值。层间连线是选中单元与全部相邻层单元的关系；默认筛选绘制，勾选后绘制全部，数值不截断。

## 数据和结论边界

- 2048篇1024-token中英文自然文本，每层32768个抽样位置；复用原有长文本库，并非新的独立语义盲测。
- 原生MLP输出逐位复算正确；词语关键词、token线索、权重余弦和共同响应仍是候选解释。38912是覆盖量，不是已破解语义的数量。
- 所有15张9728×9728矩阵保留（3边界×3划分的Pearson，以及3边界×2类权重对齐）。权重对齐未包含RMSNorm和注意力；两者均不等于因果路径。
- 稀疏8父单元预测及连续递推存在明显失败，报告保留FVU、反例与全部残差，不根据留出结果调参补过门。
- 原模型96语境、12源单元、9216干预/对照行；每个文档干预后重新原始前向逐位恢复。曲线只在双方范数相差1%以内的相同文档上描述性比较。无效对照不删除、不用于晋级。
- 能力保持仅为自然下一词KL/损失代理；未证明翻译、推理和编程的非劣效，也未完成所有单元的语义或因果解释。
- Goodfire的长上下文、原生参数与正负门控分析提供方法启发；本轮不是完整APD复现，也没有把其工作假设当作定理。
- 准入审计发现干预未事先登记期望行为效应与功效，原始结果缺少五字段provenance信封。已保留原始冻结，另外登记事后溯源与缺陷；本轮只作探索性观察，不追认正式机制确认。若未来以5个百分点、48次比较规划，功效计算器给出每比较至少680个文档；这是未来设计示例，不是本轮事前方案。

## 手动正式部署

网页由新版中心包提供；旧中心没有 `/api/research/mlp-tail`，不能把本机验收当成正式环境已更新。

1. 按原有手动升级流程安装本轮中心包（保留原AI2050_DIST_DIR及账号）。
2. 上传最终 `ai2050-mlp-tail-display-20261108-r2.tar.gz` 及 `.sha256`，核对外包哈希。仅使用含准入审计的r2包。
3. 在新中心程序目录、使用中心虚拟环境执行（把数据目录替换为服务实际的AI2050_DIST_DIR）：

```bash
sha256sum -c ai2050-mlp-tail-display-20261108-r2.tar.gz.sha256
python deploy/mlp_tail_pack.py import --archive /上传目录/ai2050-mlp-tail-display-20261108-r2.tar.gz --data-dir /实际中心数据目录
```

导入器逐文件核对大小和SHA-256，拒绝缺件、路径穿越、链接、重复成员和不同版本覆盖。先在数据目录的独立staging校验，成功后原子激活。同一包再次导入会校验现有文件并返回already_installed；不修改账号，不启动模型。

4. 在正式客户端「上传研究包」上传 `ai2050-research-mlp-tail-20261108.tar.gz`（约4MB），由已有研究包协议写入报告、每个单元观察卡、预注册、方法源码、反例和空间绑定。**这个小包只含研究元数据；不能单独提供所有稠密矩阵和原生参数。**
5. 回查：`GET /api/research/mlp-tail`、`/layers/35`、`/units/35/9727`、`/relations/34/1244?kind=causal&factor=2`。无需开放GPU接口或模型加载接口。客户端按同一快照读取。

展示包约7GB解压，包含全部稠密矩阵、四层完整参数、两极原始值、长文本token、词表参数、干预结果及manifest。大规模原生G/V/A全场约7GB保留于采集节点供重算，不重复随展示包上传。必要公开许可与来源随包保留。本机全部结果仍在tests/glm5/result/mlp_tail_goodfire_v1；中间副本经验证后清理。
