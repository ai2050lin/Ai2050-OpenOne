# 图谱透镜 · 三模块视图设计方案 v1

日期：2026-10-13 ｜ 状态：方案待评审（配套原型 `atlas_module_view_mockup_v1.html`）
作用面：可视化客户端「路线 → 图谱」（AtlasLens 图谱全景的重组方案）

## 1. 背景与问题

现图谱全景（AtlasPanorama）以**特征为中心**：三域泳道（KN/AR/GR）→ 语言族 → FTR 节点，回答的是"我们确证了哪些内部结构"。但项目的使命表述是**两张图谱及其关联**：

1. 外部语言模式族图谱（语言模板 / 句式 / 关系族）；
2. 内部响应图谱（特征 FTR / 机制 MEC / 坐标与层位）；
3. 两图谱之间的关联机制（哪个模板锚定了哪个内部结构，哪些还没有对应）。

现状下三者被拆散：模板在「模板与技术」tab（LANG_TEMPLATES / TM-xx），特征在「图谱全景」，关联关系根本不存在于任何数据结构。用户无法回答"知识网络这个能力，测过哪些句式、各自对应什么编码机制、还缺什么"。

## 2. 设计主张

**把"模块"提升为一等组织单元，把"模板 ↔ 机制关联边"提升为一等数据。**

图谱首屏从「三域泳道」重组为「三模块工作台」：

```
知识网络 KN ｜ 推理功能 AR ｜ 语法机制 GR   ← 模块选择条（带覆盖度徽标）
┌──────────────────────────────────────────────────┐
│  左栏：外部语言模板        中栏：关联边      右栏：内部编码机制  │
│  （外部语言族图谱）     （第三图谱·一等公民）  （内部响应图谱）   │
│  · 句式 pattern                    · 特征 FTR（E 级着色）      │
│  · 示例句                          · 归属族（读出/类轴/谱外…） │
│  · 状态 measured/demo/pending      · 机制 MEC（横切带）        │
│  · 指标 E_read 等                  · 层位 / 坐标线索           │
└──────────────────────────────────────────────────┘
底部 strip：跨模块交叉边（X1–X3）+ 共享机制（MEC 横切）+ 缺口清单
```

边类型三态：
- **实测锚定**（实线）：该模板的实验已作为该特征的 anchor（res/seal sha8 可回查）；
- **采集中**（虚线）：模板已注册、数据在收集，关联为计划口径；
- **缺口**（红色点线）：模板无任何机制对应（待立项），或特征无模板覆盖（证据链来源不清）。

## 3. 信息架构

AtlasLens tab 结构由 4 个调整为 4 个（替换首屏，不新增顶层 tab）：

| tab | 变化 |
| --- | --- |
| 图谱全景 → **模块视图**（默认） | 三模块双栏对照；保留 图形/3D/列表/卡片 四模式切换，四模共享选中态与 FeatureDetail 抽屉 |
| 跨线账本 | 不变（唯一 Phase 时间线） |
| 结果库 | 不变 |
| 模板与技术 | 不变（生产词表面；模块视图只读引用，不重复承载） |

钻取路径：模块 → 模板卡（样本与激活示例）/ 特征节点（FeatureDetail 抽屉，复用现有）→ 研发透镜派实验（onGo('process')）。URL 即状态扩展：`?lens=atlas&atlasTab=overview&module=KN&sel=FTR-01`。

## 4. 数据归位表（研究决策，须预注册后入派生器）

### 4.1 模板 → 模块

| 模块 | 语言模板（LANG_TEMPLATES / TM-xx） |
| --- | --- |
| 知识网络 KN | is_a（TM-07）、attr（TM-08）、part_of、数字与计数（TM-06）、实体×位置等变网格（TM-05）、句式×知识因子网格（TM-04） |

| 语法机制 GR | 句法角色（TM-09）、重复填充句（TM-10）、语言最小对中英（TM-01）、多语言混合句（TM-11）、风格最小对（TM-02） |

### 4.2 模板 → 特征关联（初稿，逐条须能回查 anchor phase）

- is_a → FTR-01/02/17/18（读出几何）、FTR-04（类轴）、FTR-20/21/22/25/26（谱外边界）
- attr → FTR-06（跨模块引用，语法机制）
- 逻辑连接词 / 真假命题 → FTR-03；否定与转折 → FTR-03、FTR-08
- 句法角色 → FTR-06、FTR-23；重复填充句 → FTR-13；语言最小对 → FTR-14；多语言混合 → FTR-24；风格最小对 → FTR-12；实体×位置 → FTR-12；句式×知识 → FTR-01
- part_of、数字与计数：**缺口**（无特征对应，列入缺口清单）

### 4.3 已有结构直接复用

特征 → 模块归属沿用 derive_atlas_tree.py 的 DOMAINS 归位表（不动 registry）；交叉边 X1–X3 与机制层 MEC-01–07 原样渲染为底部 strip。

## 5. 交互与视觉规范

- 模块色：KN #0ea5e9（青）/ AR #d85a30（橙）/ GR #059669（绿）；E 级着色沿用现规范（E2 绿、E2h 绿、E3 橙、E1 蓝），模块色只用于头部与选中描边，不与 E 级语义混用。
- 点击模板或特征 → 高亮其关联边、淡化无关节点；底部详情面板显示陈述全文 / 指标 / anchors sha8。
- 缺口行内标记：模板卡右上角红点 + 缺口清单 strip 汇总（模板无机制 N 项 / 特征无模板 M 项）。
- LIVE/DEMO 范式不变：服务不可达显示空态，不伪造；DEMO 模板（attr/syntax/part_of）带 DEMO 徽标。
- 布局确定性：模板列与特征列均按 id 排序固定行高，关联边在渲染后按 DOM 实测坐标画贝塞尔曲线，无随机；图内标注"示意布局，非模型真实几何"。

## 6. 数据来源与协议

- 派生器扩展：`server/derive_atlas_tree.py` 输出 atlas_tree_v2.json，新增 `modules[].templates[]` 与 `template_feature_links[]`（含 edge_type: anchored|collecting|gap、anchor_phases 引用）；归位表与关联表为 §4 研究决策，改动走预注册。
- 端点：`GET /api/ai-rnd/atlas/tree?schema=v2`（v1 保留兼容 AtlasPanorama/Gallery/Tree）。
- 界面纪律不变：协议键驱动，零实验字面量；模板陈述/指标只引用 LANG_TEMPLATES 与 registry 字段。

## 8. 边界与风险

- 关联表是当前证据的回溯整理，**不等于因果 claim**；边上不画方向性因果箭头，只画锚定关系。
- 一模板多模块归属（如 attr → FTR-06 跨模块）以"主归属 + 跨模块引用"处理，不重复建卡。
- 模板维度（语言/风格/逻辑/句法）与模块（知识/推理/语法）并非一一对应，归位表允许后续随证据修订——这正是需要预注册的原因。
- AR 模块当前仅 FTR-03 一个特征，模块覆盖度失衡应在首屏可见（这本身是研究缺口信息，不用视觉手段掩盖）。

## 9. 附录：语言模板 3D 关系空间（2026-10-13 追加）

配套原型 `atlas_template_space3d_mockup_v1.html`（零依赖 Canvas 3D，离线可开）：

- **节点 = 语言模板**（12 个 LANG_TEMPLATES + TM-xx），按模块聚簇（KN/AR/GR 三区，黄金角确定性布点，零随机），区域地面环 + 模块色；
- **边 = 模板间关系**三类：共享编码机制（灰，标签 = 共享 FTR id，由模板→特征关联表自动派生，非手工维护）/ 同模板家族（紫：关系族/最小对/结构探针/逻辑族/位置探针）/ 跨模块桥（橙虚线，经交叉特征 FTR-05/07/08）；
- **交互**：拖拽旋转 / 滚轮缩放 / 自动旋转开关 / 模块显隐 / 边标签开关；点击节点 → 下方详情面板；
- **详情面板三段**：①测试输入（token 级激活示例着色 + attention 回看注记，数据 = LANG_TEMPLATES demo act_lines/peaks/lookback）②生产采集（TM-xx 节点数/cells/聚合状态/峰位/关联模板/缺口警告）③对应编码机制（关联 FTR 列表：E 级徽章 + 陈述 + 锚定类型）；
- 缺口模板（part_of、TM-06）红圈标记，面板内给立项建议；
- 冒烟：node 无头跑数据段 SMOKE_OK（14 模板 / 16 边 / 无悬空引用 / links 全覆盖 FTRS 表）。
- 落地口径：3D 坐标为「模块聚簇 + 黄金角」派生坐标，界面必须标注非模型真实几何（与 gallery3d/space3d 同一纪律）；正式实施时布点逻辑进 derive_atlas_tree.py v2 的 template_space3d 段，前端零字面量。
