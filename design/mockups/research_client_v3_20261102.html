PROPOSAL · v3 · 2026-11-02

三个目标成立，但「全部基于注意力」「单神经元对应概念」「特征图谱完整即破解」三条都要改写

把项目重述为：在四个冻结数据集上，用一条连续证据链（材料 → 路由 → 特征 → 联合 → 留出预测）解释模型为什么这样预测。目标一测「上下文怎样分出优先级」，目标二测「单元做什么、被谁用」，目标三测「只用图谱能不能复现原模型输出」。三者共用同一份材料、同一个模型快照、同一套证据等级。

有条件可行三条目标互补，且本机已有 350,208 单元的普查与 6 个模式族的干预证据作为起点。真正的瓶颈不是算力，而是证据链在大规模上从未闭合：2 张特征卡对 350,208 个单元、单层 NULL 对全层联合。方案的第一优先级是把「一个数据集 × 一个模式族」的端到端案例真正跑完，再谈扩图谱。

二、研究假设的必要修正

把叙事改成可证伪对象
原思路问题可检验版本
各种语言能力都是模式，全部基于注意力实现注意力做跨位置路由，但变换在 MLP、承载在残差流、收敛在归一化与输出头。热图不是解释。本机已有四次「几何≠计算」。每个模式族分别测：信息怎样被 QK 选中、经 OV 搬运、经 MLP 变换、最终影响 logit。允许不同模式用不同机制，不预设统一实现。
注意力建立模式的层级与优先级「层级」至少三义：语言组合层级（文法）、计算顺序（跨层接续）、竞争强弱（条件化优先级）。混用会让结论无法证伪。softmax 权重不是优先级。优先级 := 冲突最小对下，沿模式方向干预使行为翻转的剂量倒数；并平行报告 J-space 因果效应排序做交叉验证。计算顺序用跨层 patch 定，组合层级用文法定。
参考 Goodfire 逆向全部 MLP 神经元普查可做（已做 350,208），但「标签大全」≠ 机制图谱。2026-10 论文证明最忠实的那批 transcoder 特征多数就是原生神经元。原生神经元为主轨、SAE/transcoder 为对照轨；每张特征卡必须有自然激活、留出选择性、unembedding、干预、上下游、反例、字典保真度。
两者结合即可破解语言编码拼两套可视化不产生计算机制；跨 prompt 聚合与忠实性是行业公认难点。用联合图连「外部变量 → 路由 → 特征 → 输出」，验收只有一条：只用图谱预测 lockbox 的损失恢复，并与词法/位置/n-gram 基线比较。

⑤ 独立验收lockbox 预测 + 干预 + 跨模型复现
注意力路由的基本对象
A_lh = softmax(Q Kᵀ/√d + M)　·　s_qk ≈ Σ fᵢᵩ ᵀ W_qk fⱼₖ

QK 解释「为何看这里」，OV 解释「看了做什么」，干预解释「不这样会怎样」。三者缺一不可，注意力分布从不单独命名功能。

联合图谱的唯一验收
R = (L_ablate − L_graph) / (L_ablate − L_original)

R→1 接近原模型，R→0 接近消融。必须报 lockbox、CI、样本量，并与词法身份 / 位置 / n-gram 三条基线并列。

四、与行业最新进展相比

核对至 2026-11-02
方向最新进展本项目位置要吸收什么
原生神经元回潮2026-10《Many Transcoder Features Are Neurons in Disguise》：13 个开源 transcoder（Gemma/Qwen/Llama 1B–27B），最稳定特征的编解码权重与某个原生神经元 cos > 0.6–0.7。优势：本机已有独立证据——L30 同 k 下 neuron_k64 loss-recovered 0.758 vs transcoder 0.608。把「原生优先、字典对照」写进协议；不因 SAE 是热点就跳过原生基线。这条是本项目少见的先于论文的实测。
注意力 QK 归因Anthropic 2025 把 QK 交互分解成特征对并并入归因图：解释「为何这个目标特征选了那个源特征」，而不停在「看哪」。2026 综述把它列为「注意力必须做特征级分析」。短板：本机路由证据集中在少数模式族，且以头级为主，缺特征对级。引入 QK 特征对级归因；用「路由 + 内容」双条件才算机制，避免把路由当运算。
可读表征 / J-space2026-07 Anthropic《Verbalizable Representations Form a Global Workspace》：Jacobian lens 逐层估计激活对最终输出的平均因果效应，得到「准备说但没说」的排序，并通过换坐标翻转答案做因果检验。缺口：本机优先级只有 softmax 与 patch 两种粗糙量。把 J-space 排序作为「优先级」的第二个独立度量：与干预剂量互证。这正好补上「层级与优先级」缺的可操作定义。
SAE 开源生态Qwen-Scope（2026-05）开源 Qwen3/3.5 全层 SAE，14 组权重覆盖 1.7B/8B/2B/9B/27B 与两个 MoE；Gemma Scope 2 覆盖全家族。硬约束：主模型 qwen3-4b 与 qwen3-14b 都不在名单里。本机只有自训 L30 一层。先在有官方 SAE 的 qwen3-8b 上验证方法，再迁移到 4b；或明确接受「自训 + 外部校准」路线。
归因图与忠实性CLT 归因图把 MLP 换成跨层 transcoder，误差节点显式保留；但注意力固定、重构误差限制完整性，且「转码器是否用同一机制」仍未定。优势：有 E 级 taxonomy 与失败账本，不会把漂亮图当结论。误差节点必须进界面，不能只画通路；图必须标「这是某个 prompt 的局部图」。
评测与功效SAEBench（ICML 2025）多维评测、AxBench 显示简单监督基线常强于无监督 SAE；业界共识「代理指标 ≠ 效用」。短板：缺公共基准与多 seed；已发生噪声地板误判（同折 cv_fast −0.10 vs 手写 −0.97）。接入 SAEBench/AxBench 子集做校准；正式结论一律报功效、CI、多重比较。

结论：本项目的真正差异化不是「也做 SAE」，而是把语言学的模式族因子与内部坐标放在同一份冻结材料上对质，并且有失败账本。这是绝大多数可解释性工作缺的一环。

五、分阶段：先把一个案例走通，再扩图谱

阶段共同问题验收（不过不进下一阶段）
P0 · 契约统一数据集/模型/机制/协议/证据统一标识；三套作业合并；顶部全局上下文接入所有页。任一结论能从页面追到冻结文法、模型 revision、代码 SHA、原始分片、判据与审计。
P1 · 一个端到端案例选本地模板族的一个模式族（GR-Q 或 GR-NEG，句类或否定），在 qwen3-4b 上跑完五步。行为门 + QK/OV + 双轨特征 + 原模型干预 + lockbox R 全部有数；失败也完整入账。
P2 · 优先级理论集中测「上下文 vs 记忆」「语义 vs 语法」「肯定 vs 否定」三类竞争。能在未见实体/句式/更深组合上预测竞争胜负；负贡献与反例有明确边界。
P3 · 全层规模全层 Δ 表 + S4/S5/S8 批量判据，把特征卡从 2 张推到全谱；NF4 保真度先过门。特征卡覆盖率与解释率同时报告；NF4 vs bf16 一致性有 CI。
P4 · 跨模型同一冻结协议顺序跑 14b、GLM4，再开开放节点。报告哪些机制跨模型复现、哪些是模型指纹（已有三例）。
P5 · 理论凝练从稳定案例提取条件化路由、特征组合与跨层转移的数学规律。理论能对未见新组合给出可证伪预测，而不只是解释已有样本。
