一、当前版本 × 上一版效果图 × 本综合方案

维度当前生产版本research_client_dataset_centric综合方案
数据集数据集实测、题库、模板、响应族分散；模型选择在 SpaceLens 内，其他页不共享。数据中心思想正确，但有“导入数据包/新建模板”入口；选择器并非每页一致。五个固定公开数据集白名单；顶部全局选择器贯穿所有页面，不提供上传、导入或任意切换外部数据。
研究进展神经元与语言证据丰富，但指标、列表和矩阵同时铺开，数据集口径不连续。三核心指标和折叠层次更清晰，但部分为静态演示，和真实组件尚未对应。沿用三指标，全部按当前数据集×模型计算；执行、审计、证据、lockbox 保真度分轴。
全层 3DTower.jsx 已支持全部层、拖动旋转、滚轮缩放、点击层和跨层连线。只有少量示意层与静态 SVG，不能真正旋转缩放，也没有完整层数。直接复用 Tower 的 Canvas 投影与命中检测；全层始终显示，选中层高亮，右侧进入层内。
AttentionLivePane 有逐层 32 头、头写出能量、注意力分布与参数，但和神经元页分开。只有示意头与简短检查器，缺少头阵列和 QK/OV 数据层级。Layer → Attention → 32 Head → QK 特征交互 / 注意力分布 / OV 写出 / 干预证据。
MLP 神经元NeuronPane 有完整单元阵列、精选单元、上下游；NeuronUnitCard 已有激活分布、极值例句、读出、解释、选择性和干预。特征卡内容较浅，容易把原生神经元和 SAE 特征混为一谈。保留现有单元卡作为“原生神经元”页，新增并列的“SAE 特征”和“因果与上下游”页。
Goodfire 特征现有主线是原生 MLP 单元，没有完整 SAE 字典、重构与稀疏度数据契约。提出 Goodfire 方向，但只有名称和少量指标，没有 Top 激活、分布和字典元数据。Goodfire 风格特征卡包含字典版本、Top 激活上下文、激活分布、unembedding、L0/重构、解释检验、因果与反例。
分布式模板任务、普查、自动测试三套状态；节点、队列、结果和审计入口分散。统一作业对象的方向正确。统一作业继续保留，但强制绑定顶部固定数据集；执行完成不自动提升证据。

二、固定公开数据集：公开源不等于可直接做机制实验

建议首批五个，正式冻结时再确认版本与许可
公开数据集主要模式项目内冻结派生材料机制研究注意事项
CounterFact知识网络、实体—关系—属性实体替换、上下文冲突最小对、答案槽与读出位置区分参数记忆与当前上下文证据，避免把事实准确率当机制。
StrategyQA多跳分析推理中间步骤变量、实体替换、组合深度分层行为门必须通过；区分真实中间计算与答案词复述。
GSM8K数学分析推理数值替换、步数与运算类型控制、最终答案槽控制长度、数字 token 化与草稿文本，不将 CoT 等同于内部机制。
BLiMP语法系统、最小对按语法现象分族、成对强制选择、句式留出适合语法选择性，但不能单独证明完整语言组合能力。
Winogrande上下文、指代与常识竞争指代候选、触发词与上下文最小对防止答案先验和位置泄漏，重点测条件路由与竞争。

客户端只显示项目审核后的冻结派生版本。原始公开数据、派生最小对、discovery/confirm/lockbox 和版本哈希均可查看，但不开放用户任意导入。

三、全层机制空间的四级信息架构

避免一次性显示全模型所有神经元造成“毛线团”
L0 · 全部 Layer全部层板、证据叠加、旋转缩放、点击命中；跨层边只显示当前样本相关子图。
L1 · 单个 Layer残差输入 → Attention → 残差 → MLP → 输出；两侧模块并列。
L2 · Head / NeuronAttention 头阵列与 MLP 全单元阵列；保留原生索引，不按相似度重排。
L3 · QK/OV 或特征卡Head 看 QK/OV 与干预；Neuron 看原生卡、SAE 卡、上下游和反例。
始终保留全局位置面包屑 + 全层选中高亮 + 顶部数据集/模型，任何详情都能返回原层。

五、分阶段实施建议

阶段内容验收
P0 · 全局上下文五个数据集白名单、模型与划分共享；进展和研发先接入。切页不丢上下文；任何指标都能追溯到数据集版本和模型 revision。
P1 · 全层钻取复用 Tower，连接 Layer、Attention、MLP 和现有原生单元卡。36/40 层均可旋转缩放和点击；每层可进入两类模块，返回不丢状态。
P2 · Goodfire 双轨特征接入 SAE/transcoder 数据与并列特征卡，补外部评测。原生与字典特征不混用；重构、L0、因果和反例完整。
P3 · 联合证据当前样本跨层子图、lockbox 保真度和分布式统一作业。从数据样本到机制边、原始分片、审计和预测结果连续可查。
