SYSTEM PROPOSAL · 2026-11-01

从“注意力 + 神经元两条观察线”升级为“数据集驱动的联合机制科学”

目标不是给每个头和神经元贴标签，而是对明确的语言模式族，找到能在未见样本上复现、在原模型上具有因果效应、并能预测模型行为的跨层计算结构。最终成果仍是外部语言模式族图谱、内部结构与响应图谱，以及两图谱之间可执行的映射。

有条件可行三条目标彼此互补，适合现有 qwen3-4b / qwen3-14b / GLM4 和分布式协议；但“全部能力基于注意力”“单神经元对应完整概念”“特征图谱完整即破解”都不能作为预设结论。优先完成少量端到端案例，再扩大覆盖。

一、核心研究假设怎样修正

把宏大叙事改成可被证伪的对象
原思路需要修正的地方建议的可检验版本
所有语言能力都是模式，全部由注意力实现注意力确实做跨位置路由，但 MLP、残差流、归一化与输出读出也参与计算；热图本身不是解释。对每种模式分别测量：上下文信息如何经 QK 被选择、经 OV 被搬运、经 MLP/残差流被变换，最后如何影响 logit。允许不同模式使用不同机制。
注意力建立模式层级与优先级“层级”可能指语言组合层级、跨层计算顺序或竞争强弱，三者不能混用；softmax 权重不是全局优先级。预注册冲突数据集和反事实最小对，以干预后的行为效应定义条件优先级；用跨层因果路径定义计算顺序，用语言文法定义组合层级。
参考 Goodfire 逆向全部 MLP 神经元完整神经元普查可做，但神经元多义、特征分裂、SAE 非唯一和重构误差意味着“标签大全”不等于机制图谱。原生神经元基线与 SAE/transcoder 双轨并行；每个特征卡必须有自然激活、典型上下文、留出选择性、unembedding、因果检验、上下游与反例。
两者结合即可破解语言编码拼接两套可视化不会自动产生计算机制；行业难点正是跨 prompt 聚合、忠实性和完整性。用联合计算图连接“外部变量 → 注意力路由 → MLP/特征 → 输出”，最终只用图谱预测 lockbox 激活与下一 token，和简单基线比较。

二、统一研发体系：一个研究对象、三个引擎、两道独立门

① 数据集 / 文法模式族、因子、最小对、读出位置、discovery / confirm / lockbox
② 行为门确认模型能完成该条件格；失败不作为机制正例
③ 三引擎发现A 字典学习 · B 受控对照 · C 因果归因
④ 联合图QK / OV + MLP / 残差边；保留负边、误差节点和反例
⑤ 独立验收lockbox 预测 + 原模型干预 + 跨数据集 / 模型复现
注意力路由的基本对象
Aₗₕ = softmax(QₗₕKₗₕᵀ/√d + M + P)　·　s_qk ≈ Σᵢⱼ fᵢqᵀ W_QK fⱼk

QK 归因用于解释“为何看这里”；还需 OV、softmax 竞争和干预来解释“看了以后做什么”。

联合图谱的可度量验收
R = (L_ablated − L_graph) / (L_ablated − L_original)

R→1 表示接近原模型，R→0 表示接近消融；必须报告 lockbox、置信区间和词汇身份 / 位置 / n-gram 基线。

三、证据等级与客户端指标

覆盖、执行和证据不使用同一个进度条

E0 · 未研究

只有计划或材料，未产生可复算数据。

E1 · 观察关联

自然前向采集完整，可定位候选头、单元或特征。

E2 · 留出读出

在未参与发现的材料上复现选择性或结构。

E3 · 原模型因果

干预预测兑现，含随机 / 剂量 / 特异性对照。

另设 E4 · 跨族 / 跨模型复现 与 J · 联合预测保真度。界面首屏建议只显示：达 E3 的模式族数、达 E3 的特征卡数、lockbox 的 R 及其简单基线；任务完成率、token 数和节点数放入展开层。

四、与行业最新进展相比：优势、短板与吸收方式

调研截至 2026-11-01
行业方向最新可用进展本项目相对位置应怎样改进
Goodfire / SAE 特征开放 SAE、特征引导、推理模型特征；Goodfire 也明确指出 SAE 并非完整解法，2026 年进一步研究曲线流形。优势：原生坐标与语言模板结合深。
短板：字典基线和外部评测不足。		保留神经元主线，同时引入 SAE / transcoder 对照；用 SAEBench 的多维指标，不以 L0/MSE 或自动标签作为唯一质量。
Anthropic 归因图 + QKCLT 归因图追踪特征计算；2025 年 QK attribution 开始解释注意力为何落到某处。优势：已有 QK 与跨层响应积累。
短板：替换模型忠实性和跨 prompt 聚合不足。		把 QK 特征交互、head loading、OV 路径接入现有模板；关键边必须回到原模型干预，不用替代模型图直接下结论。
神经元基线回潮2026 年研究重新显示 pre-down-projection 神经元基可形成稀疏有效回路，挑战“必须先用 SAE”的假设。优势：项目长期做单坐标 / 单神经元研究，方向得到新证据支持。把 RelP、AttP* 等外部归因基线放在同一数据上比较；证明新增方法比简单神经元基线多解释了什么。
评测与负结果SAEBench 表明代理指标不等于实际效用；AxBench 等提示简单监督基线常强于无监督 SAE。优势：有失败账本与预注册文化。
短板：缺公共基准、功效与多 seed。		加入 SAEBench / AxBench / MIB 校准；所有正式结论报告功效、置信区间、多重比较和反例。
NDIF / Neuronpedia 开放生态远程内部访问、共享预加载模型、在线特征与归因图浏览，降低大模型机制研究门槛。优势：已有分布式任务、租约和结果包。
短板：三套作业状态、志愿者校验与产品深链不足。		统一作业对象，增加签名任务包、隔离运行、重复计算和审计；界面从作业直接深链到样本、图和原始文件。

五、阶段性大任务：先做完整案例，再扩图谱

阶段共同问题进入下一阶段的验收
P0 · 契约统一统一数据集、模型、机制、协议和证据的对象标识；合并三类分布式作业视图。任一结论可从页面追溯到冻结文法、模型 revision、代码 SHA、原始分片、判据和审计。
P1 · 三个端到端案例知识属性冲突、否定真值、句类线索各做一个 qwen3-4b 完整案例。三个案例都完成行为门、QK/OV、MLP 双轨特征、原模型干预和 lockbox R；失败也完整入账。
P2 · 模式竞争理论集中研究上下文 / 记忆、语义 / 语法、肯定 / 否定的动态优先级。在未见实体、句式和更深组合上预测竞争胜负；负贡献和反例有明确边界。
P3 · 跨模型与规模化同一冻结协议顺序跑 qwen3-14b、GLM4，再扩数据集和开放节点。报告哪些机制跨模型复现、哪些是模型特异；新增覆盖带来实际预测增益。
P4 · 理论凝练从稳定案例中提取条件化路由、特征组合和跨层转移的数学规律。理论不仅解释已有样本，还能对未见过的新组合给出可证伪预测。
