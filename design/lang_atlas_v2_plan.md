# 语言图谱 v2：研究方案与界面方案

> **流程修订（2026-10-30 晚）**：入口已改为「先选数据集 → 三个类型各测一遍 → 跨数据集比普遍规律」，
> 实现与实测见 `design/lang_atlas_dataset_flow.md`（新增 `server/lang_atlas_service.py` 与
> `frontend/src/components/v8/LangAtlas.jsx`）。本文档剩下的部分保留为**方法论与原有盘点**，
> 其中「证据阶梯 L1–L4」「注意力三问」仍然有效；入口设计以修订版为准。
>
> 修订的结论：C-Eval 169 题上 28 个普遍头全部落在 L24–L35，前 24 层为 0；换到 CMMLU 2301 题，
> 这 28 个全部复现、层范围不变。**「答案收口集中在最后三分之一网络且跨能力类型共用」成了第一个稳定规律。**

> 前提：语言能力本质是**模式**——知识网络、分析推理、语法规则都是「在某种输入条件下，某种映射稳定成立」的东西。
> 注意力机制是这些模式的提取器。所以语言图谱要回答的不是「有哪些语言现象」，而是
> **每个模式的内部特征是什么、由哪些注意力头与 MLP 单元承载、其中哪些真的被用上了**。
>
> 本方案基于 2026-10-30 对现有实现的实测盘点，不含推测性数据。

## 1 现状实测：证据是「一条腿」

|---|---|---|---|---|---|---|
| KN.ISA | 上下位（是一种） | 3 | 3 | 0 | 24 | 5–32 |
| KN.CAT | 名词语义类别 | 2 | 2 | 0 | 28 | 35–40 |

| KN.ORIGIN | 来源与产地 | 0 | 0 | 0 | 0 | — |
| RS.NEG | 否定与真值 | 3 | 5 | 0 | 16 | 7–28 |
| RS.COND | 条件推理 | 0 | 0 | 0 | 0 | — |

**9/14 有表征证据，1/14 有机制证据（MLP 选择性），0/14 做过注意力分析，5/14 完全空白。**

已有的表征证据质量不差：每个拼图有 4 个读出位置（target / cue / final / probe_answer）× 41 层曲线，
带峰值 `{layer, sep, acc, rep}`、留出复现、token 身份基线、词表基线、框架泛化。
KN.ISA 峰值 L40 sep 7.02 acc 1.00；GR.CONSTR 峰值 L2——差了两个数量级的「深度」，这本身就是可研究的信号。

但这条腿只回答「**对比方向存在且可分**」。它不回答：

- 谁在算？（头 / 单元）
- 算的是「模式」还是「表层词表」？
- 模型真的用了吗？

## 2 诊断：三个缺口

**缺口 A：注意力完全缺席。** 现有神经元主线只做 MLP（普查激活 + 单元选择性 + 前后锥），
注意力只作为电路的「过路口」（`neuron_circuit_service.py` 里经注意力头的路径），从未被当作被检验对象。
而用户的前提——「注意力提取了模式」——在系统里没有任何测量支撑。

**缺口 B：模式之间没有边。** 现在是「大类 → 语言族 → 条目」的三级目录，本质是一本辞典。
辞典无法回答唯一真正有价值的问题：**两个模式是不是同一套机制在承载**。
（GR.CONSTR 峰值 L2 与 KN.CAT 峰值 L35–40，很可能是完全不同的机制族；而 KN.ISA 与 RS.NEG 可能共享同一批中继头。）

**缺口 C：证据不可比。** 每个模式只有自己的曲线，没有统一的、可放进同一坐标系的量。
因此无法排序、无法聚类、无法跨模型对齐——这三点正是「图谱」的定义。

## 3 重新定义：模式 = 一个可测签名

把「模式」从目录节点改为一等对象。一个模式在某个模型上的**签名**是五元组：

```
S(pattern, model) = ⟨ P 位置画像, L 层画像, H 头集, U 单元集, R 稳健性 ⟩
```

| 分量 | 含义 | 可算量 |
|---|---|---|
| **P 位置画像** | 对比信息在句子的哪些位置被读取 | 对比位置对各相对位置的注意力质量分布（相对位置桶：前一词 / 前二词 / 主语 / 句尾 / 标点 / 同词复现 / 其余）+ 熵 |
| **L 层画像** | 何时开始可分、何时达峰 | `onset` = 首次达到可读判据的层；`peak` = argmax sep；两者之差 = **计算跨度** |
| **H 头集** | 哪些头对这个对比敏感，各自是什么类型 | 每头 `{layer, head, diff, js, keys, ov_align, qk_align, type}` |
| **U 单元集** | 哪些 MLP 单元承载，前后是否自洽 | 选择性单元 + 其 `bowtie` 自洽角 θ 与沿轴对齐 |
| **R 稳健性** | 结论有多硬 | 留出复现率、置换族错误率、跨模型一致率、消融后变化量 |

**「内部特征」就是 P 和 H 的具体取值**，不是形容词。举例（目标形态，当前尚未采集）：

> RS.NEG 的内部特征 = 偏置点在否定词位（P 熵 0.8）、onset L7、峰 L12；
> 主承载 4 个头：L3H11（previous-token，ov_align 0.41）、L7H2（否定—谓词桥，0.38）、
> L9H19（句尾汇聚，0.22）、L12H5（类型：induction，0.19）；消融 L7H2 后 sep 掉 63%、行为掉 21% → 控制轴成立。

这段文字里每个数字都必须能点回证据。这就是 v2 的目标形态。

## 4 注意力的三问：只测第一问等于没测

这是整个方案里最容易被做错的地方，先立纪律。

| 问题 | 测什么 | 方法 | 失败的典型长相 |
|---|---|---|---|
| **① 敏感** | 最小对两句，这个头的注意力分布变了没有 | 同位置注意力分布的 JS 散度 + 注视点位移 | 大量头「看起来变了」，其实只是句长差一个 token |
| **② 传输** | 变了的方向，是不是朝着对比轴 | `ov_align = cos(W_O^h W_V^h r̂, r̂)`；`qk_align = cos(W_Q^h r̂, r̂)` | 分布变了但与读出轴无关 → 视觉上头很亮，机制上头是路人 |
| **③ 因果** | 拿掉它，对比还剩下多少 | 头级零消融 → Δsep / Δ行为 | 「注意力权重高」被当成「重要」——这两件事在本项目的前后锥里已经被证伪过一次（强度 0.345、沿轴对齐 −0.000） |

**红线：①→②→③ 必须顺序通过，才能写「这个头承载这个模式」。只过①的一律记为「相关」，不进结论。**

已知的反例正好可以拿来校准：块 18·U100 的上下游锥里，最强写入者强度 0.345 但沿读轴对齐 −0.000，
**强度高、方向错**。头级分析会出现完全一样的情形，且注意力图比权重更漂亮、更容易骗人。

## 5 测量阶梯与判据

在现有 A–F 六节之上，把证据组织成四级阶梯（每级独立，不允许跳级）：

```
L1 行为   模型分得清吗    行为门（已有）        通过率 + 成对间隔
L2 表征   有没有编码      线性读出 + 层曲线（已有） 留出 sep / acc / 复现
L3 机制   谁在算          注意力差分 + OV/QK 对齐（新）  diff / ov_align
L4 控制   用没用          头级与单元级消融（新）    Δsep / Δ行为
```

等级判据沿用现有 `LEVELS`，但**把「控制轴」从「未检验」推进到可检验**，新增两条：

- `L3 机制` 成立条件：至少 1 个头 `diff > 阈值` **且** `ov_align > 0.25` **且** 在留出对上复现；
  或至少 3 个 MLP 单元选择性通过置换检验且前后锥自洽角 < 60°。
- `L4 控制` 成立条件：消融 top-1 头或 top-3 单元后，`Δsep < −30%` 或 `Δ行为 > 10pp`，
  且随机消融同数量头/单元的对照不变（这一条是防止「消融任何东西都掉」）。

## 6 研究路线

### P0 采集器（1 天，最关键）
在 `live_analysis_service.py` 的 `output_attentions=True` 已有实现上加一个「任意位置行」提取：
现在只返回 `attn_last`（末位）与全矩阵 top-8，而模式分析需要**对比位置**那一行。
产出 `POST /api/lang/attn`：给定文本 + 位置 + 层范围，返回 `[L][H][T]` 的行（截断到语句长度，约 36×32×40 个浮点，~50 KB）。
验收：一句话 < 1 s，与 `attn_last` 在末位一致（回归断言）。

### P1 差分扫描（2 天）
对每个模式的**已通过行为门**的最小对，逐对算 `diff`（同位置注意力分布的 JS）与注视点位移。
聚合到 `(layer, head)` 得 `Δ[l,h]` 矩阵。产出「模式 × 层 × 头」效应热图。
验收：GR.Q（已有 3 次选择性运行可交叉验证）上，头级 top-10 与 MLP 选择性运行的最高层出现一致或可解释的差异。

### P2 传输对齐（1 天）
纯权重运算，无需前向：`W_O^h W_V^h r̂`、`W_Q^h r̂` 与读出轴 `r̂` 的夹角。
`r̂` 直接复用每个拼图已拟合的 LDA 轴（`pieces[].axes`）——**这一步之所以便宜，是因为 L2 已经做完了**。
产出每头 `{ov_align, qk_align}`，与 P1 的 `diff` 正交组合成二维散点，四象限命名：
`敏感+传输`（候选承载头）/ `敏感不传输`（旁听）/ `不敏感但传输`（通道）/ `都不是`。

### P3 消融（2 天，GPU 约 40 min）
每个模式取「敏感+传输」象限 top-3 头 + 选择性 top-3 单元，做零消融，测 `Δsep` 与 `Δ行为`。
对照组：随机同数量头/单元。产出 `control` 段。
**这是唯一能把「相关」升级为「因果」的步骤，不能省。**

### P4 谱图（3 天）
把 14 个模式的签名放进同一坐标系：`onset` × `peak` × `P 熵` × 头类型分布 × `|U|`。
聚类 + 连边（共享头 / 共享轴 / 跨模型一致）。
产出：机制族划分（预期至少 3 族：早层句法型、中层关系型、晚层知识型），以及「哪些模式共用中继头」。

### P5 系统化说明（持续）
每个模式一页，形态与第 3 节的样例一致，全部数字可点回证据。跨模型（qwen3-4b / DS7B / GLM4）成表。

## 7 界面方案：从「读文章」改为「看矩阵，再下钻」

### 7.1 为什么必须改
14 个模式 × 36 层 × 32 头 × 3 个模型 = 一张五维表，用它去支撑一篇文章是错配。
现有 A–F 六节的写法对**单个模式的取证**是对的，但作为入口是错的：进来先读三千字，看不出模式之间的关系。

**保留 A–F 作为「模式卡」，新增两个视图作为入口。** 不是推倒重来，是补上前置的「地图」与「检验台」。

**视图① 谱图**：模式是点，坐标是**测量出来的层画像**（不是人工分类），所以「相邻」意味着「机制相似」。
边的定义可切换：共享承载头 / 共享读出轴 / 跨模型一致。
用色 = 聚类出的机制族。这一步把「辞典」变成「图谱」。

**视图② 模式 × 机制矩阵**：每行一个模式，列是机制位置（早/中/晚层的头、MLP 单元、控制是否检验、等级）。
格子填实心度 = 该处证据强度。**一眼能看出「哪个模式还只有表征证据」**——现在 13/14 都是空的，
这张表本身就是一个诚实的进度看板。

**视图③ 模式卡**（原 A–F，改造两处）：
- 原「E 由哪些神经元承载」拆成 **E1 注意力头** 与 **E2 MLP 单元** 两栏；
- 新增 **F′ 控制与结论**：消融结果 + 三条轴（读出 / 控制 / 跨模型）。原来的 F 只有两条轴且控制恒为「未检验」。

### 7.4 与神经元主线的关系

现有「空间 / 神经元」是**自下而上**：从单元出发，看它的前后锥、它的选择性。
语言图谱 v2 是**自上而下**：从模式出发，落到头与单元。
两者在同一个对象上会合：**`B{block}·U{unit}` 与 `L{layer}H{head}` 都是可跳转的锚点**。
语言图谱里的「E2 单元」直接跳「空间 → 神经元 → 选中该单元」，前后锥已经在那一页。
反向也补：神经元页的单元卡如果参与过某个模式的选择性运行，显示「承载模式：KN.ISA」。

**这是两条主线唯一的硬接口，值得优先做。**

## 8 数据契约

新端点：

| 方法 | 路径 | 说明 | 成本 |
|---|---|---|---|
| POST | `/api/lang/attn` | 文本 + 对比位置 → 逐层逐头注意力行 | <1 s / 句 |
| GET | `/api/lang/pattern/{id}/heads` | 该模式的 `Δ[l,h]`、`ov_align`、`qk_align`、候选头集 | 依赖 P1/P2 缓存 |
| GET | `/api/lang/atlas/signature` | 全部模式的签名（谱图数据） | 读缓存，<100 ms |
| POST | `/api/lang/pattern/{id}/ablate` | 头/单元消融，返回 Δsep / Δ行为 | ~2 s / 次，需 GPU |

签名结构（`lang_pattern.v2`）：

```json
{
  "pattern": "RS.NEG", "model": "qwen3-4b", "run": "...",
  "levels": ["affirm", "neg"], "n_pairs": 8,
  "behavior":   {"gate": "passed", "acc": 0.94},
  "representation": {
    "readout": "target",
    "onset_layer": 7, "peak": {"layer": 12, "sep": 3.41, "acc": 0.97, "rep": 0.81}
  },
  "attention": {
    "position_profile": {"prev": 0.31, "subj": 0.22, "punct": 0.18, "other": 0.29},
    "position_entropy": 0.80,
    "heads": [
      {"layer": 7, "head": 2, "diff": 0.44, "js": 0.19, "ov_align": 0.38,
       "qk_align": 0.21, "type": "neg-predicate-bridge", "replicated": true}
    ]
  },
  "units": {"selective": [[12, 903, 0.41]], "bowtie": [[12, 903, 63.2, 0.31]]},
  "control": {"ablated": [["head", 7, 2]], "delta_sep": -0.63, "delta_behavior": -0.21,
              "sham_delta_sep": -0.04},
  "signature": {"onset": 7, "peak": 12, "span": 5, "n_heads": 4, "n_units": 3,
                "family": "mid-relation", "robustness": 0.81},
  "level": {"read": 2, "control": 1, "cross_model": 1}
}
```

`bowtie` 字段是四元组 `[block, unit, θ°, 沿轴对齐]`，直接来自已实现的 `/api/neurons/bowtie`——
**语言图谱和神经元主线在数据层第一次真正接上**。

## 9 语料缺口：先把空白补上，再谈机制

14 个模式里 5 个完全空白（KN.PART / KN.ORIGIN / RS.COND / RS.CAUSE / RS.COMPARE）。
**没有最小对的模式不可能有机制结论**，所以补语料优先级等于机制分析。

另外建议新增三个模式，因为它们正是「注意力提取模式」这一前提的最佳测试对象：

| 新模式 | 为什么必须有 |
|---|---|
| `XL.TRANS` 翻译对等 | 用户明确提出。中英同义句对，检验「跨语言是否共用同一读出轴」——这是注意力最可能有专责头的场景，也是现有体系完全没有覆盖的 |
| `RS.COT` 多步推理链 | 「分析推理」目前 3 个模式全空。多步推理的 `span`（onset→peak）应当显著大于单步，是可证伪的预测 |
| `GR.AGREE` 主谓一致 / 长距离依赖 | 经典 induction head 场景，已有大量文献基线，用来**校准整条流水线**：如果在这一项上测不出 induction 头，说明采集器有问题，而不是模型没有 |

`GR.AGREE` 是校准项，建议 P1 第一个做。

## 10 已知失效模式与红线

1. **注意力权重 ≠ 重要性。** 本项目已有反例（强度 0.345 / 沿轴 −0.000）。必须 ①→②→③。
2. **句子长度混淆。** 最小对两句 token 数常常不同，JS 散度会把「多一个 token」算成效应。对策：先对齐位置，再算；句中长度不一致的对照单独记录。
3. **读出轴依赖拟合集。** LDA 轴在发现集上拟合，轴本身随样本变化。`ov_align` 是「对这个轴的投影」，不是「对内禀方向的投影」——`|ov_align|` 小可能只是轴不稳。对策：报告 bootstrap 下轴的稳定性，轴不稳时不做结论。
4. **SwiGLU 规范自由度。** MLP 侧的 θ 与范数不是内禀量（已知）。头侧无此问题（W_Q/W_K/W_V/W_O 是线性的），这是头级分析比单元级分析更干净的地方——**可以作为一个正面理由写进方案**。
5. **单模型结论不外推。** 跨模型一致率是签名的必要分量，缺它只能写「在 qwen3-4b 上」。
6. **不要用示意数据填格子。** 矩阵里没有证据就留白，空着比填假的好。现有「未测」纪律必须延续到新视图。
