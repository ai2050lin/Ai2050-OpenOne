# 神经元「3D 前后锥」视图（neuron_bowtie.v1）

设计时间：2026-10-29 11:40 ｜ 位置：研究工作台 · 空间 · 神经元 → 选中任一 MLP 单元 → 卡片一
代码：`server/neuron_bowtie_service.py`、`frontend/src/components/v8/Bowtie3D.jsx`

## 1 为什么要这个视图

Cammarata《Neural Networks Are Already Clean》给出的读法是：判断一个单元是否「读得通」，不能只看它自己
的读出标签，还要看它的**前后**——上一层谁喂它、下一层谁用它，并且这三处说的是不是同一个概念。

现有界面只做到一半：`CircuitPane` 是一张二维列表（谁喂它、谁读它、分数多少），层塔上画了几根跨层连线。
列表能读数字，看不出形状；层塔能看连接，看不出概念是否对得上。缺的是**几何**：
「上游写出的方向」与「目标读取的方向」相差多少，「目标写出的方向」与「下游读取的方向」相差多少。

这个视图把这几件事放进同一个三维坐标里：y 轴是层（前 / 本 / 后），水平面是方向空间。

## 2 数学定义

对块 $L$ 的第 $i$ 个 MLP 中间单元：

| 量 | 定义 | 含义 |
| --- | --- | --- |
| 读方向 $r_i$ | `gate_proj.weight[i]`（残差空间） | 什么输入会让它兴奋（一阶代理） |
| 写方向 $w_i$ | `down_proj.weight[:, i]` | 它每单位激活往残差流里加什么 |
| 自洽角 $\theta$ | $\arccos(\hat r_i \cdot \hat w_i)$ | 检测与写出是否同向 |
| 平面 | $a_1 = \hat r_i$，$a_2 = \dfrac{\hat w_i - (\hat w_i\cdot a_1)a_1}{\|\cdot\|}$ | $r_i$ 与 $w_i$ 张成的二维（精确，不降维） |
| 写轴坐标 | $\hat w_i = (\cos\theta,\ \sin\theta)$ | 平面内写方向的位置 |

每个邻居的方向 $d_j$（上游取它的写方向，下游取它的读方向）投影到同一平面：

$$(u_j, v_j) = (\hat d_j \cdot a_1,\ \hat d_j \cdot a_2)$$

于是判据变成两条可直接看的几何命题：

- **上游**收敛到 $(1, 0)$ ⟺ 它写的正是目标读的；
- **下游**收敛到 $(\cos\theta, \sin\theta)$ ⟺ 它读的正是目标写的。

三个汇总指标（后端返回，界面顶部显示）：

| 指标 | 公式 | 读法 |
| --- | --- | --- |
| 自洽角 | $\theta$ | < 30° 概念一致；30–60° 部分偏离；> 60° 更像「检测 A 写出 B」 |
| 上游对齐 | $\overline{u_j}$ | 1 = 全部沿读轴 |
| 下游对齐 | $\overline{u_j\cos\theta + v_j\sin\theta}$ | 1 = 全部沿写轴 |
| 横向偏离 | $\|v_j\|$（下游为 $\|v_j\cos\theta - u_j\sin\theta\|$） | 越大越说明它写/读的是另一回事 |

权重路径强度沿用 `neuron_circuit_service` 的口径（残差直连 / 经注意力头 OV），因此分数与列表视图一致。

## 3 怎么读这个图

```
        ┌──────────── 块 L+1 · 读取者 ────────────┐     ← 下游：应落在写轴
        │              ● ●  ●                     │
        └────────────────┬───────────────────────┘
                         │  蓝虚线
        ┌────────────────┼──── 块 L · 目标 ───────┐
        │        读轴 →  ●  ↖ θ 131°   ↖ 写轴     │     ← 两条轴张开的角度就是自洽角
        └────────────────┬───────────────────────┘
                         │  橙实线
        ┌────────────────┼──── 块 L−1 · 写入者 ───┐
        │              ● ●                       │     ← 上游：应落在读轴
        └────────────────────────────────────────┘
```

- **层板**只是排列，不代表模型几何；平面里的位置才是数据。
- **节点大小** = 沿轴对齐 |投影|（路径强度含经注意力头的路径，放在清单里，否则会与位置矛盾）；
  **填充色** = 普查分型（T1–T6）；**描边粗细** = 该节点标签与目标标签的 token 重叠；
  **描边颜色** = 哪一侧（橙 = 上游，蓝 = 下游）。
- **编号**与下方清单一一对应（上1–上6 / 下1–下6），清单给出 B/U、读出词、强度、对齐、偏离，点一行即以它为新的目标继续走。
- **蝴蝶结收拢** = 前后一致：两侧节点都贴在自己那根轴上，且两根轴夹角小。张开 = 不一致。
- 径向做了 $r^{0.6}$ 的显示展开（实测投影半径多在 0.1–0.4，不展开会挤成一团）；只改径向，不改角度，精确值在清单里。

实测样例（块 18 · U100）：$\theta = 122.1°$，上游对齐 0.168、下游对齐 0.092、token 重叠 0。
这是一个典型的「前后不一致」单元：它检测的方向和写出的方向几乎相反，前一层最强写入者（U6，0.495）也只有
0.41 的沿轴对齐。按 Cammarata 的判据，这个单元的标签不足以支撑「它表示 X」。

## 3.1 先看分布：这张图大多数时候是张开的

视图好看不等于结论成立，所以先量一下这个指标本身。抽样（块 6/12/18/24/30 × 每块 6 个单元，共 30 个）：

| 块 | θ 中位 | 范围 | 上游对齐中位 | 下游对齐中位 |
| --- | --- | --- | --- | --- |
| 6 | 91.6° | 87–110 | +0.008 | −0.005 |
| 12 | 89.7° | 75–101 | +0.045 | +0.051 |
| 18 | 84.2° | 53–118 | +0.042 | +0.045 |
| 24 | 87.3° | 51–97 | +0.033 | +0.066 |
| 30 | 93.9° | 77–106 | +0.034 | +0.025 |

θ < 30° 的单元 **0/30**，> 60° 的 28/30。也就是说，绝大多数单元画出来都是**张开的蝴蝶结**。

这里必须先排除「高维随机向量本来就不相关」这个平凡解释。直接读块 18 的权重做零模型：

| 量 | 随机期望 | 实测 |
| --- | --- | --- |
| 单元自身 gate 行与 down 列的 \|cos\| | 0.0198（= 1/√2560） | **0.245**（400 个单元） |
| θ 中位（400 个单元） | 90° | 91.6° |
| 目标读方向 vs 9728 个写方向的 top-1 | 0.162 | **0.495**（U100 的上游 U6） |
| 同上 top-6 均值 | 0.116 | **0.226**（U100 上游） |

读法：\|cos\| 是随机值的 12 倍，说明读/写之间**确实有结构**；但符号是混的（中位 90°），
说明没有全局的「同向」趋势——既有强对齐，也有强反对齐。单条最强链路（0.495）远高于随机 top-1（0.162），
邻域平均（0.03–0.07）却接近 0。结论是：**强连接存在，但「邻域一致」在这套权重口径下不普遍。**

还有一处必须讲清：清单里的「强度」取的是 `max(gate 行, up 行, 经注意力头)`，而「对齐」只对 gate 轴投影。
实测两者经常不一致（强度 0.2、对齐 0.04），说明这些连接多数不走 gate 轴，而走 up 行或经头路径。
所以画布上节点大小改用**沿轴对齐**，不用强度——否则会出现「点很大却离轴很远」的自相矛盾。

## 5 已知问题与边界（必须写在纸面上）

1. **读方向不是不变量。** SwiGLU 的激活是 $\mathrm{silu}(W_g x)\odot(W_u x)$，单个 gate 行只在「门控因子」意义上
   有定义；真正的读方向依赖工作点（$0.5\,u\,W_g + \mathrm{silu}(g)W_u$ 一类）。所以 $\theta$ 是**一阶代理**，
   不是内禀量；换成 up 行或按语料求最小二乘读方向（$r = \mathbb{E}[a x]/\mathbb{E}[a^2]$）会得到不同的角。
2. **logit lens 标签在中间层噪声极大。** 实测 U100 的 gate 读出是 ``` ` ```、``` `- ``` 这类碎 token，
   down 读出才是 `claimer`（与普查「首位读出」一致）。权重行本身没有经过 tuned lens 校准。
   界面上把标签降为辅助信息，判断以几何为准。
3. **权重路径 ≠ 因果。** 分数是线性化路径强度，没有经过消融/干预。「读得出 ≠ 控得住」在这里同样成立：
   这个视图回答的是「结构上像不像一条电路」，不是「模型是否真的用它」。
4. **只对同结构模型有效。** 依赖本机权重，跨模型（qwen3-14b / GLM4）需要各自加载后重算，且坐标不可比。
5. **$\theta$ 接近 0 时平面不稳定。** $a_2$ 由 $\hat w - \cos\theta\,\hat r$ 得到，$\theta < 5°$ 时会退化，
   代码里用 $\|t_2\| < 10^{-3}$ 判断并退回一个正交方向；此时 $v$ 分量没有意义，只看 $u$。
6. **显示变换。** 径向 $r^{0.6}$ 是为了分辨，不能用来比较「谁离轴更近」；比较请用清单里的 align/off。

## 6 下一步

1. **把代理换成数据。** 用普查激活与同语料残差求每单元的最小二乘读方向 $r = \mathbb{E}[a x]/\mathbb{E}[a^2]$，
   让 $\theta$ 不再依赖 gate/up 的选择；这是把这个视图从「结构假设」升级为「实测关系」的关键一步。
2. **多跳。** 现在只展开前后各一层。沿电路连走两跳（$L-2 \to L \to L+2$）才能看出「中继头族」这类结构；
   数据结构已经支持（点编号即重算），需要的是把路径叠在同一张图上。
3. **接上干预。** 对上游对齐最高的几个单元做 steering / 消融，验证「对齐高」是否预测「干预有效」。
   这是把 E 级升到 E2/E3 的唯一途径，也是判断这个视图是否有预测价值的硬指标。
4. **和 P0 归因对齐。** 3280/3281 的写入头聚集与份额归一化结果可以直接画进这个视图：
   把「共享承载头」标在同一平面上，看它们是否在写轴上共位。
