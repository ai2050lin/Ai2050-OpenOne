# 注意力 × 神经元 联合方案 v1（模式路由与优先级、神经元图谱、联合机制）

> 日期：2026-10-31。性质：设计方案，不是实验结果。执行记录写入 `research/claude/docs/AGI_CLAUDE_MEMO.md`（Phase 263 起）。
> 依据：用户提出的新方向（语言能力 = 模式；注意力根据上下文建立模式的层级与优先级；MLP 参照 Goodfire 做神经元逆向；两者结合破解编码）、
> Phase 256–262 的实测结果，以及 `design/unified_dual_sided_plan_20261031.md`、`design/system_audit_20261031.md`。

## 0. 一句话

保留新方向的三个目标，但先把它们改写成**可证伪、可度量**的问题：注意力侧回答「冲突时谁赢、在哪一层决出、靠哪些头、哪些线索能翻转」；
神经元侧按归因优先级给单元做四轴卡片；两者合成归因图，进度只用一个数——留出材料上的预测保真度。

## 1. 对新方向的三处修正

| 原表述 | 修正 | 依据 |
| --- | --- | --- |
| 各种模式「全部基于注意力机制实现」 | 改为假设 H-attn：按模式分解输出贡献（注意力头 / MLP / 嵌入直连），逐模式记录注意力占比 | 事实属性主要存在中前层 MLP、注意力负责搬运（ROME；Geva et al. 2023）；算术等有大量 MLP 启发式单元（Nikankin et al. 2024） |
| 「层级结构与优先级」 | 优先级 = 两种模式冲突时的胜者与决出层；层级 = 模式 A 的输出成为模式 B 的输入（跨层路径修补 / 归因图的边），不用层号先后代替 | 没有操作定义就无法检验；冲突范式已有对标（Ortu et al. 2024 "Competition of Mechanisms"） |
| 神经元「完整图谱」 | 完整 = 每个单元都有四轴卡片（可读 / 读出 / 控制 / 连接）与证据等级，不要求每个单元都有干净含义；单元讲不清时用单元组或 ≤10 维子空间作原子 | EXPL-v1 可输 0.49；APPX-8 单坐标覆盖 1.9–5.9%；Phase 262：同 k 下神经元损失恢复 0.76 > transcoder 0.61，但第 30 层 10 个高选择性单元消融无效 |

**方法纪律（来自 Phase 262 C1 校准）：** 单组件消融 / 修补会被下游补偿误导（GPT-2 IOI 上名称搬运头被排错、两个符号相反）。
注意力头的结论必须同时报告**直接作用**（DLA：头输出经最终归一化投到答案对数几率差）与**总效应**（消融 / 修补），并用路径修补区分「搬运」与「上游」。

## 2. 三个目标的可测版本

### 目标一：注意力的模式路由与优先级

- **材料：** 冲突数据集——上下文与记忆冲突（中文 counterfact，实体与属性改写）、语法与语义冲突、否定与疑问覆盖（GR-NEG、GR-Q）、指令与常识冲突。每条材料带无冲突基线（行为门：模型在无上下文时知道该事实）。
- **测量：**
  1. 逐层 logit lens「赛跑曲线」：上下文答案与记忆答案的对数几率差随层变化，决出层 = 差值最后一次越过 0 且之后保持同号的层；
  2. 逐头直接作用（DLA）与逐头均值消融总效应并列；
  3. 路径修补：上游头 → 下游头的 Q / K 输入，回答「为什么看这里」（QK 归因）；
  4. 线索操纵：对冲突句加入不同可信度与重复次数的线索（如「据说」「事实上」、重复一次 / 两次），记录胜率变化。
- **产出：** 模式优先级表（每种冲突一行：上下文胜率、决出层、负责的头、能翻转胜负的线索）。

### 目标二：MLP 神经元图谱（Goodfire 式，按归因优先级推进）

- 每个数据集上按归因质量（单元对答案对数几率差的直接作用，加跨层间接作用）排序，只对排在前面的单元跑 goodfire_probe.v1 四轴测量与自动解释打分。
- 单元卡沿用 §5.3 特征卡字段；来源字段区分神经元 / 字典特征 / 对照方向。transcoder（transcoder.v1）作为对照原子，补端到端（下游 KL）训练目标。

### 目标三：联合机制与「破解」度量

- **归因图：** 节点 = 神经元或特征；边经过注意力头，头上附 QK 归因；
- **唯一的进度数字：** 预测保真度（AGENTS §5.4）——保留注意力、只保留图中成分（其余均值消融或替换），在留出材料上测答案差值保留比例、损失恢复与 KL，对照 token 身份 / n-gram 基线，按模式分别报告；
- 在完整图谱出现之前，报告的是「头电路保真度」（只保留所选头，其余头均值消融），名称上与图谱保真度区分。

### 校准先行

- 注意力侧方法先在 GPT-2 small 上找回已知 QK 组合：IOI 中 S 抑制头（7.3 / 7.9 / 8.6 / 8.10）经查询侧决定名称搬运头看向 IO；归纳头的键侧依赖前一 token 头（4.11）。
- 之后再用在 Qwen3-4B；外部基准（MIB）作为下一步。

### 数据集分工

- C-Eval / CMMLU 等考试题库：只做行为广度与消融后的分科退化画像。选项字母格式会污染读出，不作机制材料。
- 机制材料：最小对模板（现有文法、中文最小对）与冲突数据集。

## 3. 执行顺序

1. 校准（GPT-2，QK 路径修补）——`scripts/calib_qk_gpt2.py`，结果 `research/calibration/C2-qk-gpt2/`。
2. 一个冲突做透：上下文与记忆冲突，Qwen3-4B——数据 `shared/dist_protocol/conflict/CF-v1.json`，脚本 `scripts/conflict_case.py`，结果 `research/mechanism/CF-v1-qwen3-4b/`。产出优先级表、负责的头、相关神经元列表与头电路保真度。
3. 客户端「例句」与「模式与优先级」两页，用第 2 步的真实数据；清理不可达代码。
4. 用同一流水线扩到语法类（GR 族）与推理类。

## 4. 客户端整理

原则：以「一句话」为中心，围绕三个目标组织页面，不按数据来源分页。

| 页面 | 内容 |
| --- | --- |
| 数据集 | 各数据集与类别、模型正确率、行为门；点题目或句子进入「例句」 |
| 例句（核心） | 输入 / 选择一句话 → 行为（答案概率）→ 注意力路由（层 × 头热力图，直接作用与总效应并列）→ 激活的神经元 → 该句的归因图与保真度 |
| 模式与优先级 | 每种冲突的赛跑曲线与优先级表 |
| 神经元图谱 | 按层浏览，单元卡四轴 + 证据等级，按归因优先级排序 |
| 进展 | 只放三类数：各模式保真度、完成的完整案例数、未通过的检验；失败与成功同样醒目 |

- 3D 层塔降为侧边小导航，主区用二维热力图与表；
- 删除不可达代码（`blueprint/` 等约 40%），请求统一走 `rdc_fusion/api.js`，每个面板包 ErrorBoundary，核心页补端到端测试；
- 管理功能收成分步骤向导；普通用户只看到「贡献算力」与「我的上传」；
- 没有真实数据时显示「未接入」，不回退演示数字。

## 5. 风险

- 冲突材料里「上下文胜」既可能是复制机制（归纳 / 检索头），也可能是理解；需要「上下文改写但不出现答案词」的对照来区分。
- 均值消融把模型推离分布的程度不同层不同；重要结论用重采样消融复核。
- 头电路保真度不是图谱保真度；完整图谱需要 MLP 侧原子接入后才能计算。
