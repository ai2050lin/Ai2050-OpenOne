# 图谱主界面方案 · 三域主图 + 证据流（v1）

> 2026-10-11。用户指定形态：**一个主要的大图形（含三域）+ 点击看详情 + 下方证据流**。
> 本方案为 AtlasLens v1.6 的替代首屏设计（主图式布局，"上图下流"）。

---

## 1. 布局（两段式，单页无 tab 跳转）

```
┌──────────────────────────────────────────────┐
│  ① 三域放射主图（大图形，主视图）                │
│     中心=图谱整体（E2+ 20/26）                  │
│     第一环=三域（KN 绿 / AR 蓝 / GR 琥珀）       │
│     第二环=6 语言族（弧段宽∝特征数）             │
│     外圈=26 特征节点（E 级着色）+ X1–X3 交叉灰点  │
│     选中特征 → 右上悬浮详情卡（非遮挡）           │
├──────────────────────────────────────────────┤
│  ② 证据流（下段，随主图选中联动）                 │
│     过滤条：过滤 FTR-23 / 域 / 线 ×清除          │
│     垂直时间线：每 Phase 一卡（verdict/读数/sha8）│
│     特征选中时=该特征完整生命史（立项→升级→当前）  │
│     无选中=全账本 n=374（分页/虚拟滚动）          │
└──────────────────────────────────────────────┘
```

原 4 tab 的去向：**图谱全景（三模）→ 被主图+列表切换取代**；跨线账本 → 并入证据流（下段，全量回溯入口保留"查看完整账本表"链接）；结果库 / 模板与技术 → 保留为次级入口（主图右上角两个小按钮或头部链接，不占主视图）。

## 2. 主图设计（AtlasRadial，新建组件）

**几何**（确定性公式派生，零实验字面量）：
- 中心圆 r=52：图谱名 + E2+ 总覆盖（`e2plus/total`，派生器 coverage 字段）。
- 第一环（三域弧，stroke 30）：每域弧角 = 120° 均分（KN/AR/GR 各 1/3）；弧色沿用全景 E 级配色系。
- 第二环（族弧，stroke 18，半透明）：域内族弧角 ∝ 族特征数（派生自 atlas_tree_v1.json 的 families）。
- 外圈特征节点 r=160：角度=族弧内按索引均分；半径微抖禁用（确定性）；E 级着色（E2 绿/E3 橙/E1 蓝/交叉灰）。
- X1–X3 交叉：三域边界外侧灰点 + 「交叉」标注，点击同样开详情。

**交互**：
| 点击目标 | 行为 |
|---|---|
| 中心圆 | 清除选中 → 详情卡关、证据流回全账本 |
| 域弧 | 详情卡=域摘要（覆盖度/族清单/代表特征）；证据流过滤该域（按特征族归属匹配） |
| 族弧 | 详情卡=族摘要；证据流过滤该族特征集合 |
| 特征节点 | 详情卡=FeatureDetail 摘要（陈述/读数/res·seal）；证据流过滤 `FTR-xx` 生命史 |
| 悬停节点 | title=陈述全文（沿用全景） |

**与现有状态贯通**：`sel` 状态与 `?atlasSel=` 协议键共用（点顶栏特征源选择器 → 主图高亮 + 详情卡 + 证据流过滤，三处一体）；机制过滤 chips（MEC-01–07）保留在主图头（非成员置灰沿用）。

## 3. 证据流（EvidenceStream，新建组件）

- 数据源：`GET /api/ai-rnd/atlas/ledger`（现有端点，零改动）；主图选中态作为过滤参数（前端过滤，特征匹配 anchors/mentions，域匹配族归属表）。
- 每卡字段（协议键渲染）：`phase` / `name` / `line` / `date` / `verdict`（截断）/ 关联特征 chips（可点击跳主图选中）/ `res_sha8·seal_sha8`（有则显）。
- 特征过滤模式 = **生命史视图**：该特征从立项到当前的全部 Phase 连续呈现（升级链一屏可见——方案 C 的核心价值并入）。
- 排序 phase 降序；加载更多分页（`?limit&offset`），首屏 12 条。

## 4. 数据结构影响

**零端点改动**。主图所需全部来自现有 `atlas_tree_v1.json`（domains/families/features/cross_links/coverage/mechanisms），仅前端重排为放射几何；派生器不升级（族弧角由 features.length 现算）。

## 5. 落地清单（确认后执行）

1. 新建 `AtlasRadial.jsx`（主图：环弧几何 + 节点 + 详情卡 + 交互回调）；
2. 新建 `EvidenceStream.jsx`（证据流：过滤条 + 时间线卡 + 分页）；
3. `AtlasLens.jsx` v1.7：总览首屏重构为「主图 + 证据流」，panMode 三模收缩为「主图 / 列表」二模（卡片模式并入列表），账本 tab 保留为全量表（证据流尾"查看完整账本表 →"跳转）；
4. CSS：`.at-radial-*` / `.at-stream-*` 两块；删被取代的 `.at-pan-*` 泳道规则（python assert 防护）；
5. 验证：esbuild、vite、tree/registry/ledger 端点、`?atlasSel=` 贯通回归。

**成本**：~1 个会话。风险：26 节点外圈在窄右栏（400px）会偏小——主图区域建议占透镜全宽（路线-图谱 tab 本就全宽，非右栏），无碍。
