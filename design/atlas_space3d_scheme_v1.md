# 图谱 3D 空间方案 · 多维度信息编码（space3d v1）

> 2026-10-11。目标：一个 3D 场景同时承载图谱的多维信息——几何 / 证据 / 关系 / 模型 / 族属 / 时间 / 下钻。
> 前置资产：cloud_map.v1 映射协议（family 级先行）、atlas_tree_v1.json（派生档）、CloudMode 相机系统（可复用）。

---

## 1. 核心：视觉通道 → 信息维度编码表

| 视觉通道 | 承载维度 | 数据来源 | 备注 |
|---|---|---|---|
| **位置 xyz** | 特征几何（空间真相） | collect.npz L6 / 簇质心+确定性偏移派生 | 派生坐标期显式标注「非模型真实几何」 |
| **颜色** | E 证据级（E2 绿/E3 橙/E1 蓝/未入册灰）· 可切换为域着色 | registry evidence_level | 颜色模式切换 = 同一场景两种读法 |
| **大小** | 证据强度（anchors 数） | registry anchors | 半径 = 4 + 1.2·√n（确定性） |
| **边·实线（紫）** | 机制共享（MEC-xx 多对多） | atlas_tree mechanisms | 同一机制服务的特征互联 |
| **边·虚线（灰）** | 交叉关系（X1–X3） | atlas_tree cross_links | 跨域证据的几何呈现 |
| **平面层（y 分层）** | 模型维度（qwen3-4b / 14b / glm4-9b） | registry model_scope | 同特征跨层垂直连线=跨模型稳健性一眼可见 |
| **簇晕（半透明椭圆）** | 语言族 / 域归属 | cloud_map.v1 clusters | family 级映射（协议 A 步产出） |
| **时间滑块** | 证据流回放（P3154→P3222 图谱逐步生长） | ledger measurements | 与主图方案证据流共用时间状态 |
| **高亮环** | 选中态（?atlasSel= 三处一体） | URL 协议键 | 主图 / 特征源选择器 / 3D 同一 sel |

**一场景七维**：几何 · 证据 · 强度 · 机制 · 模型 · 族属 · 时间——每个通道单一归属，不重复编码。

## 2. 场景三层结构

```
L3 语境层：族晕（域/族归属）+ 模型平面底板 + 参考轴
L2 关系层：机制边（实线）/ 交叉边（虚线）/ top-k 邻居线（可开关）
L1 几何层：1024 点云（灰底噪）+ 26 FTR 主角点（E 级着色 + 大小编码）
```

**图层控制板**（右上浮动）：五类图层勾选开关 + 颜色模式（E 级/域）+ 模型层（三层同显/单层聚焦）+ 相机预设（按域聚焦 / 跨模型对比 / 全景俯瞰）。

## 3. 交互

- **相机**：复用 CloudMode 现有投影系统（拖拽旋转 / 滚轮缩放 / 惯性自动旋转），零新依赖。
- **点击 FTR 点** → 悬浮详情卡（陈述/读数/anchors/簇归属）+ 证据流过滤该特征生命史（与主图方案联动同一 sel）。
- **点击族晕** → 该族成员高亮、其余降透明度（沿用 cloud_map.v1 §3 簇高亮规则）。
- **时间滑块** → 按 phase 逐步点亮 FTR 点（图谱生长回放）；拖回过去即"截至 P3180 时的图谱"。
- **跨模型对比预设**：单选一特征 → 相机飞至其三模型投影 + 垂直连线高亮（model_scope 一眼可查）。

## 4. 数据协议：cloud_map.v1 → space3d.v1（派生器扩展段）

```json
"space3d": {
  "version": 1,
  "points": {"ftr": [{"ftr_id": "FTR-23", "family": "GR.context", "e_level": "E2_held_out",
              "n_anchors": 4, "models": ["qwen3-4b","qwen3-14b","glm4-9b"],
              "pos": {"origin": "derived_centroid", "xyz": [12.3, -4.1, 7.7]}}]},
  "edges": {"mech": [["MEC-05", "FTR-12", "FTR-23"]], "cross": [["X1", "FTR-08"]]},
  "cloud": {"source": "collect.npz|demo", "n_points": 1024, "layer": "L6",
            "note": "真实坐标接入前为派生/演示口径，界面必须标注"},
  "unmapped_families": []
}
```

纪律（延续既有红线）：
1. 一切派生字段（e2plus 计数、点位公式、边表）由派生器计算，`--check` 幂等，**人手禁写**；
2. 簇质心 = cloud_map.v1 family 映射 + npz 簇坐标均值；npz 未接入前用确定性伪坐标（mulberry 种子固定，同现网点云口径）并标注；
3. token 级下钻（SAM-xx 粒子云）**不在本方案**——等研究侧 Phase C，界面留插槽注记。

## 5. 落地拆步

| 步 | 内容 | 量级 | 前置 |
|---|---|---|---|
| A | 派生器 space3d 段（FTR 点位/边表/云口径） | 零 GPU | cloud_map 簇 label 对齐表确认（P3-A 同一件事） |
| B | `AtlasSpace.jsx`：三层场景 + 图层板 + 悬浮卡（复用 CloudMode 相机） | 中 | A |
| C | 时间滑块证据回放 + 主图/证据流 sel 贯通 | 小 | B |
| D | npz 真实坐标管线接入（客户端拉真实点云） | 中 | 研究侧数据管线 |
| E | token 级 SAM-xx 粒子下钻 | 中大 | Phase C |

建议本轮做 A+B+C（派生坐标口径，界面诚实标注）；D/E 挂账。

## 6. 与现有界面的关系

- 空间透镜·特征点云（CloudMode）→ **升级为 AtlasSpace**（demo 伪 3D → space3d.v1 驱动的多维度场景），旧 demo 相机代码复用不重写；
- 路线-图谱主图方案（atlas_radial_main_scheme_v1）→ 主图管"结构总览"，3D 管"几何与跨模型"，二者经 `?atlasSel=` 共用选中态互跳；
- 顶栏特征源选择器 → 三端（主图 / 3D / 详情）同一 sel。
