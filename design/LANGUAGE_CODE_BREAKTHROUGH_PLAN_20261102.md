# 语言编码机制的破解路线：从局部特征到脉络图谱

日期：2026-11-02 · 状态：提案（未预注册）· 上游依据：`research/gpt5/docs/AGI_GPT5_MEMO.md`、`PATTERN_SEARCH_FRAMEWORK_v1.md`、`PAT_Q2EFG_FINDINGS_20261101.md`

**一句话：我们不是测错了，是一直在问错的问题。问「哪个单元编码转折」必然失败——相对编码的定义就是「没有绝对载体」；该问的是「转折在什么变换下保持不变」。把问题从「定位」换成「不变性」，无限循环才停得下来。**

---

## 一、诊断：为什么两年一直停在局部特征

把已归档的硬结论排在一起，会看到一条很一致的失败模式：

| 已成立 | 数字 | 它否掉了什么 |
|---|---|---|
| 无必需头 / 无必需层 / 无致病组合 | L28–L35 消融 133 头 drop 0.000；同一段 patch L33 一个位置翻转 1.00 | 「功能由某个/某组单元承载」 |
| 承载是累积量不是结构量 | k=1 .638 → k=4 .909 → k=16 .995 → k=32 1.000，单调无饱和 | 「有一个最小充分电路」 |
| 几何 ≠ 计算 四次成立 | Q2-L、Q2-C1、Q8-B（R² 0.826 但前向零效应）、L30 GQ-ATOM-v1 | 「读出得好 ⇒ 被下游使用」 |
| 三类模式几何形态各不相同 | 属性=一支方向 / 层级=区域 / 关系=三点二维 | 「存在统一的概念地图」 |
| 没有关系向量表 | 有实体静态码（T1 cos .998）+ 按实体索引的稀疏标签（7.88× vs 1.24×）+ 匹配算子 | 「模式 = 一条方向」 |

这五条不是五个孤立发现，是同一个事实的五个侧面：**响应强度与响应位置都不是机制的载体，只有「响应之间的差」才可能是。**

而我们的实验设计几乎全部落在「对象 × 模式 → 强度」这个二维表里：一个头、一个神经元、一个特征、一层，在某模式上的激活/选择性/分离度。这个表的上限就是「有分离、无因果」，也就是 `NULL_BOUNDED` 的批量产地。每加一个模式族，就多一行这样的 NULL——循环就是这么形成的。

### 三个结构性原因（不是执行失误）

1. **抽象层选错。** 「强度」是标量，「编码」是关系。用标量表去测关系表，信息量天生不够，只能得到「这里有点东西」。
2. **推断单位选错。** 我们以「单元」为单位做推断，但承载是累积量（k 曲线单调）——单元层面根本没有稳定的因果量可估，MDE 会一直大于效应。
3. **判据落在形状上。** E1 剖面只约束用词（D10），却反复被当成机制证据；真正需要的是干预可分离性，而这一条在 3201 次实验里只有少数几条落盘。

## 二、三个假说的形式化：从「说法」变成「可算的量」

用户的三个概念本身是对的，但必须以可测量定义落地，否则又会变成换个词继续测强度。

### 2.1 相对编码 → **差分不变性**

> 「苹果是各种关系的总和」「疑问句相对非疑问句定义」

形式化：对同一模式 P 取 k 个实例（不同上下文 / 不同模板 / 不同实体），得响应向量 r₁…r_k，定义差分 Δᵢⱼ = rᵢ − rⱼ。

**相对编码成立 ⇔ Δ 的方向在实例间近似共享，而幅度随实例变。**

- 方向共享 = 有稳定的「相对轴」（对比的是同一件事）
- 幅度可变 = 该轴是相对的、可缩放的，不是绝对码

可测量 `I_dir`：Δ 集合的 top-1 奇异方向跨实例 cos 均值，**对照 = 打乱实例标签的零分布**（必须报倍率，禁写绝对 cos 差——这是 11-01 两道闸自废的教训）。

若 `I_dir` 不高于零分布 2 倍 ⇒ **相对编码的差分形式化不成立，整条链停**。

### 2.2 复用差分 → **共享基 + 残差**

> 「上百万物体的颜色大小属性，有限参数记不住，必然有高效复用」

形式化：把模式集 {P} 的响应写成 r_P = B c_P + δ_P，B 为跨模式共享基（低秩），δ_P 为模式特异残差。

两个量必须同时高，才叫「复用差分编码」：

| | 高 | 低 |
|---|---|---|
| **复用度 R**（held-out 用 B 重建的 R²） | — | 每模式一套专线（参数不够，与「必然高效」矛盾） |
| **差分度 D**（δ 在 held-out 模式上的可分性 AUC） | 复用差分编码 ✔ | 塌成通用方向（= 什么都没编码） |

**单独 R 高或 D 高都能造假。** 只有 R 与 D 在同一 held-out 集上同时超基线，才构成一次正结果。这一条直接对应 D17（稀疏分解必报 held-out）。

附加：B 的秩必须远小于模式数（否则「共享」是假的，只是每模式一根轴换个说法）。给出 B 的秩–R 曲线，报拐点。

### 2.3 脉络体系 → **跨层轨迹 + 共享图**

> 「各种模式在 LLM 中可能都有自己的脉络」「苹果和香蕉复用某些脉络，又有些不一样」

形式化：脉络(P) = 沿层的二元剖面 `(R_l, D_l)`，加上「在哪些层、与哪些模式共享 B」。

于是「整体图谱」有了确切对象，而且是**一张能画的图**：

- 节点 = 模式（6,720 个模板族 / 三类能力 / 语言项）
- 坐标 = 跨层 (R, D) 剖面（不是二维嵌入，是剖面指纹）
- 边 = 共享基重叠度（同一层上 B_P 与 B_Q 的主角）

**这就是「画整体图谱而不是局部特征」的具体做法**：不画单元的激活，画模式之间的复用关系与各自的层段轨迹。

## 三、判据：三轴制，缺 C 只叫线索

每个 Phase 的每条结论必须落成三元组：

| 轴 | 量 | 通过门 | 不通过的含义 |
|---|---|---|---|
| **R** 复用度 | held-out 重建 R² | > 打乱基线的 2× | 没有共享基，复用假设否证 |
| **D** 差分度 | held-out 可分 AUC | > 同族随机方向基线 + 2σ | 差分不携带身份 |
| **C** 可控性 | 干预 δ 与干预 B 的行为效应差 | z > 3 **且** Δ行为 > 预注册 MDE | 只能叫线索（E2），不得称编码 |

**为什么必须三轴**：R 与 D 都是几何量，而「几何 ≠ 计算」已经四次成立。C 是唯一的因果轴，也是唯一能防住第五次的轴。任何一个 Phase 只拿到 R、D，结论一律写成「线索（E2）」，不许升格。

**判据优先级沿用 D24（预测 > 剖面 > 点陈述）**，且 D 轴必须用 held-out 预测，不许用训练集剖面替代。

## 四、五个 Phase：一条链，不是五个并列

每一 Phase 预注册四栏（hypothesis / 判据 / MDE / kill），预算 3 轮（D12），产出一份 `result.json` + ledger 一条。

### P1 · 差分不变性（最便宜，也最能止损）

- 材料：**ENT-XF 5,040 族**——同一模式（因子）配 5,040 个不同实体，正是「同模式多实例」的现成金矿。不需要新造数据。
- 做法：固定因子，跨实体取 Δ，算 I_dir 与零分布。
- 判据：I_dir ≥ 2× 零分布；跨 3 个模型同向（任一模型反向即记 NULL）。
- **kill：若 4/5 个大类（属性 / 层级 / 关系 / 语法 / 语用）都不超 2×，整条链停，改为承认「差分不变性不成立」并记账。**
- 成本：一次前向 × 5,040 × 3 模型，本机可跑。

### P2 · 共享基 B 与其秩

- 做法：在 discovery 切分上学 B（SVD / CCA），在 lockbox 上报 R 与 D；给秩–R 曲线。
- 判据：lockbox R² ≥ 2× 打乱基线，且拐点秩 ≪ 模式数（否则「共享」是同义反复）。
- kill：若 R 随秩线性上升无拐点 ⇒ 无低秩共享结构，复用假设否证。

### P3 · 差分因果（**这一条决定成败**）

- 做法：三组干预，同材料同预算：
  1. 沿 δ_P 方向加减（差分干预）
  2. 沿 B 方向加减（共享干预）
  3. 随机同范数方向（对照）
- 判据：`effect(δ) − effect(B)` 的 z > 3，且超 MDE；随机组必须为零。
- kill：若 effect(δ) ≈ effect(B) ⇒ 差分不可分离，「相对编码」只是描述，不是机制。
- 已有基建：patch 通道已证明可用（L33 单位置翻转 1.00），不需要新建。

### P4 · 层级组合（回答「苹果–水果–食物–物体」）

- 做法：取 KN-ISA 420 + KN-ATTR 180 构四级链，测 δ_高 ≈ Σ δ_低 的加性（残差占比）。
- 判据：加性残差 < 30% 且跨模型可复现 ⇒ 层级由**组合**实现，不是独立编码。
- 注意：层级类几何是「区域」不是「方向」（各向同性 −0.5 基线所致），所以 P4 **不能**直接用 2.1 的 Δ 余弦，必须先在区域坐标下做中心化——这是本 Phase 独有的预处理要求，必须写进预注册。

### P5 · 跨语言 / 风格迁移（回答「中英翻译、论文 vs 口语、代码」）

- 做法：同义中英句对、同内容三风格改写、自然语言 vs 代码同语义对；测 δ 的同向性与 B 的共享。
- 判据：语义 δ 跨语言同向（cos 高于零分布 2×）而风格 δ 语言特异 ⇒ 语义脉络与风格脉络是两层，这正是「复用差分」的最强证据形态。
- 材料现状：中英双语有（census 语料 + CMMLU/C-Eval 双语条目）；**代码风格目前无对齐语料**，必须先补一个 P5-C 子集，不得用文学类比替代。

### 依赖关系

```
P1 ──▶ P2 ──▶ P3 ──▶ P4
                    └▶ P5
```

P1 失败则全停；P2 失败则停在「无低秩共享」；P3 失败则整条链降级为「描述性」，禁止再开新的模式族变体（这是唯一能真正止住循环的硬闸）。

## 六、为什么这次不会再产出第五个 NULL_BOUNDED

三个结构性差异：

1. **推断单位从单元换成模式间差分。** k 曲线已经说明单元层面估不出稳定量；差分把推断单位抬到「模式对」，累积量的噪声在相减时被抵消一部分。
2. **判据从形状换成不变性 + 干预。** 形状判据只能给 E1，不变性给 E1+E2，干预给 C。三轴制让「有趋势但未达阈」无处躲（D16）。
3. **有真 kill 阀。** 以前的 NULL 是「这轮没测出来」，现在是「这条假设被否证，记账，禁止同子空间再开」。P1/P3 的 kill 是链级而非轮级——这是与过去最大的不同。

仍要警惕的老问题：**「读得出 ≠ 控得住」已经四次成立**，所以 P2 出任何漂亮 R² 都不许先写结论，必须等 P3 的 C 轴。

## 七、客户端如何承载（本次三项界面要求的落点）

研究路线变了，界面就得跟着变——原界面是「对象 × 模式 → 强度」的表，正好是我们要离开的抽象层。

### 7.1 三维空间放大，层内可见 Attn / MLP

层塔从 330px 侧栏升为**主画布**（≥55% 宽、高度 720+）。每层板面上画出两个模块盒：

- 后半（z < 0）= **Attention**（蓝 `#2a78d6`）
- 前半（z > 0）= **MLP**（橙 `#eb6834`）

点盒 = 选中 `(block, mod)`，右侧面板展开该模块在该层的实测。这一改动把「层」这一级从「一个板」变成「两个可点的功能块」，正好对应研究上的「同一层里注意力与 MLP 是两条不同通路」。

不传 `modules` 时 Tower 行为与现状**像素级一致**（旧调用点零影响）。

### 7.2 页顶统一「数据集 + 模型」

全局上下文条 `Gctx` 插在子导航之下、内容之上，所有一级界面共用：

- 数据集（C-Eval / CMMLU / Xiezhi / 本地模板族）→ `/api/lang/atlas/datasets`
- 模型（4 个）→ `/api/lang/tree`
- 右侧一句状态：该数据集 N 题 / 进池 M / testable

状态升到 `Workbench` 并进地址栏（`ds=`、`mdl=`，只写与缺省不同的键）。**这解决了一个真缺陷**：原来 `LangAtlas` 的 `picked` 困在组件 `useState`，换页即丢，于是「三类池 100% 来自 CMMLU，换数据集结论还成立吗」在工作台上无法回答——而这正是 P1 最要紧的外部效度问题。

### 7.3 默认简单，选中后展开

- 默认：只显示大层塔 + 一句「点一层看块内结构」。右侧详情面板不渲染。
- 点击层或模块后：右侧滑出详情（块结构 / 单元阵列 / 单元卡），带「收起」。
- 原则沿用既有纪律：**没有数据源的东西不上屏，不回退演示数字**。

### 7.4 与研究方案的对应

| 界面元素 | 对应的研究对象 |
|---|---|
| 层塔 + Attn/MLP 盒 | P1 的 Δ 取在哪个模块（attn vs mlp 的 I_dir 应分别报） |
| 数据集全局条 | P1 的跨数据集外部效度（单源结论必须先分离） |
| 详情面板的 R / D / C 三轴 | 每 Phase 的三轴落盘，替代现在的「证据等级」文字自陈 |

**尚未做、也不该在本轮做**：证据台账页（需 P1–P3 的数据）、脉络图谱页（需 P2 的 B）。没有数据源就先不画——这是本项目最容易犯的错。
