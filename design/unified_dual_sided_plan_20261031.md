## 2. 核心修正：功能颗粒度（对长文的三处硬修正）

### 修正一：原子 = ≤10 维联合子空间 + 中继头，不是单子组件/单神经元

本地证据链已给出结论：
- **APPX-3 K3 死线 3/3 触发**：top-50 单坐标对 η² 的覆盖率仅 1.9–5.9% ≪ 30% 预注册阈值 → **单坐标机制目标已按 p35 正式废弃**，转 ≤10 维联合 + 端口类；
- **R-MLP-16**：L34 top-1%（97 单元）是**冗余饱和共享池**，删一半不饱和——单元级"必要性"在通用 QA 上天然弥散；
- **R-MLP-14**：差分对符号无功能意义——单方向载体不成立。

因此：长文 Step 1 的 VPD 分解**必须约束输出颗粒度**——分解目标设为 rank≤10 的低秩因子（或对 census 分型聚类后的单元组做分组 VPD），否则会把已被本项目否证的单坐标观重新引进来。Goodfire 原版 VPD 的细粒度子组件在本项目只作为**中间表示**，最终入册原子一律是子空间。

### 修正二：数据集的角色是"行为门 + 分层退化测量"，不只是探测任务

owner 思想"选择多种语言数据集"的正确落地不是"用数据集出题考模型"，而是：
- **行为门**：每类题池先测 base 正确率，只有模型做对的格子才进内部分析（AGENTS.md 行为门纪律）；
- **分层退化测量**：消融原子后按类别/科目分层测正确率变化，得到 d_i ∈ R^K（K=类别数）——41k 题库 + 2,900 题/分钟的打分基建使这件事第一次在算力上可行；
- **交叉验证**：d_i 的类别模式（如"语法掉、知识不掉"）就是原子功能画像，直接喂给 auto-interp 与模板选择性交叉核对。

**前置条件**：三大类必须扩池。P0 用 CMMLU 67 科目重映射类别（语法规则 ← 古代汉语/现代汉语/汉语言文学/高中语文等全量；功能推理 ← 逻辑学/逻辑谬误/公务员系列；知识网络 ← 生物/历史/地理系列），目标每类 n≥1,000。C-Eval val 三类保留为"外部锚"（与已发布结果可比），不进功效计算。

### 修正三：路由侧不是从零筛，而是"专用→通用"两级

3280 已发现专用中继头族（对 R_logic/K_entity 写入 ~9×）。长文的 PR 积分筛选是内容通用筛选。两级合并：
- **一级（通用）**：PR 积分筛内容依赖头全集 H_content——覆盖未来新模式，不只服务现有两个子空间；
- **二级（专用）**：现役 S_rel 中继头族直接进候选，3281 的份额归一化（D_norm=‖proj‖/‖c‖）先行完成，其结论是 P3 仲裁的直接输入。

### P1 写入侧行为画像相（GPU ~3–5 小时）

**问题**：每个候选原子在五个语言类别上的退化向量 d_i 是什么？哪些原子是"语言相关写入候选"？

**算法**：
1. 原子构造：L34 现役 97 单元 + 各 census 分型 top 组 + （owner 批准后）单层试跑 rank≤10 VPD 因子；目标 M≈100–200 个原子；
2. 对每个原子 a：钩子消融（投影置零或单元组置零），在 5 类 × 每类分层抽样 n=400 的题池上跑字母概率打分；
3. `d_i(k) = acc_base(k) − acc_ablate_a(k)`，配对 McNemar + 多 seed（≥3）重复（审计 C4）；
4. **格式不变读出**：全部打分用 H22 的固定前缀 + gold 间隔口径，防格式单元污染（R-MET-12）；
5. 匹配随机对照：按激活频率 + 范数 + 位置分布三变量匹配的随机原子组，构建零分布（R-MET-11：匹配变量预注册，防通用脆性题击穿）。

**成本**：200 原子 × 2,000 题 = 400k 次前向 ≈ 3–5 小时（钩子开销 ~2×）。可分层执行：先 20 个种子原子全量，其余按需。

**验收**：d_i 显著性由功效分析背书（预期效应 2–5pt 时 n=400/类 McNemar 检验力 ≥0.8）；每原子一张特征卡入原子注册表。

### P2 路由侧筛选相（GPU ~1 小时 + 3281 先行）

**问题**：哪些头在做内容依赖计算？它们从残差流哪里读、往哪里写？

**顺序**：**3281 先行**（消费方归因份额归一化，同判据）——其结论是本相输入。

**算法**：
1. **PR 积分筛选**：对 36 层 × 32 头 = 1,152 头，在 1,000 条混合类别前向上采集逐头输出，算每头输出协方差的 participation ratio 积分 `PR(Σ_h) = (Σλ)²/Σλ²`，与身份随机对照比较，取"持续内容依赖计算"头集 H_content；
2. **读写方向基**：对 h ∈ H_content，R_h = W_OV 左奇异 top-m（读取），W_h = 头输出写回残差流方向的 top-n（写入）；GQA 8 KV 组共享 V，按 KV 组合并；
3. **类别条件化**：对 5 个题类分别算逐头的"类别特异注意力指纹"（对答案位置/前缀/关键 token 的注意力质量分布），ACC++ 口径的低维信号内容留 P3 用；
4. 中继头族（3280+3281 结论）直接并入候选并标注来源。

**验收**：H_content 清单 + 每头 R_h/W_h 入注册表；PR 筛选与 S_rel 筛选的重叠度报告（两个独立口径的交叉验证）。

### P3 联合仲裁相（GPU ~5–8 小时，本方案核心）

**问题**：哪些（写入原子， 路由头， 写入方向）三元组构成语言模式的编码路径？

**算法**（长文 Step 3–5 的可执行版）：
1. **前向干预**：消融原子 a，测头 h 的输出在 R_h 各方向投影的变化 Δπ；显著方向记为"受 a 调制的路由方向"；
2. **反向干预**：在 h 输出处沿 W_h 单方向投影置零，测 a 的 d_i 是否被"解释"（该方向阻断是否复现 a 的类别退化模式）；
3. **补全替换**：activation patching——把对照输入在 R_h 方向的激活替换进目标输入，检验能否**恢复** a 消融破坏的行为（长文改进三；区分"中继"与"编码"）；
4. **匹配零分布**：对每类干预跑匹配随机原子/头对照组，效应量超过零分布 95% 分位才保留；
5. **最短充分路径**：每语言类别的路径集合用贪心剪枝到"最小充分"——剪枝后行为保留比 ≥τ=0.9 的最小边子集（K-MSHC 思想，防全连接归因图）；
6. **范围**：先做两个层带——L24/L34 现役原子 × 中继头族（28–35）× H_content top-20，候选对 ≤400；不许全模型铺开。

**验收**：编码路径图（三元组带效应量 + 零分布分位 + patching 恢复率）；每条边在原子注册表挂 evidence 边。

## 4. 数学口径明细（全部可计算）

| 量 | 定义 | 说明 |
|---|---|---|
| 原子 a | rank≤10 子空间：`a = span{u_1..u_k} ⊂ R^9728`（MLP 侧）或 `a = span{c_1..c_k} ⊂ R^2560`（残差流侧），k≤10 | 颗粒度由 APPX-3 K3 预注册结论约束 |
| 消融算子 | `Abl_a(h) := h − P_a h`（P_a 为到 a 的正交投影） | 与 3155 平衡正交基操作同构，逐位可复算 |
| 退化向量 | `d_a(k) = acc_base(k) − acc_ablate_a(k)`，acc 为格式不变字母概率 argmax 正确率，k∈5 类 | McNemar 配对；≥3 seed 报均值±sd |
| PR 积分 | 头 h 输出协方差 Σ_h（N×d_h，N=1,000 前向）：`PR = (Σλ_i)²/Σλ_i²`；内容依赖分 = PR − PR_identity_control | 身份对照 = 同协方差的随机正交旋转基线 |
| 读写基 | `R_h = top-m 左奇异向量 of W_OV^{(h)}`；`W_h = top-n 右奇异向量 of W_OV^{(h)}`（写回残差流） | GQA：同 KV 组的 4 头共享 V 侧，按组合并 |
| 前向调制 | `Δπ_{h,j}^{(a)} = cos(P_{r_j} out_h^{base}, P_{r_j} out_h^{ablate})`，r_j ∈ R_h | 显著性对匹配零分布 95% 分位 |
| patching 恢复率 | `ρ = (acc_patched − acc_ablate)/(acc_base − acc_ablate)`，ρ≥1 完全恢复 | ρ 与 Δπ 联合判"编码 vs 中继" |
| 最短充分路径 | 边集 E' ⊆ E 使 `retention(E') ≥ 0.9·retention(E)` 的最小 |retention| —— 贪心删边至破坏 | τ=0.9 预注册 |
| 编码路径 | 三元组 (a, h, w) 满足：前向调制显著 ∧ 反向解释显著 ∧ ρ≥0.5 | 三条件全过才入册；缺一记"候选" |

## 6. 风险与硬伤（诚实清单）

1. **VPD 计算成本**：Qwen3-4B 单层 MLP 是 2560×9728，全模型 VPD 不现实。本方案只对 1–2 个层带试跑 rank≤10 因子分解；若成本仍超预注册预算，回退"census 分型单元组"作为写入原子（功能等价，只是参数空间解释力弱一档）。**这是最大的单点风险。**
2. **d_i 的信噪比**：即使扩池到 n=1,000/类，单原子效应若 <2pt 仍可能不显著。缓解：功效分析前置（P0.5）+ 只对预筛 top 原子做全量，避免"跑了但读不出"（审计 3.5 教训）。
3. **类别重叠**：CMMLU 科目重映射后类别边界有主观性（如中国历史既属知识网络也可能属语法材料）。缓解：允许多标签 + 映射表冻结 + 灵敏度检查（换映射结论不变）。
4. **格式单元污染复发**：H17–H21 的教训是"答对/答错"当因变量会把格式单元排到第一位。P1 全程用格式不变读出，但**换因变量本身是新风险**，需在 P1 结束时做一次"格式单元是否再次登顶"的专门检查。
5. **饱和池问题未解**：R-MLP-16 表明 L34 top-1% 是冗余饱和池——消融单原子的 d_i 可能普遍接近零（冗余兜底）。这恰恰是 patching/scrubbing（P3.3/P4.1）必须先行设计的原因：删不动的东西要用"保持假设的重采样"来测。若 P1 大面积零效应，**不是方案失败**，而是"原子粒度仍大于功能冗余粒度"的证据，回退到子空间联合消融（≤10 维联合已是本决策的动机）。
6. **3281 排序依赖**：P2 依赖 3281 的份额归一化结论。若 3281 推迟，P2 只能做 PR 通用筛选一半。
7. **本方案不直接产出"破解"**：编码路径图是机制假设的结构化载体，"可度量的破解"仍由谱图预测保真度（AGENTS.md 5.4）在留出材料上最终度量——P4 之后应另立保真度评测相，本方案不含。
