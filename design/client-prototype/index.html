本地题库清单：14,893 题（C-Eval 169 · MMLU 14,042 · M3Exam 682）。这是已收录题数，非已测试题数；未映射到三类的学科保持未分类。下表任务进度为演示。

为 4B–14B 模型安排怎样的数据梯度？

先在 Qwen3-4B 用受控属性、角色和语法材料确认采集与行为门；能力门通过的题再做机制正例。用同一冻结材料依次比较 9B 与 14B，较难任务可保留为能力失败面板。自然语料和机制上下文采用 512 / 1,024 / 2,048 token 面板，读出必须位于区分信息之后；长文本不能靠重复无关句子凑长度。

公开基准保持原始评测协议。若加长上下文，另建新版本、配平干扰并重新验证答案，不能把它仍称为原基准成绩。
