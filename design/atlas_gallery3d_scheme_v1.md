# 图谱立体馆方案 · 图形 × 3D 融合（gallery3d v1）

> 2026-10-11。目标：在「路线-图谱-图谱全景」内，把 2D 泳道图（AtlasPanorama）的**结构可读性**
> 与 3D 空间（AtlasSpace）的**多维编码**融合为一个新 3D 图谱效果——结构建筑化：
> 三域不是标签，是场景里的三座塔；族不是晕圈，是塔内的楼层；横切机制不是连线，是贯穿的竖井。

---

## 1. 动机：两个现有视图各缺什么

| | AtlasPanorama（图形） | AtlasSpace（3D 空间） |
|---|---|---|
| 结构归位（域/族归属） | **强**：泳道即骨架 | 弱：族属只靠 halo 标签暗示 |
| 多维编码（证据/模型/时间） | 弱：仅 E 级着色 | **强**：七通道 |
| 横切机制（MEC 多对多） | 过滤器（不显形） | 实线边（易交叉成团） |
| 域间交叉（X1–X3） | strip 条（不显形） | 虚线边 |
| 时间维度 | 无 | 滑块回放（点逐步点亮） |

**融合原则：每个 3D 元素都必须同时回答"结构上属于哪"和"证据上是什么"。**

## 2. 核心隐喻：「三域立体馆」

| 视觉元素 | 承载维度 | 编码规则（确定性） | 来源 |
|---|---|---|---|
| **三座塔** | L1 三域 KN/AR/GR | 方位 = 圆环 120° 均布（域序）；塔体半透明域色 | atlas_tree domains |
| **塔内楼层** | L2 语言族 | 每族一层圆盘平台；层高 = 族序 × 固定层距；盘径 = √(特征数) | domains.families |
| **证据节点** | L3 特征 FTR | 站立在所属族楼层盘面上（黄金角环布点）；颜色 = E 级；半径 = 4+1.2√n_anchors | space3d/registry |
| **机制竖井** | MEC-xx 横切层 | 贯穿"该机制全部特征所在楼层"的细立柱，柱顶横杆连接各节点——多对多天然表达 | mechanisms |
| **塔间天桥** | X1–X3 交叉边 | 两塔之间悬索桥（虚线弧），桥上标注交叉类型 | cross_links |
| **环绕轨道环** | 模型 scope（3 模型） | 馆外地面三圈同心环（每模型一圈）；特征向其覆盖的环投射光束 = 跨模型稳健性 | model_scope |
| **建馆生长** | 时间（Phase 流） | 滑块回放 = 建馆过程：节点/竖井/天桥按首锚 phase 逐层点亮 | anchor_phases |
| **高亮环** | 选中态 | ?atlasSel= 三端一体（图形/3D/详情抽屉共用 sel） | URL 协议键 |

**一馆七维**：结构 · 族 · 证据 · 机制 · 模型 · 时间 · 选中——每个元素单一归属。

## 3. 场景三层

```
L3 馆体层：三座塔（域色半透明壳）+ 楼层盘 + 族名匾额 + 天桥
L2 关系层：机制竖井（实线柱）+ 交叉天桥（虚线弧）+ 模型轨道环光束
L1 证据层：26 个 FTR 证据节点（E 级高饱和着色）+ 地面三环 + 参考轴
```

**图层控制板**：塔体 / 楼层匾额 / 竖井 / 天桥 / 轨道环 五开关 + 颜色模式（E 级/域）+ 相机预设
（逐塔巡航 / 跨模型对比 / 全景俯瞰）+ 时间滑块（建馆回放）。

## 4. 交互

- 相机：沿用现有伪 3D 投影（左旋 / 右移 / 滚轮 / 闲置自转），预设按钮一键飞位（缓动插值）。
- 点击节点 → 与四模一态共用 sel + FeatureDetail 详情抽屉（不引入第二事实源）。
- 悬停节点 → tooltip（ftr_id + statement）。
- 滑块拖回 = "截至 P3xxx 时建到几层、点亮哪些节点"——图谱生长叙事。
- 逐塔巡航预设：相机贴近某塔，其余降透明。

纪律（延续红线）：
1. 全部点位/半径/层高由派生器确定性公式计算（黄金角 + 固定层距），`--check` 幂等，人手禁写；
2. 26 特征全节点覆盖断言；桥梁/竖井端点必须命中已登记节点；
3. 坐标仍是派生口径（非模型真实几何），场景保留诚实标注；token 级下钻等 Phase C。

## 6. 与现有 3D 的关系（需要用户决策）

- **方案 A（推荐）**：gallery3d **替换**当前全景「3D」模式。space3d 散点视图的"几何自由度"
  在没有真实 npz 坐标前价值有限（派生伪坐标下散点易读成真实分布，反而不诚实）；
  立体馆的结构表达明确优于散点。避免"每条信息两家"。
- **方案 B**：并存为第 5 模式（图形 / 3D·空间 / 3D·馆 / 列表 / 卡片），模式条变长，
  且两个 3D 共享同一 sel——冗余但可对比。

## 7. 已知硬伤（诚实批判）

1. **装饰性维度**：楼层高度=族序，无信息语义，纯布局手段——须在注记声明，防误读为时间/重要性；
2. **塔高不编码**：塔高若编码覆盖度会与节点数重复编码（同一信息两个通道），故塔高固定、
   覆盖度只读节点颜色分布；
3. **竖井交叉**：一特征多机制时多柱共点，柱密会糊——竖井只画柱不画全部两两连边，柱顶横杆一层；
4. **派生坐标天花板**：在 npz 接入前，一切 3D 都是"结构示意图"而非"几何真相"——
   本方案的诚实增益是：它明确自我定位为结构馆，而不是伪装几何。
