# 语言编码机制 · 联合归因方案 v3

> 缘起：外部方法论意见（以残差流为共同基底、参数分解 × 路由归因联合、方向而非单元作为原子）
> 与本地实测审查（`design/lang_atlas_expert_review.md`）合并。
>
> 三条硬约束决定这份方案长什么样：
> ① 本机 16 GB 单卡、Qwen3-4B（36 层 × 32 头，d_model 2560，d_ff 9728，共 350 208 个 MLP 单元、1 152 个头）；
> ② 已有可复用的实测资产（DLA 管线、层画像、普查、前后锥读写轴），不推翻，只升级；
> ③ 所有结论必须能被证伪，因此每阶段带 kill criterion 与预注册预测。
>
> 时间 2026-10-30。

## 0 一句话主张

**把「参数分解」与「路由归因」合并的唯一合法接口是残差流方向，因此 v3 的原子不是神经元、不是头，而是
「写入方向 × 读取方向」的方向对；几何负责提出候选，因果负责定罪，稀疏性负责让图可读。**

与 v2 的差别不是加两条流水线，而是换了原子与证据链：

| | v2 | v3 |
|---|---|---|
| 原子 | MLP 单元、注意力头（两个独立对象，靠跳转连接） | **方向对** `(写入方向, 读取方向)`，单元与头只是方向的载体 |
| 基底 | 各自坐标系（单元用 gate/down 行，头用 OV/QK） | **统一到残差流 2560 维的同一组方向字典 D**（D0 输出基 / D1 层内读写基 / D2 子组件基） |
| 证据链 | ①敏感 ②传输 ③因果 | **归因 → 必要 → 充分 → 恢复** 四段，且双向（写→读、读→写） |
| 族的定义 | 层画像 + 头列表 | 层画像 + **路径集合** + 方向组合 |
| 结论单位 | 「这个头参与这个模式」 | 「这条路径承载这个模式，因果权重 w，随机对照分位 q」 |

## 1 对两份输入的取舍

### 1.1 采纳（4 条，构成 v3 骨架）

1. **残差流是唯一共享接口。** 单元、头、VPD 子组件都能表示为 2560 维里的方向或方向集，只有在这里才能谈「谁写、谁读」。
2. **方向而非单元作为载体。** 绕开叠加问题。本项目已有先例：前后锥把单元拆成读轴 `r̂`、写轴 `ŵ` 与自洽角 θ，实测 θ 中位 84–94°、θ<30° 为 0/30——**同一个单元的读与写本来就不是同一件事**，用单元当原子会把这个事实抹掉。
3. **双向干预。** 只做「消融 S 看头变化」是单向的；必须再反向做「方向性消融头，看 S 负责的探测任务是否被孤立」。
4. **稀疏性 + 最小充分路径。** 否则得到一张全连接归因图，解释力为零。

### 1.2 修正（4 条，外部意见在本机不成立或不完整）

1. **VPD 全模型不可行，且「用语言探测做 VPD 训练约束」有循环论证风险。**
   VPD 需要在行为保持集上反传（4B 权重 + 激活，16 GB 卡），单层估计 3–6 h/次。全 36 层不可能。
   → 只在 4 个选定层做原型，且**探测任务只用于验证、不参与训练**；训练保持集用通用语料，
   另设留出探测集检验「低幅度句法子组件是否被系统性丢弃」。
2. **「头 = 路由」在选择题格式下暂不成立，必须先补位置分辨。**
   实测：答案位置对选项文本的注意力总质量中位数只有 0.05–0.2，信号极弱；真正强的是 DLA 收口（28 个通用头全在 L24–L35，前 24 层 0，两数据集一致）。现在只读末位，等于只看到「汇聚点」，看不到「路由过程」。
   → v3 把「位置」升为一等维度，R 流水线必须在 ≥3 个读出位分别测。
3. **统计口径必须同时升级，否则双向干预矩阵的假阳性会爆炸。**
   外部意见没有提功效与多重比较。本项目的实测教训是硬的：C-Eval 上 11 个「专属头」在 CMMLU 上 40/40 全翻到知识网络，纯粹是 1487 vs 282 的功效差。
   → 双向矩阵每层约 512 个候选对 × 4 类，必须 BH-FDR + 匹配随机对照 + 功效匹配（每类等样本量）。
4. **「编码路径」要能跨层复合，不能停在 (S_i, h, w) 三元组。**
   残差流是累加的，单层三元组无法说明「第 24 层的写入如何被第 34 层用上」。
   → 路径 = 跨层 resid patch 链，且必须给出「恢复率」，而不是只有「退化率」。

## 2 共同基底：残差流方向字典 D

三层精度，按成本递增、按需使用。

| 层 | 内容 | 怎么来 | 成本 | 用途 |
|---|---|---|---|---|
| **D0 输出基** | unembedding 方向（5 个字母 token + 全词表 top-k）；`g ⊙ W_U` | 已有 | 0 | 跨层可比的唯一标量（DLA 是**层增量**，`h_final = h_0 + Σ(attn_l+mlp_l)`，一阶近似下 logit 可加，所以层归属本身是对的） |
| **D1 层内读写基** | 每单元 `(r_i = gate_i, w_i = down_col_i)`；每头 `(OV 主方向 = top 奇异向量 of W_O W_V, QK 主方向)` | 纯权重，SVD | 秒级/层 | 几何配对（本方案的主筛），以及 θ 与对齐的既有口径 |
| **D2 子组件基** | 单元分组（共激活簇）→ 组级写方向 = 组内 `w_i` 的加权和 | **普查 top-32 位置共现聚类（零训练）**，或 VPD（研究性） | 10 min / 3–6 h | 绕开单神经元多义：「一组单元共同写入的方向」才是 VPD 意义上的子组件 |

**D2 的零训练实现（本方案的关键便宜点）**：普查 `L{b}.npz` 已存每单元 `top_idx`（各单元激活最大的 32 个 token 位置）、`hist`、`s1/s2`、`readout_top`。
把 `(unit, position)` 建成稀疏矩阵、算共现相似度、谱聚类 → 得到「在语料中一起亮的单元组」。
这是 VPD 的**经验代理**：VPD 优化的是「消融后行为保持」，共现聚类优化的是「统计上同现」。
两者不等价，但对「候选写入方向」这一层足够，且可先验证：
**若聚类出的组与普查已标注的 `type_name` 高度重合，说明分组有结构；若与随机分组无差别，直接否决 D2。**

零模型基线（沿用前后锥口径）：随机单位向量 |cos| ≈ 1/√2560 = **0.0198**。

## 3 五条流水线

编号即执行顺序；W/R 可并行，G 依赖 W+R，C 依赖 G。

### W 写入侧（MLP）

| 步 | 内容 | 产出 | 成本 |
|---|---|---|---|
| W1 | 每层每单元 `(r_i, w_i)` + θ；每层 `down_proj` 的 top-k 奇异方向 | D1 表 | 秒级 × 36 层 |
| W2 | 共现聚类 → D2 组（含组写方向、组大小、与 `type_name` 的重合率） | 分组表 | 10 min（CPU） |
| W3 | 组级行为画像：消融组 → 在 5 个探测任务上的退化向量 `d_i ∈ R^5`（主谓一致 / 指代 / 短语边界 / 否定 / 翻译方向） | `d_i` 表 | 每层 16 组 × 100 题 × 5 任务？→ 改为 16 组 × 100 题一次前向，任务指标离线算 ≈ 15 min/层 |
| W4（可选，研究性） | VPD 单层原型 | 必要性分数谱 | 3–6 h/次，**上限 2 次尝试** |

探测任务直接从现有题库派生（语法规则 / 功能推理 / 知识网络），不新造语料；翻译与指代若缺，用 XL.TRANS 补齐（v2 §9 已提）。

### R 路由侧（注意力）

| 步 | 内容 | 产出 | 成本 |
|---|---|---|---|
| R0 | **位置分辨读出**（v2 P0 的缺口）：在「题干末 token / 各选项末 token / 答案位」三处取逐层逐头行 | `attn_pos[l][h][pos]` | 169 题 ≈ 1 min |
| R1 | 每头 OV 主方向（top-3 奇异向量 of `W_O W_V`，按奇异值加权）与 QK 主方向；`ov_align = cos(OV·r̂, r̂)` | 头方向表 | 秒级 |
| R2 | 路由指纹：注意力熵、对依存弧集中度（用 token 距离桶近似）、对重复 token 的抑制强度、attention sink 占比 | 指纹表 | 复用 R0 数据，离线算 |
| R3 | 头类型标签：induction / prev-token / successor / duplicate-token / sink（自动打分） | 类型表 | 200 行打分器 + 1 h |

R3 是族的定义前提（见 §6），不可省。

### G 几何配对（便宜的主筛）

对每个 `(写入方向 u, 读取方向 v)` 算 `cos(u, v)`，与零模型 0.0198 比，取 `|cos| ≥ 5×` 的对子进 C 阶段。

- 输入：W 的组写方向、R 的 OV/QK 主方向（同层 + 跨层 ±1）。
- 产出：`pairs.json`，含 `cos`、`null_z = cos / 0.0198`、来源标记。
- 成本：矩阵乘，秒级。

**这一条是 v3 能否成立的关键桥**：几何便宜、可穷举；因果贵、必须稀疏。若几何提出的候选在因果上命中率低于随机，整条路线作废（见 §8 kill criterion G）。

### C 双向因果

| 步 | 干预 | 测量 | 成本（每层） |
|---|---|---|---|
| C1 写→路由 | 消融 D2 组（组内单元输出置零 / mean 替换） | 目标头在 `R_h` 各方向上的投影变化 `Δπ`；同时报 sham（同规模随机组） | 16 组 × 32 头 × 8 prompt = 4 096 前向 ≈ 17 min |
| C2 路由→写 | 方向性消融：把头输出在 `w_hj` 上投影置零（只断一个方向，不断整个头） | 组 `d_i` 的退化向量是否出现 / 放大 | 32 头 × 3 方向 × 100 题 = 9 600 前向 ≈ 40 min |
| C3 恢复 | 从对照输入 patch 回 `R_h` 方向 | 被 C1 破坏的行为恢复率 | 候选路径 × 100 题 ≈ 20 min |
| C4 必需性 | 与 C1 同源，但用 mean ablation 与 zero ablation 两版对照 | `Δ行为` 两版同向才算必要 | 与 C1 合并 |

**C 阶段纪律**：`必要`（C1/C4）、`充分`（加性干预：沿 `w_hj` 放大 2× 看答案是否翻转）、`恢复`（C3）三件套缺一不可。
只有「必要 + 充分 + 恢复」三者同向，才写「承载」；只有两个写「参与」；只有一个写「相关」。

### P 路径稀疏化与模式特异性

1. 只保留 C1、C2 双向显著且 C3 恢复率 > 50% 的三元组。
2. 每条路径求**最小充分集**：贪心删边直到恢复率跌破阈值（K-MSHC 思路）。
3. 跨层延伸：上一层的头是否也读写同一方向 → 向前追溯到 embedding 或不可再分节点。
4. 每条路径一条「匹配随机对照」零分布（同规模随机组 / 同 PR 但指纹不同的头），只保留效应超过 95% 分位的。

## 4 数据结构

```json
{
  "schema": "mech_path.v3",
  "pattern": "GR.AGREE",
  "model": "qwen3-4b",
  "src": {"kind": "mlp_group", "layer": 24, "gid": 7, "units": 43, "basis": "D2",
          "w_dir": "sha1:…", "type_mix": {"syntax": 0.61, "semantic": 0.22, "other": 0.17}},
  "dst": {"kind": "head_dir", "layer": 31, "head": 12, "dir_idx": 1, "basis": "D1",
          "r_dir": "sha1:…", "head_type": "induction", "fingerprint": {"entropy": 0.41, "dup_suppress": 0.63}},
  "geometry": {"cos": 0.31, "null_z": 15.7},
  "causal": {"fwd_delta_pi": 0.24, "rev_probe_drop": 0.18, "restore": 0.62,
             "sham_fwd": 0.03, "sham_rev": 0.02, "necessary": true, "sufficient": false},
  "verdict": "参与",
  "q_value": 0.004
}
```

模式签名（族的载体）升级为四元组：

```
Family(pattern) = ⟨ 层画像, 类型组成, 方向组合, 因果权重 ⟩
```

其中**层画像是唯一已经实测稳定、对样本量不敏感的分量**：

```
C-Eval   L24:2 25:2 26:1 27:1 29:4 30:3 31:2 32:2 33:1 34:4 35:6
CMMLU    L24:5 25:4 26:2 27:2 28:4 29:9 30:6 31:8 32:7 33:11 34:9 35:11
```

族的判据 = 画像形状跨数据集稳定 **且** 路径集合跨模型功能对应（不要求头编号一致）。

## 5 预注册预测（跑之前写死，跑完对账）

| # | 预测 | 若失败意味着 |
|---|---|---|
| P1 | MLP 组写方向与头读方向的 max |cos| 分布显著超过 0.0198，且 top-100 对里因果命中率 ≥15% | 几何→因果的桥不成立，回退纯消融筛选 |
| P2 | 编码路径 ≥60% 落在 L24–L35，L0–L11 <10% | 「收口」只是读出假象，不是机制 |
| P3 | 知识网络 vs 语法规则的路径 Jaccard <0.3；共享路径集中在 L29–L33 | 两族其实同族，v2 的「跨类型共用」要改写 |
| P4 | 功效匹配（每类 280 题）后，功能推理专属路径仍 ≥5 条 | C-Eval 的 L32/L33 专属头是功效幻觉（与 CMMLU 40/40 翻面一致） |
| P5 | D2 组内单元对同一头方向的对齐，显著高于同规模随机组（≥2×） | 共现聚类无机制含义，D2 作废 |
| P6 | 早层（L0–L8）在选项位的 DLA 显著高于末位；晚层相反 | 「位置」这一维无效，R 流水线可简化 |
| P7 | 被 C1 破坏的行为，C3 恢复率中位 ≥50% | 路径假设错（破坏的不是这条通路） |
| P8 | qwen3-4b 与 DS7B 的 top-10 路径在功能对应下重合 ≥30% | 单模型结论不可外推，「族」只是本模型现象 |

P3、P4 直接回应用户的核心问题（语言模式族的特征）；P1、P7 决定方法是否成立。

## 6 分析粒度（v2 第 4 问的固化）

三层的结论不变，v3 只是把它写进数据结构：

1. **层内比较**：所有「谁更强」只在层内做（全局归一化会让深层虚高，实测已证）。
2. **层画像**：族的特征 = `onset / peak / 尾部占比 / 层间符号结构`，不是头列表。层画像对样本量不敏感，头显著性会翻面。
3. **跨层对齐**只能借三种基：输出基（D0，可加）、因果基（resid patch 曲线）、类型基（头类型 × 层带）。
4. **族的最终定义 = (头类型, 层带) 的组成 + 跨层路径**，不是头编号集合。跨模型时用功能对应，不用编号对应。

## 8 排期、成本与止损

### 档 A：最小可交付（10 个工作日，风险低）

| 阶段 | 内容 | 交付 | 估算 |

| A2 | W1/W2 方向与共现分组 + P5 验证 | `groups.json` | 2 天 |
| A3 | G 几何配对（4 层：L2 / L24 / L30 / L34） | `pairs.json` | 0.5 天 |
| A4 | C1+C4 前向干预（4 层 × 16 组） | 双向矩阵前向半 | 1.5 天（GPU ~2 h） |
| A5 | C2 反向方向性消融 | 双向矩阵反向半 | 1.5 天（GPU ~3 h） |
| A6 | P 稀疏化 + 模式特异性 + 界面②③ | 路径表 + 两视图 | 2.5 天 |

**验收**：至少在 GR.AGREE（校准项）上给出 1 条「必要+恢复」路径，且通过 sham 对照。

### 档 B：完整版（再加 10–15 天）

- C3 恢复检验全覆盖、跨层路径延伸、跨模型（DS7B / GLM4）功能对应、功效匹配重跑三类各 280 题、W4 VPD 单层原型。

### 止损点（硬性）

| 阶段 | Kill criterion | 触发后 |
|---|---|---|
| G | top-100 对因果命中率 <5%（随机 1%） | 放弃「几何提候选」，改用纯消融扫；v3 降级为 v2 + 双向干预 |
| C1 | 消融任何 top 组 Δ 行为 <2pp 且与 sham 无差异 | 写入侧在选择题格式上不可分辨 → 换任务格式或转 SAE |
| W4 | 6 h 内必要性分数无长尾 | 降到 D2 共现聚类，VPD 只作附录 |
| P5 | 组内对齐 ≈ 随机 | D2 作废，只用 D1 单单元方向 |

### 注：外部意见里未采纳的一条

它建议用 Spectral Probe-Circuits 的 PR 积分筛选「内容依赖头」。本机更便宜的等价物已经存在
（OV 谱有效秩 + 注意力熵 + 已有 hit/mass 统计），且 PR 筛出的「内容依赖头」与「答案收口头」
很可能不是同一批——**这本身是个可检验预测（P1 的旁支），而不是必须先复现的方法**。

## 10 风险清单

1. **循环论证**：用探测任务定义分解、再用同一探测任务验证。对策：留出探测集不参与任何训练或筛选。

# H 段：杠杆集的 held-out 复现与「删 1% ≈ 删 100%」的机制（2026-10-30）

C 段的结论全部落在 C-Eval val 169 题上，且留下一个没法自洽的现象：删 top-1% 的 KL（0.178）比删整层（0.171）还大，翻转也更多（5/169 vs 5/169）。这有两种可能——杠杆集是模型属性，或者只是这批题的属性。H 段先做判决实验，再解释那个反常现象。

## H1 判决实验：L24 杠杆集的跨数据集复现（PASS）

源集 = C-Eval val 169 题上 |Δ| 的 top-97；目标 = CMMLU test 两套 169 题抽样（seed 20261101）：
**match** 按科目逐科配对（生物 19 / 地理 19 / 中国史 10 / 世界史 10 / 公文 47 / 逻辑 22 / 现代文 23 / 古文 19），
**wide** 在 69 个科目里均匀随机（不加任何结构，最严）。

| 判据 | 阈值（预注册） | match | wide | 结论 |
|---|---|---|---|---|
| K1 集稳定 | top-97 重叠 ≥ 20（随机期望 0.97） | **65** | **65** | PASS（67× 机会） |
| K2 方向一致 | spearman(\|Δ_ce\|,\|Δ_cm\|) ≥ 0.30 | **0.607** | **0.605** | PASS |
| K3 杠杆可迁移 | KL(ce97) ≥ 3×KL(rand97) 且 ≥ 0.5×KL(cm97) | 0.04764 vs 0.00088（54×）/ 0.91× | — | PASS |

两套抽样的数字几乎相同（0.607 / 0.605、65 / 65），说明结论与科目构成无关。K3 更硬：**在 CMMLU 上删 ce97 的 KL = 0.04764，删整层 = 0.04765，两者到小数点后四位仍相等。**

**结论 H1：杠杆集是模型属性，不是数据集属性。** L24 的 97 个单元（1%）在跨数据集、跨 69 个科目时仍是同一个集合，且删掉它等于删掉整层。这是本项目第一条可跨集引用的单元级结论。

同时复现了反常：CMMLU 上删 top-97 翻 **8/169**，删整层只翻 **5/169**，随机 97 个只翻 1–2/169。

## H2 平衡假说：被否证

假设是「top-97 是被其余 99% 对冲着的净正杠杆，只删一侧才打破平衡」。构造对冲集：P 净 Δ = +9.80，故在 rest 里取 Δ<0 的单元，两个版本——
`Nabs`（只按 |Δ| 取最大 97 个）、`Nopp`（要求 down_proj 写方向与 P 最相似，逐 p 配对）。

| 集合 | KL | 翻转 |
|---|---|---|
| P（97） | 0.04764 | 8 |
| Nabs（97） | 0.01312 | 2 |
| Nopp（97） | **0.00141**（≈随机 0.00089） | 1 |
| **P∪Nopp（194）** | **0.04543 < P** | 10 |
| P∪Nabs（194） | 0.04776 | 10 |
| rand194 | 0.00133 | 1 |
| 整层 | 0.04765 | 5 |

**加进配重，KL 下降。** 这是次加性而不是超加性。翻转数 8→10 在 n=169 下是噪声级（二项检验 p≈0.5），且 Nopp 与 Nabs 给出完全相同的 10，说明「写方向对齐」没有额外作用（B3 实际未区分）。

**结论 H2：平衡假说不成立，预注册 B2 的 KL 判据实际未通过**（我原设的 0.85 阈值太松，把它误判成通过，这里更正）。Nopp 的 KL 近乎为零这一点另有含义：一个单元的 Δ 小，不代表它对分布无影响——见 H3b。

## H3 范数被常数平移污染

把 Δlogits 当向量看（未中心化）：

| 集合 | ‖Δ‖/‖Δ整层‖（中位） | KL |
|---|---|---|
| P | 1.73 | 0.04764 |
| 补集 | 1.44 | 0.02397 |
| rand97 | **8.16** | **0.00089** |
| 整层 | 1.00 | 0.04765 |

随机删 97 个单元把 logits 推得最远（8 倍），却几乎不动分布。原因是删除小规模随机单元近似于给全部 logits 加一个常数——softmax 对整体平移不敏感。中心化后这个假象消失：‖δ_c‖ 中位 P 139.8 / 补集 194.2 / 整层 235.2 / **rand97 仅 31.4**。

**结论 H3：任何以「logits 距离 / 范数」为指标的消融分析都会被常数平移污染；也必须记下 rand97 是个弱对照——它连扰动规模都没打到，1/97 的 KL 差距有一部分来自此。**

## H3b 扰动效率：KL 是长尾量，不指代答案决策（E1 FAIL）

去掉常数分量后，看扰动落在哪里（151936 维词表）：

| 集合 | top-20 token 能量占比 | 字母 token 能量占比 | KL | ‖δ_c‖ | 效率 KL/‖δ_c‖² |
|---|---|---|---|---|---|
| P | 0.0007 | 0.0002 | 0.04764 | 139.8 | **0.244** |
| 补集 | 0.0003 | 0.0001 | 0.02397 | 194.2 | 0.064 |
| rand97 | 0.0004 | 0.0001 | 0.00089 | 31.4 | 0.090 |
| 整层 | 0.0003 | 0.0002 | 0.04765 | 235.2 | 0.086 |

（效率单位 ×1e5；均匀分布下 top-20 能量占比应为 0.00013。）

**关键读数：top-1% 的扰动只有 0.07% 的能量落在概率最高的 20 个 token 上，字母上只有 0.02%。** 扰动几乎均匀铺满整个 15 万词表，**几乎不动那几个高概率字母**。

E1（定向性，要求 ≥3×）判 FAIL（0.0007 vs 0.0003 = 2.3×）；E2（效率 3.8×）、E3（字母 2×）过阈值，但基数都极小，只能当弱证据。

**结论 H3b（本轮最重要的一条）：KL 排名测的是 logit 长尾的敏感性，不是答案决策的因果贡献。** 这一次性解释了 C 段三个反直觉结果：
· 为什么删 top-1% 的 KL 等于删整层——两者都在抖长尾，量级由「抖多少」而非「抖哪里」决定；
· 为什么整层删掉答案不翻（5/169）——扰动压根没落在答案 token 上；
· 为什么 Σ|Δ|=633.7 而 ΣΔ=16.1（97.5% 抵消）——一阶归因在答案 logit 上的分量本来就是次要项。

**因此 ② 阶段必须换因变量，且不能换「另一种 next-token 分布指标」，要换到行为层面（生成任务的正确率）。** 只要因变量还在 next-token 分布上，测到的都是长尾。

> 用电路语言说：它们是**差分对（differential pair）的载体**，不是单向功能模块。删掉一对，两端同时消失，净输出不变。

**这一条同时解释了三件此前分开记录的事**：
· C5' 的「删整层不翻答案反而更自信」→ 不是"层不重要"，是正反两端一起消失。
· H4 的 L24「P = rand」→ L24 的单元也成对，只是更分散（top-1% 只占 7.9%–14.7% 的 |Δ|）。
· H1 的跨集稳定性 → 稳定的正是"哪一对单元承载这个差分"，它是模型属性。

**可证伪的推论（预注册，下一轮第一项）**：若"差分对"成立，则
1. **按符号配对删除**（同时删 +Δ 与 −Δ 的高幅单元）应比删同量随机单元**更**扰动行为，而删单侧（只删 +Δ）应改变答案的**方向**（系统性偏向某一侧）。
2. **steering（沿单元写方向加，不对称）应远强于 ablation（删，对称）** —— 这正是很多论文里 steering 有效而 ablation 无效的原因。

**次要但稳定的观察**：删 top-97 把格式遵循率从 0.888 抬到 **0.994**、解析失败从 19 降到 1。即删掉这批单元后，模型输出**更模板化**、更少自由发挥。这是"删掉某类单元 → 行为变机械"的正面例子，方向与"删掉能力"相反。

## H6 差分对判决实验：删单侧 vs 删双侧（预注册后执行，2026-10-30 09:10）

H5 的结论（杠杆真实但双向抵消）只是**从结果反推**的解释。要把它变成机制，必须有一个
**在跑之前就能说清方向**的预测。差分对假设给出的预测非常明确：既然这批单元成对正反编码，
把两侧拆开单独删，方向就应当显现；合起来删，方向就应当消失。

**设计上唯一的差别是「删哪一侧」**：L34 的 top-97 里正侧 45 个、负侧 52 个，取 |Δ| 最大的
**各 45 个做数量与幅度双匹配**（Σ|Δ|：pos 48.77 / neg 45.54，比 1.07）。

| 条件 | 删哪些 | 单元数 | Σ\|Δ\| |
|---|---|---|---|
| base | 不干预 | 0 | — |
| pos | Δ>0 且 \|Δ\| 最大 | 45 | 48.77 |
| neg | Δ<0 且 \|Δ\| 最大 | 45 | 45.54 |
| both | pos ∪ neg | 90 | 94.31 |

**预注册判据（跑之前固定）**：

- **S1 基线可复现**：本轮 base 的逐题答案与 H5 一致率 ≥ 0.95。不成立则 greedy 不可复现，
  整轮作废（不能拿旧 base 当分母）。*干跑 3 题已测得一致率 1.000。*
- **S2 单侧有方向**：net(pos) ≤ −5 且 net(neg) ≥ +3 且 acc(neg) > acc(pos) + 0.03，
  其中 net = (由错变对) − (由对变错)。
- **S3 双侧抵消**：|net(both)| ≤ max(2, 0.35 × max(|net(pos)|, |net(neg)|))。
- **S4 都在动行为**：三个条件的改答率均 ≥ 2× rand97 的 0.089，且 McNemar p < 0.01。

**判读**：S2+S3 → 差分对成立；S2 过 S3 不过 → 「部分抵消」，不是严格差分对；
S2 不过 → 差分对被否证，杠杆只是无向抖动。

> 这一轮的设计要点是**把「数量」和「幅度」都匹配掉**，剩下的唯一变量就是符号。
> 如果单侧删除给不出方向，那 H5 的「双向抵消」就只能退回成「效应小、测不出」。

但同时要否掉脚本原来的那个读法（「无向抖动」）。随机删 97 个单元是 **+0.73 pt（无损伤）**，
而这批单元删 45 个就掉 5 个点、改答率是随机的 4–6 倍（neg/both 的 p = 6e−5）。**特异性极强。**

两个事实合起来只有一种自洽解释：**L34 这 90 个单元是一个冗余饱和的功能池。**

- 池内**任一半**被删（45 个）→ 触及饱和点，掉 5 个点；
- 两半**全删**（90 个）→ **不再多掉**（−5.11 vs −5.11，p = 1.0000）；
- 池外随机删同等甚至两倍数量 → 几乎不动（+0.73）。

也就是说：信息高度集中在池内，但池内是**冗余并行承载**，不是**正反配对抵消**。
「差分对」要求删一半只有一半后果、删全部才有全部后果；实测是删一半就等于全部后果。
这个「删一半 = 删全部」的饱和形状，本身就是差分对假设的反证。

> 与 3280 阶段的发现一致：静态 top 写入集中在少数头层、两子空间共享中继头族——
> 共享一个功能，而不是两两配对。H6 在单元层面给出了同一形状。


## H7 放大 vs 删除：不依赖「删除」本身的方向性检验（预注册）

H6 有一个无法回避的弱点：删是 **×0**，是个极端且对称的操作。H5 已经看到删 top-97 会把
格式遵循率从 0.888 抬到 0.994，说明删除本身带有副作用（输出变模板化）。所以
「删单侧没方向」也可能是删除操作的副作用淹没了方向。

更干净的检验是把同一侧推向**两个相反方向**：

| 条件 | 操作 | 若该侧真的推高答案，应观察到 |
|---|---|---|
| amp_pos | 正侧 45 个 × 2 | 提分 |
| abl_pos | 正侧 45 个 × 0 | 掉分 |
| amp_neg | 负侧 45 个 × 2 | 掉分 |
| abl_neg | 负侧 45 个 × 0 | 提分或不掉 |

**预注册判据**：
- **A1 单侧单调**：acc(amp_neg) < acc(base) < acc(amp_pos)，且两端差 ≥ 0.05
- **A2 同侧反向**：net(amp_pos) 与 net(abl_pos) 符号相反且 |net(amp_pos)| ≥ 3；
  net(amp_neg) 与 net(abl_neg) 符号相反且 |net(amp_neg)| ≥ 3
- **A3 非饱和**：acc(amp_pos) < 0.995（否则是任务天花板，不是效应）

**判读**：A1+A2 → 单元是**有符号的功能载体**，「删除测不出」只是对称操作抹平了符号；
A1 过 A2 不过 → 只有一端真正参与答案计算；A1 不过 → 归因的符号不是功能性的。

> H7 复用 H6 的单元表（`pair_sign_L34.json` 的 `units`），保证两轮测的是同一批单元。

## H8 饱和点：冗余池的剂量-反应（预注册，2026-10-30 10:45 起跑）

H6 给出一个反常形状：删 45 个（−5.11 pt）与删 90 个（−5.11 pt）毫无差别。这只能是「饱和」——
删到某个数量就吃掉了全部可损伤的功能。**H8 要回答那个数量是多少**，这是「冗余度」的直接测量，
也是「池内还有没有分工」的前置问题。

**设计**：单元按 |Δ| 降序（不按符号分组——H6 已证符号无方向性），取前 k 个全部 ×0，
k ∈ {10, 20, 40}；169 题、同 SEED（20261101）、同 hook（`down_proj` 输入置零）。
高剂量端不重跑，直接用 H5 的 k=97（−5.84 pt）与 H6 的 k=90（−5.11 pt）两点。

**预注册判据（写死在 `tools/mech_dose.py`，跑之前固定）**：

- **D1 单调**：acc(k) 随 k 不增（允许 1 题抖动）。
- **D2 饱和点**：Δ(k) 达到 Δ(97) 的 80%（即 −4.67 pt）时的最小 k，记 **k80**。
- **D3 起点离噪**：k=10 的 |Δ| ≥ 3 pt，否则曲线起点就在噪声里、k80 无意义。
- **对齐校验**：当轮 base 必须与 H5/H6 逐题一致（同 SEED、同题序）；不一致则整轮作废。

**判读**：k80 ≤ 20 → 极强冗余（20 个承担整池）；20 < k80 ≤ 45 → 中等冗余（与 H6 一致）；
k80 > 45 → 接近线性，这批单元更像独立累加而非共享池。

### 关键矛盾：\|Δ\| 头部在功能上是惰性的

把 H8 与 H6 摆在一起，出现一个任何「幅度即重要性」模型都容纳不了的事实——**同一份归因数组、
同一个 hook、同一批题、同两个 SEED**：

| 集合 | 单元数 | Σ\|Δ\| | Δ |
|---|---|---|---|
| top-40（按 \|Δ\| 降序） | 40 | 73.63 | **−0.74 pt** |
| pos45（全部 45 个正号单元，H6） | 45 | 48.77 | **−5.11 pt** |
| neg45（45 个最大负号单元，H6） | 45 | 45.54 | **−4.38 pt** |
| 随机 97（H6 对照） | 97 | ≈3 | +0.73 pt |

top-40 拿走了 top-97 归因总量的 **76%**（73.63 / 96.50），削掉它几乎无损；

所以不是「没删到关键单元」，是**排在最前面的那批单元删掉不痛不痒**。

这直接打击「按 |Δ| 排序取 top-k = 取最重要单元」这个归因方法的核心假设。
它**不推翻 H5**：H5 比较的是「整池 97 vs 随机 97」，问「这批单元重不重要」，答案重要；
H8/H6 问的是「池内按幅度排序有没有意义」，目前看没有。

> 顺带更正 H6 段的一处读法：那里我写「删池内任一半即触及饱和点」，H8 说明这话不成立——
> 删 40 个（含两半各一部分）并不触顶，删 45 个**整类**才触顶。差别不在数量，在**是否把某一符号类删到接近干净**。


> 这一轮的成本只有 H7 的 3/4，但它回答的是 H6 直接指出的问题。
> H7（放大 vs 删除）仍然值得跑——它用不对称操作独立复核「符号无功能意义」，
> 但优先级降到 H8 之后：如果饱和成立，「放大」能做的只是把已经很确定的输出推得更极端。

## H9 L24 同口径重测：必要性是否取决于集中度（预注册，等 H8 结束后跑）

## H10 头部惰性 vs 尾部承载：\|Δ\| 排名能不能预测必要性（预注册，2026-10-30 12:25 起跑）

H8 摆出了一个自相矛盾的事实（详见 H8 实测段）：top-40 占归因总量 76% 却几乎无伤，
而各 45 个的 pos45 / neg45 掉 4–5 点。这一轮要在**同一次运行内**分清两种解释，
而不是靠跨轮拼数据。

**两种候选解释**

- **A 尾部承载**：效应就在 `pos45 \ top40`（27 个）与 `neg45 \ top40`（23 个）里，
  符号类的完整性无关。若成立 ⇒ |Δ| 排序在头部**反预测**必要性，归因幅度大 ≠ 必要。
- **B 类覆盖阈值**：必须把某一符号类删到接近干净才触发（pos45 是 45/45 = 100%，
  neg45 是 45/52 = 87%），删 27/23 个不够。若成立 ⇒ H6 的「饱和池」应改写为
  「类覆盖阈值」，"饱和"不是删够了数量，而是某一类的单元被删到近乎为零。

**设计**：四个条件，全部 ×0（`down_proj` 输入置零，与 H6/H8 同一个 hook），169 题、同 SEED（20261101）：

| 条件 | 单元集 | 个数 | Σ\|Δ\| |
|---|---|---|---|
| `tailP` | pos45 去掉 top-40 之后剩下的 | 27 | 11.25 |
| `tailN` | neg45 去掉 top-40 之后剩下的 | 23 | 9.43 |
| `k60` | \|Δ\| 降序前 60 | 60 | 83.45 |
| `k80` | \|Δ\| 降序前 80 | 80 | 91.04 |

base **不重跑**，复用 `dose_L34.json` 的逐题 base（贪心解码，H5/H6/H8 三轮逐题一致 169/169，
确定性已两次验证）。严格子集 = base 有效 且 四个新条件全有效。约 88 分钟。

**预注册判据（写死在 `tools/mech_headtail.py`）**：

- **T1 尾部承载**：`|Δ(tailP)| ≥ 3pt` **或** `|Δ(tailN)| ≥ 3pt`。
- **T2 类覆盖阈值**：两个 tail 的 `|Δ|` 都 `< 1.5pt`。
- **C1 悬崖位置**：k ∈ {40, 60, 80, 97} 中 `|Δ| ≤ −3pt` 的最小 k（97 用 H5 实测 −5.93）。
- 两条都不成立 ⇒ 效应依赖特定单元组合，需逐单元留一验证（成本高，另立 Phase，本轮不猜）。

**可证伪点**：若 `tailP`（27 个、Σ|Δ| 只有 11.25、平均 |Δ| 0.42）能打出 −5 点，
那么在同一层上「归因幅度」与「必要性」在头部是**反相关**的——这会让「按 |Δ| 排序」的
整套做法在 L34 失效，也是对 3280「静态 top 写入头层聚集 ~9× 特异性」的重要限定。

**判读的意义**：
- T1 成立 → 归因排序失效区被定位，后续所有「取 top-k」类实验必须改用「整类删除 / 留一」口径；
- T2 成立 → 回到「类覆盖」，H6 的结论从「冗余池」修正为「符号类覆盖阈值」，
  而符号是否有功能意义要重新审（H6 只证了正负两侧同向，未证「删一半」的性质）；
- 都不成立 → 承认目前测不出机制，登记为开放问题，不再用 top-k 口径反复测。

### 损伤不是均匀分布的：12 道题承担了整个「−5.9 点」

> **本节自身的缺陷，必须写下来**：我把「prompt 最后一位」当成答案决策点，但 base 在这个位置
> 生成的第一批 token 是「 答案：」，**字母是之后几步才决定的**。所以「字母 Δ 只有 0.06」
> 不能读成「字母没被影响」，只能读成「这个位置上字母的差异被格式效应淹没了」。
> 正确读法是：**767 在这个位置的主要作用是「别换行、接着答」**，字母层面的事要在前缀条件下重测。

### H19 第一版设计当场作废：强制前缀不中性（`tempdata/format_test_L34.json`）

为了把格式因素扣掉，最直接的想法是强制接上「 答案：」再让模型只吐字母。**跑到第 1 题就废了**：

| 条件 | qi=5（gold D）给出的答案 |
|---|---|
| base 正常生成 | **D** ✓ |
| base + 强制「 答案：」前缀 | **C** ✗ |

原因很简单：prompt 以「分析：」结尾，直接接「 答案：」等于**把推理过程整段删掉**，
模型于是在没分析的情况下作答。前缀条件同时改了两个因素（格式 + 推理），不能用来分离它们。
**这一版当场废弃，没有产出任何结论。** 这是本轮唯一一次「设计错误在第一个样本上就暴露」，
代价只有 75 秒——比跑完再发现便宜得多。

改用 **teacher forcing**：让 base 正常写完，取 `prompt + base 输出直到第一个「答案：」`
作为固定前缀，再在这个前缀上分别用 {base, 767, 2 个随机单点} 做一次前向，只看 A/B/C/D 的分布。
前缀完全一致 ⇒ 格式自由度被完全扣掉。

| 条件 | 字母 argmax 不变 | KL vs base（4 类） |
|---|---|---|
| 767 消融（9 道坏题） | **9/9** | 中位 **0.000000**（非饱和的两道：qi=29 → 0.0021、qi=94 → 0.0019） |
| 2 个随机单点（同 9 道） | 9/9 | 0.000000 |
| 767 消融（8 道对照） | 8/8 | 0.000000 |

（19 题里 2 道跳过：qi=61、78 的 base 输出没有「答案：」字样，msign.parse 用的是别的模式。）

N1/N2/N3 三条判据全过。**但这个读出是饱和的**——7/9 道题在这个位置的字母概率 p = 1.000，
分析写全之后答案几乎是强制的，任何单元的消融都推不动它。
所以 H19 只能排除「答案已确定时 767 还改答案」，**不能**证明「767 不携带内容」。这个 caveat 不写就是又一次把弱检验读成强结论。

### H20 前缀长度扫描：把饱和读出拆开，仍然没有内容效应（`tempdata/prefix_scan_L34.json`）

把 base 的分析文本按 token 边界截到 25% / 50% / 75% / 100%，让答案重新变得不确定：

| 前缀 | 字母 argmax 变化 | 间隔位移（中位 / 最大） | 该位置字母最大概率（中位） | gold 间隔范围 |
|---|---|---|---|---|
| 25% | **0/11** | 0.031 / 0.12 | 0.584 | −5.2 … +1.7 |
| 50% | **0/11** | 0.016 / 0.12 | 0.725 | −6.0 … +8.0 |
| 75% | **0/11** | 0.031 / 0.12 | 0.513 | −3.7 … +14.0 |
| 100% | 1/11 | 0.000 / 0.12 | 0.601 | −12.9 … +2.4 |

S1 早段有影响 **✗**、S2 晚段无影响 ✓、S3 剂量方向 ✓。

**关键点是这个读出不再饱和**：25% 前缀上字母最大概率中位 0.58、gold 间隔从 −5.2 到 +1.7 都有，
说明这个位置上答案确实还没定。而 767 的消融把间隔挪动的上界是 **0.12 个 logit**——
与 H18 里换行族的 **9–10.7** 相差两个数量级。

⇒ **在所有前缀长度上，767 对「选哪个字母」都没有可测的影响；它对答案位置的主要作用是换行。**
这一条比 H19 强，因为它不依赖饱和读出。

### H21 因果闭环：767 消融后 8/11 先吐换行，答案跟着变（`tempdata/head_tokens_L34.json`）

最后一步是看**自由生成**（767 真正起作用的场景）里发生了什么。11 道坏题，每条记录 base 与消融后的首 token：

| qi | gold | base 首 token → 答案 | 767 消融首 token → 答案 |
|---|---|---|---|
| 5 | D | `本` → D ✓ | `\n` → C ✗ |
| 11 | B | ` \n` → B ✓ | `\n` → D ✗ |
| 25 | C | `宁夏` → C ✓ | `\n\n\n` → A ✗ |
| 29 | B | `____` → B ✓ | `\n\n\n` → D ✗ |
| 41 | D | `俺` → D ✓ | `战国` → A ✗ |
| 61 | A | `根据` → A ✓ | `根据`（无「答案」行）→ B ✗ |
| 73 | A | `根据` → A ✓ | `题目`（无「答案」行）→ 解析失败 |
| 78 | D | `人民` → D ✓ | `\n` → C ✗ |
| 94 | B | `____` → B ✓ | `\n` → A ✗ |
| 97 | D | `根据` → D ✓ | `\n` → C ✗ |
| 125 | A | `非` → A ✓ | `\n` → D ✗ |

- **首 token 是空白/换行：base 1/11 → 消融 8/11**（R1 ✓）
- **格式崩坏（无「答案」行或 8-gram 重复 ≥3 次）7 道，这 7 道答案全部改变**（R2 ✓ / R3 ✓）
- 剩下 4 道（25/29/97/125）虽然首 token 也是 `\n`，但输出最终仍带「答案」行，只是答案变了——
  也就是**格式没有完全崩，但轨迹已经偏了**。

R1+R2+R3 三条全过。**闭环成立：767 的作用是「别换行、接着答」；把这一行去掉，
模型另起一段重写分析，答案随之改掉。** 答案的正确性依赖它，但依赖的是**格式**，不是它携带的知识。

## H 段总收口

**一句话结论（已按 H8/H10/H11 修订）**：MLP 里的"重要单元"真实存在、可复现，而且在集中式层（L34）上
**整池是必要的**——删 top-97 打坏 14/110 道题，删随机 97 只打坏 1 道（p = 0.0074）。
但这条结论的**分辨率只到「池」这一级**：池内按 |Δ| 排序无效、也预测不了哪道题会坏。

**H6 曾给出「冗余饱和的共享池」这个形状，H8/H10 把它改写为三条更准确的话**：

1. **效应集中在一小批题上**：110 道 base 对的题里只有 12–14 道会被打坏，
   其中 qi = 73、5 被全部 8 个条件打坏。所以「−5.9 点」≈「12 道题」，
   任何在这个量级上做文章的子集比较，误差都以「几道题」为单位。
2. **池内按 |Δ| 排序无意义**：top-40 占归因总量 76%（Σ|Δ| 73.63/96.50），删掉只打坏 4 道；
   而 tailN 的 23 个「小队负号单元」（Σ|Δ| 9.43）打坏 11 道——与整池 97 个（14 道）接近。
   `k10 → k97` 的曲线在 40 名之前全平，悬崖落在 40–80 之间（C1 = 60）。
3. **符号仍然不是功能单位，但「删得够不够」也不是关键**：tailP(27) 打坏 3 道、改答 4 题；
   tailN(23) 打坏 11 道、改答 15 题（配对 p = 0.0010）。两者单元数与 Σ|Δ| 相近却差 4 倍——
   差别不在数量、不在符号，在**是否覆盖到那批承载单元**。

**所以「删一半 = 删全部」这个读法是错的**（H6 原话已更正）：删 40 个（含 pos45 的 18 个、
neg45 的 22 个）几乎无损，删 45 个整类才触顶。准确的说法是**近二值的池依赖性**：
覆盖到承载单元就一次性打满（~12 道题），覆盖不到就是 0，中间没有剂量梯度。

**这个形状对"编码破解"的直接含义**：继续在「正/负符号」上找区分是死路——符号不是功能单位（H6 已证）；
继续在「|Δ| 排名」上找更要死路——头部惰性（H8/H10 已证）。下一步只剩一条有信息量的路：
**把承载单元真正定位出来**（池内最小承载集），再问这几个单元编的是什么、读出到哪。

**H12/H13 给出了答案，本文「分辨率只到池这一级」这句要改**：分辨率原来卡在**指标**（|Δ|）上，
不是卡在池上。换测法（自适应二分 + 少题高重复，再做全量确认）后，承载核是 **3 个单元 [767, 1540, 35]**：
它们占 tailN 归因量的 12.7%，却承担 tailN 损伤的 75%（9/12，且 9 道**全部**包含在 tailN 的 12 道里），
在整池 97 个打坏 13 道（同口径 107 题）的尺度上贡献 8 道，而随机 97 个只打坏 3 道。
H14-pre 进一步证明这三个不是彼此的副本（写方向两两 |cos| ≤ 0.029）——是**三条几何独立的写通道**。

**但只能读结构，不能读显著**：效应以 9–10 道题计，core3 vs base p = 0.065、vs rand97 p = 0.070、
vs core5 p = 0.344，都不过 0.05。这是题池上限决定的硬分辨率（169 题封顶），
所以本段的正确措辞是「3 个单元承担了池损伤的四分之三」，而不是「3 个单元显著比随机伤」。

**仍未测的**：这 3 个是否**每个都必要**（H12 的二分到 3 个就停了，只测过三个一起删）→ H15 在跑。

### ⚠️ H15–H21 的翻案：所谓「承载核」是一个格式单元，不是知识单元

上面那段「3 个单元承担池损伤的四分之三」写于 15:34。**五个实验之后它要改口，而且改的不只是数字。**

1. **H15 推翻了「3」**：二分的 `while len(cur) > 3` 是搜索下限，从没测过单点。补测后 **767 一个就打了 9 道**，
   比三个一起（7 道）还多，加伙伴会把 qi=25 救回来（9 → 8 → 7 非单调）。账本 R-MLP-22（五档最小充分集）因此改判 refuted。
2. **H17 在全量上确认了「1 ≈ 3 ≈ 23」**：767 打坏 11/110（保留率 90.0%）、core3 9 道、tailN 23 个 12 道。
   但同一份数据否掉了「只此一个」：随机单点最大也能打坏 2 道。按身份读则相反——
   10 个随机单点损伤的**并集只有 3 道题**，767 有 **6 道在其外**。分歧全部来自 qi=73 这道
   **通用脆性题**（10 个随机单点里 8 个能弄坏它，且真改答与解析崩两种模态都有）→ R-MLP-24。
3. **H16 说它不是「特别火的单元」也不是「认某个词的单元」**：per-question 峰值的 AUC 0.573（≈随机），
   坏题与对照的 token 分布几乎重合（最大富集 1.2×），88% 激活质量落在标点上。
4. **H18 突然给了它一个非常具体的身份**：在答案位置，消融 767 把**换行族** logit 抬高 **9–10.7**，
   11 道题推的是**同一批 token**（Jaccard 1.00），而四个选项字母只动 ±0.06–0.12——小两个数量级。
5. **H19/H20 把「内容」这一支排掉**：把 base 自己的前缀固定（teacher forcing），9/9 坏题的字母 argmax 不变；
   再把前缀截到 25%（读出不再饱和，字母概率中位 0.58、gold 间隔 −5.2…+1.7），
   四档前缀上 767 对字母间隔的位移上界仍是 **0.12 个 logit**。
6. **H21 闭环**：自由生成时，消融后首 token 变空白/换行 base 1/11 → **8/11**，
   格式崩坏的 7 道题**答案全部改变**。

**所以正确的说法是三句话**：

- 单元级的「必要性」（删掉就打错）**真实存在且高度特异**：一个占该层 0.01% 的单元决定了 10 道题的对错。
- 但它的**机制是格式/轨迹**，不是知识：它负责「`分析：` 之后别换行，接着写答案」。
  消融后模型另起一段重写分析，答案于是漂移。字母层面的判断在任何前缀长度上都几乎没被它影响（≤0.12 logit）。
- 于是「承载核」这个名字必须换掉。它不是**概念承载单元**，是**格式承载单元**；
  「一个单元决定 10 道题」这句话要读成「一个单元决定输出格式，格式崩坏时带走 10 道题」。

**对整条线最重要的那条警告**（已入账 R-MET-12）：**用「答对/答错」当因变量的单元消融，
会系统性地把格式单元排到第一位。** 格式是全模型的瓶颈，只需要极少数单元；
知识是分布的。所以「最有必要性的单元」这个问法本身会先捞出格式单元。
任何「某个单元承载某个概念」的结论，都必须用**格式不变的读出**（固定前缀 + 答案位置间隔）复核过才算数。

**下一相预注册（H22）**：用格式不变读出重做池级必要性——对 top-97 / tailN / core3 / 单点
在 110 道 base 对的题上测「gold 间隔被压缩多少」，看是否还有单元排在前面。
若一个都没有，则本线要接受「L34 的 MLP 单元里没有可归因的内容承载者，内容在别处（注意力头 / 分布式方向）」。


> 口径纪律（第二次踩到，已入账本）：H6 脚本自带的 verdict 把 None 记错，把 net(neg) 从 −6 抹成 0、
> 把 net(both) 从 −8 抹成 −1，于是读出「无向抖动」。判据必须与报告口径同源——
> 任何「先看正确率、又用改答率下结论」的混用都会重复这个错误。


四个反直觉现象的最终解释链：
1. 删 1% 的 KL ≈ 删 100%（C3'）→ 因为 KL 测的是 logit 长尾的抖动幅度，而抖动幅度对「删多少」的依赖被常数平移和非线性放大搅乱（H3/H3b）。
2. 删整层不翻答案、反而更自信（C5'）→ 因为扰动只有 0.07% 的能量落在高概率 token 上，压根没动答案（H3b）。
3. 删最优 97 = 删随机 97（H4/H5）→ 因为效应成对抵消，**不是层不重要**。H5 用扩样把这条从"待定"变成定论：L34 上改答率 2.6×（p<1e-4）证明杠杆真实，但 14 错 / 11 对互相抵消，净 −3。
4. 40 题 vs 169 题的结论翻转（H4→H5）→ 前 40 题 base 0.850 / 全 169 题 0.651，是偏容易子集造成的抽样偏差；**任何"掉几点"的结论都必须看全量题与 McNemar p**。

**对 v3 流水线的修正（生效）**：
· **C 环节（因果归因）保留「单元」作统计单元，但判据换成"改答率"而不是"正确率"**：H5 证明正确率对双向效应不敏感（抵消 88%），而改答率对杠杆极敏感（2.6×，p<1e-4）。**用改答率量"杠杆"，用正确率量"必要性"，两者不可混用。**
· **删单侧 vs 删双侧成为新的核心实验设计**：任何"删 top-k"的因果结论都必须说明删的是哪一侧；只删高 +Δ（或只删高 −Δ）才能看到方向性效应。
· **沉默层直接排除**：整层 KL < 0.02（L30 = 0.0128）视为沉默，任何单元级结论都不入账。
· **头级归因仍是主力**（A1 的 58 个 DLA 显著头、46 个 induction 头）：头有明确读写分工和已知类型，不需要过集中度闸门。
· **KL 只作辅助，主因变量必须是行为，且必须带随机对照**：本轮若无 rand97，L34 的 7.5 点会被误读成「top-1% 可归因」（H5 扩样后这 7.5 点是抽样偏差），L24 的 2.5 点会被误读成「top-1% 有贡献」（p=1.0）。
· **配对检验不可省**：n=40 时 7.5 点差距的 McNemar p 只有 0.453，任何"掉几个点"的结论都必须给 p 值和 discordant 计数。
