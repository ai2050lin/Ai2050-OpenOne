# 首行查找的并行注意力与下游 MLP

输入材料已由 `clt_first_record_materials.py prepare` 封存，并用 `verify` 核对哈希、分组和前缀。清单位于 `tests/glm5/result/clt_first_record_path_v1/materials/manifest.json`。确认和干预各有 96 家族使用原句式、96 家族使用改写。按 15 个百分点的配对差异、失配比例 0.25、α=0.025 的规划示例，192 家族的近似功效为 0.972，单句式 96 家族为 0.757。单句式独立推广主张需独立核算。

发现采集入口为 `clt_first_record_discovery.py`。`--build-plan <路径>` 可以在不加载模型的情况下构建归档协议。现用 `discovery-plan-v2.json`，只使用已暴露的 Phase 2990 确认题。V1 的绝对量纲技术门失败，V2 另取正式回执，用每个样本和头的原生最大值归一重建误差，并独立复算 SDPA。V1 记录保留。

本地项目客户端通过「模型探索 → 条件对照 → 三线索选源 → 首行并行路径实验」直接使用当前管理员会话。正式查重后保存中心回执，由 `run_routine_test.py` 登记并启动；题目文件选用 Phase 2990 的 `confirm-materials.json`，磁盘预算 12 GiB。入口核对预检方案哈希、运行登记、实际脚本和题目哈希。分片保存全部头在五条记录及表外的注意力、按记录加权的 V、原 pre-O 向量、同层原 MLP 输入和中间神经元。发现归档读回后，留出阶段单独查重和登记，只在已暴露材料上冻结候选。只有留出过门后才取得匹配干预的新回执并运行。客户端分别显示可读出、可预测和因果状态。登录凭据不写入实验产物。

发现 V2 在 1,536 题中复现 303 道模型答对但 B26/H36 在五条记录中选错的物理首行题。选出的替代路径是较晚的 B28/H21 接 B28 MLP。B28/H21 在旧反例中有 301/303 次首选正确。192 个确认家族的 2,304 题中，按题目线索分组的真实注意力首选正确率为姓名 100%、印刷标签 97.66%、物理首行 99.74%。留出主门用其中 768 道物理首行题，预测一致率 97.53%，同预算随机列为 98.96%。所选坐标的优势见于数值误差：相对随机列，中心化记录对数注意力质量、O 写入和 MLP 激活 MSE 分别下降 71.31%、76.24% 和 84.18%，也优于发现集均值，六项家族配对下界均为正。正式中心已读回核验发现和留出产物。

独立干预覆盖 192 家族各一个预选的物理首行输入，共 1,152 次按臂执行。B28/H21 在原 O 投影前减半。以五个候选代码中正确码对最强错误码的 logit 差衡量答案优势。相对同层等剂量随机头干预，目标头的平均优势额外下降 0.3301 logit，按家族计算的 97.5% bootstrap 区间为 [0.1816, 0.4766]。等剂量率 192/192。sham 和同输入头恢复均逐位复现完整 logits。仅将所选 128 个 MLP 单元恢复到原值，正确码优势平均再下降 0.1510 logit。这组单元的因果中介仍待检验。基线首 token 准确率 189/192，减半后为 192/192，实验确认的是平均 logit 优势作用。确认和干预预注册覆盖一般物理首行题，尚无独立的 H36 失败切面复核或双头交互检验。

## 可证伪命题和对照

在 `BEGIN` 后物理首行题上，其他头可能把首行代码搬进残差流，B26 的 MLP 或更下游单元利用这段写入来稳定答案。还要比较三种解释。H36 排首错误时仍可能对首行保留足以写入的注意力。某头高质量可能仅跟随锚点格式或绝对 token 位置。候选 MLP 可能只是从已经正确的残差流中读出信息。平行头候选必须出现与换行同步的写入，并对下游变化作出留出预测。因果资格由原模型干预单独检验。

Phase 2990 中 303 个模型首 token 正确且 H36 首选五记录中另一条的首行样本，按原生未舍入质量和全词表 top-1 重放，家族为独立单位。同一表保留未交换、只换标签、只换首尾、两者均换四格，及对应姓名、印刷标签题。发现时同时保留同批 H36 首选正确的首行题、行为错误和不合格控制格的计数。主留出门在全部冻结首行样本上计算，另预注册报告“模型答对但 H36 选错”切面。因果代表由家族哈希在每个平衡条件中预抽，保留无条件总体和原始前向定义的切面；禁止按干预后答案再筛样本。附加等长锚点替换和整体平移从独立校准开始，以区分相对首行、固定符号和绝对 token 位置；只报告过行为门的预注册范围并公开未通过格。

计划 32 新校准家族、192 新确认家族、192 干预家族。保留同族的 12 格，家族互斥，同时隔离既往姓名和未暴露题目。锁定旧句式复现和预先隔离的一种新指令表达，分别报告。正式数量和阈值在预检前根据家族配对功效核算固定，报告有效家族数、条件格和资源峰值。使用当前 Qwen3-14B BF16 快照，40 块、40 查询头、8 KV 组、中间层宽 17,408。runner 逐层在 CUDA 执行，单模型串行。D 盘实查、预留 ≥20 GiB，采集批量和读出边界先做字节预算。长批次每 ≤5 分钟刷新进度、耗时、ETA 和专用/共享显存。

## 原生计算和留出门

1. **发现候选。** 从最终输入 token 扫过第 0–39 块的所有 1,600 个查询头。记录五个记录跨度和各代码 token 的注意力质量，以及表外质量。用原 `o_proj` 对每个头在各记录上的值贡献分解，核对五记录加表外可以重建单头原始 V/O 写入，随后核对全部头的合成与真实注意力输出。先按家族配对的首行换位-写入联合效应排名，再用发现集内部家族分组检查选择稳定性。保留 H36、同层同预算随机头和没有首行选择性的头作对照。按原张量边界保存残差流、Q/K/V 投影前坐标、O 切片、MLP 的 gate/up/乘积和 down、规范化权重。候选头最多三个，跨层连接须满足真实先后顺序，B26 同块 MLP 位于注意力后。
2. **选源与写入。** 令 $a_{h,t}$ 是候选头从末位置读来源 token $t$ 的权重。记录 $r$ 的质量 $m_{h,r}=\sum_{t\in r}a_{h,t}$，写入 $w_{h,r}=O_h\sum_{t\in r}a_{h,t}v_{h,t}$。候选发现分别选 Q、K、V 的原生输入列，最多各用 512 列；预算阶梯 32、128、512。所有未选列用发现集基线补全，保留原矩阵、RMS、RoPE、softmax、GQA 分组。区分单支条件复算和 Q/K/V 联合预测。联合路径从投影前状态、位置和预注册记录跨度出发，真实注意力、V/O 写入、MLP 输出和答案仅作目标。留出同时评五记录 top-1、记录质量误差、首行换位方向、各记录写入与整头写入全维误差。比较均值填补、同预算随机列、只用位置格式及 H36；纯位置基线不能读入正确记录 ID。入门建议是五记录一致 ≥90%，对随机及均值的中心化记录误差和 O 写入误差各下降 ≥20%，按家族配对区间的校正下界为正。冻结时另列有效 RMS/SDPA 复算容差及近零写入的处理。
3. **MLP。** 在注意力后的残差 $x$ 上，逐个原生神经元计算 $u_j=\mathrm{SiLU}((W_g z)_j)(W_u z)_j$，其中 $z=\mathrm{RMS}(x)$，写入为 $W_d[:,j]u_j$。登记单元和活跃条件、残差坐标、标量权重绝对索引与 BF16 值，逐位核对。候选最多 128 个原生单元。B26 同块复算可固定其他头并报告为条件预测。跨块模型必须冻结明确的中间模块读入或预测接口；中间实测输入一经使用即注明边界。留出检验 MLP 坐标/激活和写入误差、首行换位造成的同向变化，增加对全部 12 格的连续答案 logit margin 预测。对照同预算随机单元、观察探针及按幅度选单元。主要门与多重比较按事前固定阈值。规则和答案身份的线性读出单列，即使读出无误也不能代替写入预测。
4. **因果。** 只有候选头、写入和相应下游指标都通过冻结门，才开剂量校准。分别对 B26/H36、候选其他头的 O 输入贡献及接收 MLP 的 gate×up 支持设置阻断；含单点、候选头+H36 的 2×2 和候选头→MLP 的同输入恢复。随机对照与目标同层同边界同原生预算，干预局部表示的实际 L2 在 ±10% 内比例 ≥95%。共享 K/V 编辑在目标头接口克隆隔离，验证同 KV 组其他头无变化；若选择同时处理多个头，按联动操作另报。设 sham 与恢复原值检查，记录剂量、中间路径、首行答案 margin 以及姓名和标签副作用。主要因果指标是目标阻断比匹配随机导致更大的首行 margin 损失及恢复后的差值，家族置信界须通过冻结规则。若恢复仅在头生效而未恢复 MLP 或答案，只登记对应头级证据。单坐标、单神经元、单参数的因果主张分别要求隔离该元素的正式干预及合理控制；群体阻断只支持群体级作用。

## 数学判断

QK 选源、V/O 加权写入和 SiLU 门控已有明确的代数表达。这个任务需要的是在精度和预算限制下找出能跨家族复用的简化路径，用因果模型和匹配干预测试其反事实。不能从有限坐标的失败推出数学无法表达该机制。更广泛的语言理论可以在现有数学中定义新的可组合对象；判据是对留出样本的预测和干预解释优于已有抽象，并说明适用范围。形式背景可参照 [Transformer 原论文](https://papers.neurips.cc/paper/7181-attention-is-all-you-need.pdf) 和 [Causal Abstraction: A Theoretical Foundation for Mechanistic Interpretability](https://www.jmlr.org/papers/volume26/23-0058/23-0058.pdf)。
