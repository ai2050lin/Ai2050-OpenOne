# B26H36 行号与名字选择的原生干预

使用本地 Qwen3-14B BF16，CPU 读取权重、CUDA 分层计算。新发现64家族和确认128家族，名字与上一轮和彼此隔离。每族交叉两个实体的独立正文行序、所查询名字和档案，均为条件后置，共16格。自然运行用全部格。每家族固定一格进入干预，按家族号循环分配16格。家族是推断单位。先冻结材料、算法、功效和执行代码。发现的索引、匹配组及筛选统计另行封存，封存通过后才读取确认。

自然运行需每格严格四候选及全词表首选均达95%。B26H36重新计算的单头输出与原生 SDPA 输入 O 前的结果绝对误差不超过0.065419，复用上轮冻结的数值界。Q/K 局部用原始投影、RMSNorm、RoPE 和 GQA。不使用任何供体状态。发现分析只用自然运行。

同一族内，通过平衡主效应分开两个行号、查询名字、档案。取 h18 查询名末 token，选32行号坐标和32名字坐标。Q 使用 B26 最终位置归一化输入，按所选行、档案、名字的主效应筛选原生列，并乘 H36 原 Q 权重列平方和。K 使用正文代码 token 的归一化输入，分别计算正文实体身份和物理行的族内效应，选择 K 共享头7的原生列。上述候选按目标能量减竞争因子能量排序，保留目标和竞争效应。身份信号以族内区别衡量，名字在各族没有固定语义。干预并不假设坐标纯净，确认自然数据重新量化交叉负载。

干预只执行冻结的16格循环代表题。h18 查询名末 token 原坐标归零，分别试行号与身份。B26 最终位置只删除 H36 Q 指定权重列与当前输入的乘积。正文记录 token 位置只删除 GQA 组7 K 指定列的乘积。K 另做位置冲突：交换两条记录对应 token 的 RoPE 相位，保留原内容 K、原物理记录上的 V 和下游输入。对照在未查询档案做同一操作。若主要依赖所交换的物理相位，正确记录的相对优势预计下降，可能转向同档案另一行。若主要比较保持不变的正文名字内容，预计保留正确记录优势；位置本身仍影响内容匹配，故结果只直接识别此相位干预。若行号在其他原生通道编码，位置冲突不覆盖它。

V 检查在 O 写入之前去掉 H36 对正确记录的注意力加权 V，另去掉同档案竞争记录。两者按写入 O 后的 L2 较小剂量缩放，并记录绝对剂量；这是同一次输入里真实计算项的删除。路由因子的参数阻断是位置耦合的投影项消融，未全局修改权重。GQA K 的效应范围包括共用投影的5个 Q 头。恢复臂执行阻断然后用同一输入的原缓冲区/原参数恢复，核验与基线的逐题读数一致。恢复是局部可逆与正对照。

每组32候选的匹配列从其余坐标中按发现激活 RMS 或投影乘积 RMS 最近邻、固定种子顺序匹配。确认逐题记录实际修改的范数。整体剂量比须在0.67–1.50，超界保留结果但不用于选择性判断。两项预注册主要统计为代表题上 h18 行号组与其匹配组、K 身份组与其匹配组的 H36 四记录命中率差。二值配对功效预期15个百分点、discordance=.25、alpha=.025、n=128。报告97.5%家族 bootstrap区间，阈值效应方向至少10点且区间下界>0。其余 Q、K 行位置、RoPE、V、logit、配对路由间隔和身份对照均作机制诊断。所有环境与匹配门分开记账。

若行号阻断选择性降低路由而身份阻断及其确认剂量无法解释该影响，才支持这条路径依赖该组行号坐标。若身份 K 阻断选择性降低路由，并且相位冲突较弱，才支持正文内容比较。若读出存在但阻断无效、两个对象交叉负载、与匹配同幅、或两条路线都有影响，保留混合或未识别解释。诊断涉及一个残差位置和一个晚层头，不能决出全模型首次选择、分布式行号或缓存。保留逐题数据、索引、实际原参数和局部观测。磁盘新增预算512MiB，保留20GiB；GPU预算40分钟。
