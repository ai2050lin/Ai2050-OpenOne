# B26/H36 三线索来源冲突预注册

模型为本地 Qwen3-14B 原始 BF16，冻结模型与分词器快照。读出为 B26/H36 最后输入 token 的注意力，KV 组7。主动表含五条原创记录，记录的 NAME 和 CODE 在同一家族全部条件里绑定。身份线索固定指向一个中间记录。标签交换只在另外两个中间记录间发生，先登记查询的印刷 ROW，再在两记录间交换该标签。物理位置交换只把首、末两条记录及其原标签整体交换，询问首或末位置在家族间平衡。两种交换构成 2×2，和最后问 NAME、印刷 ROW、物理位置三条件完全交叉，共12格。每条输入三种线索都指向三个不同记录。五个代码固定为不同的单 token 词。所有问题共享提示前缀，每组长度严格匹配。新家族与既往表格题的名字隔离。至少保存每个家族完整的内容、token、记录跨度、三个索引及输出评分。

预先分别冻结校准32、发现64、确认128和因果128家族。各自然阶段严格五候选及全词表top1均须总体≥95%、每格≥90%，技术须规则前状态逐位一致、原生QKV重算对实际SDPA上下文最大绝对差≤0.065419。失败阶段不晋级。另算逐规则错误落在另两条线索或其它记录的比例。限制结论于固定的表格提示，以及首／末位置；查询有效键也会在末尾重新出现。

自然路由保存每条记录的质量和原生四十头中的H36上下文。以同正文三问中 `s=log(m_gold)-mean(log(m_other_two))` 为主要配对偏好，逐规则报告其家族97.5%区间。报告三候选与全五记录argmax、3×5落点混淆、两交换及交互、固定按姓名或标签或位置的基线。只有三规则各全五记录命中至少75%且偏好区间下界大于0，才登记H36在协议范围内普遍跟随三种规则。结论区分相对候选偏好与五记录首位。操作前末位置的固定32维岭分类规则只登记为可读出。

将发现集操作前z的方差与原投影各输入列平方范数相乘，分别冻结 Q 和 K 的 32、128、512 原生坐标。Q用最终位置，K用有效前缀全位置。省略坐标固定为发现均值，以原权重计算投影，原Q/K RMSNorm、RoPE和因果掩码继续参与。比较同预算种子固定随机与均值。分别缩减Q、K并保留另一支真实操作前投影，同时报告联合缩减。V保持原生。以全部五记录自然argmax一致率、三线索中心化log质量MSE、原5120维O写入MSE比较。512是唯一准入预算。Q/K各自须五记录吻合≥90%，中心化MSE相对随机及均值各改善≥20%，配对家族97.5%区间下界大于0。其余预算、写入误差和联合结果独立报告。配对二值功效采用预期15点、p_d=.25、alpha=.025和128家族，连续差按实际区间。

各支只有达到确认门才进入原模型干预。新独立家族各一冻结代表题，先用校准家族复核技术。目标对H36最终Q，或对三候选记录token的组7 K，扣除50%冻结坐标乘积项。使用单头原生SDPA重算，仅替换H36的O入口，其他头保留原样。随机对照逐题匹配 RMSNorm 与 RoPE 之后实际变化的L2（K为三个跨度的联合Frobenius范数），比值0.90–1.10且至少95%满足；另记输出处变化。Sham与实施编辑后恢复同输入原头上下文须在头和全词表logits逐位一致。主要因果差为匹配随机减目标的金记录相对另两候选的中心化log质量，配对家族97.5%区间下界须>0。答案分差单列，单参数效应不由坐标组干预推出。若校准失败，仅关闭受影响分支。
