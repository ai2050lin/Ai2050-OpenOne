# CLT 自然发现与确认扩展（2026-11-17，发现采集前）

继承 conditional_lookup_prereg.md，不修改旧冻结文件。执行代码的 SHA256 绑定在 natural-plan.json；本扩展只增加自然观察、信息诊断和局部参数近似，不运行差分搬运或原模型干预。

## 样本和自然观测

64 个发现家族、128 个确认家族，每族 16 格。行号读出只取条件后置且 b=0 的四个实体前缀，避免把未来条件不同但前缀相同的两份状态当成独立样本。统计重采样单位是家族。实体位置采全部 41 个残差边界；B20–22 采真实 G、U、A 和归一化输入 z。注意力采 B20–30，保留六个互斥来源：四条正文记录、查询名字末 token、其他位置。B20–22 同时采名字和最终位置，B23–30 采最终位置。

## 冻结的分析规则

1. 原生读出池 h01–h40 与 A20–A22；每池比较 1 与 32 坐标。用与两个行号平方相关之和选索引。五折按家族编号循环分组，每折仅用训练家族选坐标及标准化；ridge 的 alpha 从 .01/.1/1/10/100 选 OOF 联合准确率最高者。跨池也以联合准确率选，平局优先小预算、较早列表位置。发现指标用于筛选，有选择乐观偏差，确认才是独立检验。
2. 在胜出池内固定种子 101/202/303 的同预算随机坐标，另用 token 长度、名字位置、名字字符数、标题顺序与四槽代码身份作 nuisance 特征（最多32列，种子404）。嵌入层另报免费基线。确认必须胜过每一个冻结基线，不能挑弱基线。
3. 答案缓存诊断：在胜出读出坐标上，固定 alpha=1 拟合两个档案的代码类别。只作为额外诊断；失败不能排除非线性、多位置或其他坐标的缓存。
4. 原生参数局部近似：在三个 A 池中冻结最好的32单元读出，导出其原始 gate/up 权重行、down 权重列。用发现输入方差乘 gate/up 权重平方和选共同32个 z 坐标；其余输入固定为发现均值。原参数计算 G、U 和 SiLU(G)U，不再拟合权重。比较发现均值 A 及固定种子900偏移的随机32输入，冻结后在确认测 MSE。该近似仍接入该层真实 z，不是从文本开始的闭合机制。G/U/A 原生数值复算单列技术证据。
5. 自然选择来源：对所有 B20–30 头计算最终位置对四条记录的实际注意力质量，冻结发现阶段后置准确率最高的头（平局较早块、较小头号）。比较 argmax 与目标记录，同时报告前置、两种 b 都正确、正文与查询名字质量。这里读取的是实际注意力，不能冒充“操作前预测选择”的验收。
6. OV 写入按原参数分解，再投影到四代码的原始 unembedding；报告正确代码相对其余三代码均值的来源贡献。未经过最终 RMSNorm 和下游层，是局部代数记账，不是最终 logit 归因，不说明某来源必要。

两位信息读出的门槛继承原预注册：每位90%、联合85%、胜所有冻结基线至少10点，家族 bootstrap 10000次、97.5%区间下界大于0。局部参数近似 MSE 需比均值和随机均低20%、配对区间下界大于0；它只验收局部近似，不独自满足原始选择机制的共同终点。

候选模型、参数索引、头索引、发现结果与分析代码哈希写 candidate.json 后才允许读取确认材料。即使发现候选未过门，也可冻结为负结果复现；确认不再选层、改阈值或改特征。若没有满足“操作前紧凑选择预测”的候选，本轮明确报告尚无选择机制，不能用注意力统计替代它，不开展扩大因果实验。

## 技术门与保存

使用旧 pilot 首家族16输入校准 FP32 注意力来源重算与实际 BF16 SDPA 头输出的误差，容差为 max(1e-4, 两倍试跑最大误差)，在发现前落盘。正式各分片超过容差或后置前缀实体状态不逐位相等即停科学判定。全部16格行为须各达95%。额外磁盘预算3GiB，逐分片预留0.5GiB且保持D盘20GiB空闲，保留无损BF16证据与最小原参数切片。确认不作未见表型组合声明，只检验新名字家族。
