# Qwen3-14B：跨分支复用与层间组合

目标是检验同一原生单元或单元组是否跨语义分支复用共同结构，以及这些响应能否通过层间组合预测后续计算。固定快照上的层间递推不等于训练时的分支形成，也不等于同一算法的多步递归执行。

当前结果目录为 `tests/glm5/result/branch_reuse14_20261113_v3/`，阅读入口为 `report.html`。完整结论以 `conclusion.json`、冻结协议、实际逐项结果和审计为准；不能仅凭脚本退出码认定机制通过。

本轮已完成全部获准的两分支计算。预选B19组7/8、B39根6/8单元复现共同A响应；同一B36权重组的0倍/2倍操作对数值和标签的答案间隔产生同向损伤/提升，相对匹配组也有差异。这些结果支持范围内的共同响应和组输出作用，尚未识别共同抽象语义。两条稀疏链自由递推16格、反事实效应预测16格均未过冻结门；后者所有格均达到实测效应下限。条件化输出KL的8格收益不能代替这一失败。材料未直接改变组合深度，因此更复杂特征如何形成仍待检验。

`feature-cards.json`保存17张原生单元卡，`native-group-effect-card.json`保存B36组作用、匹配控制、反例和边界。后者的逐单元作用、通过B39根的中介关系以及广泛副作用均未确认。

## 材料与边界

- 本机 Qwen3-14B 原始 BF16，快照 `1e970d119494affd09689ec3dd25aa30587dfcbb16d873b40fb917016fe2a2ce`；CPU 读取原 safetensors，CUDA 逐块运行，batch=4，固定 padding 长度256。
- v3 共1,536条、384家族：试跑192条，发现384条，确认960条。家族内交叉通用规则/有限记录与技术/普通标题。数值和坐标发现材料用于拟合；标签分支不参与拟合。
- 确认使用新表达及词池；数值可能重叠。每确认分支80家族。角色差异仍混合共同措辞与任务格式，有限记录也表达关系，不能称为概念完全缺席。
- 序列分支在v2扩大试跑及选项轮换后不合格。v3坐标分支的确认行为门失败，全部原始材料保留，停止该分支的内部确认与干预。
- 剩余数值和标签为640条、160家族。`qualified-execution.json`在内部分析前冻结这一部分执行；所有拟合、索引、阈值、每分支样本数与原六项校正保持不变。原三个分支的联合门永远不能用剩余子集补过。

## 执行顺序

在项目根目录使用 `.venv/Scripts/python.exe -B -X utf8 -u`。所有写入先通过 `deploy/storage_policy.json`，临时文件和模型缓存均在任务专属D盘目录。CUDA进程持有GPU租约，不并行加载其他模型。

1. `branch_reuse14_materials.py`生成材料；`branch_reuse14_collect.py freeze`冻结身份与试跑协议；`collect --split pilot/discovery/confirm`依顺序采集。已有完整采集不可覆盖。
2. `branch_reuse14_analysis.py plan/select`在确认前冻结方法、组、两条预测链及96个拟合文件。`branch_reuse14_execution.py`保存下游源码和数值工程测试绑定。
3. 原全分支流水线已在坐标行为失败处停止，保留失败日志。当前后续入口是 `branch_reuse14_qualified.py pipeline`，不要直接运行原三分支分析或干预入口。它依次进行合格分支的分析、输出预测、B19干预、B36干预、汇总及对照。
4. `branch_reuse14_group_cards.py`生成预选组的次级响应描述与特征卡；不修改原主门。`branch_reuse14_fieldmaps.py`只使用发现集绘制未排序全坐标图。
5. `branch_reuse14_audit.py native`逐项核对全部984个原生NPZ、形状、有限值、分词及模型文件哈希。所有干预完成后执行 `audit.py final`，验证文件自全量审计以来未改变、逐臂重放、数值无操作及失败批次恢复一致性。
6. `branch_reuse14_report.py`生成离线报告；`branch_reuse14_browser.cjs`检查桌面、手机、图像、因果正文与后续问题分离，以及本地证据链接。浏览器回执通过后登记，再归档源码、按归属清理、追加研究备忘录及生成交付哈希清单。

## 数据格式

每个 `split/chunk-NNNNN/` 保存40份 `B0.npz` 至 `B39.npz`，含 `G/V/A`，形状 `[n,2,17408]`。`states.npz`保存 `hidden[n,41,2,5120]`、最终归一化后的 `final_hidden[n,2,5120]`、正文前缀平均embedding，以及两个历史候选的每token G/V/A。BF16用uint16位模式无损保存，通过 `branch_reuse14.unbits`解码。

两个读出位置分别是问题与选项出现前的正文末位，以及作答提示末位。`hidden[:,40]`是原始最后块输出，`final_hidden`已归一化，不能再次混同。完整坐标只覆盖这些声明位置，不是保存了所有token的全部单元场。

`chunk.json`和`collection.json`绑定行ID、文件SHA、分数及冻结协议；`native-manifest.json`记录原始字段保留目的与复查日期。完整模型重跑不是图谱机制提取成功。

## 校准和工程恢复

v1/v2的材料、试跑、探针诊断和源码分别保留在相邻目录及源码ZIP。当前脚本的公共路径已指向v3，复算旧版必须从对应归档恢复，不能直接把当前脚本当作旧版本运行。

冻结采集器原先用argmax计分，会把部分正确选项排在首位的同分算作正确。独立严格门要求正确分数严格大于其余分数；不修改原分数或阈值。试跑严格191/192，发现376/384，完整确认928/960，但坐标条件格未过门。第一次暂停登记器因工具进程不可跨调用枚举而未执行任何进程操作；之后仅暂时保管执行回执。原流水线先在行为门自行停止，暂停等待器因预期另一种异常而超时；核对确实未进入分析后原样恢复回执。全部恢复记录保留。

合格分支首个B19干预块在Windows路径分隔符的结果登记处失败，原生数组已保存。`qualification-runtime-recovery.json`只允许适配器规范化保存路径并登记对应源码变化；所有原始科学源码、拟合和干预计算均未改变。原失败数组与重放数组逐字节一致。未登记的块不得直接认定完成。

## 验收含义

历史B19/U64的V/A主检验、预选组共同响应、自由递推G/V/A误差、完整词表KL、原模型行为扰动及反事实效应预测分别报告。预测从真实B36晚层状态开始，不能称为文本到输出的完整图谱。真实B39根输入只是测量到的读出上限参照，并不保证拟合读出器在域外表现最好。

B19干预覆盖正文位置；B36干预仅作答末位。每合格分支40家族，两个位置实验共用同一批家族；10臂结果不能扩增独立样本量。1倍臂是数值无操作，不是独立救援。随机方向必须检查实际BF16写入范数；资格不足时不得宣称控制合格。

保留所有未通过项、被排除分支、反例和替代解释。不从单元组共同响应直接推断共享语义，不从输出受扰动直接推断必要性，更不从一条稀疏链失败推断全模型不存在跨分支复用。
