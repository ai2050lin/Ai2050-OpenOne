# B26/H36 操作前紧凑预测预注册

固定本地 Qwen3-14B 原始 BF16、Qwen 聊天模板、关闭 thinking、`Answer:\n` 最终位置、B26 查询头36与GQA组7。新材料使用与Phase 2969同构的两个档案、两个实体、四独立代码。交叉两档案各自的行序、实体身份和档案条件共16格，档案条件后置。名字排除原CLT与Phase 2969所有暴露名字。64发现家族与128确认家族，另留128干预家族。公开试跑材料与此次新家族完全不同。确认和干预文件在各自准入前不被运行器读取。首词行为各格严格四候选及完整词表top1均需≥95%。任务金答案只参与评分，结构定位仅用表格四记录跨度、causal mask和位置。

1. 从发现家族原生B26 attention输入归一化张量积累均值和逐坐标方差。Q用最终位置，K/V用全有效前缀（包括非记录位置）；选输入方差乘原权重列平方和最大的固定32、128坐标，分别处理Q/K/V。省略输入以发现全局均值补全。种子固定的同预算随机坐标、以及发现均值路线作对照。两预算事前固定，128是唯一准入判定，32仅报告剂量趋势。无拟合确认集。
2. 用原Q/K/V标量参数重算选定列与截距，保留Q/K RMSNorm、RoPE和GQA。预测对所有可见token的注意力、四记录质量和H36独立O写入（全部5120坐标）。比较自然Q/K/V经softmax重算的头向量与原SDPA向量，以此前冻结绝对门0.065419核对。以真实SDPA头向量和原O切片的点积为局部写入目标。报告同档竞争行对数质量差误差。全头/全输入复算只作技术校准。
3. 显式条件背景为B26输入残差与其他39头写入。将其他头占位张量中H36槽置零后独立执行原O（无H36贡献），加预测H36写入后重算post-attention RMSNorm。冻结32个MLP单元按发现集实际A相对无头背景A变化的均方排序，使用原gate/up行预测其G/U/A。原下游G/U/A只作目标和发现阶段单元筛选。FP32加法的结果按原模型顺序舍入BF16。报告用完整原头写入代替稀疏预测的分流数值误差，单列零头背景对照。该模型有真实上游背景且不预测完整模型logits；32单元完整gate/up矩阵、down列与背景均计入成本，不能视作从文本闭合。首词行为为原模型行为门。发现集保存B26最终与实体位置全坐标、全部MLP单元的头写入敏感性；确认以冻结32单元、全5120写入坐标及必要原生切片为主。
4. 128坐标选择预测对实测四记录argmax命中≥90%，且胜每个同预算随机及均值基线≥10个百分点、家族配对97.5%区间下界大于0。写入MSE相对每个同预算基线至少改善20%，且家族配对差97.5%区间下界大于0。下游A的MSE也须相对同预算随机、均值和零头背景各改善20%，且配对区间下界大于0。所有指标在同一材料上评估，按家族bootstrap，三条门均满足才进入因果。G/U、单格失效和替代解释另外报告。二值代表题参考效应15点、p_d=.25、alpha=.025、128家族，由工具核算。连续量以效应和区间作实测判定，不沿用二值功效。
5. 干预仅在联合预测门通过后另冻结索引、主指标和剂量。独立新家族检验H36最终位置的选定Q项，比较等实际剂量的随机原生分量、sham、自身恢复，记录Q/K间隔、O写入、冻结MLP单元及答案边际。候选必须先在独立校准材料预报效应并验证剂量与无操作对照。若预测未过门，本轮无因果测试。Phase 2969的干预关系不计本轮晋级证据。

预算：模型CPU按层读取，CUDA使用项目互斥锁，逐分片写出，分层进度含时间、ETA和共享显存。新输出峰值≤700MiB，D盘留20GiB，45 GPU分钟。实验用自行生成的文字材料。依据本协议保留原生BF16参数和冻结索引、发现聚合与确认逐题对照、行为、日志与哈希。只清理本轮无引用临时物。选择状态、运算预测、因果关系独立登记。
