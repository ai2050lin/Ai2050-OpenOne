# Qwen3-14B 分支验证与末层回溯

本轮测试固定 Qwen3-14B BF16 快照，只直接检验此前六个案例中属于14B的 B26/U13099 和 B19/U64。另四个4B候选不按编号迁移。最终快照的响应规律不能证明训练时的递归分支形成。

结果根目录：`tests/glm5/result/recursive_branch14_20261113_v6/`。先读 `report.html`；身份与门槛以 `plan.json`、`model-identity.json`、`selection.json` 和各采集目录的 `collection.json` 为准。脚本内编号均为零基。

## 执行与恢复

在项目根目录使用 `.venv/Scripts/python.exe -B -X utf8 -u`。所有新增数据、临时目录和缓存均在D盘，使用 `deploy/storage_policy.json`；真实模型任务持有 `GpuLease`，不并行加载其他模型。

1. `recursive_branch14_materials.py` 生成修订材料；`recursive_branch14.py freeze` 核对快照并冻结。已经存在的冻结文件不能覆盖。
2. `recursive_branch14_pipeline.py` 串行执行384条发现集试跑、1,536条发现集采集、组选择冻结、三份各1,536条留出采集、响应分析及两项干预。
3. `recursive_branch14_audit.py` 复读原生数组，校验形状、有限值、重复采集、重放缓存、哈希及干预检查。
4. `recursive_branch14_fieldmap.py` 仅使用发现集生成全部40层、17,408坐标的G/V/A原始与标准化观察图，不更改候选或冻结规则。
5. `recursive_branch14_controls.py` 汇总家族配对的匹配组和条件差异；`recursive_branch14_cards.py` 生成特征卡。`recursive_branch14_position_diagnostic.py` 是冻结主检验完成后的探索性位置诊断，不参与重新选点或判定。
6. `recursive_branch14_report.py` 构建图表与离线报告；`recursive_branch14_browser.cjs` 检查离线页面。浏览器结果写入临时目录，退出码为0且checks.passed为true后，再经`R.save`登记browser-check.json。
7. `recursive_branch14_closeout.py archive` 保存当前源码；`clean-final` 在审计和浏览器通过、源码归档核对后，清理本轮独占缓存以及与最终JSON逐条一致的流式副本。`recursive_branch14_memo.py` 仅向两份研究记录尾部追加；`closeout.py manifest`生成最终交付哈希清单。依赖关系按此顺序执行。

流水线跳过已经完成的阶段；部分干预产物存在时拒绝覆盖。失败后先保存日志、已完成产物和原身份，再审查错误是否影响数值、材料或统计假设。不能开封后调整阈值再称独立确认。

## 测量与检验

6,144条材料来自1,024个家族，每家族有三种表达×两种标题。留出为新词、新词加新句式、新词加新领域背景；每候选每划分128家族。新领域只是受控背景替换，不代表完整自然领域。家族变体配对分析，不算独立样本。

正文结束读出位于问题与选项之前；第二读出在答案提示结束。保存hs[0]及40层完整残差状态，40块的全部原生G/V/A，并保存两个候选的每token响应。BF16以uint16位模式保存，使用 `recursive_branch14.unbits` 解码。`prefix-embedding.npy` 是前缀平均输入embedding基线。

候选计算：G=gᵀz，V=uᵀz，A=SiLU(G)V，写入=A·d。响应主检验为两种关系表达均值减清单条件，预期G正向；家族配对效应dz≥0.35、六项校正p<0.05/6，两种表达各自差值为正，关系元数据加词汇模型的G误差至少比词汇模型低10%，三类留出都须通过。语义元数据是实验者已知材料信息，不是自动解析器。

末层试验从B39选8根单元，向B38、B37、B36各选32父单元。比较父层A预测子层G/V/A、同数量随机父单元、词汇基线。自由递推仅从真实B36 A开始，其余使用预测值；它不是输入文本到完整输出分布的图谱保真度。

干预每候选包含192个目标家族和48个另一任务家族，保留六个版本，十个操作臂。对正文位置实际A做单元/8单元组0倍和2倍，加入恢复、同层匹配组及实现后BF16写入范数控制。四项主检验使用家族聚合答案间隔；显著扰动不能独自证明关系选择性。随机方向控制必须逐token达到2%范数容差，其余结果保留并标记。

`restore`臂是A按1倍直接重新计算的数值无操作检查，并非先损伤再独立救援。严格范数匹配子集可能有选择偏差；对照没有合格行时不报告选择性。全词表KL是干预导致的原模型输出变化，不是图谱预测保真度。

## 失败与限制

v5的“引用但未生效”及部分排序表述未过行为门。诊断只使用发现集，v6收窄为指令式/参考描述的关系理解并保持家族划分。旧失败保留在相邻v5目录，不计入新确认。

本轮没有训练检查点、自然生成、同预算SAE/transcoder、独立节点复算，也未覆盖广泛副作用任务。词池、句式与领域数量有限；同家族配对无法消除所有重复词/模板依赖。原始场、关联、预测和干预分别记账，未通过的解释或递推链不能晋级为机制图谱。

两个候选均未通过三类留出的冻结正向G联合门；两组末层回溯链也未通过所有留出与随机父组比较。六项G预测都不如前缀平均embedding。可读报告保留实际干预结果、负结果和反例。正式原生场登记用于后续分析及复核，复查日期2026-12-13；native-manifest.json列出精确范围和哈希。
