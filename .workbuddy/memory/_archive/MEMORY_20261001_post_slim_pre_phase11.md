## 1 装置铁律（跨轮，违反即返工）
- (a) 份额判据必须用**精确可加量（向量预算）**，效应份额不可加。(b) SMOKE 必做且必看数字。(c) 门裕度必须写进报告。(d) 预注册与修正案都要落盘并记 sha8。
- (e) 行为端与层内端必须同时测（`amp`），否则无法区分层内阈值与下游读出阈值。(f)「充分」用放大剂量臂、「必要」用撤除对偶臂，必须分开测。(g) 曲线类判据必须**参数化**（x\*、陡度、饱和值），禁止二值"是否阶跃"。(h) 冒烟产物必须落 `smoke/` 子目录。(i) SMOKE 截断 α 网格必须保留定义点 α=1。
- (j) 跨位点比较必须分**绝对/相对双剂量坐标**，半饱和点换算 `x*·r_ℓ` 才能比。(k) 判据符号必须与物理方向一致（越浅⇒层越多⇒非线性越强）。(l) 位点 `r_ℓ` 可差 3–17 倍，任何"打不动"先自检是方向旋转（自基臂）还是真衰减。(m) 以"读数端/度量端"解释机制必做**读数位点探针**。(n) 深部位点固定基探针必须同时报 `overlap(U_ℓ, U_ref)`。(o) **同一消息内多条 Edit 会静默丢失**（Phase 10 实测 6 丢 4）⇒ 关键修改一律 **Python 补丁脚本逐处 `assert count==1` + 回读复核**。
- (N3) patch 必剔末层；写入窗用相邻最大增量定位；判据用归一化跳变 `jump/max|effect| ≥ 0.5`（绝对阈值不可跨族）；排除实例 token 须同时剔类别 token（`白纸`→`白` 撞车使 base 变 −1.7e8）。
- (统计) cos 与 relative-L2 双报；门先验证可达域；秩相关用平均秩；paired 门 `margin=err_cand−err_B4`（**负=候选优**），pass 当 `m ≤ −2×MDE`；numpy2 batch solve 需 `[..., None]` 尾维；one-hot+截距共线 → λ≥1e-3。

## 5 本机环境缺陷（Windows）
- bash shim 劣化：rm/ls/grep/cat 坏 → python 文件化；`-c` stdout 丢 → 写文件再 Read；反引号/反斜杠被吃 → `chr(96)` / 避免内联 `python -c`。
- **`python script.py > log` 在 shim 下产 UTF-16 且路径二次转换**（`/d/...` → `d:\d\...`）⇒ 用 **`run_<phase>.py` 包装器**（`runpy` + Tee）自写 UTF-8 日志；调用脚本用 `cd <root> && python tests/...` 相对形式。PowerShell `*>` 同样产 UTF-16、stdout 捕获不稳。
- **Edit 幻影**（同消息多 Edit 静默丢失）+ **IME 吞字**（中文 old_string 少一个汉字）+ **Read 行号空行 off-by-one** ⇒ 大段中文改动拆小步或走 Python 补丁脚本。
- 关键写入后 Grep 复核真实磁盘；GPU 逐模型防 OOM。项目 Python：`D:\AI2050\Ai2050-OpenOne\.venv\Scripts\python.exe`。
