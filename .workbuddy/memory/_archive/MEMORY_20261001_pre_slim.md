## 统计纪律（3102 五原则 + 3151 教训）
- cos 与 relative-L2 双报；门先验证可达域；秩相关平均秩；JVP 准≠映射混；次模=条件二阶差分。
- paired 门 margin=err_cand−err_B4，**负=候选优**，pass 当 m≤−2×MDE。
- numpy2：batch solve 需 [..., None] 尾维；one-hot+截距共线 → λ≥1e-3。
