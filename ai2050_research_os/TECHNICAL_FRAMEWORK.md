# AI2050 技术方案框架与研究主线

## 0. 文件定位

本文件专门保存 AI2050 语言计算机制研究的**技术方案框架、科学主线、实验层级和实现边界**。

二次开发者和 AI 必须先完整读取 [README.md](README.md)，再读取本文件：

- `README.md` 定义系统治理、JSON 事实源、数据纪律、客户端和研发中心总体架构；
- 本文件定义“接下来研究什么、怎样测量、怎样建模、何时停止、什么结果才算规律”；
- 动态研究状态、当前 Phase、运行结果和裁决保存在 `registry/`、合同、Run Bundle 和 Canonical Snapshot 中，不写死在本文件；
- 本文件不得被当作实验结果或正证据；其中的数学表达是待检验的测量合同，不是已被证明的语言理论；
- 技术主线发生变化时必须更新本文件，同时检查 `README.md` 是否需要同步更新。

## 一、总体判断

“从静态局部闭合转向语言计算系统辨识”的方案**总体可行，而且是当前比继续扫描单层、单方向、单神经元更合理的主线**。

它正确抓住了历史结果反复暴露的共同边界：

1. 局部响应和短程因果作用广泛存在；
2. 固定坐标、单一方向和单个算子很少跨条件守恒；
3. 首 Token 修复不等于多 Token 生成机制；
4. 最终读出接口可以被精确操纵，但不能反推上游语言算法；
5. 语言计算更像条件化、分布式、跨层和跨 Token 的动态响应系统，而不是静态代码表。

过去 Phase 的主要价值不是已经找到统一机制，而是形成了三类重要资产：

- 已确认的局部经验规律；
- 可复用的行为、观测、干预和审计仪器；
- 新理论必须解释的失败边界和反例。

因此，应该停止的是以下研究循环：

```text
猜测一个低维结构
→ 扫描最优层/方向/单元
→ 在同一材料上做补丁
→ 要求一次性闭合
→ 失败后更换数学比喻
```

不应该停止的是：

- 行为资格；
- 严格 Discovery/Selection/Confirmation 分离；
- 自然输入反事实；
- 组件因果干预；
- Destroy/Restore、Wrong Rescue 和 Matched Null；
- 多 Token 时间分析；
- 跨任务、跨模型和失效边界验证。

### 1.1 方案必须改进的核心点

原方案需要九项收敛，否则容易形成一个更昂贵的新循环：

1. **不能一次采集所有数据**：采用多分辨率采集，避免全层×全 Token×全模块×全干预×全生成步的数据爆炸；
2. **自然反事实与内部干预必须分账**：前者定义外部响应，后者验证内部因果，不能混成一个 Response；
3. **高容量临摹器只能提供可预测性上界**：不能把第二个黑箱称为机制；
4. **可解释临摹器必须通过独立留出竞争**：不能先看 Confirmation 再选择状态维度、阶段或模型族；
5. **复杂度曲面不能被解释为真实内在维度**：它只是在给定观察量、实验族和模型类下的预测复杂度；
6. **跨模型比较必须使用功能响应而非坐标对齐**：不同模型无需共享神经元或层号；
7. **阶段切换只能由数据提出并在新数据确认**：不得把浅层重组、中层路由、深层决策预写为事实；
8. **必须设置 Campaign 死亡条件**：受限模型长期无法超过基线时，要允许得出“未发现低复杂度规律”；
9. **必须先同步 Research OS 状态**：Registry、Decision、Snapshot 和最新正式记录不一致时，不得启动新 Campaign。

## 二、唯一科学主线

下一阶段的统一主任务固定为：

> **语言计算系统辨识：寻找能够预测模型在语言条件变化和受控干预下，内部事件轨迹及完整输出如何变化的最小经验规律。**

研究问题从：

> “意义存在哪一层、哪个方向、哪个神经元？”

转为：

> “对象、关系、查询、否定、范围、上下文、输出协议或生成前缀变化时，系统之后的响应如何变化；这种变化能否被压缩、预测、组合和因果验证？”

### 2.1 主线不承诺什么

该主线不预先承诺：

- 一定存在低维宏观状态；
- 一定存在跨模型相同坐标；
- 一定存在有限群、流形或统一算子；
- 一定能从 LLM 直接推出大脑编码机制；
- 高预测准确率自动等于机制解释。

即使最后得到“长程响应需要高维、强条件化和模型特异状态”，只要该结论经过系统测量和严格留出，它仍然是有效研究结果。

## 三、基本研究对象

### 3.1 计算事件，而不是单一层切片

使用事件索引 $e$ 表示一个可审计计算位置：

```text
事件 = 模型 + 调用步 + Token角色 + 层 + 模块 + 模块子阶段
```

事件至少区分：

- Prompt Prefill 与增量生成；
- Residual Input/Output；
- Attention Output；
- MLP Gate、Product 和 Down；
- 最终 Norm 与 Unembedding；
- Query、Source、Relation、Candidate、Generated Prefix 等语义角色。

绝对 Token 位置和绝对层号可以保留，但跨模板、语言和模型比较优先使用语义角色、相对深度和事件类型。

### 3.2 两类干预必须分开

#### 外部语义干预

例如：

- 对象替换；
- 属性或关系替换；
- 查询切换；
- 否定、范围和顺序变化；
- 指代变化；
- 输出协议变化；
- 两个操作的组合。

外部语义干预用于定义模型在语言变化下的自然响应。

#### 内部机制干预

例如：

- Ablation；
- Activation Patch；
- Path Patch；
- Destroy/Restore；
- Donor Rescue；
- Wrong-Identity、Matched-Null 和随机控制。

内部干预只在预测模型冻结后用于因果确认。不得在发现阶段反复扫描内部坐标，并用最佳坐标同时宣称发现和确认。

### 3.3 因果响应场

设：

- $c$ 为上下文、任务、查询、语言、模板和输出协议条件；
- $H_e^c$ 为计算事件 $e$ 的系统状态；
- $I$ 为外部或内部干预；
- $Q_r$ 为下游事件 $r$ 的测量量；
- $F_{e\rightarrow r}$ 为从事件 $e$ 到事件 $r$ 的后续计算。

定义差分响应：

$$
\mathcal R_{e\rightarrow r}(c,I;Q)
=
Q_r\!\left(F_{e\rightarrow r}(H_e^c;\operatorname{do}(I))\right)
-
Q_r\!\left(F_{e\rightarrow r}(H_e^c)\right).
$$

必须同时保存基线值、干预值和差值，不能只保存差值。对于尺度差异大的量，可以另行定义冻结的归一化响应，但不得根据最终结果选择归一化方式。

### 3.4 功能响应签名

给定预注册实验族 $\mathcal T$，定义状态的功能响应签名：

$$
\Sigma_{\mathcal T}(H_e^c)
=
\left\{
\mathcal R_{e\rightarrow r}(c,I;Q)
\right\}_{(I,Q,r)\in\mathcal T}.
$$

两个状态的功能近似等价必须相对于实验族、误差容差和适用域定义：

$$
H_e^c\sim_{\mathcal T,\varepsilon} \widetilde H_e^{\tilde c}
\iff
d_{\mathcal T}\!\left(
\Sigma_{\mathcal T}(H_e^c),
\Sigma_{\mathcal T}(\widetilde H_e^{\tilde c})
\right)
\le \varepsilon.
$$

这不是绝对身份，而是“在已声明未来测试中足够相似”。实验族扩大后，等价类允许被拆分。

### 3.5 预测响应状态

寻找压缩状态 $z_e$，使其能够预测一组未来响应：

$$
z_e=E(H_e,c),
$$

$$
z_{e+1}=F_{\rho_e}(z_e,u_e,c)+\eta_e,
$$

$$
\widehat{\mathcal R}_{e:H}=G(z_e,I,c).
$$

其中：

- $E$ 是冻结的状态编码器；
- $u_e$ 是当前输入、查询、路由或生成前缀；
- $\rho_e$ 是候选动力学阶段；
- $H$ 是未来预测跨度；
- $F$ 和 $G$ 必须在未见条件上评价。

阶段 $\rho_e$ 不能人工固定为“浅/中/深”。只能在 Discovery 中提出候选切换规则，再在独立数据中确认。

## 四、复杂度—跨度曲面

系统不再只问“是否存在闭合”，而是测量：

> 在给定实验族、观测量和模型类下，要预测多远的未来，需要多少状态容量？

定义经验曲面：

$$
\mathcal E(k,H,\tau)
=
\min_{M\in\mathcal M_k}
\operatorname{Err}_{\mathrm{holdout}}
\left(
\widehat{\mathcal R}^{M}_{e:e+H},
\mathcal R_{e:e+H}
\mid \tau
\right),
$$

其中：

- $k$ 是预先定义的模型容量等级，不直接等同于真实内在维度；
- $H$ 是层、事件或生成 Token 的预测跨度；
- $\tau$ 是干预类型；
- $\mathcal M_k$ 是冻结的候选模型类；
- 误差必须分别报告模型、任务、条件和失效组，不能只报告总体均值。

### 4.1 正确解释

可能出现：

- 小容量模型可预测长轨迹：存在候选低复杂度宏观规律；
- 短期可预测、长期迅速失效：存在局部规律但长程强耦合；
- 不同操作需要不同模型：存在类型化、条件化机制；
- 分段模型稳定优于全局模型：存在候选阶段结构；
- 高容量模型可预测但受限模型均失败：响应可预测，但尚未找到可解释压缩；
- 高容量模型也无法预测：测量状态不充分、数据有歧义，或系统在当前实验族中不可预测；
- 随容量增长仍无稳定平台：不能宣称存在低维闭合。

### 4.2 禁止解释

不得把一条平滑下降的误差曲线直接称为：

- 语言流形维度；
- 大脑编码维度；
- 唯一宏观状态数；
- 模型真实模块数量。

它首先只是冻结测量合同下的预测复杂度曲面。

## 五、临摹模型竞争

### 5.1 两级临摹器

#### 高容量响应临摹器

用途：

- 测量响应是否可以被当前观测量预测；
- 估计可达到的预测上界；
- 发现结构化残差；
- 判断是否缺少关键条件变量。

它不具备自动机制解释权，不能直接进入理论。

#### 受限临摹器

按照预注册复杂度顺序竞争：

1. 零响应和均值响应；
2. 全局线性；
3. 层/事件局部线性；
4. 条件化双线性；
5. 冻结分段数量的切换动力学；
6. 小型非线性状态空间模型；
7. 有限、可执行的类型化算子模型。

只有比更简单基线稳定改善，并能预测未见条件、失败组和副作用的模型，才获得候选规律资格。

### 5.2 三房数据治理

```text
Discovery：发现变量、模型族和阶段候选
Selection：选择容量、超参数和有限候选
Confirmation：一次性裁决冻结候选
```

必须按语义世界或对象簇分房，不能让同一对象的表面改写跨房泄漏。跨语言、跨领域和跨模型测试分别登记，不得混成随机样本划分。

### 5.3 必要基线

至少包括：

- 零响应；
- 条件均值；
- 当前事件复制；
- 时间/层平移；
- 随机标签或置乱条件；
- 错误对象、错误关系和错误查询；
- 同容量但移除关键条件变量的模型；
- 只预测首 Token 的弱基线；
- 记忆训练世界但不能外推的检索基线。

### 5.4 模型选择纪律

- 模型族、容量序列和选模准则在 Confirmation 前冻结；
- 不得在 Confirmation 失败后增加一个更复杂模型继续同一合同；
- 高容量临摹器与可解释临摹器分账；
- 预测误差、复杂度、校准误差和最坏条件组同时报告；
- 不允许只展示成功样本的平均曲线。

## 六、多分辨率数据采集

“完整轨迹”是科学范围，不等于每个案例都保存全部张量。

### 6.1 Tier A：全案例轻量轨迹

对所有合格案例记录：

- Token 和语义角色；
- 每层 Residual/Attention/MLP 的范数和冻结摘要；
- 候选 Margin、全词表 Rank 和序列 Logprob；
- 生成 Token、停止状态和缓存步；
- 非有限值、截断和右删失标记。

### 6.2 Tier B：固定子集组件轨迹

在行为结果揭盲前按固定分层抽样选择案例，记录：

- Attention Output；
- MLP Gate/Product/Down；
- 预注册候选子空间读出；
- 事件间响应向量；
- 必要的低维投影和原始 Artifact 引用。

不得根据 Tier A 的“漂亮热点”重新选择同一 Confirmation 子集。

### 6.3 Tier C：因果确认轨迹

只对冻结预测进行：

- Destroy；
- Correct Restore；
- Wrong Restore；
- Matched Null；
- 随机同规模控制；
- 路径阻断；
- 多 Token Rollout 副作用测量。

### 6.4 Tier D：必要时的原始张量

只有当聚合摘要无法区分竞争解释时，才保存大规模原始 Hidden/Attention 张量。原始张量使用 NPY、Safetensors 或 Parquet，JSON 只保存 Manifest、形状、dtype、分片和哈希。

## 七、覆盖维度与泛化梯度

测试范围分为逐级授权，而不是一次全开。

### 7.1 任务层级

1. 自包含微型世界：排除预训练事实污染；
2. 受控自然语言：加入释义、否定、范围、指代和组合；
3. 真实自由生成：评价完整序列和停止行为。

微型世界通过不能直接升级自然语言；受控自然语言通过也不能直接升级自由生成。

### 7.2 泛化轴

分别建立留出：

- 未见对象和值；
- 未见模板和释义；
- 未见操作组合；
- 未见领域；
- 未见语言；
- 未见模型；
- 未见生成长度和前缀状态。

每一轴单独报告，不能用“总体 Holdout”掩盖某个关键轴失败。

### 7.3 跨模型升级顺序

本地 GPU 模型必须依次执行：

```text
无模型材料与仪器审计
→ Qwen3
→ GLM4
→ DS7B
```

只有前一模型通过冻结资格门，后续模型才获得授权。测试完一个模型必须释放显存后再加载下一个模型。

跨模型不要求相同层号、相同神经元或相同方向；要求的是预注册响应图结构或模型间映射能够预测未见响应。

## 八、协变、分段与组合规律

### 8.1 不变量

在条件变化后近似保持的量。它仍然值得寻找，但不再是唯一目标。

### 8.2 协变/等变候选

状态坐标可以变化，但响应之间存在可预测映射：

$$
\Sigma_{\mathcal T}(g\cdot c,g\cdot I)
\approx
A_g(c)\,\Sigma_{\mathcal T}(c,I).
$$

$A_g$ 必须在 Discovery 中拟合，在未见变换、未见世界或未见模型上确认。不能通过逐样本重新对齐获得“协变”。

### 8.3 分段动力学

候选模型可以具有有限状态：

$$
F=
\begin{cases}
F_1,&\rho=1,\\
F_2,&\rho=2,\\
\cdots\\
F_m,&\rho=m.
\end{cases}
$$

必须同时预测：

- 阶段数量；
- 切换位置；
- 切换所需条件；
- 未见样本中的切换；
- 删除阶段后损失的预测能力。

如果只在训练轨迹上得到清晰分段，不能称为机制阶段。

### 8.4 类型化部分算子

操作应视为有定义域和条件的部分映射：

$$
T_a^c: \mathcal Z_{\operatorname{dom}(a,c)}
\rightarrow
\mathcal Z_{\operatorname{cod}(a,c)}.
$$

组合必须更新条件：

$$
T_{b\circ a}^{c}
\approx
T_b^{c\oplus a}\circ T_a^c.
$$

需要测量：

- 定义域与拒答域；
- 可交换和不可交换操作；
- 近似逆；
- 路径依赖；
- 组合产生的新 Blocker；
- Target Gained 与 Target Lost 的耦合副作用。

只有在实验中自然出现稳定结构后，才允许引入 Groupoid、非交换代数、控制理论等更高层数学语言。

## 九、主线阶段

### M0：状态同步与历史约束迁移

目标：停止以过期 Registry 或客户端状态启动新实验。

任务：

- 修复根目录移动后的路径发现和 Manifest 位置映射；
- 对齐 Registry、Contract、Run、Decision、Snapshot 与最新正式记录；
- 将旧结果整理为局部规律、测量工具、被否定假说和未决解释；
- 建立旧范式失败图谱；
- 禁止把路径迁移错误误判为 Artifact 丢失。

输出：

- Canonical Snapshot；
- 历史经验约束 JSON；
- 失败模式注册表；
- 可复用仪器目录；
- 数据可复用清单。

退出门：所有正式对象可追踪，状态漂移为零。未通过时禁止进入 M1。

### M1：测量合同与已知真值校准

目标：证明采集器和临摹评分能识别已知响应、边界重叠和拒答。

任务：

- 定义事件、条件、干预和测量量；
- 冻结轨迹对齐规则；
- 校准差分响应、序列响应和右删失；
- 建立泄漏、错误身份和不可识别负控；
- 校准高容量上界与受限模型选择流程。

退出门：已知真值类型、边界拒答、错误身份和泄漏 Sentinel 全部通过；否则关闭相应仪器。

### M2：全轨迹条件响应基线

目标：采集第一份受控、多分辨率自然响应图谱，不寻找最佳坐标。

任务：

- 自包含微型世界；
- 受控自然语言；
- 对象、关系、查询、否定/范围和双操作组合；
- Tier A 全案例与 Tier B 固定子集；
- Qwen3 首先执行，后续模型受门控。

输出：

- Response Case Registry；
- Trajectory Manifest；
- Response Observations；
- 行为与生成资格矩阵；
- 数据质量审计。

### M3：临摹模型竞争与复杂度曲面

目标：判断响应是否可预测，以及最低需要何种经验复杂度。

任务：

- 零模型、线性、条件化、分段和小型非线性模型竞争；
- 分别预测短程、长程和多 Token；
- 输出模型×跨度×干预类型曲面；
- 报告整体、最坏组和拒答区域。

退出门：至少一个冻结模型在 Selection 中稳定优于简单基线，且 Confirmation 仍保持；否则登记“当前观察量下未发现可压缩规律”。

### M4：结构化残差驱动发现

目标：只从稳定残差提出新变量或新阶段。

分析：

- 残差是否集中在否定、范围、组合或多 Token；
- 是否在候选翻转、缓存切换或停止前出现；
- 是否跨模板、世界和模型复现；
- 加入哪个变量能在新数据中消除残差；
- 高容量模型能否预测这些失败。

不得仅凭聚类图命名机制。残差候选必须产生可反证预测。

### M5：协变与类型化组合

目标：判断跨上下文规律是坐标不变、可预测变换，还是仅局部有效。

任务：

- 未见重命名和释义变换；
- 双操作顺序；
- 近似逆；
- 定义域和拒答；
- 模型间响应映射。

退出门：映射必须在未见条件预测响应，而不是只提高对齐相似度。

### M6：预注册因果确认

目标：让临摹模型提前预测内部干预结果。

冻结预测至少包括：

- 影响开始事件；
- 传播方向和幅度区间；
- Target Gained/Lost；
- Correct/Wrong Rescue 差异；
- 是否进入后续 Token；
- 预期失效条件。

随后只运行有限的 Tier C 干预。因果结果与预测不符时，必须降低或关闭候选规律。

### M7：自由生成与跨模型复现

目标：验证规律是否从受控任务进入完整自回归轨迹。

任务：

- 未见生成长度；
- 前缀和缓存变化；
- 语义正确、格式、句界和停止分别记账；
- Qwen3、GLM4、DS7B 顺序复现；
- 坐标不同但功能响应映射可预测。

### M8：理论压缩

只有 M2—M7 出现稳定结构后，才建立理论。

理论至少需要：

- 有限对象和定义域；
- 能生成实验预测；
- 能解释成功与失败；
- 比逐案例记忆更简洁；
- 明确误差、适用域和不可识别区域；
- 能被新实验反证。

如果没有低复杂度理论胜出，也必须正式记录高维、局部、条件化的复杂度边界。

## 十、第一个新 Campaign

正式编号由 Registry 在 M0 状态同步后分配，不在本规范中写死。

建议名称：

> **全轨迹条件响应临摹基线**

### 10.1 目标

在不扫描“最佳机制坐标”的前提下，判断模型面对语言反事实变化时的响应轨迹是否可以被预注册模型预测。

### 10.2 执行顺序

#### WP00：无模型材料与数据管线

- 生成自包含世界和受控自然语言材料；
- 建立对象、关系、查询、否定/范围和双操作反事实；
- 完成语义唯一性、泄漏、Token 对齐和拒答审计；
- 生成冻结 Discovery/Selection/Confirmation 分区；
- 验证 JSON、JSONL 和大型 Artifact 管线；
- 在模拟响应上校准临摹器与复杂度曲面。

#### WP01：Qwen3 行为与 Tier A/B 轨迹

- 先运行行为资格；
- 只有合格组进入轨迹采集；
- 所有层采轻量摘要；
- 固定子集采组件轨迹；
- 不做内部 Patch；
- 输出短程和首 Token 响应基线。

#### WP02：Qwen3 临摹模型竞争

- 冻结候选模型和容量；
- 完成 Selection 后一次性运行 Confirmation；
- 输出复杂度—跨度曲面；
- 输出结构化残差和拒答区域；
- 决定是否授权有限因果确认。

#### WP03：Qwen3 有限因果确认

- 只测试冻结的少量预测；
- Correct、Wrong、Matched Null 和随机控制成套运行；
- 评价后续 Token 和副作用；
- 失败后不换层、不换指标、不补选单元。

#### WP04：GLM4 复现

只有 Qwen3 的行为、临摹和因果预测达到冻结门后才授权。不得复用 Qwen3 的绝对层号或单元编号。

#### WP05：DS7B 复现

只有 GLM4 完成后才授权。测试结束必须形成跨模型功能映射裁决，而不是只比较三张热图。

#### WP06：受控自由生成

只有至少两个模型在受控自然语言上形成预测规律候选后，才进入多 Token 自由生成。

### 10.3 首轮不要做什么

- 不同时加载三个模型；
- 不采集所有案例的完整 Hidden Tensor；
- 不根据轨迹热点选择 Confirmation；
- 不要求一个临摹器解释所有任务、语言和模型；
- 不把高容量模型的成功称为机制闭合；
- 不在 Confirmation 失败后增加容量或更换阶段数；
- 不立即引入流形、曲率、群论或范畴论。

## 十二、什么结果有资格称为系统规律

候选规律至少需要满足：

1. **压缩性**：明显简单于逐样本记忆；
2. **未见预测**：能预测未见世界、模板或组合；
3. **跨度明确**：说明能预测多少层、事件或生成 Token；
4. **条件明确**：知道在哪些任务、语言和协议中成立；
5. **因果预测**：在干预前给出方向、时间和副作用预测；
6. **校准与拒答**：知道边界样本何时不能区分；
7. **副作用覆盖**：同时解释 Target Gained 和 Target Lost；
8. **竞争胜出**：超过零响应、均值、局部线性和记忆基线；
9. **跨模型功能复现**：允许坐标不同，但响应映射能预测；
10. **反证条件**：明确什么新结果会关闭该规律。

只有行为预测而没有内部因果，不得升级为完整机制；只有内部响应而不能预测自然语言变化，也不得升级为语言规律。

## 十三、失败分类与停止条件

### 13.1 失败分类

```text
behavior_failure          行为资格不足
measurement_failure       采集器或对齐不可靠
identifiability_failure   候选在当前实验族不可区分
predictability_failure    高容量模型也不能预测
compression_failure       可预测但受限模型不能压缩
causal_prediction_failure 预测不能通过内部干预
rollout_failure           首 Token 有效但多 Token 失效
transfer_failure          跨任务/语言/模型失效
data_leakage_failure      分区或材料泄漏
engineering_failure       运行环境或 Artifact 不完整
```

### 13.2 Campaign 硬停止

满足任一条件必须停止当前合同：

- 行为资格主门失败；
- 数据泄漏或语义 Gold 不唯一且未允许拒答；
- 已知真值仪器不能恢复类型或拒答边界；
- Confirmation 低于冻结门；
- 高容量模型也无法超过冻结基线；
- 受限模型在预算内均无稳定增益；
- 因果预测失败；
- 多 Token 副作用超过冻结上限；
- 模型升级前一模型未通过；
- GPU、样本或 Campaign 预算耗尽；
- Registry、Decision 和 Snapshot 状态漂移未解决。

停止后禁止：

- 删除失败组；
- 更换 Holdout；
- 扩大容量继续同一 Confirmation；
- 改变误差定义；
- 换层、换单元或换算子恢复同一强版本；
- 把失败改写成“发现更深规律”并立即自动续行。

### 13.3 允许开启新 Campaign 的条件

新 Campaign 必须提出：

- 数学上或测量上不同的新对象；
- 能提前解释旧失败的预测；
- 新的死亡条件；
- 与旧数据隔离的新 Confirmation；
- 明确的预算和阶段终止条件。

## 十四、数学理论的使用边界

当前不需要预先指定流形曲率、纤维丛、群论、Groupoid、Koopman、范畴论或重整化群作为答案。

数学工具的引入顺序必须是：

```text
稳定、重复的经验结构
→ 简单描述是否足够
→ 与竞争解释可区分的预测
→ 独立确认
→ 选择最小必要数学语言
```

经验现象与可能工具的对应关系只能作为路由提示：

| 已确认经验现象 | 候选数学工具 |
|---|---|
| 跨条件存在稳定变换 | 等变和响应几何 |
| 操作只有局部定义域 | 类型化部分映射或 Groupoid |
| 操作顺序改变响应 | 非交换组合和路径依赖 |
| 事件间出现可预测切换 | 混合/切换动力系统 |
| 少量响应变量预测未来 | 预测状态和基础控制理论 |
| 多尺度响应形状复现 | 粗粒化或多尺度模型 |
| 低容量模型持续失败 | 高维分布式响应模型 |

“图形相似”不能授权高级数学理论。必须先有可重复数据和可反证预测。

## 十五、与当前理论的关系

“条件化输出场闭合理论”暂时保留为工作框架，但科学地位必须明确：

- 它不是已经闭合的语言理论；
- “复用—差分—条件化”是经验原则，不是已证明公理；
- 最终层读出公式描述输出边界，不代表上游语言算法；
- 未知变换符号只是研究对象命名，不能代替规律；
- 新主线把“意义”操作化为实验族中的功能响应签名。

工作定义：

$$
\operatorname{Meaning}_{\mathcal T}(x\mid c)
\equiv
\Sigma_{\mathcal T}(H;x,c).
$$

未来“闭合”只允许定义为相对闭合：

> 一个有限复杂度的预测状态，是否能在预注册适用域和误差范围内，预测一整类未见未来响应。

这称为 Predictive Closure，不是绝对、全局、唯一语言代码的证明。

## 十七、最终技术主线

本项目接下来的主线可以压缩为：

```text
历史证据与失败边界规范化
→ 建立行为合格的语言反事实实验族
→ 采集多分辨率完整响应轨迹
→ 竞争不同复杂度的预测临摹器
→ 测量复杂度—跨度曲面
→ 从稳定残差发现条件变量、阶段和组合结构
→ 预注册内部因果预测
→ 多 Token 与跨模型确认
→ 用最小必要数学语言压缩规律
```

最关键的范式变化是：

> **不再优先寻找“意义在哪里”，而是测量“语言变化使整个系统如何变化”，并检验这种变化是否存在可压缩、可预测、可组合、可因果确认的规律。**

该路线可行，但它是一个多 Campaign 的系统辨识计划，不是一次实验。成功标准不是重新获得一个漂亮的局部闭合，而是得到一个能够提前预测新条件、新干预和新生成轨迹，同时明确自己失效边界的经验模型。
