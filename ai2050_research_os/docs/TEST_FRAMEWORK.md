# 完整测试框架

## 一、测试目标

测试系统不再围绕“哪个位置最亮”，而围绕下面的问题组织：

> 哪个最小结构能够以最低描述长度，预测未知世界、未知干预、多步生成和跨条件响应？

测试框架由测试宇宙、数据分房、十三个测试电池（一个构念前置电池加十二个执行电池）、六类全局图谱、候选机制竞赛和封存裁决组成。

## 二、正交测试宇宙

| 轴 | 必测水平 | 主要混杂 |
|---|---|---|
| 内容 | 对象、类别、属性、关系、绑定 | 词频、答案载荷、表面重复 |
| 角色 | source、query、receiver、distractor、answer | 固定位置和角色泄漏 |
| 操作 | 读取、逆查、交换、否定、比较、多跳 | 难度与长度不匹配 |
| 表达 | 裸短答、固定句式、自然句式、同义改写、多语言 | 格式服从替代内容能力 |
| 解码 | 完整候选评分、前缀树、全词表贪心、采样 | 外部约束解码器制造成功 |
| 评价 | 精确字符串、内容判据、语义判据、序列概率 | parser（解析器）即相机 |
| 事件 | 层、位置、注意力、MLP、生成步、缓存 | 层号不等于同一功能事件 |
| 干预 | 删除、交换、放大、路径阻断、错误供体、随机同范数 | 非流形状态与范数损伤 |
| 模型 | Qwen3、GLM4、DeepSeek、可控微型模型 | 架构和词元化差异 |
| 计算 | 精度、backend（后端）、缓存实现、批大小 | 数值布局改变物理状态 |
| 训练 | 任务、词汇、架构、种子、检查点 | seed（随机种子）不是普通误差项 |

不运行完整笛卡尔积。正式设计使用覆盖阵列：

- 所有二阶因素组合至少覆盖一次；
- 内容×角色×协议、内容×操作×解码等关键三阶组合全部覆盖；
- 每个决定性主张都有匹配反事实；
- 统计单元按 `world cluster`（世界簇）而不是句子行计算。

## 三、数据分房

### 1. 四个互斥房间

| 分区 | 用途 | 是否允许反复查看 |
|---|---|---|
| calibration | 校准仪器、阈值和预算 | 是 |
| discovery | 画图、聚类、生成候选结构 | 是 |
| selection | 主动选择高分歧实验，不评最终输赢 | 受限 |
| confirmation | 一次性封存裁决 | 否 |

### 2. 拆分规则

- 按潜在世界、事实图或生成规则拆分，禁止随机拆句导致泄漏；
- 同义改写、模板变体和同一事实的不同语言必须处于同一世界簇；
- 机制发现与阈值选择不能接触 confirmation（确认集）；
- 跨模型验证优先采用“留一模型”，而不是把三个模型行混合随机拆分；
- 训练形成研究按任务×词汇×架构×种子完整分房，删失状态保留。

## 四、十三个测试电池

### TB00：构念分型与接口解耦

目标：分离内容正确、格式正确、协议服从和自然生成。

四格控制：

1. 正确内容、正确格式；
2. 正确内容、错误格式；
3. 错误内容、正确格式；
4. 错误内容、错误格式。

必须加入：否定、引用、自我纠正、双标记、同义句和多参考答案。输出是类型化行为响应向量，不是单一准确率。

### TB01：测量与干预相机校准

在已知真值系统中验证：目标是否可识别、相机能否拒答、坐标变换下哪些量保持、干预算子是否保持 matched-null（匹配空对照）和 carrier（载体）近零。

未通过 TB01 的相机不得进入预训练模型。

### TB02：行为正交资格

对内容、角色、操作、表达、解码和评价分别设门，不再用无关格式门绑架内容研究，也不允许内容通过替代格式闭合。

通过某个类型门，只授权对应构念的下一层测试。

### TB03：全域低成本扫描

一次记录全部层、关键位置、注意力与 MLP 增量、候选余量、完整序列概率、实际生成轨迹和缓存摘要。此阶段只构造全局轮廓，不做大规模神经元搜索。

### TB04：响应张量试采集

在固定少量事件和预注册干预族上，采集：

\[
\mathcal R_{e,I,Q}^{c,\pi,\eta,\rho,\kappa}
=Q(F_{\ge e}(\operatorname{do}_I(H_e)))-Q(F_{\ge e}(H_e)).
\]

先验证响应是否可重算、控制是否干净、张量缺失机制是否可处理，再扩大规模。

### TB05：结构发现与候选竞赛

同时使用：变化点检测、双向聚类、张量分解、稀疏联盟搜索、结构化预测瓶颈、图模体发现和最小描述长度评分。

发现集允许产生多个候选，不允许直接产生最终机制结论。

### TB06：主动决定性干预

选择分数：

\[
S(x)=
\frac{
\operatorname{Disagreement}(x)
\times \operatorname{Coverage}(x)
\times \operatorname{Uncertainty}(x)
}{\operatorname{Cost}(x)}.
\]

优先运行候选机制预测方向相反、且能覆盖尚未区分假说对的实验。禁止只挑预期效应最大的热点。

### TB07：封存确认

在新世界、新改写、新组合、新干预和留一模型上一次运行。所有主要分区分别裁决，禁止总体平均掩盖失败。

### TB08：同一对象因果闭环

依次要求：

1. 未见响应签名预测；
2. 正确供体充分性；
3. 单点与联合删除必要性；
4. 正确救援；
5. 错误供体不得救援；
6. 同答案错误绑定不得救援；
7. 上游效应由候选状态中介；
8. 最小因果联盟稳定；
9. 内容和格式可选择性改变。

### TB09：自回归生成闭环

测试全部正确前缀、每步竞争、实际词元反馈、增量键值缓存、结束词元、错误累积和采样稳定性。首词元正确或教师强制序列概率都不能替代本电池。

### TB10：操作组合

从单操作预测未见双操作、操作顺序和作用域：查询切换、绑定交换、逆查、别名、否定、多跳。只有组合误差显著低于查表和独立拼接基线，才授权“操作代数”。

### TB11：跨协议与跨模型功能同构

寻找：

\[
\Phi_{m\to n}\circ T_o^{(m)}
\approx T_o^{(n)}\circ\Phi_{m\to n},
\]

并要求映射保持未来响应，而不是只对齐神经元、层号或 CCA（典型相关分析）。

### TB12：训练形成

在可控小模型和训练检查点中研究功能状态、路由和冗余路径何时形成。分别预测：是否形成、何时形成、形成哪种实现。右删失不得当作数值起点。

## 五、六类全局图谱

| 图谱 | 轴 | 单元值 | 算法目标 |
|---|---|---|---|
| 层—词元轨迹 | 层×位置/生成步 | 余量、序列概率、干预效应 | 变化点与阶段边界 |
| 源—接收运输 | 源事件×接收事件 | 交换或阻断响应 | 路径与汇聚模体 |
| 因素—组件 | 因素×组件/联盟 | 匹配反事实效应 | 复用和选择性 |
| 干预—读出 | 干预×读出 | 类型化未来响应 | 双重分离与冗余 |
| 协议交换 | 供体协议×受体协议×事件 | 内容和格式变化 | 分离或交织 |
| 跨模型响应 | 功能事件×功能事件 | 响应签名相似度 | 功能同构 |

每张图必须具备固定色标、标签置换零分布、自助置信区间、原始和聚类顺序、观察与真实干预对照。图像只用于发现集假说生成。

## 六、候选结构基准线

至少同时比较：

1. 固定方向编码；
2. 层间旋转子空间；
3. 稀疏因果联盟；
4. 内容—角色因子化；
5. 内容—协议分离；
6. 条件化路由图；
7. 预测动力状态；
8. 操作代数；
9. 零假说：只有局部、条件化、阶段特定的计算模体。

所有候选共享相同发现数据、封存数据和计算预算。无限制黑箱模型只作为可预测上限，不参与可解释结构排名。

## 七、统一指标

### 1. 归一化预测增益

\[
G_M=\frac{L_{\mathrm{null}}-L_M}{L_{\mathrm{null}}-L_{\mathrm{oracle}}}.
\]

### 2. 必需指标族

- 未知世界损失；
- 未知干预损失；
- 干预方向准确率及置信区间下界；
- 多步滚动误差；
- matched-null、错误供体、同答案错误绑定优势；
- 跨协议保留率；
- 跨模型保留率；
- 描述长度与查表模型压缩比；
- 完整生成内容、格式、结束和缓存一致性；
- 所有必需分区的最差组表现。

建议初始校准目标为：可预测上限覆盖约 80%、方向准确率置信下界约 80%、跨协议保留约 70%、描述长度优于查表至少一个数量级。它们只是校准起点，正式数值必须在 confirmation 数据揭盲前冻结，并由已知真值和噪声上限校准。

## 八、生死合同

每条机制正式进入竞赛前必须写出：

1. 数学对象；
2. 适用域；
3. 至少三个区别性预测；
4. 最强零假说；
5. 主要指标与阈值；
6. 必须分别通过的分区；
7. 死亡条件；
8. 重开条件。

裁决只有：全局幸存、局部机制、限定否决、拒答。不得使用“有希望”“基本成功”等不可计算状态。

## 九、审计要求

- 正式程序和结果审计器职责分离；
- 合同、代码、材料、环境、原始结果和最终摘要分别计算摘要；
- 审计从原始结果重算指标和裁决，不读取正文结论；
- 保存失败分区和零支持事件；
- 数值异常、缺失、删失和协议错误必须显式登记；
- 任何揭盲后修复均生成新运行编号，旧结果保留。
