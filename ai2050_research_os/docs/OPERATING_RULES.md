# 研究运行与记录规范

## 一、每次研究工作的标准流程

### 步骤 1：先更新问题，不先写脚本

在 `registry/puzzles.json` 中选定一块拼图，确认依赖、当前闭合层级、阻塞项和下一决定性问题。

### 步骤 2：选择候选机制对

在 `registry/hypotheses.json` 中明确本次实验至少区分哪两个候选。若所有候选给出相同预测，本次实验信息增益不足。

### 步骤 3：建立冻结合同

复制 `templates/experiment_contract.json`，填写构念、材料、分区、预测、对照、阈值、预算、停止规则、失败结论和权限。

### 步骤 4：校准与预审计

先在已知真值或 calibration（校准集）上验证相机、parser（解析器）、指标、随机控制和审计器。预审计不得读取正式模型输出。

### 步骤 5：冻结

记录合同摘要、代码摘要、材料摘要和环境。冻结后，正式运行不得修改原合同。

### 步骤 6：运行与独立审计

正式程序只写原始结果和机器摘要；审计器从原始结果重算全部门、置信区间和最终裁决。

### 步骤 7：先登记证据，再写分析

更新顺序固定为：

```text
sources.json / corrections.json
→ phases.json（record_id 为主键，Phase 只作标签）
→ evidence.json
→ objects.json / constructs.json
→ contracts.json / runs.json / artifacts.json
→ hypotheses.json
→ puzzles.json
→ decisions.json
→ researchctl build
→ 长篇分析
```

### 步骤 8：明确权限

每个 Phase 必须写：`authorizes`（允许的下一动作）与 `forbids`（明确禁止的外推或续行）。

## 二、状态修改规则

### 1. 证据不可被解释覆盖

新解释只能新增决策或更新候选状态，不得修改旧证据的原始 claim（主张）、scope（适用域）和 grade（等级）。若旧记录确有错误，新增勘误记录并保留原版本。

### 2. 闭合层级不能跳跃

- 可读不等于预测；
- 预测不等于因果；
- 充分不等于必要；
- 正确救援不等于中介；
- 首词元不等于生成闭环；
- 单模型不等于跨模型结构；
- 终态存在不等于形成机制。

### 2.1 合同与运行状态不能跳跃

- 合同：`draft → calibrated → preregistered → ready → running → auditing → adjudicated`；
- 运行：`planned → ready → running → auditing → adjudicated`；
- `preregistered` 只表示问题、预算和停止条件已冻结，不等于 `run_ready`；
- 只有代码、材料、环境和独立审计器全部进入 manifest 后，合同才可转为 `ready`。

### 3. 负结果必须产品化

负结果至少关闭一个明确定义的强版本，或标明只是资源删失、构念失败、相机失败、不可识别或外部效度失败。

### 4. 重开规则

已限定否决的机制只有同时满足以下条件才能重开：

1. 新版本在数学对象上与旧版本不同；
2. 在运行前解释旧实验为何失败；
3. 对旧数据给出可复算预测；
4. 对新封存数据给出区别性预测；
5. 登记新的适用域和死亡条件。

## 三、Phase 报告最小结构

1. 任务来源与拼图编号；
2. 候选机制和区别性预测；
3. 构念、材料、分区与预算；
4. 冻结合同和摘要；
5. 正式结果；
6. 审计结果；
7. 失败类型；
8. 证据登记；
9. 候选机制裁决；
10. 拼图状态变化；
11. 授权、禁止和下一决策；
12. 工程产物路径。

完整模板见 `templates/phase_report.md`。

## 五、反循环硬规则

1. 发现集可以看，确认集只能揭盲一次；
2. 同一失败强版本不得通过换层、换模板或删分区重跑；
3. 总门只能连接同一构念的必要条件，异质构念使用类型化门；
4. 不围绕一个局部正结果连续生成相邻 Phase；
5. 每个战役预先规定最大 Phase 数、GPU 预算和停止点；
6. 每次主动实验必须覆盖至少一个尚未区分的假说对；
7. 若所有紧凑结构均失败，合法结论是局部条件化模体，而不是继续寻找正结果；
8. 理论升级必须预测未运行实验，不能只重新命名历史结果。

## 六、每周与每个战役的汇总

### 每周汇总

- 新增证据及等级；
- 候选状态变化；
- 关闭的假说对数量；
- 拼图层级变化；
- 预算使用与删失；
- 下周唯一最高信息增益决策。

### 战役结案

- 幸存机制及适用域；
- 被否决强版本与死亡证据；
- 未区分候选对；
- 因果与生成闭合达到的最高层；
- 可迁移工程资产；
- 是否授权下一战役。
