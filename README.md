# OpenOne / AI2050

OpenOne 是一个面向语言机制、神经网络原理与通用智能的逆向工程研究项目。

项目试图回答一个核心问题：

> 深度神经网络如何把知识网络、逻辑推理和语法规则融合为稳定的语言能力？它的底层编码、动态运行和形成机制是什么？

当前项目已经积累了大量行为、HiddenState、Q/K/V、干预与跨模型结果，但尚未找到一个完整闭合的语言编码机制，也尚未完成智能理论或 AGI 系统。README 中的“假设”“候选”“拼图”均不等于已证明结论。

---

## 一、路线分析

### 1. 基本判断

1. 人脑依靠高效可塑性形成语言、视觉、听觉、身体控制等能力。可塑性可能是智能形成的关键机制之一。
2. 深度神经网络通过大规模训练获得了稳定语言能力，说明它至少恢复了语言结构中的一部分可计算规律。
3. 对深度神经网络进行逆向工程，恢复语言从输入条件到内部状态、再到输出行为的完整计算链，是探索语言数学结构和神经网络原理的一条可执行路线。
4. 如果进一步解释这些结构如何通过训练形成，才可能从语言编码推进到可塑性机制、智能理论和新的 AGI 架构。

项目主路线因此定义为：

```text
语言模式图谱
→ Embedding / HiddenState 完整场
→ 条件化内部算子
→ 知识、推理、语法的组合机制
→ 网络可塑性与形成规律
→ 可预测、可干预的智能理论
→ AGI 工程
```

### 2. 可以借鉴的大脑视角

大脑不同区域可能共享兴奋、抑制和可塑性等底层机制，同时因连接、参数、输入输出和学习历史不同而处理不同信息；跨区域整合产生统一知觉和行为。这为研究“共享底层机制如何在不同参数下形成不同能力”提供了启发。

但必须保持边界：

- LLM 是语言计算模型，不是完整大脑；
- 目前没有证据证明 LLM 直接复制了某个脑区，或只等同于前额叶的一部分；
- 从 LLM 得到的机制必须先在模型内部完成行为、因果和跨材料验证，不能直接外推到人脑；
- 兴奋/抑制、意识整合和生物可塑性属于后续需要独立验证的研究对象。

### 3. 需要避免的误区

1. **把 LLM 当作完整大脑。** LLM 没有自然具备完整知觉、身体控制和生物意识机制，用完整脑功能解释每个 LLM 现象容易产生错误类比。
2. **从架构名称推导心理功能。** Q、K、V、Attention、MLP 是计算组件名称，不能直接命名为“请求”“地址”“语义”“意识”等功能。
3. **把热点当作机制。** 高激活、高相关、可读 probe、Top-K 坐标或漂亮几何都只能产生候选，不能单独证明必要性、充分性和特异性。
4. **把特殊网络路线当作统一理论。** 世界模型可以研究视觉与环境预测，但不能替代语言编码和可塑性机制研究；其结论也需要独立闭合，不能自动升级为通用智能原理。
5. **把小模型直接当作普遍规律。** 模型规模、训练数据、架构和 tokenizer 都会改变实现方式。小模型中的局部机制必须经过跨规模、跨架构和自然任务验证。

### 4. 路线成功标准

真正的机制必须同时做到：

- 解释已经观察到的语言行为和内部状态；
- 在冻结规则后预测未见材料、未见构式和未见干预；
- 精确改变目标能力，同时不破坏匹配负控制；
- 能够删除、调用、替换或救援目标功能；
- 在自然生成中产生预期结果；
- 明确适用范围，并能解释失败与模型差异；
- 最终说明机制如何通过训练和可塑性形成。

## 二、理论框架

### 1. 语言的工作定义：可组合模式集合

本项目暂时把语言能力统一描述为模式集合，但这里的“模式”不是简单的词表分类或相似度聚类，而是带有类型、角色、关系、上下文、变换和组合规则的可执行对象。

语言模式至少包括：

- **知识模式**：实体、类别、属性、关系和层级，例如“苹果—水果—食物—物体”；
- **任务模式**：续写、问答、分析、推理、翻译、润色、重排和代码生成；
- **语法模式**：词性、构式、依存角色、标点、边界、否定和作用域；
- **序列模式**：多个模式在时间顺序和上下文中的组合，例如“我—喜欢—吃—苹果”；
- **输出模式**：候选竞争、格式、风格、停止和生成协议。

外部语言图谱可以写成类型化超图：

\[
\mathcal G_{lang}=
(V_{form},V_{concept},V_{role},V_{context},
E_{relation},E_{transform},E_{compose})
\]

它的目标不是枚举所有句子，而是找到能够生成大量语言现象的基本对象和组合操作。

### 2. LLM 为什么可能有效

#### 注意力：条件化相对计算

Attention 允许当前位置根据上下文选择其他位置的信息。概念身份因此可能部分来自关系网络中的位置、角色和当前任务，而不是来自一个孤立、固定坐标。

#### 多 Layer：逐层状态更新

多层结构允许输入表示不断被更新：识别任务、连接上下文、组合关系、形成输出条件并参与下一个 token 的竞争。研究对象应是完整更新过程，而不仅是某层静态表示。

\[
H_{l+1}=F_l(H_l;x,c,\Theta)
\]

其中 \(x\) 是输入，\(c\) 是上下文与任务条件，\(\Theta\) 是模型参数。

#### 自回归训练：统一输出目标

自回归训练把知识调用、上下文分析、语法约束、风格控制和输出协议共同压入“预测下一个 token”的训练目标，使多种能力能够在同一网络中竞争和协作。

它可能产生：

- 族内、族间和全局模式的多尺度组织；
- 随上下文变化的动态功能位置；
- 知识、逻辑、语法、风格和输出协议的多场竞争；
- 可复用结构与样本特异差分的共同存在。

“深度思考”或长推理模式说明模型能够通过特定上下文和训练形成不同的推理运行制度，但这还不能证明存在一个固定的高优先级底层模块。

### 3. 当前内部结构假设

1. **相对编码**：模式身份可能由它与其他模式的关系、角色和作用决定。
2. **复用与差分**：不同语言对象可能共享部分计算骨架，再通过条件相关差异形成独特功能。
3. **多层级、多维度处理**：知识、句法、段落逻辑、风格和输出协议可能在不同时间、位置和组件中并行作用。
4. **条件化路由**：同一坐标、head 或 token region 在不同任务中可能承担不同作用。
5. **分布协同**：有效机制可能是多个 token、层、head 和坐标的协同集合，而非单个神经元或固定小集合。
6. **功能约束高于物理位置**：不同模型可能实现相同功能约束，却使用不同层位、head 和坐标基底。

### 4. 实现粗糙度

模型规模、数据、训练目标和架构限制会产生噪声、捷径、冗余和模型特异实现。受控微世界中的强结果可能只是一种任务实现，不代表自然语言普遍机制。研究必须同时保存正结果、反证、失败条件和替代解释。

## 三、具体工程

### 1. 完成语言图谱

语言图谱分为三个核心系统：

#### 知识网络

记录实体、类别、属性和关系，例如：

```text
苹果 → 水果 → 食物 → 物体
苹果 → 颜色 / 大小 / 味道 / 生长方式
```

目标是研究类别层级、属性绑定、关系调用、复用和差分的计算机制，而不是只建立传统知识库。

#### 分析与推理系统

系统研究续写、润色、翻译、重排、问答、代码生成、单步推理、多步推理和长距离调用。每个任务都要拆成明确的输入操作、角色、不变量、变化量、正确输出和错误类型。

#### 语法系统

记录名词、动词、形容词、副词、介词、标点、构式、依存角色、否定、作用域和语序变化，分析语法规则如何在序列中形成和调用。

#### 序列与多维分析

以“我喜欢吃苹果”等自然序列为例，同时记录：

- token 与词性；
- 主体、动作、对象等角色；
- 概念和知识关系；
- 语法构式与顺序；
- 上下文条件；
- 生成目标和候选竞争。

语言图谱最终应能自动生成 discovery、confirmation 和 lockbox 数据，而不是依靠手工挑选少量句子。

### 2. 完成 Embedding—HiddenState 全场图谱

对每个行为合格的语言操作，保存所有 token、所有层、所有物理坐标以及必要的 Q/K/V、Attention、MLP 和输出读出数据。

基础场包括：

\[
H_{l,t,j}
\]

原始 HiddenState；

\[
\Delta_l H=H_{l+1}-H_l
\]

层更新；

\[
\Delta_fH=H(f_{on})-H(f_{off})
\]

条件差分；

\[
U_{f,u,l,t,j}=Delta_lH(f_{on})-\Delta_lH(f_{off})
\]

条件相关的局部更新差分。

工程原则：

- 原始数据保存全坐标，Top-K 只用于显示；
- 同时保留真实物理顺序和预先冻结的响应排序；
- 每个值都能追溯到模型、输入、token、layer、dtype、代码和工件哈希；
- discovery 中发现的排序和阈值不能在 lockbox 中重新调整；
- 没有真实数据时显示缺失，不使用演示值填充研究结果。

### 3. 完成语言图谱与内部场的关联

目标不是寻找“苹果神经元”，而是寻找外部语言操作与内部条件算子之间可预测、可干预的对应：

\[
\Psi_\theta(O_f^{ext}(x))
\approx
G_f^{int}(\Psi_\theta(x);x,r,l,c)
\]

其中内部算子依赖样本 \(x\)、角色 \(r\)、层 \(l\) 和上下文 \(c\)。

关联机制必须依次通过：

```text
行为资格
→ 仪器与数值资格
→ 完整场重复
→ 条件选择性
→ 充分性
→ 必要性
→ 错角色/错关系/错位置负控制
→ 未见预测
→ 自然生成
→ 跨模型功能复现
```

### 4. 三个工程工作区

#### 研究积累

保存语言节点、超图关系、构式、Case/Pair、完整场、干预、证据、理论主张、关键拼图和闭合申请。

#### 3D 机制显微镜

观察真实模型结构、实时前向事件、Embedding 完整场、当前 Layer HiddenState、条件差分、响应边和输出贡献。3D 是研究仪器，不是结论生成器。

#### AI 自动研发

采用项目任务线程、计划、执行日志、代码差异、测试、产物和独立审查组织自动研发：

```text
读取证据缺口
→ 冻结研究合同
→ 主模型完成编程或实验
→ 辅助模型独立检查原始工件
→ 主模型综合冲突与反证
→ 确定性程序裁决
→ 保存结果并更新数据库
→ 人工审核 Evidence / Closure 申请
```

AI 可以提出假设、编写代码和执行有界任务，但不能自行批准理论闭合。

## 四、当前进展

当前可审计基线是 **Phase 2578：Phase2551—2577 证据终审、产物核验与下一阶段合同**，记录时间为 **2026-09-03 17:19**。Phase 只表示实验与审计批次；正式研究主轴是语言操作、构念、合同、Run、工件和证据权限。

### 1. 本轮完成的关键纠错

- 旧单关系任务中的 relation 在同一提示内保持常量，答案实际可以退化为结构化键值匹配，因此不能作为自然关系语义机制证据。
- Q、K、V 只是架构投影名称，不能根据名称直接解释为内容、地址、请求或输出编译。
- facts-value 的早期 V 效应只是在指定模型、任务和干预中的 region 级局部充分性，不是最小齿轮。
- 固定坐标提取算法失败只淘汰该算法，不能推出信息必然均匀分布于全网。

### 2. 已得到支持的结果

#### 关系和值联合必要的行为任务

项目构建了关系和值共同决定答案的四事实交叉格。经过 padding、候选索引和 token 兼容修正后，Qwen3-4B 英文新实体单步任务达到：

```text
完整输入准确率：0.868164
缺少关系：      0.500000
缺少值：        0.500000
```

这说明在该受控任务中，relation 与 value 在行为设计上共同必要。它仍是人工二元/有限候选任务，不能直接代表自然语言关系系统。

#### Qwen3-4B 的局部全坐标算子候选

在独立留出且行为合格的 Qwen3-4B 子集上，layer 0 query-slot V 的全 1024 坐标替换表现出选择性 XOR 充分性：

```text
relation 单因子 flip：0.930233
value 单因子 flip：   0.930233
双因子保持 base：     0.953488
matched-null flip：   0.023256
XOR margin：          0.906977
```

它是当前最接近“条件齿轮”的局部因果事件，但严格名称只能是：

> 模型、材料和干预条件化的全坐标因果算子候选。

#### 分布式协同边界

- 该局部事件横跨全部 8 个 KV heads；
- 单个 head 或连续 32 维块均不充分；
- H5 锚定的 7-head 压缩在跨实体留出上失败；
- 因而当前不能把机制压缩为固定单 head、Top-K 或固定小坐标集合。

#### 完整场和客户端资产

已经保存并发布七类新面板：

- Embedding/HiddenState：2560 个物理坐标；
- Q：4096 个坐标；
- K：1024 个坐标；
- V：1024 个坐标；
- 8-head 子集；
- 32 个无遗漏 V 坐标块；
- Qwen3-4B/14B 十事件因果对照。

可视化源资产与正式构建资产哈希一致。未展示的大型原始场已按合同清理，但索引、摘要和重建元数据保留。

### 3. 重要反证和未复现结果

- Qwen3-14B 在修正后的行为任务中达到完整输入 `0.810547`、两种缺失条件均为 `0.5`，但没有复现 Qwen3-4B 的选择性 layer-0 V 事件。
- Qwen3-14B 的早、中、中晚、晚四层段 V/KV 测试全部未通过完整选择性门；中晚层的高 flip 同时伴随 `0.8125/1.0` 的高 matched-null，属于非特异效应。
- 现有两跳和三跳组合任务没有获得合格行为，单步关系调用不能外推为多步组合机制。
- DeepSeek7B 和 GLM4 在本轮关系×值任务中没有通过进入同一因果比较的行为资格。

这些结果说明：功能约束可能比固定层位、head 或物理坐标更可复用，但这一判断仍是假设，而不是已证明理论。

### 4. 当前可以说什么

- 语言条件依赖输入角色、关系、值、位置、上下文和任务的联合状态。
- 在一个受控 Qwen3-4B 任务中，发现了全坐标、跨全部 KV heads 的局部充分算子候选。
- 单点、单 head、固定 Top-K 和固定小联盟不足以解释该事件。
- 相同任务能力可以在更大模型中以不同内部实现出现，物理位置不能直接跨模型对齐。
- 完整场、因果结果、负控制和失败复现可以在客户端中统一检查。

### 5. 当前不能说什么

- 尚未破解自然语言的知识网络、逻辑推理和语法融合机制；
- 尚未发现跨模型稳定的最小计算单元、固定语言向量或完整相对编码规则；
- 尚未完成逐 token、逐 head、逐坐标的 source—recipient 中介链；
- 尚未证明必要性、自然生成闭环或多跳组合；
- 尚不能把模型结果外推到人脑可塑性、意识或完整智能理论；
- 尚未形成任何新的数学闭合。

### 6. 当前最强理论拼图

当前最稳妥的工作对象不是固定语义向量，而是条件化有向响应图：

\[
\mathcal G(x,q)=
\{(l,h,j\rightarrow a,c):
\Delta z_y\text{ 在匹配控制下稳定且可干预}\}
\]

候选机制由 layer、head、source token、recipient token、coordinate 和上下文共同定义。Qwen3-4B 的全坐标 XOR 事件支持这种研究对象具有价值，但跨规模失败说明其物理实现不是普遍定律。

### 7. 下一大阶段

下一阶段不再追逐单个高翻转区域，而是：

1. 重建 token 等长、四种词面均行为合格的四选一关系任务，使错误类型不再自动等于 donor 答案；
2. 在 Qwen3-4B 和 Qwen3-14B 上分别冻结独立 lockbox；
3. 冻结 `relation × value × role × context` 事件，保存逐 token 而非 region 均值的全坐标场；
4. 同时使用正确 slot、错 slot、错 relation、错 value 和同损伤剂量 null 定义选择性；
5. 先建立功能图，再寻找物理坐标联盟；
6. 依次在新实体、新关系词表、新 surface、新语言上验证，无需重新发现规则；
7. 最后才进入必要性、逐边中介和自然语言多跳/长句重排。

验收标准不是再获得一个高 patch flip，而是：

> 使用同一套冻结规则，准确预测留出场结构、干预方向、错误类型和自然输出变化。

详细进展以 [GLM5 研究备忘录](research/glm5/docs/AGI_GLM5_MEMO.md) 的原始记录和对应 `tests/glm5/result/` 工件为准。

## 五、研究方法与证据纪律

### 机制边闭合门

\[
E_{u\rightarrow v}=I\land S\land N\land C\land P\land R
\]

- `I`：仪器身份等价，no-op 和自补丁不漂移；
- `S`：充分性，干预可以选择性改变目标；
- `N`：必要性，删除会破坏对应能力；
- `C`：特异性，匹配负控制不出现相同效应；
- `P`：预注册预测在未见材料上成立；
- `R`：独立材料、模型或实现中重复。

### 研究纪律

1. 先行为，后内部；
2. 先仪器，后机制；
3. 先相关，后因果；
4. discovery、confirmation、lockbox 严格分离；
5. 实验对象、阈值、分区、颜色尺度和失败条件预先冻结；
6. 完整场优先，不用 Top-K 代替原始证据；
7. 模型、材料、行为、内部场、组件因果和生成分别记账；
8. 正结果、反证和未决结果全部保留；
9. Phase 只作来源坐标，不作为理论进展本身；
10. AI 意见不属于实验复现，不能自动提升证据等级。

## 十一、当前结论

深度神经网络稳定的语言能力说明语言中存在可以被训练获得的计算规律，这使逆向工程路线具有价值。当前项目已经从固定语义向量、单神经元和 Top-K 热点，推进到类型化语言操作、完整物理场、条件化响应、分布式联盟和跨模型功能约束。

但 Phase 2578 的终审同时表明：当前最强结果仍然只是 Qwen3-4B 受控任务中的局部全坐标因果算子候选；它没有跨规模复现，也没有完成必要性、逐边中介、自然生成或语言组合闭合。

因此下一步不是给已有拼图命名为新数学理论，而是继续扩大语言图谱和完整场数据，用冻结规则完成未见预测与因果闭环，让语言背后的结构从证据中自然浮现。
