# OpenOne / AI2050

OpenOne 是一个深度神经网络逆向工程研究项目，目标是破解语言能力在深度神经网络中的编码与运行机制，并寻找能够解释、预测和控制智能系统的基础计算原理。

项目尝试回答一个核心问题：

> 深度神经网络如何把对象、关系、规则和上下文组织成语言能力？这种能力背后是否存在可验证、可干预、可复现的数学结构？

仓库同时包含科研实验、证据管理、3D 可视化和 AI 自动研发工具。当前研究仍在推进中，尚未完成语言编码理论、智能统一理论或 AGI 系统。

## 项目大纲

### 核心猜想

以下内容是项目的研究方向，不是已经证明的结论：

1. 人脑具有极高可塑性。语言能力可能是神经网络被经验反复塑造后形成的系统能力，而这种可塑性可能是智能的重要来源。
2. 注意力、自回归训练和大规模语言材料，使深度神经网络部分恢复了支撑语义、逻辑、语法和生成控制的内部数学结构。
3. 如果能够恢复语言编码的可执行机制，就可能反推神经网络的塑造规律，为智能理论和可控制 AGI 架构提供基础。

本项目假设语言背后存在一套系统结构。在找到核心规律之前，局部相关、热点神经元和漂亮几何都可能只是投影或虚影；真正的突破应当像一个正确物理理论一样，能够统一解释已有结果，并对新材料和干预结果作出准确预测。

### 系统工作假设

1. **模式本体**：知识网络、分析推理和语法规则可以暂时统一为不同尺度、不同功能的模式。
2. **相对编码**：概念身份可能来自它在关系网络中的位置和作用，而不是孤立、固定的坐标。
3. **复用与差分**：可共享结构尽量复用，不能复用的部分通过较小差异表达独特特征。
4. **多尺度组织**：族内结构、族间关系和全局模式族分布可能共同平衡能力、容量与计算效率。
5. **动态生态位**：训练和上下文持续调整词的含义与用法，使每个模式形成条件化、相对独特的功能位置。
6. **多场竞争**：风格、逻辑、语法、知识和输出协议共同参与下一个 token 的候选竞争。
7. **实现粗糙度**：模型规模、训练数据和架构限制会产生噪声、捷径与模型特异实现，特别是小模型不能直接代表大模型或人脑。

这些假设相互关联，但必须分别接受实验检验。观察到模式复用不能证明结构最优；观察到条件化状态也不能直接证明人脑采用相同机制。

### 三级破解目标

#### 1. 具体模式

恢复特殊词、翻译、转折、标点、终止等模式从输入条件到输出选择的完整计算链：模式何时形成、由什么组件推进、怎样改变候选竞争。

#### 2. 模式族

分析水果、动物、颜色、翻译和语法等模式族内部及族间的复用、差分、抽象和条件化路由，寻找决定模式身份的最小差异。

#### 3. 整体网络

重建模式族在位置、层、Attention、MLP 和 residual 中的全局分布，解释网络如何同时获得表达能力、效率与稳定性，并寻找可跨任务复用的最小计算单元或不变量。

### 主要难点

1. 语言同时混合语义、语法、知识、风格和协议，任何测试都可能包含多个因素，很难获得只改变一个变量的纯净实验。
2. 现有数学工具通常只能描述局部投影，尚不能直接表达完整的条件化、分布式计算结构。
3. 编码可能同时包含相对关系、复用、差分、抽象与精确化，静态距离容易产生误导。
4. 规律跨越大量层、位置和组件；可读热点、强激活或高相似度不一定是模型实际使用的机制。
5. 紧凑结构、模型噪声和小模型粗糙度会产生大量虚影。当前仍缺少能够贯穿全网的最小计算单元或稳定不变量。

### 核心目标

找到一个算法或不变量，能够：

- 解释深度神经网络的运行机制；
- 预测内部状态和输出如何随条件变化；
- 对关键机制进行精确修改、恢复和控制；
- 在跨材料、跨任务和跨模型测试中保持有效；
- 为新的智能架构和 AGI 系统提供可执行理论。

## 当前研究进展

当前研究推进到 **Phase 1140：多 token 决策路径对齐**。

项目已经从“寻找固定语义向量或单个概念神经元”，逐步转向“恢复上下文条件化的状态转移和有向因果机制”。最新结果来自时效实体关系绑定任务及 Qwen3 同架构尺寸复验。

### 六阶段推进

| 阶段 | 核心问题 | 主要结果 | 方法论推进 |
| --- | --- | --- | --- |
| Phase 901-1106 | 是否存在固定语义方向、单点运输器或局部通用组件 | 获得候选竞争、内容条件化、复用拓扑和地址路由等局部拼图；固定跨材料执行方向等假说未通过项目测试 | 从静态坐标转向条件化过程 |
| Phase 1107-1125 | 自然语义行为、线性可读和真实使用是否一致 | 形容词双正交行为三模型通过；自然语境方向与定义方向的固定物理桥未闭合 | 确立“先行为、后内部；可读不等于使用” |
| Phase 1126-1134 | 数值、运行路径和材料是否具备机制研究资格 | 定位 GLM4、DS7B 的 FP16 问题，建立模型、材料和运行路径资格门 | 先校准仪器，再讨论机制 |
| Phase 1135-1138 | 时效绑定答案状态何时获得可搬运性 | Qwen3-4B 行为在 Qwen3-14B 同族复验；两尺寸在相对深度 0.6-0.7 出现可搬运性增强，但没有共同充分深度 | 从方向搜索转向状态转移与充分性 |
| Phase 1139 | 后半程变化是相变、平滑调制，还是仪器漂移 | live-state 同路径插值使 α=0 漂移为 0；深度 0.7 是强调制 donor，但约三成样本不足以翻转 | 身份等价成为因果实验前置门 |
| Phase 1140 | 单点补丁能否代表多 token 候选决策 | 覆盖 candidate prediction span 后，12/12 条共享前缀曲线被恢复；统一充分状态仍未获得双模型授权 | 下一目标转向候选首次分叉边界 |

### 当前可以说什么

- 项目测试中的语言信息更符合上下文条件化、分布式展开的过程，而不是一个跨材料固定不变的执行向量。
- 输出表现为候选竞争；表示、控制、执行与最终生成必须分别记账。
- Qwen3-4B 与 Qwen3-14B 在时效绑定任务上重复出现后半程状态可搬运性增强。
- live-state 同路径插值可以消除自补丁漂移，说明干预仪器必须先验证身份等价。
- 当候选共享首 token 时，干预必须覆盖真实预测路径；答案开头并不总是唯一决策位置。

### 当前不能说什么

- 尚未找到跨模型、跨任务稳定成立的语言编码不变量或最小计算单元。
- 相对深度 0.6-0.7 的跃迁不等于存在统一语义层，也不等于完整机制已经形成。
- 整残差 donor 尚未同时通过必要性、充分性、特异性、独立预测和跨材料重复。
- 当前结果不能直接外推到所有大模型，更不能直接证明人脑采用相同编码机制。
- 真实生成闭合、精确修改控制和完整智能理论仍未完成。

详细进展说明见：[当前研究总结](research/MainAnalysis/20260806_01_当前研究总结.md)。

## 当前理论框架

当前使用的工作名称是 **条件化输出场闭合理论**，组织原则是 **复用—差分—条件化**（Reuse-Difference-Conditioning, RDC），数学对象暂时描述为条件计算动力系统。

核心主张是：

1. 语义不预设为一个固定向量，而是在输入、上下文和组件作用下逐层展开的过程。
2. 输出不是单一开关，而是知识、逻辑、风格、格式、终止和候选答案等多个场的竞争结果。
3. 真正的机制对象不是某个静态状态本身，而是从条件和状态到后续状态及输出变化的有向因果边。
4. 复用已经得到多类局部观测支持，但“为什么复用”“是否最优”仍是待检验假说。

该框架尚未完成，不应被表述为已成立的统一理论。

## 测试原理与公式

### 四状态绑定效应

```text
I_bind = 1/2 [(m_orig,post - m_orig,pre)
              - (m_swap,post - m_swap,pre)]
```

该设计用于消除候选静态偏好、时间方向偏好和档案格式偏好，保留真正的“时间条件到实体选择”效应。

### 自然状态转移

```text
X_(l+1) = F_l(X_l; q, c, Θ)
```

其中 `X_l` 是第 `l` 层状态，`q` 是查询条件，`c` 是上下文，`Θ` 是模型参数。研究对象是状态如何变化，而不是仅测量某个静态向量的位置。

### 同路径干预响应

```text
ρ_l(α) = M(F_>l((1-α)X_l^a + αX_l^b))
```

在同一执行路径内，将条件 `a` 的状态向条件 `b` 插值，并观察候选 margin 或真实生成如何变化。

### 机制边闭合门

```text
E_(u→v) = I ∧ S ∧ N ∧ C ∧ P ∧ R
```

一条机制边必须同时满足：

- `I`：身份等价，no-op 或自写回不产生仪器漂移；
- `S`：充分性，状态移植能够选择性改变目标；
- `N`：必要性，消融会破坏对应能力；
- `C`：特异性，无关任务和负控制不被同样破坏；
- `P`：独立预测，在留出材料上预先预测结果；
- `R`：重复，在独立材料或模型上再次成立。

## 下一项关键任务

当前硬伤是：深度 0.7 的 donor 仍有约三成样本不能翻转答案，两个 Qwen3 尺寸也没有共同通过的充分深度。

下一项可证伪任务是对齐 **候选首次分叉的决策边界**：

```text
冻结四状态材料与候选序列
→ 定位候选共享前缀和首次分叉 token
→ 建立同路径 no-op 基线
→ 扫描分叉位置前后的状态转移
→ 必要性消融
→ 充分性移植
→ 匹配负控与特异性测试
→ 独立材料预测
→ 跨尺寸与跨架构重复
→ 真实生成闭合
```

## 研究纪律

1. **先行为，后内部**：行为门未通过时，内部观测不能解释为目标机制。
2. **先相关，后因果**：差分、余弦、probe 和热点只提供候选，不能替代干预。
3. **先仪器，后机制**：数值健康、no-op、自补丁和路径等价必须先通过。
4. **预注册与硬停止**：实验对象、阈值、分区和负控在运行前冻结；失败后不事后改门。
5. **独立确认**：discovery、confirmation 和留出预测使用不重叠材料。
6. **分账记录**：材料、行为、hidden 相关、组件因果和真实生成分别记录，不能越级升级。

## 证据等级

客户端和研究记录统一采用以下证据链：

1. **研究对象冻结**：任务、材料、候选、分区、负控和哈希可审计。
2. **数值与仪器资格**：运行路径、精度、no-op 和自补丁满足身份等价。
3. **行为通过**：目标效应稳定超过候选先验、模板和 matched-null 负控。
4. **Hidden 重复**：层间状态事件在独立材料或模型中重复。
5. **组件与状态因果**：干预选择性改变目标 margin，并通过必要性和充分性检验。
6. **预测重复**：预注册结果在留出材料和模型上成立。
7. **生成闭合**：干预稳定改变真实生成输出，并可通过自然重算或状态恢复复原。

任何较低等级结果都不能自动升级为更高等级结论。

## 可视化客户端

客户端以 3D 主空间为核心，理论分析和自动研发作为独立工作界面。

### 3D 机制工作区

主空间保留 Layer 3D 模型和组件细节模型，围绕 Layer 提供三种视图：

- **机制观察**：查看真实前向传播、层内事件和候选竞争；
- **证据比较**：比较原始、反事实、干预和匹配负控制；
- **成果展示**：只显示达到声明证据等级的重复或因果结果。

底部机制工作区显示候选差值、反事实、干预结果和数据来源。缺少实验数据时必须显示“暂无数据”，不能用演示值补齐。

### 理论分析

- **项目大纲**：核心猜想、系统假设、三级破解目标、难点和证据边界；
- **语言分析**：模式本体、相对编码、复用差分、多尺度组织和研究图谱；
- **智能理论**：三条研究路线的理论总结、证据等级和可证伪任务；
- **模型与系统**：六阶段进展、测试公式、模型运行和系统状态。

### 自动研发

自动研发作为独立侧边栏运行：

```text
任务定义
→ 研究对象与仪器门检查
→ 协议和负控冻结
→ 单模型顺序运行
→ 辅助 AI 审阅
→ 主 AI 综合
→ 生成标准结果文件
→ 人工确认或进入下一轮
```

AI 可以提出假设、编写脚本和整理证据，但不能自动把探索性结果升级为正式机制结论。

## 标准结果格式

新的测试脚本应直接生成客户端可读取的结构化结果：

```text
manifest.json       实验身份、Phase、模型、协议版本和文件哈希
samples.jsonl       输入样本、分区、目标、候选和负控
metrics.json        行为指标、仪器指标、证据门和失败原因
events.jsonl        层、位置、组件和 hidden 事件
```

## 谨慎结论

项目已经积累了候选竞争、条件化内容、复用拓扑、动态路由、行为门、数值校准、晚层状态跃迁和序列路径对齐等拼图，也建立了更严格的反事实与因果验证纪律。

但目前还没有找到跨模型稳定成立的完整语言机制，没有完成真实生成闭合，也没有完成智能统一理论。当前最重要的进展，是研究对象从“某个向量或热点是什么”推进到了“状态如何沿真实决策路径变化，以及哪条因果边能够通过完整证据门”。
