# OpenOne / AI2050

OpenOne 是一个面向语言机制、神经网络原理与通用智能的逆向工程研究项目。

项目试图回答一个核心问题：

> 深度神经网络如何把知识网络、逻辑推理和语法规则融合为稳定的语言能力？它的底层编码、动态运行和形成机制是什么？

当前项目已经积累了大量行为、HiddenState、Q/K/V、干预与跨模型结果，但尚未找到一个完整闭合的语言编码机制，也尚未完成智能理论或 AGI 系统。

---

## 一、路线分析

### 1. 基本判断

1. 人脑依靠高效可塑性形成语言、视觉、听觉、身体控制等能力。可塑性可能是智能形成的关键机制之一。
2. 深度神经网络通过大规模训练获得了稳定语言能力，说明它至少恢复了语言结构中的一部分可计算规律。
3. 对深度神经网络进行逆向工程，恢复语言从输入条件到内部状态、再到输出行为的完整计算链，是探索语言数学结构和神经网络原理的一条可执行路线。
4. 如果进一步解释这些结构如何通过训练形成，才可能从语言编码推进到可塑性机制、智能理论和新的 AGI 架构。

项目主路线因此定义为：

```text
语言模式图谱
→ Embedding / HiddenState 完整场
→ 条件化内部算子
→ 知识、推理、语法的组合机制
→ 网络可塑性与形成规律
→ 可预测、可干预的智能理论
→ AGI 工程
```

### 2. 可以借鉴的大脑视角

大脑不同区域可能共享兴奋、抑制和可塑性等底层机制，同时因连接、参数、输入输出和学习历史不同而处理不同信息；跨区域整合产生统一知觉和行为。这为研究“共享底层机制如何在不同参数下形成不同能力”提供了启发。

但必须保持边界：

- LLM 是语言计算模型，不是完整大脑；
- 目前没有证据证明 LLM 直接复制了某个脑区，或只等同于前额叶的一部分；
- 从 LLM 得到的机制必须先在模型内部完成行为、因果和跨材料验证，不能直接外推到人脑；
- 兴奋/抑制、意识整合和生物可塑性属于后续需要独立验证的研究对象。

### 3. 需要避免的误区

1. **把 LLM 当作完整大脑。** LLM 没有自然具备完整知觉、身体控制和生物意识机制，用完整脑功能解释每个 LLM 现象容易产生错误类比。
2. **从架构名称推导心理功能。** Q、K、V、Attention、MLP 是计算组件名称，不能直接命名为“请求”“地址”“语义”“意识”等功能。
3. **把热点当作机制。** 高激活、高相关、可读 probe、Top-K 坐标或漂亮几何都只能产生候选，不能单独证明必要性、充分性和特异性。
4. **把特殊网络路线当作统一理论。** 世界模型可以研究视觉与环境预测，但不能替代语言编码和可塑性机制研究；其结论也需要独立闭合，不能自动升级为通用智能原理。
5. **把小模型直接当作普遍规律。** 模型规模、训练数据、架构和 tokenizer 都会改变实现方式。小模型中的局部机制必须经过跨规模、跨架构和自然任务验证。

### 4. 路线成功标准

真正的机制必须同时做到：

- 解释已经观察到的语言行为和内部状态；
- 在冻结规则后预测未见材料、未见构式和未见干预；
- 精确改变目标能力，同时不破坏匹配负控制；
- 能够删除、调用、替换或救援目标功能；
- 在自然生成中产生预期结果；
- 明确适用范围，并能解释失败与模型差异；
- 最终说明机制如何通过训练和可塑性形成。

## 二、理论框架

### 1. 语言的工作定义：可组合模式集合

本项目暂时把语言能力统一描述为模式集合，但这里的“模式”不是简单的词表分类或相似度聚类，而是带有类型、角色、关系、上下文、变换和组合规则的可执行对象。

语言模式至少包括：

- **知识模式**：实体、类别、属性、关系和层级，例如“苹果—水果—食物—物体”；
- **任务模式**：续写、问答、分析、推理、翻译、润色、重排和代码生成；
- **语法模式**：词性、构式、依存角色、标点、边界、否定和作用域；
- **序列模式**：多个模式在时间顺序和上下文中的组合，例如“我—喜欢—吃—苹果”；
- **输出模式**：候选竞争、格式、风格、停止和生成协议。

外部语言图谱可以写成类型化超图：

\[
\mathcal G_{lang}=
(V_{form},V_{concept},V_{role},V_{context},
E_{relation},E_{transform},E_{compose})
\]

它的目标不是枚举所有句子，而是找到能够生成大量语言现象的基本对象和组合操作。

### 2. LLM 为什么可能有效

#### 注意力：条件化相对计算

Attention 允许当前位置根据上下文选择其他位置的信息。概念身份因此可能部分来自关系网络中的位置、角色和当前任务，而不是来自一个孤立、固定坐标。

#### 多 Layer：逐层状态更新

多层结构允许输入表示不断被更新：识别任务、连接上下文、组合关系、形成输出条件并参与下一个 token 的竞争。研究对象应是完整更新过程，而不仅是某层静态表示。

\[
H_{l+1}=F_l(H_l;x,c,\Theta)
\]

其中 \(x\) 是输入，\(c\) 是上下文与任务条件，\(\Theta\) 是模型参数。

#### 自回归训练：统一输出目标

自回归训练把知识调用、上下文分析、语法约束、风格控制和输出协议共同压入“预测下一个 token”的训练目标，使多种能力能够在同一网络中竞争和协作。

它可能产生：

- 族内、族间和全局模式的多尺度组织；
- 随上下文变化的动态功能位置；
- 知识、逻辑、语法、风格和输出协议的多场竞争；
- 可复用结构与样本特异差分的共同存在。

“深度思考”或长推理模式说明模型能够通过特定上下文和训练形成不同的推理运行制度，但这还不能证明存在一个固定的高优先级底层模块。

### 3. 当前内部结构假设

1. **相对编码**：模式身份可能由它与其他模式的关系、角色和作用决定。
2. **复用与差分**：不同语言对象可能共享部分计算骨架，再通过条件相关差异形成独特功能。
3. **多层级、多维度处理**：知识、句法、段落逻辑、风格和输出协议可能在不同时间、位置和组件中并行作用。
4. **条件化路由**：同一坐标、head 或 token region 在不同任务中可能承担不同作用。
5. **分布协同**：有效机制可能是多个 token、层、head 和坐标的协同集合，而非单个神经元或固定小集合。
6. **功能约束高于物理位置**：不同模型可能实现相同功能约束，却使用不同层位、head 和坐标基底。

### 4. 实现粗糙度

模型规模、数据、训练目标和架构限制会产生噪声、捷径、冗余和模型特异实现。受控微世界中的强结果可能只是一种任务实现，不代表自然语言普遍机制。研究必须同时保存正结果、反证、失败条件和替代解释。

## 三、具体工程

### 1. 完成语言图谱

语言图谱分为三个核心系统：

#### 知识网络

记录实体、类别、属性和关系，例如：

```text
苹果 → 水果 → 食物 → 物体
苹果 → 颜色 / 大小 / 味道 / 生长方式
```

目标是研究类别层级、属性绑定、关系调用、复用和差分的计算机制，而不是只建立传统知识库。

#### 分析与推理系统

系统研究续写、润色、翻译、重排、问答、代码生成、单步推理、多步推理和长距离调用。每个任务都要拆成明确的输入操作、角色、不变量、变化量、正确输出和错误类型。

#### 语法系统

记录名词、动词、形容词、副词、介词、标点、构式、依存角色、否定、作用域和语序变化，分析语法规则如何在序列中形成和调用。

#### 序列与多维分析

以“我喜欢吃苹果”等自然序列为例，同时记录：

- token 与词性；
- 主体、动作、对象等角色；
- 概念和知识关系；
- 语法构式与顺序；
- 上下文条件；
- 生成目标和候选竞争。

语言图谱最终应能自动生成 discovery、confirmation 和 lockbox 数据，而不是依靠手工挑选少量句子。

### 2. 完成 Embedding—HiddenState 全场图谱

对每个行为合格的语言操作，保存所有 token、所有层、所有物理坐标以及必要的 Q/K/V、Attention、MLP 和输出读出数据。

基础场包括：

\[
H_{l,t,j}
\]

原始 HiddenState；

\[
\Delta_l H=H_{l+1}-H_l
\]

层更新；

\[
\Delta_fH=H(f_{on})-H(f_{off})
\]

条件差分；

\[
U_{f,u,l,t,j}=Delta_lH(f_{on})-\Delta_lH(f_{off})
\]

条件相关的局部更新差分。

工程原则：

- 原始数据保存全坐标，Top-K 只用于显示；
- 同时保留真实物理顺序和预先冻结的响应排序；
- 每个值都能追溯到模型、输入、token、layer、dtype、代码和工件哈希；
- discovery 中发现的排序和阈值不能在 lockbox 中重新调整；
- 没有真实数据时显示缺失，不使用演示值填充研究结果。

### 3. 完成语言图谱与内部场的关联

目标不是寻找“苹果神经元”，而是寻找外部语言操作与内部条件算子之间可预测、可干预的对应：

\[
\Psi_\theta(O_f^{ext}(x))
\approx
G_f^{int}(\Psi_\theta(x);x,r,l,c)
\]

其中内部算子依赖样本 \(x\)、角色 \(r\)、层 \(l\) 和上下文 \(c\)。

关联机制必须依次通过：

```text
行为资格
→ 仪器与数值资格
→ 完整场重复
→ 条件选择性
→ 充分性
→ 必要性
→ 错角色/错关系/错位置负控制
→ 未见预测
→ 自然生成
→ 跨模型功能复现
```

### 4. 分布式测试闭环（dist_protocol v3）

大量测试只有在「可合并、可复核、可做留出预测」时才会累积成机制证据。分布式测试按下面的闭环组织，实现在 `shared/dist_protocol/`，中心节点服务在 `deploy/distributed_service.py`：

```text
生成式模板（句式框架 × 填充词表 × 因子水平）
→ 按填充切分 discovery / confirm / lockbox，留出句式进 lockbox_frame
→ 试跑行为门（模型答不对的条件格不进入内部分析）
→ 冻结（design_sha 固定语料、runner 与预注册阈值）
→ 分片派发到 GPU 节点
→ 节点回传充分统计量 + 行为结果 + 金丝雀摘要
→ 中心按「模型快照 × 精度」精确合并（金丝雀漂移、审计驳回的结果不进入）
→ η² 分解 / 因子方向 / 格均值结构
→ 留出预测：discovery 方向在未见词表、未见句式上是否达到预注册阈值
→ 逐样本规律分析（analysis.v1）：置换检验、句式不变性、可加性、词身份与长度混杂 → 3D 响应空间与规律陈述
→ 证据门链判定；证据等级仍在 Research OS 人工登记
```

关键设计：

- **生成式模板**（`template_grammar.v1`）：一个模板族 = 若干句式框架 × 若干填充；每个组合生成一条样本，条件 = 框架水平 ∪ 填充水平。内置模板族见 `shared/dist_protocol/grammars/`（知识上下位、属性绑定、施事/受事 × 构式、否定 × 语气），在客户端「研发 · 模板工作室」编辑和预览。
- **切分防泄漏**：按填充词确定性切分，同一填充的全部句式落在同一划分；lockbox 的词汇从未参与发现。
- **可合并统计量**：节点不回传摘要，而是回传每个 (划分, 条件格, 层, 维) 的 n、Σx、Σx²。这些量可以相加，所以多节点合并后的 η² 与单机在全部样本上计算的结果一致。
- **金丝雀**：每个模板包附带固定输入；同一模型快照和精度下，各节点的金丝雀向量摘要必须在容差内一致，否则该结果标为漂移并排除。
- **证据门链**：行为 → 仪器 → 重复 → 留出复现 → 未见词表预测 → 未见句式预测 → 跨模型 → 选择性/充分性 → 必要性与负控制 → 自然生成。前 7 道由分布式协议自动判定，后 3 道需要干预或生成实验，当前显示「未运行」。门按顺序判定。
- **验收指标**：预测记分板中 discovery 方向在 lockbox / lockbox_frame 上的复现分数（与冻结阈值比较），以及跨模型的功能结构一致性。它衡量「对未见材料的预测能力」，不等于机制闭合。
- **逐样本向量（items.npz，`items.v1`）**：runner 默认同时保存每条样本在各采样层的向量（float16；超过 48MB 时用以语料种子固定的 JL 随机投影降维，同一模板族各分片投影一致）及条件、划分、填充、句式、token 数、作答对错。中心按 `results.sha` 去重拼接各分片。
- **模式族规律分析（`shared/dist_protocol/analysis.py`，`analysis.v1`）**：只在 discovery 上拟合，在 confirm / lockbox / lockbox_frame 上检验。每层计算校正迹 η²（ε²，因子与词身份）、白化空间中的因子方向复现 cos 与最近质心探针准确率、按单位（填充词 / 句式 / 样本）整体打乱标签的置换零分布、句式不变性矩阵、split-half 可靠交互（可加性）、词身份超额方差、格内长度偏相关；再按代码中固定的判据（`CRITERIA`，随结果返回）生成「支持 / 未支持 / 注意 / 描述」规律陈述。3D 坐标为 discovery 拟合的 LDA（按因子）与 PCA，层堆叠视图用 Procrustes 对齐相邻层。接口：`GET /api/analysis/{tm_id}?bucket=&gate=1`。
- **方法验证与负对照**：`tests/dist_protocol/test_analysis.py` 用合成模式植入已知规律（早层句式与词身份主导、中层类别可读且跨句式不变、组合可加），检查分析能否找回；再打乱类别标签，检查不会报告「支持」。

#### 一个模式族的完整流程

`scripts/run_language_family.py` 用中心 HTTP 接口和 `deploy/node_agent.py` 把一个模式族从头跑到报告，数据与客户端看到的是同一份：

```text
① 文法预览 → ② 冻结试跑版 → ③ 节点跑试跑分片（行为门；达标格比例低于 --min-pilot-pass 时停止）
→ ④ 冻结正式模板 → ⑤ 逐分片采集（node_agent --tm-id）→ ⑥ 中心合并 + 规律分析 → ⑦ 写报告（research/family_runs/）
```

```powershell
# 真实模型（先启动后端 server.server，:5001 已挂载中心路由）
python scripts/run_language_family.py --family KN-ISA --center http://127.0.0.1:5001 `
  --model-path D:\AI2050\Ai2050-OpenOne\models\hf\qwen3-4b --model-id qwen3-4b --dtype bf16
```

完成后在客户端「空间 · 实验响应」选择该模板与模型桶，查看 **3D 响应空间** 与 **规律分析**。

#### 在客户端一键运行：研发 · 自动测试

「研发」的默认工位是 **自动测试**，用来对多个模型批量跑模式族测试，不需要敲命令：

1. **登记被测模型**：「＋ 添加模型」→ 从本机模型库（`/api/models/local`，即 `models/` 与 HF 缓存）选择或填写权重目录 →「检查」读取 config.json（架构、层数、隐藏维、权重大小，不加载权重）→ 填 model_id（进入模型桶名）与精度。被测模型必须是本机权重：只有 API 的模型拿不到内部状态，不能作为被测对象。
2. **勾选模式族**：列表来自文法库 `shared/dist_protocol/grammars/`。
3. **运行**：填管理令牌，点「▶ 运行 N 个测试」。中心为每个「模型 × 模式族」组合建一个作业，在中心所在机器上**逐个**执行（同一模型的作业连续执行，一张 GPU 同时只跑一个模型），每个作业调用 `run_language_family.py --progress` 走完 7 步。
4. **看进度与结果**：运行队列显示 7 段进度条、当前步骤、日志（可展开）、规律摘要；可取消、重跑。结果矩阵（模型 × 模式族）点击「完成」格直接进入「空间 · 实验响应」，并预选该模板与模型桶。

试跑行为门达标比例低于设置值时，该组合停在「行为门停止」，不冻结正式模板。多个模型共用同一个冻结模板（同一文法与 runner 只冻结一次），中心按模型补齐各自缺的分片，每个模型一个模型桶。作业与日志保存在 `<AI2050_DIST_DIR>/autotest/`；后端重启时运行中的作业记为「中断」，需手动重跑。

作业通过 `AI2050_AUTOTEST_CENTER`（缺省 `http://127.0.0.1:5001`；独立中心服务为其自身端口）回连中心。被测模型在子进程中加载：如果后端已通过「空间 · 实时分析」连接了一个大模型，先断开，避免显存不足。接口：`GET /api/autotest/state`、`POST /api/autotest/models|probe|batches|clear`、`DELETE /api/autotest/models/{id}`、`POST /api/autotest/jobs/{id}/cancel|retry`、`GET /api/autotest/jobs/{id}/log`。

**沙盒合成模式（只验证流程）**：中心以 `AI2050_DIST_ALLOW_SYNTHETIC=1` 并配独立的 `AI2050_DIST_DIR` 启动时，才接受 `kind=synthetic` 结果并参与合并；模型桶名带「合成·」前缀，客户端总览和实验响应显示合成横幅，报告写入 `research/family_runs_synthetic/` 并标注 SYNTHETIC。正式中心默认拒绝合成结果。驱动加 `--synthetic` 即可在无 GPU 环境走完整流程。合成结果不代表任何真实模型，不能写入研究记录。

#### 题库、研究包与语言谱图（开放参与）

任何用户都可以通过客户端连接中心：读**题库**（`GET /api/catalog`：类别 → 模式族 → 冻结版本、各模型的测试状态、领题命令、贡献者），领取分片在本地 GPU 测试并回传；下载**研究包**（`GET /api/export/{tm}?bucket=`，respack.v1 zip：corpus / agg / analysis 含 3D 坐标 / suffstats / 逐条向量）到本地观察与复算；读**语言谱图**（`GET /api/atlas`，atlas.v1）。

语言谱图（`shared/dist_protocol/atlas.py`）把各模式族的稳定特征连成跨族结构。
- **特征**：每个因子水平在各层的对比方向，在原生坐标中比较，只在同一模型内比较方向。
- **基线**：族基线与共享轴交替估计，避免共享成分经由本族平均泄漏。
- **成边**：要求两组互不重叠的词各自复现，并超过该层跨族 cos 的经验零分布。
- **共享编码轴**：用贪心生长，以留一族迁移检验。
- **概念假设**：文法 `concepts` 预注册的跨族概念（如「疑问」），留出句式的水平作为未见句式预测。
- **跨模型**：检验同一结构是否在其他模型复现。

AI 解读（`POST /api/atlas/interpret`）用 Agent 工作流的主模型读谱图摘要，输出可检验假设，一律标为「未检验」，必须写成新模式族运行后才有结论。完整规范见 [design/platform_spec_v1.md](design/platform_spec_v1.md)（测试方法、结果格式、3D 可视化方案、挖掘算法、接口、客户端四界面修改建议）。

完整设计与端点清单见 [design/client_v6_pipeline_ia.md](design/client_v6_pipeline_ia.md) 与 [design/platform_spec_v1.md](design/platform_spec_v1.md)。

> **2026-10-14 工程更新**：分布式测试协议 v3 与客户端 v6 已实现并通过离线测试（单元测试、中心服务端到端、界面交互）。内置模板族尚未在真实模型上运行，**本次更新不产生任何新的研究结果**；下文研究进展仍以 Phase 2578 为准。

当前可审计基线是 **Phase 2578：Phase2551—2577 证据终审、产物核验与下一阶段合同**，记录时间为 **2026-09-03 17:19**。Phase 只表示实验与审计批次；正式研究主轴是语言操作、构念、合同、Run、工件和证据权限。

### 1. 本轮完成的关键纠错

- 旧单关系任务中的 relation 在同一提示内保持常量，答案实际可以退化为结构化键值匹配，因此不能作为自然关系语义机制证据。
- Q、K、V 只是架构投影名称，不能根据名称直接解释为内容、地址、请求或输出编译。
- facts-value 的早期 V 效应只是在指定模型、任务和干预中的 region 级局部充分性，不是最小齿轮。
- 固定坐标提取算法失败只淘汰该算法，不能推出信息必然均匀分布于全网。

### 2. 已得到支持的结果

#### 关系和值联合必要的行为任务

项目构建了关系和值共同决定答案的四事实交叉格。经过 padding、候选索引和 token 兼容修正后，Qwen3-4B 英文新实体单步任务达到：

```text
完整输入准确率：0.868164
缺少关系：      0.500000
缺少值：        0.500000
```

这说明在该受控任务中，relation 与 value 在行为设计上共同必要。它仍是人工二元/有限候选任务，不能直接代表自然语言关系系统。

#### Qwen3-4B 的局部全坐标算子候选

在独立留出且行为合格的 Qwen3-4B 子集上，layer 0 query-slot V 的全 1024 坐标替换表现出选择性 XOR 充分性：

```text
relation 单因子 flip：0.930233
value 单因子 flip：   0.930233
双因子保持 base：     0.953488
matched-null flip：   0.023256
XOR margin：          0.906977
```

它是当前最接近“条件齿轮”的局部因果事件，但严格名称只能是：

> 模型、材料和干预条件化的全坐标因果算子候选。

#### 分布式协同边界

- 该局部事件横跨全部 8 个 KV heads；
- 单个 head 或连续 32 维块均不充分；
- H5 锚定的 7-head 压缩在跨实体留出上失败；
- 因而当前不能把机制压缩为固定单 head、Top-K 或固定小坐标集合。

#### 完整场和客户端资产

已经保存并发布七类新面板：

- Embedding/HiddenState：2560 个物理坐标；
- Q：4096 个坐标；
- K：1024 个坐标；
- V：1024 个坐标；
- 8-head 子集；
- 32 个无遗漏 V 坐标块；
- Qwen3-4B/14B 十事件因果对照。

可视化源资产与正式构建资产哈希一致。未展示的大型原始场已按合同清理，但索引、摘要和重建元数据保留。

### 3. 重要反证和未复现结果

- Qwen3-14B 在修正后的行为任务中达到完整输入 `0.810547`、两种缺失条件均为 `0.5`，但没有复现 Qwen3-4B 的选择性 layer-0 V 事件。
- Qwen3-14B 的早、中、中晚、晚四层段 V/KV 测试全部未通过完整选择性门；中晚层的高 flip 同时伴随 `0.8125/1.0` 的高 matched-null，属于非特异效应。
- 现有两跳和三跳组合任务没有获得合格行为，单步关系调用不能外推为多步组合机制。
- DeepSeek7B 和 GLM4 在本轮关系×值任务中没有通过进入同一因果比较的行为资格。

这些结果说明：功能约束可能比固定层位、head 或物理坐标更可复用，但这一判断仍是假设，而不是已证明理论。

### 4. 当前可以说什么

- 语言条件依赖输入角色、关系、值、位置、上下文和任务的联合状态。
- 在一个受控 Qwen3-4B 任务中，发现了全坐标、跨全部 KV heads 的局部充分算子候选。
- 单点、单 head、固定 Top-K 和固定小联盟不足以解释该事件。
- 相同任务能力可以在更大模型中以不同内部实现出现，物理位置不能直接跨模型对齐。
- 完整场、因果结果、负控制和失败复现可以在客户端中统一检查。

### 5. 当前不能说什么

- 尚未破解自然语言的知识网络、逻辑推理和语法融合机制；
- 尚未发现跨模型稳定的最小计算单元、固定语言向量或完整相对编码规则；
- 尚未完成逐 token、逐 head、逐坐标的 source—recipient 中介链；
- 尚未证明必要性、自然生成闭环或多跳组合；
- 尚不能把模型结果外推到人脑可塑性、意识或完整智能理论；
- 尚未形成任何新的数学闭合。

### 6. 当前最强理论拼图

当前最稳妥的工作对象不是固定语义向量，而是条件化有向响应图：

\[
\mathcal G(x,q)=
\{(l,h,j\rightarrow a,c):
\Delta z_y\text{ 在匹配控制下稳定且可干预}\}
\]

候选机制由 layer、head、source token、recipient token、coordinate 和上下文共同定义。Qwen3-4B 的全坐标 XOR 事件支持这种研究对象具有价值，但跨规模失败说明其物理实现不是普遍定律。

### 7. 下一大阶段

下一阶段不再追逐单个高翻转区域，而是：

1. 重建 token 等长、四种词面均行为合格的四选一关系任务，使错误类型不再自动等于 donor 答案；
2. 在 Qwen3-4B 和 Qwen3-14B 上分别冻结独立 lockbox；
3. 冻结 `relation × value × role × context` 事件，保存逐 token 而非 region 均值的全坐标场；
4. 同时使用正确 slot、错 slot、错 relation、错 value 和同损伤剂量 null 定义选择性；
5. 先建立功能图，再寻找物理坐标联盟；
6. 依次在新实体、新关系词表、新 surface、新语言上验证，无需重新发现规则；
7. 最后才进入必要性、逐边中介和自然语言多跳/长句重排。

验收标准不是再获得一个高 patch flip，而是：

> 使用同一套冻结规则，准确预测留出场结构、干预方向、错误类型和自然输出变化。

详细进展以 [GLM5 研究备忘录](research/glm5/docs/AGI_GLM5_MEMO.md) 的原始记录和对应 `tests/glm5/result/` 工件为准。

## 五、研究方法与证据纪律

### 机制边闭合门

\[
E_{u\rightarrow v}=I\land S\land N\land C\land P\land R
\]

- `I`：仪器身份等价，no-op 和自补丁不漂移；
- `S`：充分性，干预可以选择性改变目标；
- `N`：必要性，删除会破坏对应能力；
- `C`：特异性，匹配负控制不出现相同效应；
- `P`：预注册预测在未见材料上成立；
- `R`：独立材料、模型或实现中重复。

### 研究纪律

1. 先行为，后内部；
2. 先仪器，后机制；
3. 先相关，后因果；
4. discovery、confirmation、lockbox 严格分离；
5. 实验对象、阈值、分区、颜色尺度和失败条件预先冻结；
6. 完整场优先，不用 Top-K 代替原始证据；
7. 模型、材料、行为、内部场、组件因果和生成分别记账；
8. 正结果、反证和未决结果全部保留；
9. Phase 只作来源坐标，不作为理论进展本身；
10. AI 意见不属于实验复现，不能自动提升证据等级。

## 九、标准研究工件

新的测试应生成客户端可读取的结构化结果：

```text
manifest.json       实验身份、模型、协议、分区和哈希
samples.jsonl       输入、角色、候选、正确答案和负控制
metrics.json        行为、仪器、因果指标和失败原因
events.jsonl        token、layer、组件和 HiddenState 事件
causal_graph.json   干预节点、机制边、充分性、必要性和救援
report.md           原理、公式、结果、限制和结论
```

客户端不得根据文件名或 Phase 猜测证据等级，必须读取 manifest 的明确字段。

分布式 v3 模板的节点产物（每个分片一份，内容寻址上传）：

```text
summary.json      状态（real / smoke / synthetic）、分片、逐格行为准确率、token 长度、本分片 η² 自检
suffstats.npz     每 (划分, 条件格, 层, 维) 的 n、Σx、Σx²（float64，可跨节点相加）
behavior.json     probe 条目的首 token 是否 top-1、排名、对数概率
canary.json       金丝雀输入的目标位置向量摘要（范数、均值、前 16 维）
```

只有 `kind=real`、design_sha 一致、金丝雀未漂移且审计未驳回的结果进入合并；合并统计是观测结果，不自动成为 Evidence。

`MechanismCase` Schema 位于 [shared/schemas/mechanism_case.schema.json](shared/schemas/mechanism_case.schema.json)。

## 十一、当前结论

深度神经网络稳定的语言能力说明语言中存在可以被训练获得的计算规律，这使逆向工程路线具有价值。当前项目已经从固定语义向量、单神经元和 Top-K 热点，推进到类型化语言操作、完整物理场、条件化响应、分布式联盟和跨模型功能约束。

但 Phase 2578 的终审同时表明：当前最强结果仍然只是 Qwen3-4B 受控任务中的局部全坐标因果算子候选；它没有跨规模复现，也没有完成必要性、逐边中介、自然生成或语言组合闭合。

因此下一步不是给已有拼图命名为新数学理论，而是继续扩大语言图谱和完整场数据，用冻结规则完成未见预测与因果闭环，让语言背后的结构从证据中自然浮现。
