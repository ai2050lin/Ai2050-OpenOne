# OpenOne / Ai2050

这个仓库的核心目标是研究一件事：

**通过研究深度神经网络中的语言原理，实现AGI。**

 

## 路线分析

实现 AGI 主要有三条路线：

1. **类脑路线**：直接研究大脑，要解决人脑神经信号极其复杂的难题。
2. **继续扩大 DNN**：人脑极为高效，实现了实时学习、准确理解、系统思维三种能力，目前无法确认DNN能否达到这种效率。
3. **逆向工程 DNN**：分析语言模型内部如何形成语言能力，破解智能原理。

为什么选择第三条路线？因为以下原因：

1. 人脑具有极为强大的可塑性，语言是大脑的完全产物，体现了人脑的各自核心特性。
2. DNN通过大量训练，部分提取了语言的数学结构。
3. 分析DNN中的语言编码机制，逆向破解大脑的运行原理和智能理论。

基于以上分析，可以得到当前最可行的AGI实现方案：

```text
DNN 语言原理分析 -> 语言编码机制 -> 人脑结构原理 -> 智能统一理论 -> AGI
```

 

## 语言特性分析

语言至少包含三个核心部分：

1. **知识网络**：具备了完整的知识体系，比如苹果、太阳、水、石头等对象，以及颜色、味道、功能等属性。
2. **逻辑推理**：具备了完整的逻辑能力，比如给出规划建议，分析文章内容，各种语言翻译等能力。
3. **语法体系**：具备了完整的语法体系，比如词语组合、句子结构、时态、语序、指代、修饰等规则。

在深度神经网络的运行中，每次只生成一个token，却可以包括三个层级：

1. **文章风格**：可以生成不同的风格，比如讨论、小说、诗歌、论文、代码。
2. **段落连贯**：每次生成一个token，但是在小说和论文中，可以看到完整的逻辑连贯性。
3. **语法规则**：生成内容完整符合语法规则，不会出现语法错误。

深度神经网络把多个规则系统放到一个系统中运行，形成一个多层级的网络系统。
我们认为破解以上能力背后编码机制，就可以完成智能理论。




## 语言编码机制

当前最可靠的机制图是：

```text
对象进入上下文
-> 形成身份和位置
-> 句式、角色、关系、规则组成当前语义场
-> 模型选择内部路线
-> 对象被重编码成关系状态
-> 候选答案进入竞争
-> 范数、格式、策略门决定能否读出
-> 输出层选择 winner
```

也就是说，模型不是简单"存了苹果=水果"，而是在当前上下文里重新计算：

```text
这个对象是谁？
它在句子里扮演什么角色？
当前问题问的是类别、属性、关系还是规则？
哪些候选答案被激活？
正确候选能否压过错误候选？
输出格式是否允许它说出来？
```

当前识别出的核心模块包括：

- **相对编码**：概念不是固定点，而是在任务、位置、候选集合中的相对差异。
- **身份与角色**：token 本身和它在句中的功能可以分离。
- **构式与格式**：句式和表面格式会影响语义路线，不是噪声。
- **操作符与作用域**：not、never、no 等更像状态变换，不是简单逻辑取反。
- **绑定**：对象-属性、对象-类别、对象-关系-值主要由 transformer 层计算产生。
- **候选竞争**：正确答案必须压过 old top-wrong、generic、echo、format token 等竞争项。
- **范数与读出门**：RMSNorm、final norm weight 和格式门会改变最终可见输出。
- **路径路由**：同一语义任务在不同 prompt 中可能走不同内部路径。
- **条件化状态变换**：最新结果指向 layer-to-layer update，而不是单点向量移植。

**最新突破（Phase 940-944）**：首次完成了从语义坐标到 MLP 通道齿轮到 boundary movement 的完整桥接链。在 qwen3 color en→en 任务上，定位到 hidden 36/channels 2509,16,249，activation gap +3.70，slope gain +0.69。

当前最严格的限制：

1. 很多证据仍是 projection-level evidence，不等于因果闭合。
2. 单点 residual patch 经常失败，说明状态不是简单可移植向量。
3. 候选 embedding 不正交，common/specific 分解会泄漏。
4. 三个模型 Qwen3、GLM4、DS7B 的编码策略差异很大，不能轻易提升为通用理论。
5. **跨模型闭合 = 0/72**：三模型用不同内部实现完成相同语言任务，共同机制语言尚未找到。
6. **自然门控缺失**：所有有效干预都是人工缩放，模型自然状态下不启动这些齿轮。
7. **strict-clean 自然生成 = 0**：语义答案已被推出但模型不停止。
8. **行为稳定性脆弱**：仅在极窄窗口中存在稳定行为。




## 智能理论

本项目对智能的工作定义是：

**智能是一个系统在持续输入中形成相对状态网络，并能根据目标、上下文和反馈，对对象、关系、规则和候选行动进行重编码、选择和修正的能力。**

更通俗地说：

**智能不是存了多少知识，而是能否把当前问题放进正确关系网络里，找到可执行路径，并在竞争答案中选出最合适的一个。**

一个智能系统至少需要七层能力：

1. **特征提取**：从文字、图像、声音、动作中提取对象和差异。
2. **相对编码**：把对象放进关系网络，而不是只贴固定标签。
3. **绑定**：把对象、属性、类别、关系和值绑定成可操作状态。
4. **路径路由**：根据任务选择检索、推理、翻译、解释、生成或规划路线。
5. **条件化变换**：每一步都根据上下文改变状态更新规则。
6. **候选竞争**：生成多个可能答案或行动，并比较优劣。
7. **反馈学习**：根据错误和新信息修改路径、关系和优先级。

现代 DNN 已经具备其中一部分：大规模相对编码、局部绑定、关系检索、候选竞争和复杂读出门控。

但它们仍缺少：

- 稳定实时学习；
- 可控的中间状态传递；
- 可验证的多跳组合闭环；
- 抗格式、echo、policy gate 干扰的语义读出；
- 真正可编辑、可因果定位的关系图谱。

AGI 的关键突破可能不是简单扩大模型，而是找到：

```text
相对编码 + 条件化变换 + 可塑性更新
```

这三者的基本结构。




## 数学体系

当前数学体系仍是研究中的框架，不是最终定理。它的目标是用尽量基础的方式描述语言状态如何形成和变化。

最核心的第一性原理表述是：

**智能系统不是存储孤立概念，而是在上下文中把对象、关系、规则、候选和目标重新编码成可读出的相对状态。**

一个隐藏状态可以粗略拆成：

```text
h = 身份 + 角色 + 格式 + 构式 + 操作符 + 作用域
  + 知识锚定 + 绑定 + 候选竞争 + 范数/读出门 + 未建模项
```

候选竞争可以粗略理解为：

```text
候选族先整体被激活
-> 每个候选获得自己的 specific 分数
-> 正确候选必须超过旧错误候选
-> 格式门、echo 门、策略门不能抢走输出
```

类别边界不是一层写入，而更像：

```text
类别边界 = 多层写入 - 多层抑制 + 末层释放 + 读出增益
```

连续属性也不是单一大小轴，而是：

```text
对象知识锚定 + 上下文规则调制 + 层间状态变换 + 候选词读出
```

为了避免把相关性误认为机制，本项目把证据分成六级：

1. **相关证据**：距离、聚类、投影相似。
2. **projection node**：能读出方向或候选排序。
3. **transition node**：层间 update 产生或增强目标信号。
4. **component causal node**：attention、MLP、head 或 channel patch 改变 margin。
5. **hidden causal repair node**：最小隐藏状态修补能改变 winner。
6. **generation closure**：真实生成稳定改变，并通过随机、范数、模板对照。

当前研究已经从 Level 2 推进到部分 Level 3-4。GLM5 路线 Phase 944 在 qwen3 上达到 Level 4 component causal evidence（MLP 通道齿轮 intervention 改变 boundary movement）。GPT5 路线建立了行为资格→物理记录→密封预测→因果闭合→神经元定位的证据等级阶梯。但跨模型闭合仍为 0，尚未达到 Level 6 generation closure。




## 研究历史

当前 GPT5/GLM5 研究可以压缩成九个阶段：

### 阶段一：基础方向分解与操作符机制（Phase 301-312）

分解 identity、role、frame、construction、operator、scope、norm、position。早期发现一些方向分解有伪影，后来改用更严格的 construction、position、norm 控制。

核心收获：语言编码可能有两类结构，一类接近正交子空间，一类是共享主方向加微小差分读取。

### 阶段二：关系网络、上下文激活与否定修正（Phase 313-321）

分析 W_U 读出、关系保持、属性/功能/否定关系和随机基线。

核心收获：语言关系不是静态表，而是条件激活的相对关系网络；否定更像语义极性偏移，不是严格逻辑取反。

### 阶段三：绑定机制、层归因与 MLP 主导路径（Phase 322-365）

研究对象-属性绑定、slot、temperature、interaction、层归因，以及 attention 和 MLP 的分工。

核心收获：binding 主要由 transformer 层产生，embedding 贡献很小；MLP 经常承担主要绑定计算，attention 更多参与检索、路由和边界写入。

### 阶段四：范数、类别中心、连续属性与规则调制（Phase 366-414）

研究范数掩蔽、RMSNorm、类别中心、连续属性、规则强度和候选词读出。

核心收获：连续属性更像"对象知识锚定 × 上下文调制 × 候选词读出"，不是简单等级轴。

### 阶段五：自然运输、关系槽位、类别边界和读出接口（Phase 415-499）

研究虚构对象、自然运输方向、属性中介、类别边界、shared/private 通道和读出接口。

核心收获：类别边界是跨层累积，不是单层写入；存在支持层、反对层、共享语义抑制和末层释放。

### 阶段六：正交语义场、轨迹价值与生成策略门（Phase 500-567）

统一 GLM5/GPT5 路线，研究 orthogonal semantic field、trajectory、path value、generation closure、paraphrase gate 和 scaffold route。

核心收获：语义状态和生成策略门必须分开。模型"知道"不等于一定能按要求输出。

### 阶段七：Norm gate、路径瓶颈与格式/echo 机制（Phase 568-574）

追踪 pre-layer source、final norm gate、norm weight 维度、path bottleneck、format gate 和 echo suppression。

核心收获：读出瓶颈包括语义状态、格式门、echo 路径、norm gate 和 clean output policy。

### 阶段八：闭合语义微世界与检索-推理闭包（Phase 575-583）

构造闭合微世界，隔离 object-category、object-relation-value、规则检索、两跳组合和 yes/no 极性读出。

核心收获：检索不等于推理。组合瓶颈主要在中间状态选择和极性读出，而不是简单缺少检索。

### 阶段九：状态门修复、值候选竞争与条件化变换图谱（Phase 584-594）

研究 state gate、hidden patch、distributed relation-filter、value winner competition 和 ranking atlas。

核心收获：正确值排序更像某些层、位置、组件根据上下文生成的 update，而不是可直接移植的静态向量。理论从"静态方向 patch"升级为"条件化状态变换图谱"。

### 阶段十：语义方向—MLP通道齿轮—边界移动桥接（Phase 852-944，GLM5路线）

GLM5 路线从 Phase 852 推进到 Phase 944，完成从抽象语义因子到具体组件齿轮的完整因果链。

核心收获：
1. **MLP通道齿轮桥接**：Phase 940-944 在 qwen3 color en→en 上，从共识残差坐标定位到 hidden 36/channels 2509,16,249 的 MLP 通道齿轮，activation gap +3.70，slope gain +0.69。这是全项目最强的正结果。
2. **EOS-vs-a 边界齿轮**：Phase 918-920 在 GLM4 L39 MLP 中精确定位有符号边界子空间。
3. **GPT5 行为资格门**：Phase 428-429 建立内容/接口/改口/终止四分离门控系统和证据等级阶梯。

### 阶段十一：跨模型审计与方向收敛（Phase 429+，GPT5路线）

GPT5 路线完成跨模型审计，精确守恒验证 1248/1248 通过。

核心收获（也是核心瓶颈）：
- 关系签名观测复现 27/27，但因果关系载体 0/9——看到的模式是"足迹"不是"发动机"。
- 跨模型 72 机制闭合 = 0/72——三模型用不同内部实现完成相同语言任务。
- 单神经元因果闭合 = 0/72——神经元不是正确的研究对象。
- 行为稳定性脆弱：Qwen3 仅在无示例合同下通过，交叉示例后消失。

### 阶段十二：全历史交叉分析与三条突破路线（Phase 945）

基于 AGI_GLM5_MEMO_SUMMARY.md（Phase 20-940 全部历史）的系统审计，
从 1300+ Phase 中筛选出 12 个最关键发现，提炼三条突破路线。

**12 个关键发现（四维评分排序）**：
- 第一梯队：#1 语义→MLP通道→边界桥接（13分）, #2 GLM4 L39 EOS-vs-a齿轮（11分）
- 第二梯队：#3 可解码≠因果（14分，改变方法论）, #4 Jacobian暗物质（10分）,
  #5 CleanCausalEdge框架（12分）, #6 I-R-F-O分解+否定算子稳定（12分）,
  #7 Attn-MLP契约差异（13分）, #8 Protocol场压语义场（13分）,
  #9 Blocker子场+公共骨架（11分）
- 第三梯队：#10 W_U候选竞争接口, #11 小方差大因果, #12 target-lift边界迁移

**三条突破路线**：
- **路线A**：跨模型复现Phase 944的三层桥接（语义→通道→边界）
- **路线B**：从否定算子扩展到逻辑算子族，建立语言算子代数
- **路线C**：攻克Protocol场，让语义场在自然生成中胜出

**核心洞察**：语言编码是"场博弈"系统（语义场+Protocol场+候选场+EOS场），
正确对象是"因果状态等价类 + 场间转移算子"。

## 当前最重要的下一步

Phase 945 全历史交叉分析后，确定了三条突破路线，对应的执行计划（Phase 946-950）：

```text
Phase 946（路线B起点）：三模型否定算子复现 + 扩展到量化/模态算子族
Phase 947（路线A扩展）：GLM4上复现color语义→MLP通道齿轮三层桥接
Phase 948（路线C起点）：Protocol场token组成全量审计 + 激活来源追踪
Phase 949：跨方向交叉验证——三条路线的发现是否指向同一机制
Phase 950：根据Phase 946-949结果确定主攻方向
```

核心逻辑：继续扫描更多候选组件的边际价值已近零。必须用三条路线并行推进：
- 路线B测试"语言算子代数"假设（理论突破潜力最大）
- 路线A测试"桥接结构"的跨模型通用性（最可操作）
- 路线C直接攻克"自然生成不停止"的最大现实瓶颈

核心风险：三条路线可能全部失败——操作符代数不封闭、GLM4桥接不可复现、Protocol场不可修改。如果发生，需要重新审视整个研究方向。

## 谨慎结论

当前理论已经形成比较清晰的主线：

```text
语言智能 =
相对编码网络
+ 对象知识锚定
+ 关系/规则检索
+ 条件化状态变换
+ 候选竞争
+ 范数/格式/策略读出门
```

但它还不是完成态理论。

两年多、1300+ Phase 的研究得出最关键的结论：

**语言编码机制不是单个概念向量、单个神经元或单条路径，而是"因果状态等价类 + 条件化状态转移算子 + 动态路由 + 共享终端接口"组成的系统。**

目前已系统性排除了：单个神经元、单个注意力头、单个通道、固定语义方向、组件范数、总层更新、单条动态路线、单个查询位置状态、局部关系签名、宽事件区间、峰值层流水线、完整状态续跑、线性方向注入、静态向量闭合、角色主导假设——共 15 类候选对象。

最核心瓶颈仍是跨模型闭合 = 0/72。三模型用不同内部实现完成相同语言任务，共同机制语言尚未找到。

最关键突破是 GLM5 Phase 944 的 MLP 通道齿轮桥接（qwen3 color，activation gap +3.70），这是当前最接近可操作机制的发现。如果能在 GPT5 路线的盲化框架下被独立复现，将是两条路线首次交汇。

Phase 945 全历史交叉分析揭示：语言编码本质上是"场博弈"系统——
语义场、Protocol场、候选场、EOS场同时竞争。
真正的数学对象不是单个神经元或向量，而是"因果状态等价类 + 场间转移算子"。
下一个突破口可能在"否定算子代数"（路线B）或"Protocol场攻克"（路线C）。
