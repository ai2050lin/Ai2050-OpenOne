# 三、生物脑不是“固定线路”


# 四、脉冲神经网络（SNN）真正关键点

# 五、STDP才是真正关键

SNN里最核心机制：

# STDP（Spike-Timing-Dependent Plasticity，脉冲时序依赖可塑性）

核心规则：

```text
A先于B发放
→ A-B连接增强

B先于A发放
→ A-B连接减弱
```

即：

# 时间顺序决定连接结构

注意：

这与Transformer非常像：

Transformer：

```text

→ attention变化
→ 路由变化
```

SNN：

```text
spike顺序
→ synapse变化
→ 路由变化
```

本质高度一致。
