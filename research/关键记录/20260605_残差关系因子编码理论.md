# 一、为什么这个名字最合适

你的框架核心不是单纯研究：

```text
词向量
神经元
某一层
某个方向
```

而是研究：

```text
语言关系如何被分解成多个因子，
并在 residual stream（残差流）中编码、传播、压缩、归一化、读出。
```

所以名字里必须包含三个关键词：

```text
残差
关系
因子
```

分别对应：

## 1. 残差

因为目前研究已经确认，真正承载语言机制的不是单层输出，而是：

```text
residual stream（残差流）
```

也就是跨层持续存在、被不断写入和修改的状态空间。

---

## 2. 关系

因为语言编码的核心不是孤立词，而是关系：

```text
apple-red（苹果-红色）
not-happy（否定-高兴）
open as verb（open 作为动词）
open as adjective（open 作为形容词）
style + logic（风格 + 逻辑）
syntax + scope（语法 + 作用范围）
```

所以它是关系编码，不是词表编码。

---

## 3. 因子

因为你已经把语言状态拆成：

```text
I(identity，身份)
R(role，角色)
F(frame，句框)
C(construction，构式)
O(operator，操作符)
S(scope，作用范围)
N(norm，范数)
P(position，位置)
```

这就是因子分解。

所以最准确的名字就是：

```text
残差关系因子编码理论
```

---

# 二、这个理论的正式定义

可以这样定义：

```text
残差关系因子编码理论认为：

语言模型内部的语言表示，
不是单一词向量、单一语义方向或单个神经元活动，
而是多个语言关系因子在残差流中的动态叠加、交互、压缩、归一化和读出。

这些因子包括：
身份、角色、句框、构式、操作符、作用范围、范数和位置。
```

也可以写成公式：

```text
h_l ≈ μ_l
    + I_l
    + R_l
    + F_l
    + C_l
    + O_l
    + S_l
    + N_l
    + P_l
    + Interaction_l
    + ε_l
```

其中：

```text
h_l：第 l 层 residual stream（残差流）状态
μ_l：背景均值
I_l：身份因子
R_l：角色因子
F_l：句框因子
C_l：构式因子
O_l：操作符因子
S_l：作用范围因子
N_l：范数因子
P_l：位置因子
Interaction_l：交互项
ε_l：未解释噪声
```

# 六、一句话定名

最合适的名字是：

```text
残差关系因子编码理论
```

它的核心命题是：

```text
语言不是被编码成单个向量，
而是被分解为多个关系因子，
这些因子在残差流中动态叠加、交互、压缩、归一化和读出。
```

这个名字能覆盖你目前所有关键发现：

```text
identity / role 分解
operator 独立性
not ≠ antonym
object-attribute binding
category + object + interaction
A 类高维直接保留
B 类范数压缩编码
RMSNorm 重映射
position 迁移
norm 编码
残差流轨迹
```
