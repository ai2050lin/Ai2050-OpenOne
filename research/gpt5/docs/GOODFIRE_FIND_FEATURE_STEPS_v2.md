# 从「一个编号」到「一句说明书」

> 对 `https://already-clean.goodfire.com/` 中"找特征"全过程的逐步拆解：每步做什么、用什么参数、怎么算、产物长什么样、哪里会翻车。
>
> **阅读约定（很重要）**
> - 标「**原文**」的，是从文章里逐字摘出来的，可以直接信。
> - 标「**示例**」的数字，是我为了让你能手算核对而构造的。真实数值必须来自你自己跑的那一次。
> - 标「**建议**」的参数，是我们的工程取值，文章里没有给。
>
> 本文只讲一件事：**一个编号（如 `L18.N2047`）如何变成一句话（"它在区分水果义的苹果和公司义的苹果"）。**

---

## 0 先把三个词摆正，否则后面全错

| 词 | 到底是什么 | 数学 | 形状（qwen3-4b） |
|---|---|---|---|
| **神经元 / 通道** | MLP 中间空间的一个坐标，有固定编号 | `g_j(x) = W_gate[j,:]·x + b_j` | 一个标量 |
| **正极 / 负极** | **同一个**通道的输出分数的两端 | `P = top-k`，`N = bottom-k` | 各 k 个 token 位置 |
| **特征** | 一份说明书，是一句话 | "它在区分 A 和 B" | 一个方向向量 |

三处最容易错的地方：

1. **不存在"正极神经元"**。正极描述的是某个神经元的**样本集合**，不是一个神经元类别。
2. **不是"输入一段文字 → 找到神经元"**。方向反了。是"扫全部通道 → 挑一个有编号的 → 问哪些文字让它最大"。文字是用来建仓库的，不是触发器。
3. **特征不是从数据里"挖"出来的东西，是你写出来又被检验活下来的句子。** 它的计算载体是 Δ 这个向量，但它的内容是那句话。

| S3 | 取两极 | P、N 的地址集 | 各 k 个 | 秒级 |

## 2 逐步拆解

### S1 建激活仓库

**干什么**：让所有通道把几千段真实材料看一遍，记下它在每个字上的**原始分数**。

**算式**：对第 l 层、第 p 个位置，取 MLP 中间层非线性**之前**的值

```
g[l,p,:] = W_gate @ x[l,p] + b_gate      # 9728 维
```

**参数（建议）**：

| 参数 | 取值 | 为什么 |
|---|---|---|
| 语料段数 | 2000 ~ 5000 | 见下"坑 1" |
| 单段长度 | 256 ~ 512 token | 太短看不见长上下文现象 |
| 总位置数 | ≈ 400,000 | 2000 × 200 平均 |
| 采集层 | 先只取 1~2 层（如 L18） | 36 层全取太大 |
| 精度 | fp16 | 存得下，够用 |

**产物有多大（qwen3-4b 实测参数：hidden 2560，inter 9728）**：

- 残差流 `H`：`400000 × 2560 × 2B` = **1.91 GiB**
- 中间层 `G`：`400000 × 9728 × 2B` = **7.25 GiB**

7.25 GiB 塞不进显存和内存的舒适区。**解决办法是流式堆**：不存全量 G，边算边给每个通道维护一个 top-200 / bottom-200 的表。

```
每个通道 400 条 × (4B 分数 + 4B 地址) × 9728 通道 = 31 MB
```

**7.25 GiB → 31 MB。** 这是整个工程里最省钱的一步设计，必须做。

**勾点注意（静默错误第一名）**：残差流的 `H` 要取 `post_attention_layernorm` 的**输入**（norm 之前）。若在 `mlp` 的 pre-hook 取，拿到的是 norm 之后的值——每个位置缩放不同，Δ 会混进位置伪影，而且没法用于 steering。

> **坑 1（原文用失败换来的）**：
> *"At first we didn't include long context, **two paragraphs felt like enough**. But this accidentally made all the **long-context neurons look polysemantic**."*
>
> 语料不宽，会**系统性地伪造出多义**。这条不是精度问题，是方向性错误——它会让你把所有复杂通道都误判成"混合物"，然后一路错下去。

### S2 排序：先读哪一格

**干什么**：9728 个通道里，先读最容易读懂的。

**参数**：`k = 100`（排序用的 k，和算 Δ 用的 k 可以相同）

**算式**：集中度（coherence），用最便宜的形式

```
coh_j = ‖mean(h[P_j])‖ / mean(‖h[P_j]‖)
```

分子是"平均之后的长度"，分母是"长度的平均"。如果 k 个向量都指向同一个方向，平均之后长度几乎不变 → 比值趋近 1；如果方向散乱，平均互相抵消 → 比值很小。

**关键：这个阈值的来源不是玄学。** 若 k 个方向随机，和的期望长度 ≈ √k，平均后 ≈ 1/√k：

```
coh_random ≈ 1/√k = 1/√100 = 0.10
```

所以：

| coh | 含义 |
|---|---|
| ≈ 0.10 | **随机基线**，等于没读出东西 |
| > 0.30 | 3 倍于随机，可读（**建议**初值） |
| > 0.60 | 6 倍于随机，优先读 |

**成本对比（这是选这个估计量的原因）**：
- 两两余弦（k=100 → 4950 对 × 9728 通道 × 2560 维）≈ **5×10¹¹ 次运算**
- 均值范数比（9728 × 100 × 2560）≈ **2.5×10⁹ 次运算**

**便宜 200 倍，且单调等价。** 真正的两两余弦留到 S5 只对通过的通道算。

**示例**：9728 个通道里，coh>0.3 的有 812 个（8.3%），>0.6 的有 143 个（1.5%）。**先读这 143 个。**

### S3 取两极

**干什么**：把这个通道给分最高的 k 条和最低的 k 条摊开。

**参数**：`k = 100`（**建议** 50~200）

| 场景 | 文章用的量 |
|---|---|
| 视觉扫描总量（**原文**） | *"20 strongest responses out of **50,000 images**"* |
| 定性判断时展示几张（**原文**） | *"the **two** strongest images at each pole"* |
| 语言侧展示条数（**原文**） | *"**Top 8 firings**"* / *"top 100"* 用于分组统计 |

**这里有个非常重要的分工，很多人没注意到：判断用少，计算用多。**

- 判断"它是不是一条轴"，看**各 2 张**就够——因为对偶关系一眼可见（下详）。
- 算 Δ，必须**各 50~200 条**——因为均值差的方差要压下去。

**产物长这样（示例，`L18.N2047`）**

| 序 | 文本片段 | 位置 | z |
|---|---|---|---|
| 1 | 他把**苹果**削了皮，切成小块 | 6 | +4.82 |
| 2 | 果园里的**苹果**熟了，压弯枝头 | 5 | +4.51 |
| 3 | 这个**苹果**有点酸 | 3 | +4.37 |
| … | | | |
| 98 | **苹果**发布会定在九月 | 0 | −4.66 |
| 99 | **苹果**市值突破三万亿 | 0 | −4.87 |
| 100 | 分析师上调**苹果**目标价 | 4 | −5.13 |

左边 P，右边 N。**都是同一批语料里的真实片段，没有按语义挑过**——是模型自己的打分把它们分到两端的。

**四条操作纪律**：

| 纪律 | 数值 | 不守会怎样 |
|---|---|---|
| 有效文本数 | ≥ k/5（k=100 → ≥20 段） | 同段相邻 token 的 h 高度相关，k=100 若只来自 5 段，实际独立样本 = 5，方差被低估 4.5 倍 |
| k 下限 | ≥ 20 | 采样噪声主导 Δ，换个语料就翻盘 |
| k 上限 | ≤ 位置总数的 1% | 中间态混进来，Δ 被稀释 |
| 必须读 pre-activation | 不能读 post-ReLU | 见下 |

**为什么必须读 `g` 不能读 `a`**：ReLU 把负半轴整段压成 0，于是所有负样本并列第一，**bottom-k 取谁都行**——负极集合在数学上根本没有定义。不是"精度损失"，是结构性不可辨识。

> 你的三个模型全是 SwiGLU + SiLU，比 ReLU 更麻烦一层：`a = silu(g) · u` 是**乘积**。g 与 u 同时为负时乘积为正，两个负号抵消。只读 `a` 会把"门关着但值是负的"误判成"正极激活"。这就是**原文**说的
> *"a **double-negative regime in SwiGLU neurons** that, as far as we know, no one had noticed, and that a decomposition mixing many neurons together would likely have hidden."*

### S4 算差：整个方法唯一的算子

**算式**：

```
Δ = mean(h[P]) − mean(h[N])
```

**形状流动**：`100 × 2560` 堆成矩阵 → 各求列均值 → `2560` − `2560` = **一个 2560 维向量**。

**示例**：`‖Δ‖ = 41.3`（参照：`‖h‖ ≈ 62`）。Δ 的长度不是重点，**方向**才是。

**这一步唯一的产出是方向，不是数值。** 因为 Δ 不是 w，而是 `c·Σw`——被残差流的协方差矩阵拉歪过的 w（推导见 `NEURON_POLE_ATLAS_METHOD_v1.md` §3.4）。所以：

- Δ 的**方向** ≈ w 的方向（示例 cos 0.972）
- Δ 的**分量绝对值**与 w 完全不可比
- 跨通道比 Δ 之前必须**白化**，否则你比的是 Σ 的差异

**信度检验（这一步必须做，文章没做）**：把 P 和 N 各劈成两半，分别算 Δ_A、Δ_B：

```
示例：cos(Δ_A, Δ_B) = 0.71
Spearman-Brown 校正后全量信度 = 2×0.71/(1+0.71) = 0.83
```

**0.83 勉强能用，但不算好。** 若劈半 cos < 0.5，说明 k 太小或有效文本数太少，**必须回 S3 加量**，不要往下走——否则后面所有结论都建在一个抖动的方向上。

### S5 对偶检验：唯一能否定假设的一步

**这是全文最硬的一条规则，也是"负极"存在的全部理由。**

**原文**：
> *"The negative side tells us what distinction matters at this point in the circuit, which also makes it a **quick check on whether a grouping is real**: the V neuron's negative side is an O."*

**怎么算（把定性判断变成两个标量）**：

```
coh_P = 集中度(P)          # 正极内部一致吗
coh_N = 集中度(N)          # 负极内部一致吗
R = coh_N / coh_P          # 对称比
```

| 情况 | coh_P | coh_N | R | 判读 |
|---|---|---|---|---|
| **真轴** | 0.41 | 0.37 | 0.90 | 两极都是实数，互为对偶 → 通过 |
| **混合物** | 0.44 | 0.12 | 0.27 | 负极端近乎随机 → **A 不是真共享维度，退回 S3 重写描述** |
| **数据不足** | 0.22 | 0.19 | 0.86 | 对称但两边都低 → 不是多义，是**语料覆盖不够**，回 S1 |

**这张表就是全部方法论的核心。** 它把"我觉得它是水果神经元"这种话，变成了一个可以用两个数字否掉的命题。

**为什么"负极杀假设"在逻辑上成立**：
- 只看正极，你**永远能编出一个故事**。任何 100 条样本，人类都能找出一个共同点——这叫确认偏误，不是发现。
- 但让你说"这 100 条共同**不是**什么"，就编不出来了。负极是唯一能暴露"你猜的那个共同点根本不存在"的地方。

**原文那个决定性细节（我上一轮漏掉的，这次补上）**：`4e:55` 的两极样本里，**狗同时出现在正极和负极**。

- 正极（**原文**编号 1–6）：dog、fox、cat、car、pool table、bullet train
- 负极（**原文**编号 1–6）：**dog**、**dog**、snail、golf ball、tennis ball、clock

同一个标签，两端都有。这直接证伪了"它在识别猫/汽车/狗"这类名词式解释，**原文**的结论只有一句：

> *"pointed things drive it and round ones push it negative, **whatever the label**."*

**推论（非常实用）**：如果两极出现了**同一个词**，这是好事不是坏事——它说明分类边界不在词义层，而在更细的几何/功能层。真正的危险信号是**负极什么都读不出来**。

**另一条独立的对偶检验（留出法）**：拿排名 101–200 的"肩部"样本，投影到 Δ 上，看是否仍落在正确一侧、且顺序单调。这一步防的是"Δ 只记住了 top-100 那批样本"。

### S6 投影到输出侧：Δ 的两端是什么词

**干什么**：Δ 是 2560 维，每一维没有名字。所以不能读分量，只能**乘到输出侧去看它推哪些词**。

**算式**：

```
s = U · (γ ⊙ Δ̂)          # Δ̂ = Δ/‖Δ‖
```

| 符号 | 是什么 | 形状（qwen3-4b） |
|---|---|---|
| `Δ̂` | 单位化的轴 | 2560 |
| `γ` | 最终 RMSNorm 的增益 | 2560 |
| `U` | 输出词表矩阵 | 151936 × 2560 |
| `s` | 每个 token 的 logit 偏移 | 151936 |

**两个必须说清的细节**：

1. **`γ` 该乘，但不是决定因素（实测修正）。** Δ 在残差空间，`lm_head` 期待的是**norm 之后**的向量。忽略 RMS 的标量缩放（只均匀缩放，不改变排序）是安全的，`elementwise` 增益 γ 按定义应当乘上。但在 qwen3-4b `L30.N80` 上的实测消融显示：**乘不乘 γ，top-20 只差 1 个词（19/20 重叠）**。所以正确表述是"应当乘，但它不决定结论"——不要声称"不乘 γ 就会得到完全不同的词表"。详见 `L30_N80_WALKTHROUGH.md` §1.5.3。
2. **`U` 取哪一个，因模型而异（实测）**：`qwen3-4b` 的 `tie_word_embeddings = True`（embed 与 lm_head 同一矩阵，取哪个都行）；`Qwen3-14B` 和 `glm4-9b` 是 **False**，必须用 `lm_head.weight`。用错不报错，只会给你一个语义不通的词表——**静默错误最难查**。

**成本**：`151936 × 2560 ≈ 3.9×10⁸` 次乘加 ≈ 0.8 GFLOP，笔记本 CPU 上几十毫秒。

**产物长这样（示例，取 top-20 / bottom-20）**：

| 正端（Δ 方向） | 负端（−Δ 方向） |
|---|---|
| 削、脆、果、甜、皮、果园 | 市值、股价、发布会、iPhone |
| 熟、汁、核、摘、酸 | 库克、供应链、财报、分析师 |

**判读**：两端必须**各自通顺**，而且**互为对偶**。如果一端是"苹果、香蕉、水果"而另一端是"因为、所以、的"——那不是轴，那是"实体 vs 虚词"的通用方向，Δ 落在了无语义子空间。

### S7 steering：唯一能立刻证伪解释的检验

**算式**：在残差流上加一个沿轴的偏移

```
h' = h + α · Δ̂
```

**参数**：`α` 取 `‖h‖` 的 0.5 / 1 / 2 / 4 倍（`‖h‖ ≈ 62` → α ≈ 31 / 62 / 124 / 248）。

> **文章没有给任何 steering 强度数值**（我核对过原文，只有 "turn the neuron up"、"made the model want to go hiking" 这类定性描述）。所以 α 是我们自己扫的。

**必须双向做，这是关键**：

| α | 输出特征 | 判读 |
|---|---|---|
| +0.5‖h‖ | 几乎不变 | 太弱 |
| +2‖h‖ | 出现"削皮、果肉、酸甜" | 方向正确 |
| −2‖h‖ | 出现"财报、市值、发布会" | **对偶成立** |
| +4‖h‖ | 重复、崩坏 | 过强，别用 |

**只做 +α 是本项目已经付过代价的错误。** 如果 +Δ 有反应而 −Δ 只产生乱码，说明 Δ 不是在移动轴，而是在**破坏分布**——这两件事在行为上看起来相似，机制上完全不同。F20 的教训（读出几何 ≠ 行为控制）就落在这张表上：**几何对、行为不对**，是第四种结果，必须单独记一栏。

### S8 上下游：它在电路里接在哪

**干什么**：这个通道读什么、写什么。**线宽就是权重强度。**

**三个算式**：

| 问 | 算 | 示例 | 含义 |
|---|---|---|---|
| 它读的方向和它定义的轴一致吗 | `cos(W_gate[j,:], Δ)` | 0.83 | 高 → 它确实按自己报的轴读数 |
| 它写回残差的方向和这条轴一致吗 | `cos(W_down[:,j], Δ)` | 0.71 | 低 → **读的轴 ≠ 写的轴**，行为可能不跟着走 |
| 上游是谁 | `cos(W_down[:,i], W_gate[j,:])` 排名 | i = N881, N39, N1744 | 前三个就是它的主要供源 |

**第二行是新加的，也是最重要的一行。** 它给 F20 那条账提供了一个可算的指标：**若 cos(写, 读) 明显低于 cos(读, 轴)，那么这个通道"看得见但控不住"是有几何根据的**，不是实验失误。

### S9 定向测例 + 归族：把一格填死

**定向测例**：造最小对，只在目标维度上不同。

```
例句 A：他把苹果削了皮
例句 B：苹果发布了新手机
```

10 对，看 z 的差值和符号。**示例：10/10 符号正确，平均 z 差 +3.8。**

> **原文**用的是另一种形式：*"run **specific tests**, like checking which **store brands** it responds to"*——不是造句子，而是**枚举一个类别下的所有成员**，看它挑哪些。这更狠，因为它能发现"它其实只认某一类商店"。

**归族**：`cos(Δ_j, Δ_k)`

| 对象 | 示例 cos | 判读 |
|---|---|---|
| L17.N881 | 0.78 | 同族（相邻层） |
| L18.N39 | 0.74 | 同族（同层） |
| L16 最佳 | 0.51 | 边缘 |
| L5 最佳 | 0.21 | 不同族 |

> **这里有个 0.7 阈值的陷阱，必须纠正。** 残差流有一个巨大的公共分量（所有 h 都朝同一个方向偏），所以两个**毫不相干**的通道，Δ 的 cos 也可能是 0.4~0.5。直接套 0.7 会把一堆无关通道判成同族。
>
> **正确做法**：先减掉语料均值方向 `mean(h)` 再算 cos，并且用**同层随机通道对的经验分布**定阈值（取 +2σ 或 95 分位）。**"cos > 0.7" 只是视觉模型的旧经验，语言侧必须重定。**

**规律**：五个案例里有**两个**的转折点是"发现数据不够"，**一个**是"发现编码不同"，**一个**是"发现自动工具错了"。**只有一个是纯粹的语义洞察。** 这就是文章那句的实证基础——大部分"多义"是工具和数据的病，不是模型的病。

还有一条几乎每个案例都出现的现象，**原文**：
> *"In general attention seems to **collect on the punctuation, which we call the summary motif**."*

句末/逗号处的激活，可能是**整句的滚动摘要**，不是局部词义。所以按标点取读出位时，你拿到的可能是聚合量——这一点必须写进设计里。

## 6 失败诊断表：看到什么，说明什么

| 现象 | 诊断 | 动作 |
|---|---|---|
| 两极都很散（coh 都 ≈ 0.1） | 语料覆盖不足，或该通道确实是混合 | 先扩语料，再判 |
| 正极聚、负极散 | **不是轴**，正极的共同点是编的 | 退回 S3 重写描述 |
| 两极出现同一个词 | **好事**：边界在更细的层（几何/功能） | 换动词性描述 |

## 7 为什么一个减法就能得到答案

严格结论（推导见 `NEURON_POLE_ATLAS_METHOD_v1.md` §3.4）：若残差流近似 `h ~ N(μ, Σ)`、分数线性 `z = wᵀh + b`，则

```
Δ = E[h | z 极大] − E[h | z 极小] = c · Σ w,   c > 0
```

于是

```
Σ⁻¹ Δ ∝ w
```

**Δ 就是被协方差拉歪的权重方向；白化一下，它就是 Fisher / LDA 判别方向。**

这一条式子一次性解释了三件事：

1. 为什么玩具例里 Δ 与 w 的方向几乎一致（cos 0.972）而分量绝对值完全不可比——差的就是 Σ；
2. 为什么"跨通道比较 Δ 必须白化"不是洁癖，是硬要求——不白化，你比的是 Σ 的差异；
3. 为什么这套流程在数学上不是新发明——它就是判别分析，只是把"两类"换成了"极值样本"，并且坚持用真实数据而不是优化出来的样本。

## 8 边界：这套方法不回答什么

| 它不回答 | 要回答得靠 |
|---|---|
| 这个通道在计算中**是否必要** | 消融 / 归因，另一条线 |
| 这个概念如何跨通道聚合 | 文章没给方法（第三档风险） |
| 描述是否**语料无关** | 无法回答——换语料 Δ 就变 |
| 组合功能（多通道协同） | 单通道看不到 |
| 填图是否真的复利 | 需要画"已读格数 → 下一格耗时"曲线，文章没画 |

**最该记住的一句**：Δ 永远算得出来，**哪怕这个通道是纯噪声**。所以 S4–S9 的判据目的全部是**排除**，不是确认。它们不能证明你读对了，只能证明你读的**不是伪影**。
