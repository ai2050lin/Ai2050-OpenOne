## 0 为什么这一轮值得做

Q8-A 的 P7 是个**自打的结果**：单坐标四分类 0.780，开了诊断就垮（top-1 坐标与 zipf 的 ρ=0.802，
四组材料频率跨 4 个数量级），扣频率后 k=32 只剩 0.411。于是结论变成"类别骨架大半是频率"。

这句话目前**只有一个秩相关撑着**，而且它有个更麻烦的版本：如果这根旋钮本身就是范数，那"频率旋钮"
不新鲜（项目已知"范数预测可读性"）；如果旋钮只是"排名单调"而刻度非线性，那它就不是"一根标量"，
而是"一个被压扁的标量"。这两件事都不做，Q8-A 的这条结论就只是**排名事实**，不能当量纲用。

本轮要把它做成**有刻度的量**，并回答一个 Q8-A 没敢答的问题：**语义是不是频率的残差**。

**边界（先声明）**：全部仍为 **E1（剖面）**。B5 是**静态预检**（看旋钮能不能拧），不是干预；
真正的干预（改嵌入看行为）属 Q8-D。本轮任何一句"模型在用"都不许写。

## 1 材料（冻结）

### 1.1 三个池

| 池 | 定义 | 预期 n | 用途 |
|---|---|---|---|
| `CHAR` | `dec` 为单个 CJK 字符（U+4E00–9FFF 或 U+F900–FAFF）且 `zipf(s,'zh')>0` | ≈8 500 | 主材料 |
| `WORD` | `dec` 长度 ≥2、全 CJK、`zipf>0` | ≈16 000 | 主材料 |
| `LATIN` | `strip().isalpha()`、`len≥3`（排除 BPE 碎片 `ing`/`##ed`）且 `zipf>0` | 视词表 | **稳健性对照**（检验旋钮是不是 CJK 特有） |
| `BYTE` | `dec` 形如 `<0xXX>` | ≈1 457 | **只入 B7 与 B5 的诊断，不入任何回归** |

**主回归材料** = `CHAR ∪ WORD`（下称 `POOL`，n≈24 500）。
**理由（写死）**：全表 82% 是非 CJK 子词，`zipf` 对 BPE 碎片没有定义，混进回归等于拟合分词器。
CJK 单字与整词有干净的 `wordfreq` 定义，是唯一能谈"频率"的材料。

### 1.2 频率的两个刻度（关键区分）

`zipf = log10(freq_per_billion) + 9`。因此：

- **`zipf` 轴 = 对数刻度**。拟合 `zipf` 得到线性，等于说"旋钮按 log 频率走"；
- **`freq` 轴 = 原始概率刻度**（1e-9 … 1e-2，跨 7 个数量级，几乎全压在低端）。

**两个轴都拟合，必须并列报告 R²**。只报 `zipf` 的 R² 会把"对数刻度"误说成"线性刻度"。
这是本轮最容易出的表述错误。

### 1.3 向量定义（沿用 Q8-A，不改口径）

`E ∈ R^{V×d}` = `get_input_embeddings().weight`，float32；`μ = mean_j E[j]`，`x̃ = x − μ`（D15）。
回归一律用 `x̃`，并带截距（通过中心化 y 吸收）。

## 2 判据（7 条，每条给出统计量 / 零分布 / 阈值 / 未达阈的处理）

零分布统一口径：**标签打乱 20 次**（同一 POOL、同一维度、同一折数），报 R² 的均值与 95 分位。
`R²` 的零分布期望≈0，故本轮阈值用**绝对 ΔR²**是合法的（不是 Q8-A 那种依赖基线的 cos 差）；
但必须先打印实测零分布确认 <0.01，否则阈值作废（R-MET-33）。

### B1 刻度形状

- 统计量：以全空间 OLS 方向 `w_freq` 的投影 `t = x̃·ŵ_freq` 为读数，拟合
  `M1` 线性、`M2` 二次、`M3` 12 分箱查表（分段线性），5 折 held-out R²；
  同时在 `freq` 轴上重复 M1。
- 判决：
  - `M3 − M1 ≥ 0.05` → **SATURATING**（刻度被压扁，底部/顶部有平台）
  - `M3 − M1 < 0.02` 且 `R²_zipf(M1) ≥ 0.50` → **LINEAR_LOG_SCALAR**（旋钮 = log 频率的线性标量）
  - `0.02 ≤ M3 − M1 < 0.05` → **WEAKLY_NONLINEAR**
  - `R²_zipf(M1) < 0.50` → **WEAK_SCALAR**（旋钮只解释少部分方差，Q8-A 的 0.80 是排名不是量）
- 附带必报：`R²_freq(M1)`。若 `R²_freq ≪ R²_zipf` ⇒ 明确写"刻度是对数的"。
- **未达阈处理**：`WEAK_SCALAR` 不撤销 Q8-A 的排名事实，但**禁止**再引用"一根旋钮"表述。

### B2 维数（单标量还是几维）

- 统计量：①**坐标稀疏曲线**：按 `|ρ(coord_j, zipf)|` 排序取前 k 个坐标做 OLS，k∈{1,2,4,8,16,32,64,128,256,512,1024}，
  held-out R²；`k*` = 达到 `max R²` 的 95% 的最小 k。
  ②**PLS-1 曲线**：迭代取与残差相关最大的正交方向（k=1…32），报 held-out R² 曲线。
- 判决：`k* ≤ 4` 且 `R²(k*) ≥ 0.50` → **SINGLE_SCALAR**；`5–16` → **FEW_DIM**；`>16` → **DISTRIBUTED**。
  PLS 曲线独立判决 `pls_k*`，两者不一致即报 `AMBIGUOUS_DIM`（不得只报有利的那条，R-MTH-22）。

### B3 「旋钮是不是范数」

- 统计量：`ρ(log‖e‖, zipf)`；`cos(w_freq, w_norm)`，其中 `w_norm` = `log‖e‖` 对 `x̃` 的 OLS 系数方向；
  `R²_ctrl` = 把 `log‖e‖` 从 `x̃` 回归掉之后，`zipf` 的 held-out R²。
- 判决（**归因级，D27**）：`R²_ctrl / R²_full ≥ 0.70` → **FREQ_INDEPENDENT_OF_NORM**；
  `≤ 0.50` → **FREQ_IS_NORM**；中间 → `PARTIALLY_NORM`。
- 附必报：`R²_ctrl` 的绝对值。若 `R²_full < 0.50`，本条只作描述（B1 已判 WEAK）。

### B4 跨模型同构

- 统计量：Qwen3-4B 与 GLM-4-9B 各自跑 B1/B2/B3，比较：形状判决是否一致、`R²_zipf(M1)` 差、
  `R²_ctrl/R²_full` 差、`ρ(log‖e‖,zipf)` 差。
- 判决：三项判决全一致且 |ΔR²| < 0.15 → **SHAPE_ISOMORPHIC**；判决一致仅数值不同 → **SHAPE_QUALITATIVE**；
  判决不一致 → **MODEL_SPECIFIC**。
- 不做向量空间对齐（两模型词表不同，Procrustes 需要共享 token 且语义同构，本轮不做）。

### B5 可拧性静态预检（**E1，不是干预**）

- 统计量：δ = 1/|a|（`a` 为 B1 中 `zipf ~ t` 的斜率，即"一个 zipf 单位"的位移）。
  对 `CHAR` 随机 200 个 token：`e' = e + δ·ŵ_freq`（向高频）与 `e − δ·ŵ_freq`（向低频），
  在全表中心化 cos 下找 `e'` 的最近邻（排除自身），报 `Δzipf = zipf(nn) − zipf(e)₀` 的中位数。
- 判决：`|median(Δzipf) − 1| ≤ 0.5` 且符号正确（两侧都成立）→ **SMOOTH_KNOB**（可连续拧动，Q8-D 干预有戏）；
  `Δzipf` 极性正确但幅度偏离 >1 → **COMPRESSED_KNOB**；符号反或 |Δzipf|<0.2 → **KNOB_NOT_LOCAL**
  （最近邻不是频率邻居 ⇒ 旋钮不接在邻域结构上）。
- **未达阈处理**：`KNOB_NOT_LOCAL` 只否定"平移嵌入=改频率"，不否定"存在频率方向"。

### B6 语义是不是频率的残差

- 统计量：用 Q8-A **完全相同的材料**（COLOR n=52 / FRUIT n=50，中心化，A 档/B 档同 Q8-A），
  计算 `within cos`：①原始（Q8-A 值，作对照）②扣掉 `t = x̃·ŵ_freq` 分量后。
  保留比 `retain = within_after / within_before`。
- 判决：`retain ≥ 0.70` → **SEMANTICS_ORTHOGONAL_TO_FREQ**；`≤ 0.40` → **SEMANTICS_ALONG_FREQ**；中间 → `PARTIALLY_FREQ`。
- 附必报：`within_after` 对同规模随机 CJK 子集的零分布（Q8-A 的 0.0153 量级），防止把"扣完还剩一点"当成"还有结构"。

### B7 单标量能预测多少"单位类型"

- 统计量：仅用 `t`（一个标量）做 one-vs-rest AUC：`CHAR` vs `WORD`、`CHAR` vs `BYTE`、`WORD` vs `BYTE`。
- 判决：`AUC(CHAR vs WORD) ≥ 0.90` → **TYPE_IS_FREQUENCY**（Q8-A P7 的 confound 被定量确认）；
  `< 0.70` → **TYPE_HAS_FREQ_FREE_PART**（类别信息里有不可由频率解释的部分）。
- 意义：正面回答"类别骨架大半是频率"的"大半"到底是多少。

## 3 已知陷阱（写死，防自己）

1. **字节残片无 zipf**（`wordfreq` 对 `<0xE9>` 返回 0）⇒ 必须排除出所有回归，否则 1 457 行假低端把斜率拉歪。B7 才允许出现。
2. **拉丁 BPE 碎片**（`ing` / `ed` / 单字母）⇒ `isalpha + len≥3` 过滤；不满足就用 `LATIN` 只做定性。
3. **zipf 已是 log** ⇒ 见 §1.2，两轴并列。
4. **in-sample R² 会虚高**（d=2560, n=24 500，比例 1:9.6）⇒ 一律 5 折 held-out，in-sample 只作参考打印。
5. **范数与频率共线**是已知风险（Q5-A 的 pos0 寄存器、Q6-B 的指针都碰过）⇒ B3 必须同时报 cos 与扣除后 R² 两个数，不能只报一个。
6. **`WORD` 与 `CHAR` 有共享字**（R-MET-32）⇒ B6 用 Q8-A 原材料，不得换成"共享字分解版"，否则与 Q8-A 不可比。
7. **单模型单种子**（沿用 Q8-A）⇒ 跨模型只比判决与数值，不做种子方差。
8. **`μ` 的估计**用全表（含残片），与 Q8-A 一致；换成只 POOL 的 `μ` 会让所有 cos 尺度变化，禁止中途改。

## 4 预注册的"将被证伪的表述"

若结果支持，本轮将**撤回/收窄** Q8-A 的这两句：

- 「频率是一根显式旋钮」（P7 结论）→ 若 B2 判 FEW_DIM/DISTRIBUTED，改为"频率是一个低维投影，不是单坐标"。
- 「类别骨架大半是频率」（P7 结论）→ 若 B7 的 `AUC(CHAR vs WORD) < 0.70`，改为"频率只解释一部分，类别另有来源"。

这比新增结论更重要：**本轮的价值在于给上一轮的话加刻度或加限制**。
