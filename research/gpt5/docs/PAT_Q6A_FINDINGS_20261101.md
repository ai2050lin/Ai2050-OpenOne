## 1 设计，以及三个专门用来杀死「假方向」的对照

材料：6 个关系族、54 个实例、78 个词；每个词放在 3 个不同载体句末，取残差流在词跨度内的均值，
37 个层全取。Δ(a→b) = v_b − v_a，不归一化（归一化会抹掉范数这一可能信号）。

**三个对照，缺一个就会得出假结论：**

1. **A1b（目标无关）**：只用「同族内目标词不同」的配对。防「Δ 只是指向同一个目标词」。
2. **A1p（置换零假设）**：族内打乱源—目标配对，**但保持目标词多重集不变**，重算同一统计量。
   这是唯一能挡住「F4 只有小/大两个目标、两者本身 cos 0.82」这类伪影的检验——
   目标相似性、‖Δ‖、n 全部被零分布吸收。
3. **族×族矩阵**：检验「跨词区/跨词性转换」是不是全部原因。

判决用**形状**（37 层里达阈的层占比），不用单层极值 ⇒ 不做 36 次比较。

### 2.2 族×族：排除「跨词区转换」解释

若「名词 → 修饰词」的跨词区跃迁才是全部原因，则 F3（名→色）与 F4（名→形容词）应当互相对齐。实测：

| 对 | Δ 中位 cos | 含义 |
|---|---|---|
| F1–F2 | **+0.208** | 同为分类关系 → 对齐 ✔ |
| F4–F6 | +0.201 | 名→修饰 / 名→动词，都指向「谓词性目标」 |
| F2–F4 | +0.120 | — |
| **F3–F4** | **+0.081** | **同为名→修饰，却几乎不对齐** ⇒ 跨词区解释不成立 |
| 其余 11 对 | ≤ 0.062 | — |
| F4–F5 / F5–F6 | −0.057 / −0.019 | 反义与别的族**反向** |

**决定因素是语义关系本身，不是词性。** 颜色方向和大小方向是**两支不同的箭头**，
而不是同一支「名词到修饰词」的箭头。

### 2.3 A2 层级：反向否证，且两个解释都不成立

同链 `cos(Δ(a→b), Δ(b→c))` 的 37 层剖面：

```
L0 −0.39  L4 −0.36  L8 −0.28  L12 −0.25  L16 −0.24  L20 −0.23
L24 −0.19  L28 −0.23  L32 −0.26  L35 −0.30  L36 −0.32
跨链对照：全程 −0.06 … +0.01（就是 0）
```

**每一层都是负的，中位 −0.246，而对照精确为 0。** 这不是噪声，是有结构的反向。

我先预注册了一个替代解释（**径向编码**：越抽象的词越靠近全局均值方向，于是第二跳是「朝均值回缩」、
第一跳是「离开均值」，内积自然为负），并写死了判据。**实测不成立**：
严格单调的链占比全程 ≤0.60，且峰值 0.60 只出现在 L35（单层），达阈层 **0/37**。

⇒ **A2 = `HIERARCHY_NOT_SHARED`，A2b = `RADIAL_NOT_SUPPORTED`。**
「苹果 → 水果 → 食物」不是一支箭头用两次，也不是半径递增。**它是什么，本轮不知道。**
