## 一、三个必须先纠正的前提

### P1「模式保存在参数里」——错，是条件化调用

三条已有证据共同反对"存储"图像：

| 证据 | 内容 | 推论 |
|---|---|---|
| 2840 | 语义调制全部走注意力骨干，无专用存储模块 | 存储与计算共用同一硬件 |
| 2844 | 功能词「的」是集线器，携带 2.11× 条件化信号 | 语法件不是内容，是接口 |
| 2839 | 通道可加比 1.03，独立分布式 | 内容以叠加方式共用参数 |

正确图像：**同一批参数被不同条件以不同方式调用**。因此"参数机制"不是一个可清点的抽屉集合，而是三个可测量：

1. **方向**：模式在激活空间占据哪个低维子空间；
2. **门**：什么条件把读写切到这个子空间（开关函数）；
3. **槽位**：切换后信号流向哪里。

"破解"= 把这三件事测出来并交叉验证。这是有终点的问法；"找出提问用到的参数"没有终点。

### P2「一个算法破解所有模式」——做不到，三类对象要三套算子

| 模式类 | 本质 | 该问的问题 | 算子 | 现状 |
|---|---|---|---|---|
| 知识网络 | 查表（静态内容） | 存了哪个方向 | 差分方向 + 稀疏回归 + 单头消融 | 已破（2806/2809/2824） |
| 语法系统（提问/转折） | 算子（条件→动作） | 何时开门、开到哪里 | 判别对 + 三谱交集 + 路径修补 | 接口破，算子未破 |
| 分析推理 | 程序（多步状态） | 中间状态怎么流转 | 路径修补 + 中介分析 | 仅定位 |

**最危险的错误**：拿第一行的工具打第二行——找"提问方向"、做线性探针、看到 92% 判准率，再做消融发现零损伤。2838–2841 已证：对齐谱与因果谱 Spearman ρ=0.106，近正交。探针能读到的与能改变行为的，是两套东西。

### P3「破解 = 讲出一个解释」——不可验收，改成三条硬判据

- **C1 能构造**：不改输入文字，只改内部激活，使陈述句在内部表现为提问且输出行为随之改变；
- **C2 能关闭**：内容完全不变，定向抑制使模式行为消失，损伤可定位到部件；
- **C3 能预测**：机制写成小模型，能预测 held-out 新句的内部响应，误差显著低于 null。

三条全过才算破。对应 E0→E3 阶梯：读得出 → 控得住 → 可构造 → 可预测。缺 C2 叫相关，缺 C3 叫轶事。

## 二、四步破解循环

### Step 0 形式化：把「模式」做成 2×2 对比

**唯一必须人做、且决定成败的一步。**

四格设计：(内容A, 陈述) / (内容A, 提问) / (内容B, 陈述) / (内容B, 提问)。
激活差分解为：内容主效应 + 模式主效应 + **交互项**。

- **只有交互项是算子签名**。算子若真是算子，作用在不同内容上必然不同（"苹果是红的"→"苹果是什么颜色"，槽位依赖内容）。
- 若模式主效应大而交互近零 → 不是算子，是**体裁标记**（属第一类），工具要退回查表型。

三个 null 缺一不可：

| null | 做法 | 排除的混杂 |
|---|---|---|
| 长度 null | 同长度随机句 | 句长效应 |
| 标点 null | 去问号、保留疑问词 | 纯标点查表 |
| 语法 null | 打乱词序 | 表层 n-gram |

规模：每模式 ≥ 20 组最小对比对 × 3 null，词频/长度/标点匹配。

### Step 1 定位：三谱并行，只信交集

| 谱 | 算子 | 特点 |
|---|---|---|
| 对齐谱 | 分层线性探针 / logistic（层 × 位置） | 快、便宜、单用不可信 |
| 因果谱 | **激活修补**：模式句残差流 patch 到对照句，测恢复率曲线 | 主判据；比消融可靠（消融触发补偿） |
| 门谱 | 模式切换下注意力源-目标质量重分配矩阵 | 定"何时开门" |

交集 = 候选部件。初筛可直接复用 1152 头损伤矩阵，不需重跑普查。

### Step 2 分解：拆成 方向 × 门 × 槽位

- 方向：差分 + SVD 取低维子空间 U_pattern（**不是单方向**，概念=子空间纪律）；
- 门：替换/删除模式词，测 attention mass 与 QK 自绑定强度变化；
- 槽位：路径修补（attn→MLP→unembed 可组合路径）测信号落点。

### Step 3 复现：跨模型同构判定

- **禁用**单向量 cos（跨层 cos 不可用；SwiGLU 规范自由度使范数非内禀量）；
- 用子空间主角度（principal angles）；
- 最硬证据是**跨模型迁移干预**：A 模型找到的干预经线性映射搬到 B 模型仍生效；
- 主角度小但迁移失效 → 子空间同构、接口不同，独立结论。

## 三、预注册 A：提问（P-QUESTION）

### 假设与判决

| ID | 机制主张 | 判决实验 | 若为真的签名 |
|---|---|---|---|
| H1 | 槽位空缺：插入"待填"标记 | 槽位类型探针 + 填充后是否消失 | 空缺方向随填充衰减 |
| H2 | 说话者切换：下一说话者 self→other | 提问/命令/陈述 三分类交互结构 | 命令亦有切换，但无空缺 |
| H3 | 句法移位：wh-词原位移至句首 | wh-词注意源是否稳定指向原位 | 存在专用 copy/route 头 |
| H4 | 表面标记：只是「？」查表 | 标点 null | 签名随问号消失 |

**判决顺序**：H4（排除）→ H1/H2 判别对 → H3（路径修补）。

**核心判别对：提问 vs 命令**。两者都不改内容、都指向对方，唯一差别是提问留槽、命令不留。此对分开，即把"请求信息"与"请求行动"两类算子分开——干净的逻辑切分，非数据堆出。

### 层轴预测（可证伪）

2831 已测：问句不改写历史（苹果@2 谱 diff 0.009–0.017 ≪ null 0.053），模式选择发生在生成端 next-token 分布。

**预测**：提问因果峰落在**读出段 L24–35**，写入段 L0–21 基本不动。
**证伪条件**：若峰落在写入段，则对 2831 的解读错误，定位全流程重做。

## 四、预注册 B：转折（P-CONTRAST）

| ID | 机制主张 | 判决实验 |
|---|---|---|
| T1 | 覆盖写入：转折触发负向写入压制前文 | 带符号投影：前文命题方向上写入是否为负 |
| T2 | 注意力重置：转折后只回看转折从句 | 前后注意力质量比 |
| T3 | 双命题共存：同时持有 p 与 ¬q | "双命题"维度是否升高 |

**三格判别对**：`虽然A，但是B`（让步）/ `因为A，所以B`（因果）/ `A。B。`（无连接词）。

- T3 为真 → 三格都升高；
- T1 为真 → 仅第一格出现负向写入；
- T2 为真 → 因果句亦出现，故 T2 是伴随现象而非机制。

**前置改造（必须）**：现有 D_norm = mean_rows(‖proj‖/‖c‖) 只有份额、无符号。3281 已证绝对范数被 ‖c‖ 驱动（ρ=0.97），符号一旦丢失，"覆盖写入"与"单纯加量"无法区分。**测转折前先把 D_norm 扩成带符号投影**。

**层轴预测**：转折因果峰落在**写入段**，且表现为负向写入。

## 五、反直觉先验（防自欺用）

提问与转折**不在同一层级**：

- 提问 = 句内算子，局部、句法触发 → 机制应集中于少数层，可由单头/单方向描述；
- 转折 = 跨句关系算子，需维护两命题状态竞争 → 机制应分散、需状态变量，**不应存在漂亮的小方向**。

**警报**：若转折也测出一个干净小方向，先怀疑是「但是」本身的查表效应（体裁标记），不得直接宣布破解。此先验用于抵抗"想看到结果"的动机偏差。

## 六、陷阱清单（写入每次预注册）

1. 对齐 ≠ 因果（ρ=0.106）：只信修补，不信探针。
2. 归因图 ≠ 机制：attribution 是相关性排序。
3. 范数混淆：绝对范数被内容量驱动（ρ=0.97），必须份额归一化或带符号投影。
4. 跨层 cos 不可用；SwiGLU 规范自由度 ⇒ 范数非内禀量。
5. 多重实现：不假设唯一机制，判据是"充分且最小"，非"唯一"。
6. 长度/标点/词频混杂：三个 null 缺一不可。
7. 消融触发补偿：优先激活修补，消融作辅助口径。
