## 0 先承认诊断

### 0.1 我们刚刚走完了一个完整循环

今天 02:00 到 05:00 的三个小时，实际发生的序列是：

| 时刻 | 声称找到的规律 | 存活时间 | 死因 |
|---|---|---|---|
| 02:43 Q1 | 263/1152 头"落点=所问角色"，9× 于 null | 约 40 分钟 | Q2-A：密度混杂（23% vs 5.2%），对齐后 +0.101，整带 −0.028 |
| 03:49 Q2-C1 | L33 是角色读出汇聚点 | 存活 | 未死，但被判"只证明存在一个读出点"，不构成机制 |
| 04:17 Q2-C2 | "角度门锥 53°"，角色有共享方向 | 约 40 分钟 | Q2-L：注入任意词嵌入差模型就答那个词，与层、与角色无关 ⇒ 测的是 LM head 线性读出 |
| 05:00 Q2-L | 三角色基 (d1 0.977 / d2 1.000 / d3 1.000) | 当场 | 自己判为平凡：T1 退化成线性读出 |

四点注意：

1. 这不是"运气不好"。**三个假设各自都设计得很干净**，每个都在自己的判据下成立。
2. 死因全部是**同一个类型**：找到的东西是另一个已知机制的影子（密度、读出、长度）。
3. 每轮的新实验**自带新混杂**。Q2-A 治好了密度，Q2-C2 引入了长度，Q2-L 治好了长度，又撞上读出。
4. 因此"再设计一个更严的对照"这条路，在结构上是**发散的**：对照空间无穷，你总能再造一个。

**上万个测试没有产出一个稳定规律，不是因为不够多，是因为没有一个测试的结论是「永久」的。**

### 0.2 账本记了过程，没记知识

项目有 `atlas_ledger.json`（455 条），但它是**过程账**：谁在什么时候跑了什么、hash 是多少。
它不回答"我们现在知道什么、不知道什么、什么已经被永久排除"。

- 过程账 → 支撑复现。
- **排除集 E**（本文新增）→ 支撑决策：下一轮该测什么。

没有 E，下一轮就无法知道"这个方向已经死了"。于是同一个方向换个包装又回来——这正是循环的燃料。

## 1 循环的三条机制

### M1 命题形态错了：点陈述必然被下一个对照推翻

"在第 28 层第 0 头消融，准确率从 0.94 掉到 0.66"——
这是一个**点陈述**（关于一个格子、一个样本集、一个对照设置的事实）。

点陈述的稳定性定理（本项目的经验版本）：

> 对任意点陈述 P，若测量维度 ≥3（层 / 头 / 样本 / 对照 / 长度 / 分布），
> 则存在某个维度上的一个合法对照 P'，使 P 不成立。
> 因为这些维度是**连续可调**的，总能找到让效应消失的那个切片。

Q1、Q2-C2 都死于这条。不是巧合。

### M2 对照空间不封闭

每轮引入的对照（混杂、长度、读出、位置、种子……）都是**临时想出来的**。
只要对照是临时加的，就永远能加下一个。这等价于**无限多次假设检验**：
在 5 个自由维度上各搜一遍，总能搜到 p<0.05 的格子。

### M3 没有关闭机制

没有任何规则说"这个子空间测过 3 次不行就永久关闭"。于是可以用更细的切片重开。
Q2-D → Q2-D2 → Q2-G → Q2-H 就是这个模式：一轮比一轮细，最后得出"无必需头"——一个**否定性**结论。
否定性结论是有效知识，但它没有进入任何"禁止再问"的清单。

## 2 Goodfire 那次为什么终止了循环

不是因为它因果性更强。**它的因果证据强度未必超过本项目的 patch 实验。**
它终止循环，是因为判据的形态换了：

| | 本项目前 3 小时 | Goodfire 那套 |
|---|---|---|
| 命题 | 第 X 层第 Y 头对角色 Z 有因果作用 | 通道 j 的 gate 分布在 **5 万张图**上呈两极化 |
| 形态 | 点陈述 | **分布形状陈述** |
| 被什么推翻 | 换一个对照 | 只有"形状变了"才能推翻 |
| 抽样敏感度 | 极高（n=24 vs 全量结论反转，已实测） | 低（形状是聚合量） |
| 关闭条件 | 无 | 有：coh 阈值 + 两极各 2 例展示，一次性判定 |

关键差别一句话：

> **点陈述在问"这里有没有效应"；形状陈述在问"这个量在所有条件下长什么样"。**
> 前者有无穷多个切片可以证伪，后者只有一个剖面，测一次就定了。

这就是为什么本项目 2026-10-21 的九步参数溯源（`GOODFIRE_STEP_PARAMS_DERIVATION_v3.md`）能落地成流程，而今天的头级因果实验只能不断撤回。

**本项目真正的教训不是"要找因果"，而是"要找剖面"。**

## 3 PSF-1 框架

### 3.1 四层证据等级（E0–E3）与升格规则

| 级 | 名称 | 典型测量 | 稳定性 | 允许的结论词 |
|---|---|---|---|---|
| E0 | 现象 | 行为准确率、logit、注意力权重 | 极高 | "模型做了 X" |
| E1 | 剖面 | 沿层/头/token 的分布形状、直方图、集中度 | **高** | "X 的分布是形状 S" |
| E2 | 干预 | 消融 / patch / 注入 | 低（必被下一对照削弱） | "在条件 C 下，X 影响 Y" |
| E3 | 机制 | 能构造 + 能关闭 + 能预测 + **能迁移** | 需要 E1+E2 双支撑 | "机制是 M" |

**升格规则（本框架的核心条款）**

- **E1 可以独立升格为"规律"，不需要 E2 支持。**
- **E2 单独永远只能叫"线索"，不能叫规律。**
- E3 必须同时有：一个 ≥7/8 不变的 E1 剖面 + 一个 E2 干预 + 一次跨模型/跨语言迁移。

这条规则直接堵住 M1：**规律不再由点陈述承担，点陈述降级为辅助证据。**
过去三小时的撤回全部发生在 E2；如果一开始结论词就锁死在"线索"，这些撤回不会发生——它们本来就不该被当成规律。

### 3.2 变换族 T（冻结，v1）

一次注册 8 个变换，**冻结、不许边测边加**：

| # | 变换 | 操作 |
|---|---|---|
| t1 | 句法 | 主动 ↔ 被动 |
| t2 | 实体身份 | 换施事/受事的人名（同性别、同长度约束） |
| t3 | 词形 | 同义改写、单复数、量词变化 |
| t4 | 位置 | 目标实体在句中的相对位置（句首/中/末） |
| t5 | 句长 | 插入 1–3 个修饰短语（答案不变） |
| t6 | 指令 | 换 system prompt / 换提问措辞 |
| t7 | 种子 | 温度=0 下无意义，故改为**批量顺序**打乱 |
| t8 | 模型 | qwen3-4b ↔ 同族更大/更小 |

**冻结条约**：新增 t9 必须发布 T-v2，且 T-v2 要求**重测全部历史 Q**。
这个成本就是防 M2 的闸门：加对照变贵了，就不能靠"边测边加"无限拖延判决。

### 3.3 不变量判据（一次性判决）

对任一候选量 Q（标量或剖面）：

```
inv(Q) = |{ t ∈ T : Q 在 t 下保持不变 }| / 8
```

| inv(Q) | 判决 | 归档 |
|---|---|---|
| ≥ 7/8 | **不变量**（规律） | 写入 INV 清单，永久保留 |
| 4/8 – 6/8 | **条件规律**：必须逐条写明在哪几个 t 下失效 | 写入 INV 清单但标注条件 |
| ≤ 3/8 | **排除** | 写入 E 集（永久禁止以同形态重问） |

"保持不变"必须**预注册数值容差**（例如剖面形状：Spearman ρ ≥ 0.8；标量：相对变化 ≤ 20%）。
容差在跑之前写进 pre-registration，跑完不许改。

### 3.4 三道闸（直接防循环）

**闸 1 — 预算封顶**
每个子空间（一个 Q 的家族）最多 **3 轮**正式实验。3 轮内拿不到 inv ≥ 4/8 → 子空间永久关闭。
理由：3 轮足够覆盖一个混杂的发现-修正-复审周期（Q1→Q2A→Q2L 正好 3 轮，结论是"这个子空间没有不变量"）。

**闸 2 — 空轮禁入**
每轮结束必须让 E 集**至少 +1**。E 不增大的轮次记 NULL，不计入成果，且**禁止在同一子空间再开 Phase**。
理由：一轮什么都没排除，说明这轮的测量没有分辨力——再来一轮也一样。

**闸 3 — 双片复现**
任何 E2 线索升级为 E3 之前，必须在**不共享样本**的第二个分片上独立复现。
单片 E2 永远停在"线索"。

### 3.5 分布式结构

**分片键（正交，五维）**

```
shard = (模型 m, 层带 b, 头组 g, 样本族 s, 变换 t)
```

- 层带 b：`L0–3 / L4–11 / L12–19 / L20–27 / L28–35`（5 带）
- 头组 g：每带 × 4 组（8 头/组）
- 样本族 s：`人物 / 物体 / 抽象 / 混合`（4 族）
- 变换 t：t1–t8
- 模型 m：至少 2 个

最细 5×4×4×8×2 = 1280 片。每片独立 SMOKE、独立 provenance（五字段）、独立 result.json。

**合并规则（分布式可解释性最容易搞错的地方）**

| 量 | 合并算子 | 理由 |
|---|---|---|
| **不变量 Q** | **交集**（全部片都成立才算） | 抗假阳性。一片成立七片不成立 = 条件现象 |
| **候选规律** | **并集**（任一片发现即入候选池） | 抗漏。但入池后必须过闸 3 双片复现 |
| **剖面形状** | 逐片保留，最后做**形状一致性**（Spearman 相关矩阵），不取平均 | 平均会抹掉双峰（D5 已实测过这个错） |

**汇总器只收原始量，不收结论。**
分片上报：剖面向量、直方图、每个 t 下的 Q 值、样本 id 列表。结论由汇总器按冻结规则算。
这一条防的是"每片用不同判据"——那是分布式实验最常见的失效方式。

**成本**：单次消融在 4B 模型上约 0.6–1.2 s/sample（GPU 实测），
1280 片 × 平均 200 sample ≈ 6–10 小时单卡；分 4 卡约 2 小时。
这个量级是可以做的，前提是**判据先冻结**，否则跑完还得重跑。

## 4 把"齿痕 + 注意力"写成可测量

用户的表述是隐喻，隐喻不能证伪。下面把它翻译成三个可判定命题。

### 4.1 齿痕 = token 身份子空间

**结构事实**：`k_{l,h}(pos) = W_k^{l,h} · LN(x_{l,pos})`。
同一 token 在不同上下文里，`W_k` 固定、嵌入固定，**只有 `LN` 的输入（残差流）在变**。
所以"齿痕"如果存在，必然是：**同一 token 的 k 在 M 个不同上下文中共享一个稳定低维方向**。

**可测定义**

对 token w，取它在 M=20 个不同上下文中的 key 向量 `{k_1..k_M}`：

```
k̄(w) = mean_i k_i / ||mean_i k_i||          # 身份方向
R_id(l,h,w) = ||mean_i k_i|| / mean_i ||k_i||  # 身份占比，[0,1]
```

`R_id` 就是**齿痕强度**。它是标准"均值/均值范数"比（与九步手册 S2 的 coh 同构），
随机基线 `1/√M ≈ 0.22`（M=20）。

**验证齿痕真的携带身份**：用 token 身份做分类，`k` 上的线性探针 20 折交叉验证准确率。
若 R_id 高但分类准确率 ≈ 1/V（V=词表子集大小），则那个方向与身份无关（伪齿痕）。

**这是 E1 剖面**：R_id 在 36 层 × 32 头上的剖面。测一次，永久有效。
预注册预测：低层高 → 中层被上下文稀释 → 高层回升（因为要传给 LM head 做词形匹配）。
三种形状（单调降 / 单调升 / U 形）互斥，测出来就是判决。

### 4.2 注意力怎么用齿痕 = key 的可加分解

**这是本轮最干净的实验，因为它没有统计混杂。**

注意力分数 `s = q · k`。把 k 唯一分解为：

```
k_id  = k̄(w) · ||mean_i k_i||        # 身份分量（沿身份方向的投影）
k_ctx = k − k_id                     # 上下文分量（正交补，精确残差）
```

于是 `s = q·k_id + q·k_ctx`，**两项都是可精确计算的数，不是拟合**。

**判决问题**：实际 softmax 出来的注意力权重，与 `s_id` 的相关性 vs 与 `s_ctx` 的相关性，谁高？

- 若 `s_id` 主导 → 注意力本质是**词表查找**（"齿痕匹配"），上下文只做门控（调幅不调向）。
- 若 `s_ctx` 主导 → 注意力是**上下文寻址**，token 身份只是索引。
- 若两项在不同层/头分工 → 这就是"多模式"的直接证据：**同一层内，一部分头做身份匹配，一部分做上下文寻址**。

这个分解预测了一个可证伪的东西：**若身份主导，则把句子里的词换成同义词（t3），注意力分布应该基本不变（因为齿痕随词变，但同义词齿痕相似）。**

配套度量：**解释力比** `ρ = corr(s_id, s_actual) / corr(s_ctx, s_actual)`，
沿层剖面 → E1；再做一个"只保留 s_id 做 softmax"的替换实验 → E2。
两者合起来才有资格叫 E3。

### 4.3 融合 = 加性写入 + 稀疏复用

**结构事实**：残差流是纯加法，LM head 是线性（LN 前）。所以

```
logit(y) = W_U · LN( h_0 + Σ_l Σ_h write_{l,h} )
```

**可判定命题（形状陈述，不是点陈述）**：

> 存在一个小字典 D（|D| ≤ 64 个方向），使得
> (a) 任意样本相对 uniform 的 logit 差，可用 D 中 ≤3 个方向的线性组合重建（R² ≥ 0.9）；
> (b) **同一语义角色（施事/受事/客体）在 144 格中复用同一批字典列**（复用率 ≫ 随机）。

(a) 是"融合是稀疏的"，(b) 是"融合是稳定的"。
两条都是分布性陈述，测一次定论，不会因为下一个对照被推翻。

**复用率**是这里的关键量：`reuse(role) = 该角色命中列的 Jaccard 重叠 / 随机期望`。
若 reuse ≈ 1，说明角色没有专属方向（Q2-C2 的教训）；若 reuse ≥ 3，说明有专属列族——那才是"模式"。

## 5 下一 Phase 预注册：Q3-T（齿痕三测）

**只做三件事，全部是 E1 剖面 + 一个干净的 E2。**

### T1 齿痕剖面（E1）
- 60 token × 20 上下文 × 36 层 × 全 32 头
- 产出：`R_id(l,h)` 热图 + 探针准确率 `acc(l,h)`
- 判据：剖面形状属于 {单调降, 单调升, U 形} 之一（预注册三选一），或"无形状（平坦）"
- 成本：36×32×60×20 ≈ 138 万次前向的 key 采集；**用一次 batched forward 抓全部层**，约 40 分钟

### T2 归因分解（E1 + E2）
- 对 144 格，逐层逐头算 `s_id`、`s_ctx`、`s_actual`，输出 `ρ(l,h)` 剖面
- E2：只保留 `s_id` 的注意力替换实验，看行为掉多少（配三控制，D9）
- 判据：`ρ` 剖面是否存在"前半段身份主导 / 后半段上下文主导"的分界层
- **这是本轮的核心**，因为它直接回答"注意力怎么用钥匙"

### T3 稀疏复用（E1）
- 采集 144 格 logit 差，稀疏分解得 D，测 reuse(role)
- 判据：reuse 的 bootstrap CI 下界 > 1.5 才认"有专属列族"

### 关闭条件（闸 1）
Q3-T 家族上限 3 轮。若 T1–T3 全部 inv ≤ 3/8，**"注意力用身份齿痕做寻址"这个子空间永久关闭**，
写入 E 集，转向"注意力完全由上下文位置决定"的备择。

## 6 框架本身怎么被检验

框架不是免检的。它有一个可证伪的自我预测：

> **PSF-1 的第一条不变量，应该在 3 轮内出现；且一旦出现，后续 Phase 不应再推翻它。**

若 3 轮内没有出现任何 inv ≥ 4/8 的量，则**不是模型没有规律，是这套测量没有分辨力**——
此时不许换假设，必须换测量（换模型、换精度、换层序）。

这条把"框架失灵"和"假设错误"分开了。以前的循环之所以无限，就是因为这两种失败从未被区分：
每次失败都被归因为"假设不对"，于是换假设；而不换工具。

## 8 一句话

**上一个循环的真因不是"假设不够好"，是"用点陈述承担规律"。**
把命题换成剖面、把对照冻结成族、把失败写进排除集，

## 9 PSF-2 修订（2026-11-01，由 Q3-T 三连 NULL 触发）

**触发事件**：Q3-T 家族 T1/T2/T3 全部 NULL。这是同一类失败的**第四次**（头侧九轮 → k 侧三轮 → 输出端一轮）。
按 §6 的自检条款，第 3 轮无 inv≥4/8 时就该"换测量而非换假设"——我们换了三侧（头 / k / 输出端），
**仍然全空**。所以问题不在"测哪一侧"，在**问的题型**。以下是四条修订。

### 9.1 必要性的适用单元：不是取消，是换单元（修 D12 配套）

用户提出的第一条质疑是"是否必须符合『消除后就无效』"。**方向对，落点错。**

- **错在哪里**：消融测的是**容量与冗余**，不是功能。分布式系统的构造决定它必然回答"删掉这个不坏"。
  Q2-A/D2/E/F/G 五轮全部得到这个答案（L0–L3 内 93% 的头可消融而零损伤、无必需层、无必需组合）。
  **这不是假设错，是单元错。**
- **正确单元在哪里，本项目自己的数据已经指出来了**（Q2-C1）：

  | 段 | 干预 | 结果 |
  |---|---|---|
  | L28–L35 | 消融**全部 133 个头** | drop **0.000** |
  | L28–L35 | patch **L33 一个位置**的内容 | 翻转 **1.00** |

  同段、同层带，一个是 0，一个是满值。⇒ **必要性存在于"位置上的内容"，不存在于"头的参数"。**

- **新增规则**
  - **D20**｜干预锚点必须落在系统**实际使用的单元**上（位置 / 内容 / 路由），不得默认落在参数（头、神经元、层）上。
    消融类只答"缺了会不会坏"，**永久降级为容量测量，不作机制证据**。
  - **D21**｜每个 Phase **至少一个**干预锚点，**不是每条结论都要**。E1 剖面可独立成立（沿用 D10）。
    这条直接采纳用户意见：不要求"符合全部范式"。
  - **D22**｜机制主张的三件套：**(i) 可预测的剖面或规则 + (ii) 一处方向性干预 + (iii) 跨变换族稳定**。
    三者不必同源、不必同轮，但**缺 (ii) 只能叫描述**。

- **为什么不能干脆取消 (ii)**：E-01…E-06 六条排除，死因**全部**是"效应是另一已知机制的影子"
  （密度、长度、readout、覆盖率、损伤预算），**没有一条**是被"范式要求"谋杀的。
  它们的死因是**缺对照**。取消 (ii) 不会救活它们，只会让那类结论重新被写下来。

### 9.2 算力与关闭：算力不设限，但"跑完了"≠"测不出"（修 D12）

用户第二条质疑是"是否必须限制测试量"。**同意，但它解决的不是循环问题。**

- **算力确实不是约束**。本轮 T3 全量（144 次前向 + 5 折字典 + 1000 次 bootstrap）耗时 **103 秒**。
  本项目至今没有一次失败是因为"没算够"。
- **3 轮上限拦的不是算力，是多重比较**。8 个变换在 α=0.05 下期望 0.4 个假阳性；100 个临时变体期望 5 个。
  这个期望值**与算力无关**——算力再大，假阳性率照涨。所以 D11（变换族冻结）必须保留。
- **但用户有一半是对的，必须补**：原 D12 用"轮数"代替"证据"，会把**"跑完了"**和**"测不出"**混为一谈。
  若效应真实但很弱，3 轮小样本会误关；若效应强，3 轮足够。轮数是错的代理变量，**功效才是**。
- **新增规则**
  - **D23｜关闭前必须报功效**。给出本轮 n 下的最小可检测效应（MDE）；判据：
    - `MDE < 关心的效应量` ⇒ "测不出"是真结论，可关闭；
    - `MDE > 关心的效应量` ⇒ 只能说"**本轮未测出**"，该子空间**不关闭**，记 `pending`，且必须写明需要多大的 n。
  - **算力预算改为**：单个测量的规模**由功效反推**，不由轮数或时长决定。贵不是不做的理由；贵是"要先算需要多大 n"的理由。

- **自检示例（本轮）**：
  - T3 的 R² 0.819 vs 阈值 0.90：5 折分布 0.753–0.888，**无一折达阈**，MDE 约在 0.03 量级 ⇒ 结论稳，不是功效不足。✅
  - T1 的形状判据：n=1200、sep 极差 0.227、判据阈 0.10 ⇒ MDE 远小于阈值 ⇒ "四选一全落空"是真落空。✅
  - 反例：若某轮 n=36、效应量 0.05、MDE 0.20，则那轮**没有资格**产出 NULL。

### 9.3 真病因：十二轮全在做"定位"，而机制是"规则"（本轮最重要的修订）

把十二轮的题目列出来，问题一目了然：

| 轮次 | 问的题 | 题型 |
|---|---|---|
| 头侧九轮 | 哪些头/哪组头承载角色 | **定位** |
| Q3-T1/T2 | 身份存在 key 的哪一部分 | **定位** |
| Q3-T3 | 复用存在哪些字典列 | **定位** |
| Q3-Q（在队） | 角色分量存在 q 的哪一段 | **定位** |

**十二轮，同一个题型。** 定位问题假设"某处存着 X"。在分布式表示里，这个假设可能**根本不成立**——
不是"没找到"，是"没有那个地方"。所以定位类测量会持续返回 NULL，且每换一侧就更确认一次"没有那个地方"。

**这是循环的真机制**：不是假设不够好，不是算力不够，是**问错了题型**。

**改法：问"执行的是什么规则"，用预测判决。**

- 规则型命题形如：`答案 = f(句式, 查询, 上下文里的实体)`，且 `f` 必须在**未见的 (三元组, 句式, 查询)** 上预测正确答案。
- 判据是**预测准确率 vs 随机/多数类基线**，不是"某处效应显著"。
- **为什么这条不能被切片拯救**：预测错了就是错了。没有"在某个子集上显著"可以挽回。
  这是本项目至今唯一一种**自带备择、无法用细分换结果**的判据形态。

**已有原料其实已经是一份算法草图**（把三测的负结果正着读）：

| 已有事实 | 对算法草图的含义 |
|---|---|
| T1：key 携带身份，同词跨上下文 cos 0.998，sep 峰在 L13 | key 侧是**静态实体码**，不是动态重编码 |
| T2：share_ctx ≈ 0.01 | 上下文**不通过改写 key** 进入检索 |
| T3：输出复用按答案实体 7.88× vs 角色 1.24× | 输出是**实体索引查表**，不是角色模式相加 |
| Q2-C1：L33 patch 1.00 / L28–35 消融 0.000 | 读出发生在**一个位置的内容**上 |

四件事合起来说的是同一句话：**答案 = 用查询在实体表里查到某个槽，把该槽的实体码交给读出。**
缺的唯一一块是：**"查询→槽"的映射规则是什么。**

- **新增规则 D24｜判据优先级**：预测型 > 剖面型 > 点陈述型。
  新 Phase 必须先尝试写成预测型；写不出预测型时，才退到剖面型，并说明为什么无法预测。

### 9.6 D25：剖面必须打印全部层，不许抽样打印

Q4-R 的自伤记录：逐层剖面用 `profile[::3]` 打印，36 层正好打印到 L33，**跳过 L34/L35**。
于是在结论文档与账本里写了"L28 起稳定满分"。独立复核脚本读原始数组后发现 **L35 塌到 0.562**。

- 性质：抽样打印是**报告环节的泄漏**——它不改变数据，但会系统性掩盖末端效应。
- 为什么偏是末端：36 不是 3 的整数倍端点友好数，任何固定步长抽样最容易漏掉最后几层，
  而最后几层恰恰是注意力重新分配（塌陷或跳变）最常发生的地方。
- **D25｜剖面类结果必须以完整数组形式打印/落盘；抽样只能作为摘要，且必须同时给出完整版本。**

这条与 D5（双峰禁用均值）、D13（剖面不平均）同属一类：**聚合可以，但聚合不得替换原始分布**。

### 9.7 D26：bootstrap 必须与点估计同口径（同一类错第二次出现）

Q3-T3 的 D18 只写了「bootstrap 必须跳过自配对」，是**针对一个具体 bug** 的补丁。
Q6-A 又以**另一种成因**犯了同一类错：点估计用「按词留出」，bootstrap 用「样本内全实例」，
结果 CI [0.61, 0.84] 整体高于点估计 0.196——与 T3 的「CI 下界 > 点估计」是同一个结构性症状。

- 诊断：**D18 记错了根因。** 根因不是「自配对」，而是「估计器与统计量不对齐」。
- **D26｜bootstrap 的重采样单位、留出划分、层选择必须与点估计完全一致；
  且必须断言「CI 包住点估计」，不满足即判 `ESTIMATOR_BUG`，不输出判决。**
- 为什么改成断言而不是逐条排查：两次的成因不同（自配对 / 口径混用），
  列清单式的规则只能挡住已经见过的那一种；断言式检查挡住的是整类。

配套提醒：`CI 不含点估计` 这个症状**只有一行代码就能查**，任何 Phase 都应默认带上。
