## 0. 一句话

语域方向**加上去就动、删下去不动**：patch 充分（α≥2 时 1/3 样本翻类）、ablation 无效（mlp+attn 联合消融后 acc 仍 0.989）、权重空间秩一移除非空但可忽略（KL 0.09 vs 随机 0.001）。**"读写分离"在 patch 口径下被否证（注意力同轴效力 = MLP），WSP 式的单方向闸门手术对语域风格不成立。**

## 4. W3 读写分离（同方向、同 α、同层带）

MLP patch Δmargin **+5.69** / KL 0.095；注意力 patch Δmargin **+6.20** / KL 0.129。预注册要求"MLP 翻类率 − 注意力翻类率 > 0"，实测 0.022 − 0.061 < 0 ⇒ **ATT_ALSO_WRITES，H-RW 强形式被否证**。

原因不是数据错，而是**残差流是加性信道**：同一方向注入任一组件，下游读到的几乎是同一件事。Q9-A 的"中段 MLP 主写"是**写入份额**（raw 0.11–0.39），不能外推成"只有 MLP 能写入"。这条已固化为 **R-MET-42**。

## 7. 与 WSP 的对质（本 Phase 最重要的理论增量）

WSP 的单方向手术能成立，前提是**故障是退化自激**（重复循环 = 状态被一个方向锁死在固定点）。语域风格不是这种结构：

- 它的信息在 **hs[0] 就有 2/3**（Q9-A），删中段写入等于删冗余副本；
- 它的写入摊在 **~1000 列**上（本 Phase 预检），秩一手术只切掉 11%；
- 下游对"方向"而非"来源"响应（W3），所以任何组件都能补上。

⇒ 把功能分成**容量（分布式、加性、不可局部编辑）× 门控（低秩、秩一可关）**的两分法在这里得到第一个项目内判据：**语域风格属于容量侧**。WSP 自己的 Gemma 数学失败（6.8→7.7%）是同一分类的另一实例。
