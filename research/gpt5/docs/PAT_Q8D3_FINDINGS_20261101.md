## 零、一句话结论

**pos0（寄存器位置）同样不承载频率旋钮，但它是分布敏感性的热点——且这是模型指纹**。
两模型在 pos0 上都出现**同号的微弱反向剂量响应**（推高频率 → 输出反而略偏低频，幅度
0.01–0.06 zipf，效率 ~2%），都远低于因果阈 0.10 ⇒ 双模型 `WEAK_COUPLING`；而扰动对输出
分布的 KL 敏感性 Qwen 是末位的 **19.2 倍**（`REGISTER_SENSITIVE`，支持 Q5-A 寄存器假说）、
GLM 只有 **1.9 倍**（`POSITION_NEUTRAL`）——**位置敏感性结构与 Q8-B/B5、Q8-D2/C3 一样，
是逐模型性质**。至此"输入侧任何位置都不使用频率方向"的结论完备，Q8-D 线关闭。

## 二、解读与边界

1. **反向弱耦合不是频率旋钮**：0.01–0.06 zipf / 2 zipf 推度的效率 ~2%，且 Qwen 的剂量曲线
   非单调（+2 回弹到 −0.009）。按 D10 升格判据这最多是"线索"，不能叫规律。可信的表述是
   **"pos0 对频率方向扰动有分布层面的响应（KL），但响应不沿频率轴组织"**。
2. **REGISTER_SENSITIVE 是模型指纹**（第三次出现 FUNCTION_MODEL_SPECIFIC 模式：Q8-B/B5
   拧旋钮、Q8-D2/C3 方向特异性、Q8-D3/C4 位置敏感性）。Q5-A 的"pos0 占竞争 46%"在
   Qwen 上被扰动复现（19×），在 GLM 上不成立（1.9×）——**寄存器结构是 Qwen 家族的
   训练产物，不是普遍架构性质**。
3. **KL 的形状不同**：Qwen 的 KL 随 |δ| 单调（0.006→0.06，U 形对称）；GLM 的 KL 对剂量
   几乎平坦（0.034–0.040）——GLM 在 pos0 上"怎么推都一样晕"，Qwen 有结构化的响应。
4. **Q8-D 线关闭**：LAST（内容位）、ALLPOS（全部位）、POS0（格式位）三个位置、两模型、
   输入臂全部 NULL/WEAK——静态频率子空间在前向输入侧的任何入口都不承载频率控制。

## 三、跑后修订与硬伤

1. **【材料】Qwen3 默认 chat 模板强制 `<think>`**（top1=1.000，p_M=0，主指标退化）——
   必须 `enable_thinking=False`（诊断 q8d3_diag：修后 top1='你' 0.776）。
2. **【材料】HF 版 GLM-4 模板缺官方尾换行**：模板止于 `<|assistant|>`，模型在该处 1.000
   预测 `\n` ⇒ p_M=0。补 `\n` 后 top1='这句话' 0.468（诊断 q8d3_gdiag）。两次都是
   **模板补全而非材料挑选**（只看基线分布）。
3. **【实现】PHASE 键类型**：环境变量是字符串，判决字典用了 int 键（KeyError）；主循环
   位置列表补丁第一轮静默未命中（无 assert），SMOKE 抓到。
4. **【复核校准】chat 模板长序列的 bf16 内核噪声大一个量级**：主跑 batch 不变性 per-prompt
   max|ΔE|=0.147（均值 0.0019），复核逐剂量容差按实测校准 0.02（D2 裸串为 0.01）；模板闸
   p_M 容差 0.10，且**饱和区翻转**（p_M≥0.90 的候选被 8-bit/内核噪声压过阈，GLM 实测
   max|Δp_M|=0.0934 翻掉了 p_M=0.963 的一张{N}）不算不一致。
5. **【复核自打 bug】dE() 内部第二次 tok(s) 没走 wrap()**——位移算在裸串、基线算在包装串，
   恒定 −0.55 偏移；修复后逐剂量一致（max|Δ|=0.012）。教训：**复核脚本里"编码"必须只有
   一个入口函数**。
6. **【覆盖】只测了 pos0 一个格式位置**；`<|im_end|>`/换行等后续格式位未测。GLM 的 KL 平坦
   现象（剂量不敏感）值得单独一轮。
