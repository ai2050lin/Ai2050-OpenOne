## 零、一句话

**同一 token 在不同句子里的 key，几乎完全一样（cos 0.998）。**
所以"上下文改变了钥匙"这件事在本模型上**不成立**——上下文不是从 key 这一侧进入注意力的。
这条负结果把问题重新定位了：**要问的不是"钥匙怎么变"，是"锁孔怎么选"。**

两个预注册判据**全部落空**（T1 的 U 形、T2 的分界层），本轮在 PSF-1 意义上记 **NULL**。
下面是落空过程中测到的、可以留下来的东西。

## 一、开工前必须修的三处（写脚本时发现，不是跑完再改）

## 二、T1：齿痕的绝对可分性满格，相对份额随层衰减

### 设计

```
模板 P9  「{A}送给了{B}一个{W}。」   W 在 token 24（主动句 theme 槽）
模板 P0  「{W}被{A}送给了{B}。」     W 在 token 17（被动句 theme 槽）
30 个单 token 名词 × 20 个 (A,B) 上下文，共 1200 条
```

同一模板下 W 的位置恒定（已断言），唯一变量是周围词。

### 实测

| 量 | P9 | P0 |
|---|---|---|
| 身份检索率 match（36 层均值） | **1.0000** | **1.0000** |
| 随机基线 1/30 | 0.0333 | 0.0333 |
| 倍数 | **30×** | **30×** |
| cos 同词（L0 / L35） | 1.0000 / 0.9979 | 1.0000 / 1.0000 |
| cos 异词（L0 / L35） | 0.9976 / 0.9559 | 0.9977 / 0.9472 |
| sep = 同词 − 异词（中位） | 0.100 | 0.128 |
| sep 峰 | L13（0.230） | L13（0.260） |
| sep 在 L0 | **0.002** | **0.002** |

### 三条可以留下的事实

**F1-1　齿痕强到近乎恒定。** 同一 token 跨 20 个不同句子的 key，方向 cos = 0.998。
不同 token 之间也有 0.9976（L0）。也就是说 **key 基本是一个"位置 + 一点点词身份"的量**。

**F1-2　身份在任何一层都可以完整读出。** match = 1.000 全层，30 倍基线，**没有任何一层下降**。
即使 sep 掉到 0.04（L35），top-1 检索仍然全对——因为身份住在一个稳定的低维方向里，
绝对差异小不等于不可分。

**F1-3　L0 的身份差异精确为零。** sep(L0) = 0.002，而 L13 是 0.230，相差 100 倍。
第一层的 key **完全不含词身份**，只有位置。身份是从 L2 之后才被写进 key 的。

> 注意 F1-2 与 F1-3 不矛盾：L0 的 key 差异**全部**来自身份（份额高），但**绝对量**几乎为零。
> 这与 T2 的 share 剖面方向相反，原因见 §四。

### 判决

| 判据 | 结果 |
|---|---|
| 形状四选一（U / 单调降 / 单调升 / 平坦） | **全部落空**：不满足 U（前−中 = 0.007），不满足单调（ρ = −0.169 / +0.194），不满足平坦（极差 0.227） |
| 预注册预测（U 形） | **错** |
| 身份有效性闸（match ≥ 5× 基线） | 通过（30×） |

⇒ **T1 记 NULL**。但形状在**两个不同位置**上高度一致：P9 vs P0 的 sep 剖面 **Spearman = 0.835**，
max\|Δ\| = 0.080。按 PSF-1 的变换族，这是 t4（换位置）下的**不变量候选**——
形状不是位置造成的。

## 三、T2：把点积拆成三项之后

### 设计（与预注册的两处偏离，均在跑前记录）

1. **判据从 ρ 改成方差份额。** 因为 `s_act = s_id + s_ctx` 是恒等式，两个相关系数必然同号，
   ρ 会系统性失真。改报 share = var(该项)/var(s_act)，并报份额和（偏离 1 说明两项相关）。
2. **范围只做 theme 槽。** 身份方向必须在与目标句**完全同构、同位置**的模板上测（RoPE），
   agent/recipient 需要各自的模板族，本轮不作任何主张。

**分解是三步**（这是 SMOKE 逼出来的修正，见 §五）：

```
g    = 所有词、所有上下文共有的方向          → k_cmn = (k·g)g
perp = k − k_cmn
û_w  = 该词跨上下文在 perp 上的平均方向      → k_id  = (perp·û_w)û_w
k_ctx = perp − k_id
s = q·k_cmn + q·k_id + q·k_ctx   （精确恒等，三项正交）
```

### 实测（114 格 = 19 三元组 × 2 句式 × 3 查询）

行为门 **113/114**（ag 37/38、re 38/38、th 38/38）。

| 份额 | L0 | L12 | L24 | L35 | 中位 |
|---|---|---|---|---|---|
| share_id（身份） | 0.95 | 0.89 | 0.21 | 0.60 | — |
| share_cmn（共同） | 0.37 | 0.13 | 0.87 | 0.60 | 0.543 |
| **share_ctx（上下文特异）** | **0.00** | **0.02** | **0.00** | **0.01** | **0.009** |

份额和的中位 = 1.050（略高于 1，说明三项有正相关，分解不严格正交，结论要打折）。

### 判决：判据失效

| 判据 | 阈值 | 实测 | 结果 |
|---|---|---|---|
| J1 分界层 | 前 1/3 > 0.5 且 后 1/3 < 0.2 | 0.822 / 0.289 | **不成立**（差 0.089） |
| J2 层内分工 | 双峰 \|mean−median\|/std > 0.3 | 0.154 | 不成立 |
| J3 等权 | 中位 ∈[0.35,0.65] 且无 J1/J2 | 中位在区间内 | **字面成立，但与单调趋势矛盾** |

J3 字面成立却明显不对（剖面从 0.95 一路降到 0.29，ρ(层, share_id) = −0.838），
说明**四选一判据没有覆盖"有趋势但没到阈值"这一档**。⇒ 判据本身失效，**T2 记 NULL**。

### 而且有一处不稳健，必须放在这里

按查询分组重算，share_id 剖面变成：

| 分组 | L0 | L12 | L24 | L35 | 降幅 |
|---|---|---|---|---|---|
| ag | 0.94 | 0.90 | 0.86 | 0.68 | 0.26 |
| re | 0.94 | 0.90 | 0.54 | 0.71 | 0.23 |
| th | 0.94 | 0.92 | 0.56 | 0.68 | 0.26 |
| **混合 114 格** | 0.95 | 0.89 | 0.21 | 0.60 | **0.66** |

**混合 query 把降幅夸大了 2.5 倍**（0.66 vs 0.25）。份额是**相对于所选样本集的条件量**，
换分组就变。三个分组各自独立、方向一致（都是单调下降 0.23–0.26），
所以**稳健的只有那 0.25 的降幅，不是 0.66**。

⇒ 任何"身份份额从 0.95 掉到 0.29"的说法都是**分组假象**，不得引用。

## 四、T1 与 T2 方向相反，为什么不矛盾

T1 说身份差异 L0 最小、L13 最大（绝对量）；T2 说身份份额 L0 最大、逐层下降（相对量）。

两者测的是不同的东西：

- **绝对量（sep）**：同词与异词的 cos 差。L0 时所有词的 key 几乎完全一样，所以差≈0。
- **相对份额（share_id）**：在 key 这一点点差异里，有多少来自身份。L0 时差异虽小，但**全部**是身份。

合起来是一幅自洽的图：**L0 的 key 是"位置"，身份是叠在上面的一层极薄但纯的膜；
到高层，key 的差异被"共同方向"的漂移撑大，身份那层膜的相对占比就被稀释了。**

## 五、本轮最值钱的一条：share_ctx ≈ 0.01

上下文特异分量几乎不贡献注意力分数的方差（中位 0.009，全层 ≤0.03）。

这**部分来自构造**：`k_ctx` 定义为"偏离该词跨上下文平均方向"的部分，
所以它衡量的是上下文的**特异**贡献，不是总贡献——上下文的"共有"影响已经被算进 `k_cmn`。

即便如此，结论仍然硬：**不同句子之间的差异几乎不改 key**（与 F1-1 的 cos 0.998 互相印证）。
把这句话说完整：

> **上下文信息不是从 key 这一侧进入注意力的。** 锁（k）几乎不动，动的是锁孔（q）。

这条直接改写了下一步该问什么：

- 过去九轮一直在**头和 k 侧**找"角色"，全部失败（E-01…E-06）。
- 如果 k 几乎不含上下文，那头级差异只能体现在 **q 侧**——末位 query 携带全文，
  由它决定"去谁那里取"。
- 这解释了 Q2-C1 的 L33 现象：末位内容到 L32 还能被改写、L33 之后不能，
  说明**q 在 L20–L32 被逐层塑形，L33 定稿去读出**。

## 六、预注册下一轮 Q3-Q（未开跑）

**把同一个分解搬到 q 侧。** 这是本轮负结果直接指出的唯一方向。

```
q_common：末位 query 里与"问哪个角色"无关的共有分量
q_role  ：随查询角色（ag/re/th）变化的分量
q_ctx   ：随句子内容变化的残差分量
```

判据（三条互斥，跑前冻结）：

- **Q1 角色主导**：q_role 的方差份额 > 0.5，且沿层不下降 ⇒ "注意力靠 q 选角色"成立
- **Q2 交接**：q_role 份额在 L20–L32 出现单次跨中位下降 ⇒ 与 Q2-C1 的 L33 汇聚点对齐
- **Q3 无角色化**：q_role 份额 ≤0.2 全层 ⇒ 角色选择不由 q 承担，须转向 v 侧或 MLP

预测：**Q2 成立**，交接层落在 L28–L32。

关闭条件：Q3-Q 家族上限 3 轮；若三轮全 inv ≤ 3/8，转 v 侧与残差写入。

## 七、纪律补记

- **D14**（本轮新增）：**份额类指标必须报分组敏感性**。`share` 是相对于样本集的条件量，
  混合不同条件会夸大效应（本轮 0.66 vs 0.25，2.5 倍）。报份额必须同时报至少两个分组的重算值。
- **D15**（本轮新增）：**分解必须先扣共同方向，再取身份方向**。直接把"跨上下文均值方向"
  当身份方向，会让身份分量吃掉全部能量（本轮 share_id 假性 = 1.00），
  因为所有 key 高度共线（cos 0.998），均值方向就是主方向。
- **D16**：预注册的形状判据要覆盖"有趋势但未达阈值"这一档，否则 J1 不成立而 J3 字面成立，
  判决会自相矛盾（本轮实际发生）。

## 八、T3：输出端同样没有"角色列族"，复用是按答案实体索引的

### 设计（三处偏离，均在跑前记入脚本 docstring）

```
144 格 = 24 三元组 × 2 句式 × 3 查询
Δ = log p(cand) + log V        V = 39（12 人名 + 30 名词，按首 token 去重）
候选集质量覆盖中位 = 1.000     （答案全在候选集内，Δ 没有漏掉概率质量）
字典 K = 32，每格非零 ≤ 3，按三元组对半切 5 折，OMP 编码
```

三处跑前偏离：

1. **三元组换成 24 个互不相同的名词。** 若沿用 T2 的"12 人 × 2 名词"，
   `th` 角色 24 格的答案只有 2 个词，`reuse(th)` 会退化到接近上限——判据自动成立却零信息。
2. **主报 held-out R²。** K=32 相对 V=39 已接近过完备，in-sample R² 必然虚高（实测 0.989），
   无信息。
3. **加去角色均值版 Δc。** 防止"不同问题答案不同"冒充"角色专属列族"。

### 实测

行为门 **140/144**（ag 48/48、re 44/48、th 48/48）。

| 量 | 值 |
|---|---|
| 角色内 Δ 余弦 / 角色间 | **0.9676 / 0.9556** |
| 有效维度（参与比，原始 Δ） | 3.99 / 39 |
| 有效维度（去角色均值） | 8.05 / 39 |
| R² held-out 中位（5 折） | **0.819**（0.845 / 0.819 / 0.888 / 0.753 / 0.807） |
| R² held-out 均值 | 0.770 |
| R² held-out 去角色均值 中位 | 0.851 |
| R² in-sample（过完备对照） | 0.989 |
| 随机期望 E[Jaccard] | 0.0604 |

共享 PCA 的 held-out 曲线（r = 1,2,3,4,5,6,8）：

```
raw    0.346  0.394  0.447  0.489  0.546  0.578  0.653
centrd 0.203  0.279  0.334  0.381  0.424  0.455  0.577
```

**共享 8 维子空间只解释 65.3%。** 换一批没见过的三元组，学到的低维模式就失效了。

复用率（相对随机期望的倍数，bootstrap 95% CI）：

| | ag | re | th | 跨角色 | 同答案实体 | 不同答案实体 |
|---|---|---|---|---|---|---|
| raw | 1.79 [1.52, 2.10] | 1.61 [1.35, 2.00] | 1.30 [1.04, 1.60] | 1.18 | **7.88** (n=168) | 1.24 (n=3216) |
| 去角色均值 | 1.56 [1.34, 1.81] | 2.33 [1.85, 3.07] | 1.99 [1.54, 2.56] | 1.35 | **8.38** | 1.62 |

### 判决：NULL_decomposition

| 判据 | 阈值 | 实测 | 结果 |
|---|---|---|---|
| 重建质量 | R² ≥ 0.90 且 ≤3 非零 | 0.819（≤3 已满足） | **不成立** |
| reuse(role) | ≥3.0 且 CI 下界 >1.5 | 1.30–1.79（中位 1.61） | 不成立（落在 1.5–3.0 的弱复用档） |
| 预注册预测 reuse ≥ 3 | — | 1.30–1.79 | **错** |

按预注册，**T3 记 NULL**：分解前提不成立，reuse 数值只作诊断，不作主张。

### 三条可以留下的事实

**F3-1　输出端不存在 ≤3 原子的共享模。** held-out R² 0.819 < 0.90，且共享 rank-8 只有 0.653。
不是"字典太小"——in-sample 0.989 说明容量足够；差距**全在泛化**。
意思是：Δ 的结构随三元组变，学不到能迁移的共享低维模式。

**F3-2　三种查询的 Δ 几乎同一个方向。** 角色内 cos 0.9676，角色间 0.9556，差 0.012。
"角色专属列族"从原料上就不成立——三种查询的输出分布形状差异远小于它和自身的相似度。
（原担心的"答案词表差异"混杂因此**没有出现**：如果角色真的由词表主导，
角色间余弦应该明显低于角色内；实测只低 0.012。）

**F3-3　复用真实存在，但索引是答案实体。** 同答案 7.88×，不同答案 1.24×，**比值 6.4 倍**。
同一个答案词在两格之间共用字典列，不同答案几乎不共用。角色内复用（1.3–1.8）远低于此。

⇒ 合起来：**输出端不是"少数几个角色模式相加"，而是"每个答案实体各自一条写入方向"。**

### 与 3281 的衔接

3281 测到写入强度 `D_norm` 能预测动态份额（ρ=0.97），而静态中继头族是 9 倍。
T3 的 F3-3 是同一件事从输出端的镜像：结构住在 **q·k 匹配强度**里，
不在"可复用的输出原子集合"里。两处独立测量同向。

### 两处自己的 bug（本轮暴露并修掉，记录在案）

| # | 错误 | 怎么暴露的 | 修法 |
|---|---|---|---|
| BUG-1 | 我声称"3 原子的 R² 上界 = 全局 rank-3 PCA" | OMP 实测 0.541 **高于**我给的"上界"0.477 | 该命题错：不同格可选不同原子，二者约束集无包含关系。删掉"上界"主张，PCA 曲线只作"共享子空间解释多少"的参照 |
| BUG-2 | bootstrap 重采样产生 (i,i) 自配对，Jaccard 恒为 1 | CI 下界 1.813 **高于**点估计 1.788 | 重采样后跳过同索引配对；判据：CI 下界 > 点估计即估计器错 |

BUG-2 修好后 CI 才正常（ag 1.79 [1.52, 2.10]）。

### 纪律补记

- **D17**：稀疏分解的 R² **必须报 held-out**。K 接近 V 时 in-sample R² 必然接近 1
  （本轮 0.989 vs 0.819），拿它当"分解成立"是自欺。
- **D18**：bootstrap **必须跳过自配对**。重采样后 (i,i) 的相似度恒为 1，
  会把整个分布抬上去。**判据：CI 下界 > 点估计 ⇒ 估计器错，不是发现。**
- **D19**：不得声称"某受限模型是另一受限模型的界"，除非两者的约束集确有包含关系。
  本轮 rank-3 PCA（全局单一子空间）与 3-原子 OMP（每格自选原子）**没有**包含关系。

## 九、Q3-T 家族结算：3/3 NULL，预算耗尽，关闭

| 子测 | 判据 | 结果 |

**关闭依据是闸 1 的预算封顶，不是 inv。** 这一点必须说清楚：
预注册 §4 写的关闭条件是"三轮后 inv ≤ 3/8"，但 inv 需要把 T-v1 八个变换全扫一遍，
**本轮没做**。所以现在的状态是：

- Q3-T 的三个操作化**在预算内全部未获支持**；
- **不得再开 Q3-T 的第四种变体**（否则就是 M2：对照空间不开放，永远能再试一次）；
- 但**不能**声称"注意力用身份齿痕做寻址"被永久排除——那需要 T-v1 全扫。
  真要主张，得发新 Phase 做变换族，不能就地补测。

这条划线的意义：闭合靠**预算**执行，不靠"我觉得差不多了"。这是对最初那个
"会不会无限循环"问题的制度性回答——闭环不是靠找到规律，是靠把尝试次数写死。
