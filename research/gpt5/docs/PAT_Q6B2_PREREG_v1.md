# Q6-B2 预注册：A2 的负值，是几何必然还是语义反排列

日期：2026-11-01
上游：`PAT_Q6A_FINDINGS_20261101.md`（A2 同链 cos 37 层全负、中位 −0.246，跨链对照 −0.005）
定位：Q6 家族第 2 轮（预算 3 轮，本轮后仅剩 1 轮）

---

## 0 为什么必须先跑这一测

Q6-A 的 A2 是本项目少见的**反向**结果：同链 `cos(Δ(a→b), Δ(b→c))` 中位 **−0.246**，
而跨链对照 −0.005（精确为 0）。我当时写成「层级不是方向」，并列进 E-07。

但这个结论有一个我**跑完才发现**的漏洞：

> `Δ1 = v_b − v_a` 与 `Δ2 = v_c − v_b` **共享中间词 b，且符号相反**。
> 对独立同分布的各向同性向量，`E[Δ1·Δ2] = −σ²`、`E[‖Δ1‖‖Δ2‖] = 2σ²`，
> 故 `E[cos] = −0.5`。

也就是说，**−0.246 可能只是「共享 b」的几何后果，与语义层级无关**。
跨链对照 = 0 是因为跨链两跳不共享词；它**不能**用来判定同链负值的来源。

若不先分离这一点，E-07 就是一条**把几何必然当语义发现**的记录——正是 PSF-1 §1 的 M1（用点陈述承担规律）。

---

## 1 三个竞争解释（互斥，判决集在 §3）

| 代号 | 解释 | 对 `cos − null` 的预测 |
|---|---|---|
| **G 几何必然** | 负值完全来自共享 b 与各向同性 | ≈ 0，且 null 复现 −0.5 |
| **S 上位词区域** | 上位词（食物/生物/物品）自成一片，与下位词的差向量都反向 | ≈ 0 于 `null_level`，但显著区别于 `null_rand` |
| **H 层级延伸** | 层级确实是一支箭延伸（c 在 b 之外） | > +0.10，且 `t > 1` 的链占比高于 null |

## 2 测量（全部冻结）

### 2.1 主量

对每条链 `(a, b, c)`、每层 `li`：

```
h1 = v_b − v_a ,  h2 = v_c − v_b
u  = unit(h1)
cos = ⟨unit(h2), u⟩
t   = ⟨h2, u⟩ / ‖h1‖            # c ≈ b + t·h1；t>1 表示 c 在 b 之外继续延伸
ρ   = ‖h2 − ⟨h2,u⟩u‖ / ‖h2‖      # 残差比；ρ=0 表示完全共线
```

### 2.2 两个零假设（同一估计器，同时算）

- **`null_rand`**：把 `c` 换成从全词表（37 词）中均匀抽到的 `d ∉ {a,b,c}`，
  重算 `cos(h1, v_d − v_b)`。保留：共享 b 与符号相反、‖·‖ 尺度、维度、n。
- **`null_level`**：把 `c` 换成从**上位词池** `{食物, 生物, 物品, 蔬菜, 水果, 动物}` 中抽到的 `d`。
  这是针对解释 S 的**层级匹配对照**——若负值来自「上位词自成一片」，`null_level` 应同样负。

每个 (链, 层) 抽 **N_NULL = 200** 次。

### 2.3 前置闸 G0（框架失效闸，R-MTH-17）

`null_rand` 的全层中位必须落在 **[−0.65, −0.35]**。
若不在，说明零假设构造错了（例如词表太小、各向同性不成立），
判 **`FRAMEWORK_INVALID`**，不解释 obs。

### 2.4 统计量与功效（D23）

- 逐层取 10 条链的中位，得 37 点剖面。
- 对 `obs − null_rand` 在**峰值层**做 bootstrap（B=1000，重采样单位为**链**），报 95% CI。
- 功效反推：10 条链、配对差的标准差若为 0.15，则 MDE（α=0.05, power=0.8, 双尾）≈ **0.14**。
  ⇒ 判据阈值 **0.10 低于 MDE**，故 `|diff| < 0.10` 只能判「未测出差异」，
  不代表「差异为零」；但 `|diff| < 0.05` 且 CI 含 0 时，可与「G 几何必然」相容。

## 6 跑前修订（SMOKE 暴露，§0–§5 判据不得删改，本节 append-only）

### 6.1 缺陷一：脚本漏掉了已冻结的 `t>1` 条款

§3 的 `HIERARCHY_PARTIAL` 条件是三条并列：`obs−null_rand ≥ +0.10` 的层占比 ≥0.30、
CI 下界 >0、**且 `t>1` 显著高于 null**。脚本只实现了前两条。
SMOKE 实测 `t>1` 层占比 **obs 0.00 vs null 0.00** ⇒ 第三条不成立，
但脚本仍判 `HIERARCHY_PARTIAL`。**这是判据实现错，必须修**（D6：判据缺一条就不是这个判据）。

### 6.2 缺陷二：单一判决把「绝对水平」与「相对差值」压成一个数

SMOKE 实测：`obs ≈ −0.25`、`null_rand ≈ −0.40`、`null_level ≈ −0.30`。
若只看差值，`obs − null_rand = +0.15` 会被读成「层级有部分延伸」；
但 **obs 本身是 −0.25**，而 Q6-A 已确立的共享方向分别是颜色 **+0.40**、大小 **+0.54**。
**−0.25 与 +0.40 之间差 0.65，不可能是同一类东西。**

把两者压成一个判决，就会出现「差值显著 ⇒ 结论成立」这种 M1 式误读。
**修法：拆成主判 + 归因两级，各自独立判决，且必须同时报。**

### 6.3 修订后的判决结构（取代 §3，跑前冻结）

**主判（回答原问题：层级是不是一支方向）**

| 主判 | 条件 |
|---|---|
| `SHARED_DIRECTION` | `obs ≥ +0.30`（沿用 Q6-A 的 TH_W）的层占比 ≥ 0.30 |
| `NOT_A_SHARED_DIRECTION` | 其余（即在全层都没达到「已确立共享方向」的量级） |

**归因（回答负值从哪来；只在主判为 `NOT_A_SHARED_DIRECTION` 时有意义）**

| 归因 | 条件（层占比均 ≥0.30） |
|---|---|
| `PURE_GEOMETRY` | `\|obs − null_rand\| < 0.05` 且峰值层 CI 含 0 |
| `WEAK_ABOVE_GEOMETRY` | `obs − null_rand ≥ +0.10` 且 CI 下界 > 0，**且 `obs − null_level ≥ +0.10`** |
| `SUPERORDINATE_EXPLAINED` | `obs − null_rand ≥ +0.10` 但 `\|obs − null_level\| < 0.05`（对齐全由上位词解释） |
| `ANTI_BEYOND_GEOMETRY` | `obs − null_rand ≤ −0.10` 且 CI 上界 < 0 |
| `ATTRIBUTION_UNCLEAR` | 其余 |

**参照线（不给判据，必须同报）**：在同一次运行里计算 Q6-A 的 F3（颜色）与 F4（大小）的
within-cos 逐层剖面，作为「已确立的共享方向长什么样」的标尺。
没有这条参照线，`−0.25` 和 `+0.40` 无法在同一个刻度上比较。

### 6.4 处置（§4 相应更新，更严格）

- 主判 `NOT_A_SHARED_DIRECTION` 且归因 `PURE_GEOMETRY`
  ⇒ **−0.246 完全不可用**，E-07 从「已否证」改为「**本估计器下不可判**」。
- 主判 `NOT_A_SHARED_DIRECTION` 且归因 `WEAK_ABOVE_GEOMETRY`
  ⇒ 结论写成「层级方向**不存在**（obs 最高 X，远低于共享方向阈值 0.30），
  但存在 +Y 的弱对齐，显著高于几何零假设」。**弱对齐不得改称「部分成立」。**
- 主判 `NOT_A_SHARED_DIRECTION` 且归因 `SUPERORDINATE_EXPLAINED`
  ⇒ 负值改写为上位词区域效应，仍不是层级否证。
