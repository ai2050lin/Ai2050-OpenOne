## 零、一句话

**用一条完全不含答案词的规则——"末位 query 在三个实体上注意力最大的那个槽，就是答案"——
在第 28 层上 held-out 预测 144/144 全对，而同样不看查询的位置规则只有 1/3。**

这是本项目十二轮以来**第一个非 NULL 的判决**。但它是**可预测的描述**，不是机制——
按 D22，还缺一个干预锚点（见 §六）。

## 一、为什么这条规则不是"我知道中文"

这是本 Phase 唯一真正的难点。如果规则写成"ag 的答案是 A"，准确率必然 1.0，
但测到的是我的语言学知识。所以三条规则**只输出"哪个槽"**，槽里的词由句子本身给出：

| 代号 | 规则 | 用的内部量 |
|---|---|---|
| **R1** | `argmax_slot 末位 query 在该槽实体上的注意力质量` | 完整 `s = q·k`，RoPE 后自算 |
| **R2** | 同 R1，但三个实体的 key 换成**去上下文的静态码** `k̄(w)` | 只有 `q·k̄` |
| **R3** | 该句式**最后一个实体槽**，不看查询 | 无（位置规则，真备择） |

五条防作弊：① 规则不含答案词；② 层选择按三元组 5 折，`l*` 只在训练折选；
③ R2 的 `k̄` 来自**独立夹具**（324 次前向，不与被测格共用前缀）；
④ 自算注意力，不用模型 `output_attentions`（bf16 存储，T1 已测 4e-3 误差）；
⑤ 报全层剖面，不只报单点。

**SMOKE 暴露的一处设计错误**：12 个人名里只有「大卫」是单 token，其余全是 2 token
（张/三）。原设计假设"槽 = 一个位置"，不成立 ⇒ 改为按**词跨度**处理，
静态码也按跨度内逐位置存。这条如果没在 SMOKE 抓到，全量会静默算错。

| 规则 | held-out 准确率 | 说明 |
|---|---|---|
| 随机 | 0.3333 | 三选一 |
| **R3 位置规则** | **0.3333** | 不看查询，恰好只对 1/3 |
| **R1 完整注意力** | **1.0000** | 144/144，5 折全部自选 `l* = 28` |
| **R2 静态码** | **1.0000** | 去上下文后不下降 |

## 三、三个防泄漏诊断

`acc = 1.000` 这种满格数字必须先怀疑泄漏，所以加了三道：

| 诊断 | 结果 | 排除什么 |
|---|---|---|
| 规则 vs **模型实际输出** | **0.9722**，恰好等于模型自身行为门 0.9722 | 排除"规则只是复述输出"——在模型答错的 4 格上，规则仍指向正确的槽 |
| `l*` 处分类边际 | 中位 **0.816**、最小 **0.251** | 排除"边际极小、靠临界值凑对" |
| R3 位置规则 | **0.333** | 排除"注意力本来就在最后一个实体上"的位置偏置 |

第二条值得单独说：规则对**意图答案**是 1.000，对**模型实际输出**是 0.9722，
两者之差正是模型自己错的那 4 格。这说明规则描述的是**查询→槽的路由**，
而模型失败发生在路由下游。

## 四、三条可以留下的事实

**F4-1　查询选槽这件事可以被一条纯内部量规则完全预测。** 不含任何答案词，
L28 上 144/144。这是本项目第一次拿到的"规则型"正面结果。

**F4-2　路由决策集中在 L21–L23，不是读出层。** 三层爬升 0.590 → 0.653 → 0.972；
L20 及以前与位置规则同分（0.312–0.354），L23 起接近天花板。
与 Q2-C1 的读出点在 L33 相衔接：**L21–L23 决定去哪个槽，L33 才把内容读出来。**
注意 L35 塌到 0.562——最后一层的注意力不再指向答案，规则的有效区间是 L23–L34。

**F4-3　匹配用的是去上下文的静态实体码。** 把三个实体的 key 整体换成跨上下文平均值 `k̄`，
准确率仍 1.000。与 T2 的 share_ctx ≈ 0.01 一致。

> **但 F4-3 要打折看**：T1 已测到同词跨上下文 key 的 cos = 0.998，
> 所以 `k̄ ≈ k` 几乎是恒等式，R2 ≈ R1 在很大程度上是 T1 的推论，不是独立证据。
> 它排除的是"上下文特异改写影响选槽"，不是"上下文完全不参与计算"。

## 六、本轮不能声称什么（D22）

**这不是机制，是可预测的描述。** 机制三件套缺第二件：

- (i) 可预测的规则 ✅
- (ii) 一处方向性干预 ❌
- (iii) 跨变换族稳定 ❌（只做了 t1 主/被动，8 个变换里的 1 个）

按 D10，本轮结论只能叫"规律"（E1 级）或"描述"，**不能叫机制**。

下一 Phase（Q4-P，已预注册，未开跑）补的就是 (ii)：
**在 L20 把末位 query 的激活换成另一个查询的，预测槽与输出应当一起翻**。
按 D20，锚点落在**末位位置的内容**上，不落在任何头上。
若预测成立 ⇒ 升 E2，与 (i) 合成机制候选；若不成立 ⇒ 规则只是相关，退回描述。
