## 1 相对 D1 的三处改动（每一处都写明理由）

### 1.1 剂量网格收窄到 ±2

`δ ∈ {−2, −1, −0.5, 0, +0.5, +1, +2}`，最大相对位移 6.1%。

理由：D1 实测 |δ|≥4 时 top-1 一致率掉到 ≤0.73、|δ|=8 时掉到 0.17。±2 是**唯一被证明不破坏模型的量程**。
这不是"挑能出结果的范围"——恰恰相反，D1 在 ±2 上给的是零，D2 把最不利的范围锁定下来测。

### 1.2 能力门改用"分布形变"而不是"top-1 一致率"

D1 的门 `top-1 一致率 ≥ 0.75` 在本材料上**过严**：基线 `top1_p` 中位只有 0.243，分布本来就平，
top-1 在近似并列项之间跳是正常的，跳 27% 不等于坏了。

D2 的门：**`ΔH_med ≤ 0.30 nat` 且 `top-1 一致率 ≥ 0.60`**。
依据（全部来自 D1 的实测，不是拍脑袋）：
- D1 健康剂量（±1/±2）的 ΔH 是 −0.028…+0.025，坏的剂量是 +1.257/+1.956 ⇒ 0.30 能把两者干净分开；
- 0.60 允许平局抖动，但不允许"几乎全变"（D1 坏剂量是 0.055/0.170）。

判 `DEGRADED` 的条件同步改为 **剔除数 ≥ 半数**（7 档里 ≥4）。

### 1.3 新增同流形对照 `EMB`

D1 的 C3 里 FREQ 的 KL 是 RAND 中位的 **20.8 倍**。这个数字**不能**当功能证据：
RAND 是各向同性随机向量，本来就"离开嵌入流形"；而 w_freq 是从真实数据回归出来的方向，
必然落在流形上。所以 20 倍可能只是"在流形上 vs 不在流形上"。

D2 加 `EMB` 对照：**随机取两个真实 token 的嵌入之差**（中心化后归一化到 ‖u‖）。
它在流形上、语义上与频率无关。若 `EMB` 的 KL 与 FREQ 同量级 ⇒ D1 的 20 倍作废。
Qwen 8 个、GLM 4 个。

## 2 判据

除下列改动外，全部沿用 D1 §2 的 C1–C8 定义（统计量、口径、CI、MDE 一致）。

### C1′ 因果传导（主判，`FREQ × IN × LAST`）

`ρ_dose` = ΔE[zipf] 对 δ 的 Spearman（7 档）；主剂量 `ΔE(+2)`。

| 判决 | 条件 | 含义 |
|---|---|---|
| `CAUSAL_KNOB` | \|ρ\|≥0.8 且 ΔE(+2) ≥ +0.10 且 CI 不含 0 | 旋钮成立 |
| `CAUSAL_KNOB_INVERSE` | \|ρ\|≥0.8 且 ΔE(+2) ≤ −0.10 且 CI 不含 0 | 成立但反号 |
| `WEAK_COUPLING` | \|ρ\|≥0.8，\|ΔE(+2)\| ∈ [MDE, 0.10) | 有效应但小 |
| **`NULL_BOUNDED`** | MDE ≤ 0.02 **且** \|ΔE(+2)\| < MDE | **耦合被压在 2 个千分位以内**（定量界，比"没测到"强） |
| `KNOB_NOT_USED` | 其余 | 测不出 |

`NULL_BOUNDED` 是本轮新增的判决词，只有在 MDE 真的小到 0.02 以下才允许用；
MDE 大于阈值时仍判 `PENDING_POWER`（D23）。

### C3′ 方向特异性（三个对照并列）

同时报 FREQ / RAND / EMB 的 `|ΔE(+2)|` 与 `KL`：

| 判决 | 条件 |
|---|---|
| `DIRECTION_SPECIFIC` | \|ΔE\| 同时 > RAND p95 且 > EMB p95，且 ≥ 2× 两者中位 |
| `ON_MANIFOLD_ONLY` | \|ΔE\| 只 > RAND p95，但 ≈ EMB ⇒ 效应来自"在流形上"，不是频率方向 |
| `GENERIC_PERTURBATION` | 同时 ≤ 两者 p95 |

### C4′ / C6′ / C8

沿用 D1（`READOUT_ARTIFACT` / `INPUT_DRIVEN` / `MIXED`；`LOCAL_TOKEN_KNOB` / `GLOBAL_OFFSET` / `POSITION_CONCENTRATED`；`SEMANTICS_INTACT` / `SEMANTICS_HURT`）。

### C7′ 跨模型

Qwen 与 GLM 并列 C1′。两模型都 `NULL_BOUNDED`/`KNOB_NOT_USED` ⇒ D1 的 `KNOB_NOT_LOCAL` 扩展为"两模型都不接输出"。

## 3 噪声底（D1 实测，用于解释阈值）

D1 的 batch 不变性检查：32 vs 64 的 `max|Δlogit| = 0.339`、**逐 prompt `max|ΔE[zipf]| = 0.048`，但均值只差 0.0007**。
我们的推断统计量是**均值**，所以相关噪声底是 **7×10⁻⁴**，比 MDE（9.5×10⁻³）小一个数量级。
⇒ bf16 的内核差异不影响均值层面的判决，但**不能**对单个 prompt 的 E[zipf] 做逐条解释。
