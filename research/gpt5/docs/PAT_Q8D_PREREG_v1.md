日期：2026-11-01
上位：`PAT_Q8B_FINDINGS_20261101.md`（B5 静态预检给出 `SMOOTH_KNOB` / `KNOB_NOT_LOCAL`）
目标等级：**E2（干预）**，前提是 C1+C3+C4 全过；否则维持 E1。

---

## 零、这一轮要回答的问题

Q8-B 得到一个方向 w（嵌入空间里对 zipf 做最小二乘的方向），并证明：

- 它是**对数刻度**的、**与范数正交**、**与语义正交**、**4–16 维稠密**；
- 静态地"推一下看邻居"，Qwen 的邻居频率跟着走 0.67 格（`SMOOTH_KNOB`），GLM 无论推多少都撞在 +3.1 上（`KNOB_NOT_LOCAL`）。

**但这些都是搬表里的行、没有跑前向。** 所以到现在为止只能说：频率是表里的一个**排序轴**。

这一轮问的是唯一还没问的那句：

> **这个排序轴，模型在前向里用不用？**

具体操作：把上下文某个位置的 token 表示沿 w 平移 δ，看**下一个 token 的分布**是否往同方向偏。

## 1 材料

### 1.1 干预方向

沿用 Q8-B 的 POOL（CHAR ∪ WORD，仅取有 `wordfreq` 定义的行）与 zipf 轴，重解一次

```
w = argmin ‖(E[idx] − μ) w − (zipf − mean)‖²  +  λ·tr(G)/d·‖w‖²
```

定义**剂量方向** `u = w / ‖w‖²`。这样 `e_t ← e_t + δ·u` 使**线性预测的 zipf 精确平移 δ**，δ 的单位就是 zipf。

**剂量网格（2026-11-01 冻结前标定，只测了静态表的尺度，没跑任何前向）**：

| | Qwen3-4B | GLM-4-9B |
|---|---|---|
| `‖u‖` | 0.03640 | 0.00504 |
| `median‖e‖` | 1.1985 | 0.1036 |
| δ=1 的位移 / median‖e‖ | **3.0%** | **4.9%** |
| δ=2 | 6.1% | 9.7% |
| 位移达 10% / 20% / 40% 对应的 δ | 3.29 / 6.58 / 13.17 | 2.06 / 4.12 / 8.23 |
| 线性预测 t 的 std | 0.915（真 zipf std ≈ 1.0） | 0.666 |

原打算用 δ∈{−2,…,+2}，标定后**作废**：那套网格最大只到 token 范数的 6%，几乎不可能看到前向变化。
改为 **δ ∈ {−8, −4, −2, −1, 0, +1, +2, +4, +8}**（9 档），覆盖 median‖e‖ 的 3%–24%（Qwen）/ 5%–40%（GLM）。

两件事必须并列报，不许只报 δ：(1) `‖δ·u‖ / median‖e‖`；(2) δ 相对**频率轴自身**的尺度——线性预测 t 的 std ≈ 0.9–1.0，所以 δ=2 已经是"把这个词的频率推 2 个标准差"。跨模型不能比绝对值（Q8-B §5 注 2：GLM 平均范数比 Qwen 小一个数量级），**GLM 每单位 δ 的相对位移是 Qwen 的 1.63 倍**，读结论时按相对位移对齐，不要按 δ 对齐。

### 1.2 对照方向

| 名 | 定义 | 检验什么 |
|---|---|---|
| `FREQ` | `u` | 主条件 |
| `RAND` | 随机单位向量，缩放到 `‖δ·u_RAND‖ = ‖δ·u‖`（**位移长度对齐**），K=8 个固定种子 | 是不是任何等幅扰动都会动 |
| `RAD` | 逐 token 径向方向 `e_t/‖e_t‖`，缩放到同一位移长度 | 是不是"改范数"就够（Q8-B B3 已证频率⊥范数，这里做前向对应） |

### 1.3 干预位置

| 名 | 定义 |
|---|---|
| `LAST` | 只改**最后一个 token** 的输入表示（紧邻生成位） |
| `ALLPOS` | 改 prompt 里**全部 token** 的输入表示（等价于"改表里这些类型的行"） |

### 1.4 干预臂（tied 混淆的分离）

探针已验：Qwen3-4B `tie_word_embeddings=True`，`embed_tokens.weight is lm_head.weight`（同一 data_ptr）；解绑成独立 Parameter 后 logits 逐位不变（max\|Δ\|=0.000e+00）。

| 臂 | 输入侧 | 读出侧 | 含义 |
|---|---|---|---|
| `BOTH` | 改 | 改 | 就地改表的自然后果（tied 模型的默认行为，也是 B5 静态分析的隐含假设） |
| `IN` | 改 | 不改 | **纯输入效应**（主判用这个） |
| `OUT` | 不改 | 改 | **纯读出效应**（自证解码器） |

GLM-4-9B `tie=False`，`BOTH` 与 `IN` 在输入侧等价，`OUT` 仍独立；照跑三臂以便并列。

### 1.5 Prompt 集

200 条，**确定性生成**（固定种子 20261101，固定模板 + 固定词表），不手挑：

- 模板 24 条（陈述/疑问/并列/因果各 6），槽位从固定词表（40 个常用名词 + 20 个常用动词）抽样；
- 长度 10–18 token，**末位是内容词**（不是标点、不是功能词）；
- 干预只作用于末位（`LAST`）或全序列（`ALLPOS`），读出取 `logits[-1]`。

**为什么要末位是内容词**：功能词（的/了/是）的嵌入被平移后语义后果不可解释，会把"频率效应"和"语法破坏"混在一起。这条是口径，写死。

### 1.6 规模

| | Qwen3-4B | GLM-4-9B |
|---|---|---|
| `FREQ` 前向数 | 2 pos × 9 δ = 18 | 18 |
| `RAND` 前向数 | 8 种子 × 2 pos × 9 δ = 144 | 4 种子 × 2 pos × 9 δ = 72 |
| `RAD` 前向数 | 2 pos × 9 δ = 18 | 18 |
| 合计前向 | 180 | 108 |
| 每条件 batch | 32（7 批） | 16（13 批） |
| 预计总耗时 | ~2 min | ~18 min |

`OUT` 臂**不消耗前向**：输入不变 ⇒ 隐藏态与基线相同，只需在末位 logits 上给受影响的 token 行加 `δ·(h·u)`。
`BOTH` 与 `IN` 共用同一次前向（区别只在读出头）。

GLM 条件数少是因为本机只有 17.1 GB 显存、权重 18.8 GB，必须 offload 10 个模块到 CPU（探针 2：bs=16 为吞吐最优 0.745 s/批，bs=96 换页退化到 9.288 s）。**GLM 的 RAND 只跑 4 个种子**，Qwen 跑 8 个——这个不对称必须在结论里写明。

### 1.7 SMOKE 的边界

SMOKE（8 条 prompt / 3 档 δ / 1 个 RAND 种子 / batch 4）**只验管线**：`p_M` 是否健康、`max|logit|` 是否溢出、δ=0 三臂是否逐位一致、batch 32 vs 64 是否一致。**不看任何判决**。SMOKE 若显示 `p_M` 中位 < 0.5，允许调整 prompt 模板（属材料口径，记 §8），不允许调整 §2 的任何阈值。

## 2 判据

所有统计量定义：

- `p` = softmax(logits[-1])；`M` = 有 zipf 定义的行（Qwen 49.2% / GLM 51.4% 词表）
- **主指标** `E[zipf] = Σ_{i∈M} p_i z_i / Σ_{i∈M} p_i`（在可定义频率的行上重新归一化）
- 副指标：`top1_zipf`、`top10_zipf`（均值）、`H`（熵）、`top1_p`、`KL(p‖p_δ=0)`
- `ΔE[zipf](δ) = mean_prompts E[zipf](δ) − mean_prompts E[zipf](0)`，bootstrap 1000 次给 CI（按 prompt 重采样）

### C1 因果传导（主判）

条件：`FREQ` × `IN` × `LAST`。
统计量：`ΔE[zipf]` 对 δ 的 Spearman 相关 `ρ_dose`，以及 `ΔE[zipf](+2)` 的绝对值。

（用 +2 而不是 +1 作为主剂量：标定显示 δ=1 只有 3% 位移，功效不足；+2 ≈ 6% 位移、2 个频率标准差，是"能看出东西"的最小档。）

| 判决 | 条件 |
|---|---|
| `CAUSAL_KNOB` | `ρ_dose ≥ 0.8` 且 `ΔE[zipf](+2) ≥ +0.10` 且 CI 不含 0 |
| `CAUSAL_KNOB_INVERSE` | `ρ_dose ≤ −0.8` 且 `ΔE[zipf](+2) ≤ −0.10` 且 CI 不含 0 |
| `WEAK_COUPLING` | 单调（\|ρ\|≥0.8）但 \|Δ(+2)\| < 0.10，或 CI 含 0 |
| `KNOB_NOT_USED` | \|ρ_dose\| < 0.8 |

**方向先验**：预注册预测 `CAUSAL_KNOB`（正号）。若出现 `CAUSAL_KNOB_INVERSE` 也算"在前向被使用"，但**符号与直觉相反这件事必须单列**，不得含糊说成"验证了旋钮"。

阈值 0.10 zipf 的来源：Q8-B 的 `E[zipf]` 材料本身跨 1–7 zipf；0.10 ≈ 一个"常用/次常用"档位的 1/5，小于它无法与采样噪声区分。**MDE 必须跑后报**（D23）：按 200 prompt、δ 内配对差，若 MDE > 0.10 则 C1 的阈值判不了，改判 `PENDING_POWER`。

### C2 剂量形状

对 8 个非零 δ 的 `ΔE[zipf]` 拟合 `a·δ + b`：`R² ≥ 0.90` → `LINEAR`；`|ΔE[zipf]|/|δ|` 从 δ=1 到 δ=8 递减超过 50% → `SATURATING`；符号在非零 δ 内翻转 → `NONMONOTONE`。

### C3 方向特异性（**比 C1 更重要**）

把 `|ΔE[zipf](+2)|`（FREQ）与 8 个 `RAND` 方向的 `|ΔE[zipf](+2)|` 分布比较（GLM 用 4 个）：

| 判决 | 条件 |
|---|---|
| `DIRECTION_SPECIFIC` | FREQ 的 \|Δ\| > RAND 的 p95，且 FREQ 的 \|Δ\| / RAND 中位 ≥ 2.0 |
| `GENERIC_PERTURBATION` | FREQ 的 \|Δ\| ≤ RAND p95 |

**并且**必须在 **KL 匹配**下比较：报 `|ΔE[zipf]| / sqrt(KL)`，FREQ 与 RAND 并列。理由：随机方向也能把分布推得动（KL>0），只比 \|Δ\| 会把"扰动大"误读成"方向对"。若 KL 差 3 倍以上，C3 判决降级为 `INCONCLUSIVE_KL`。

### C4 tied 混淆归因

比较 `|ΔE[zipf](+2)|` 在 `IN` 与 `OUT` 两臂：

| 判决 | 条件 | 含义 |
|---|---|---|
| `READOUT_ARTIFACT` | IN/OUT < 0.30 | 效应只在解码器，不是前向使用 |
| `INPUT_DRIVEN` | IN/OUT > 3.0 | 效应在输入侧 |
| `MIXED_CONTRIBUTION` | 0.30 ≤ IN/OUT ≤ 3.0 | 两路都有 |

C1 的判决词归属：若 C4 判 `READOUT_ARTIFACT`，则 C1 的 `CAUSAL_KNOB` **自动降级为** `CAUSAL_KNOB_READOUT_ONLY`，不得作为 E2 证据（见 §4）。

### C5 能力门（不是结论，是剔除规则）

逐 δ 检查：`H` 相对基线增加 ≤ 0.5 nat，且 top1 与基线一致率 ≥ 0.75。

- 不满足的 δ 标 `DEGRADED`，从 C1/C2 的曲线中剔除，**但必须逐条列出**；
- 若 9 个 δ 里有 ≥ 4 个被剔除，C1 整条判 `DEGRADED`，本轮不给因果结论。

### C6 位置特异性

`|ΔE[zipf](+2)|` 在 `ALLPOS` 与 `LAST` 的比值：

| 判决 | 条件 | 含义 |
|---|---|---|
| `LOCAL_TOKEN_KNOB` | 0.5 ≤ 比值 ≤ 2.0 | 是"某个词的旋钮" |
| `GLOBAL_OFFSET` | 比值 > 3.0 | 是全局偏移，不是词级旋钮 |
| `POSITION_CONCENTRATED` | 比值 < 0.5 | 只在末位管用 |

### C7 跨模型

Qwen 与 GLM 的 C1 判决并列：

- 两者都 `CAUSAL_KNOB*` → **撤回** Q8-B 「`SMOOTH_KNOB` vs `KNOB_NOT_LOCAL` 是模型指纹」的强表述，改为"静态邻域结构不同，但前向都接"。
- Qwen `CAUSAL_KNOB` 而 GLM `KNOB_NOT_USED` → 与 B5 一致，`FUNCTION_MODEL_SPECIFIC` **加固**（从静态预检升为前向证据）。
- 两者都 `KNOB_NOT_USED` → **撤回 Q8-B 的 `SMOOTH_KNOB`**："能拧`邻居`"不等于"能拧`输出`"。

### C8 语义副作用（负对照）

用 40 条**唯一答案**探测句（如「中国的首都是」「一加一等于」），末位不是被干预位（干预施加在前缀的内容词上），检查 top-1 命中率相对基线的下降。

| 判决 | 条件 |
|---|---|
| `SEMANTICS_INTACT` | 下降 ≤ 0.10 |
| `SEMANTICS_HURT` | 下降 > 0.10 |

若 `SEMANTICS_HURT`，即便 C1 过，也只能说"干预动了频率输出，但同时破坏了语义"——不能说是频率坐标的作用。

## 3 已知陷阱（跑之前先钉死）

1. **tied 的全局平移恒等性**：tied 模型下"把整张表所有行平移 δ·u"，读出侧等价于给**所有 logit 加同一个常数**，对 softmax 完全无影响。所以"改整张表"这个操作在 tied 模型上**不可能有读出侧效应**，只有输入侧效应。不许把"没变化"读成"方向没用"。
2. **dose 的绝对幅度跨模型不可比**：δ 是 zipf 单位，但 ‖u‖ 依赖 w 的尺度与 d。必须并列报 `‖δu‖/median‖e‖`。
3. **E[zipf] 的重归一化口径**：只在有 zipf 定义的行上重归一化（约一半词表）。若某个方向的效应主要是"把概率挪到无定义行"（残片、标点、代码），重归一化会人为放大 \|Δ\|。**必须并列报 `p_M = Σ_{i∈M} p_i` 的变化**；若 `p_M` 变化 > 0.05，主指标不可用，退到 `top1_zipf`。
4. **批内 padding 污染**：右 padding 时 `logits[-1]` 不是真末位。必须取 `logits[arange, len-1]`，并用 attention_mask 校验（探针里 `(1,7)` 说明 tokenizer 已吃掉行尾，取的是真末位）。
5. **bf16 数值**：δ=2 时位移可能达 token 范数的 50%，bf16 下 attention 的 softmax 可能溢出。逐条件报 `max|logit|`，超过 60 记 `UNSTABLE`。
6. **prompt 集泄漏**：词表是常用词，可能与 Q8-B 的 POOL 重叠——没关系（不同用途），但**不许**用 Q8-B 的池子挑 prompt（会引入频率选择偏差）。prompt 词表在 §1.5 定死。
7. **单种子**：各模型 1 个 prompt 种子。prompt 集是固定的，不加种子方差；但 **RAND 方向必须多种子**（这是 C3 的分母）。
8. **batch 大小影响 bf16 结果**：同一条件不同 batch 划分会有 1e-3 级差异。固定 batch（Qwen 32 / GLM 16），并在 SMOKE 里验一次"batch 32 vs 64 的 logits 一致性"。

## 4 E 级归属（先写死，不许跑完再调）

| 结果组合 | 等级 | 可以说 |
|---|---|---|
| C1=`CAUSAL_KNOB*` ∧ C3=`DIRECTION_SPECIFIC` ∧ C4≠`READOUT_ARTIFACT` ∧ C5 未 DEGRADED ∧ C8=`SEMANTICS_INTACT` | **E2** | 频率方向在前向被使用，且是方向特异的 |

| C1=`KNOB_NOT_USED` | E1 | 频率方向是表里的排序轴，不参与计算 |
| C5=`DEGRADED` | E0 | 干预把模型打坏了，不给结论 |

**E3 本轮不适用**：E3 需要 E1 + E2 + 跨模型迁移，且迁移还得是"机制"而非"判决"。本轮跨模型只到 C7。

## 5 预注册的、将被证伪的表述

1. 若 C2 判 `NONMONOTONE`，则撤回 Q8-B「频率是一根旋钮」的措辞，改称"一个方向"。
2. 若 C3 判 `GENERIC_PERTURBATION`，则撤回 Q8-B B5 的"可拧性"整条解读（`SMOOTH_KNOB` / `KNOB_NOT_LOCAL` 都退化为"扰动幅度的函数"）。
3. 若 C4 判 `READOUT_ARTIFACT`，则声明「tied 模型的嵌入表频率方向是**解码器自证**」，并回收 Q8-A/Q8-B 中所有"模型知道词频"的暗示性表述。
4. 若 C7 两者都 `KNOB_NOT_USED`，则 `FUNCTION_MODEL_SPECIFIC` 这一跑后标签**作废**（因为它的两个分项都不再成立）。
5. 若 C8 判 `SEMANTICS_HURT`，则本轮所有正向结论降级为"干预-输出相关"，不得写"机制"。

## 6 不允许的表述

- 不说"模型用 w 计算频率"——只能说"沿 w 平移会改变输出频率分布"。方向是**干预手段**，不是已证的计算通路。
- 不说"因果箭头是 w → 频率"：干预的是输入表示，途经的中间层一律未观测。
- 不把 `E[zipf]` 说成"模型认为下一个词多常见"——它是**可定义频率行上的期望**，口径依赖重归一化。
- 不跨模型比 `E[zipf]` 绝对值（Q8-B §5 注 2）。
- 不把 GLM 的 offload 差异当作模型性质。
