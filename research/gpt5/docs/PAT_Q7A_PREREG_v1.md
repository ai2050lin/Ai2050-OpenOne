状态：**跑前冻结**。§1–§5 为冻结判据，§6 为跑前修订（append-only）。

## 0 为什么是这一题（不是 Q6 第四轮）

Q6 全家族问的是「关系在**词对上**是不是一支方向」，三测已闭合（A / B2 / B）。
本 Phase 问的是**完全不同的题**：

> 给一对句子 (A, B)，模型内部有没有一个**与具体内容无关**的量，能被固定线性映射读出
> 「顺承 / 转折 / 因果」，并且这个映射在**从未见过的内容**上仍然成立？

三点与 Q6 家族的区别：

| | Q6 家族 | Q7-A |
|---|---|---|
| 测量对象 | 词对的差向量 | 句对的残差流位置 |
| 判据形态 | 剖面（余弦份额） | **预测（留出内容的分类准确率）** |
| 内容控制 | 词表内换词 | **主题词全不相交的 18 个内容** |
| 表面控制 | 无 | **显式连接词 vs 隐式（无连接词）** |

`转折` 与 `颜色` 的根本不同：颜色是「实体→值」的**单点映射**，转折是「A→B 的**关系**」。
颜色的测量点是名词，转折的测量点是**连接词位置与从句边界**。所以本 Phase 必须换位置、换判据。

按 D24（判据优先级：预测 > 剖面 > 点陈述），本 Phase 的主判**全部是预测型**，
且预测型的错误没有「换个子集仍显著」的退路。

## 1 设计（冻结）

### 1.1 三因子

| 因子 | 水平 | 说明 |
|---|---|---|
| **关系 REL** | 3：顺承 `seq` / 转折 `con` / 因果 `cau` | 标签 |
| **内容 CONT** | **18**：主题词两两不相交 | 同一内容的三个变体共用同一主题词 |
| **表面 SURF** | 3：`S1` 连接词+逗号 / `S2` 连接词+句号 / `S3` 隐式（无连接词） | 隔离「读到连接词这个 token」 |

句子总数 **18 × 3 × 3 = 162**。每个 (内容, 关系) 单元有一个手写 B 从句。

- `S1`：`A，CONN，B。`
- `S2`：`A。CONN，B。`
- `S3`：`A。B。`（**无连接词**，关系只由语义承载）

连接词按 `CONN[rel][content_idx % 3]` 轮换（顺承：然后/接着/随后；转折：但是/可是/不过；
因果：所以/因此/于是）。轮换的目的：让同一关系的连接词在训练折与测试折之间**必然不同**，
使探针无法靠单一 token 身份过关。

### 1.2 内容控制（机器可校验）

每个内容声明 2 个**主题词**，必须满足：

1. 两个主题词都出现在该内容的 A 与全部 3 个 B 中（内容匹配，关系变动）；
2. 任一主题词**不出现在**其它 17 个内容的任何句子中（跨内容不相交）。

两条都在脚本里断言，不满足即 `STIMULI_INVALID`，不跑下游。

### 1.3 测量位置（3 个，全部报）

| 位置 | 定义 | 角色 |
|---|---|---|
| `P_END` | 全段最后一个 token（结尾句号） | **主判位置** |
| `P_CONN` | 连接词首 token（仅 S1/S2） | 控制：是否只是连接词 token 身份 |
| `P_AE` | A 末尾 token（A 后标点） | **对齐自检**（J0） |

`P_AE` 的正则性：同一 (内容, 表面) 下三个关系的**前缀完全相同**，所以该位置上的三点输入逐位相同。

### 1.4 切分与选层（冻结，防泄漏）

- 外层：**6 折，按内容**（`content_idx % 6 == f`），每折测试 3 个内容 = 27 句，训练 15 个内容 = 135 句。
- `alpha`：只在层 17、位置 `P_END` 上用内层 5 折（按内容）从 `{0.01, 0.1, 1.0} × n_train` 选一次，**全程冻结**。
- `l*`（选层）：**每个外层折内部**用内层 5 折（按内容）在 36 层上选出，测试折只用来评一次。
- 不依赖测试折的任何量（含逐维标准化统计量：只用训练折的均值/方差）。

### 1.5 探针

- 线性：标准化特征的岭回归（对 one-hot 目标），对偶闭式解 `A = (K+αI)^{-1}Y`。
- 判定：`argmax` 三类得分。
- 不做特征选择、不做 PCA、不用非线性。

## 2 判据（冻结）

地板（三选一）= **0.3333**。所有准确率必须同时报**离地板的距离**（D4）。

### J0 对齐自检（管线）

`P_AE` 上，每个表面水平的留出准确率必须**恰等于 0.3333**（三点输入逐位相同 ⇒ 预测必然相同 ⇒
每内容恰对 1/3）。偏离即 `PIPELINE_LEAK`，停止解释。

### J1 稳定（主判，预测型）

`P_END`，冻结协议下的留出准确率 `acc_J1`（162 句合并），内容级 bootstrap 95% CI。

| 判决 | 条件 |
|---|---|
| `PASS` | `acc_J1 ≥ 0.60` 且 CI 下界 > 0.3333 |
| `WEAK` | `0.3333 < acc_J1 < 0.60` 且 CI 下界 > 0.3333 |
| `NULL` | CI 下界 ≤ 0.3333 |

### J2 表面解耦（主判，预测型；本 Phase 最关键的一条）

**`S1+S2 → S3` 迁移**：在显式连接词的句子上训练，在**隐式（无连接词）**的同一内容上测试，
按内容留出。判据与 J1 同档（`PASS ≥ 0.55`，`WEAK`，`NULL`）。

三条辅助，全部报：

- `S3 → S1+S2`（反向迁移，训练样本少，只报不判）；
- `S1 → S2`（**标点最小对**：词全同、只差一个标点；这一条应高，用来证明不是长度/位置假象）；
- `P_CONN` 上的准确率（若 `P_CONN` 高而 `S1+S2 → S3` 塌，则结论是「码=连接词 token」）。

### J3 复用（主判，秩压缩曲线）

把该折的探针权 `W`（`d×3`）SVD 截断到秩 `k ∈ {1,2,3}`，在测试折上重评准确率：

| 曲线形状 | 判决 | 含义 |
|---|---|---|
| `acc(k=1) ≥ acc(k=3) − 0.05` | `SHARED_AXIS` | 三种关系落在**同一条轴**的不同位置 ⇒ 强复用差分 |
| 否则 `acc(k=2) ≥ acc(k=3) − 0.05` | `PARTIAL_SHARING` | 两支（例如转折独立、顺承/因果共享） |
| 都不满足 | `PRIVATE_DIRECTIONS` | 三支各自独立，几乎无共享 |

秩-1 的几何含义是确定的：`W ≈ u vᵀ` ⇒ 得分 `u_c (v·x)` ⇒ 分类由**一个标量** `v·x` 的阈值决定。

### G0 刺激有效性闸（跑前跑，信息性但硬）

用**隐式**句对（无连接词）做元语言选择：
`「{A}。{B}。这两句的关系是什么？只回答一个词：顺承、转折、因果。答：」`，读三个标签首 token 的 logit。

| `acc_G0` | 处置 |
|---|---|
| ≥ 0.50 | 刺激有效，正常解释 |
| 0.40–0.50 | `STIMULI_WEAK`：报数，结论降级为「内部可读但模型不能命名」 |
| < 0.40 | `STIMULI_INVALID`：**不发 J1–J3 判决**，先改材料 |

理由：这是本轮唯一能证伪「我手写的 B 真的表达了那个关系」的量。G0 在 SMOKE 阶段就先跑一次，
不达标则在 §6 记录改材料，不进入正式跑。

### 零分布

标签在**内容内**置换（3 个 B 的标签循环错位），重跑全管线 10 次，报均值与 95 分位。
置换保持内容/长度/词汇分布不变，只破坏「标签—句子」配对。

### 框架前置闸

`acc_J1 < 0.45` ⇒ `FRAMEWORK_INVALID`：不解释 J2/J3。含义是**测量位置或表征层选错了**，
不是「关系不存在」。此判据与 §9.5 的自检条款对齐（PSF-2 若有效，预测型判据应产出数字）。

## 4 关闭条件与功效（D23）

- 本 Phase **一次性**：J0–J3 与零分布一起跑完，不追加变体。
- 关闭前必须报 **MDE**：以 18 个**内容簇**重采样的口径，模拟求 α=0.05、power=0.80 下
  相对地板（0.3333）的最小可测提升。若 MDE > 0.30，则本设计只能判「远高于地板 / 在地板上」，
  不得声称「部分可读」。
- 若 J1 落在 `WEAK` 且 MDE 覆盖它 ⇒ 判 `UNDERPOWERED`，不给 `WEAK_ONLY` 结论词。

## 6 跑前修订（append-only）

以下四条均在**正式跑之前**写入，日期 2026-11-01，SMOKE 已过（管线、索引、断言全通）。

### 6.1 材料主题词覆盖：断言抓到 14 处缺失，已改

原稿中 14 个 (内容, 主题词) 组合没有同时出现在 A 与三个 B 里（例：内容 1 的「台风」
三个 B 全无；内容 7 的「前锋/教练」A 里全无）。断言按设计拦下，材料已重写：
现在每个主题词在 A 与全部 3 个 B 中都出现，跨内容仍两两不相交（复检 0 冲突）。

这条本身是「机器可校验断言」的价值证明——手写材料必然有这类漏洞，靠肉眼看不出。

### 6.2 G0 从「硬闸」降级为「条件诊断」，并新增 G0b

SMOKE 阶段实跑了三种行为口径，三者互相打架：

| 口径 | 总准确率 | 顺承 | 转折 | 因果 |
|---|---|---|---|---|
| G0a 元语言三选一（隐式） | 0.5926 | 0.889 | **0.278** | 0.944 |
| G0b 连接词契合度·原始 | 0.4444 | 0.778 | 0.333 | 0.222 |
| **G0b 连接词契合度·去偏** | **0.4815** | 0.389 | **0.611** | 0.444 |

诊断：
- G0a 有**标签先验偏置**——模型几乎不吐「转折」，把转折句归给顺承；
- G0b 原始版有**约束力偏置**——「然后」约束最弱，`p(B | 然后)` 天然最高；
- 逐连接词减全局均值去偏后，转折反而是三者里最好分辨的（0.611）。

⇒ **处置**：G0 的作用不是"及格线"，因为它自己就有三个互相矛盾的读数。
新规则：G0 只在**结果为 NULL / WEAK 时**用来区分「模型不编码」与「我的材料没表达出关系」；
正式跑只保留一条「粗失败」闸 `g0b 去偏 < 0.30`（当前 0.4815，远高于此）。
若 `g0b 去偏 < TH_G0_GRAY(0.40)`，结果里置 `stimuli_unverified=True` 并在结论中标注。

**必须承认**：这条修订是在看到三个数字之后做的。防事后解释的办法不是假装没看见，
而是把三个口径**全部**报出来，并说明「去偏版」为什么是较可用的那个（约束力偏置有明确的
统计机制，标签先验偏置也有），而不是选出最好看的那个当门。

### 6.3 `P_CONN` 只统计显式表面

隐式（S3）没有连接词位置，原实现把 `P_CONN` 退化为 `P_END`，会把 2/3 的 S1/S2 与 1/3 的 S3
混在一起，系统性稀释「连接词位置」这个控制量的读数。改为只对 S1/S2 统计。

### 6.4 零分布改为「每内容独立置换」

原稿写「内容内标签循环错位」。**这是错的**：对每个 (内容, 表面) 用同一个循环位移，
等价于全局重命名三个类，分类器学一遍就回来了，零分布会等于真准确率。
改为**每个内容抽一个独立置换** `π_ci`，使「标签—句子」的对应关系跨内容不一致，
此时任何一致性映射都不存在，零分布才真的塌到 1/3。

### 6.5 MDE 模拟的随机源固定为单一实例

原实现在循环内新建 `default_rng(SEED)`，导致每次模拟抽到同一批随机数，power 曲线是假的。
改为函数内单一 `rng`（SEED+7）持续抽样。

### 6.6 保留一条已知的弱分离，不修

去偏 G0b 显示**顺承 0.389 / 因果 0.444**，两者只在弱分离——
「A 之后发生的事」与「A 导致的事」在中文叙事里本来就高度重叠（`然后` 对两者都通）。
本 Phase 不为此改材料，而是在结果里**分关系报准确率**，并明确：
若只有顺承/因果可分、转折不可分，则「关系码」的证据强度只按转折那一条算。

## 7 跑后追加（明确标注为「非预注册判据」，append-only）

以下四项在拿到 J1/J2/J3 数字**之后**才加入。它们不改变 §3 判决表，但改变了结论的**强度措辞**。

### 7.1 三个面基线与一个配对检验（J4/J5/J6）

| 编号 | 内容 | 结果 |
|---|---|---|
| J4 | 整句字符词袋，同 6 折同 alpha 留出内容 | **0.8025** |
| J5 | 只给「整句长度、B 从句长度」两维 | 0.3704 |
| J6 | 只给「B 是否含否定字」一维 | 0.6481 |
| 配对 | McNemar 精确二项，隐藏态 vs 词袋 | 148 对 / 130 对，不一致 28 vs 10，**p=0.0051** |

**为什么必须做**：没有 J4，"hidden-state probe 90%" 与 "char bag 80%" 无法区分，
而后者完全不需要任何表征论断。有 J4 之后，可声称的只有「超出词法的真实信息 +11 点」，
不可声称「已找到抽象关系码」。J5 排除了长度，J6 量化了否定词所占的份额。

### 7.2 逐层剖面必须以完整 37 值报告（D25 的再次应用）

L1 已达 0.7840，与 J4 的 0.8025 近乎相同。这意味着**大部分可读性在任何组合加工之前就存在**。
若只报「L16 峰值 0.9506」，会隐去这条最关键的事实。

### 7.3 判别平面几何（描述性，非留出）

三质心两两余弦 −0.501 / −0.499 / −0.500，第一轴方差占比 0.501 ⇒ 等边三角形。
**明确标注为描述性**：它用全量数据拟合，只是把 J3 的 rank-2 结论画出来，
不作为独立证据。并写死「此 −0.5 ≠ Q6-B2 的 −0.5」。

### 7.4 预注册 J3 判决表存在结构性偏差（自我否证）

§2 的 J3 三行表把 rank-3 当作「三支私有方向」。但 **3 个类质心最多张 2 维判别子空间**，
rank-3 对 3 分类与 rank-2 恒等（除非类协方差不同），所以 `PRIVATE_DIRECTIONS` 这一行
**在数学上不可达**，判决表被结构性地压向 `PARTIAL_SHARING`。

处置：不修改已发出的判决（`PARTIAL_SHARING` 仍然正确，因为 rank-2 确实足够、rank-1 确实不够），
但把**有效比较限定为 rank-1 对 rank-2**，并把这条写成 negative
（`pat_q7a_neg_3class_rank3_is_degenerate`）。下一轮若要用秩曲线，类数须 ≥ 4，
或把饱和秩显式写成 C−1。

### 7.5 G0 的最终处置（与 §6.2 一致，落地版）

G0 不进判决链。它的用途只剩一个：**当 J1 落在 NULL/WEAK 时，用来判断是模型不编码还是材料没表达**。
本轮 J1 = 0.9136，G0 不参与结论。三个口径的数字全部落盘，供他人重判。
