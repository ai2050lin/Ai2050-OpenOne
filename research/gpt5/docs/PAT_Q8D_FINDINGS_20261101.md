- **冻结预注册**：`PAT_Q8D_PREREG_v1.md`（D1 宽网格）+ `PAT_Q8D2_PREREG_v1.md`（D2 窄网格注册检验）
- **主脚本**：`tools/pat_q8d.py`（Q8D_PHASE=1/2 切换）｜**独立复核**：`tools/pat_q8d_verify.py`
- **结果**：
  - Qwen3-4B D1 宽网格 `results/2026-11-01/111900?`（已删，被 D2 取代）；D2 `162208_pat_q8d2.json` sha8 **ca7fcc07**（141 次前向）
  - GLM-4-9B D2 `162016_pat_q8d2.json` sha8 **401a884c**（8-bit 量化加载，见 §六-3）
- **等级**：E1（干预未产生任何频率方向的因果效应——**定量 NULL**，不是"没测到"）

## 零、一句话结论

**静态嵌入表里那个 R²=0.826 的"频率子空间"，在两个模型的前向计算中都不被用作频率旋钮。** 沿 w_freq 平移 token 嵌入（剂量标定过的、句法不完整的 200 条 prompt、末位读出、输入臂与输出臂对照、同流形对照），下一 token 分布的期望 zipf 的变化被 CI 定量界死：**|ΔE[zipf]| ≤ 0.01，MDE 0.0095（Qwen）/ 0.0086（GLM）**——精确的零。Q8-B 的"SMOOTH_KNOB"（静态邻域响应）与 Q8-D 的"NULL_BOUNDED"（前向不使用）合起来是一个完整命题：**频率结构写在静态几何里，但计算不经过它**。

## 一、D1 宽网格（δ∈±8）先暴露剂量耐受窗

D1 用 9 格宽网格，发现：

- **δ=±8 时模型坏掉**：top-1 一致率掉到 0.055（δ=−8）/ 0.170（δ=+8），熵 +1.96 ⇒ 位移达 token 中位范数的 24% 以上时输出崩坏，任何读数作废。
- **健康区间（|δ|≤2，位移 ≤6%）内 ΔE[zipf] ≈ 0**。
- FREQ 方向 δ=+2 的 KL 是各向同性 RAND 的 20.8 倍 ⇒ **方向不是惰性的**。

D1 不能出注册结论（网格里有坏剂量、C5=DEGRADED），但完成了两件事：定出 D2 的窄网格 ±2，暴露了 RAND 对照的缺陷（见 §三）。

## 二、D2 窄网格主判（C1）：两模型 NULL_BOUNDED

材料：36 个候选模板 × 50 名词，**模板闸 p_M≥0.80 且 H≥1.00** 筛出 32 个模板（Qwen）/ 25 个（GLM），取前 200 条 prompt（句法不完整：把字句/量词/介词短语，末位是有频率定义的内容词，基线 p_M 中位 0.977–0.979）。

剂量标定（预注册前实测）：δ=1 个 zipf 单位 = 位移 ‖u‖ = token 中位范数的 **3.0%（Qwen）/ 4.9%（GLM）**，替换了原封冻稿里拍脑袋的 δ∈±8 网格。

| δ | −2 | −1 | −0.5 | 0 | +0.5 | +1 | +2 |
|---|---|---|---|---|---|---|---|
| **Qwen ΔE[zipf]** | −0.008 | −0.001 | +0.000 | 0 | −0.001 | −0.002 | −0.001 |
| 95% CI | [−0.030,+0.016] | … | | | | | [−0.007,+0.006] |
| **GLM ΔE[zipf]** | +0.000 | +0.001 | +0.002 | 0 | +0.003 | −0.001 | **+0.004** |
| 95% CI | [−0.006,+0.008] | … | | | | | [−0.001,+0.011] |

- Qwen：ΔE(+2) = −0.00114，CI [−0.0074, +0.0058]，**MDE 0.00948** ⇒ 精确零。ρ_dose = −0.107。
- GLM：ΔE(+2) = +0.00426，CI [−0.0013, +0.0106]，**MDE 0.00856** ⇒ CI 含 0 且点估计 < MDE。ρ_dose = +0.25。
- 判决：**NULL_BOUNDED**（新增枚举词：不是 PENDING_POWER 的"没测到"，是 CI/MDE 定量界死的零）。

## 三、C3 方向特异性：Qwen 被 EMB 对照击落，GLM 过了但没用

预注册 D2 加了**同流形对照 EMB**（随机两个真实 token 嵌入之差），因为 D1 的"KL 20×"只能证明 FREQ 方向**在嵌入流形上**，不能证明它有功能角色。

| 对照 @δ=+2 | Qwen | GLM |
|---|---|---|
| FREQ \|ΔE\| | 0.00114 | 0.00426 |
| RAND \|ΔE\| 中位 / p95 | 0.0012 / 0.0038 | 0.0015 / 0.0020 |
| EMB \|ΔE\| 中位 / p95 | 0.0009 / 0.0027 | 0.0006 / 0.0023 |
| FREQ KL | 0.0182 | 0.0297 |
| RAND KL 中位 | 0.0011 | 0.0151 |
| EMB KL 中位 | 0.0010 | 0.0155 |
| **判决** | **GENERIC_PERTURBATION** | **DIRECTION_SPECIFIC** |

- **Qwen**：FREQ 的 |ΔE| 连 RAND 的 p95 都不到。D1 看到的"KL 20×"在 EMB 对照下消失（EMB KL 与 RAND 几乎相同、FREQ 略高）⇒ 那只是"在流形上"的扰动感，不是方向的功能。
- **GLM**：FREQ 的 |ΔE| 和 KL 都显著高于 RAND/EMB（KL 0.030 vs 0.015）⇒ w_freq 是 GLM 分布的真实敏感方向。**但它不往频率方向推**（C1 = 0）——敏感≠承载频率语义。

## 四、C4/C6/C8：位移落在输入、分布整体偏移、语义门两模型分裂

- **C4 INPUT_DRIVEN（两模型同判）**：把同一位移加在**输出臂**（读出前改 h）几乎零效应（Qwen 21×、GLM 1847× 的 IN/OUT 比）。位移必须发生在**输入嵌入**处才会传播——符合"静态表是输入编码"的预期，也再次证明 Q2-C1 的教训：**OUT 臂测的只是读出线性度，不是机制**。
- **C6 GLOBAL_OFFSET（两模型同判）**：ALLPOS（平移全部位置）效应是 LAST（只平移末位）的 3.4–6.2 倍，且 ΔE 仍为零 ⇒ 干扰是"整体分布偏移"不是"位置内容变化"。
- **C8 语义探针**（40 条属性-实体知识题，强制选择）：
  - Qwen：acc 0.600 → 0.575（δ=8 最差 drop 0.075）⇒ `SEMANTICS_INTACT`（健康剂量内 0.575→δ=2 0.575 持平）
  - GLM：acc 0.575 → 0.45（δ=8）⇒ `SEMANTICS_HURT`。δ=8 是 D1 网格的坏剂量，与 Qwen 同剂量 drop 0.075 相比 GLM 更脆（8-bit 量化背景可能放大）——**跨模型不能比绝对值**，只报各自门。
- C5 能力门：两模型 7/7 剂量全过（dH≤0.30，agree≥0.60）。
- C2 形状：线性 R² 都只有 0.26–0.29，噪声主导（Qwen `NONLINEAR_OTHER` / GLM `SATURATING`——在 |ΔE|≤0.004 的量级上没有可解释形状）。

## 五、与 Q8-B 的合流：完整命题成型

| 问题 | Q8-B（静态几何） | Q8-D（前向因果） | 合并 |
|---|---|---|---|
| 频率信息在表里吗 | 在：4–16 维稠密子空间，R² 0.73–0.83 | — | 写入了 |
| 邻域跟着频率方向走吗 | Qwen SMOOTH_KNOB（+0.67/格）；GLM KNOB_NOT_LOCAL（恒 +3.1） | — | 几何性质 |
| 前向用这个方向算频率吗 | — | **两模型都 NULL_BOUNDED** | **不经过** |
| 方向对分布有特异性吗 | — | Qwen 无（连 RAND 都不如）；GLM 有但不推频率 | 敏感≠承载 |

**为什么 D10 的升级判据在这里见效**：Q8-B 的 B5（最近邻位移）看起来像"旋钮可拧"，但那是 E1 剖面——推嵌入看邻居是谁，没有前向。Q8-D 做了真干预，答案是零。若没有 Q8-D，"SMOOTH_KNOB"会被误读成"模型用这个方向编码频率"。**静态几何的对称性不等于计算的依赖性**——这是 Q2 家族"读得出≠控得住"在静态表上的镜像，也是本项目第三次独立撞到同一堵墙（Q2-L 注入、Q2-C1 消融/patch、Q8-D 平移）。

## 六、跑后修订与硬伤（严格审视）

1. **【实现】D2 门限实现滞后于注册**：首次 D2 跑用了 D1 的 0.5/0.75 门，发现后按注册值 0.30/0.60 重跑并删除旧结果。教训：**预注册值必须进代码断言，不能靠人肉对齐**。
2. **【材料】模板闸是跑后看清再写的**：诊断发现句法完整的 prompt 模型只预测标点（p_M 0.033，`，`占 0.849），主指标失效；"他把苹果" p_M=0.971。闸门（p_M≥0.80、H≥1.00）只看基线、不看干预，属材料口径，但**是 SMOKE 阶段才定下来的**——预注册 v1 的材料表作废，预注册 v2 冻结的是闸门规则而非具体模板。
3. **【GLM 材料变更】8-bit 量化加载**：GLM 全精度 18.8 GB 在 17.1 GB 卡上必须 offload，而 offload 路径在本机反复段错误（外部内存压力相关）。改用 bitsandbytes 8-bit 整卡加载，**lm_head 与 embed_tokens 跳过量化**（`llm_int8_skip_modules`），所以嵌入平移与读出都是 bf16 原值，量化只作用于中间层注意力/MLP。这是环境妥协，写明：(a) 量化扰动可能混入 C8 的 SEMANTICS_HURT；(b) 主判 C1 的零效应量级（|ΔE|<0.004）远小于量化噪声底（基线复现 0.977 vs Qwen 同管线 0.979，模板闸 p_M max|Δ|=0.33 是模板池不同所致，非量化）。
4. **【bug】GLM offload 时 `get_output_embeddings().weight` 停在 meta device**：值是未初始化垃圾（‖o2‖=115761 vs ‖ref‖=764），手算 head 与原生差 1.8e4。`calibrate_head` 断言失败**正确地**中止了跑——若没有这个断言，会在假 head 上算出一整轮假结论。修复：safetensors 直读。**新纪律 R-MTH-26**。
5. **【对照设计】EMB 对照是 D2 才加的**：D1 的 C3 若按 RAND 对照会给出 GLM `DIRECTION_SPECIFIC` 的过度声明——实际上 GLM 的 KL 特异性有一半是"在流形上"。加对照后 GLM 仍过，Qwen 被击落。**新纪律 R-MET-35**：方向特异性的对照必须含同流形随机方向，各向同性 RAND 只能对照"离流形"分量。
6. **【独立性】复核脚本首次跑 GLM 报 8 FAIL**——复核脚本硬编码了 Qwen 路径，拿 GLM 结果对 Qwen 重算比（自打 bug，不是结果错误）。修正为从 provenance 读 model_path 后**两模型各 21 PASS / 0 FAIL**。GLM 复核另暴露两个校准点：(a) 8-bit 核选择随 batch 变化，模板闸 p_M 噪声 0.0307（容差按量化取 0.05）；(b) 通过集差集只有边界候选 `一棵{N}`（结果表 p_M 0.7807，距阈 0.019 < 容差）——量化噪声把刀刃候选推过阈，非真不一致。GLM 复核第一次尝试还在 8-bit 加载时段错误一次（本机环境不稳定，重试即过）。
7. **【覆盖】只测了 LAST 位置的内容词**。ALLPOS 臂显示整体偏移也不推频率（C6），但开头位置 `<|im_start|>` 的嵌入被平移后的效应未单独测——Q5-A 显示 pos0 占分布竞争的 46%，若频率旋钮藏在格式位置，本轮测不到。挂账。
8. **【覆盖】只测了"下一 token 的期望 zipf"这一个读数**。若频率结构用于 logits 空间的其他坐标组合（如语法频率偏好而非词频），本设计的 E[zipf] 读不出。这是设计选择不是缺陷，但边界要写明。

## 七、纪律增量（本轮新账）

- **R-MTH-26**（证实）：offload/量化加载下，`get_output_embeddings()` 的权重可能是 meta 垃圾；任何手算 head 前必须有设备与数值断言（对 ref logits 复现），失败即中止。
- **R-MET-35**（证实）：方向特异性检验的对照必须含**同流形**随机方向（真实嵌入之差）；各向同性高斯 RAND 只能对照"离流形"分量，会系统性高估特异性。
- **R-MET-36**（证实）：干预实验的 prompt 末位必须是**有频率定义的内容词**且句法不完整（否则 p_M→0，主指标失效）；闸门只看基线分布（p_M、H），不看干预结果。
- **R-MTH-27**（证实）：预注册的门限/网格值必须以环境变量默认值写进代码并打日志，禁止"注册写 A、代码默认 B"。
- C5 能力门 / batch 不变性检查（ΔE 口径而非 logit 口径，bf16 下不同 batch kernel 不同是正常的）沿用 D2 注册稿。
