## 0 一句话

把"词嵌入有独特齿痕 → 注意力处理后融合 → 生成下一词"这句隐喻，
拆成三个**代数可测**的量：`R_id`（齿痕强度）、`ρ`（注意力归因比）、`reuse`（融合复用率）。
三者都是剖面/复用率型指标（E1），不是点陈述（E2），因此不会被下一个对照推翻。

## 1 T1 齿痕剖面

### 定义

对 token w 在 M=20 个不同上下文中（同一句法槽位，只换句子的其余部分）取 key：

```
k_i = W_k^{l,h} · LN(x_{l,pos_i})            i = 1..M
k̄(w) = mean_i k_i / ‖mean_i k_i‖
R_id(l,h,w) = ‖mean_i k_i‖ / mean_i ‖k_i‖   ∈ [0,1]
```

随机基线：`1/√M = 0.224`（M=20，解析值，不是经验值）。

### 身份有效性检验（防伪齿痕）

用 token 身份做标签，在 `{k_i}` 上训线性探针，20 折交叉验证（留一上下文）。
- `acc(l,h)` 显著高于 `1/V`（V = 候选 token 数 = 60）→ 该方向携带身份
- `R_id` 高但 `acc ≈ 1/V` → **伪齿痕**，记入 negatives

### 判据（四选一，互斥）

| 形状 | 条件（预注册） |
|---|---|
| U 形 | 前 1/3 均值 − 中 1/3 均值 ≥ 0.10，且后 1/3 均值 − 中 1/3 均值 ≥ 0.10 |
| 单调降 | Spearman ρ(层, R_id) ≤ −0.7 |
| 单调升 | Spearman ρ(层, R_id) ≥ +0.7 |
| 平坦 | 全 36 层极差 < 0.10 |

容差：`R_id` 跨 20 次 bootstrap 重采样的 95% CI 宽度须 < 0.05，否则判"测量无分辨力"，本轮 null。

### 预测

**U 形**。理由：低层 key 直接由嵌入生成（齿痕最强），中层被上下文写入稀释，高层需要交给 LM head 做词形匹配，身份信息被重新强化。

### 成本

60×20 = 1200 条序列，每条 1 次前向，`output_hidden_states=True` 一次抓全部 36 层。
4B 模型 bs=8，约 150 次前向 ≈ 25–40 分钟（GPU）。

## 2 T2 归因分解（核心）

### 定义

对每个 (层 l, 头 h)，在 144 格上计算三组数：

```
s_id  = q · k_id       (k_id = 沿 k̄(w) 方向的投影)
s_ctx = q · k_ctx      (k_ctx = k − k_id，精确残差，非拟合)
s_act = 实测注意力分数（logit，softmax 前）
```

```
ρ(l,h) = |corr(s_id, s_act)| / |corr(s_ctx, s_act)|
```

`ρ > 1` 身份主导；`ρ < 1` 上下文主导。沿 36 层画 `ρ` 剖面。

### 关键性质：无混杂

- 不消融 → 没有"覆盖率/集中度"混杂（Q2-A/D2/G/H 的死因）
- 不注入 → 没有"LM head 线性读出"混杂（Q2-L 的死因）
- 不跨上下文移植 → 没有"移植匹配"混杂（Q2-L 第一版的死因）
- `s_id` 与 `s_ctx` 是**同一次前向的精确加法分解**，不是统计近似

这是本项目第一次出现"没有任何旧混杂能杀死"的测量。

### 判据

1. **分界层存在性**：`ρ(l)` 剖面若在某个 l* 两侧符号翻转（前 1/3 段中位 ρ > 1.5，后 1/3 段中位 ρ < 0.67），判"存在身份→上下文的交接层"，报 l*。
2. **分工存在性**：同一层内 `ρ` 的双峰性。若 `ρ` 的层内分布呈双峰（`|mean − median| / std > 0.3` 或核密度双峰检验显著），判"层内存在身份头/上下文头分工"——**这是多模式融合最直接的证据**。
3. 若 `ρ` 全层 ≈ 1（0.8–1.25）→ 判"身份与上下文等权叠加"，无分界，无分工。

三条互斥，任一成立即判决。

### E2 配套（必做，受 D9 约束）

只保留 `s_id` 重算 softmax（把 `s_ctx` 置零），看 144 格准确率掉多少。
三组控制：换层（至少 3 层）、换位置（非末位）、换目标词。
**只报离地板距离（D4，地板 0.3333），不报裸 drop。**

### 预测

存在分界层，且 l* 落在 **L20–L33 之间**（Q2-C1 已知 L33 是读出汇聚点，Q2-D2 已知 L28–35 承载为 0，所以身份→上下文的交接如果存在，只能在这两件事之间）。

## 3 T3 稀疏复用

### 定义

对 144 格，取每格相对 uniform 的 logit 差向量 `Δ_k ∈ R^V`（V 取候选集并集，或 top-2000 词）。

1. 稀疏分解（非负 + L1，或 OMP）得字典 `D ∈ R^{V×K}`，K ≤ 64
2. 重建质量：`R² ≥ 0.90`，且每格非零系数 ≤ 3
3. 角色复用率：

```
reuse(role) = 该角色在 144 格中命中的字典列集合的 Jaccard 均值 / 随机期望
随机期望 = E[Jaccard(两个随机 3 元子集)] ，B=1000 次模拟
```

### 判据

| reuse | 判决 |
|---|---|
| ≥ 3.0（bootstrap 95% CI 下界 > 1.5） | **角色有专属列族** → 融合是结构性复用 |
| 1.5 – 3.0 | 弱复用，报条件 |
| ≤ 1.5 | 角色无专属方向（复现并强化 Q2-C2 的否证）→ 入 E 集 |

### 预测

reuse ≥ 3。理由：如果融合真是"多模式叠加"，施事/受事/客体三者应该各自有稳定的写入列，否则 144 格的行为模式无从稳定。
