### 1.2 必须修正的三个概念（证据强制）

1. **子空间不能定义为静态权重子空间。**
   2914 P4：载体头无静态谱身份（t12 rank h7=30/32、h8=4/32；谱统计 vs margins_h Spearman ≈ 0）。子空间只能定义为四元组 **(轴 a, 层 l, 头 h, 数据上下文 c)** 下的运行时响应子空间。静态 W_VO 谱是"容量目录"，不是"内容"。任何"某轴占用某静态子空间"的表述都会被 2914 证伪。

2. **"不同类别必然有各自的路径"过强——证据是"事件链 + 部分复用 + 极性交替"。**
   2918 核心发现：语言轴全部 24 个全族显著事件共享**同一个 en-vs-非en 词位响应模式**，分两个极性类（en+ {(8,2),(22,12),(7,19)}；L+ {(26,6),(25,3),(24,23),(27,24)}），同极性相关 +0.45…+0.72、异极性 −0.42…−0.60，**极性随深度交替翻转**（L2 en+ → L3 L+ → L6 L+ → L12 en+ → L19 en+ → L23 L+ → L24 L+）。因此：不存在"每类一条专属路径"，也不存在"一个静态载体"；存在的是**一根极性交替的事件链**——不同类别（这里=语言类）靠同一模式的极性与类纯度差异区分（lang_align 每事件不同：如 (26,6) en 侧对齐 1.0、(22,12) L 侧 0.943）。

3. **密度门控有三层，且词位层是"宽门"不是"窄门"。**
   2918 P1/P3 实证（语言轴）：
   - **词位层 DENSE**：强事件 PR_word 37.6–39.7/57（同层 null 的 79–97 百分位——比基线更"密"！），top-3 词仅承载 14–31% 的 |r| 质量。语言轴事件靠**大多数词的符号对齐**，不是少数词门控。
   - **层位层 SHARP**：temporal PR 6.3–10.3 / 36 层，相邻层对比 0.76–1.15——事件在层轴上尖锐。
   - **头层 SPARSE**：1152 格中仅 24 格全族显著（2.1%）。
   - **幅度不敏感**：早期事件响应幅度比 (7,19) 小 5–10 倍，sign-Gram 仍检出——门控判据是**符号对齐密度**而非幅度。这解释了"回归均值"类范数效应为何不摧毁可读性。

## 2. 理论对象的形式化（LPF v6 草案）

五个可预注册、可证伪的对象：

1. **轴 a ∈ A**：语义轴（语言 en/L、速度、尺寸、湿度、类别…），每轴逐层方向族 D_a(l)（2886 类间差口径的推广）。
2. **事件 e = (a, h, l)**：sign-margin M_a(h,l)，maxT 家族校正（2917 口径）。
3. **词位签名 s_e ∈ {±1}^57 与极性 π(e)**：事件的符号模式及其相对轴参照的极性（2918 的两极类）。词位签名即 LPF"词位随身档案"的事件层内容。
4. **门控密度场 D**：D_word(e)（PR_word、top-k mass）、D_time(h)（temporal PR）、D_head(a)（事件率）。2918 基线：词宽 / 层尖 / 头稀。
5. **复用结构 R**：
   - R_channel：同头跨层/跨轴事件数（2918：头内跨层复用稀缺，h4 L1↔L19 是唯一 + 例）；
   - R_pattern：跨事件词位签名相关 |ρ|（2918：0.42–0.72，单模式双极性）；
   - R_subspace：复用 cell 上不同轴响应子空间的主角度（**待测，2921**）。

**"关键分布"** = P(e, π, D | a, l) × R。用户直觉"这个分布极为重要，是完成智能理论的关键"在本框架中的对应物是：**智能 = 以极少的通道（32 头 × 36 层）通过极性交替与子空间复用，承载指数级多的（轴 × 类别 × 上下文）组合**。2917+2918 已给出该分布在语言轴上的完整一列；多轴扩展后即为完整图谱。

## 5. 风险与硬伤

1. **轴共线**：多轴方向族可能高度相关（语义轴共享词表）→ 2919 先验正交化/残差化，否则"多轴"退化为单轴的重复测量。
2. **family 膨胀**：|A| 轴后 family = 32×36×|A| → 置换数 ≥ 2000、maxT 口径强制（2917 教训已制度化）。
3. **单 run 证据**：全部结论 n=1 前向；关键结构（极性链、复用稀缺）需 2914 式跨 run 复现后方可入典。
4. **词表 57 词**：密度估计功效有限；扩词表是独立预注册 Phase。
5. **sign-Gram 只看符号**：2918 发现的 5–10 倍幅度差需要补充幅度口径（加权 Gram）作为对照判据。
6. **2918 family 依赖**：事件关联在 10-slot family 显著、276-family 不显著——跨事件结构效应量中等（|ρ| 0.42–0.72），一切"复用"结论必须带 family 口径标注。

## 6. 结论

思路判定：**正确，且已被 2918 部分实证**。
- "多轴坐标系" → 层匹配方向族（已有单轴实现）；
- "单通道多子空间" → 头通道复用 + 极性交替 + 类纯度分级（2918）；
- "密度门控" → 三层密度结构：词位宽门、层位尖门、头位稀门，判据为符号对齐密度而非幅度（2918）。

图谱可以完成：语言轴一列已闭环（2917 图谱 + 2918 解剖），多轴扩展路线已定（§4）。该分布——轴 × 事件 × 极性 × 密度 × 复用——确为"最小充分原语"搜索的自然完成形态：它把"智能如何用有限通道承载无限语义"转成一个可测量、可证伪的实证问题。
