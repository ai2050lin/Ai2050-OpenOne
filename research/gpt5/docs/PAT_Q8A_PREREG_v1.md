## 0 为什么这一轮值得做，以及它不是什么

前七轮（Q1–Q7）全部在**上下文之后**的残差流上做，`hs[0]` 只当过"免费基线"用来证明中间层超出了词汇身份。
从没有人**正面测过 embedding 表本身**。而 owner 这次问的正是它。

**必须先说清边界（否则会被自己的数字骗）**：

1. 嵌入是**静态表**，同一 token 的向量恒定（Q3-T1 已测 cos 0.998）。因此本轮所有结论都是 **E1（剖面）**，
   不涉及计算、不涉及因果。任何"模型在用这个结构"的说法必须另有干预证据，本轮不做。
2. 嵌入表是**语料统计 + 训练目标**的产物，不是"语言结构"的直接抄本。频率、分词、脚本（汉字/拉丁）、
   字节回退会与语义混在一起。**因此每一族假设都必须带一个非语义的对照**，否则测到的是分词器不是语言。
3. 本轮最容易犯的错（本项目的已知错法）有三种：**份额饱和**（R-MET-29）、**各向异性当语义**（D15）、
   **只报剖面不报预测**（D24）。下面每条判据都按这三条设计过。

## 1 材料与对象定义（冻结）

### 1.1 对象

`E ∈ R^{151936×2560}`，Qwen3-4B 的 `get_input_embeddings().weight`（**tied**：与 unembedding 同行）。
词向量定义（冻结，两档）：

- **A 档（主档）**：单 token 词 → 直接取该行 `e_w = E[id(w)]`。
- **B 档（次档，仅在 A 档样本不足时使用）**：多 token 词 → **token 行算术平均** `e_w = mean_i E[id_i]`。
  这是**组合对象**，与 A 档不是同一个数学对象，一律分档报告，不混算。

中心化：`μ = mean_j E[j]`（全表），`x̃ = x − μ`，`cos̃` 一律用中心化向量（D15）。
**原始 cos 同时报告**（本模型 ‖μ‖=0.31、平均范数 1.10、随机 2000 token 原始平均两两 cos 0.0916、
中心化后 0.0005 ⇒ 本模型各向异性**弱**，与 GPT-2 不同，这条本身要入账）。

### 1.2 三组语义材料 + 三组非语义对照

| 组 | n | 说明 |
|---|---|---|
| COLOR | 52 | 基本色 12（红橙黄绿青蓝紫粉棕灰黑白）+ 扩展 40。**每个词配 sRGB 十六进制**，Lab 与色相角由脚本按标准 sRGB→XYZ→Lab 计算，色相不是手填数字 |
| FRUIT | 50 | 常见 + 边缘水果。坚果类（核桃/板栗/榛子/腰果/花生）**保留**但单列子集报告（植物学是果实、语用是坚果） |
| RARE | 56 | 手选生僻字（龘靐齉爨麤鱻鑫犇羴猋骉毳掱嫑兲巭勥埊玊烎氼嘦圕孖冇乜冚蠱彧翀仝亓甪氍觳黼黻鼗龠龢籴粜耷耨薅搴殳厍卺耄耋饕餮魑魅） |
| COMMON_CHAR | 60 | 高频单字（的一是不了在人有我他这个们中来上大为和国地到以说时要就出会可也你对生能而子那得于着下自之年过发后作里用道行所然家种事成方多经去法学） |
| FREQ_CTRL | 200 | 从词表抽的**双字纯汉字 token**，按 zipf 分层抽，作为"无语义结构"的频率匹配对照 |
| RADICAL | 8 组 × 10–18 | 氵木火讠忄石虫鸟，**全部是单字 token**（已验 100%） |

关键预探结论（跑前已知，披露）：COLOR 只有 12/52 是单 token，FRUIT 17/50，RARE 35/56 是单 token。
⇒ 类别测试必须走 B 档（组合），并把 A 档子集作为稳健性单列。**这不是可以掩盖的事，是分词器事实。**

### 1.3 频率

`wordfreq.zipf_frequency(w,'zh')`（外部词频，与模型无关）。RARE 组 zipf 中位约 1.3、多数 ≤ 2.2。

## 2 假设与判据（冻结，共 8 条）

判据形态统一为「**预测量 + 零假设 + 阈值 + 备择**」。阈值在看结果前写定；如果 CI 跨阈，按 D23 记 `PENDING_power`。

### P1 词表不是一张表：三种单位类型混编（E1，描述 + 一条预测）

预测：词表按单元类型分成三个几何上可分的种群——**整词 token（≥2 汉字）/ 单字 token / 字节回退 token（`<0xXX>`）**。
判据：三类的中位范数、种群内平均两两 cos 各自报告；**预测** byte 类中心化后种群内平均 cos
≥ 整词类种群内平均 cos **+0.15**（"字节类塌缩"）。零假设：三类的内部 cos 无差异（用同规模随机抽样分布）。
判决：`BYTE_COLLAPSE` / `NO_BYTE_COLLAPSE`。

### P2 频率—范数律（E1，预测型）

预测：单字 token 种群内，`log‖e‖` 与 zipf 频率显著相关，且**符号为正**（越常见范数越大）。
说明：**预探已看到 ρ≈+0.33（n=7849）**，此处按"确认 + 形状"设计而非发现；预探与正式用**不同抽样**：
正式在全单字种群上做 5 折（按字符划分），由训练折拟合 `log‖e‖ ~ zipf` 的等距回归，预测留出折的范数秩。
判据（三条全过才算 PASS）：
- (a) `ρ_s(log‖e‖, zipf) > 0` 且置换 p < 1e-4；
- (b) 留出折 **Spearman ≥ 0.30**（预测型，主判）；
- (c) **单调性**：按 zipf 分成 8 个等频段，段中位范数的 Spearman 与 zipf **> 0**（D16：不许用"有趋势"糊过去）；
  若出现 U 形（低端反转），判 `NON_MONOTONE` 并在报告中画出 8 段曲线。

### P3 类别骨架：语义类有超出频率/词形的聚集（E1，预测型）

三条并列，缺一不可：
- (a) **聚集量**：`within(FRUIT) − within(FREQ_CTRL)`。FREQ_CTRL 与 FRUIT 按 zipf 分层匹配（每词配 4 个最近频率对照）。
  判据：**≥ +0.05**（中心化 cos）。
- (b) **预测（2AFC，主判）**：留一词法——对 FRUIT 中每个词，用其余 FRUIT 的质心与全部 COLOR 质心比较，
  选更近者。**准确率 ≥ 0.80**（机会 0.50）；反向（COLOR 留一 vs FRUIT 质心）同样报。
  **不用线性探针**：2560 维 / 50 词，探针必然满分（R-MET-29 第三次同类错），2AFC 不饱和。
- (c) **词形对照**：把每对共享汉字（如"红枣/枣"、"西瓜/甜瓜"）的配对数报出来，**去掉共享字的词对后重算 (a)**，
  若 (a) 的下降超过 50%，判 `CHAR_OVERLAP_EXPLAINED`（阴性归因），否则 `SEMANTIC_RESIDUAL`。

### P4 色相几何：颜色的"外部结构"在嵌入里可读（E1，预测型）

材料：COLOR 中 chroma `C* > 10` 的子集（脚本按 Lab 自动筛，预期 ≈ 45）。
- (a) **色相**：Mantel 检验，`ρ_s(色相圆周距离, 中心化 cos 距离)`。判据 **≥ 0.30**，置换 p < 0.01（10000 次）。
- (b) **明度**：`ρ_s(L*, ‖e‖)`。**不预设符号**（可能编码"深"= 更靠某方向），只报 |ρ| 与 p，
  达 |ρ| ≥ 0.30 记 `LIGHTNESS_LINKED`（方向留待下轮）。
- (c) **稳健性**：仅用单 token 的 12 个颜色词重算 (a)，只报不判（n 太小）。
- (d) **上下文对照（只报不判）**：模板「颜色：{w}。」取 L20 末位残差流，重算 (a)。用于回答"静态 vs 上下文"是否保序。

### P5 生僻字 = 字节组合，不是向量（E1，预测型；本轮最重要的候选）

- (a) **覆盖**：RARE 中**非单 token（字节回退）比例 ≥ 30%**（预探：21/56 = 37.5%）。
- (b) **码位律（主判）**：在字节回退生僻字子集上，`ρ_s(Unicode 码位距离, cos 相似度)`：
  预测 **≥ +0.50**，置换 p < 1e-3。零假设：相似度与码位无关（若成立 ⇒ 嵌入对它们"只知道 UTF-8 字节"）。
- (c) **塌缩**：`within(RARE) − within(COMMON_CHAR)` ≥ **+0.10**（中心化 cos）。
- (d) **邻居构成**：RARE 词的 10 近邻里"也是字节回退生僻字"的比例 ≥ **0.70**。
- 判决：三条 (b)(c)(d) 过两条即 `BYTE_COMPOSED`，全过为 `BYTE_COMPOSED_STRONG`。

### P6 形旁：汉字内部结构进入嵌入，且与语义可分（E1，预测型）

8 个形旁组（单字，100% 单 token）。判据：
- (a) `within(radical) − between(radical)` 的中心化 cos 差，量化到每组；**≥ +0.03** 记该组有聚集。
- (b) **关键判别**：把组按"语义同质"预分级——**同质**：氵木火鸟虫；**异质**：**石**（硬/碰/碗/破/碎/砖/砂/码/磁 语义几乎无关）、讠（半同质）、忄（半同质）。
  预测：**异质组（石）的聚集量 ≥ 同质组聚集量 × 0.5** ⇒ 说明载体是**字形/部件**而不是语义。
  若异质组聚集 ≈ 0 而同质组强 ⇒ `SEMANTIC_ONLY`（形旁不起作用）。
- (c) 频率对照：用 `FREQ_CTRL` 同规模随机组做零分布（每组重抽 1000 次），报每组的 z。

### P7 单坐标载荷：类别信息集中在少数坐标（E1，预测型；直接对应"单参数"提法）

- (a) **选择性普查**：对 2560 个坐标逐个做 4 组（COLOR/FRUIT/RARE/COMMON）单因素 η²；置换 200 次得零分布。
  报**超过零分布 99.9 分位的坐标数** `n_coord`。
- (b) **top-k 曲线（主判）**：按"训练半"的 η² 排序取前 k 个**原始坐标**（不旋转、不中心化），
  用最近质心对**留出半**做 4 分类（机会 0.25）。曲线 k=1,2,4,8,16,32,64,128,256,512,2560。
  **预测 k=32 时留出准确率 ≥ 0.75**（= 1.25% 的坐标承担类别骨架）。
- (c) **重叠**：COLOR-vs-rest 的 top-32 坐标 与 FRUIT-vs-rest 的 top-32 坐标，重叠数 vs 超几何期望
  `32×32/2560≈0.4`。预测重叠 ≥ 8 ⇒ `SHARED_BACKBONE`，否则 `SEPARATE_COORDINATES`。

### P8 嵌入 → 输出：几何与模型自己的下一词分布一致（E1+读出，非干预）

材料：`我喜欢吃的水果有苹果、香蕉、` 一个 prompt（另跑颜色版 `常见的颜色有红色、蓝色、` 作对照）。
- 量：候选水果（50 个 FRUIT 词首 token）在末位的 logit，与「该词到 FRUIT 质心的中心化 cos」的 **偏 Spearman（控制 zipf）**。
- 判据：**ρ_partial ≥ 0.30**，置换 p < 0.05（1000 次）。
- 说明：这是**读出相关性**，不是"模型用了这个几何"。且 `logit` 与 `cos` 共用同一张表（tied），
  **同表效应无法排除** ⇒ 结论只能写"一致"，永不得写"因果"。

## 3 零假设与置换纪律

| 检验 | 零分布构造 | 关键陷阱（本项目的已知错法） |
|---|---|---|
| P3a/P5c/P6 | 同规模随机组重抽（1000 次），从 `FREQ_CTRL` 或词表抽 | 抽到同字/同部件会虚高 ⇒ 按"共享字"过滤后再抽 |
| P3b 2AFC | 打乱类别标签（保持每类规模） | 留一词法必须先扣掉自身再看质心 |
| P4 Mantel | 置换色相标签 10000 次 | 色相是圆周量，距离用 `min(|Δ|,360−|Δ|)` |
| P7 | 置换组标签 200 次，取**每次的 max η²** 作零分布 | 用逐坐标零分布而非 max 会大幅高估显著坐标数（多重比较） |
| P8 | 置换 logit 与 cos 的配对 | 必须控制 zipf，否则测到频率 |
