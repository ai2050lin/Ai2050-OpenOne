## 一、对目标分析本身的评估（先判决，再定案）

### 1.1 总体判定：**框架正确，四处校准**

用户提出的目标分解——外部语言族图谱 / LLM 内部响应图谱 / 两图谱关联机制，以及"破解条件化齿轮组（单坐标、单神经元、单参数的相对编码与 layer 间复用差异化）"作为关联机制的钥匙——**与 LPF v5.3 范式同构，方向正确**。但基于 2820–2836 的预注册证据，需要四处校准：

| # | 原分析 | 校准 | 证据 |
|---|---|---|---|
| C1 | 知识网络（苹果的属性类别）是待破解的运行时机制 | 知识链**不是运行时传播**，是训练固化的共激活结构；运行时形态 = 实体档案（词位随身档案）+ 写头簇读写，**food 等下游语义不在运行时通道** | 2828/2830（teacher forcing）、2834（自由生成）、2836（c_food 无簇集中）——三范式+生成式四重收敛 |
| C2 | 知识/推理/语法三种能力是三个并列破解对象 | 三种能力**共享同一硬件基元**（属性写头簇 + 归一化接收），差异化在连接与读出模式，不在专门模块。归纳复制与属性调制共用 {h20,h22,h23,h26} | 2836（B2 4/4 写头参与归纳）、2826（域×通路分工）、2831（模式切换在生成端分布，不在历史） |
| C3 | 齿轮组从单参数入手 | 分辨率阶梯必须逐级打开：**头级（已有）→ 神经元级 → 坐标级 → 参数级**。且头级之下已发现强中间结构：亚加性归一化接收（0.28–0.71）、通用/语义双通道、L6 massive-activation 通道 | 2832、2833、2836 |
| C4 | 无限组合能力来源待破解 | 机制线索已锁定：**独立写入 + 归一化接收 = 分配而非叠加**，这是有限参数支撑无限组合的候选数学原理；属性束并发、'的'拮抗、束头复用是其实例 | 2832（A1=false 亚加性）、2831（单向固化历史）、2833（双通道接口） |

### 1.2 结论

- **正确并保留**：两图谱 + 关联机制的三分框架；条件化齿轮组作为钥匙；layer 复用/差异化问题；单坐标/神经元/参数的相对编码问题。
- **修正后采纳**：知识网络按 C1 重新定义为"档案-共激活"问题；三种能力按 C2 统一为"一个齿轮组、三种读出模式"；齿轮组按 C3 分辨率阶梯推进。
- **已有直接资产**：写头簇图谱（2824/2826/2833/2836）、Δh 双通道分离口径（2833）、逐层增益分解（2836）、写出谱管线（2824–2832）、中文 8 方向组与 2806 层级（外部图谱雏形）。

## 二、总目标与三大 Delta

**总目标 G**：破解（I）外部语言族图谱、（II）LLM 内部响应谱、（III）两图谱的关联机制及其数学原理；最终以"齿轮组三层解剖 + 接口方程 + 因果验证"闭合。

### Delta I：外部语言族图谱（语言侧）

> 目标：把"有限参数要编码的无限语言"本身先测绘清楚——没有精确的外部图谱，内部响应谱无法对齐。

| 任务 | 内容 | 既有资产 | 预注册判据类型 |
|---|---|---|---|
| I1 词位档案全集 | 高频实词/功能词的档案向量字典（iso 谱 + 单 token 谱），建立"词位 → 档案"查找表 | 2824 实测写出谱管线、LPF 词位随身档案 | 档案可分性（同词跨上下文档案稳定性 > 跨词） |
| I2 关系拓扑普查 | 同义/上下位/属性/部分-整体/句法依存 各关系类型的编码拓扑差异（400b 已发现不同关系不同拓扑，需系统化） | Phase 400b TYPE×SPEED_LEVEL 分层几何、2806 层级 | 关系类型在谱空间可聚类，且拓扑类型间判据互相独立 |
| I3 组合语法侧 | 修饰结构、词序、功能词（'的'拮抗位）、属性束的 external 侧规律表 | 2831（问法→生成槽位映射）、2832（束写入局部性） | 语法结构的谱签名可预测生成模式 |
| I4 不变性 | 跨句长/跨位置/跨域的档案不变性边界 | 2831 Q2（历史单向固化） | 不变性成立域的定量刻画 |

### Delta II：LLM 内部响应谱（模型侧）

> 目标：测绘"条件化齿轮组"的完整硬件图谱——头级 → 神经元级 → 坐标级 → 参数级。

### 里程碑

- **M1**（Delta I 收口）：词位档案字典 v1 + 关系拓扑分类表，外部图谱可查询。
- **M2**（Delta II 头级收口）：全 36 层 × 全方向响应张量 + 写头簇全图谱（含 L6 通用通道）。
- **M3**（Delta III 因果闭合）：写头消融双重检验 + 档案级编辑，接口方程因果版确立。
- **M4**（神经元/坐标级）：写头簇内部三层解剖完成，单参数相对编码给出至少一个闭合案例。
- **M5**（理论收口）：组合性定量律 + 接口方程 v1 = "有限参数 → 无限组合"的数学原理陈述。

## 五、v1.1 修订（2026-09-17，依据 Phase 2837–2840 预注册结果）

### 5.1 双谱规范（修订 II1/II3）

Phase 2839 实证：对齐谱（share 归因）与因果谱（消融损伤）Spearman ρ=0.106，几乎正交。**响应谱图谱正式定义为双谱对象：图谱 = 对齐谱 ⊕ 因果谱**；任何仅基于归因的谱分析（logit lens、头分解、特征对齐）不能替代因果消融谱。两谱错位度 ρ 本身列为架构观测量。

### 5.2 通道架构画像（修订 II4/III1）

Phase 2837–2840 四级因果链闭合：单点头非必要（decoupled，2.3%）→ 因果峰层 L22-23（单层 <10%）→ 层组独立可加（ratio 1.03，16层×top-4 承载 27.3%）→ 消融阶梯（top-8 32.7% / top-16 40.2% / L20-35 全头 73.7% / **全注意力 100% 塌陷**）。语义调制通道 = **注意力骨干 + 头级长尾幂律样分布**，MLP 不独立产生方向对齐的语义调制。2836 预测的"L30 决定层"修正为"L22-23 起始、跨层独立分布式"；"属性写头簇"重新定性为**观测口径的前缘切片**（簇随分辨率变化，骨干是物理实体）。

### 5.3 优先级更新

2841 = 长尾分布形状判决（单头扫描：幂律 vs 指数）→ 2842 = 注意力写入路径回溯（L22-23 峰值头 QK 边，对接实体档案读写）→ 之后回到 M2（全层×全方向响应张量）与 M4（神经元/坐标级解剖）循环。
