# MATH_STRUCTURE_VERDICT_v1 — 「语言的数学结构可能是哪种」逐条裁决

- 日期：2026-10-15 17:40
- 问题来源：用户列出的八类候选数学结构（代数/几何/拓扑/范畴/动力系统/信息几何/代数拓扑），问本库实测证据更支持哪一个。
- 方法：**只用在册可溯源数字说话**。每条判定必须挂 Phase 编号与封存值；无实测的候选一律标「未检验」，不得因"理论上优美"而晋级。

## 一、总裁决

> **不是单一结构，是三层复合；且统摄层是「动力学」，不是「形状」。**

| 层 | 数学性质 | 主要证据 |
|---|---|---|
| **载体层（代数）** | 高维向量空间上的**分布式叠加码**；语义/关系/角色 = 方向；组合 = 叠加 + 条件路由 | 3154 KOUT 份额 [L5.6,S19.4,C57.6,G1.16,D0.31,R15.9]；3161 无单点头；3163 全流分布式；3237 F20+F21 |
| **组织层（动力学）** | 残差流 = **离散动力系统** h_{l+1}=h_l+F_l(h_l)；几何形状是**算出来的**而非 inherited | 3159 dynamics_destroyed 3/3；3160 attention 再分配 primary；3156 readout 层范数恢复 |
| **读出层（信息几何）** | 末层线性投影 + softmax → 统计流形上的**弹性响应**，近各向同性 | 3158 预算比 1.03–1.33、KL 曲线指纹 0.9995；GAP-5（非线性只在 post-softmax） |

**组合性的代数形式**：不是群（有逆元、可交换），而是**有限生成的近似交换算子半群（幺半群）作用在高维模上**——token 序列 = 半群中的词，状态 = 模元素被逐词作用后的像。交换性被实测打破但不严重（对易子 ≈√2 而非 0 或 2），扭曲量由上下文调节。

**最重要的否定性结论**：点云几乎没有形状（谱平坦 97%、有效秩 26.7/40、Fisher 近各向同性、属性流形假说 false）。**形状不在点集里，在变换里。** 因此以「点云几何/拓扑」为主的工具（TDA、流形学习、PCA 主结构）在本系统上先天低产；跨模型守恒的对象全部是**变换的共轭不变量 / 形状指纹**（曲线、比值、谱形状），不是坐标、幅度或层号。

## 三、由证据直接推出的四条结构性结论

### 结论 A：承载是分布式的 ⇒ 不存在"单点充分原因"
- 3161 逐头消融无单点头；3163 残差流全流分布式；**3235 UPSTREAM_ABSENT**（全层 × 全方向 norm-matched patch，flip delta 对 null 全 0.0000）；3230 第二配方 dR 同向但传递正交 cos(dR,Δw)=+0.0997/+0.0625。
- 数学后果：**不能用"生成元/基"的语言找单位**（K1 算子代数 / K2 条件门 / K3 单坐标机制三条死线已否决）。最小机制单位转向 **「载体子空间 × 幅度调度 × 组合规则」**（3237 已入册；u\* 幅度承载类级 ROBUST，amp_ratio_c 6.57–12.21、spearman 0.79–0.83）。

### 结论 B：跨模型守恒的是「形状」，不是「值」
全部指纹级不变量都是曲线/比值：KL-vs-α 弹性曲线 **0.9995**、re-emergence 曲线 **0.9526–0.9755**、对易子层曲线 **0.79–0.90**、消耗段对齐 **0.9945**（错位 2 层即稀释到 0.38）；而绝对坐标、幅度、层号一律不守恒（KSTAR 指纹 0.244–0.908 不稳，F5）。
⇒ 正确的数学对象是**传递算子流的共轭不变量（谱形状 / 响应函数形状）**，不是点云的拓扑不变量。

### 结论 C：语义算子"近似交换 + 恒定小扭曲"，扭曲由语境调节
3157：exch ≈1.0–1.3（≈√2），上下文使 exch 下降（R 0.88–1.01、N 1.05–1.11）。
⇒ 语言组合性在代数上对应**近似可交换的半群作用**：词序的语义效应存在但量级有限（这解释了词序鲁棒性与词序敏感性的并存），语境是"代数的软化剂"而非新算子族。

### 结论 D：读出的几何是"算出来的各向同性"，不是 inherited 结构
3158 谱平坦 + 3159 动力学不保持软零性 ⇒ 剩余层主动把任何注入方向旋转、消耗、缓冲（pass-through 2.5×+），终点是近各向同性的弹性响应。
⇒ 末层没有"意义流形"可供流形学习；意义在**上游分布式承载 + 末端线性投影 + 归一化非线性**的三段式里（GAP-5）。

## 四、诚实边界（必须随结论一起读出）

1. **模型覆盖**：跨模型一致性基于 qwen3-4b / qwen3-14b / glm4-9b 三个模型；qwen 双胞胎（4b/14b）非独立样本，实际独立度 ≈2。
2. **3157 对易子**：仅为 KOUT 层 D 空间 last-token 度量（非全层）；partial 区间（0.5–2）判据较宽，"近似交换"是弱结论；扭曲来源（正交 vs 反平行）由比值近 √2 **推断**，未直接分解。
3. **3158/3159 商否证**：只否证"子空间型商"；连续弹性型商（纤维直径 1.7% @ KL 0.0008）仍成立，是"极薄邻域"意义上的商。
4. **谱平坦与近各向同性**：源于 unembed 谱与 Fisher 加权，KL 支撑集中于高概率 token，与全谱 RMS 解耦——"各向同性"是**输出敏感意义下**的，不等于表征空间无结构。
5. **半群/模的表述**：目前是**对证据的形式化命名**，机制级检验（半群的乘积律、结合律的可测推论、生成元有限性的定量口径）**尚未预注册执行**。在拿到这些之前，它只是候选语言，不是结论。
6. **TDA/范畴**：本库的否定是**针对具体预言**（Betti 数/环面、典范自然变换），不等于"拓扑/范畴工具永久无用"；Mapper 等价类检验（G5）与"带校准的纤维范畴"仍是未执行的开放项。

## 六、可预注册的三条判据（把"半群/模"从命名升级为可检验命题）

1. **P1 结合律的可测推论**：对同一锚态，测 (T_A∘T_B)∘T_C 与 T_A∘(T_B∘T_C) 的终态差 / 各自单算子差；若半群模型成立，差应 ≤ 单算子对易子同阶（预注册 exch_partial 区间复用 3157 的 0.5–2 口径），而非随算子数累积。
2. **P2 生成元有限性**：把 26 封存特征的响应方向做子空间聚类，测「新表述（held-out）能否由已有方向族的线性组合 + 幅度重标定解释」——解释率门与随机方向 null 对照（3238 阶段 A 普查的 hub 排序可直接复用）。
3. **P3 共轭不变量的稳定性**：跨三个模型、跨模板族，测传递算子谱形状 / KL 弹性曲线的不变量等级；判据沿用指纹门 Pearson ≥0.8，且必须做**层位对齐**（3160 教训：错位 2 层把 0.99 稀释到 0.38）。

## 七、一句话答案

> 语言编码的数学结构，**不是点云的几何或拓扑，而是"有限生成的近似交换算子半群作用在高维模上、其离散流（残差流）被动力学主动整形、末端以近各向同性的统计流形弹性响应读出"这一复合体**；其中代数负责组合（离散），动力学负责整形（连续），信息几何只在最后一步负责归一化——而唯一跨模型守恒的东西，是**变换的形状不变量**，不是结构本身的坐标。
