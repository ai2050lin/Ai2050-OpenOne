## 0 一句话

不问"角色存在哪里"，问**"用哪条规则能预测出模型的答案"**。
规则只用模型内部量（注意力、key），不用"我知道 ag 的答案是 A"这类语言知识——
否则准确率必然 1.0，测到的是我的中文水平，不是模型机制。

## 2 三条候选规则（比预测准确率，不比显著性）

对每个格 `(三元组, 句式, 查询)`，三个实体分居三个槽。
规则给出**一个预测槽**，槽里的词就是预测答案。

| 代号 | 规则 | 用的内部量 |
|---|---|---|
| **R1** | `预测槽 = argmax_slot 末位 query 在该槽实体上的注意力质量` | 完整 `s = q·k`（RoPE 后，自算） |
| **R2** | 同 R1，但把三个实体位置的 key 换成**去上下文的静态码** `k̄(w)` | 只保留 `q·k̄`，即身份分量 |
| **R3** | `预测槽 = 该句式的最后一个实体槽`（**不看查询**） | 无（纯位置规则） |

R2 的 `k̄(w, 句式, 槽)` 在**独立夹具**上测：同模板、同槽位、换其余两个实体填 M=3 个上下文取均值。
不共用被测格的句子，避免"用自己的 key 预测自己"。

**R3 是真正的备择**：如果查问只是幌子、答案永远是"最后提到的那个实体"，
R3 就会赢。这时"查询选槽"是假的。

## 3 判据（跑前冻结，四条同时报）

| 编号 | 判据 | 含义 |
|---|---|---|
| **P1** | `acc(R1) ≥ 0.80` 且 `≥ 0.333 + 0.40` | 规则本身可用（远超随机） |
| **P2** | `acc(R2) ≥ acc(R1) − 0.05` | **静态码足够** ⇒ 上下文对检索无贡献（与 T2 一致） |
| **P3** | `acc(R1) − acc(R3) ≥ 0.30` | **不是位置规则** ⇒ 查询真在选槽 |
| **P4** | 置换一致率 ≥ 0.80 | 同一句内三查询的预测槽必须互不相同，且与实际的查询→槽映射一致 |

基线：随机 `1/3 = 0.3333`；多数类（按训练折统计）；R3。

### 判决（互斥，按序判）

| 条件 | 判决 | 含义 |
|---|---|---|
| P1 ∧ P2 ∧ P3 ∧ P4 | `RULE_CONFIRMED_STATIC` | 查询选槽 + 静态码匹配即可 ⇒ 草图落地，机制第一块成立 |
| P1 ∧ P3 ∧ P4 ∧ ¬P2 | `RULE_CONFIRMED_CONTEXT` | 查询选槽成立，但上下文确有贡献 ⇒ 与 T2 冲突，须复核 T2 |
| P1 ∧ ¬P3 | `POSITION_RULE` | 答案是位置决定的，查询是幌子 ⇒ 草图要改 |
| ¬P1 | `SKETCH_FALSIFIED` | 规则不成立 ⇒ 按 §9.5 整体换机制假设，**不许再换测量侧** |

## 4 防作弊条款（这是本 Phase 的全部难点）

1. **规则不得使用答案词**。R1/R2 只用 `argmax` 选槽，槽→词的映射由句子本身给出。
2. **层选择不得泄漏**：按三元组 5 折；`l*` 只在训练折上选（最大化 R1 准确率，并列取较小层），测试折用该 `l*`。
3. **夹具独立**：R2 的 `k̄` 来自独立生成的句子，不与被测格共用前缀。
4. **自算注意力**，不用模型 `output_attentions`（bf16 存储，T1 已测误差 4e-3）。
5. **同时报全层剖面**（描述量，注明其对层选择是 in-sample），不报单点。

## 5 预测（跑前写死）

- **P1 成立**（acc ≥ 0.80）：注意力 argmax 在末位已经指向答案，与行为门 0.97 一致。
- **P2 成立**（R2 ≈ R1）：T2 的 share_ctx 0.01 预示静态码够用。
- **P3 成立**（R1 显著高于 R3）：句式 C 的末位实体是 recipient，而 ag 查询的答案是 agent，
  所以 R3 在句式 C 上必然大面积失败——这条几乎是被设计决定的，但仍要报数。
- **l\* 落在 L24–L35**：Q2-C1 已知 L33 是读出汇聚点。
