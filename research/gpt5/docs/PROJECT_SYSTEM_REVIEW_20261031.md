## 一、项目定位与现状梳理

### 1.1 使命与研究边界

核心命题：**深度神经网络如何用有限参数实现无限组合的语言能力**（知识网络、分析推理、语法系统），目标是破解 LLM 内部语言编码机制，产出三件可查询资产：

1. **外部语言模式族图谱**（词义—关系—角色—组合—语境）；
2. **内部 LLM 结构与响应图谱**（embedding → 全 HiddenState 场 → unembedding）；
3. **两图谱的关联机制**（可执行提取算法 + 候选数学规律 + 留出预测）。

理论名称保留：**条件化输出场闭合理论（RDC）**。双线并行：deepseek/N 线（P1–40 收官，REACH 域 + A 闸门 K1/K2/K3 判决）与 G 线（gpt5，现役至 Phase 3281）。

### 1.3 已确立的关键结论（含证据级与边界）

1. **u\* 双轨道几何为预训练属性**（APPX-7）：轨道 I（embedding 秩 1）在 25/25 训练态逐位不变；轨道 II（载轴）中层低谷是衰减非替换；支配比 D 具规模依赖（1.7b 带 15.98–17.28 vs 跨模型 30–40× 带）。
2. **K3 单坐标机制废弃**（APPX-8，3/3 触发）：top-50 单坐标 η² 覆盖率仅 1.9–5.9% ≪ 30% 死线 → 机制单位改为 ≤10 维联合子空间 + 端口类。
3. **"读得出 ≠ 控得住"**（F2/F16，E3 级）：C_steer=0/376，Wilson 上界 1.01%——几何方向可读出但无单方向行为杠杆；F20/F21 补充 UPSTREAM_ABSENT（全层杠杆扫描 flip=0）。
4. **GAP-5 三段式**：pre-softmax logit 空间 effectively 线性，非线性住在 softmax 之后。
5. **谱外三档梯度**（GAP-4）：实体轴/组合轴可泛化，类别轴崩塌（ratio_B=2.54，校准 k=8 残留 1.8×）——"未见组合 ≠ 未见类别"。
6. **数学结构裁决**（MATH_STRUCTURE_VERDICT v1）：三层复合（分布式叠加码代数 × 残差流离散动力系统 × 信息几何弹性响应），**算子半群是最强候选**（有限生成近似交换算子半群作用在高维模上）；低维流形/拓扑/商结构被拒。
7. **消费方归因**（3280/3281，本轮最新）：静态中继头族（层 23–30，~9× 随机基）获动态份额确认（K-A 15/15、K-A2 ρ=0.340/0.362）；K_entity 头输出 19–24% 落 8 维载荷子空间；3280 的 FAIL 定性为度量混淆（D_abs~‖c‖ ρ=0.97）而非机制缺失。

### 1.4 工程与治理现状

- **优势**：五段式流程（freeze→SMOKE→正式→verdict→closeout）、sha8 锚实测纪律、registry/gap immutable + append-only、失败必入账、E 级 taxonomy——**诚实性与可审计性高于多数公开研究**。
- **债务**（system_audit_20261031）：① 双系统并存（产品平台 vs 脚本前线）；② tools/ 37 脚本 7,356 行未入 git、结果无 provenance（P0 刚补）；③ 统计功效历史薄弱（n=110 仅 p≈0.07）；④ 前端 51 孤儿模块、CI 空转、判据靠人肉；⑤ 治理系统 29 contracts 空转。

### 2.3 本项目的相对优势（不应丢掉的资产）

1. **失败账本 + E 级 taxonomy + 预注册五段式**——行业正在补的课（misranking、输入敏感性）本项目早已制度化。
2. **负结果的机制化**：C_steer=0 不是简单失败，而是"读得出≠控得住"的定量负规律（与 AxBench 结论独立汇合）——这是可以写进社区的结论。
3. **K3 单坐标废弃**（η² top-50 覆盖 1.9–5.9%）与 Engels et al.（特征非一维线性）、Goodfire（SAE 抓不住流形）方向一致，且本项目用的是直接测量而非 SAE 代理。
4. **u\* 双轨几何 + 训练步轨迹**（P-TRAJ，位精确恢复 W_t）：行业少有的"训练维度"证据——双轨几何是预训练属性而非微调产物。
5. **语言学切面**：多语言轴、语法/知识/推理三分池、格式单元污染的警惕（R-MET-11/12）——行业电路案例多为英语单任务。

## 三、问题与硬伤的严格审视

### 3.1 科学层

1. **"破解"尚不可度量**。AGENTS.md §5.4 定义了谱图预测保真度（留出 KL、损失恢复比例 vs 词汇身份/位置/n-gram 基线），但至今没有一个实测数。行业已经用 CMD/IIA 给方法打分——**没有保真度数，就没有"破解进度"可言**。
2. **正机制稀缺**。26 特征多为"几何可分性/读出面板/负规律"，真正闭合的计算机制只有 GAP-2（attention 再分配）和 3280/3281 中继头族。F20（读出几何≠行为控制）已从边界变主攻，但 Cammarata 对齐的电路归因（P3 联合仲裁）尚未跑出第一例"写入原子×路由头×写入方向"三元组。
3. **原子定义悬空**。K3 废弃单坐标后，atom_registry.v1 是空表（n=0）；≤10 维联合子空间原子一个都没注册。理论承诺（条件化齿轮组/算子半群）与可操作单元之间存在断层——**这是当前第一断点**。
4. **与 Cammarata 假说的张力未对质**。3280 转向头级归因与 K3"单坐标废弃"表面矛盾。需要明确颗粒度映射：神经元 pole（MLP 中间单元）≠ 残差流坐标 ≠ 头方向。Cammarata 的 90% 干净率是在 Qwen3-32B 的 MLP 神经元上，**本项目从未在自己的模型上跑过神经元 pole 审计**——便宜、高信息量、直接裁决原子路线。
5. **外部语言族图谱名不副实**。三图谱目标的第一件，目前只有 6 个 grammar + CMMLU 三类池（n=3761）。距离"词义—关系—角色—组合—语境的族内/族间/整体分布"还差一个量级。行业用 IOI/Arithmetic/MCQA/ARC 做横向锚点，本项目没有等价锚。
6. **算子半群假说不可证伪**。MATH_STRUCTURE_VERDICT 给出"最强候选"但无预注册预测（如近似交换子定量界、生成元谱）。不给可证伪预测，它只是记账语言——项目自己的标准（AGENTS.md §2）正是这么要求的。
7. **GAP-4 谱外崩塌未机制化**。ratio_B=2.54 是刻画不是解释。"有限参数→无限组合"的核心恰恰在组合泛化的边界条件上，这是全项目最大的科学机会点，目前投入不足。
8. **nf4 量化伤结论已被实测**（APPX-1 G-C top1 FAIL 4.15°）。在 16GB 卡上做 14b 级结论必须带量化误差棒，目前只有 APPX-1 一处处理。

### 3.2 方法与工程层

1. **零外部基线**：SAE / transcoder / circuit-tracer / AtP* / EAP-IG 一个都没在本项目跑过（G5-DP01 P4 才排期）。2026 年的 sanity checks 表明 SAE 可能很弱——**但必须自己测**，否则无法声称路线优越。
2. **可复现性缺口**：tools/ 未入 git、结果 provenance 刚起步、双系统事实源分裂。行业门槛已是"别人能重跑你的图"。
3. **治理/科学产出比失衡**：3256–3273 十余个相消耗在封章/核验/待命刷新上。审计纪律是资产，但边际收益递减；同类错误（预算型断言、口径混用）复发 5 次说明该把规则变 assert_fn 而不是继续人肉审计。
4. **单人研究、无盲测**：所有发现、判定、复核同一主体完成。行业通过共享任务/公开图谱获得外部复核。
5. **行为门与机制分离的回路不完整**：dist_protocol 有行为门，但"行为失败→probe 设计问题 vs 模型能力问题"的分辨在部分历史材料中仍含糊。

## 四、改进路线（分阶段大任务，非小功能）

### 阶段 R1（1–2 周）：让"破解"变得可度量、可对话

- **R1.1 破解保真度首发**：选 1 条已闭合机制（GAP-2 attention 再分配链 或 3281 中继头族），在留出集上实测谱图预测保真度（KL / 损失恢复比例 vs 词汇身份、位置、n-gram 三基线）——项目第一个"破解度"数字。
- **R1.2 外部基线接入**：在 qwen3-4b（或 Gemma-2-2b）上跑通 ①EAP-IG/AtP*（IOI 任务，MIB 口径）②circuit-tracer/attribution graph 开源管线——建立与 MIB/CMD 的可比性。
- **R1.3 神经元 pole 审计对质**：用 Cammarata 方法（agent 解释-测试环）审计 qwen3-4b MLP 神经元，直接裁决"神经元已干净 vs 必须 SAE/子空间"，落 atom_registry 原子路线。
- **R1.4 工程地基强制化**：tools/ 入 git、provenance 五字段全量强制、10 条账本规则变 assert_fn 进 CI（审计"五件事"①⑤）。

### 阶段 R2（1–2 月）：从几何图谱升级为可预测电路

- **R2.1 G5-DP01 P1–P3 按改后验收执行**：写入侧退化画像 + 路由侧 PR 筛（即预注册 3282）+ 联合仲裁；**验收改为 necessity+sufficiency 双向 + 留出预测**，干预用反事实消融（MIB 结论：优于均值消融）。
- **R2.2 外部图谱补规模**：dist_protocol 扩到每类 ≥1000 且加 2 个跨研究锚任务（IOI + 一位数算术），使两图谱关联可与社区对表。
- **R2.3 谱外崩塌机制化**：把 ratio_B=2.54 升级为可证伪假设（类别轴缺位→u\* 幅度兜底→读出层崩塌），预注册干预实验（类别轴注入/端口替换），闭合 GAP-4。
- **R2.4 多语言/语法族机制案例**：选 1 个语法族（如否定/疑问）做完整"外部构式→内部原子→路由头→logit"全链案例，对标 Biology of LLM 的叙事完整度。

### 阶段 R3（一季）：理论闭合与外推

- **R3.1 算子半群可证伪化**：给 2–3 个预注册预测（近似交换子范数上界、生成元谱形状、组合深度律），任一被拒则降级为记账语言。
- **R3.2 机制级跨模型复用**：把"几何可分性跨 6 模型守恒"升级为"同构电路复用"（对应 head/MLP 角色对应而非仅角度）。
- **R3.3 causal abstraction 接轨**：把 RDC 条件化算子族翻译为交换图（interchange intervention 可测），提交 MIB/BlackboxNLP 式评测。
- **R3.4 训练维度扩展**：P-TRAJ 已证双轨几何是预训练属性；扩展到更大 checkpoint 轨迹（qwen2.5-3b/7b），回答"编码结构何时成形"。

### 资源约束下的优先级裁决（若只能做三件事）

1. **R1.1 破解保真度首发**（没有它一切进度主张无效）；
2. **R1.3 神经元 pole 对质**（裁决原子路线，直接决定 P1–P3 的颗粒度）；
3. **R2.3 谱外崩塌机制化**（离"无限组合"核心命题最近的可证伪缺口）。

## 五、智能理论视角的关键洞察

1. **有限参数→无限组合的当前最佳候选**：不是坐标复用，而是"低维载荷子空间 × 幅度调度 × 近似交换的算子组合"（F21 + MATH_STRUCTURE_VERDICT）。组合性住在**算子层**不在**坐标层**——K3 废弃单坐标、S 族跨模型守恒形状不守恒值、u\* 双轨不变，三条独立证据同向。这与人脑"复用+分化"和生成语法的递归组合形成三方呼应，但需要生成侧证据补强。
2. **"读得出≠控得住"是特性不是缺陷**：编码是分布式承诺而非开关。对 AGI 安全的含义是监控应走**预测/归因**路线（CoT monitorability + attribution），而非激活编辑路线（steering）——本项目的 C_steer=0 与 AxBench 独立汇合，值得作为一级结论固化。
3. **谱外崩塌是边界不是失败**：类别轴不可迁移而实体/组合轴可迁移，暗示"无限组合"有结构边界——组合能力按轴类型分层。破解这条边界（R2.3）比再加 100 个特征更接近第一性原理。
4. **工具乐观主义要打折**：SAE/叠加叙事正在被行业自我修正（GDM 降级、sanity checks、Already Clean）。本项目从 K3 直接测量出发的"子空间原子"路线站在了正确一侧，但要防止用"子空间"词汇重复"叠加"的旧错误——每个原子必须过行为门和干预门。

## 六、结论

- 本项目在**研究纪律**（预注册、失败账本、E 级、链式账本）上达到甚至超过行业顶级水准，在**负结果机制化**上有可发表的一级结论；但在**可度量破解、外部基线、标准化评测对接、工程可复现**上显著落后于 Anthropic/DeepMind/社区生态。
- 最大风险不是"做不到"，而是**治理开销吞噬科学产出**与**原子断层（理论有承诺、注册表为空）**。
- 建议按 R1→R2→R3 推进，R1 三件事（保真度首发、神经元对质、基线接入）两周内可完成且各自独立可判。
