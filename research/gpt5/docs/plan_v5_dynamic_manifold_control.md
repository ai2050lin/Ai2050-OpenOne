### 判定小结
附件五大空白的**定位基本准确**（尤其是自回归动力学与 Base 对照两处，是真实的结构性空白），其最有价值的贡献是把我们的注意力从"零件在哪里"推向"系统如何演化"；其风险点与方案 v4 处理的附件同构：**把隐喻当机制**（虫洞/引力透镜/雪崩）、**给未测问题预设答案**（正交转换矩阵——已被 2985 否证其最简形式）、以及一处**关键事实错误**（qwen3-4b 是 chat 模型， immune 差距不能归因对齐状态差异）。三处校正后，附件的全部正确部分均可整合为工作包。

## 二、方案 v5 工作包（执行顺序）

### P0（3003，随本方案发布收官）：放大带剂量律+镜像对称性（Ω-G3）
- **设计**：3002 机器 verbatim；L15/L17 剂量网格 s∈{0.5,1,2,3} K=3（过原点线性拟合，最大相对残差门 0.15）；镜像 −xdir s=2 K=2（对称门 |r−/r+−1|≤0.2，整流门 r−/r+≤0.3）；sub_rnd0 剂量对照。
- **判据（预注册）**：linear_symmetric_amplification（被动无洗消）/ symmetric_nonlinear / rectifying（主动特异电路）/ asymmetric 四分支。
- **意义**：决定 3002"放大带"的本体——这直接是战役一"防御带如何长出来"的 qwen 侧基线。

### P1（3004-3006，战役一主攻）：对齐手术刀——同家族 Base 对照
- **前置资产**：下载 Qwen3-4B-Base（~8GB，HF/镜像，待网络确认；GLM 侧 base 若可得同步）。
- **设计**：2999/3000/3002 机器 verbatim 三件套一次性移植到 base：①全层扫描剖面（ratio/sep，对照 3000 chat 剖面 bit 级协议）；②词 token swap 加法 2×2 分解（对照 3002 carry 63.4%）；③剂量+镜像（对照 3003）。
- **判据（预注册）**：对齐 delta = chat − base 在三个协议上的差值剖面；base 的放大带若消失/反转 → 对齐雕刻假说成立；base 与 chat 无差 → 免疫差异归因架构/规模，空白一改写。
- **命名门**：三协议 delta 达成前禁用"对齐相变定律"。

### P2（战役二）：生成轨迹记录器 + 扰动-恢复操作化
- **P2a（3007+）轨迹学**：自回归生成 256 token（固定 prompt 集），逐 token 记录 final-norm 在 u35/Vt8 基下的坐标 + 逻辑词位/内容词位的读出剖面（2993 签名机器移植到生成态）；统计：轨迹自相关、逻辑词位的坐标锁定度 vs 内容词位。
- **P2b（Ω-E 延伸）扰动-恢复**：生成中途单步注入 xdir/sub_rnd 微扰，测 K 步内读出坐标的恢复 vs 发散（判据：恢复指数 = 注入后轨迹与未注入轨迹的距离衰减率）；一致性吸引子（重复/循环/漂移率）先于"幻觉"命名。
- **工程**：KV cache 生成循环 + 逐 token hook，batch=1 序列；单卡内存可控。

### P3（战役三，跨语言先行）：翻译对深层同构检验
- **设计**：中/英/法翻译对集（各 ≥40 对，资产：2972 fr 词表扩展），测每对在深层（L24-33 qwen / L28-37 GLM4）final-norm 坐标；Procrustes 等距检验：跨语言对齐残差 vs 语言内随机词对 null（2931 口径）。
- **判据（预注册）**：同构成立 = 跨语言对的 Procrustes 残差显著低于 null p95 且配对内距离 < 语言内距离；"语义中枢 vs 直接扭曲"由中层（L15-17）坐标是否已收敛判定。
- **跨模态后置**：需 VL 资产（如 Qwen2.5-VL），单列立项不阻塞主线。

### P4（战役一后半，零新 forward）：层间传递算子结构
- **设计**：对 3001/3002 已存 trk 剖面（per-cell per-layer Δ）做逐层 SVD：Dl 的有效秩、能量谱、跨细胞共享性（top-1 方向的细胞间 cos 分布）。
- **判据（预注册）**：若 Dl 低秩且跨细胞共享 → "转换算子"有意义（但非正交、非固定——2985 修正版）；若逐细胞独立 → 单点操作化关闭的又一证据。能量分账（保持/正交化/吸收）随 SVD 直接产出。
- **优势**：纯重分析，无 GPU forward，可与 P1 下载期并行。

### 插队规则（延续 v4）
主线新硬伤优先于下一工作包；P1 下载期以 P4 填充；附件类输入一律先判定再整合（本方案先例）。
