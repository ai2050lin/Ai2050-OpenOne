## 零、一句话

本轮本想弄清 Q2-C2c 那个「角度门锥」是角色锥还是实体锥。
**答案是：都不是。它测的是 LM head 的线性读出。**

证据：在末位注入任意一个词的嵌入差，模型就答那个词——与注入层无关
（L20 到 L35 全部 1.000），与「角色」无关（注入"苹果"的嵌入差，模型答"苹果"）。

因此 **Q2-C2 / C2b / C2c 关于「锥 / 角度门 / 无共享角色方向」的全部判定撤回**
（negative #20）。同时本轮自己的 O1 判定也被判为平凡，一并降级。

## 一、Q2-L：Δ 的成分分解（设计）

### 为什么要重做

Q2-C2c 的 Δ = h(clean) − h(corrupt) 由「实体互换」构造，同时混了三样东西：
答案词的**词法身份**、**角色归属**、以及大量**与答案无关的句子特异内容**。
三者从未分开。

### 第一版设计有一个必须记下的错

第一版把「实体差分」在 S1→S3 上测量却注入 S2（跨上下文移植），
而「角色差分」在 S2→S4 上测量并注入 S2（原位移植）。两者差 0.875 与 0.000，
看上去像"实体换不了、角色换得了"，实际可能只是移植匹配与否。
SMOKE 当场暴露，设计作废重写。

### 最终设计：全部同基座

```
B  = (Y, X, T)     答案 Y        ← 唯一注入基座
P1 = (X, Y, T)     答案 X        ← 角色与身份同时变；目标 X 在上下文中
P2 = (Y', X, T)    答案 Y'       ← 只变施事身份；目标 Y' 不在上下文中
P3 = (Y, X, T')    答案 Y        ← 只换宾语，答案不变（特异性对照）
```

全部 Δ 都从 B 测得、都注入 B 的同一个末位。
样本 n=44（24 三元组 × 主动/被动，跳过 4 条长度不匹配），覆盖 **12 对人物**
（`triples()` 只覆盖 4 对，本轮改用自建 `build_triples()`，D8）。

方向清单（位移长度统一 `p·‖d1‖`，D7）：

| 记号 | 定义 | 目标 |
|---|---|---|
| d1 | h(P1) − h(B) | X |
| d2 | h(P2) − h(B) | Y' |
| d3 | h(P3) − h(B) | Y（应不变） |
| lex1 | unit(E[X] − E[Y]) | X |
| lex2 | unit(E[Y'] − E[Y]) | Y' |
| orth1 | unit(d1 − (d1·l̂ex1) l̂ex1) | X |
| orth2 | unit(d2 − (d2·l̂ex2) l̂ex2) | Y' |
| rand | 随机单位向量 | X |

### 结果（n=44，p=1.0）

| 组 | 翻转率 |
|---|---|
| d1（完整差分） | 0.977 |
| d2（只换身份，目标不在句中） | **1.000** |
| lex1（纯嵌入差） | **1.000** |
| lex2（纯嵌入差） | 0.909 |
| orth1（d1 去掉词法分量） | **0.159** |
| orth2 | 0.000 |
| rand | 0.091 |
| d3 自然长度下答案不变 | **1.000** |

逐级剥离词法分量（固定长度 ‖d1‖）：

| λ | 0.00 | 0.25 | 0.50 | 0.75 | 1.00 |
|---|---|---|---|---|---|
| 翻转率 | 1.000 | 1.000 | 0.795 | 0.364 | 0.159 |

夹角：cos(d1,d2) 中位 **0.545**；cos(d1,lex1) **0.469**；cos(d2,lex2) **0.555**。
范数比：‖d2‖/‖d1‖ = 1.160；‖d3‖/‖d1‖ = 0.386；‖Δ_voice‖/‖d1‖ = **0.564**。

### 当时的判读，以及为什么它不够

按预注册判据，三块分别是 O1（全词法）、C2（目标不必在上下文内）、D1（剥离即崩）。
**但这个判读有一个致命的平凡解释没有排除**：Qwen3-4B 是 tied embedding，
末层 RMSNorm 之后直接与 E 做内积。那么「往残差流里加 E[X] − E[Y] 就抬高 X 的 logit」
几乎是代数恒等式。若如此，O1 只是测量装置的镜像，不是关于机制的发现。

于是有了 Q2-L2。

## 二、Q2-L2：三组控制，判定平凡与否

同一向量 `unit(E[X] − E[Y])`，位移同为 `p·‖d1‖`（n=44）。

### 层控制：只改注入层，L20 → L35

| 注入层 | L20 | L25 | L29 | L31 | L33 | L35 |
|---|---|---|---|---|---|---|
| p=0.75 | 1.000 | 1.000 | 1.000 | 1.000 | 1.000 | 1.000 |
| p=1.00 | 1.000 | 1.000 | 1.000 | 1.000 | 1.000 | 1.000 |

**六个层全部 1.000，一点衰减都没有。** 若这个向量承载的是"角色信息"，
注入到 L20 必被后续 15 层洗掉。它没有。所以它不是信息，是**直通输出的偏置**。

### 位置控制：同一向量注入问句首 q0（L33）

| | 命中率 |
|---|---|
| 末位 | 1.000 |
| 问句首 q0 | **0.091** |

与随机方向的 0.091 相同。所以效应必须发生在**被 LM head 读取的那一个位置**——
这本身是因果注意力的必然结果（只有末位进 head），不构成机制证据。

### 词表控制：注入"苹果"（非答案）的嵌入差

| | 答成"苹果" |
|---|---|
| p=0.75 | 0.818 |
| p=1.00 | 0.886 |

**注入哪个词的嵌入差，模型就答哪个词。** 连同 d3 的超长注入（答成"苹果" 28/44），
这条把「末位是个通用词表转向器」钉死了。

### 判决

**T1 平凡：注入直通输出，与末位读出点无关。**

## 三、撤回清单（这是本轮的主产出）

| 被撤回的判定 | 原出处 | 撤回理由 |
|---|---|---|
| 「角度门锥，边界 cos≈0.60（≈53°）」 | Q2-C2c | 门的位置由目标词嵌入方向与位移的夹角决定，是线性读出的几何，不是机制 |
| 「锥逐样本朝向不同，无共享角色轴（cos 0.245）」 | Q2-C2c | Δ 里 76% 能量是与答案无关的句子特异内容，压低跨样本 cos 的是它，不是"每个角色有自己的方向" |
| 「S/R 各承担一半」 | Q2-C2 | 已在 Q2-C2b 撤回（长度未对齐），本轮补充：即便对齐，S/R 分解也无意义 |
| 「一维线性标量读出被否定」 | Q2-C2c（M4） | 相反，读出**就是**线性的；M4 的不成立来自 m̂ 不是功能轴 |
| 本轮 O1「全词法，锥=反嵌入几何」 | Q2-L | 结论正确但平凡（T1），不得作为机制发现引用 |

**为什么 Q2-C2c 会量出 53° 的门，而本轮去掉 24% 词法能量就崩？**
因为两者的参考轴不同：C2c 的 R 是相对**共识方向 m̂**（47 个其他样本 Δ 的均值）
取的残差，而 m̂ 与真实功能轴（词法方向）只有 0.48 的对齐；R 去掉的是 m̂ 分量，
很可能完整保留了词法分量。本轮 orth1 去掉的正是词法分量，所以立刻失效。
**用错误的轴做"各向异性"测量，会把轴的选择误差读成锥的形状。**

## 四、什么还成立

撤回的只是「L33 末位做向量注入」这一类干预的判读。以下不依赖它：

1. **行为地板 = 1/3**（Q2-G）。最大可测损伤 0.667，越阈即掉到猜测。
2. **损伤 = 覆盖率 × 集中度**，与总头数无关（Q2-F/G，3.4× 差）。
3. **无必需头、无必需层、无致病组合**（Q2-H，四路独立否定）。
4. **注意力对齐与因果承载在层轴上反相**（Q2-D2）：L28–L35 的 133 个高对齐头
   全消融零损伤，几乎无对齐头的 L0–L3 掉 0.674。
5. **L33 是读出汇聚点**（Q2-C1，用的是真实激活而非嵌入差）：
   - L0–L32：改**施事位置**的激活，答案跟着翻（1.00 → 0.79 → 0.58 → 0）；
   - L33 起：改施事位置无效（0.00），改**末位**有效（1.00）。
   这条测的是"信息还能不能从别处进到读出位"，与词法注入无关，仍然有效。
   **新的理解**：L33 之前末位的内容还能被上游改写，之后不能。所以角色解算发生在
   L33 之前，末位在 L33 只是把已经定好的答案摆出来。

## 五、这轮真正学到的方法论

**在读出点上注入向量，测的是 LM head 的线性映射，不是模型的计算。**

任何"特征方向""概念向量""steering vector"在末位（或任何被直接读取的位置）上做，
都会得到"注入了就生效"的假阳性；而它生效的原因与你想研究的机制无关，
只需要它是某个 token 的嵌入方向。

**判据（D9）：任何读出点注入实验，必须报三组控制——换层、换位置、换目标词。**
三者任一仍生效，该干预就不能用来推断机制。

这条与既有的 D1–D8 是同一族：**先问「这个数在什么条件下会不成立」，再问「它说明了什么」。**

## 六、对整个 Q 线的后果

Q 线前九轮（Q1 → Q2-L2）走过的干预类型：

| 类型 | 轮次 | 能回答的问题 | 结果 |
|---|---|---|---|
| 头消融 | Q1, Q2-A…H | 缺了会不会坏 | 容量分布式，无承载者 |
| 真实激活修补 | Q2-C1 | 内容换了会不会变 | L33 是汇聚点（有效） |
| 向量注入 | Q2-C2…L2 | **基本不能回答机制问题** | 测到的是线性读出（本轮撤回） |

剩下唯一没被证伪的窗口是 **L20–L32，读出点之前**，而且必须用**真实激活或注意力权重**
做干预，不能用嵌入差。机制问题是：

> L29–L32 那 4 层里，末位残差流是如何从「一堆候选实体」收敛到「就是张三」的？
> 谁把哪个位置的信息送进去？为什么 L33 之后就送不进去了？

这正好落在 Q1 的 263 个对齐头（中位层 28）与 Q2-D2 的承载剖面之间——
两者在层轴上反相，而反相的交叉区就是 L20–L32。
