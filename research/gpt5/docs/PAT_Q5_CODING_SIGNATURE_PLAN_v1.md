## 0 一句话

你说的「多维度竞争融合」是一个**类型断言**，不是一个位置断言——这恰好是本项目十二轮来
一直缺的那种题型。它可以用**四次测量**判决完，而判决完就没有下一个问题了：

## 1 你的假设里，哪一部分已经被现有数据说了「不」

先把假设拆成四条独立断言，逐条对账。

| # | 你的断言 | 现有数据 | 读数 |
|---|---|---|---|
| A1 | 知识、推理、语法都是「模式」，同一种机制处理 | 未测 | **可测**（Q5-G，暂缓） |

### A3 为什么不看好：三处独立证据都指向「单选」，不是「加权」

**证据一（Q4-R 的边际）**：`l*` 处 `(top1−top2)/top1` 中位 **0.816** ⇒ top1 是 top2 的
**5.4 倍**。如果三槽是加权融合，边际应接近 0（三槽各 ~0.33）。

**证据二（Q4-R 的置换一致性）**：同一句内三个查询给出三个**互不相同**的槽，48/48。
若是融合，三个查询应得到三个高度相似的混合分布，argmax 会大量撞车。

**证据三（Q2-E/F/G 的串联结构）**：两带 L0–L3 / L16–L19 是**串联共享通路 + 损伤预算阈值**，
轻度组超可加（0.03+0.13→0.35）。并联加权系统不会出现阈值式饱和。

⇒ **我目前的判断：这个系统更像「每层选一个赢家，逐层串联」，不像「多维加权求和」。**
但这三条都是**间接**证据。必须直接测一次形状，否则又会变成「我记得它是单选」的口头断言。
这就是 Q5-A。

### 但 A4 我认为你是对的，而且它是整件事的核心

「相对编码 + 复用差分」——这两条不是待验证的猜想，而是**架构事实 + 唯一可能的实现方式**：

- RoPE 让 `q·k` 只依赖**相对位移**，所以「相对编码」在架构层已经成立；
  真正没测的是**模型在多大程度上依赖它**（是把位置当坐标用，还是当门用）。
- 「复用差分」是**必然的**：有限参数要覆盖无限组合，只能靠「共享基 + 少量修正」。
  问题从来不是「有没有」，而是**修正项长什么样、能不能 held-out 预测**。

Q3-T3 已经给了一个**边缘**读数：共享 rank-8 子空间只解释 65.3% 的方差。
这既不是「没有共享基」（否则远低于此），也不是「共享基就够」（否则接近 100%）。
⇒ **恰当的解释是「基 + 一个还没被测出来的修正项」。** Q5-D 就是去测那个修正项。

## 2 方法论改动：从「找零件」改成「定类型」

十二轮全是定位题（「角色存在哪里」），死因同一：**分布式系统里可能根本没有那个地方**。

但你这次的问法不一样。你说的不是「融合发生在第几层」，而是
**「融合是哪一种运算」**。这是一个**类型问题**，不是位置问题。

而类型问题有一个定位问题不具备的性质：**取值空间是有限的。**

把编码机制写成四个正交的代数选择：

| 位 | 问题 | 取值 | 含义 |
|---|---|---|---|
| **S** 选择 | 同一决策点，多个候选怎么合并 | `argmax` / `Σ` | 赢家通吃 / 加权求和 |
| **X** 坐标 | 匹配依赖什么 | `rel` / `abs` | 相对位移 / 绝对位置 |
| **D** 差分 | 模式复用时怎么落地 | `delta` / `recode` | 基 + 修正 / 每次重编码 |
| **C** 组合 | 复杂表达怎么搭起来 | `∘` 串联 / `+` 叠加 | 逐层接续 / 一次求和 |

**4 位 × 2 = 16 种类型。** 每一种对应一个能直接写下来的算式，例如：

```
(S=Σ, X=rel, D=delta, C=+)  →  out = Σ_m w_m · (B + δ_m)，w 为 softmax 权重
                              ← 稀疏线性编码：无限组合来自基的组合数
(S=argmax, X=rel, D=delta, C=∘) →  s_l = route(s_{l-1}) = argmax_slot q·k
                              ← 路由串联：无限组合来自 槽数^层数
```

这两种类型的**下游一切都不一样**：怎么解释、怎么利用、怎么继续测。
而现在我们连自己在哪一种里都不知道——这才是循环的真正原因。

> **这是对「怎么不进入无限循环」的直接回答**：问题空间有限，测完就没了。
> 不需要靠「3 轮预算」封顶（D23），而是靠**穷举**。预算封顶是制度约束，
> 签名穷举是**数学终止**。后者才是「破解」的形式。

## 4 Q5 三个 Phase

### Q5-A　融合的形状（最便宜，先跑）

**问题**：三槽注意力分布是「赢家通吃」还是「加权？」。

**测量**：144 格，在 L21–L23 与 L28 读末位 query 到三槽的注意力质量 `a ∈ R³`，
报 `H(a)/log 2` 的**分布**（不是均值——D5：先看分布）。

**判据（跑前冻结）**：

| 编号 | 判据 | 判决 |
|---|---|---|
| **A1** | 归一化熵中位 **≤ 0.35** | `WINNER_TAKE_ALL`（S=argmax） |
| **A2** | 归一化熵中位 **≥ 0.70** | `WEIGHTED_SUM`（S=Σ） |
| **A3** | 0.35 < 中位 < 0.70 | `MIXED` —— 记录双峰，**不允许报均值**（D5） |

**冲突臂（决定性）**：构造「双有效查询」——把两个查询的末位 q 激活相加后注入 L20。
- 若 S=`argmax`：注意力应仍集中在**一个**槽（另一个查询的槽得不到质量），归一化熵仍低。
- 若 S=`Σ`：注意力应分裂到两个槽，熵升高接近 1。
- **这条是本 Phase 的真正判据**，因为单查询下的低熵可能只是「只有一个正确答案」。

**成本**：144 格 + 288 次冲突前向，约 1–2 分钟。

---

### Q5-D　差分能不能被 held-out 预测（核心）

**问题**：模式复用时，修正项 `δ` 是否可由**实体码**线性生成。这是「复用差分」的机制形式。

**构造**：
```
同一句式、同一查询、换三元组 T：  a_T ∈ R³（三槽注意力质量）
分解：                            a_T = ā + δ_T       ā = 跨三元组均值（共享基）
假设：                            δ_T ≈ W · (k_A − k_B)   （实体码之差 → 修正项）
```
`k_A、k_B` 用**独立夹具**的静态码（Q4-R 已建好，324 次前向）。

**测量**：按三元组 5 折。训练折拟合 `W`，测试折预测 `δ` 与**槽选择**。
- 同时报一个更强的版本：`δ_T ≈ W·[k_A; k_B; k_W]`（三个槽的码一起）

**判据（跑前冻结）**：

| 编号 | 判据 | 判决 |
|---|---|---|
| **D1** | 槽选择 held-out 准确率 **≥ 0.90** | `DELTA_LINEAR` —— 差分是实体码的线性泛函 |
| **D2** | `δ` 的方差解释率 **≥ 0.80** | 同上，且给出 `rank(W)` |
| **D3** | 以上都不成立，但 `δ` 的方差解释率 **≥ 0.40** | `DELTA_NONLINEAR` —— 存在修正项但非线性 |
| **D4** | 方差解释率 **< 0.20** | `RECODE` —— 每次重新编码，无共享差分（与 T3 的 0.653 冲突，须解释） |

**为什么这条重要**：若 D1/D2 成立，则「有限字词无限组合」就有一个**可计算的机制**——
用有限个实体码做线性泛函，predict 任意组合的路由。这可以直接外推、可以验证、
可以用新实体做**零样本预测**。这是「破解」的可操作含义。

**成本**：144 格与 Q5-A 共用前向，拟合 < 1 秒。

---

### Q5-C　组合的曲线形状（判定 C 位）

**问题**：复杂表达是「加起来的」还是「一节节接起来的」。

**构造**：关系链嵌套深度 1→4。
```
深度1: A 把 W 给了 B。              查询: 谁拿到了 W？
深度2: A 把 W 给了 B，B 把它给了 C。  查询: 谁最终拿到了 W？
深度3: ... 再传给 D
深度4: ... 再传给 E
```

**判据（形状二选一，跑前冻结）**：

| 编号 | 形状 | 判决 |
|---|---|---|
| **C1** | 准确率随深度**平滑下降**，每级降幅接近常数 | `ADDITIVE`（C=+） |
| **C2** | 准确率在某深度前**基本平坦**，之后**崩塌**（>0.5 drop） | `SERIAL_THRESHOLD`（C=∘） |
| **C3** | 无下降 | 深度不够，**判 NULL_POWER**，须加深（D23） |

**为什么用形状而不是显著性**：这与 Q2-E/F/G 的「损伤预算阈值」是同一个判据形态（E1 级可独立成立），
且与 Goodfire 那次终止循环的判据同型——**换对照只改幅度，不改形状**。

**成本**：4 深度 × 24 三元组 × 2 句式 = 192 格，约 2–3 分钟（含新模板校验）。

## 5 为什么这不是又一轮局部特征

| 局部特征型（前十二轮） | 签名型（本轮） |
|---|---|
| 「角色存在哪里」 | 「融合是哪一种运算」 |
| 取值空间：每个位置 × 每个头 × 每层 = 无限 | 取值空间：**16** |
| 找不到 ⇒ 换一侧再找 | 测完 ⇒ **类型确定，问题关闭** |
| 判据：显著 / 不显著（可用切片救） | 判据：形状 / 预测准确率（不可用切片救） |
| 终止条件：预算用完（制度） | 终止条件：**空间穷举完（数学）** |

**并且本轮有明确的失败条件**（写在跑之前，不是事后）：

> 若 Q5-A 判 `MIXED`（熵双峰且不能分层解释）、Q5-D 判 `RECODE`、Q5-C 判 `ADDITIVE`
> 三者同时与 Q2-E/F/G 的串联证据冲突 ⇒ **不是签名没测准，是四位划分本身不适用**。
> 此时应放弃「代数签名」框架，而不是加第五位。这是 PSF-3 的自检条款。

```
Q5-A（形状）──┬─→ 决定 S 位
              └─→ 约束 C 位（若 argmax 则 C 几乎必为 ∘，若不成立 ⇒ 类型划分错）
```

跑完 A + D + C，就能写出四位的完整签名。**签名确定之后，本项目的「破解」目标即达成**——
因为签名就是编码机制的规格说明，剩下的工作是按签名去构造，而不是继续测量。
