## 一、把例句拆开：四样东西不是四类模式

「我喜欢吃苹果」的准确结构：

```
喜欢( 我 , 吃( ⟨我⟩ , 苹果 ) )
```

- **两个实体型模式**：我（第一人称、单数）、苹果（类别、可食）
- **两个谓词型模式**：喜欢（二元，带命题补足语）、吃（二元，带实体论元）
- **一个隐含控制代词**：吃的施事没有字面出现，是 PRO，必须指回"我"

三个必须承认的事实：

1. 谓词之间是**嵌套**，不是并列。「喜欢」的第二个论元是整个命题「我吃苹果」。
2. 控制关系是**等号约束**，不是相似度。「吃」的施事必须 = 「我」，绑错就变成"苹果在吃自己"。
3. 这句话的实际内容量 ≫ 四词词义之和，**差额全在绑定里**。

**论断 1**：词向量只提供填充物，句式提供角色结构，被"理解"的是绑定关系。

## 二、模式的数学结构：三个候选，必须判决

### A 方向叠加
句子 = Σ 模式向量。
**致命缺陷**：加法可交换 ⇒「我吃苹果」与「苹果吃我」编码相同。模型明显分得清。
结论：A 只在无角色要求时局部成立，不可能是全局机制。

### B 张量绑定（VSA / HRR）
bind(r, f) = r ⊛ f；多个绑定叠加 M = Σ rᵢ ⊛ fᵢ 仍可解绑。
优点：解释"同一记忆、不同指针取不同答案"。
**可算代价**：串扰。绑定数 n 增加时解绑信噪比按 ~1/√n 衰减。
⇒ 定量预测：长句角色解码精度随论元数下降，斜率可预先计算。

### C 注意力路由
绑定不在向量里，在注意力里：query = 角色，key = 位置，value = 填充。
绑定是"取的时候现建"的。

### 判决与立场
**C 是真机制，B 是 C 的低秩等价描述，A 是 B 在角色退化时的特例。** 三者不互斥。

判据只有一问：**角色是"存"在表示里，还是"取"时才算？**

已知证据指向后者：2831 测得问句不改写历史（苹果@2 谱 diff 0.009–0.017，null 0.053），模式选择发生在生成端 next-token 分布。若角色是存进去的，问不同问题时历史表示应当不同；实测不变。

**可证伪**：若测出该句在早期层即按问法分化，则 C 错、B 对。

## 三、关联的三种形式

| 类型 | 数学形式 | 载体 | 状态 |
|---|---|---|---|
| 共现关联 | P(苹果\|吃) | 词嵌入 | 已破（2806/2809/2824） |
| 结构关联 | 加权有向图，边带角色标注 | 位置索引 + 注意力 | 可测，未系统化 |
| 同指关联 | 等号约束（①=①） | 跨位置身份传递 | 最难，几乎空白 |

**论断 2**：「我」与「苹果」嵌入不相似，却都与「吃」有角色关系 ⇒ 关联的载体必须是位置索引 + 注意力，不能是向量相似度。

推论：一切"用嵌入相似度建语言图谱"的做法只能复原第一行，而第一行早已破了。共现聚类的作废（R-MET-11/12）与此一致。

## 四、模式四元组 M = (S, r, g, π)

| 分量 | 数学对象 | 实体（我/苹果） | 谓词（喜欢/吃） | 测法 | 判据 |
|---|---|---|---|---|---|
| S 内容子空间 | R^d 低维子空间，dim 2–8 | 强 | **弱** | 差分 + SVD | 谓词 S ≪ 实体 S |
| r 角色基 | 一组近正交方向 | 空/弱 | 强，2–3 个 | 角色互换差分 | cos(Δ, r_role) 显著 |
| g 门 | 标量门函数 | 常开 | 句法位置/功能词触发 | attention mass + QK 自绑定 | 谓词出现时门跳变 |
| π 指针 | 位置概率分布 | 自身或同指链 | 论元位置 | 注意力矩阵 + 路径修补 | 落点与角色一致 |

### 强预测（可证伪）
谓词的 S 很小、r 很大；实体的 S 很大、r 很小。
若测出谓词携带厚重内容子空间 ⇒ 框架错，重做。

### 推论
谓词几乎不带内容 ⇒ **模型里不存在"吃"的知识，只存在"吃"的角色槽位**。关于吃的事实全在填充物与绑定里。

对应三类模式：
- 语法系统 = g 与 π（算子）
- 知识网络 = S（数据）
- 分析推理 = 算子的串联（复合）

**"破解语言"的精确表述**：写出 (S, r, g, π) 的完整代数与复合规则。

## 五、查询算子：为什么换个问法就激活不同信息

同一份绑定，换一个角色向量去解，取出的就是不同槽。

| 问法 | 解绑槽 | 落点 |
|---|---|---|
| 谁喜欢吃苹果 | agent / exp | 我 |
| 我喜欢吃什么 | patient / theme | 苹果 |
| 谁喜欢吃什么 | 双空缺 | 需同时保持两个未填槽 |

历史表示可以完全不变——因为解绑发生在读取端。

### 实验 Q1（最高性价比）
同一句 + 三种问法 + 一个对照（换谓词：谁讨厌吃苹果）。
测：问句末位回看原句的注意力质量分布。

**判据**：
- 两个查询的分化发生在**同一层**，且落在**不同 token** ⇒ C 成立；
- 分化出现在早期编码段 ⇒ C 错、B 对。

## 六、最深的未决问题：角色是方向，还是置换

| 假设 | 预测 | 判决 |
|---|---|---|
| 角色 = 方向 | 角色互换表现为线性变换，Δ 对齐固定方向，可跨句迁移 | 迁移干预生效 |
| 角色 = 位置/置换 | 向量不变，注意力指向改变 | 迁移失效但注意力目标重定向 |

**倾向"位置"的两个理由**：

1. **容量**：4096 维只能放数百个近似正交方向，而语言角色是开放的（每个谓词论域结构不同）；位置方案无上限。
2. **自洽**：与"角色取时现算"（C）一致——位置天然在取时才可用。

**后果**：若判定为"位置"，神经元图谱工程的形态要改——找的不是"提问神经元"，而是"提问时把指针拨到哪个位置"的规则。图谱从"特征清单"变成"指针规则表"。

## 八、与既有纪律的接口

- 对齐 ≠ 因果（ρ=0.106）：Q1 的落点必须用激活修补复核，不能只报注意力权重。
- 归因 ≠ 机制：注意力权重是相关性，须配路径修补。
- 范数混淆（ρ=0.97）：S 的大小必须份额归一化，不能比绝对范数。
- 跨层 cos 不可用：r 的跨层比较用子空间主角度。
- 多重实现：判据是"充分且最小"，非"唯一"。
