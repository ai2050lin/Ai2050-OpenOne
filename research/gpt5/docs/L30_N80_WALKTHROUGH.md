## 1 零 GPU 能测到的四件事

### 1.1 它的强弱：**极弱**

| 量 | L30.N80 | 同层 9728 通道中位数 | 百分位 |
|---|---|---|---|
| 读方向范数 `‖W_gate[80,:]‖` | **0.8170** | 1.2247 | **0.22%** |
| 写方向范数 `‖W_down[:,80]‖` | **1.0064** | 1.2667 | **2.40%** |

（**实测**）

百分位的意思是"有多少通道比它更小"。0.22% 意味着**全层只有 22 个通道比它更弱**（9728 × 0.23% ≈ 22）。

（**修正**：本文初版写"绝大多数通道范数都在 1.22~1.27 之间"，这个说法不准确。实测分布是 min 0.6384 / p1 0.9229 / median 1.2247 / p99 1.6215 / max 2.0629，跨度比中位数附近的集中区宽得多。准确的说法是：**左尾很薄**——中位数 1.2247，而 0.8170 已经落到 0.23 百分位，说明在 1.22 以下左侧下降极快。）

### 1.2 它的读方向和写方向：**80° 分开**

| 量 | 值 | 同层零分布 |
|---|---|---|
| `cos(读, 写)` | **0.1732** | 该值即全层 `cos(W_down[:,k], W_gate[80,:])` 的 **最大值**；mean −0.0002、p95 0.0301 |
| 换算夹角 | **80.0°** | — |

（**实测**）

两个读法都对，但含义不同：

- **相对意义**：0.1732 是同层 9728 个通道里**最高的一个**，是 p95 的 5.8 倍。所以在"谁最沿着 80 的读方向写回"这个排名上，80 号自己是第一名。
- **绝对意义**：0.17 仍然很低。它的读方向和写方向**基本正交**——它读的东西，和它写回去的东西，不是同一个方向。

## 1.5 算术核对：两个问题，逐项对账

### 1.5.1 范数是怎么算的

范数是 L2 范数，就是"每一项平方、全部加起来、再开根号"：

```
‖r‖ = √( Σᵢ r_i² ),   i = 0 … 2559
```

L30.N80 的实测对账：

| 量 | 值 |
|---|---|
| `Σ r_i²` | **0.667551** |
| `√0.667551` | **0.817038** |
| 抽样 `r[0:6]` | −0.000664, +0.002472, +0.000740, +0.010498, +0.000919, −0.013062 |
| 该 6 项平方和 | 0.000289（占总量 **0.0433%**） |
| `|r_i|` 最大 10 个坐标合计占 `‖r‖²` | **8.47%** |
| 其余 2550 维合计占 | **91.53%** |

最大那 10 个坐标是：dim 259(−0.0947)、10(+0.0815)、295(+0.0796)、27(−0.0791)、91(−0.0762)、211(−0.0752)、102(−0.0679)、460(+0.0669)、359(−0.0630)、7(−0.0618)。

**这张表最重要的一行是"8.47%"。** 它说的是：**这条 2560 维方向没有任何一个坐标说了算**——最大的单个坐标只占总能量的 1.34%，前十名加起来才 8.5%。所以"读这条方向的第 259 维是什么意思"这种问法从一开始就不成立。这也解释了为什么必须靠"乘到词表上看两端"，而不能靠读分量。

（注：这里算的是**权重范数**，不是激活范数。`‖h‖ ≈ 62` 是残差流的长度，两者量纲不同，不可比。）

### 1.5.2 正端 / 负端是怎么得到的

**它不是取 top-k 激活样本**（那是 S3，需要前向）。它是把一条 2560 维的**权重方向**投影到 151936 个词表条目上，再排序。五步：

| 步 | 操作 | 形状 |
|---|---|---|
| ① | `r = W_gate[80,:]` | `[2560]` |
| ② | `r̂ = r / ‖r‖`（只留方向、丢掉长度） | `[2560]` |
| ③ | `x = γ ⊙ r̂`（逐维乘最终 RMSNorm 的增益） | `[2560]` |
| ④ | `s = E · x`（E = `embed_tokens.weight`，qwen3-4b 与 `lm_head` 共享） | `[151936]` |
| ⑤ | 取 `s` 最大 20 个 = 正端，最小 20 个 = 负端 | 各 20 个 id |

写成一行：

```
s_t = Σᵢ γ_i · r̂_i · E[t, i]        t = 0 … 151935
```

**一个 token 的分数 = 2560 个三数乘积之和。** 以 `authorised`（s = 0.3460）为例：

| 坐标 | γ_i | r̂_i | E[t,i] | 乘积 |
|---|---|---|---|---|
| 259 | 3.1094 | −0.115939 | −0.0586 | **+0.0211** |
| 32 | 8.2500 | −0.028387 | −0.0781 | +0.0183 |
| 295 | 3.1719 | +0.097413 | +0.0457 | +0.0141 |
| 760 | 2.7969 | −0.045121 | −0.0830 | +0.0105 |
| 102 | 3.4844 | −0.083070 | −0.0349 | +0.0101 |
| 其余 2555 维 | — | — | — | **+0.2719（78.6%）** |
| **合计** | | | | **0.3460** |

注意前五行全部为正：**负×负=正**。`authorised` 之所以被推高，靠的是那些 `r̂` 为负的坐标恰好撞上了 `E` 也为负的坐标。这就是"方向"的作用方式——不是某一个坐标在表态，是 2560 个符号投票的净和。

### 1.5.3 两个必须一起说的限定

**限定一：这些 s 值不是真实 logit，只能用来排序。** 实测 `s ∈ [−0.4330, +0.3460]`，std = 0.0618；而真实前向的 logit 量级是几十。差两个数量级的原因是：`r̂` 是**权重**方向，不是真实激活；真实 `h` 的长度是 62，而 `r̂` 的长度被归一成 1。**所以"正端 20 个词"只表示"如果残差流沿这个方向偏，这 20 个词的分数相对最高"，不表示模型真的会输出它们。**

**限定二：γ 的作用比预想的小。** 实测消融：

| 变体 | top-20 重叠 |
|---|---|
| 基准（单位化 + 乘 γ） | 20/20 |
| **不乘 γ** | **19/20** |
| 不单位化、直接乘 γ | 20/20（仅缩放，排序本应不变，✓ 自检通过） |

所以"γ 必须乘否则各维错配"这个说法在**概念上**成立（γ 的 min = −0.0221，某些维度甚至翻符号；max = 9.75，跨度 440 倍），但**在本次这条方向的 top-20 上只改变了 1 个词**。正确的表述是：**γ 必须乘，但它不是结果的决定因素**——不要把它当成"做对了才有意义"的关键步骤，也不要不乘就宣称结论不同。

### 1.5.4 一个附带观察：负端比正端更强

| 端 | s 区间 |
|---|---|
| 正端 top-20 | +0.2367 ~ +0.3460 |
| 负端 top-20（即 s 最小） | **−0.4330 ~ −0.3701** |

**负端的幅度系统性大于正端**（0.37~0.43 vs 0.24~0.35）。也就是说，这条读方向更擅长"压下美式地名类 token"，而不是"推高英式拼写"。这与文章那条"负极常常是更 informative 的一侧"呼应——但必须注意：词表投影的幅度受 `E` 中各 token 行范数影响，**不能直接当成效应强度**，只能当成"排序上更靠外"。

### 结论一：如果你随手点 L30.N80，S2 就会把它刷掉

按方法论 S2，先按集中度排序再决定读哪个。一个读方向范数在 0.22 百分位、写方向在 2.40 百分位的通道，它的 z 动态范围小、输出贡献小，**极大概率 coh 低于 0.3 的可用线**。

这不是猜测，这是"为什么文章里那套流程不可复制"的具体机制：**Cammarata 是"闲逛"到好通道的，而闲逛的命中率由通道范数分布决定**——绝大多数通道是弱的。工程上必须靠 S2 排序替代闲逛。

> **操作修正**：在跑 S1 之前，先做一次零 GPU 的**范数预筛**——把 `‖W_gate[j,:]‖` 和 `‖W_down[:,j]‖` 都算出来（一次 25M 浮点运算），把低于 5 百分位的通道直接从候选里剔掉。这一步不需要任何前向，能省掉大量无效的 S3–S9。

### 结论二：概念不是一个方向，是一个子空间

这是本次实测最重要的发现，也是对整个方法论的一处修正。

方法论（和文章）隐含一个假设：**一个通道 ≈ 一条轴 ≈ 一个概念**，所以 Δ 是一个方向。

但 L30.N80 给了一个反例：

- 读方向的词表两端 = 英式拼写 ↔ 美式拼写
- 写方向的词表两端 = 英式制度/地名 ↔ 美式地名
- **两个词表都通顺，都指向"英式 vs 美式"**
- **但两个方向的 cos 只有 0.17（夹角 80°）**

如果"概念 = 一个方向"，这两个方向应该几乎重合。它们没有。

所以正确的图景是：

> **一个概念在这一层对应的是一个低维子空间（至少二维），而不是一条线。读和写各自用这个子空间里的不同方向表达同一件事。**

这直接对上我们自己的两条既有证据：3255 的双轨道几何（两条轨道而非一条）、3253 的"中层低谷是载轴衰减而非替换"。**"通道当单位"的问题不在粒度，在维度**——一个通道内部就已经有两个方向了。

**对流程的修正**：S5 的对偶检验不能只验 `Δ` 一条轴，必须验 `Δ` 所在的**子空间维度**。具体做法：对 P 和 N 的 h 做 PCA（或对 Δ_read、Δ_write 两个方向求夹角），若前两个主成分都承载两极差异，则"单轴"假设不成立，描述里必须写成"它在区分 X 的两个侧面"，而不是"它在区分 X 和 Y"。

### 结论三：F20 是默认状态，不是例外

F20 的账是"读出几何 ≠ 行为控制"。本次实测给出了它在参数层的根据：

**9728 个通道里，读方向与写方向的自对齐中位数是 0.0007。** 也就是说，"读一个方向、写另一个方向"是**默认情况**；"读和写同一个方向"才是稀有情况（34/9728 = 0.35%）。

所以：

- 从"我读出了它在区分什么"推到"改变它会改变行为"，中间那一步**在几何上本来就不成立**，除非该通道恰好落在 0.35% 里。
- F20 不是实验设计失误，是**结构性现象**。
- 反过来，`cos(读,写)` 可以作为一个**筛选指标**：只想找"可控"的通道时，先筛自对齐 > 0.5 的那 34 个，它们的几何与行为有理由一致。

## 3 剩下五步：需要一次前向

以下全部是**待跑**。给出确切参数、算式、以及每一步的预期形态（预期由 §1.4 的词表实测推出，可被证伪）。

### S1 采集

```python
# 只取第 30 层，只存两个张量
# H: [N, 2560]  post_attention_layernorm 的【输入】（norm 之前）
# G: [N, 9728]  mlp 的 gate_proj 输出（silu 之前）
hooks = [
    ("model.layers.30.post_attention_layernorm", "forward_pre", "H"),
    ("model.layers.30.mlp.gate_proj",            "forward_hook", "G"),
]
```

| 参数 | 取值 | 依据 |
|---|---|---|
| 语料 | 2000 段，单段 256~512 token | 覆盖优先；长上下文现象必须能出现 |
| 位置数 | ≈ 400,000 | 2000 × 200 平均 |
| 层 | 只取 30（其余层不要） | 内存省 35 倍 |
| 精度 | bf16 | 与权重一致，无额外损失 |
| `H` 体积 | `400000×2560×2B` = **1.91 GiB** | 可以全存 |
| `G` 体积（全存） | `400000×9728×2B` = **7.25 GiB** | 不要全存 |
| `G` 体积（流式堆） | `9728×400×(4+4)B` = **31 MB** | 只留每通道 top-200/bottom-200 |

**必须做的两件事**：
1. 流式维护 31 MB 的堆，不落全量 `G`。
2. 只对**范数预筛后**的通道（§2 结论一）建堆，其余跳过——9728 个堆里有九成是浪费。

### S3 取两极

| 参数 | 值 |
|---|---|
| k | 100（先用 50 试，看 coh） |
| 有效文本数下限 | 20 段 |
| 读出位置 | 全部 token 位置（不做标点屏蔽，但要**记录**是否在标点/句末，见下） |

**必须记录的一个字段**：每个 top 位置是否落在标点或句末。文章**原文**说 *"attention seems to collect on the punctuation, which we call the **summary motif**"*——情感/社交类通道常在逗号上最强。若 P 集里标点占比 > 30%，说明读到的可能是**整句滚动摘要**，不是局部词义，描述必须相应改写。

**预测（可证伪）**：基于 §1.4 的读方向词表，若 L30.N80 的 P 集集中在**英式拼写的词**（`-ise/-our/programme`）或**英国语境文本**（postcode、railway、Ltd），则读方向与激活方向一致；若 P 集与此无关（例如全是中文或全是标点），则说明**权重空间的词表投影与激活空间的行为无关**——这本身是一个重要否定结果，第 6 节会用到。

### S4 算差

```
Δ = mean(H[P]) − mean(H[N])        # [2560]
```

三个必须一起报的量：

| 量 | 阈值 | 不过怎么办 |
|---|---|---|
| 劈半 `cos(Δ_A, Δ_B)` | > 0.5 | 回 S3 加 k / 加语料 |
| 有效文本数 | ≥ k/5 | 回 S1 扩语料 |
| `cos(Δ, W_gate[80,:])` | 参考值，**无阈值** | — |

第三个量是本文档特有的：**Δ 与读方向的夹角，衡量"这个通道实际读的，和它参数的读方向，是不是一回事"**。§1.3 告诉我们不要期待它高——全层自对齐中位数只有 0.0007，所以 Δ 与读方向夹角大是正常的。

### S5 对偶检验（含子空间修正）

```
coh_P = ‖mean(H[P])‖ / mean(‖H[P]‖)
coh_N = ‖mean(H[N])‖ / mean(‖H[N]‖)
R     = coh_N / coh_P
```

随机基线 `1/√k = 0.10`；`R > 0.6` 通过。

**按 §2 结论二加一步**：对 `H[P] ∪ H[N]` 做 PCA，看前 2 个主成分是否**都**承载两极差异（即两极在 PC2 上的均值也显著不同）。若是，则描述写成"两个侧面"，不写"一对反义"。

**预期**：若 §1.4 的双方向结构在激活层也成立，PC1 和 PC2 分别对应"拼写侧"和"制度/地名侧"。

### S6 词表（已有，但要换成 Δ 的）

§1.4 已经给了**读方向**和**写方向**的词表。S6 要算的是 **Δ 的词表**，三者对照：

| 方向 | 词表 | 来源 |
|---|---|---|
| 读方向 | 英式拼写 ↔ 美式 | **已完成（实测）** |
| 写方向 | 英式制度 ↔ 美式地名 | **已完成（实测）** |
| **Δ** | ? | 待跑 |

**三者一致** → 该通道单义且自洽。
**Δ 与两者都不同** → 该通道的激活行为不由它的参数方向决定（frozen / 被 override），这在深层不罕见。

### S7 steering

```
h' = h + α · Δ̂          α ∈ {0.5, 1, 2, 4} × ‖h‖
```

双向都做。**预测**：若轴成立，`+α` 应让输出更"英式"（`whilst`、`programme`、`-ise`），`−α` 更"美式"（州名、`-ize`）。这是本文档给出的第二个可证伪断言，而且**用生成文本就能一眼看出**，不需要任何指标。

## 4 一个必须纠正的方法论错误：跨层归族不能直接用 cos

方法论 S9 说"查族：这条轴在其他通道、其他层是否复现，阈值 cos > 0.7 或基线 +2σ"。本次实测证明**这条在权重空间里会给出错误答案**。

| 层 | 与 L30.N80 读方向的最大 cos | 通道 | p99 | 随机对基线 |
|---|---|---|---|---|
| **L26** | **0.2665** | N247 | 0.0502 | 0.0067 |
| L28 | 0.1476 | N12 | 0.0611 | 0.0063 |
| **L29**（相邻） | **0.1578** | N61 | 0.0533 | 0.0078 |
| **L31**（相邻） | 0.1813 | N29 | 0.0565 | 0.0079 |
| L32 | 0.1408 | N91 | 0.0559 | 0.0072 |
| L34 | 0.1722 | N21 | 0.0598 | 0.0037 |

（**实测**）

看第二行和第三行：**L26（隔 4 层）的 0.2665 比 L29（相邻）的 0.1578 还高。** 如果"相邻层最像"，这个结果不该出现。

原因有两个，都不能靠调阈值解决：

1. **坐标系在漂移。** 第 26 层的残差流和第 30 层的残差流不是同一个空间——中间隔了 4 个 block 的累加。两个"读方向"是在各自层的坐标里量的，直接比 cos 等于比两个不同坐标系里的向量。
2. **绝对值太小，排名无意义。** 0.27 和 0.16 都远低于"同一件事"该有的量级（§2 结论二里同层同概念的两个方向是 0.17，而它们明确是同义的）。在这个量级上比大小，比的是噪声。

**修正后的做法（三选一）**：

| 方案 | 做法 | 代价 |
|---|---|---|
| A 共同空间 | 把各层的读方向都投影到**输出词表空间**（乘 `lm_head`），在词表空间里比 cos | 便宜，但丢失残差空间几何 |
| B 同层激活 | 只在**同一层**内比较 `Δ`，跨层只比较"描述"不比较向量 | 最稳，但失去定量 |
| C 变换矩阵 | 估计层间变换 `T_{26→30}`（用同一批 h 做最小二乘），把 L26 方向搬过来 | 最准，但贵且引入新假设 |

本次实测建议 **B 为默认**、**A 为补充**。同时把方法论里"cos > 0.7"这条降级为"仅同层可用"。

## 6 这个例子的三个方法论产出

1. **范数预筛应前置到 S1 之前。** 9728 个通道里绝大多数是弱通道（L30.N80 读范数在 0.22 百分位），先剔掉再采集，能省掉大量无效 S3–S9。这一步零 GPU、一分钟。

2. **"一个概念 = 一个方向"要改成"一个概念 = 一个低维子空间"。** L30.N80 的读方向和写方向都指向"英式 vs 美式"，但夹角 80°。这条同时对上 3255 双轨道和 3253 载轴衰减——**问题不在通道粒度，在维度**。

3. **跨层归族的 cos 阈值是错的，只能同层用。** 实测 L26 的 0.2665 > L29 的 0.1578，说明权重空间的跨层比较被坐标系漂移污染。

附带一条可直接用于 F20 的量化接口：**`cos(读方向, 写方向)` 的中位数是 0.0007，只有 34/9728 个通道 > 0.5。** 若我们的 steering 实验在某些通道上"几何对、行为不对"，先查它落不落在这 34 个里——这是一个**在做实验之前就能算出来的预测变量**。
