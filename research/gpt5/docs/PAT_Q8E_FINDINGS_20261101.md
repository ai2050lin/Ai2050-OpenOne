## 零、一句话结论

**频率子空间的「形状」跨规模完全稳定，但「内容」只是弱共享**：Qwen3-14B（d=5120）完整复现
Q8-B 的全部形状不变量（R² 0.7515、对数刻度 gap 0.858、Krylov k*=2、语义正交保留 1.00），
使「低维稠密频率子空间 + 对数刻度」成为**三模型、两家族、两个数量级参数差的引用级规律**；
但控制 zipf 后两个模型的逐 token 标量预测残差只有 ρ=0.427（零分布 p99=0.0175 的 24 倍，
但低于预注册的 SHARED 阈 0.50）——**形状是训练动力学的普遍吸引子，频率标量的具体分布
大部分是各自训练的偶然**。

## 二、跨模型仪器的口径教训

1. **cos(w_freq) 无意义**：两模型坐标轴各自训练，没有对齐保证（AGENTS.md §3）。唯一干净
   的跨模型量是逐 token 标量 `t = (E−μ)@w`（共享行空间）。任何"跨模型方向余弦"都属
   坐标巧合。
2. **Gram 缓存键不含 X 身份**：pat_q8b 的缓存键是 (ns, 折指纹)。诊断脚本里两个模型用了
   相同 ns，5120 维的 G 被塞进 2560 维的键下直接 `solve` 维度报错——**实证了 R-MTH-24
   的推论：跨模型复用同一缓存函数时，ns 必须带模型名**（本轮主脚本已带 `name|` 前缀）。
3. **噪声地板量不可点复现**：原始频率轴（无信号目标）的 held-out R² 在同一折划分下
   cv_fast 给 −0.10、手写正规方程给 −0.97——差异来自两条代码路径在最小特征值方向上的
   数值细节。**点值没有意义，判决必须按不等式**（本条：r² < 0.10 且 gap ≥ 0.30，两条路径
   都满足）。多种子波动：4B [0.020, 0.027]、14B [−0.113, −0.102]。
   **新纪律 R-MTH-30**：无信号/噪声地板量报"多种子均值±极差 + 不等式判决"，禁止把单次
   点值写进结论。
4. 复核自身两次被抓出 bug：①汉字判类漏了扩展 A 区 200 字（池 24221 vs 24421，全部数值
   漂移）——判类语义必须逐字符区间对齐；②上述噪声地板点值复现。最终 **18 PASS / 0 FAIL**。

## 三、理论定位

- Q8-B（4B vs GLM-9B）：形状同构 → "两家族共享"。
- **Q8-E（4B vs 14B，同家族 3.5× 参数差）：形状不变量第三点成立** —— 对数刻度、2–4 维
  稠密子空间、与范数/语义正交、无单坐标承载（4B 最强单坐标 −0.4414、14B +0.4990，R²
  0.195/0.249 vs 全空间 0.83/0.75）。**升格为引用级规律**。
- E4 的 SCALAR_WEAKLY_SHARED 与 Q8-D2 的 NULL_BOUNDED 合起来：**频率子空间是训练
  过程的普遍副产品（吸引子），不是功能组件**——它有跨规模共享的真实成分（残差相关 0.43），
  但模型不通过它计算频率，且其逐 token 分布大半是训练偶然。这与「训练化石」假说一致，
  并给化石增加了一条可测的内部结构：化石之间也部分相关。
- 挂账：ρ_partial=0.427 的来源未定位（词族结构？语域共现？）；GLM 无 14B 对照
  （ZhipuAI 无 9B 以外同家族权重）。
