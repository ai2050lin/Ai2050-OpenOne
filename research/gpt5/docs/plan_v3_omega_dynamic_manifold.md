### 逐条详注

**空白一（多轴融合）**——附件问"线性叠加 A+B+C 还是非线性交互 A×B"，这是可操作的好问题。但三点修正：①"子空间互斥"是 2944/2938 的低秩近似表述，2939 证明能量可在 SVD 基内流动，互斥不彻底，不能作为融合代数的公理；②响应量是 C[层,词,头] 张量（2964 口径），交互项必须逐格定义，"R_a×R_b 标量式"写法会丢掉头级结构；③2950 铁律：消融差分=直接+竞争重平衡、符号可反——融合代数主张必须快照线性分解与真实消融双口径分账，否则会把重平衡误读为交互。

**空白二（长上下文）**——完全成立。我们已有间接证据：2934 证明同一实现下 batch 组成差异使读数漂移 3.7e-3，说明前文确实进入计算；但 s_c 开关阈值、A11 路由增益谱、B 带差分随上下文长度的漂移从未测量。附件"流体粘滞度/引力拖拽"是隐喻，入方案必须改写为可失败判据（漂移曲线的存在性、单调性、饱和性三个分开的检验——2966 教训：单调检验与峰位/形状检验不能混用）。

**空白三（握手协议）**——问题真实，但附件提案有一个**致命方法缺口**：在 2560 维空间里，两个低秩子空间的 top 主方向几乎必然近似对齐（高维随机几何的确定性事实）。不做随机旋转 null 校准就报"对齐"，会得到纯机会水平的假阳性（这正是 2809/2928/2931 三次教训的子空间版，已制度化）。"自适应对齐机制"是目的论语言，可证伪版本是：真实头（如 h15 的 W_ov 输出子空间）与下游 MLP 行空间的对齐度**超过随机头 null 的 p95**（2931 重叠校准口径）。

**空白四（抽象推理）**——附件对现状的复述准确（具体/抽象在承重带无签名、F/C 有）。但"更高维度、更复杂曲率"不可操作（维度/曲率在本框架无估计器）。可操作替换：逻辑连接词（because/although/therefore…）vs 名词基线的深层带签名检验——F/C 机器直接扩维；"跨数百 token 聚合"依赖空白二机器，必须排在 Ω-C 之后。

**空白五（幻觉）**——目前不可操作：我们没有"真实事实流形"的坐标，"势垒/相变热力学"在无能量泛函前是隐喻，按纪律 17（定义保证永真的判据禁令）不得入判决。可操作第一步：**误导=竞争方向注入**（2950 竞争重平衡机器现成）——测注入撤除后读出的**持久位移（滞后/hysteresis 面积）**与**不可逆剂量阈值**的存在性；"病态相变"的名字只允许在滞后与阈值都被证实后出现。

**空白六（跨规模）**——完全正确，与方案 v2 阶段三重合。2971 的 34 卡原语卡片集正是为此准备的登记物：先在第二模型上逐卡复制（同协议、同锚结构），复制状态分级登记后，"新原语"才有定义域（没有基线就无法定义"新"）。

**Phase Omega-4 提案本身**——三合一违反本项目"一 Phase 一冻结判决映射"纪律（2933 教训：多分支映射每条阈值都要可达性预估，一个 Phase 兜六个问题必然出现映射漏洞）；且其任务 3 漏 null 校准（见上）。**修正方案：拆为伞形方案下的六个工作包，每包独立 execution.json 预注册。**

## 二、Omega 伞形方案（六个工作包）

统一纪律延续：execution.json 先冻结；判据可达性先检；任何"对齐/重叠/包含"主张配随机 null；结构（rho）/选拔（maxT）/功能（真实消融）三层分账；量级主张先过 norm/cos 分解 → 口径标签 → 子空间检查审计链。

### Ω-A 跨模块子空间对齐（零前向，最先做）
- **测量**：全 32 头 W_ov 输出子空间（2948 机器，SVD 取有效秩）vs 下游 MLP up-projection 行空间；逐层主角度谱。
- **判据（预注册）**：真实头对齐度 > 随机旋转头 null p95（1000 个随机头，2931 口径）；lin_r 分层报告（准线性层 vs 强非线性层）。
- **产出**：握手协议的几何登记物；对齐-不对齐头清单。

### Ω-B 多轴融合代数（注入机器现成）
- **设计**：三轴方向 = 语言 dir（2887 en/L 差）、词类 dir（F/C 差）、属性 dir（词对差，如大小）；2^3 因子单元（各轴 ±1）× 剂量格；响应 = C 张量逐格。
- **判据**：快照加法模型逐格残差（交互项存在性，maxT 族校正）× 消融差分复核（2950 双口径）；判决映射带"带状确认 + 耦合边界"分支（2933 教训）。
- **产出**：多轴融合代数定律（正交绑定 vs 干涉的边界条件）。

### Ω-C 长上下文调制
- **设计**：真实篇章上下文长度档 {2, 16, 64, 256, 1024}；读出三件套：s_c 漂移（2953 网格粗化）、A11 增益谱、B；**逐条件独立 batch**（2934 铁律）。
- **判据**：漂移曲线存在性 / 单调性 / 饱和性三检验分开预注册；同词跨长度配对置换。
- **产出**：流形漂移图谱（附件"引力场"的可操作版本）。

### Ω-D 逻辑/抽象深层签名（依赖 Ω-C）
- **设计**：连接词/因果词表（because、therefore、although、unless…）× 名词基线；F/C 机器扩维；在 Ω-C 的长度档上重复，测"逻辑聚合"是否随上下文出现。
- **产出**：抽象逻辑的深层带签名（或其缺失的如实登记）。

### Ω-E 竞争-滞后操作化（幻觉第一步）
- **设计**：与读出方向竞争的误导方向注入，剂量爬升→撤除→恢复；读出 dirs_word[35] 投影轨迹。
- **判据**：恢复残差 hysteresis 面积 > 0（配随机方向对照）；不可逆剂量阈值存在性。
- **产出**："错误吸引子"的操作化判据；达成本 Phase 之前禁止使用"相变/势垒"命名。

### Ω-F 跨模型卡片复制（方案 v2 阶段三并入）
- **设计**：第二模型（GLM4-9B 优先，已在本地模型库）跑同协议 34 卡复制；锚结构按新模型重建（a1 dirs 锚等）。
- **判据**：逐卡复制分级 = 复制 / 方向性复制 / 不复制；新原语候选单独登记。
- **产出**：机制的 Scaling Law 第一版（卡片级，不是口号级）。
