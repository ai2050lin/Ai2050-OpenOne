# 神经网络早就是干净的：完整通俗讲解 + 图谱障碍评估

**文档性质**：方法论解读与障碍评估，零 GPU，不占 Phase 编号。  
**对象**：Goodfire《Neural Networks Are Already Clean》(Nick Cammarata) 的操作过程。  
**配套**：技术口径见 `NEURON_POLE_ATLAS_METHOD_v1.md`；本文只管"讲明白 + 说清坑"。  
**状态**：文中数值为手算示例或经验建议值；标注"实测"的来自本地 config 读取，其余未执行验证。

---

## 0 一句话：这篇文章在干什么

模型里有一批"打分员"。qwen3-4b 有 **35 万个**（36 层 × 9728 个 MLP 通道）。每个打分员只看一件事、给一个分数。

- 有人问"这些打分员是不是各自管好几件不相干的事？"（这就是**多义性 polysemanticity**）
- 过去的答案是"是，因为维度不够，只能挤"（这就是 **superposition**）
- 这篇文章说：**不是挤，是我们以前看错了。** 大部分打分员其实只干一件事，只是我们没读懂它在挑什么。

所以全文的方法只有一个目标：**给每个打分员写一份准确的工作说明。**

下面六步就是这个"写说明"的流程。

---

## 1 第一步：让所有打分员把材料看一遍（采集）

### 人话

把几千段真实文本喂进去，记录每个打分员在**每一个字的位置**上给了多少分。

### 操作

跑一次前向，在指定层的 MLP 上挂两个钩子：

| 要记录的量      | 钩子位置                                | 形状          |
| ---------- | ----------------------------------- | ----------- |
| 门控原始分 `g`  | `mlp.gate_proj` 的 **输出**            | `[N, 9728]` |
| 当时的残差流 `h` | `post_attention_layernorm` 的 **输入** | `[N, 2560]` |

`N` = 文本段数 × 每段 token 数。

### 计算

打分员的分数就是一次加权求和：

```
g_j = W_gate[j, :] · x + b_j
```

`W_gate[j,:]` 是这个打分员的**权重行**（2560 个数），`x` 是当前残差流经过归一化后的值。

### 参数

| 参数   | 建议值                | 依据                                    |
| ---- | ------------------ | ------------------------------------- |
| 语料段数 | 1000–5000 段        | 要保证后面 k 个极值样本至少来自 k/5 段不同文本           |
| 单段长度 | 128–512 token      | **不能太短**：只给两段会让所有长上下文打分员看起来"多义"（原文教训） |
| 采集层  | 全部层                | 一次前向全采，比按需重跑省得多                       |
| 精度   | bf16 存储、float32 计算 | 累加要在 fp32，否则 9728 维求和会掉精度             |

### 这一步最容易犯的错

- **在 `mlp` 的输入上取残差流** → 拿到的是归一化之后的值，每个位置缩放不同，后面算出的轴带位置伪影。
- **只读 `g` 的激活后值** → SwiGLU 里真正的输出是 `silu(g) × u`，是个**乘积**。两个负数相乘得正，会把"门关着"看成"开得很足"。极性必须读 `g`。

---

## 2 第二步：决定先给谁写说明（排序）

### 人话

35 万个打分员，不可能都先写。先挑**最容易读懂**的那些——也就是"给分最集中"的那些。

怎么知道集中？看它给最高分的那批材料，彼此像不像。

### 计算

取每个打分员的 top-k（比如 k=100）个位置，算这些位置的残差流两两之间的平均余弦相似度：

```
coh_j = mean over pairs (a, b) in top-k of  cos(h_a, h_b)
```

- `coh` 高 → 这 100 个位置的状态长得很像 → 它抓的是同一件事
- `coh` 低 → 要么它真在管好几件事，要么你的语料不够宽

### 参数

| 参数         | 建议值     | 说明                  |
| ---------- | ------- | ------------------- |
| k（算 coh 用） | 50–100  | 与第三步的 k 可以不同        |
| 优先读 coh    | > 0.6   | 最可能一次读懂             |
| 可读         | 0.3–0.6 | 注意是否两个子群混杂          |
| 先别读        | < 0.3   | **先怀疑语料覆盖不足**，再怀疑多义 |

### 为什么这一步文章里没有

作者是"闲逛"遇到的（同事发现 Colorado 神经元）。工程上不能靠闲逛，所以必须补这个排序。**这是原文的空白，不是本文的发明。**

---

## 3 第三步：问它"最喜欢什么""最讨厌什么"（读两极）

### 人话

对某个打分员，把它给分**最高**的 100 段材料摆出来，再把它给分**最低**的 100 段材料摆出来。两边一起看。

### 计算

```
P = top-k   { g_j }        # 正极：100 个位置地址
N = bottom-k{ g_j }        # 负极：100 个位置地址
```

注意 P 和 N 不是向量，是**地址簿**——每一条记着"第几段文本、第几个字"。

### 参数

| 参数   | 建议值               | 依据                                  |
| ---- | ----------------- | ----------------------------------- |
| k    | 50–200            | <20 时采样噪声主导；>1% 总位置时会混进"中等分"样本，把轴稀释 |
| 去重要求 | k 个样本来自 ≥ k/5 段文本 | 同一段里相邻字的 h 高度相关，否则方差被低估             |

### 验收标准

必须打出**真实文本片段**，不是数字摘要。看到这张表，"两极"才从符号变成能检验的东西：

```
正极  1  +4.82   ...他把苹果削了皮，切成小块...
      2  +4.51   ...果园里的苹果熟了，压弯枝头...
负极  1  −5.13   ...分析师上调苹果目标价...
```

## 4 第四步：算"喜欢"和"讨厌"的平均差异（Δ）

### 人话

把正极那 100 个位置的内部状态取平均，把负极那 100 个也取平均，然后相减。

**这个差，就是它在挑什么。**

### 计算

```
Δ = mean(h[P]) − mean(h[N])        # 一个 2560 维向量
```

### 为什么这个减法有效（数学根据）

如果残差流近似高斯分布，`z = w·h`，那么条件期望是线性的：

```
E[h | z] = μ + Σw · (z − w·μ) / (w·Σw)
```

两边极值相减，得到：

```
Δ = c · Σw      (c > 0)
```

也就是说：**Δ 就是被协方差矩阵"拉歪"的权重方向。** 白化一下就还原成真正的权重：

```
Σ⁻¹Δ ∝ w        ← 这正是 Fisher / LDA 判别方向
```

这解释了三个现象：

1. 为什么 Δ 和真实权重**方向一致但数值不可比**（差的正是 Σ）；
2. 为什么跨族比较必须**白化**（各族 Σ 不同，不白化 cos 会被 Σ 污染）；
3. 为什么说这套方法的数学本质就是"判别分析"——它不新，新的是**用真实语料的极值样本当两个类**，而不是用人工标注。

## 5 第五步：用四种方式验证你的猜测（四路检验）

### 人话

Δ 算出来永远是有的，**哪怕是纯噪声也有**。所以必须证明它不是假的。四条互不相关的路，任何一条不通就退回重猜。

### 四路与参数

| 路            | 怎么做                     | 参数                   | 失败含义        |
| ------------ | ----------------------- | -------------------- | ----------- |
| ① logit lens | 把 Δ 乘输出层权重，看两端是什么词      | 取 top/bottom 20–30 词 | Δ 落在没语义的子空间 |
| ② steering   | 给残差流加上 α·Δ̂，看模型写什么      | α 从 0.5 扫到 4（相对残差分量） | 几何在，行为不控    |
| ③ 对偶检验       | 正极是 A，负极必须是**同一根轴的另一端** | 人工判定                 | 是混合物，不是轴    |
| ④ 定向测例       | 造只在这件事上不同的最小对           | 人工设计                 | 描述错了        |

**第③路是最狠的一路，也是唯一能"杀掉"假设的一路。** 正极只能提出假设（任何一堆材料你都能编个故事）；负极才是否证——如果负极那 100 条找不到共同点，说明你猜的那个"共同点"根本不存在。

### logit lens 的模型差异（实测）

| 模型        | tie_word_embeddings | 该乘哪个矩阵                 |
| --------- | ------------------- | ---------------------- |
| qwen3-4b  | **True**            | embed 与 lm_head 同矩阵，等价 |
| Qwen3-14B | False               | 必须 `lm_head.weight`    |
| glm4-9b   | False               | 必须 `lm_head.weight`    |

用错不报错，只会给你一个语义不通的词表——静默错误。

## 6 第六步：写进手册，和别的手册互相印证（归族）

### 人话

一个打分员的说明写好了，看它和别的打分员是不是在管同一类事。是的话归成一族。族越多，后面的越好写——因为族给了你先验。

### 计算

```
cos(Δ_a, Δ_b)     # 两条轴的角度
```

| cos     | 含义            |
| ------- | ------------- |
| > 0.7   | 同轴，可能同族       |
| 0.3–0.7 | 相关但不完全同       |
| < 0.3   | 不同族，或被层间变换旋转了 |

**跨层陷阱**：残差流各层共享同一空间，但同一功能隔了多层的可能被旋转。所以跨层比 cos 只在**相邻层**可信。

### 手册一格长什么样

| 字段       | 例                    |
| -------- | -------------------- |
| 编号       | L18.N2047            |
| 一句话      | 在区分「水果义」与「公司义」       |
| 正极摘要     | 削皮 / 果园 / 压弯枝头       |
| 负极摘要     | 发布会 / 市值 / 目标价       |
| 方向指纹     | Δ 的 sha8（便于复现）       |
| 两端词表     | logit lens 各 10 词    |
| steering | α=2 时开始写果园，α=−2 时写股价 |
| 同族       | L17.N881（cos 0.81）   |
| 证据级      | E1（留出语料复现）           |

## 7 一个从头的数字例子

### 设定

4 维玩具（真实模型是 2560 维，这里只为能手算）：  
权重 `w = [+2.0, +1.5, −2.0, +0.5]`，偏置 `b = −1.0`  
维度含义：尖角 / 直边 / 圆形 / 纹理

`z = 2x₁ + 1.5x₂ − 2x₃ + 0.5x₄ − 1`

### 六个样本

| 样本     | x₁  | x₂  | x₃  | x₄  | **z**     |
| ------ | --- | --- | --- | --- | --------- |
| A 狐狸脸  | 2.0 | 1.0 | 0.0 | 1.0 | **+5.00** |
| F 汽车正面 | 1.5 | 1.8 | 0.2 | 0.5 | **+4.55** |
| D 火焰   | 1.8 | 0.5 | 0.1 | 1.0 | **+3.65** |
| E 网球   | 0   | 0   | 2.2 | 1.0 | **−4.90** |
| C 时钟   | 0   | 0   | 2.5 | 0.2 | **−5.90** |
| B 蜗牛   | 0   | 0   | 3.0 | 1.0 | **−6.50** |

### 分极（k=3）

P = {狐狸脸, 汽车正面, 火焰}，N = {蜗牛, 时钟, 网球}

### 算 Δ

| 维度 | P 均值  | N 均值  | Δ          | 符号 |
| -- | ----- | ----- | ---------- | -- |
| 尖角 | 1.767 | 0     | **+1.767** | +  |
| 直边 | 1.100 | 0     | **+1.100** | +  |
| 圆形 | 0.100 | 2.567 | **−2.467** | −  |
| 纹理 | 0.833 | 0.733 | **+0.100** | +  |

**四个符号全对**，且强弱排序也对（纹理确实最弱）。

### 两个检验

方向一致性：`cos(Δ, w) = 10.167 / (3.229 × 3.240) = 0.972`  
可分性：用 Δ 做投影，6 个样本符号全对（6/6）

**结论：这个打分员是单义的，它在区分"尖"与"圆"。** 这就是原文推翻的那个名案 `4e:55`（长期被误标为"猫/汽车多义"）。

## 8 完成整张图谱的障碍

分三类：能解的、要新工具的、可能根本解不了的。**后者才是真问题。**

### A 类：工程障碍（算力/工时可解）

| 障碍      | 量级                                                   | 出路               |
| ------- | ---------------------------------------------------- | ---------------- |
| 人工读不完   | qwen3-4b 有 35 万通道；即使每个 3 分钟（极度乐观）≈ 8.7 人年/模型         | 自动解释 + 人只审关键格    |
| 存储      | 全层全位置 h 存不下；1000 段 × 200 token × 2560 × 36 层 ≈ 数十 GB | 只存需要的层 + fp16    |
| 自动解释不可信 | LLM 生成的描述"合理" ≠ "正确"（原文里 Colorado 被自动工具标成"多义逗号"）     | 自动描述只做候选，四路检验不可省 |

**A 类的核心问题不是算力，是"合理 ≠ 正确"。** 自动工具会给你 35 万条都读得通的描述，而其中大部分你没法逐一验证。

### B 类：方法障碍（需要新工具/新指标）

| 障碍            | 具体表现                                                    |
| ------------- | ------------------------------------------------------- |
| **没有语料无关的描述** | "这个通道是 X"依赖你喂的语料。换分布 → P/N 变 → Δ 变。原文所有结论都隐含"在我看的这批数据上" |
| **通道数 ≠ 概念数** | 读懂 35 万格不等于理解网络。概念如何跨通道聚合，原文没给方法                        |
| **组合层缺失**     | 单通道全读懂，也不等于读懂电路。通道之间的"边"（什么条件下共同作用）数量爆炸                 |
| **无客观判据**     | 命名靠人。"尖角检测"和"非圆形检测"可能都对，无法判定哪个更对                        |
| **进度不可度量**    | 原文用"填字游戏"比喻复利，但**没有曲线**。填满 10% 和 50% 有什么区别，没人量过         |

**B 类里最致命的是"进度不可度量"。** AGENTS.md §5.4 要求"谱图预测保真度"作为可度量的破解程度——这正是原文缺的那一环。没有它，"地图填了一半"就只是个感觉。

### C 类：理论障碍（可能无解，必须先想清）

**① "already clean" 不可证伪。**  
他主张多义是工具问题。但若某个通道修好工具后仍然多义，他可以说"工具还没修好"。这个结构无法被数据推翻。  
→ **必须在事前预注册判据**：什么情况下承认"这真的是多义"。否则这条主张不是科学命题。

**② 复利假设没有验证。**  
整套方法的速度优势建立在"理解会互相约束"上。如果每个通道实际上彼此独立，复利就不存在，35 万格就是 35 万个独立任务。  
→ 复利是可测的：画出"已读格数 → 读懂下一格所需时间"的曲线。**原文没有这条曲线，只有主观感受。**

**③ 单通道视角可能错过真正的结构。**  
如果语言能力主要由**方向**（跨通道的线性组合）承载，而不是由单个通道承载，那么逐个读通道就像逐个读像素——读完了仍然不知道画的是什么。  
我们自己线上的证据已经在指向这个方向：3255 的双轨道几何、3253 的中层低谷（载轴衰减而非替换）都表明"轴"比"通道"更基本。  
→ **这条是最大的风险：方法可能选错了基本单位。**

## 9 结论：这篇文章该怎么用

**该拿的：**

- "正极提假设、负极杀假设"这条否证规则——这是全文最硬的东西，可直接用。
- "读 g 不读 a"、"不许用优化洗数据"、"先怀疑语料覆盖"三条纪律。
- "填图有复利"作为工作假设（不是结论）。

**不该拿的：**

- "神经网络已经是干净的"这个结论。它是 working hypothesis，而且不可证伪。
- "理解整体比理解局部容易"。这是他的主观体验，不是测过的规律。

**我们项目该怎么接：**  
把"通道"当**入口**而不是**单位**。通道给出可枚举的、有编号的抓手（这是它唯一不可替代的价值）；但真正要建的是**方向层的图谱**，通道是采样点，Δ 才是节点。  
这样即便 C③ 成立（轴比通道基本），这套流程也不是白做——它变成了"用通道采样方向"的手段，而不是目的。

## 10 参数速查

| 参数              | 建议值               | 影响            |
| --------------- | ----------------- | ------------- |
| 语料段数            | 1000–5000         | 太少 → 伪造多义     |
| 单段长度            | 128–512           | 太短 → 长上下文通道失真 |
| 采集层             | 全部                | 一次前向，省重跑      |
| 读的层             | L/2 ~ 3L/4        | 太浅是词汇，太深是输出准备 |
| k（极值样本）         | 50–200            | 太小噪声，太大稀释     |
| 文本去重            | 样本覆盖 ≥ k/5 段      | 防方差低估         |
| coh 阈值          | > 0.3 可读，> 0.6 优先 | 视觉经验，语言需重定    |
| steering α      | 0.5–4（相对分量）       | 太小无效应，太大失真    |
| logit lens topn | 20–30             | 太多混入噪声词       |
| 同族 cos          | > 0.7             | 仅相邻层可信        |
