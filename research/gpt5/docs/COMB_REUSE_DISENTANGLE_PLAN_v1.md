## 1. 用户假设的数学形式化（"球-组合"模型）

用户的假设可严格化为一个**稀疏组合编码 + 条件化调度**模型：

### 1.1 基与概念
- 存在候选机制单元集（"球"）B = {U_1, …, U_k}，k 量级待测（用户猜想 ~100 量级；本项目证据指向 k 为几十到几百、每个 U_i 是**秩 r_i ≈ 1–8 的子空间**而非单坐标——F20/F21 已否证单坐标/单方向承载）。
- 概念 c（名词/属性/关系）↔ 幅度向量 a_c ∈ R^k：a_c[i] = h_c 在 U_i 上的投影幅度（或带符号投影）。
- "选 70–100 个球" ⇒ 可测对象：a_c 的**支撑集**大小分布与幅度分布。注意 70–100/100 接近满支撑，此时编码信息主要在**幅度**而非 0/1 支撑上——这恰好与 2768"知识 = 公共坐标幅度放大 1.6–2.9×，非独立坐标组"一致。两种变体都要测：
  - V1（支撑编码）：a_c 稀疏，支撑集承载类别信息；
  - V2（幅度编码）：a_c 近满支撑，幅度谱承载语义，支撑只承载"参与哪些机制"。

### 1.2 复用
- 定义复用度 reuse(c,d) = Σ_i w_i · |a_c[i] · a_d[i]| / (‖a_c‖‖a_d‖)（加权重叠；w_i 为机制权重，可用因果承重/复用度/跨模型普适三判据校准——即 3238(a) hub 排序判据）。
- 预测：reuse(苹果,香蕉) > reuse(水果,食物) 的近邻结构 > reuse(天体,食物)。该预测把**外部语言族图谱的边（isa/hasa/属性/类别）与内部复用矩阵 R = f(A Aᵀ) 直接对齐**，可定量检验（秩相关 + 按类别置换零分布）。

### 1.3 变化与组合
- 上下文条件 g（语言 zh/en、句式、肯定/否定、逻辑角色）通过**门控**作用于幅度：a_c^{(L+1)} = T_L( a_c^{(L)} ; g )，T_L 为第 L 层条件化转移算子；attention 的作用即实现/选择 g（3160 "attention 再分配主执行"是该论断已有的证据回声）。
- 翻译 = 映射 φ: a_c^{(zh)} ↦ a_c^{(en)}，假设为**支撑保持、幅度/方向重映射**（若 φ 接近"逐坐标幅度变换 + 少量支撑交换"，则"翻译=组合映射"成立；可用最优传输在 A^{zh} 与 A^{en} 之间拟合 φ 并检验其结构秩）。

### 1.4 多维信息拆分
- 假设（有先例）：不同条件维度占据**近正交子空间**（2751 已证监督语义间近正交且跨模型复现）。故"混合编码拆分"= 找到一组近正交分解 U = U_content ⊕ U_language ⊕ U_syntax ⊕ U_logic（近似），并逐块做因果验证。

## 3. 可行方案（五阶段，全部映射到现有资产与协议）

### 阶段 A：基普查与"球"清单（零 GPU，≈已预注册的 3238(a)）
- 输入：26 个封存特征 + 3169/3225/3234 封存 npz。
- 步骤：对每个特征的封存行态矩阵测内在维度/子空间秩（participation ratio + 稳定秩 + 谱衰减拐点）；跨特征求两两子空间主角度 → 得到**近重叠/复用对**；按复用度、因果承重、跨模型普适三判据出 hub 排序。
- 输出：候选"球"清单 U（k 个载体子空间，含秩与 hub 等级）→ registry v1.33。
- 这是"球"模型的第一次直接清点：**k 是多少、秩分布如何、复用是否集中于少数 hub**，一次回答。

### 阶段 B：名词×属性复用矩阵普查（GPU，中大规模；核心新数据）
- 材料：≥1000 名词，覆盖 ≥10 个语义类（水果/食物/天体/动物/工具/乐器/…）× ≥6 种关系（isa/hasa/颜色/大小/重量/用途）× ≥3 模版（陈述/问句/语境句，中英双语）。用 `shared/dist_protocol` 生成式文法 + 确定性切分 discovery/confirm/lockbox + 行为门 + design_sha 预注册（协议纪律 1–6 全套）。规模 ≈ 1000×6×3×2 ≈ 3.6 万行/模型，qwen3-4b→14b→glm4-9b 串行（显存纪律）。
- 步骤：全层捕获 → 取阶段 A 的基 U → 每名词得幅度向量 a_c → 复用矩阵 R。
- 门（预注册）：
  - G-B1 类内复用 > 类间复用（效应量 + 按类别置换零分布，lockbox 名词上复现）；
  - G-B2 R 与外部图谱边类型的秩相关分层：isa/属性边应高于无关对（且 isa 与属性边在 R 上**可分**——不同关系类型不是同一种"复用"）；
  - G-B3 支撑/幅度两变体判别：V1 vs V2 哪个拟合更好（预注册两种计分，不许看结果后选）。
- 混杂控制：词频、token 长度、位置进入回归协变量；近重复家族（单复数/译名）标记防泄漏。

### 阶段 C：多维混合信息拆分（GPU，最小对设计）
- 材料：**最小对立面板**——同一内容 × {zh,en} × {陈述,问句} × {肯定,否定} × {逻辑保持/反转}，内容不变、单条件翻转；每格 ≥500 行。
- 步骤：
  1. 对每个条件标签在基坐标上训线性探针，得各维度的候选方向/子空间；
  2. **迭代投影移除**（INLP/RLACE 式）：移除语言方向后内容探针是否存活、反之亦然——正交性检验；
  3. **因果交叉验证**：把 A 句的"语言轴"子空间 patch 到 B 句（整子空间交换，非单方向），看输出语言是否切换而内容保持——拆分是否真实的判据；
  4. 翻译映射 φ 拟合：对齐名词在 zh/en 面板的幅度向量间做最优传输/回归，检验 φ 的结构秩（低秩 = 少数机制承载语言转换；"翻译=组合映射"的定量版本）。
- 门：拆分后各探针在 lockbox 上 AUC ≥ 预注册阈；patch 语言轴翻转输出语言率 ≥ 阈且内容探针位移 ≤ 阈（双向门，防"乱翻"）。

### 阶段 D：条件化转移算子 T_L 与组合预测（GPU/零 GPU 混合）
- 步骤：对每层拟合 a^{(L+1)} = T_L(a^{(L)}; g)（分段线性/低秩修正形式），discovery 拟合、held-out 组合上检验；**组合预测**：未见"概念×条件"组合的终态幅度由组件预测（lockbox 严格预注册）。
- 门：held-out 组合预测误差显著低于"无条件转移"与"线性外推"两个基线。
- 这是"条件齿轮组"从候选走向定量规律的一步。

### 阶段 E：整子空间因果收口（GPU，设计先行）
- DAS 式子空间交换/缩放（3238(c) 方向）：对阶段 B/C 找到的 hub 子空间做 swap、幅度缩放（norm-matched + 正交化对照），检验行为是否按复用模型预测变化。
- 判据沿用 F20/F21 教训：单方向 FAIL 不再重复；只做整子空间；FAIL 同样入 F 账本。

## 5. 硬伤与对照（诚实录）

1. **基不唯一**：字典/子空间基存在旋转自由度。对策：只用**不变量**做结论（秩、主角度、复用秩相关、因果承重），基的选取按跨模型+跨层稳定性正则化，并在 registry 记录基版本（3238(a) hub 三判据即此用途）。
2. **k 不得事后调**：k 的扫描网格与选择规则预注册；"球数 ~100"是待检验假设，不是前提。
3. **复用的混杂**：词频/长度/主题共现都可能制造 R 的块结构——回归协变量 + 伪词对照（2768 先例）+ lockbox 缺一不可。
4. **几何 ≠ 行为（F20）**：R 的强结构只是第一步声称；机制声称必须过阶段 E 的整子空间干预。
5. **支撑 vs 幅度的判别力**：若 V1/V2 在 G-B3 打平，须承认"70–100 球选择"的离散图景在末层近似失效，编码主体是连续幅度调度——这本身是重要结论而非失败。
6. **规模**：按用户纪律，每格样本量取大（≥500 行/格、≥1000 名词），避免小样本错误结论；三模型串行复现。
