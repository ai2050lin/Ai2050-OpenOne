## 三、文章遗漏的三个关键事实

1. **我们已经有"模型自己的稀疏特征"**：3149 T2 的载体 token 族经 3150 解码（见 PARADIGM_SHIFT_VERDICT_v1 附表 / phase3150 result.json）——NEG 侧=多语言词素碎片族（'ato'/' pneum'/'岸'/'وى'/'ędzy'+2×U+FFFD），POS 侧=文档骨架族（'http'/'bold'/'FunctionFlags'/'HostException'/'this'/'The'/'X'）。**SAE 的第一个检验对象不需要重新发明：检验 SAE 特征是否重新发现这两族**（G4.2）。
2. **端口替换纪律直接否决了文章隐含的干预想象**：文章未意识到"方向去除"在本文系统已被位级证据禁用（3148）——任何新路线的干预设计必须继承此约束。
3. **绑定二分（N1）**：文章不知道 is-a 类关系的层位归属取决于 `tie_word_embeddings`（6/6 模型确证）——任何跨模型的 TDA/SAE 层位比较必须先按绑定分组，否则层位对齐是伪问题。

## 四、修正版新路线预注册（并入 TESTPLAN v1 作为 G4/G5/G6）

### G4 — SAE 主线（采纳，3161+ 候选，前置=G1 完成）
- G4.1 采集器 + L17 单层 SAE（dictionary_learning 优先，d_sae=65536，在线流式训练，1B token 预算的 30-50%）
- G4.2 **特征-载体族对齐判决**（可能否证整条 G4 的实验）：SAE 特征空间中，POS 骨架族与 NEG 碎片族各自是否坍缩为少数高激活特征？判据：两族 token 的 SAE 特征激活分布的集中度（top-8 特征激活份额）≥0.5 → 通过；<0.3 → SAE 在本系统的特征假设降级。
- G4.3 特征级 circuit（写入头→特征→端口）
- **死线 K-G4**：G4.2 失败且 3 族行为预测无提升 → SAE 路线在本系统降级为描述工具。

### G5 — TDA 支线（大幅降级，仅 Mapper 等价类检验，零 GPU 预研可先行）
- 只做：State Bank 上 Mapper 图的连通结构与已知端口类标签的一致性（ARI）。
- **不做**：Betti 数/环面/流形维度断言（n<d 病态）。
- **死线 K-G5**：ARI<0.3 → 弃 Mapper 支线（判据：Mapper 若连已知的、位级复现的端口类都分不开，则其 lens 选择自由度过大，无信息）。

### G6 — 动力学支线（降级为逐层 Jacobian 谱，ODE 积分与李雅普诺夫指数禁做）
- 只做：逐层 vjp 算子范数谱 + 3148 交叉点的线性化稳定性分析（分岔重述）。
- 归 F2 判决分级：descriptive（不作下游前提）。

## 五、结论

文章问"研究应该继续吗"——**问错了对象**：该停的不是"研究"，而是"以单齿轮为目标的因果充分性主张"（3148/3149 已将其收窄为描述性共伴）。该提的不是"换船"，而是 TESTPLAN v1 已排好的航线 + 三个修正版新支线。

**执行决定**：Phase 3150 = P0 制度冻结（F1-F7）+ 载体 token 身份解码（零 GPU，本文档附表来源）+ (k,d) 等值线 + v1 阈值定位 + 三路线预注册。此后按排期进 G1。
