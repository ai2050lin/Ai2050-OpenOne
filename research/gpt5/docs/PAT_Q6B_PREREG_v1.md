# Q6-B 预注册：属性知识的秩与解耦 —— 「有限参数记无限属性」的可判决形式

日期：2026-11-01
上游：`PAT_Q6A_FINDINGS_20261101.md`（颜色 30/37 层、大小 33/37 层成立；F3–F4 仅 +0.081 ⇒ 载体是语义关系不是词性）
定位：Q6 家族第 3 轮（== 家族预算末轮）

## 0 这一测要回答的两个问题

owner 的核心断言（连续两轮提出）：
> 「上百万物体 × 颜色/大小/重量/用途，有限参数记不下，**必然有高效的复用机制**」
> 「破解的关键是画出各种模式的**整体图谱**，而不是局部特征」

这两句要变成可判决的量，需要各给一个数字：

| 问题 | 可判决形式 | 判据形态（D24 优先级：预测型 > 剖面型） |
|---|---|---|
| Q1 属性知识能否压缩到少数维度 | 物体 × 属性值矩阵的**秩**，且**留出物体**能预测 | 预测型（held-out R² vs 基线） |
| Q2 属性是否与具体物体**解耦** | 属性值向量在「物体类别子空间」里的**方差占比** | 剖面型（占比 vs 零分布） |

Q2 正是 owner 新提法「转折关系能和苹果解耦、又能稳定」的属性版：
如果一个模式（颜色）只是物体码的影子，它就**不可能跨物体复用**；若它与物体子空间近正交，才谈得上「独立的脉络」。

## 2 Q1：秩与留出预测

### 2.1 矩阵

`M[o, a] = log p(续写 | 物体 o, 属性值 a)`，28 × 12。
两个模板取平均，得 `M`；并单报每个模板的复现性。

### 2.2 分解

对每列（属性值）先减去该属性类型内的列均值（12 列 → 3 个类型，各自中心化），
得 `Mc`。这正是 Q6-A「先扣共同方向再取身份」的同一手法（D15）。

秩-R 近似：`Mc ≈ U_r S_r V_rᵀ`，R = 0..11。

### 2.3 留出（关键）

**按物体 5 折**（不留出属性值——属性值只有 12 个，留出会让秩退化）。
对每折：在训练物体上做 SVD，取前 R 个成分，用最小二乘把留出物体投影上去，
重建其 12 个格子，算 R²（对留出格子的方差归一）。

- 判据主量：`R* = 使 held-out R² ≥ 0.70 的最小 R`
- 基线：R = 0（只预测属性类型的均值）、以及 `M` 全量均值（常数预测）

### 2.4 Q1 判决（冻结）

| 判决 | 条件 |
|---|---|
| `ATTRIBUTE_SPACE_3D` | `R* ≤ 3`（= 属性类型的个数）且 held-out R² 在 R=3 时 ≥ 0.70 |
| `ATTRIBUTE_SPACE_COMPACT` | `4 ≤ R* ≤ 7` |
| `FULL_RANK` | `R* ≥ 8` 或 held-out R² 在 R=11 时仍 < 0.70 |
| `BEHAVIOUR_GATE_FAIL` | 见 §2.5 |

### 2.5 前置闸（R-MTH-17）：行为门

矩阵必须是真信号，不是噪声。检验：**8 个颜色探测物体**（苹果香蕉草雪煤天空葡萄橘子）
在 8 个颜色上的 argmax，是否等于人类常识颜色（红黄绿白黑蓝紫橙）。
- ≥ 6/8 命中 ⇒ 通过；4–5/8 ⇒ 降级（只报描述，不判决）；≤ 3/8 ⇒ `BEHAVIOUR_GATE_FAIL`。
- 同理检验大小：8 个物体（蚂蚁老鼠西瓜鲸鱼钉子蚊子老虎楼房）在 {大,小} 上的 argmax，
  常识为 小/小/大/大/小/小/大/大。

## 3 Q2：解耦

### 3.1 属性子空间 vs 物体子空间

在残差流（词跨度均值，与 Q6-A 同法）上，逐层构造：

- **物体子空间** `O_li`：28 个物体向量做 PCA，取前 **k=3** 个主成分（k 固定，不调）。
- **属性值向量** `a_j`（12 个）：各自在同一层的残差表示。
- **解耦度** `dec_li = 1 − Σ_j ‖proj_{O_li} a_j‖² / Σ_j ‖a_j − mean(a)‖²`

`dec` 高 = 属性向量基本落在物体子空间之外 = 解耦。

### 3.2 零分布（必须做，否则 dec 无法解读）

把 12 个属性值替换为**随机抽取的 12 个普通词**（从物体池 + 词表外常用词中抽，10 次重抽），
同样算 `dec`，得 `dec_null`。
- 主量：`dec − dec_null`。

（这条是为了防「任意 12 个词的向量都落在 28 个物体 PCA 的补空间里」这一平凡解释——
28 个成分在 2560 维里只占极小体积，`dec` 天然接近 1。）

### 3.3 Q2 判决（冻结）

- `DECOUPLED`：`dec − dec_null ≥ 0.15` 的层占比 ≥ 0.30
- `COUPLED`：`dec − dec_null ≤ −0.15` 的层占比 ≥ 0.30
- `NOT_SEPARABLE`：其余（含 `|diff| < 0.15` 全层）——**这等同于说「属性向量与普通词向量无法区分」**

## 5 不声称的东西

- `M` 是**行为量**（log-prob），秩是**行为矩阵的秩**，不等于「参数被压缩成 R 个」。
  可以说「行为上等价于 R 维」，不能说「模型内部只存了 R 个数」。
- 只 Qwen3-4B、12 个属性值、28 个物体；`R*` 依赖属性值的选择，不可外推到「所有属性」。
- 无干预、无跨模型 ⇒ 最高 E1。

## 6 跑前修订（写脚本时发现，§1–§5 判据不改，本节 append-only）

### 6.1 缺陷一：§2.2 的中心化口径会让结论自动成立

§2.2 只写「按属性类型中心化」。但 `M[o,a]` 是一个二因素表：

```
M[o,a] = μ + row_o + col_a + interaction[o,a]
```

- `row_o`：物体 o 的整体续写流畅度（对 12 个属性值**一视同仁**）——**不携带任何属性知识**；
- `col_a`：属性值的全局常见度（红/大比紫/冷常见）——**也不是物体知识**；
- `interaction`：o 与 a 的特定关联 —— **这才是「属性知识」**。

若只扣列均值，`row_o` 会独占绝大部分方差，**秩 1 就能解释九成**，`R* = 1`，
于是 `ATTRIBUTE_SPACE_3D`（`R* ≤ 3`）**必然成立且毫无信息量**——判据自动通过，测的是"物体有各自的口头禅"。

- **修法**：主判量改为**双中心化后的 interaction 矩阵**（扣 row 与 col 主效应），
  并把**原始矩阵的秩**作为对照一并报出（不参与判决）。
  这与 D15「先扣共同方向再取身份」是同一条纪律的矩阵版。

### 6.2 缺陷二：留出方式必须是「留出格子」而不是「留出物体」

§2.3 原本写「按物体 5 折」。但留出一个物体后，**该物体的 `row_o` 完全不可知**
（它所有 12 个格子都被留出），预测在信息上不可能——这会得到一个恒为负的 R²，
测的是冷启动问题，不是压缩率。

- **修法**：改为**按格子 5 折**（每折留出 20% 的格子，按属性类型分层），
  用软阈值迭代 SVD 补全（main effects + rank-R 残差，25 轮），
  在留出格子上算 R²。这才是「矩阵可压缩到几维」的正确问法。
- 同时报**打乱格子后的零分布**（同一管线），确认管线本身不会凭空产生 R²。

### 6.3 修订后的 Q1 判据（取代 §2.4，跑前冻结）

| 判决 | 条件 |
|---|---|
| `BEHAVIOUR_GATE_FAIL` | 颜色门 ≤3/8 或大小门 ≤3/8 |
| `ATTRIBUTE_SPACE_3D` | `R* ≤ 3` 且 `R²(R=3) ≥ 0.70` 且 `R²(R=3) − R²(R=0) ≥ 0.15` |
| `ATTRIBUTE_SPACE_COMPACT` | `4 ≤ R* ≤ 7` |
| `FULL_RANK` | `R* ≥ 8`，或 `R²(R=11) < 0.70` |

`R* = min{R : R²(R) ≥ 0.70}`；第三行 `R²(R=3) − R²(R=0) ≥ 0.15` 是防「主效应已经够、秩没贡献」的闸。

### 6.4 缺陷三（致命）：续写打分口径错，测量在测别的东西

§1.3 写「teacher-forcing 求续写总 log-prob」。实测分词形态：

```
'「苹果」通常是红色的。'  →  [... '通常是'(64,67), '红色'(67,69), ...]
'「苹果」通常很大。'      →  [... '通常'(64,66), '很大'(66,68), '。'(68,69), ...]
```

两处立刻失效：

- **颜色**：`红色` 被并成**一个 token** ⇒ 测的是「红色」这个整词的概率，不是「红」
  （各颜色都是两字词尾，尚可比较，但已不是我们要的量）。
- **大小**：`很大` 是一个 token，起点 **66 < 续写起点 67** ⇒ 该 token **被排除**，
  于是 `大` 与 `小` 的差别**只通过 `p(。|很大)` vs `p(。|很小)` 这一点间接项传播**。
  实测大小门 **0/8**（系统性反转），正是"没测"的指纹。

- **修法（口径改为单 token 条件概率）**：

  ```
  M[o, a] = log softmax( logits[前缀末位] )[ id(a) ]
  前缀 = '「{O}」通常是' / '「{O}」通常很' / '「{O}」摸起来是'
  ```

  12 个属性值都是**单 token**（已验），所以「下一个 token 是 a 的概率」良定义，
  且**一次前向同时读出该属性类型的全部候选**（颜色 8 个、大小 2 个、温度 2 个）。
  前向次数从 672 降到 84，且每个格子与其它格子共用同一前缀 ⇒ 消除了模板内差异。

- 顺带修正：行为门放宽为 **≥5/8**（颜色真值表本身有争议：葡萄可绿可紫、橘子偏红），
  但**必须同时报两个新前置条件**（见 §6.5）。

### 6.5 新增两个前置条件（取代 §2.5 的单一行为门）

`≥5/8` 仍是在测**我的标注**。真正决定矩阵能否做秩分析的是「测量是否可靠」：

| 前置条件 | 定义 | 阈值 |
|---|---|---|
| **C1 标签一致** | 颜色 argmax = 常识色 | ≥5/8，且大小 ≥6/8 |
| **C2 模板一致** | 同一物体在**两个模板**下的 8 维颜色剖面，Spearman 相关中位 | ≥0.50 |
| **C3 对比度** | 每个物体属性类型内的 (max−min) log-prob 中位 | ≥1.0 nat |

三条全过才做 Q1 判决；C2/C3 任一不过 ⇒ `MEASUREMENT_UNRELIABLE`，**不判**。

### 6.6 Q1 判决表补充一档（取代 §6.3 的 `FULL_RANK` 二分）

`R²(11) < 0.70` 与「需要很多维」是两件事，不能合并：

| 判决 | 条件 |
|---|---|
| `NO_LOW_RANK_STRUCTURE` | `argmax_R R²(R) = 0`（加秩从不改善）或 `R²(R=11) < 0.70` |
| `FULL_RANK` | 只有 `R* ≥ 8` 且 `R²(11) ≥ 0.70` |

前者说的是「interaction 不可由其它格子外推」，后者说的是「需要很多维但可外推」。**性质完全不同。**

### 6.7 Q2 的零分布混杂（§3.2 修）

§3.2 原本从「物体池 + 词表外常用词」抽 12 个词作零分布。但物体子空间正是由物体构造的，
从物体池抽词会让 `dec_null` **系统性偏低** ⇒ `diff` **系统性偏高**，Q2 会假性 `DECOUPLED`。

- **修法**：零分布改用 **24 个常见单字形容词**（美丑快慢高矮新旧轻重软硬甜苦香臭远近亮暗干湿厚薄），
  **与属性值同词性、同字长**，但不属于被测的 12 个属性值。
  这样 `diff` 测的是「属性值 vs 同词性普通形容词」的差别，而不是「实词 vs 物体」。
