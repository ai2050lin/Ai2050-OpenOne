## 0. 三版方案的关系：不是三个方案，是一个假设栈的三层

| 层 | 问题 | 对应版本 | 核心对象 |
|---|---|---|---|
| L1 基底层 | "球"是什么、稠密还是稀疏 | v1（球-组合） | 字典/子空间基底 B，幅度码 a_c |
| L2 因子层 | 状态里有几类编码、是否可分 | v2（多因子+路由） | 概念/语言/语法/逻辑/任务五因子子空间，路由表 B、搬运表 M |
| L3 组合动力学层 | 因子怎样组合、怎样拆开 | v3（纠缠/解纠缠） | 交互项 E1–E6、纠缠者/解纠缠者部件、按需解纠缠 |

**统一工作假说 H\***（一个句子版本）：
**状态是五因子幅度码在待定基底上的叠加 + 低秩交互项（纠缠）；复用通过跨因子共享方向实现，纠缠是复用的代价；解纠缠不是普遍属性而是按需操作——上下文线索（任务/语言/逻辑）在需要的层、需要的位置，由特定部件（注意力头/MLP）把被请求的因子投影成可独立读出、可独立干预的分量；注意力 = 特征级稀疏双线性路由（B 表）+ 迁移（M 表）；行为承载分布式（F20/F21），故一切机制声称最终必须过"选择性干预"门。**

反假说 R（必须同时检验）：编码近似加性可分，"纠缠"只是测量伪迹——若全部纠缠指标在零分布内，H* 推翻，退回 v1/v2 的可分框架。

## 1. 统一形式化

### 1.1 幅度码与纠缠分解（合并 v1 H 与 v3 分解）
对读出位置 p、层 l 的状态 x，在基底 D = {d_f} 上：
x ≈ Σ_f a_f d_f，并把幅度码按因子拆成主效应 + 交互：
x(θ_1,…,θ_m) = μ + Σ_k Δ_{θ_k} + Σ_{k<k'} I_{θ_k θ_{k'}} + ε
- I = 交互项即**纠缠的载体**；E1–E6 六指标全部作用在 I 上（见 §3）。
- 合取特征（v3 P18）= 交互项在字典基底下的稀疏原子——L1 与 L3 在此对接。

### 1.2 路由与搬运（v2）
特征层面展开注意力：路由表 B^h_{fg} = d_fᵀ W_QK^h d_g（谁看谁），搬运表 M^h_{gf'} = d_{f'}ᵀ W_OV^h d_g（看到后写什么）。
预测：B、M 稀疏且按因子分块；"提升某类编码权重" = 路由增益（α 偏向带目标特征的位置）+ 写入增益（头/MLP 放大目标因子幅度）。

### 1.3 三基底锚定（基底不唯一，用不变量下结论）
- S1 原生坐标（基线）；S2 模板对照方向（analysis.v1 / atlas.v1 现成）；S3 字典特征（SAE / transcoder，主路线，后置到阶段 4）。
- **基底竞赛判据（预注册）**：哪种基底使 P1–P4 与 E1–E5 结构最清晰（效应量最大）且描述长度（MDL）最短，哪种就更接近模型真实使用的"球"。旋转自由度 ⇒ 结论只用不变量（秩、主角度、交互能量、因果承重、跨模型稳定性）。

## 3. 统一算法管线：在哪 → 由谁 → 何时 → 怎样 → 是否因果

1. **在哪（纠缠谱）**：完全交叉因子化材料，逐层 × 逐读出位置 × 逐因子对算 E1（交互能量比，函数型 ANOVA/Hoeffding）、E2（交互张量奇异熵/有效秩）、E3（因子子空间主角度共享度）、E4（条件旋转）、E5（读出干扰）、E6（偏信息分解，可选）；DCI 与最小差异秩为解纠缠指标。零分布 = 按词整体 + 句式整体置换。
2. **由谁（部件归因）**：对每层每部件（头输出、MLP 输出）单独做方差分解，按"写入交互项能量 / 抵消已有交互能量 + 写任务对齐单项"排出纠缠者与解纠缠者清单。采集：全层 HiddenState + 选定读出位置逐头注意力行 + 逐头输出（o_proj 前）+ MLP 输出。**存储纪律**：逐头输出 36 层×32 头×128 维 ≈ 0.29 MB/token，全量数千条×40 token ≈ 20–30 GB——只存选定层或在采集时流式聚合成方差分解充分统计量（协议 suffstats 口径），原始头输出按层落盘本地（AI2050_NATIVE_DIR 先例）。
3. **何时（条件比较）**：有/无任务线索对照（P15）；相似概念对最小差异秩（P16）；多义词分化层位（P5）。
4. **怎样（特征机制）**：字典基底找合取/纯特征（P18）；B/M 表找跨因子项（注意力产生纠缠的方式）；MLP 神经元"与"操作（MLP 产生纠缠的方式）；门控/投影头（解纠缠方式）。
5. **是否因果**：预注册消融、注意力行 patching、整子空间 steering/交换（"英文−中文"差量、颜色差量）；判据 = 选择性（只动目标因子）。**F20/F21 铁律：不接受单方向 patch 作为机制证据；单方向 FAIL 不再重跑。**

## 5. 分阶段方案（七段；每段五段式预注册，段间门为晋级依据）

### 阶段 0：零 GPU 先行（两支合一，≈3238(a) 扩展）
- (a) 基底普查：26 封存特征内在维度/子空间秩 + 两两主角度（E3 首谱）+ hub 三判据排序 → registry v1.33；
- (b) **封存数据上的纠缠首谱**：3154 面板本就带六因子 tags、3169 带 730 行 t=0——直接在其封存缓存上算 E1/E2/E4（实体×类别×模版×语言可交叉的子集），得到第一张纠缠谱曲线与零分布。
- 晋级依据：纠缠首谱出现任一显著事件（或反假说 R 获得多点支持 ⇒ 方案降级为可分框架）。成本：零 GPU，1–2 个 Phase。

### 阶段 1：因子化小范围采集 + 纠缠谱第一全谱（GPU ~1–2 周墙上时间）
- 材料：200–500 名词（分层级+属性标注）× 语言(中/英) × 逻辑(否定/疑问) × 任务线索(问颜色/问大小/问类别)，完全交叉、行为门、按名词整体切 discovery/confirm/lockbox，生成式文法走 dist_protocol（因果可见性检查、canary、design_sha）。
- 采集：全层 + 逐头注意力 + 流式头输出/MLP 充分统计量；qwen3-4b → 14b → glm4-9b 串行（显存纪律）。
- 检验：P8'/P1/P5/P11/P12 + 稠密 vs 稀疏判定（V1 支撑编码 vs V2 幅度编码，预注册两种计分）。
- 晋级依据：≥1 对因子出现可复现纠缠/解纠缠事件（或 R 成立）；P1 优于 cos+词频基线（或明确否定）。

### 阶段 2：部件归因 + 路由结构（GPU）
- 纠缠者/解纠缠者清单（P17）；原生坐标与对照方向基底下的 B/M 表稀疏度与分块（P10）；增益归因（P11 完成机制定位）。
- 晋级依据：归因集中度显著超均匀零分布；B/M 稀疏或分块超随机基线。

### 阶段 3：按需解纠缠与跨语言映射（GPU）
- 有/无线索对照（P15）、最小差异秩（P16）、逻辑算子组合（P14）、中英平行集映射与差量迁移（P6/P9 观察级）。
- 晋级依据：线索调制可复现且位置/层可预测。

### 阶段 4：字典基底竞赛（GPU，中成本）
- qwen3-1.7B（或 4b 的 3–4 个代表层）训 SAE/transcoder；在字典基底重跑 P1–P4、P8'、P10、P18；基底竞赛判据裁决 S1/S2/S3。
- 晋级依据：合取特征解释可观比例的交互能量；字典基底 MDL 更短。

### 阶段 5：选择性因果收口（GPU，设计先行）
- 干预纠缠者/解纠缠者（P19）、特征子集替换（P7）、语言差量 steering（P9）、因子头消融（P13）。全部整子空间/部件级 + norm-matched 与正交化对照。
- 晋级依据：干预具选择性；FAIL 入 F 账本（延续 F20/F21 taxonomy）。

### 阶段 6：数学模型与预测保真度
- 拟合"主效应 + r 纠缠模式 + 门控投影"模型；未见组合预测 vs 双基线；写 gap/registry 定谳与三图谱对接。

## 6. 纪律、混杂与风险（继承已确立条款）

1. 行为门先行：行为不过的条件格不进内部分析、不作机制正例；
2. 置换按词整体 + 句式整体；token 身份折扣；句长/位置协变量；近重复家族标记（翻译对、单复数）；
3. E1 交互能量易被不平衡格子与噪声放大——完全交叉平衡设计 + 零分布 + 长度控制（KN/GR 系列既有教训）；
4. 注意力权重高 ≠ 信息被使用：必须看搬运表与因果段；单头消融无效不证无作用（冗余），归因先行再干预；
5. 几何纠缠 ≠ 行为使用（F20 回声）：O/F 级结论一律标注，M 级声称必须过阶段 5；
6. 跨模型不跨桶平均（同快照才合并）；跨线（claude/gpt5）跑同族材料时按 dist_protocol 合并规则（design_sha 一致、kind=real、canary 未漂移、分片只计一次）；
7. k、r、基底选择规则全部预注册，禁止看结果后调。
