## 0 一句话

你说「所有东西都是相对的，所以定位不到」——**这个现象我们有两个已实测的解释，你的解释是第三个。三者都能预测「定位失败」，但预测不同的几何。** 要跳出循环，不是再定位一次，而是**测它们预测不同的那个量**。

## 1 先把「为什么定位不到」拆成三个竞争解释

你说的是 C。但 A 和 B 已经有实测数字了。

| 解释 | 内容 | 已有证据 | 对「差异向量」的预测 |
|---|---|---|---|
| **A 冗余复制** | 同一信息在几十个头/神经元里各存一份，删任何一份都不坏 | Q5-A：k 曲线 1→0.638、4→0.909、16→0.995、32→1.000 单调无饱和；九轮消融 93% 头可删而零损伤 | 差异是**各向同性噪声** → 同关系内的 Δ 互不共线，within ≈ across ≈ 0 |
| **B 单元错位** | 功能单元不是参数，是位置上的内容 | Q2-C1：L28–L35 消融全部 133 头 drop **0.000**，patch L33 一个位置翻转 **1.00** | 不预测差异结构（这条已成立，只解释「为什么在参数里找不到」） |
| **C 相对编码** | 每个词的码由它与其他词的关系决定，绝对位置任意 | **未测** | 差异**按关系类型分簇** → within ≫ across，且同一「抽象方向」跨层级复用 |

**关键**：A 和 C 都预测「定位失败」，所以定位实验永远分不出来。
这也解释了为什么前十四轮换着侧问（头 / k / 输出 / q）都返回 NULL——
**问的是 A 和 C 共同蕴含的东西**。

⇒ **Q6-A 的设计目标就是让 A 和 C 给出相反的数字。** 这是它唯一的价值。

## 3 「画出整体图谱」必须变成一个可判决的定义

「图谱」如果只指「把 embedding 画成二维图」，那它没有判决力——任何东西都能画成图。所以先给三个可判决的定义：

**定义 1（结构图谱 / Q6-A）**：关系是**方向**，不是标签。
一个关系类型 R 存在，当且仅当实例化 R 的词对的差向量 **Δ_i = v_{b_i} − v_{a_i}** 在 R 内部互相共线（within-cos 显著高于 across-cos）。
这不是「有没有某个维度」，而是「同一支箭头是否被反复使用」——**这正是「复用差分」的字面含义**。

**定义 2（层级共享 / Q6-A 的 A2）**：你说的「苹果-水果-食物-物体」，如果成立，
则 `Δ(苹果→水果)` 与 `Δ(水果→食物)` 应指向**同一个方向**（同一支「抽象」箭头用两次）。
这是一个极便宜、极锋利的检验：**一支箭能不能连用两次**。

**定义 3（属性矩阵低秩 / Q6-B）**：你说的「上百万物体 × 颜色大小重量」，如果靠复用实现，
则「物体 × 属性」的响应矩阵必须**低秩 + 稀疏修正**，且 held-out 格可预测。
判据是 rank-r 曲线与留出格 R²。这一条同时是**压缩率**的直接测量。

**定义 4（全图保真度 / Q6-C）**：把 M 个实体按内部几何排成图，
用**未参与构建的人类分类标签**检验它恢复了多少——报一个百分比。
没有这个百分比的「图谱」不算图谱。

## 4 三段式方案（每段都闭合，不产生「下一个规律」）

### Q6-A 关系方向是否被复用（今天，约 3 分钟）

- **量**：6 个关系族的 within-cos / across-cos / 层级方向余弦 / 留出类比预测准确率。
- **判决**：`RELATION_SPECIFIC` / `GENERIC_ONLY` / `NO_STRUCTURE` 三选一，**互斥且穷尽**。
  - `GENERIC_ONLY` 是我最担心的一档：所有族都对齐、但族与族之间也等量对齐
    ⇒ 只有**一支通用「联想箭头」**，那等于「指向典型关联词」，**不构成编码机制**。
  - 这一档就是你和 A（冗余）之间的裁判：A 预测 `NO_STRUCTURE`，C 预测 `RELATION_SPECIFIC`，
    「差不多对但不区分类型」是两者之外的第三种真答案，而且是**信息量最低**的那种。
- **闭合**：一旦判出档位，这个子空间就关掉（预算 3 轮的家族闸仍然生效）。

### Q6-B 属性矩阵压缩（第二段）

- 造 K 物体 × J 属性的真值网格（颜色/大小/可食/可切/含水量），
  用内部表示读出每个 (物体,属性) 的值，测 rank-r 近似。
- 判据：留出格 R² ≥ 0.60 且所需 rank ≤ 8 ⇒ 复用成立且可量化压缩率。
- 若 rank 必须接近 min(K,J) ⇒ **没有属性复用，是查表**，你的 R3 需改写。

### Q6-C 图谱保真度（第三段）

- 用 Q6-A/B 得到的关系方向构建 M×M 结构，投影、聚类，
  对**留出的人类分类标签**报恢复率（ARI / top-1 近邻同类率）。
- 产出：一张真实的图 + 一个百分比。这是你要的「整体图谱」，且带判决力。

## 6 与既有结论的衔接（为什么这个方案不是又开一个坑）

- **T1（key 与上下文无关，cos 0.998）** 说：词码是**静态**的。
  这与你说的「相对」不矛盾——静态指的是「同一词跨上下文不变」，不是「绝对坐标有意义」。
  一个词的坐标可以完全由它在关系图中的位置决定，而仍然与上下文无关。
  **这两件事是正交的，Q6-A 测的正是后一件。**
- **T2（share_ctx 0.009）** 说：上下文不改 key。
  若关系方向存在，它应在**读出端**或 **q 侧**起作用，不在 k 侧。Q6-A 用残差流位置取码，绕过这个限制。
- **T3（复用按实体索引 7.88×）** 说：复用真实存在，轴是实体。
  Q6-A/B 测的是**属性轴**与**关系轴**——如果也成立，则存在**两个正交的复用轴**，
  这本身就是一个可写下来的机制结构。
- **Q4-R / Q5-A（选槽 = argmax，32 头弱证据累积）** 说：执行层是「选一个赢家」。
  若 Q6-A 判 `RELATION_SPECIFIC`，则「选哪个赢家」由查询与关系方向的匹配决定，
  下一步就是把两者接起来（Q6-D）。**这是唯一一条把三段接成机制的路径。**

### 9.3 定义 4 的前提被本轮改写

原设想「把 M 个实体排成二维图，用人类分类标签检验恢复多少」。本轮之后这个设想**不成立**：
- Q6-B2 说明层级是**区域**不是**方向** ⇒ 不存在可排的「抽象轴」；
- Q6-B 说明属性知识是**稀疏指针**不是**低维坐标** ⇒ 二维图会丢掉全部属性信息。

⇒ 若要做定义 4，检验对象应改为**「实体 × 属性值」稀疏表的预测保真度**（留出实体能否预测其属性分布），
而不是几何排布的恢复率。这属于**新题型**，不是 Q6 家族的第 4 轮。
