# PAT_Q8E_PREREG_v1 — 频率方向稳定性（同家族跨规模，静态）

冻结时间：2026-11-01 19:02。冻结后只许修实现错误，不许改阈值与判据。

## 0. 问题

Q8-B 在 Qwen3-4B 与 GLM-4-9B 上发现形状同构的频率子空间（对数刻度、低维稠密、
与范数/语义正交）；Q8-D2 证明它不被前向使用。剩下的解释分岔：

- **H-arch**：频率子空间是「架构 + 训练配方」的普遍产物（同家族不同规模都会长出同构结构，
  且对相同 token 给出相似的频率标量）。
- **H-fossil**：它是每次训练的偶然化石（结构形状普遍，但具体放哪个方向、给哪个 token
  什么值是偶然的）。

区分仪器：跨规模比较。**坐标轴跨模型不对齐**（AGENTS.md §3），cos(w_freq) 无意义；
干净的可比对象是**逐 token 的标量预测** `t = (E − μ) @ w`：两个模型共享 151936 行词表，
t 是"该行在频率轴上的投影"，跨模型直接可比。

## 1. 材料

- Qwen3-4B（d=2560，Q8-B 已测：全池 R² 0.8263）
- **Qwen3-14B（d=5120，本轮新增；embed_tokens 从分片 1 safetensors 直读，已验证
  151936×5120 与 4B 同词表）**
- GLM-4-9B 形状数字沿用 Q8-B（第三方家族参照）
- POOL：与 Q8-B 完全相同的构建（CHAR 单字 + WORD 多字全 CJK，须有 wordfreq zipf；
  残片/无文本行排除）

## 2. 判据

**E1 存在性（14B）**：全空间 held-out R²（5 折 OLS，独立代码路径复算）。
- `FREQ_PRESENT`：R² ≥ 0.5
- `FREQ_WEAK`：0.2 ≤ R² < 0.5
- `FREQ_ABSENT`：R² < 0.2

**E2 刻度（14B）**：zipf 轴 vs 原始频率轴的 held-out R² 差 ≥ 0.30 → `LOG_SCALE`；
< 0.30 → `SCALE_UNCLEAR`。

**E3 维数（14B）**：Krylov 曲线 k*（首次达到全维 R² −0.02 的 k）。
- k* ≤ 16 → `LOW_DIM_DENSE`；16 < k* ≤ 256 → `MID_DIM`；未饱和 → `DISTRIBUTED`。

**E4 标量共享性（4B vs 14B，新仪器）**：在共享 POOL 行上，
- 原始相关 ρ(t4b, t14b)（必然高——两者都与 zipf 相关）；
- **偏相关**（主判）：r_m = t_m − OLS_fit(zipf → t_m) 的残差，ρ(r4b, r14b)。
  打乱 token 行标签 1000 次得零分布。
  - `SCALAR_SHARED`：ρ ≥ 0.50 且 > 零分布 p99
  - `SCALAR_WEAKLY_SHARED`：0.20 ≤ ρ < 0.50 且 > 零分布 p99
  - `SCALAR_INDEPENDENT`：ρ < 0.20 或不超过零分布 p99

**E5 语义正交（14B）**：COLOR/FRUIT within 扣频率分量后保留 ≥ 95% → `SEM_ORTHOGONAL`。

## 3. 预注册的将被证伪的表述

- 若 E1–E3 全部复现且 E4 = SCALAR_SHARED：把 Q8-B 的「形状同构」从 2 模型观察升格为
  「跨家族、跨规模的三点规律」，且频率标量是同配方共享结构（H-arch 胜）。
- 若 E4 = SCALAR_INDEPENDENT：形状普遍但内容偶然（H-fossil 胜）——同构只是训练动力学的
  普遍吸引子，不携带可迁移信息。
- 若 E2/E3 不复现：撤回「低维稠密」跨模型提法，改为规模依赖。

## 4. 已知陷阱（沿用 Q8-B 清单 + 本轮新增）

in-sample 虚高（折缓存带指纹 R-MTH-24）、独立复算（R-MTH-25）、
全池复核（R-MET-34）、语义与频率不可分（R-MTH-23）、
**新增**：14B 与 4B 的 μ（逐坐标均值）不同，t 必须各自中心化后计算；
偏相关的 zipf 拟合用留出（防过拟合残差）——zipf 是一维，过拟合风险小，但报 in/out 差。
