### 严格审视

**问题1：组合性检验的代入混乱**
"Isn't X Y?" 既是极性变换又是疑问变换，但这两种变换的基准句不同。
pol 基准："The sky is blue" → "The sky is not blue"（改变命题）
quest 基准："The sky is blue" → "Is the sky blue?"（悬置命题）
combined："Isn't the sky blue?" → 同时否定+疑问
但 combined 的句法结构（助动词提前）可能单独产生高 cos_question，导致 gain < 0 并非"极性被吸收"，而是"结构相似度"。

**问题2：复用率"基线"计算未验证**
0.50 基线假设两个随机高维向量 normalize 后 |cos(s,d)| ≈ 0.50 的分布均匀性。
在实际高维空间中这是对的（期望为0），但不同层的 mean delta 向量可能存在系统偏差（e.g., 层归一化后某些方向被压缩）。

**问题3：共享轴 logit 投影的翻译偏差**
"anymore"/"necessarily"/"而是" 在 tokenizer 中可能占用多个 token 位，
logit lens 看到的是 subword 的第一个 token，不能完全等同于"这个词的语义"。

**问题4：DS7B L4/H12 true_cos=0.946 的解释暗礁**
true_cos 高 = W_O_h @ V_h 在极性和疑问输入上产生几乎相同方向。
但这可能是：(a) 该头真的共享命题操作子空间；(b) 该头对这类句子几乎不活跃（输出接近零向量），相似性是假象。
需要检验 ‖contrib_pol‖ 和 ‖contrib_quest‖ 的绝对量级。

**问题5：双重否定数据不自然**
"The cat is not not fast" 是语法上不常见的结构。
模型处理时可能将其视为语法错误或模糊输入，导致内部激活不稳定。

我们手动构造了语义对应的 25 对句子（"天空是蓝色的" = "The sky is blue"），并使语言对之间语义相同。这直接导致跨语言 cosine 必然更高——如果我们用语义不对应的句子，跨语言 cosine 会更低。这不是"跨语言对齐"，而是"跨语言的语义对齐"。需要用语义不对应的句子做控制组验证。

**问题2：否定变换的词序效应**
英语 "is not" vs 法语 "n'est pas"：两者都在动词附近加否定词，词序变化幅度有限。英语 vs 汉语："不是" vs "is not"：都是相对靠前的位置。但俄语的句法差异更大。这说明"跨语言共享"可能部分来自**句子结构变化模式相似**，而非真正的操作抽象。

**问题3：EN-FR 对齐显著高于 EN-ZH**
EN-FR cos=0.85-0.89 vs EN-ZH cos=0.62-0.72。这个差距部分来自：
- Qwen3 训练数据中欧洲语言共现更多（可能有平行语料）
- 英法语法相似度高于英中语法
- 这说明"跨语言对齐"程度与语言族相关，不是完全语言无关的抽象

**问题4：GLM4 缺失 L30 头（脚本层采样问题）**
GLM4 有40层，采样步长=4，层集合为{0,4,8,...,36}，跳过了 L30。导致 GLM4 的 L30/H22、L30/H23 从未被测量。run3 也存在同样问题。需要补测。

**问题5：SNR < 1 的双重解释**
SNR = ‖μ_pol - μ_quest‖ / σ_within < 1 可以是：
(a) pol 和 quest 贡献方向相同（true_cos高），μ_pol ≈ μ_quest → SNR 自然低
(b) 每对句子的贡献高度可变（σ_within 大），掩盖了真实方向信号
实际上两种效应都可能存在，难以分离。

**问题6：作用域测试的词汇线索**
"The cat neither eats nor sleeps"（wide scope）vs "The cat does not eat but sleeps"（narrow scope）：
两个句子有明显词汇差异（neither/nor vs not/but），模型可能通过这些词汇线索而非真正的作用域理解来产生差异。需要词汇控制实验。

### 理论解读

**Phase 239 的"无迁移"结论的修正**：

Phase 239 在 hidden state 空间测量，最大 gain=0.043，结论为"v_neg 是域耦合特征"。
Phase 240 在 logit 空间测量，最大 logit_tc=0.568，发现显著功能迁移。

**统一解读**：
- hidden state 空间：包含大量域特异信息（位置、语法、上下文），操作信号被淹没
- logit 空间：最终层将 hidden state 投影到 vocab 空间，该投影有"抽象压缩"效果，
  使域特异成分对齐方向上的影响减小，操作的通用成分（影响"not/no/unless"等负极性token）
  得以在 cos 度量下显现
- **logit 空间比 hidden 空间更适合测量操作迁移**

**v_mean 携带"有效域噪声"的悖论**：

v_core（纯核，R²_1d=0.10-0.20）逻辑上应该更接近域无关操作核，
但在 logit 空间中，v_mean（含80%域噪声）的功能迁移更强。
解释：logit 层 W_U（unembedding matrix）对"否定相关 token"的响应不仅来自操作方向，
也来自源域的语义方向（自然/物理属性词汇本身就有一定否定倾向的分布）。
v_mean 恰好把源域的"语义否定倾向"一并注入，这在 logit 空间中产生功能性的否定方向对齐，
但并非真正的操作迁移——更像是"来自不同域的两个否定都指向相同的负极性 tokens"。

**DS7B 的"核逆转"现象**：

DS7B 早期层（L06）：v_core=0.427 > v_mean=0.245
这与 DS7B Phase 236 的 k90=1（否定几乎完全在1维）一致：
- 当 k90=1 时，v_core（均值中心化PC1）与 v_mean 方向高度接近
- DS7B 的 v_mean 在早期层噪声大（域相关成分多），而 v_core 更"纯净"
- 但在深层（L12+），DS7B 的 v_mean 又重新胜出，说明域相关成分在深层也变得功能相关

**扰动放大的力学意义**：

peak_ratio ≈ 20 意味着 ||∂h_final/∂h_inject[L]|| ≈ 20。
这是 Transformer 计算的"Lyapunov 放大指数"近似：
早期注入的任何方向扰动，最终都会在 logit 层被放大约 20 倍。
这不是"操作传播"，而是 Transformer 的通用计算特性：
残差流在层间累积，最终层拥有对所有历史扰动的线性叠加放大效应。

### 严格审视（潜在硬伤）

1. **logit_tc 度量的混淆性**：
   cos(Δlogit_inject, Δlogit_native) 测量的是"注入后 logit 变化方向"与
   "原生否定 logit 变化方向"的对齐。这可能不是真正的"操作迁移"，
   而是"两个否定场景的 logit 分布都抑制肯定 token、提升否定 token"的共性，
   即使注入并不真正执行了否定操作。

2. **DS7B 方差危机**：
   std=0.71-0.83 意味着单个 target 句子的 logit_tc 在 -0.5 到 +0.9 之间，
   n=25 的均值极不稳定（95% CI 宽度≈0.28）。DS7B 的 Part A 结果置信度低。

3. **v_transported 的方法论问题**：
   Procrustes 传输基于"所有句子的 PCA 子空间对齐"，而非针对单个注入层的精确流形结构。
   当 source 和 target 的流形结构差异大时，线性正交旋转是粗糙近似。

4. **扰动放大 ≠ 操作传播**：
   Part C 的 peak_ratio=20 是范数放大，不是功能方向保持。
   实际上扰动方向在层间大幅改变（这解释了为什么早期注入的 logit_tc 低）。

### 核心理论进展（三模型整合）

**1. 句号漂移是Transformer的普遍机械律**  
三模型全部系统性爆炸（CV<0.5），强度DS7B>Qwen3>GLM4。这是残差流单向积累的直接体现：每层Δ_l=F_l(h_l)叠加，句号token的表示随层深单调漂移。

**2. DS7B具有"架构瓶颈"特征**  
L27消融KL=1.375（高功能依赖性）+ L26谱范数=332（极度Jacobian放大）共同说明：DS7B的计算在L26-L27层高度集中。这是"瓶颈计算"而非分布式计算。可能与DS7B k90=1（Phase 236，否定编码1维压缩）是同一个架构属性的不同体现。

**3. L26 Jacobian爆炸是最重要的新发现**  
DS7B L26 σ=332，max=1032。这是随机探针方向的放大，意味着L26的Jacobian有一个极大奇异值。但Qwen3/GLM4全层σ≈1.0。这很可能是DS7B独特的"计算爆炸层"，解释了其残差漂移为何14×于GLM4。

**4. Hub层功能重要性与模型复杂度正相关**  
DS7B(SIGNIFICANT) > GLM4(MODERATE) > Qwen3(WEAK)。更强的架构瓶颈 → Hub层消融影响更大。这暗示DS7B的语义信息流真正经过L27这个节点，而Qwen3的L12更像"观察点"。

**5. 逻辑悖论无法诱导确定性的预测不确定性爆炸（n=20不显著）**  
这不意味着模型"理解"悖论。更可能的解释：模型将悖论句当作高复杂度句子处理，entropy的提升被句子内部其他特征掩盖（CIs重叠）。需要n≥50才能得到统计显著结论。
