# 当前研究基线：Phase 1210–1235

## 一、当前最准确的项目状态

截至 2026-08-11，可见材料支持以下基线：

1. 已知真值系统中，多种功能商、时钟和时序联盟相机能够被严格校准；
2. 这些仪器迁移到自由训练网络或预训练语言模型时，存在行为广度、干预语义、载体控制和形成条件等外部效度断点；
3. Qwen3 对若干受控对象—关系—值原子操作具有稳定行为，但统一母任务、家族门和答案边界单点补丁均出现限定失败；
4. Phase 1235 证明对象—marker 的候选路径、前缀树、固定句式内容和自然句式内容稳定，而严格短字符串合同高度依赖提示载体与模板；
5. 当前没有证据授权把这种行为稳定性命名为协议不变的隐藏内容状态；
6. 当前没有完成同一对象从行为到响应预测、必要性、救援、完整生成、组合、跨模型和训练形成的纵向闭环；
7. 现有数学足以表达当前边界，新数学升级门未打开。

## 三、当前核心瓶颈

\[
\boxed{
\text{尚未形成一个可预测未知干预的全局响应张量，}
\text{也未识别能压缩该张量的功能状态和转移结构。}
}
\]

直接执行旧 Phase 1236 的问题在于：它受 Phase 1235 异质总门阻断，同时仍然只围绕一个先验对象采集隐态。新战役应把下一步改写为：

1. 用全新材料冻结内容、格式、协议和解码的类型化资格；
2. 同时注册九种候选机制和零假说；
3. 先做全域低成本轮廓和小型响应张量试采集；
4. 由结构算法生成候选；
5. 主动选择候选分歧最大的干预；
6. 最后才在封存集裁决。

## 四、当前禁止事项

- 不从 Phase 1235 的成功子集直接扫描 hidden state（隐藏状态）；
- 不把 `Marker: gold` 之类内容正确、格式错误的输出事后改成严格短答成功；
- 不继续围绕某个单层、单通道或单补丁做连续相邻 Phase；
- 不把已知真值相机成功外推为自然语言机制；
- 不把跨层相似、线性可读或高余弦写成自然因果使用；
- 不因当前数学骨架很长而声称需要新基础数学。

## 五、当前唯一优先决策

启动 C001“全局结构辨识战役”的 WP00：历史账本迁移、构念分型、候选机制生死合同与封存数据合同冻结。

WP00 不运行模型，不产生新的神经机制结论。它完成后，才由类型化资格和信息增益选择器决定 TB03/TB04 的扫描范围。
