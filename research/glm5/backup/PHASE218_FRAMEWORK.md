### 0.1 原始70/25/5分解是错误的

```
旧报告（Phase 217-3）:

  成分2[次要, ~25%]: W_U各向异性

  D. Random baseline:      0.0004 = 0.01%

结论: 70/25/5完全错误。
  h_norm效应占99.6%，不是70%
  W_U各向异性和结构性路由各占0.4%，不是25%和5%
```

### 0.2 更有意义的分解：归一化KL中各成分的比例

```
归一化后（控制h_norm），训练模型KL中各成分比例:

  L0: norm_KL_train=0.0217, norm_KL_rand=0.000363, W_U fraction=98.3%
  L7: norm_KL_train=0.00244, norm_KL_rand=0.000041, W_U fraction=98.3%
  L14: norm_KL_train=0.00165, norm_KL_rand=0.000022, W_U fraction=98.7%
  L21: norm_KL_train=0.000468, norm_KL_rand=0.000015, W_U fraction=96.8%
  L27: norm_KL_train=0.000055, norm_KL_rand=0.000012, W_U fraction=78.9%

结论: 
  归一化KL中，~98%是W_U各向异性的贡献
  只有~2%是"结构性路由"
  到L27，W_U fraction降到79% → 结构性路由贡献增加
  但绝对量级极小(0.000055)
```

### 0.3 L27 KL=0.00的数值问题

```
L23-27层的entropy=NaN → 数值溢出

  L23: p_max=0.528, logits_max=90.1, entropy=NaN
  L24: p_max=0.917, logits_max=96.7, entropy=NaN
  L25: p_max=0.523, logits_max=118.1, entropy=NaN
  L26: p_max=1.000, logits_max=157.4, entropy=NaN
  L27: p_max=1.000, logits_max=170.7, entropy=NaN

logits_max/logits_std = 7.0 at L27
→ softmax坍塌为near-one-hot
→ KL≈0是softmax的极限行为
→ 不是"等价类变厚"的证据

因此: L20之后的所有KL数据都不可靠
  有效数据范围: L0-L20
```

### 0.4 随机模型不是"无信息"

```
随机模型输出:
  L0: entropy_ratio=0.985 (接近均匀)
  L7: entropy_ratio=0.875
  L14: entropy_ratio=0.769
  L21: entropy_ratio=0.677
  L27: entropy_ratio=0.608

→ 随机模型L27仍有60.8%的max entropy
→ 不是"均匀分布"——有信息，但信息少
→ "随机模型稳定因为无信息"的说法过于简化
→ 正确说法: 随机模型的KL低因为W_U各向同性(所有奇异值~8.5)

```
事实1: h_norm增长贡献了99.6%的KL下降
  → "等价类变厚"几乎完全是尺度效应
  → 不是"主动路由"机制

事实2: 归一化KL中，W_U各向异性贡献了~98%
  → W_U各向异性是唯一有量级意义的训练效应
  → "结构性路由"只有2%的贡献

事实3: L20之后的KL数据不可靠（数值坍塌）
  → 有效分析范围: L0-L20

事实4: 随机模型W_U各向同性(σ≈8.5)
  → 所有方向对logits影响均匀且小
  → 扰动产生的logits变化极小 → KL小
  → 这是"随机模型也稳定"的根本原因

事实5: 训练模型W_U各向异性(σ=[170,85,77,...])
  → 少数方向对logits影响极大
  → 大多数方向对logits影响极小
  → 训练创造了"有效null space"——但这是W_U的线性代数性质
```

### 1.2 仍不确定的

```
不确定1: W_U各向异性是否对语言能力因果必要
  → 已知它是训练效应，但不知道删除它是否破坏语言能力

不确定2: "约束沿高奇异值方向传播"是否是同义反复
  → 高奇异值方向 = 模型频繁预测的token方向
  → "约束沿这些方向传播"可能只是说"语言约束影响模型预测"
  → 这是同义反复

不确定3: 组合性是否存在
  → 所有已验证的现象都是"局部统计一致性"
  → 没有任何实验验证了递归/组合/变量绑定
```

   → 完全正确。精确计算: 99.6%/0.4%/0.4%

2. "W_U各向异性的因果必要性从未被验证"
   → 完全正确。这是唯一surviving的强信号，但没有因果证明

   → 完全正确。在验证因果必要性之前，不应建立理论

   → 完全正确。L23-27的entropy=NaN → 数值坍塌

5. "随机模型的输出不一定是'无信息'"
   → 正确。entropy_ratio=0.6-0.98，仍有信息

6. "语义等价≠续写分布等价"
   → 正确。主动/被动句语义等价但续写分布不同
   → Phase 218-A的设计需要修正
```

### 2.2 关键新洞察

```
"约束沿高奇异值方向传播"可能是同义反复:

  W_U的高奇异值方向对应什么？
  → 对应variance最大的logit方向
  → 即模型最频繁预测的token的线性组合方向
  
  所以"约束沿这些方向传播"只是说:
  "改变语法约束 → 改变模型预测 → 改变在logits中有大方差的维度"
  
  这是tautology（同义反复）。
  
  真正有意义的问题不是"约束是否沿高奇异值方向传播"
  而是"约束是否在W_U的特定子空间中传播——这个子空间恰好对应语义敏感方向"
  
  但"语义敏感方向"和"高奇异值方向"可能完全重合
  → 因为训练就是让语义约束影响预测
  → 所以两者重合是训练的自然结果
  
  结论: W_U各向异性可能是"语言能力的自然结果"而非"语言能力的原因"
  → 需要因果实验来区分
```

## 三、修正后的实验方案

### 核心原则：在验证因果必要性之前，不建立新理论

### Phase 218-P0 [★★★★★]: W_U各向异性因果必要性验证

**这是整个项目当前最重要的实验。**

```
实验设计:

步骤1: W_U各向同性化
  - 对训练好的Qwen3，对W_U做SVD: W_U = U @ diag(S) @ Vh
  - 构造各向同性版本: W_U_iso = U @ diag(S_mean) @ Vh
    其中 S_mean = mean(S) = (1/r) * sum(S_i)
  - 保留W_U的行空间和列空间，只把奇异值均匀化
  - 这消除了"有效null space"和"高奇异值方向"

步骤2: 测试语言能力
  - 用原始W_U: 生成10个测试句子的SVA准确率
  - 用W_U_iso: 生成同样10个句子的SVA准确率
  - 对比: 准确率是否显著下降

步骤3: 进一步测试
  - Dyck-1/Dyck-2 (如果模型能处理)
  - 多约束句 (数+时态)
  - 常识推理 (简单QA)

预测:

情况A: W_U_iso后语言能力崩溃
  → W_U各向异性是语言能力的必要条件 ★★★★★
  → 这是真正的"必要性证明"
  → 理论方向: 研究W_U各向异性如何支持语言能力

情况B: W_U_iso后语言能力基本不变
  → W_U各向异性是语言处理的副产品
  → 不是核心机制
  → 需要完全重新寻找surviving信号

情况C: W_U_iso后某些能力崩溃，某些不崩溃
  → 最可能的结果
  → 例如: SVA不崩溃（因为约束传播在其他层完成）
          但生成质量下降（因为W_U的"锐化"是高质量输出所需的）

可证伪条件:
  F1: 如果W_U_iso后SVA准确率>90%原始 → 各向异性对约束传播非必要
  F2: 如果W_U_iso后生成entropy显著增加 → 各向异性对输出锐化必要
  F3: 如果W_U_iso后所有能力都崩溃 → 各向异性对一切必要
```

### Phase 218-P2 [★★★]: 语义保持变换（修正版）

**基于批评的修正：主动/被动句的续写分布不同，不能用KL直接测"语义等价"**

```
修正后的实验设计:

方法1: 同义填充（续写分布相似的语义等价对）
  "The answer is ___" vs "The solution is ___"
  → 续写分布相似（都指向相同类型的答案）
  → 但内部表示不同
  → 测量: Δh在W_U高/低奇异值方向的投影

方法2: 约束传播一致性（不依赖续写分布等价）
  主动: "The cats chase the dog" → "chase"是复数
  被动: "The dog is chased by the cats" → "chased"仍是复数语义
  
  测量: 约束"数"在主动vs被动句中的传播强度
  R_数(l) = KL(P(·|h_l(sg)), P(·|h_l(pl)))
  在主动和被动形式中是否相同
  
  如果相同 → 约束传播路径不依赖于句法结构 → 存在深层语义等价
  如果不同 → 约束传播完全依赖句法 → 无深层语义等价

方法3: 语义等价对的Δh方向分析
  不用KL来测"语义等价"
  而是测量: 语义等价对的Δh方向
  vs 语义不等价对的Δh方向
  
  如果语义等价对的Δh主要在W_U低奇异值方向
  → "语义等价 ≈ 输出等价"成立
  → W_U各向异性确实编码了"语义敏感几何"
  
  如果语义等价对的Δh也在W_U高奇异值方向
  → "语义等价 ≠ 输出等价"
  → W_U不编码"语义"，只编码"next-token"

依赖: P0的结果
  如果P0证明W_U各向异性非必要 → P2不需要做
  如果P0证明W_U各向异性必要 → P2是自然的下一步
```

## 五、理论硬伤

### 5.1 W_U各向异性可能是"自然结果"而非"原因"

```
关键问题:
  训练使W_U各向异性 → 这是语言能力的"原因"还是"结果"？
  
  如果是"原因": 删除各向异性 → 语言能力崩溃 → 找到了必要结构
  如果是"结果": 删除各向异性 → 语言能力不变 → 各向异性只是副产品
  
  类比:
    跑步使肌肉增大 → 肌肉增大是跑步能力的原因还是结果？
    删除增大的肌肉 → 跑步能力下降 → 肌肉是必要条件
    但肌肉增大本身是被跑步"创造"的 → 它是结果，但也是必要条件
    
  同理:
    W_U各向异性是被训练"创造"的 → 它是结果
    但如果删除它语言能力崩溃 → 它也是必要条件
    "结果"和"必要条件"不矛盾
```

### 5.2 "约束沿高奇异值方向传播"的同义反复风险

```
如果P0证明各向异性必要，仍然可能有同义反复问题:

  "约束沿高奇异值方向传播" 
  = "语法约束改变模型的预测"
  = "语法约束影响模型的输出"
  
  这是trivially true的——如果语法约束不影响输出，模型就没有语法能力
  
  真正非平凡的问题是:
    约束是否在W_U的特定子空间中独立传播？
    即: 不同约束是否占据不同的高奇异值方向？
    
  这需要P3（组合扰动稳定性）来验证
  如果不同约束在W_U的同一方向传播 → 无组合性
  如果不同约束在W_U的不同方向传播 → 有组合性的基础
```

### 5.3 最根本的瓶颈（未变）

```
1. 我们只有"输出分布"一个窗口
2. 语言能力可能存在于"传播路径"中
3. P0只能验证W_U是否必要，不能揭示传播路径的结构
4. 即使P0正面，我们仍然不知道"为什么W_U各向异性支持语言能力"
5. 这需要更深入的因果实验（如路径消融）
```
