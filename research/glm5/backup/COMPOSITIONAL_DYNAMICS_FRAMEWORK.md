## 一、核心升级：从argmax等价到续写分布等价

### 1.1 为什么argmax等价不够

```
argmax等价的问题:

例1: "The cat" vs "The cats"
  argmax(W_U h_cat) 可能是 "is" 或 "was"
  argmax(W_U h_cats) 可能也是 "is" 或 "was"
  → 两者argmax可能相同！
  → 但续写分布完全不同

例2: "The cat chases" vs "The cat chase"
  两者可能都argmax到 "." 或 "the"
  → argmax等价类相同
  → 但语法正确性完全不同

根本问题:
  argmax只看一个点（最高概率token）
  语言能力存在于整个分布（所有可能续写的概率）
```

### 1.2 续写分布等价（Continuation Equivalence）

```
定义（续写分布等价）:
  h₁ ≈ h₂ ⟺ KL(P(·|h₁), P(·|h₂)) < ε

其中 P(·|h) = softmax(W_U h / T) 是给定hidden state h 的续写分布
T 是温度参数（建议T=1.0，不人为缩放）
ε 是等价阈值（建议ε=0.01 nats，约1%的KL散度）

含义:
  两个状态等价 ⟺ 它们产生几乎相同的续写概率分布
  不仅仅是"最可能的下一个token相同"
  而是"所有可能续写的概率都相同"

这比argmax等价严格得多:
  argmax等价 ⟹ 续写分布等价（反向不成立）
  即: 续写分布等价是argmax等价的细化
```

### 1.3 续写等价的数学性质

```
性质1: 续写等价是W_U的row space上的等价
  KL(P(·|h₁), P(·|h₂)) < ε
  ⟺ W_U h₁ ≈ W_U h₂ （在softmax精度内）
  ⟺ (h₁ - h₂) ∈ 近似null space of W_U

  所以: null space分析仍然有效！
  88%能量在null space ⟺ 88%的方向不影响续写分布

性质2: 但比argmax更精细
  argmax: 只要求 argmax(W_U h₁) = argmax(W_U h₂)
  续写等价: 要求 W_U h₁ ≈ W_U h₂ （向量级近似）

  区别:
  - argmax允许logits的相对大小变化（只要top-1不变）
  - 续写等价要求所有logits几乎相同

性质3: 续写等价可以直接测量
  对任何两个h₁, h₂:
  1. 计算 logits₁ = W_U h₁, logits₂ = W_U h₂
  2. 计算 p₁ = softmax(logits₁), p₂ = softmax(logits₂)
  3. 计算 KL(p₁ || p₂)
  4. 如果 KL < ε → 续写等价
```

### 1.4 续写等价对理论框架的影响

```
核心修正:
  旧: 语言能力 = 约束兼容的(argmax)等价类运输
  新: 语言能力 = 约束兼容的(续写分布)等价类运输

但"续写分布等价"仍然是"下一token层面"的等价。
语言能力还需要更高层面的等价——组合等价。

所以完整框架需要三层:
  Layer 1: 续写分布等价（替代argmax等价）
  Layer 2: 组合等价（同一结构的不同实例化）
  Layer 3: 递归等价（无限嵌套的稳定传播）
```

## 二、核心升级：从约束传播到组合性动力学

### 2.1 语言能力的真正特殊性

```
语言能力 ≠ 下一token预测一致性
语言能力 = 有限参数下的无限组合泛化

具体地:
  1. 递归（Recursion）: "A says that B thinks that C believes that..."
  2. 组合抽象（Compositional Abstraction）: NP+VP→S, 不只是记住固定搭配
  3. 变量绑定（Variable Binding）: "himself"的指代随语境变化
  4. 符号复用（Symbolic Reuse）: 同一词汇在不同语境中复用
  5. 干扰抑制（Interference Suppression）: 多个约束同时生效不互相破坏

当前SVA只涉及第5点的一部分（多约束独立传播）
完全没有涉及1-4
```

### 2.2 组合等价（Compositional Equivalence）

```
定义（组合等价）:
  h₁ ~_comp h₂ ⟺ 对任意合法续写序列 C = (c₁, c₂, ..., c_k):
  |P(C|h₁) - P(C|h₂)| < δ

其中 P(C|h) = Πᵢ P(cᵢ|h, c₁...cᵢ₋₁) 是多步续写的联合概率
δ 是组合等价阈值

含义:
  两个状态组合等价 ⟺ 它们对所有可能的多步续写产生几乎相同的概率

这比续写分布等价更强:
  续写分布等价: 只看下一步
  组合等价: 看所有可能的未来路径

关键区别:
  h_"The cat" 和 h_"The cats" 可能单步续写等价（都预测"chases/chase"附近）
  但组合不等价（因为后续路径分化）
```

### 2.3 为什么组合性是核心

```
语言的组合性:
  "cat chases mouse" 的理解 ≠ "cat"的理解 + "chases"的理解 + "mouse"的理解
  而是: 语法结构 × 词汇选择 → 组合性含义

Transformer的组合性:
  如果模型只能做SVA（单约束传播）
  → 它是"局部一致性机器"
  → 不能处理递归、嵌套、变量绑定

  如果模型能做组合等价保持
  → 它是"组合性机器"
  → 可以处理递归、嵌套、变量绑定

关键问题:
  商空间动力学是否支持组合等价保持？
  还是只支持续写分布等价保持？
```

### 2.4 组合性动力学的数学框架

```
核心概念: 组合算子（Compositional Operator）

定义: 对语法规则 R: X → Y Z（如 S → NP VP）,
定义组合算子 Φ_R: H × H → H

含义:
  Φ_R(h_Y, h_Z) = 组合Y和Z后得到的hidden state
  如果模型有组合性 → Φ_R存在且可被识别

关键性质:
  1. 保持性: P(·|Φ_R(h_Y, h_Z)) ≈ P(·|h_X) （组合结果等价于整体）
  2. 可递归性: Φ_R(Φ_R'(h_A, h_B), h_C) 有效 （嵌套组合）
  3. 变量绑定: Φ_R(h_Y[g=x], h_Z) 对不同x产生不同但结构相同的输出
  4. 干扰抑制: Φ_R(h_Y, h_Z₁) 和 Φ_R(h_Y, h_Z₂) 在Z的维度上准正交

这些性质定义了"语言能力"而非"下一token一致性"
```

## 三、精确数学定义——消除元隐喻

### 3.1 约束的精确定义

```
旧定义（Phase 215）: C_f(h) = ||P_{V_f} h|| / ||h||
问题: 仍然是"存储论"——假设约束存在于某个子空间

新定义:
  约束f: 一组输入对 {(s₁, s₁'), (s₂, s₂'), ...} 的等价条件
  其中s和s'只在f的取值上不同（如sg vs pl）

  约束f在第l层的传播强度:
  R_f(l) = KL(P(·|h_l(s_correct)), P(·|h_l(s_wrong)))

  含义:
  R_f(l) 大 → 第l层的hidden state对f的取值敏感 → 约束f被传播
  R_f(l) ≈ 0 → 第l层对f不敏感 → 约束f已丢失
  R_f(l) 随层增大 → 约束f被放大
  R_f(l) 随层减小 → 约束f被衰减

优势:
  1. 不假设"约束存在于某个子空间"
  2. 直接测量"约束对输出分布的影响"
  3. 可推广到任何语言约束（不限于SVA）
  4. 有自然的零假设: R_f(l)≈0 对所有l → 约束f未被传播
```

### 3.2 兼容性的精确定义

```
旧框架: "约束传播不破坏其他约束" → 隐喻

新定义:
  两个约束f和g在第l层的兼容度:
  Compat(f, g, l) = |R_f(l)| - |R_f(l)|_{g被注入}

  其中 |R_f(l)|_{g被注入} 表示: 在g的取值被改变后，f的传播强度变化

  含义:
  Compat(f, g, l) ≈ 0 → g的改变不影响f的传播 → f和g兼容
  Compat(f, g, l) > 0 → g的改变增强了f → f和g协同
  Compat(f, g, l) < 0 → g的改变抑制了f → f和g干扰

  这是"组合性"的精确测量:
  多约束独立传播 ⟺ 对所有约束对(f,g), Compat(f, g, l) ≈ 0
```

### 3.3 可证伪条件

```
如果"约束兼容的等价类运输"理论成立，则:

F1: 训练模型的续写分布等价类"宽"于随机模型
  操作: 注入扰动，测量KL(P(·|h), P(·|h+δ))
  预测: 训练模型的KL < 随机模型的KL（对同量级扰动）
  证伪: 如果训练模型的KL ≥ 随机模型 → 理论错误

F2: 约束方向的KL敏感度高于随机方向
  操作: 注入约束方向扰动vs随机方向扰动，比较KL变化
  预测: 约束方向扰动的KL >> 随机方向扰动的KL
  证伪: 如果两者KL相似 → 模型没有选择性约束放大

F3: 多约束的兼容度≈0
  操作: 改变约束g的值，测量约束f的传播强度变化
  预测: |Compat(f, g, l)| < ε
  证伪: 如果Compat显著>0或<0 → 约束不是独立传播的

F4: 组合等价保持
  操作: 对嵌套结构，测量内层约束的传播是否被外层结构破坏
  预测: 内层约束在嵌套结构中仍被保持
  证伪: 如果嵌套导致内层约束丢失 → 不存在组合性

F5: 变量绑定的动力学实现
  操作: 测量反身代词"himself"的指代如何随主语变化
  预测: 改变主语→"himself"的绑定目标改变→对应的hidden state方向旋转
  证伪: 如果改变主语不影响"himself"的编码 → 变量绑定不通过动力学实现
```

## 四、修正后的六阶段实验方案

### Phase 1 [★★★ 最高优先级]: 架构 vs 语言分离

**核心问题**: 所有已发现的结构，是语言的还是架构的？

```
实验1A: 随机权重Transformer——续写分布等价类
  方法:
  1. 加载随机初始化的Qwen3（不训练）
  2. 输入一组句子对（sg vs pl, 过去vs现在等）
  3. 在每层注入同量级扰动δ
  4. 计算 KL(P(·|h_l), P(·|h_l+δ))
  5. 与训练模型对比

  关键指标:
  - KL(训练模型) vs KL(随机模型)
  - null space比例: 训练 vs 随机
  - 等价类"宽度": 对多大范围的扰动KL<ε

  预测:
  - 训练模型的KL << 随机模型的KL（等价类更宽）
  - 训练模型的null space比例 >> 随机模型
  - 如果否 → "等价类保持"是架构效应，不是语言效应

实验1B: 随机权重Transformer——约束方向敏感性
  方法:
  1. 对随机模型，注入"数方向"扰动
  2. 测量 R_f(l) = KL(P(·|h_l(sg)), P(·|h_l(pl)))
  3. 与训练模型对比

  预测:
  - 训练模型: R_f随层增大（约束被放大）
  - 随机模型: R_f≈0（随机模型不传播约束）
  - 如果否 → 约束传播是架构效应

实验1C: 随机权重Transformer——Jacobian谱
  方法:
  1. 对随机模型，计算每层Jacobian的奇异值谱
  2. 与训练模型对比

  预测:
  - 随机模型: 奇异值分布更均匀（近旋转）
  - 训练模型: 奇异值分布有各向异性（特定方向放大）
  - 如果否 → Jacobian谱结构是架构效应
```

**模型**: Qwen3（先做一个模型确认方法，再做GLM4和DS7B）

### Phase 2 [★★★]: 续写分布等价——替代argmax等价

**核心问题**: 续写分布等价类的几何结构是什么？

```
实验2A: 等价类的精细几何
  方法:
  1. 固定输入，生成N=500个不同方向的扰动{δ_i}
  2. 对每个δ_i，计算 KL(P(·|h), P(·|h+δ_i))
  3. 绘制KL vs ||δ_i||的曲线
  4. 分析: 在什么扰动量级下KL超过ε？
  5. 分析: 哪些方向的δ对KL影响最大？

  关键测量:
  - 等价类"半径": 令KL<ε的最大||δ||
  - 等价类"各向异性": 不同方向的半径差异
  - 等价类"边界": KL从ε以下跳到ε以上的梯度

  预测:
  - row space方向: 小扰动就使KL>ε（等价类薄）
  - null space方向: 大扰动仍KL<ε（等价类厚）
  - 量化: row space方向的半径/null space方向的半径 << 1

实验2B: 约束方向在等价类中的位置
  方法:
  1. 计算"数方向"v_num = h(sg) - h(pl)
  2. 将v_num分解为row space分量和null space分量
  3. 计算KL灵敏度: 沿v_num方向注入扰动时的KL变化率

  预测:
  - v_num主要在row space中（约束方向影响输出）
  - 但约束传播的"载体更新"主要在null space中
  - 这解释了: 约束可以被传播（row space分量），但不干扰其他约束（null space分量吸收了大部分更新）

实验2C: 语法扰动 vs 随机扰动的KL行为
  方法:
  1. 注入语法错误方向扰动（如"cat chase"→"cat chases"方向）
  2. 注入同量级随机方向扰动
  3. 比较两者产生的KL

  预测:
  - 语法扰动的KL >> 随机扰动的KL
  - 因为语法方向在row space中，随机方向主要在null space中
```

### Phase 3 [★★★]: 组合泛化——超越SVA

**核心问题**: 模型是否有组合性？能否处理递归、嵌套、变量绑定？

```
实验3A: Dyck语言——计算复杂度边界
  测试1: a^n b^n (Dyck-1, 需要计数 → DFA)
    - n = 1, 2, 3, ..., 10
    - 测量模型匹配准确率随n的衰减

  测试2: (^n )^n (Dyck-2, 需要栈 → PDA)
    - n = 1, 2, 3, ..., 10
    - 测量匹配准确率

  测试3: 混合括号: (^n [^m )^n ]^m (交叉依赖)
    - 需要同时追踪多个栈
    - 如果模型能处理 → 超越PDA

  关键指标:
  - 准确率衰减速率
  - 哪些层开始正确处理
  - 不同模型的能力差异

  预测:
  - 所有模型应能处理Dyck-1（有限状态足够）
  - 大模型可能处理Dyck-2到n≈3-5
  - 交叉依赖可能全部失败

  意义:
  - Dyck-2能力 → 模型内部有"栈样"机制
  - 如果只有Dyck-1 → 模型≈DFA → 组合性是统计错觉

实验3B: 嵌套从句——递归组合
  测试句子:
  - Level 1: "The cat sleeps"
  - Level 2: "The cat that the dog chases sleeps"
  - Level 3: "The cat that the dog that the mouse scares chases sleeps"
  - Level 4: 更深嵌套

  测量:
  1. 每层的R_f(l)（主语-动词一致性约束传播强度）
  2. 嵌套层级 vs 内层约束保持率
  3. 不同的continuation的KL散度

  预测:
  - 内层约束的传播强度随嵌套深度衰减
  - 衰减速率可能呈指数（Transformer的有限状态瓶颈）
  - 但续写分布等价类在低层仍然保持

实验3C: 变量绑定——动态指代
  测试句子:
  - "John said Bill likes himself" → himself = Bill
  - "Bill said John likes himself" → himself = John
  - "John said Mary likes herself" → herself = Mary

  测量:
  1. "himself/herself"位置的hidden state在不同主语下的变化
  2. 变化方向是否与主语的"绑定方向"一致
  3. 改变主语后，"himself"的续写分布如何变化

  预测:
  - "himself"的hidden state对主语敏感
  - 改变主语→"himself"的编码方向旋转→指向新的绑定对象
  - 这是"变量重绑定"的动力学实现
```

### Phase 4 [★★]: 动态变量绑定

**核心问题**: Transformer如何实现变量的创建、传递和重绑定？

```
实验4A: 变量的创建
  当模型遇到"John"时:
  1. 哪些层开始编码"John"作为变量的身份？
  2. 这个编码如何被传递到后续位置？
  3. 测量: 对"John likes"中"likes"位置的hidden state
     改变"John"→"Bill"后的KL变化

实验4B: 变量的传递
  在"The cat that the dog chases sleeps"中:
  1. "cat"的数信息如何被传递到"sleeps"？
  2. 中间的"dog chases"是否干扰这个传递？
  3. 测量: Compat(主语数, 中间从句, l)在各层的值

  预测:
  - 中间从句对主语数约束的兼容度≈0（不干扰）
  - 这就是"变量传递=等价类内运输"的直接证据

实验4C: 变量的重绑定
  在"John said Bill likes himself"中:
  1. "himself"被绑定到"Bill"而不是"John"
  2. 如果改为"John said Bill likes him" → "him"可指"John"
  3. 测量: "himself" vs "him"位置的hidden state差异
  4. 这个差异是否与"局部绑定 vs 长距离绑定"对应？

  预测:
  - "himself"的hidden state中，"Bill"的约束更强
  - "him"的hidden state中，"John"的约束更强
  - 两者在"绑定方向"上的子空间不同
```

### Phase 5 [★★]: 组合Jacobian理论

**核心问题**: Jacobian如何支持递归复用、稳定组合、干扰抑制？

```
实验5A: 组合Jacobian——递归复用
  方法:
  1. 对嵌套从句，测量内层和外层的Jacobian
  2. 检查: 内层和外层的约束传播Jacobian是否相似
  3. 如果相似 → "递归复用" = 相同的Jacobian结构被重复使用

  预测:
  - 不同嵌套层级的约束传播Jacobian有相似结构
  - 但随嵌套深度增加，Jacobian的有效秩可能下降
  - 这解释了: 递归能力有上限（Jacobian退化导致约束丢失）

实验5B: 组合Jacobian——干扰抑制
  方法:
  1. 对双重约束句，分别计算:
     J_f = ∂h_f/∂h_0（约束f的传播Jacobian）
     J_g = ∂h_g/∂h_0（约束g的传播Jacobian）
  2. 测量: J_f和J_g的准正交性
     即: J_f^T J_g ≈ 0?
  3. 如果准正交 → 约束在正交子空间中传播 → 不互相干扰

  预测:
  - 不同约束的Jacobian准正交
  - 这是组合性的Jacobian层面的数学基础

实验5C: Jacobian链的稳定性——组合等价保持
  方法:
  1. 测量: 对同一句子，从不同层开始追踪约束传播
  2. 从层l到层l+k的Jacobian链 J_{l+k}...J_l
  3. 这个链在约束方向的条件数如何随k变化？
  4. 条件数是否被控制（不会指数增长或指数衰减）？

  预测:
  - 约束方向的条件数被控制在有限范围
  - 这解释了: 约束可以穿过几十层而不丢失或爆炸
```

## 七、严格审视——本方案自身的硬伤

### 7.1 组合等价的计算困难

```
组合等价 h₁ ~_comp h₂ 要求: 对所有合法续写C, |P(C|h₁) - P(C|h₂)| < δ

这在计算上不可行:
  - 合法续写序列的数量是指数级的
  - 多步概率的估计需要多步前向传播
  - δ的选取缺乏理论依据

缓解方案:
  - 采样: 对N=1000个随机续写序列计算
  - 单步代理: 用续写分布等价（单步KL）作为组合等价的代理
  - 理论推导: 如果单步KL < ε 且Jacobian的Lipschitz常数有界 → 多步KL有界
```

### 7.2 "约束"仍然是操作定义而非理论概念

```
目前"约束"通过反事实对定义:
  f = {(s_correct, s_wrong)} 的集合

这没有回答: 约束的本质是什么？
  - 是语法规则？
  - 是统计规律？
  - 是计算图中的条件分支？
  - 是训练数据的隐含结构？

当前无法回答，但也不需要立即回答。
操作定义足够推进实验。
理论概念需要在大量实验后自然浮现。
```

### 7.3 Dyck语言测试的局限

```
Dyck语言是人工语言，与自然语言有本质区别:
  - Dyck有精确的形式定义
  - 自然语言有模糊性和例外

但Dyck测试的价值在于:
  它确定了"计算复杂度边界"
  - 如果模型连Dyck-2都处理不了
  → 它不可能有递归组合能力
  - 如果模型能处理Dyck-2到一定深度
  → 它内部一定有某种"栈样"机制
  → 寻找这个机制就是下一步

局限: Dyck能力 ≠ 自然语言能力
  模型可能用不同机制处理Dyck和自然语言
  需要额外验证
```

### 7.4 最根本的瓶颈

```
整个项目的根本瓶颈:

我们试图用"数学结构"解释"语言能力"
但:
  1. "语言能力"本身没有精确的数学定义
  2. 我们用SVA/Dyck/变量绑定作为代理
  3. 这些代理可能只触及语言能力的表面
  4. 真正的语言能力可能涉及我们尚未识别的结构

所以:
  当前所有实验都是在"盲人摸象"
  每个实验只验证了一个侧面
  只有积累了足够多的侧面
  才能拼出"语言能力"的真正形状

关键策略:
  - 不要过早锁定一个理论
  - 让数据驱动理论，不是理论驱动数据
  - 每个"矛盾"都可能是通向更深理解的入口
```
