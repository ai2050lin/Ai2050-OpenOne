## 1. 总体架构理解

### 已确认的架构功能分配

```
Transformer层的计算:
  h_{l+1} = h_l + Attn(LN(h_l)) + MLP(LN(h_l + Attn(LN(h_l))))

功能分工:
  Embedding  → 语义的初始低秩编码 (首层仅17-22%语义方差)
  Attention  → 信息路由/移动 (跨位置传输信息)
  MLP/FFN    → 概念计算/知识存储 (非线性特征变换)
  残差连接   → 信息直通管道 (95%+信息通过残差直通)
  LayerNorm  → 归一化/放大器 (特定维度可暴增130倍)
```

### 信息流全局模型 (Phase CCVIII)

```
Embedding → Attn提取token级特征(L0-10) → MLP整合context级特征(L10+) → 末层MLP输出最终预测
```

**证据强度**: ★★★★★ (三模型一致, 500对验证)

## 2. Attention 机制

### 2.1 确认的功能

| 功能 | 描述 | 证据 | Phase |
|------|------|------|-------|
| **因果汇聚** | 最后一层Attention将所有因果方向旋转到同一方向 | DS7B L27: Attn贡献94.7%, cos=+0.927 | CC, CCI |
| **信息路由** | 将信息从源位置移动到目标位置 | Attention方向反映信息流方向(非依存方向) | CCXLVII, Phase 52 |
| **语法图编码** | Attention模式中编码语法关系结构 | Bidir UAS=85-93%, 因果方向UAS=90-93% | Phase 52-55 |
| **概念保持** | Attention保持概念方向不旋转 | cosA>0 (三模型一致) | CCLXVIII |
| **token级提取** | 低层Attn提取token级信息 | Attn在低层贡献≈50% | CCVIII |

### 2.2 Attention 的因果角色

**因果贡献比例 (随深度变化)**:
```
低层 (L0-10):  Attn ≈ 50%  (token级信息提取)
中层 (L10-20): Attn ≈ 20-30% (信息路由, 对概念几乎无贡献, cos_attn≈0)
深层 (L20+):   Attn贡献恢复  (cos_attn=0.35-0.46)
末层:          Attn因果汇聚  (DS7B L27: 94.7%)
```

**关键发现 — 中层Attn对概念无贡献** (Phase CCXVI):
- L12-L18: cos_attn ≈ 0, attn_ratio ≈ 0.1
- 中层Attention在概念传播中几乎不起作用
- 概念修改主力是MLP

**证据强度**: ★★★★★ (三模型一致)

### 2.3 Attention 与语法

**最初发现 (Phase 52)**: Attention恢复语法依赖 UAS=85-93%

**后续修正 (Phase 56-57)**: 
- Per-layer hit rate < null → **Attention不直接追踪语法角色**
- 语义剥离实验: Attention编码的是**语法角色**，不是语义共现
- 伪词测试: 即使无意义的词，attention仍能分配语法关系 (UAS=1.000)
- **但**: best_rank=1指标是统计假象

**最终结论**:
- **Attention编码语法结构**: 语法关系 ≈ 信息流模式 ≈ attention分布中的结构
- **Attention不是语法计算器**: 其功能是**信息路由**，不是语法角色判定
- **编码的是"信息接收"模式**: 不是"依赖方向"
- 简单SVO中: attention ≈ 位置模板 (因为英语中位置=语法)
- 复杂结构中: attention追踪语法 (位置≠语法时仍正确)

**证据强度**: ★★★★ (有修正，但核心结论稳定)

### 2.4 Attention Head 功能

**Head因果定位** (Phase CCV):
- DS7B L27: h12→tense(0.956), h10→polarity(0.932) — "因果原子"
- 但 **L27并不特殊!** (Phase CCVI修正: L0的alignment反而最高)

**断裂层Head行为** (Phase CCLXXXXIV):
- 断裂层所有32个头几乎"翻转"方向 (cos < 0.11)
- 断裂层出现body_part专一头: H24(+0.77), H23(-0.89), H25(+0.83)
- 部分头在断裂层norm增大6-12倍

**Head特异性**:
- 存在概念特异性的门控神经元 (每类别≥200个, sel/rnd=42-98x)
- 但Mean-head严重低估语法追踪能力 — 信号在特定head中，mean会淹没

**证据强度**: ★★★ (Head级分析仍不够深入, SAE未训练)

### 2.5 未解决的问题

1. **Value向量分析未完成**: attn_weight × value_vec的实际信息流
2. **Head功能指纹**: 需要SAE分解head输出
3. **GQA模型的W_o分解不兼容**: Qwen3使用GQA, 无法直接分解
4. **Attention的精确计算机制**: 如何从权重模式到因果效应

## 3. MLP/FFN 机制

### 3.1 确认的功能

| 功能 | 描述 | 证据 | Phase |
|------|------|------|-------|
| **因果效应主贡献** | 末层MLP贡献60-80%因果效应 | 三模型一致 | CCVIII |
| **概念计算** | MLP是概念修改主力(cos_mlp=0.27-0.61) | 三模型一致 | CCXVI |
| **语义入口** | 语义MLP入口85-90% | 因果干预验证 | CCXVII-CCXIX |
| **语境整合** | MLP整合context级特征 | 与Attn的token级提取互补 | CCVIII |
| **扰动放大** | FFN贡献70-80%的扰动放大 | 三模型一致 | CCLXVIII |
| **非线性变换** | FFN>92%非线性, 线性<8%且指向反方向 | cos_linear=-0.38~-0.67 | CCLXVIII |

### 3.2 FFN 门控分解 — 核心发现

**FFN计算**:
```
FFN(h) = W_down @ [σ(W_gate @ h̃) ⊙ (W_up @ h̃)]
         \_________非线性部分_________/
```

**分解为两个成分** (Phase CCLXX):

| 成分 | 符号 | 含义 | 特性 |
|------|------|------|------|
| **增益调制** | Δg | 门控模式差异 σ(W_gate@h_A) - σ(W_gate@h_B) | 0~1连续, 在W_down零空间附近(控制空间) |
| **内容方向** | Δu | 输入差异 W_up@(h_A - h_B) | 对W_down线性可见(表示空间) |

**关键性质**:
- Δg ⊥ Δu (cos ≈ 0.04, 仅4x随机基线)
- W_down@Δg ≈ 0 (Δg对线性readout不可见, 但不是"无方向")
- 浅层: Δg主导 (swap Δg > Δu)
- 深层: Δu主导

**证据强度**: ★★★★ (三模型一致, 但缺行为级验证)

### 3.3 门控切换 — FFN概念差异的因果来源

**核心发现** (Phase CCLXIX):

| 模型 | cos_gate (门控切换) | cos_input (输入差异) | 结论 |
|------|---------------------|---------------------|------|
| Qwen3 | **+0.47** | -0.09 | 门控主导 |
| GLM4 | **+0.50** | +0.17 | 门控主导 |
| DS7B | **+0.49** | -0.12 | 门控主导 |

→ **门控切换是FFN概念差异的主导因果来源!** (三模型一致)

**门控稀疏度**: 20-35%激活(σ>0.5), Qwen3/DS7B比GLM4更稀疏

**门控距离编码** (Phase CCLXXI):
- 门控Hamming距离与残差流距离强相关: r = 0.936~0.956
- 门控Jaccard重叠与残差流余弦强相关: r = 0.909~0.935
- **门控二值距离完美保持语义距离!**
- 跨4种语义差异类型都成立 (corr=0.87-0.99)

**证据强度**: ★★★★★ (三模型一致, 因果验证)

### 3.4 W_gate 的几何结构

**高维无结构** (Phase CCLXX):
- W_gate行: top5_var仅1-1.5%, PCA(n90)>1700, 无聚类(sil<0.06)
- W_gate行与W_U行空间无对齐 (≈1.0x随机基线)
- 最后层有弱门控-输出对齐: top_cos=0.28-0.43

**概念特异性门控神经元存在**:
- 每类别≥200个, sel/rnd=42-98x
- 但选择性是**统计性**的, 不是**几何性**的

**核心洞察**: FFN的"概念选择性"不是来自W_gate行的几何结构, 而是来自:
1. **非线性激活**创造了概念选择 (不是权重几何)
2. **半空间组合**: 9728-18944个半空间{w_i·h>0}的组合编码
3. **W_down的线性读出**: 激活的神经元子集通过W_down产生不同方向输出

**证据强度**: ★★★★★

### 3.5 W_down 读出机制

**判别性列不指向概念方向** (Phase CCLXXI):
- W_down单个列不选择性指向概念W_U方向 (cos_own≈0)
- "读出"不是通过单列与W_U行对齐, 而是**组合效应**
- 最后层有少量(2-9%)W_down列与W_U行对齐(cos>0.3)

**FFN概念信号传播路径**:
```
h_A ─→ σ(W_gate@h_A) = gate_A (20-35%激活)
h_B ─→ σ(W_gate@h_B) = gate_B (不同模式)
                                ↓
FFN_A = W_down@[gate_A ⊙ (W_up@h_A)] → 指向A方向
FFN_B = W_down@[gate_B ⊙ (W_up@h_A)] → 指向B方向
                          ↑
              关键: 只需切换门控, 输入相同也能改变输出方向!
```

**证据强度**: ★★★★

### 3.6 未解决的问题

1. **Δg⊙Δu="概念信号"归因不成立**: cos来源不可拆分
2. **Swap实验缺行为级验证**: 需要检查token概率/logit变化
3. **n90未收敛**: 64-256词仍然不稳定
4. **"控制空间 vs 表示空间"还不成立**: 未多readout验证
5. **MLP内部的因果机制**: 神经元级? 特征方向级? SAE未训练

## 4. 残差流 (Residual Stream)

### 4.1 核心功能: 信息直通管道

**95%+信息通过残差连接直通** (Phase CCXV):
- cos(d_l, d_{l+1}) = 0.82~0.97 → 绝大部分信息直接通过
- 概念传播 = 残差直通(I) + 非线性转导(Attn/MLP)

**概念传播模型** (Phase CCXVII):
```
h_{l+1} = h_l + Δ_attn + Δ_mlp

概念传播路径:
  路径1 (直通): h_l → h_{l+1} (95%+信息)
  路径2 (Attn): h_l → Attn → Δ_attn → h_{l+1} (信息路由)
  路径3 (MLP):  h_l → MLP → Δ_mlp → h_{l+1}  (概念计算)
```

**概念漂移半衰期**: 约12层 (cos从0.93降到0.57)

**证据强度**: ★★★★★

### 4.2 残差高速公路模型 (Phase CCXLV)

**浅层perturbation传播优势**:
- 浅层perturbation像在河源头滴入墨水 — 沿主干流(残差直通)传播
- 深层perturbation只有很短的残差直通路径, 非线性压缩占主导

```
浅层perturbation: delta_output ≈ delta_h_L1 + 累积非线性修正 (直通路径长)
深层perturbation: delta_output ≈ delta_h_L1 * product(J_l)  (直通路径短)
```

**证据强度**: ★★★★ (经过多次修正, 最终确认)

### 4.3 暗物质空间

**定义**: 残差流中不在W_U行空间和W_E行空间中的86-92%分量

**核心发现** (Phase CCXVII):
- 暗物质占77-85%: 概念方向的绝大部分不在输出/嵌入空间中
- 暗物质不是噪声: 概念的暗物质比例(77-85%)**低于**随机(84.6%)
- **暗物质贡献了75-87%的steering效果!** — 它是概念传播的真正载体
- W_U-only steering几乎无效 (eff=0.01-0.09)

**暗物质的转导机制** (Phase CCXVIII):
```
暗物质注入 → 每层被Attn/MLP转导约1-2%进W_U空间 → 逐步"照亮"
暗物质方向保持性: cos(dark_injected, delta_at_k) = 0.83→0.61
```

**暗物质在中间层最浓**: L12-L18的residual最高(80-83%)

**暗物质在Attn/MLP空间中只有1-13%** — 大部分暗物质不在任何已知子空间中

**证据强度**: ★★★★★

## 5. LayerNorm

- 每层归一化约束残差流norm

LN weight异常(Dim4暴增11.6x)

**证据强度**: ★★★★★ (Qwen3完整因果链)

### 6.2 Attn vs MLP 的因果贡献分解

### 6.3 语法 vs 语义的组件差异

**语法因果动力学** — 积分算子:
```
C_syn(l) = a·l^b + c  (b<1, 幂律增长)
语法效应逐层累积, 主要由MLP贡献
语法因果效应 = Σ MLP_k的贡献
```

**语义因果动力学** — 投影算子:
```
C_sem(l) = C₀  (几乎恒定)
语义效应由首层Embedding直接编码, 不需要MLP累积
语义 = embedding层的投影
```

**语法/语义子空间完全正交** (Phase CCXIV): cross_overlap = 0.000

**证据强度**: ★★★★★

### 8.2 暗物质的转导机制

```
暗物质注入 (init_WU=0.0)
  → 每层被Attn/MLP转导约1-2%进W_U空间
  → 逐步"照亮"
  → W_U投影比逐层增长
  → 暗物质方向保持性: cos=0.83→0.61
```

**暗物质不是噪声** — 它是概念传播的真正载体:
- 比喻: W_U分量像可见光(直接检测), 暗物质像红外光
- 不同颜色的光(暗物质)通过棱镜(Attn/MLP)折射后产生更强信号
- 转导是关键: 没有转导, 暗物质无法影响输出

## 9. 语法 vs 语义的分离

### 9.1 功能差异

| 维度 | 语法 | 语义 |
|------|------|------|
| **因果动力学** | 积分算子 (逐层累积) | 投影算子 (首层直接编码) |
| **效应公式** | C_syn(l) = a·l^b+c (b<1) | C_sem(l) = C₀ (恒定) |
| **主贡献者** | MLP (逐层累积) | Embedding (首层投影) |
| **子空间** | 与语义完全正交 (cross_overlap=0.000) | — |
| **特征数** | 8个 (tense, polarity, number等) | 4个 (sentiment, topic等) |
| **位置耦合** | 英语中强耦合 (位置=语法) | 无位置耦合 |

### 9.2 Activation Patching 因果验证 (Phase 59)

**★★★ 语法信息确实存在且被使用! ★★★**
- Subject patch → 62-87%动词改变
- 语法信息与位置强耦合 (英语特有)
- 语法信息部分非线性编码 (MLP probe > Linear probe)

**但**: 跨位置patching效果快速衰减 (0-25%) — 位置锚定问题

### 9.3 语言数学结构假说 (Phase 59)

```
语言能力 ≠ 语法规则系统
语言能力 = 多层近似策略的竞争系统

P(next_token) 由以下策略混合决定:
1. 位置模板: P_pos(token|position) — 统计捷径
2. 局部共现: P_ngram(token|n-1 tokens) — 局部模式  
3. 结构路由: P_struct(token|attention_routed_info) — 信息流
4. 隐式语法: P_syntax(token|role_representation) — 分布式编码

权重(英语): 1 >> 2 > 3 > 4
但4虽然权重最小, 却是:
- 长距离依赖的关键差异化因素
- 跨语言可迁移的核心
- 最接近"理解"的部分
```

**证据强度**: ★★★★ (有因果验证, 但受英语位置耦合限制)
