## 零、范式转变：从"状态分析"到"商空间动力学"

### 0.1 三轮批评的共识演进

| 轮次 | 核心观点 | 新增认知 |
|------|---------|---------|
| 第一轮 | 必须从现象转向必要性 | "描述≠解释" |
| 第二轮 | Phase 213 vs 146矛盾需要解决；R指标需精确定义 | "H2需修正为H2'" |
| 第三轮 | 矛盾本身就是核心洞察——商空间动力学 | "等价保持运输" |

### 0.2 关键范式转变

```
旧范式（Phase 20-212）:
  问题: "语言信息在模型中如何编码？"
  方法: 分析hidden state、方向、算子
  假设: 语言信息被"存储"在某个子空间

新范式（Phase 215+）:
  问题: "什么动力学结构足以支持语言能力？"
  方法: 研究商空间 H/∼ 上的动力学
  假设: 语言能力存在于"输出等价类的保持和约束传播"
```

### 0.3 为什么这个范式转变是必要的

**Phase 146的实验数据直接支撑新范式**：

1. 扰动被放大2-5倍（状态发散）→ 状态不稳定
2. 但logits相关>0.995（输出稳定）→ 输出等价类稳定
3. 88%扰动能量在W_U的null space → 大量内部自由度
4. 扰动方向被大幅旋转（cos→0.01）→ 坐标系不断变化
5. 但输出仍稳定 → 旋转被限制在等价类内

**结论**：语言能力不在h_l中，而在等价类[h_l] = {h : W_U h ≈ W_U h_l}中。

## 一、商空间动力学的数学框架

### 1.1 核心定义

```
定义1: 输出等价关系
  h₁ ~ h₂ ⟺ argmax(W_U h₁) = argmax(W_U h₂)
  
  即: 两个hidden state等价 ⟺ 它们产生相同的top-1预测

定义2: 商空间
  H/~ = {等价类[h] : h ∈ H}
  
  即: 所有产生相同输出的hidden state的集合

定义3: 约束子空间
  对语言特征f（如number=sg），定义约束子空间：
  V_f = {h ∈ H : C_f(h) 被满足}
  
  其中 C_f 是约束条件（如"动词与主语数一致"）
```

### 1.2 为什么商空间是正确的框架

**它统一解释了所有之前的"矛盾"发现**：

| 现象 | 旧框架困惑 | 商空间解释 |
|------|-----------|-----------|
| 状态发散但输出稳定 | "矛盾！" | 等价类内自由运动 |
| 0收敛层 | "模型不修复" | 修复在等价类层面，不在状态层面 |
| 正交旋转巨大 | "信息被破坏" | 旋转在等价类内，输出不变 |
| 不同模型Jacobian差异大 | "没有统一结构" | 不同内部运输，相同等价类保持 |
| 深层扰动非特异性 | "脆弱平衡" | 接近等价类边界，任何扰动可能跨边界 |
| 88%能量在null space | "信息浪费" | null space = 等价类的"内部方向" |

### 1.3 商空间上的动力学

```
Transformer在H上的动力学:
  h_{l+1} = h_l + F_l(h_l)

在H/~上的诱导动力学:
  [h_{l+1}] = [h_l + F_l(h_l)]

关键性质: 如果F_l是"等价类保持的"，则:
  [h_{l+1}] = [h_l]  (等价类不变)

等价类保持的条件:
  W_U F_l(h_l) ≈ 0  (更新不改变输出)

实际观察:
  88%的Δh能量在W_U的null space中
  → 大部分更新确实是"等价类内的"
  → 只有~12%的更新能量影响输出

这就是语言能力的数学本质！
  模型学会了"在等价类内传播约束"
  而不是"在固定方向上传播信息"
```

## 二、约束的重新定义——从"存储特征"到"兼容律"

### 2.1 旧定义的问题

Phase 215定义约束算子为投影：
```
C_f(h) = ||P_{V_f} h|| / ||h||
```

这仍然假设约束是"存储在某个子空间中的特征"。

### 2.2 新定义：约束作为状态转移的兼容条件

```
定义: 约束f在层l的兼容条件

对于语言约束f（如"主谓一致"），定义:

Compat_f(l) = { (h, h') ∈ H×H : 
  h' = h + F_l(h),
  且 h' 的输出与 f 一致
}

即: 约束不是"存储在h中的信息"
而是: "从h出发，经过F_l更新后，输出仍满足f"

这是动态兼容律，不是静态存储！
```

### 2.3 新旧定义的关系

```
旧定义: "主语位置存了'数'信息" → h_s有数特征方向
新定义: "从主语位置出发的更新，兼容动词位置的数约束" → 状态转移被约束

关键区别:
  旧: 信息 → 存储 → 读取 → 使用
  新: 约束 → 兼容 → 传播 → 保持

新定义更深刻，因为:
  1. 它解释了为什么Value向量比注意力权重更关键
     (Value是"更新内容"，权重是"路由选择")
  2. 它解释了为什么MLP比Attention更关键
     (MLP决定更新是否"兼容约束")
  3. 它解释了为什么约束可以组合
     (多个兼容条件可以同时满足，如果它们在等价类内正交)
```

## 三、实验方案——五个阶段

### Phase A: 架构vs语言分离 [★★★ 最高优先级]

**核心问题**: 我们发现的所有结构，是语言的还是架构的？

**实验A1: 随机权重对照——约束方向放大**

```
方法:
1. 加载随机初始化的Qwen3（不训练）
2. 输入"cat chases" vs "cats chase"
3. 测量每层Δh_l = h_l(pl) - h_l(sg)的演化
4. 与Phase 147已有数据（随机方向扰动）对比
5. 与训练模型数据（Phase 213）对比

关键对比:
  训练模型的"数方向放大" vs 随机模型的"数方向放大"

Phase 147已发现:
  随机模型: L0→L27扰动增长223倍（随机方向）
  训练模型: L0→L27扰动增长4.5倍（随机方向）

但！这是"随机方向扰动"，不是"数方向扰动"！

预期:
  情况1: 训练模型的数方向放大 >> 随机模型的数方向放大
    → 数方向放大是训练习得的语言结构
    
  情况2: 两者相似
    → 数方向放大是架构的数学必然
    → 需要寻找其他语言特异性结构
    
  情况3: 随机模型的数方向放大 > 训练模型
    → 训练实际上"抑制"了数方向放大
    → 支持商空间假说（训练使更新更集中在等价类内）
```

**实验A2: 随机权重对照——等价类结构**

```
方法:
1. 对随机Qwen3和训练Qwen3
2. 注入同量级扰动（随机方向和数方向）
3. 测量输出等价类保持率
4. 对比两者的null space比例

预期:
  训练模型: 88%扰动能量在null space → 强等价类保持
  随机模型: 可能<50%在null space → 弱等价类保持
  
  如果确认:
  → "等价类保持"是训练习得的语言特异性结构
  → 这是整个项目的基石发现
```

**实验A3: 随机权重对照——JVP/旋转**

```
方法:
1. 对随机Qwen3，重复Phase 213的EXP3（JVP分析）
2. 对比JVP类型分布

预期:
  随机模型可能也有大量"旋转"（因为残差+LayerNorm天然产生近正交变换）
  如果随机模型的旋转比例 ≈ 训练模型:
  → "旋转"不是语言结构，是架构先验
  → 需要寻找旋转中的语言特异性成分
```

### Phase B: 输出等价类动力学 [★★★]

**核心问题**: 等价类的几何和动力学结构是什么？

**实验B1: 等价类几何**

```
方法:
1. 对一个固定输入，生成N个不同扰动版本{h^1, h^2, ..., h^N}
2. 对每个h^i，前向传播得到最终层h_L^i
3. 计算W_U h_L^i，检查是否在同一个等价类中
4. 分析等价类的几何：
   - 等价类的"宽度"（内部自由度有多大？）
   - 等价类的"边界"（什么扰动会跨越等价类？）
   - 等价类的"纤维结构"（null space vs row space方向）

预期:
  等价类是"厚"的——内部有巨大自由度
  但等价类边界是"薄"的——小扰动可能跨边界
```

**实验B2: 约束方向在等价类中的位置**

```
核心问题: "数方向"是在等价类内（null space方向）还是在等价类间（row space方向）？

方法:
1. 计算"数方向"v_num = h(sg) - h(pl)
2. 计算v_num在W_U的row space和null space中的分量
3. 如果v_num主要在null space:
   → 数差异不影响输出??（与SVA存在矛盾）
4. 如果v_num主要在row space:
   → 数差异确实影响输出（与SVA一致）

预期:
  数方向主要在row space → 约束是"等价类间的"
  但约束传播的"更新"主要在null space → 更新在等价类内
  
  这就是关键：
  约束方向跨越等价类（改变输出）
  但约束传播的运输在等价类内（不破坏其他约束）
```

**实验B3: 语法扰动 vs 随机扰动的等价类行为**

```
核心问题: 为什么随机扰动被路由到null space，但语法扰动改变输出？

方法:
1. 注入随机方向扰动 → 测量row space能量比
2. 注入语法错误方向扰动 → 测量row space能量比
3. 对比两者

预期:
  随机扰动: ~12%在row space → 大部分在null space → 输出不变
  语法扰动: >50%在row space → 大部分影响输出 → 输出改变

  如果确认:
  → 模型学会了"把约束方向对齐到row space"
  → 这是语言编码的核心机制！
```

### Phase C: 约束运输机制 [★★★]

**核心问题**: 约束如何在等价类间传播？

**实验C1: Value向量约束编码**

```
方法:
1. 对"The cat chases" vs "The cats chase"
2. 在每层提取主语位置的Value向量V_j
3. 测量V_j^{sg} vs V_j^{pl}的差异
4. 测量V_j差异在W_U的row space vs null space中的分布

预期:
  早层V_j差异主要在null space（数信息被编码，但不直接决定输出）
  晚层V_j差异主要在row space（数信息被转化为动词选择）

  这就是"约束运输"的精确机制:
  早层: 约束在等价类内编码（null space方向）
  晚层: 约束被"推"到等价类间（row space方向）
  中间层: 约束在null space和row space之间"摆渡"
```

**实验C2: 多约束正交性测试**

```
核心问题: 多个约束是否在正交方向上传播？

方法:
1. 构造双重约束句: "The cat that the dogs chased sleeps"
   - 约束1: cat ↔ sleeps (sg)
   - 约束2: dogs ↔ chased (pl)
2. 提取两个约束方向的向量
3. 测量cos(v_constraint1, v_constraint2)
4. 如果≈0 → 约束正交 → 可独立传播
5. 如果≠0 → 约束耦合 → 可能互相干扰

预期:
  约束方向准正交（cos < 0.3）
  → 多约束可以独立传播
  → 这是组合性的数学基础
```

**实验C3: 约束传播的等价类保持性**

```
核心问题: 约束传播是否破坏其他约束？

方法:
1. 双重约束句（同C2）
2. 注入"数方向"扰动（改变约束1的值）
3. 测量约束2是否被破坏
4. 如果否 → 约束1的传播不影响约束2 → 等价类保持

预期:
  约束1的改变不破坏约束2
  → 多约束在"近似正交"的子空间中传播
  → 商空间允许"独立约束传播"
```

### Phase D: 必要性破坏实验 [★★]

**实验D1: MLP门控必要性**

```
方法: 在推理时将MLP的⊙改为+
  原始: Δh_mlp = W_down · σ(W_gate · h ⊙ W_up · h)
  修改: Δh_mlp = W_down · σ(W_gate · h + W_up · h)

测试:
  - SVA准确率变化
  - 长距离依赖变化
  - 输出等价类保持率变化

关键: 这个修改保留了MLP的"放大"能力，但去除了"条件计算"能力
如果SVA崩溃 → 条件计算对语言能力必要
如果SVA不崩溃 → 条件计算不必要（加法组合足够）
```

**实验D2: 旋转必要性**

```
方法: 间接测试——比较不同旋转策略的模型的等价类结构

不是直接"禁止旋转"（计算上不可行），而是:
  对比DS7B（全旋转）vs GLM4（全保持）的等价类几何
  如果两者等价类结构相似 → 旋转策略不重要
  如果两者等价类结构不同 → 旋转策略重要

关键指标:
  - null space比例
  - 约束方向在row space的比例
  - 等价类"宽度"
```

### Phase E: 计算复杂度边界 [★★]

**实验E1: Dyck语言**

```
测试1: a^n b^n (Dyck-1, 需要计数 → DFA之上)
测试2: (^n )^n (Dyck-2, 需要栈 → PDA)
测试3: 嵌套3层中心嵌入从句（需要递归栈）

对每个测试:
  - 模型能否正确匹配？
  - 如果能: 在哪个层开始正确？
  - 准确率随n如何衰减？

关键: 这确定了"语言能力的计算复杂度上界"
如果模型只能处理Dyck-1 → 模型≈DFA
如果模型能处理Dyck-2 → 模型有"栈样"结构
```

**实验E2: 从复杂度反推必要结构**

```
如果E1发现模型能处理Dyck-2:
  → 模型必须实现了某种"栈样"机制
  → 寻找: 哪些层/head在模拟栈的push/pop？

如果E1发现模型只能处理Dyck-1:
  → 模型是有限状态机
  → SVA的机制只是"状态转移"
  → 组合性只是统计错觉

这是唯一能真正建立"必要性"的路线:
  如果语言需要X复杂度，且模型实现了X
  → X是必要的
```

## 四、理论终点——商空间动力学假说

### 4.1 核心假说

> **语言能力 = 约束兼容的等价类运输**
>
> Transformer的语言能力来自:
> 1. 在输出等价类内拥有巨大的内部自由度
> 2. 约束可以在等价类间传播（改变输出）
> 3. 约束传播不破坏等价类结构（不干扰其他约束）
> 4. 多约束可以在准正交子空间中独立传播（组合性）

### 4.2 数学形式化

```
设 H 为hidden state空间
设 ~ 为输出等价关系
设 H/~ 为商空间
设 π: H → H/~ 为自然投影

约束传播在商空间上:
  如果 f 是语言约束，则 f 定义了H/~的一个划分:
  {H/_f=满足} ∪ {H/_f=违反}

语言能力 ⟺:
  1. 等价类是"厚"的（内部有足够自由度）
  2. 约束可以把状态从一个等价类"推"到另一个
  3. 这种"推"不破坏其他约束（在准正交方向上）
  4. 多个约束可以同时被满足（交集非空）
```

### 4.3 与之前所有发现的关系

```
Phase 146 (输出等价类稳定):
  → 证实了"等价类是厚的"
  → 88%能量在null space = 等价类的内部维度

Phase 147 (随机权重对照):
  → 临界传播和null space路由是训练效应
  → 训练学会了"等价类保持运输"

Phase 209 (探针伪影):
  → "可恢复≠被使用" = "信息在等价类内不意味着被使用"

Phase 210-212 (MLP条件判断):
  → MLP的"条件计算" = "把约束从等价类内推到等价类间"
  → Attention的"路由" = "选择哪些位置的约束需要被传播"

Phase 213 (0收敛层):
  → 模型不修复"错误等价类" → 它只是"选择正确的等价类"
  → 不是吸引子修复，而是等价类选择

Phase 172 (正交旋转):
  → 旋转在等价类内 → 不影响输出
  → 但旋转实现了约束的"重新编码"
```

### 4.4 可证伪条件

```
如果商空间动力学假说成立，则:
  1. 随机权重模型的等价类"薄"（null space比例<50%）
     → 训练使等价类"变厚"
  2. 约束方向在row space中的比例 > 随机方向
     → 模型学会了把约束对齐到输出影响方向
  3. 多约束方向准正交
     → 约束可以独立传播
  4. MLP门控破坏 → 约束传播崩溃 → 但输出等价类保持可能仍在
     → MLP是"约束运输器"，不是"等价类保持器"

如果以上任何一个不成立:
  → 商空间动力学假说需要修正或推翻
```

### 4.5 可预测的定量预测

```
预测1: null space比例与模型语言能力正相关
  - 更好的模型 → 更大的null space比例
  - 因为更大的null space → 更厚的等价类 → 更稳定的语言处理

预测2: 约束方向的row space比例与SVA准确率正相关
  - 更高的row space对齐 → 更强的约束传播 → 更好的SVA

预测3: MLP门控破坏的影响:
  - SVA准确率下降，但"输出等价类稳定性"可能不受影响
  - 因为门控影响约束传播，不影响等价类结构

预测4: 在新模型（如LLaMA）上:
  - 如果模型能做SVA → 应该有类似的null space比例
  - 如果模型不能做SVA → null space比例可能更低
```

## 六、最严格的审视——这个方案本身有什么问题

### 6.1 商空间概念的操作化问题

"输出等价类"的定义依赖于argmax(W_U h)，但：
- argmax是离散的，不便于梯度分析
- 需要更连续的定义（如"top-k重叠率>阈值"）
- 阈值的选择可能影响结论

### 6.2 null space分析的二值化问题

"88%能量在null space"听起来很清晰，但：
- null space的定义依赖于W_U的数值精度
- W_U本身有噪声（训练不完全收敛）
- 需要定义"有效null space"（如"奇异值<ε的方向"）

### 6.3 "约束方向在row space中"可能过于简单

如果约束方向完全在row space中：
- 那约束传播一定影响输出
- 但Phase 146发现随机扰动只有12%在row space中
- 约束方向可能既不完全在row space也不完全在null space
- 而是在两者之间的"灰色地带"

### 6.4 因果推断的根本困难

即使用随机权重对照区分了"训练效应vs架构效应"：
- 仍然无法区分"因果必要"和"相关性"
- Ablation实验（D1-D2）可以证明"破坏X→能力下降"
- 但不能证明"X是唯一的必要条件"
- 可能存在"冗余必要条件"（多个机制都能实现同一功能）

### 6.5 "约束作为兼容律"仍然缺乏操作性

新定义"Compat_f(l) = 满足f的状态转移集合"在概念上更深刻，
但如何测量"一个状态转移是否兼容f"？
需要先知道f在h_l中的"编码方式"——又回到了"约束编码在哪里"的问题。
