## 一、把"破解"翻译成可判定问题

### 1.1 问题的形式化

模型在训后由参数 θ 固定。所谓"语言能力"，观测上是：对任意上下文 c，θ 决定条件分布 P(next | c; θ)，且这个映射在未见组合上保持一致（修改、翻译、重构、语法合式）。**破解 θ** 的可判定定义：

> 找到显式结构描述 S(θ)（有限条规则/算子/坐标群的清单），使得
> ①（预测）对未见上下文 c*，S 能预测内部状态序列 H(c*) 或输出分布 P(·|c*)，误差优于零变化基线且跨模型复现；
> ②（干预）按 S 的坐标群做定向消融/交换/移植，行为改变与 S 的预测一致；
> ③（移植）把 S 标注的参数子集映射到另一模型对应位置后，功能至少族内保持。

三条判据递进：预测→干预→移植。当前项目状态：①在**整体拟合**层面部分达成（冻结提取器），但在**配对变化**层面失败（2744 终审）；②③尚未开始。因此本方案的主轴是把①升级到关系层面，再打开②③。

### 1.2 为什么"同样参数、不同输入产生不同结果"是结构必然——已有拼图已给出答案的形状

这不是待解之谜，而是已被 43 项拼图锁定的机制形态：

1. **参数存的是"映射的生成规则"，不是映射表**。拼图 #3（Phase 2725）：每个 MLP 块是条件算子 K(x)=Wd·diag(SiLU(Wg·x))·Wu——门向量 g=Wg·x 是输入实时计算的"开关配置"。参数（Wg）存储的是**开关的划分方式**，输入决定本轮开哪些。同一参数 + 不同输入 → 不同门配置 → 不同有效算子。这就是"参数极为特殊"的机制本体：**参数编码的是条件化的基，不是条件化的结果**。
2. **注意力是地址-内容路由，且逐 token 原子化**。拼图（2537–2549 token-atomic QKV、2687–2690 逐标量路由、2740 来源分配账本 #27/#33）：每个 query 从 KV 中按"来源坐标群"提取信息，Q/K/V 的单参数都有内生归一化路由角色。参数在此编码的是**寻址结构**（哪些来源坐标群对哪些输出坐标群有向连通）。
3. **语言能力是分族分层的，不是均匀场**。Phase 2744 C002：attribute_binding 分离度 0.999986（32/32），knowledge_chain ≈1.4e-8（0/32），中间档（negation_scope 0.579、word_sense 0.544、long_distance_role 0.300）。同一段参数里，不同语言功能由**不同的坐标群联盟**承担。
4. **修改/翻译/重构 = 读出-写回循环上的算子复合**。拼图（2729–2739 自身历史写回、2732 共享 head 句法组合、2738 双语来源-写回账本）：自回归把上一轮输出写回为下一轮输入，"翻译"是跨语言族共享响应（2235 拼图#2）+ 族残差的读出循环；"重构"是条件化算子在写回历史上的迭代复合。

**结论**：要提取的不是一张"知识网络图"，而是 **(来源坐标群 × 门控单元 × 输出坐标群) 的条件算子族清单**，外加每个关系族在层深度上的接入时刻表。这正是下面管线的提取对象。

## 二、当前最优机制图景（从 43 拼图综合的"语言编码假说"）

| 层段 | 功能 | 证据拼图 | 置信 |
| --- | --- | --- | --- |

| 中间层 | 条件算子族执行组合/绑定：门控乘积、关系×值交互、全参数梯度账本 | 2725、2727–2728、2733、2735 | 高 |

## 三、五层提取管线

> 与梳理报告 A–E 路线一一对应并展开。L1/L2 零新 GPU 成本（用已交付 12.15GB 数据）；L3 需一次小型准入；L4/L5 中期。

### L1 算子级提取：配对变化（Δ）预测器 ＝ 路线 A

- **对象**：2744 的 160 对严格词袋配对（同 token 多重集、关系相反），全部已在 `identifiability/analysis/pair_change_control.json`。
- **改造**：训练目标 MSE(ĥ,h) → **MSE(Δĥ,Δh)**；输入特征改为三类差分：来源 KV 差、role-交换坐标差、query-alone 嵌入差（2743 四列诊断已备好前三列）。
- **新增关键设计**：**关系族作为一阶变量**——按 5 族分别拟合、分别报留出成绩。假说：Δ 算子在 attribute_binding 族可提取（分离度≈1 的族必有可预测的算子），在 knowledge_chain 族失败会给出"链式知识不驻留在末端向量"的定位信息。
- **判据**：冻结协议 + 双重留出 + 零变化基线 E_0（公式 #38'）。任一族胜过基线 = 第一张"条件算子"实图。

### L2 分族解剖：关系族 × 层深度 × 坐标群三维地图 ＝ 路线 B

- **设计**：attribute_binding（分离度≈1）与 knowledge_chain（≈0）同预算对照采集，逐层计算分离度曲线，定位分离在哪些层/坐标群出现。
- **对接**：若属性绑定呈"早层 V 写入 + 晚层读出"（2568–2578、2519 预言的形状），而知识链无独立关系槽位——则确认知识链的载体在**别处**：候选为 Q 侧构造（L3）或分布式坐标群（无单方向）。
- **产出**：第一张真图 = 三维地图（族 × 层 × 坐标群）。**这是"破解语言编码"的主体交付物**。
- **成本**：直接复用 2740 已交付的百万查询末端坐标 + 12.15GB 数据，零新采集即可出初版。

### L3 query 构造算子：先导 → 完整阶段 ＝ 路线 C

- **理由**：2743 诊断显示观察到查询自身 H12 可再降 MSE 0.50，是剩余误差最大已知来源；"问什么"本身是被语境构造的，这是自回归语言能力（修改/翻译/重构的指令跟随）的核心。
- **先导**（≈900 秒 / 57MB，两资源门均可过）：32 表达 × 20 query × 3 模型，只采 Q 坐标 + block0–12 来源 attention。验证"query-alone H13 + 前缀规则"能否预测接入后的实际 Q 偏移（2743 四列诊断的因果化）。
- **升级条件**：先导出现可预测 Q 偏移的坐标群后，再申请 320×100×3 完整阶段（45,188 秒 / 2.85GB）。

### L4 语法系统专项：组合性探针（新增，原 A–E 未覆盖）

- **动机**：语法 = 无限组合能力（E1 已证有硬边界，但那是训练域约束充分性的反证，不是机制测量）。中间档族 long_distance_role（0.300）恰是语法机制的钥匙——既非完美槽位也非无分离。
- **设计**：嵌套/递归/长程配对探针（中心嵌套、跨从句角色、词序最小对），对接 2415–2421 一步/两步严格配对组合算子与 2732 共享 head 句法组合确认。
- **判据**：语法能力的提取成功 = 找到一组坐标群，其消融特异性破坏嵌套/长程结构而保留局部合式（双重分离），且分离模式跨语言族共享（2235 族共享响应）。

### L5 参数级白盒化终局：移植判据（新增，"破解"的终点）

- **动机**：L1–L4 产出的是"坐标群地图"；破解的最终判据是把地图**反向映射到权重标量子集**并证明可移植。
- **工具已备**：2687–2690 Wq/Wk/Wv 逐标量路由、2737 参数内容/格式非正交梯度账本（74,711,040 参数、192 方向全因子 ridge）、2733 双线性 Gram 与全参数梯度 span。
- **操作**：①对每个已定位坐标群，用梯度账本回溯到权重标量子集；②做三类干预：冻结（应无损）、交换/置乱（应按地图预测的方式破坏）、跨模型移植（同族模型间映射坐标群对应权重块，功能保持）。
- **判据**：移植后功能保持 = S(θ) 不是描述性拟合而是真正的机制提取。**这一步通过，"有限参数如何具备语言能力"问题即闭合**——答案将是：语言能力 = 坐标群化的条件算子族 + 寻址路由 + 写回循环，其中每族算子的参数子集可被命名、移动和复用。

## 五、风险与诚实边界

1. 项目终审结论保留：截至 2744 **没有一个能解释知识、推理和语法无限组合能力的普遍闭合结构**。本方案是通往该结构的路线，不是已成立的理论。
2. 最大风险在 knowledge_chain 族：若 L1/L2/L3 三路均无法提取链式知识，则需接受"链式知识分布在无单坐标群对应的广域参数中"，L5 的移植判据对该族退化为统计可移植（分布级而非坐标级）。
3. 两条已证不可能的依赖要永远避开：位置规则词ID不变式（2719）、来源矩环境单射（2739/#22/#29）。
4. 校准混杂（2744 C004）提醒一切"训练收益"类结论必须先过位移匹配（路线 D），L5 的干预判据天然免疫此混杂。
