# AI2050 语言编码机制研究总结与下一阶段计划

截至 2026-11-17，GLM5 Phase 2955。本文汇总已执行的主要研究路线、证据边界和下一阶段设计。运行、数据和发布的验收分别记录。

## 当前判断

目前最明确的进展，是在受控语言任务中把**形成内容、保存状态、后继寻址、写入下游和作答**拆成了可检验的过程。原生 MLP 的固定参数随输入条件写出不同结果。自回归时，模型已生成的 token 会形成后续可访问的 K/V。同一份 State K/V 也能因后继查询与其他来源不同而产生不同作用。在少数任务中，阻断与原生恢复可以逐例改变实际作答。

总体瓶颈是**留出预测**。当前能解释若干已观察到的局部路径，但还缺一种预算受限的算法，能从未见文本和合法的早期状态预测它会选什么、怎么更新、随后读哪个来源、最终输出分布如何变化。历史 558,080 份去重后的原生档案是索引与数据覆盖量。破解程度以留出预测、因果效应、失效范围和跨模型复算衡量，当前没有可报告的全局破解百分比。

## 最新阶段回答了什么

- **2952** 在固定提示和生成 State 条件下测定一段指定中性插入的作用。寻址与写入的原生等幅检验在该范围内通过。两个并行头的联合恢复另有证据，而其单独等幅主检验未过。
- **2954** 进一步检验提示事实、实发 State、码本、距离和 Note 竞争。原方案的新句式行为失败，修订句式在独立家族另测。加入较早原生信息的寻址预测和加入原生响应的干预改码预测均未达到冻结门槛。两块可评估面板上，改码的文本加干净边际基线 Brier 分数为 0.02281、0.01395，原生增强分别为 0.02543、0.03085。
- **2955** 的 828 个合格插入视图中，Receipt 的注意力总量没有超过 State，最高比值 0.653。新句式 32/576 次实际改码来自 4 个反角色家族，方向均为原事实码转至实发 State 码。新词合格自然 State 视图 0/252。新词反角色条件只有 27/32 个完整家族通过，低于 85% 行为准入，64 个诊断翻转保留在相应观测范围。
- **2955 的因果细化**。新句式的 31 个技术对齐改码视图中，清零 H18 读取的 State Value 后 20 个回原码。联合清零后回原码的 17 个视图，单独恢复 State 后全部重新发出插入码。Receipt 的单独阻断没有使这些改码回到原码。新句式 Receipt 的等幅剂量通过，但目标相对随机头的预注册效应没有通过。新词的两类剂量均超过 P95≤3% 门槛。State 恢复提供同路径证据，尚缺 State 的等幅头间比较。

通俗地说，模型可以把同一个词留在同一个位置，后来在答题时却以不同程度用到它。当两个候选答案原本接近时，这种变化可以翻转首选。Phase 2955 改码组的零插入胜者分差中位数为 1.25，保持组为 11.50。这是本任务中可继续检验的线索。预测的正例只来自少数家族，不能用视图数代替独立样本数。

## RDC 和三图谱的数学接口

保留 Phase 2747 的条件化输出场闭合理论（RDC）接口。设 \(p\) 为可见前缀，\(\mathcal L(p)\) 为有类型的外部语言记录，\(\mathcal X_\ell(p)=\{H_{\ell,t,j}(p)\}\) 为按生成位置与坐标组织的状态场，\(\boldsymbol W_\ell(p)\) 为受检域内的析因响应束，\(\tau\) 为条件，\(\mathcal D\) 为适用域。

$$
\mathcal T^{\mathcal D}_{\ell,\tau}:
\bigl(\mathcal L(p),\,\boldsymbol W_\ell(p),\,\mathcal X_\ell(p)\bigr)
\rightharpoonup \boldsymbol W_{\ell+1}(p).
$$

$$
\operatorname{Atlas}_{\mathcal D}=(G_{\rm external},G_{\rm internal},E_{\rm association}^{\mathcal D}).
$$

外部图节点保留文本跨度、含义、关系、角色和结构。内部节点用「模型快照、运行、前缀、生成步、层、位置、原生索引、读出边界」寻址。关联边带有条件、算法、输入权限、拟合划分、留出预测、证据状态和反例。阶段进展通过同一留出材料上的内部响应、完整词表输出与因果预测分别度量。

当前可精确核对的原生计算包括

$$
x=N(r),\quad g=W_gx,\quad u=W_ux,\quad y=W_d[\operatorname{SiLU}(g)\odot u],\quad
p_\theta(\cdot\mid p)=\operatorname{softmax}(W_U N_f(H_L)_{\mathrm{query}}).
$$

单元 \(j\) 写入残差坐标 \(k\) 的一项为 \(W_{d,kj}\operatorname{SiLU}(g_j)u_j\)。它把输入条件、单单元和单标量参数关联到同一可复核的量。注意力侧，\(s_i=q^\top k_i/\sqrt{d_h}\)，\(a=\operatorname{softmax}(s)\)，头写入为 \(W_O^h\sum_i a_i v_i\)。指定源组 \(R\) 相对 State 单位置 \(G\) 的读出是

$$
D=\log \frac{\sum_{i\in R}a_i}{a_G}
=\log|R|+\log\bigl(\operatorname{mean}_{i\in R} e^{s_i}\bigr)-s_G .
$$

\(\log |R|\) 为精确数量项。其余项合并了位置、匹配与组内分布，仍需因果设计区分。上述是架构计算和测量定义。当前 RDC 进展是这些定义在部分任务中受到更强的实验约束，尚无新的统一数学定律。第一性原理的候选命题是：有限参数的可组合语言行为可以由可复用内容写入、依赖条件的访问，以及受任务要求约束的输出组合共同产生。检验对象是这些运算跨语境的预测与复用关系。

## 下一阶段计划

计划以**从未见提示到未见生成，并预报一次原生干预会怎样改变输出**为整体目标。先冻结一套有真值的非算术记录更新与报告任务，再依次验收四个里程碑。以下为计划，结果尚未采集。

| 里程碑 | 执行方案 | 通过及失败后的动作 |
| --- | --- | --- |
| 1．行为与测量校准 | 构造原事实、有效／无效更新、竞争记录、两次更新、语法指令和码本。先评估自然生成的 State、完整输出和停止。把同长度换内容、固定内容改变距离、相同末位位置三类操作区分。位置只动 RoPE 的实验另记为原生诊断。预留新词、新句式、新组合与独立锁箱，确定因果可见位置。 | 发现期逐格核对分词、行为及剂量。按家族做功效规划。留出准入失败就保留失败格式，迭代使用新的材料版本。 |
| 2．提前预测内容与读取 | 用同一冻结面板比较词汇＋位置＋n-gram、早期原生坐标和单元组、等预算 SAE/transcoder 及候选电路。分别预测 State 内容、来源分布，以及给定可用前缀的全词表 logits／概率。比较基线和正规化误差，公开可用信息边界、修改与计算预算。 | 新词与新句式分别胜过简单基线，并在未见组合保持收益。以整家族统计置信区间。若仅输出口径通过，保留对应范围，再分析早期状态是否不足。 |
| 3．串联原生读写与反例 | 固定 E（State 前）、G（实发位置）、C（答码前）。从完整坐标热图和预报误差定位主干，再追到关键坐标、MLP gate/up/down、注意力 Q/K 与 V/O。State 和 Receipt 分别做单查询阻断、同层同幅匹配随机、原生恢复，并补充其他任务的输出损伤。 | 在样本上预测干预方向、幅度和是否换词。技术门先核对实际 BF16 范数与 sham。定位卡按「原生计算来源」「范围干预」「未通过」登记。正例、反例和残差共同入档。 |
| 4．独立复算、推广与图谱评分 | 在另一个物理节点按冻结快照、输入和容差复算。然后对 GLM-4-9B 按功能而非索引复验，模型串行执行。扩展到自然续写和两类独立语言任务，并继续使用新材料。 | 只有可复算的图谱预测和范围内干预才提高相应证据等级。若仅单模型成立，则固定范围，保留新架构上的失效。训练起源另建受控训练或检查点任务。 |

第一批独立确认的预算以可检测的二值事件预注册。若预期绝对配对差 8 个百分点、失谐率 20%、双侧 \(\alpha=.01\)，仓库配对功效计算器给出所需 365 家族，计划 384 家族时功效约 0.824。正式起跑前用发现侧波动核算预算并冻结阈值，罕见翻转、语域亚组和概率指标分别计算。保存独立家族数、实际翻转家族数和不确定性。

判定用三条账。状态预测按原生目标误差和来源概率损失。输出预测按全词表 \(D_{\rm KL}(p_\theta\Vert\hat p)\)、交叉熵及相对简单基线的损失恢复率。干预预测按逐例实际改变的 Brier、召回和误报，以及配对分差、副作用、原生恢复和第二节点复算。每条结果附输入范围和计算成本。本阶段的交付目标是一套能被反例推翻、且在冻结范围里有效的预测与干预机制。
