### 1.2 被证伪或需修正的判断

1. **L1 线性 Δ 预测器会"任一族胜出"——过于乐观**。实际结果：三模型两个主目标（Hearly/postnorm）均未同时满足"胜零变化且胜配对置乱"；Q4 postnorm 全矩阵反而比零变化更差；standalone 锚点外推灾难性失败（KL 5.5–6.3）。**限定**：2747 追加的"同语境问题选择性"目标（α 加权项防止共同背景掩盖）后来在首步上确实胜过零变化和目标置乱（三模型一致）——**说明失败的是输入特征（单末端 H1 线性规则），不是问题本身；目标函数设计（α 篇内约束）是关键改进，这是 V1 方案没有的**。
2. **"参数存的是映射的生成规则"表述过强**。项目外部审查（2745 C001）明确修正：门控乘积是架构事实，"固定参数可以有条件化作用，但这还没有说明语言组合规律"。V1 把架构恒等式叙述成了接近机制的结论，应降格为"候选机制形态"。
3. **L2"三维地图"隐含的坐标群可聚类假设过于干净**。2748 C008/C012 关系几何显示：四题关系形状跨层保留（超额 E>0 且随深度增长，H36≈0.16–0.26），**但词频/长度对照同样为正**（E≈0.03–0.09），无法把跨层对应命名为纯语义结构；H12 存在负超额篇章。
4. **完全未预料的核心新发现——生成步边界**（2748 C006/C010/C012）：首步拟合规则在真实后续生成步上不仅失效，还**稳定差于固定均值基线**（Q4 +2.64、Q14 +3.26 MSE 差；查询标准化 RMS 从首步≈1.0 跳至 10–12，分布错位）。V1 把自回归循环当作"读出-写回算子复合"，未意识到**条件规则本身必须按生成阶段索引**。
5. **来源配对置乱是弱扰动**（2748 C011）：value 置换的篇内相对扰动 η 仅 0.3–7%，"主路线对该对照无优势"不能证明来源无用，也不能证明有用——**对照强度必须预先量化**，这是 V1 干预设计缺失的维度。
6. **资源门假设过时**：用户在 2745 C001 撤销 6 小时/12GiB 单轮额度，320×100×3 全量采集已完成；"零 GPU 成本"的论证框架不再必要。
7. **账本计数过时**：拼图已从 43 → **46 项**（2745/#44、2746/#45、2747/#46；2748 未闭合），公式仍为 42 项原公式 + 若干算法/控制定义。

### 1.3 训练形成的新关键线索（V1 未展开）

2747 C010 自身历史表揭示一个反直觉事实：**在正确答案上续训使关系行为变差**（Q4 原生 99/160 双世界正确 → 真实监督终点 78/80/160；而表面类别质量监督保留 100/102/160）。即"学正确答案"主要改变的是答案分布/格式而非关系追踪，且损害配对区分。置乱方向等半径缩放后 NLL 反而更优（2747 C004）。同条件跨种子参数方向余弦 0.79–0.95（FP32），跨条件 0.59–0.60。**"训练收益"与"关系行为"是两个几乎解耦的轴**——这是参数级机制提取必须直面的结构。

## 第二部分：MEMO 最新结论综合（2745–2748）

### 2.1 六个时代的时代七（E7：条件构造与自然多问题时代，2745–2748）

- **2745**：三模型 320 表达×100 查询=96,000 条件端点；全坐标双因素 ANOVA（交互占比随深度增长：H1≈0.7–0.9% → 末层 18–25%，postnorm 14–18%）；全矩阵 Δ 拟合（失败）；standalone 锚点外推（失败）；等 BF16 位移训练方向（自然方向无稳定优势）；GLM 首 token 全为换行、Q14 两条 B1/B8 形状分叉。
- **2746**：百万自然端点交互分解（语料间查询均值差占全局交互 21.6–25.6%）；896 条全层全单元运行谱（19,392 生成位置）；完整剩余网络 JVP/VJP（**BF16 有限变化与平滑微分在 小尺度下完全脱节**：相对误差≈1.0）；可用历史条件预测（一般 Q 路径 KL 略优于直接 H36，token 一致率仍 <0.25）；**自治部署失败**（直接/一般 Q 分支出现"the101111"式重复退化，受控正确 166–171/320 vs 原生 255/320）；新文档+新表达确认（160 新配对上零变化基线改善仅 2.05–2.67%）。
- **2747**：六次真实 128 步训练（2048 例恰用一次）；等半径 40 变体；504 候选校准网格（46 变体选 T=1.25、全部选 α=0）；64 前缀×6 方向×3 尺度完整传播（**完整前缀总体胜末位置但有分族反例；BF16 小变化可不如"不变化"预测**）；文字↔代码读出映射（未稳定胜错误配对；一次读出替换不改变首 argmax 则轨迹不变）；三模型+六终点自身历史（4,608 条轨迹，见 1.3 的关键线索）。
- **2748**：Quoref/DROP 400 语境×4 题自然多问题设计；**篇内问题选择性目标**（α 加权项）；三模型首步问题变化可预测（主路线 native_source_read 胜零变化/目标置乱/词面位置，但**不胜来源 V 配对置乱**）；首步规则跨生成步失败（三模型）；跨层关系几何（E>0 随深度增长但词面混杂）；来源耦合强度（η 弱）；六次 96 步训练（正确答案仅在 96 步的后续 NLL 上胜置乱，8 步时反而更差）。

### 2.2 项目自己的最新第一性定位（原文综合）

- 2746 C004："固定参数提供可反复执行的变换，但语言规律还必须解释：输入如何使这些变换有条件地起作用，哪些误差会被读出放大，生成的 token 又如何改写下一步的完整历史。"
- 2748 C006："需要分别研究随已消费 token 和生成阶段改变的条件化规则，以及它们如何接续，而不能只扩大固定回答起点的样本数。"
- 2748 C010："共同篇章和静态关系可以可预测，并不足以解释任务内容如何沿已消费 token 继续生成；需要把稳定关系、条件切换和输出选择分别验证。"
- 2748 C011（对对照设计的自我修正）："后续更有区分力的来源研究应预先量化目标关系破坏强度……而不是重复把同一个弱置换包装成新机制门。"

### 2.3 修正后的机制图景（相对 V1 的增量）

V1 图景（写入库→条件算子族→读出→写回循环）在结构上仍成立，但需四处修正：

1. **条件规则是阶段索引的**：首步（格式主导，三模型首 token 几乎全为 `["` 或 `\n`）与后续步（内容阶段）是不同条件分布；单一静态规则无法跨阶段（C006/C010/C012 三模型复现）。
2. **读出层之前的"可预测成分"是篇内问题差异而非绝对状态**：绝对状态外推失败、共同背景占大头；可提取对象是"同篇章四题间的差分结构"（2748 核心正结果）。
3. **来源特异性尚未建立**：所有拟合收益都能被"弱扰动对照"吸收——来源正确配对的独立贡献未被分离；这恰恰说明机制定位要靠**预设强度的干预**而非拟合对照。
4. **训练形成与关系行为解耦**：正确答案监督改善 NLL 但损害双世界区分；表面类别监督保留区分。参数方向可复现（同条件跨种子高余弦）但跨条件共享变化多。

## 第三部分：提取方案 V2（Phase 2749+）

> 总原则：放弃"一个静态规则解释语言"的目标形态，改为提取**按生成阶段索引的条件规则族 + 其接续关系**。这既是 2748 三大失败（锚点外推、跨步失效、来源不特异）指向的出路，也是项目自己声明的下一对象。

### P1 内容阶段选择性提取（最高优先，数据已在库）

- **对象**：2748 的 576 条/模型自由历史（每步 postnorm + 预定样本全 H）+ 教师历史，即后续步（t≥1）的篇内问题差分。
- **设计**：把 2748 的 α 加权篇内选择性目标从首步扩展到逐步——按步带（t=1、2–3、4–7、8+，沿 C006 的分组）分别拟合 native_source_read 类规则；输入用**当步已消费前缀的 H12/来源读出**（C006 已证明当步可用特征存在，只是首步训练的规则用错分布）。
- **判据**：任一步带胜过"该步带固定均值 + 目标配对置乱"；跨步带规则间的迁移矩阵（哪阶段的规则可互相替代）= **接续结构的第一张图**。
- **假说检验**：查询标准化 RMS 从 1→10 的跳变主要是"格式→内容阶段切换"；若内容阶段内 RMS 稳定且规则可拟合，则阶段索引假说成立。

### P2 多位置真实前缀覆盖（MEMO 明示的下一大阶段）

- 同一问题在真实自回归过程的多位置（已消费不同长度自身历史）上重复 2748 的选择性拟合与评价，篇章隔离；区分词汇/位置/格式/内容四因子（用词频/长度/格式 token 三类对照逐项扣除）。
- 与 P1 合并产出：**"阶段 × 因子 × 关系族"的预测增益分解表**——这是 V1"三维地图"的可判定化版本（用可控增益代替坐标聚类叙事）。

### P3 预设强度干预设计（修正 V1 干预层）

- 每个干预先算目标关系破坏强度（η 类量），分层：弱（<5%，如 value 置换）、中（来源删除/段置换）、强（key/query 改变、跨层写入）。
- 在 η 相同的强度带上比较"语义定向破坏"与"等强度随机破坏"的双世界区分下降差——只有定向>随机的差值才是机制定位证据。
- 候选强干预：block12 篇章来源整体删除 vs 等质量随机位置删除（利用 2748 已有 KV 重放管线）。

### P4 知识链载体专项（关系族分层的深化）

- knowledge_chain 三模型全面最弱 + B1/B8 形状敏感（Q14 两条翻转）+ GLM 32 条"结论正确但格式不合规"——假说：**链式关系不驻留在末端向量方向，而在多 token 生成轨迹与解释结构中**。
- 检验：比较知识链题的逐步 postnorm 轨迹在两世界间的分叉时刻 vs 属性绑定题；若分叉系统性滞后/弥散，则"载体在轨迹"成立，提取对象改为轨迹级算子。

### P5 参数方向→权重子集→移植（V1 L5 的落地，材料已备）

- 2747/2748 的 12 个训练 checkpoint 已无损归档（XOR 编码，可逐字重建 FP32/BF16）；同条件方向余弦 0.79–0.95、跨条件 0.59。
- 三步：①方向对（正确 vs 置乱 vs 类别）的参数子集差异定位（用 2737 梯度账本 + 2748 parameter-path API 回溯到 gate/up/down 标量）；②定向置乱/冻结该子集，检验关系行为的预测变化；③**跨模型移植**（同族方向映射到 Q14/GLM 对应块）——移植功能保持仍是"破解"的终审判据，但必须显式声明精度（FP32/BF16 部署方向余弦差 0.08–0.15）。

### 成功判据 V2（替代 V1 三级判据）

1. **阶段判据**：规则族在各自步带内胜过零变化+目标置乱，且步带间迁移矩阵可解释（P1/P2）。
2. **强度判据**：定向干预在等强度带上产生显著大于随机破坏的关系行为下降（P3）。
3. **移植判据**：坐标群/方向映射到另一模型对应位置后功能保持（P5，需带精度声明）。
4. **负例纪律**：任何"训练收益→语义"的推断必须同时过等半径、校准、B1/B8 形状三类控制（2747/2748 已有全部管线）。

### 执行顺序建议

P1（纯复分析，数据在库）→ P2（需一次多位置采集准入）→ P3（中）→ P4（复分析+小采集）→ P5（大）。P1 与 P4 可并行，均无新 GPU 成本。
