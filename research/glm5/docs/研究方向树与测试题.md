# 研究方向树与测试题

设计题库 v1 · 语言图谱 v3。每个稳定编号对应一个研究项或一项横切条件。
本册公开展示的题目均为设计材料。A、B 各自列出预期答案。正式试验需要另建未曝光家族、冻结评分及通过条件。

## 目录

- **知识网络**　实体与类别、属性、实体关系、事件与情景、数量与时空、词义、知识来源
- **推理功能**　逻辑运算、推理类型、语境读取与绑定、篇章、交际意图、任务功能
- **语法规则**　书写与构词、词类、短语与组合、句类与句式、论元与角色、语序与标记、时体与情态
- **横切条件**　信息源呈现顺序、规则呈现方式、无关技术词标题、关系描述句式、语种识别、语码混用、跨语言语义对齐、地域变体与方言词汇、正式、口语与专业语域、隐喻、习语与反讽、提问表述变体、同义改写与意义保持

## 怎样逐步填充

1. 先逐项查历史。为一项测试选择一个主编号，必要时引用其他研究项与横切条件。按来源记录历史关联，保持原题、结果、权限和暴露状态可追溯。同一次运行只计一次。
2. 找到原包后，另记运行 ID、题目与条件、模型快照、实际输出、评分口径、失败环节和原始证据。只有备忘录时保留出处，标为待核对。相关旧题的成绩不能填入本版新题。
3. 先补能直接区分两种解法的题族，例如知识属性与比较、多步关系与第二条边、主谓一致与相邻名词。例题 A/B 是起点。更改无关名字、顺序、答案标签，设置维持答案和翻转答案两类对照，按家族留出。语种、读出、模型和方法分别记录。
4. 新模型数据按项目流程先查重。行为在所有关键格可靠后，再为内部机制另列竞争预测、原生阻断、等强对照和恢复。设计覆盖、实际运行、材料完整度、科学结论分别计数。

A/B 是一个对照因素的两个取值。有些对照需要改写整段语境，可能同时改变词长、位置或词汇；进入机制研究前另行配平。未登记为锁箱的公开题都属已曝光。

### 推理类型

#### 条件推理 · `LOG.COND`

对照因素为条件的使用方向。

- **A**　唯一规则为“贴星标就放入甲箱”。现知某卡贴了星标。仅据此，是否能断定它既贴了星标又在甲箱？　参考答案：**能**
- **B**　唯一规则为“贴星标就放入甲箱”。现知某卡已在甲箱。仅据此，是否能断定它既贴了星标又在甲箱？　参考答案：**不能**

#### 因果关系 · `LOG.CAUSE`

对照因素为因果的方向。

- **A**　题设唯一因果链是“拉绳 → 铃响 → 门卫抬头”。拉绳是铃响的直接原因还是直接结果？　参考答案：**直接原因**
- **B**　题设唯一因果链是“拉绳 → 铃响 → 门卫抬头”。门卫抬头是铃响的直接原因还是直接结果？　参考答案：**直接结果**

#### 传递与多步推断 · `LOG.CHAIN`

对照因素为同一关系应用次数。

- **A**　每次沿箭头走一步：青→白，白→橙，橙→紫，紫→青。从青出发，走一步到哪种颜色？　参考答案：**白**
- **B**　每次沿箭头走一步：青→白，白→橙，橙→紫，紫→青。从青出发，走两步到哪种颜色？　参考答案：**橙**

对照因素为第二条边的目的地。

- **A**　名牌上的箭头是唯一规则：青→白，白→橙，灰→紫。每一步只沿一支箭头。从青走两步停在哪里？　参考答案：**橙**
- **B**　名牌上的箭头是唯一规则：青→白，白→粉，灰→紫。每一步只沿一支箭头。从青走两步停在哪里？　参考答案：**粉**

一步的结果始终是白。两步答案应随第二条边变化；只记起点与固定答案的规则会给出相同预测。正式留出还需打乱标签和记录顺序，配足只看末行等捷径的冲突条件。

- **A**　Lin gave Bo the key. 谁收到了钥匙？统一回答 Bo 或 Lin。　参考答案：**Bo**
- **B**　Lin 把钥匙交给了 Bo。 谁收到了钥匙？统一回答 Bo 或 Lin。　参考答案：**Bo**

#### 地域变体与方言词汇 · `VAR.DIALECT`

对照因素为地域用词。

- **A**　“我刚叫了一辆的士，司机马上来接我。”说话人要乘坐出租车还是地铁？　参考答案：**出租车**
- **B**　“我刚叫了一辆出租车，司机马上来接我。”说话人要乘坐出租车还是地铁？　参考答案：**出租车**

#### 正式、口语与专业语域 · `VAR.REGISTER`

对照因素为语域正式度。

- **A**　请于2026年4月9日提交材料。 通知要求何时交材料？统一答 YYYY-MM-DD。　参考答案：**2026-04-09**
- **B**　材料4月9号交哈，说的是2026年。 通知要求何时交材料？统一答 YYYY-MM-DD。　参考答案：**2026-04-09**

#### 隐喻、习语与反讽 · `VAR.FIGURATIVE`

对照因素为比喻与直述。

- **A**　“这场讨论卡住了，谁也提不出新办法。”说的是讨论陷入僵局还是讨论进展顺利？　参考答案：**陷入僵局**
- **B**　“这场讨论陷入了僵局，谁也提不出新办法。”说的是讨论陷入僵局还是讨论进展顺利？　参考答案：**陷入僵局**

#### 提问表述变体 · `VAR.FRAME`

对照因素为相同问题的问法。

- **A**　记录“甲 18，乙 7”。甲的号码是多少？ 只答数字。　参考答案：**18**
- **B**　记录“甲 18，乙 7”。请报甲的号码。 只答数字。　参考答案：**18**

#### 同义改写与意义保持 · `VAR.PARAPHRASE`

对照因素为等义表述下角色保持。

- **A**　小松把笔递给小禾。 谁接到笔？只答人名。　参考答案：**小禾**
- **B**　小禾从小松手里接过笔。 谁接到笔？只答人名。　参考答案：**小禾**
