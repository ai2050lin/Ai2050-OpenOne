1. **"问题事实泄露"假说——否定**（2759）：删问句事实 span 使 D 从 −22 **抬升**至 −14 且世界间距增大 7+ NLL（5 run 全部反向）。问句事实 span 承载的是**共模负偏置**而非世界区分；偏置与区分是可分离通路。修正：区分载体仍在来源侧（2758 J2 符号反转），问句侧是偏置锚点。

## 第三部分：V3 计划（Phase 2763+）

### P1 组合修复：perm 训练态 × 读出端偏置抑制（Phase 2763，本路线书首个执行项）

**问题**：不使用 oracle 答案方向，去偏置能否把 kc"内部知道"转成行为（78% → ab 水平）？

**设计**：5 run（native + perm_2747/2748 + true_2747 对照 + mass_2747，2759 部署机制）× 320 diagnostic 行 × 变体 {base, bsub(α∈{0.1,0.3,1.0}), ctrl(α=0.3), 组合 perm+bsub}。bsub = 读出端偏置抑制：v_row := h_final(with_qfact) − h_final(without_qfact)（native 定义，2759 fact-token 规则），hook 于 layers[35] 输出：h := h − α·‖h‖·unit(v_row)。

**预注册判据**：
- C1（perm 无 oracle 修复）：native-kc-wrong 14 行在 perm_2747/2748 base 下翻转率 ≥0.4 且 > true_2747；
- C2（bsub 无 oracle 修复）：native + bsub(α=0.3) 在全族 native-wrong 行翻转率 ≥0.3 且 bootstrap CI 下界 > ctrl；
- C3（族特异性）：ws native-wrong 行（真不知道）在 perm 与 bsub 下翻转率 < kc，CI 分离；
- C4（组合，探索性）：perm+bsub ≥ max(单独)。
- verdict：debias_repair_confirmed = C1(≥1 perm run) ∧ C2 ∧ C3。

**完整性门**：G0 部署 L2 <1e-9；G1 base 前向确定性（前 8 行逐位）；G2 v_row 非退化（‖v‖>0，空 fact 行记 not_applicable）；G3 native wrong 集合与 2761 记录一致（14/10/16/25）。

### P2 读出端干预的系统设计（P1 后分叉）
