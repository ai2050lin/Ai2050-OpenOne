# Phase408：排他响应分区与接口协变审计

时间：2026-07-13 08:43 HDT（UTC-09:00）

## 一、总体判断

两份 Phase407 后续分析的主方向正确：不能再要求同一语义状态在不同接口下给出相同字面标签，应当把“状态是否仍可区分”和“标签是否仍与任务坐标对齐”分开研究。

本轮接受了以下方向：

1. 使用有限、机器可解析的响应注册表；
2. 把状态可分性与标签正确性独立记账；
3. 使用三个接口和六种三槽排列，消除两槽交换不可辨识问题；
4. 将语义类别、运行时数值、响应事件和停止右删失分成正交轴；
5. 在四个结构表面和两个独立词汇复本上要求响应映射稳定；
6. 发现、校准、行为留出和物理留出按门禁依次开放。

原分析仍有七处必须修正：

1. 确定性贪心是逐步局部 argmax，不是全序列 MAP；
2. allowed/rejected/ambiguous/unparsed、数值有效性和事件删失不是一个“六类互斥状态”；
3. 完整置换只说明外部响应可分，不能证明内部状态信息被完整保留；
4. 两槽交换只有一个非平凡置换，不能支撑一般接口代数；
5. 由同一批状态行派生的闭环一致性部分来自代数定义，不是独立因果证据；
6. 任务坐标变换是研究者冻结的外部标准，不是模型内部已发现算子；
7. 工程覆盖、观测结果和因果闭合不能压成单一进度百分比。

正式结果是强负结果加测量校准：

```text
正式发现案例：11,232 / 11,232
全部数值有效：11,232 / 11,232
全部条件可分组：0 / 108
表面与词汇稳定组：0 / 108
任务坐标协变组：0 / 108
功能响应分区组：0 / 108
发现跨模型候选族：0 / 3
校准、行为留出、物理留出消费：0 / 0 / 0
新增内部算子、物理路径、神经元节点：0 / 0 / 0
```

这否定的是“当前有限响应注册表能在三接口、四表面、两词汇复本和三个小模型上形成稳定可迁移分区”，不是“模型内部不存在语言状态”。

## 二、测量对象和公式

### 1. 逐步贪心轨迹

本轮实际观测为：

```text
y_t = argmax_v p(v | x, y_<t)
Y*  = (y_1, ..., y_T)
```

不能写成：

```text
Y* = argmax_Y p(Y | x)
```

因为局部逐步最优不保证全序列联合概率最大。

### 2. 正交响应账本

对接口 `i` 的外部解析器，定义最终语义类别：

```text
C_i(Y) in {allowed, rejected, ambiguous, unparsed}
```

运行时数值轴独立定义为：

```text
V(Y) in {valid, invalid}
```

注册响应、允许响应、句界和停止分别记录事件时间与右删失：

```text
(tau_registered, delta_registered)
(tau_allowed,    delta_allowed)
(tau_boundary,   delta_boundary)
(tau_stop,       delta_stop)
```

所以“最终回答允许”可以与“没有在 H48 内停止”同时成立。

### 3. 条件响应映射

对模型、组、结构表面、词汇复本和接口组成的条件 `c`，定义外部响应映射：

```text
P_c : S -> R union {missing}
```

其中 `S` 是有限语义状态集合，`R` 是该接口的注册响应类。条件单元被分为：

```text
bijective_label_aligned
bijective_relabelled
state_collapse
missing_or_nonexclusive_response
numeric_invalid
```

只有 `P_c` 对全部状态完整且单射，才称该条件可分。它仍只是行为读出性质。

### 4. 接口映射和严格边界

如果两个接口的稳定映射都可逆，可以在响应坐标上定义：

```text
T_i_to_j = P_j o inverse(P_i)
```

本轮把它与冻结任务坐标图 `G_i_to_j` 比较。即使 `T_i_to_j = G_i_to_j`，也只能说明行为响应符合外部坐标关系；没有内部激活和合法计算边证据时，不能称为内部执行算子。

闭环：

```text
T_i_to_k = T_j_to_k o T_i_to_j
```

由共享状态行上的映射构造时并非独立证据，本轮只把它作为完整性检查。

## 四、正式行为和事件结果

```text

最终 rejected：1,148
最终 ambiguous：60
最终 unparsed：4,718
```

曾观察到 allowed 比最终 allowed 多 31，说明少量轨迹先进入允许状态，随后又加入其他内容或改变最终解析类别。该差值是事件账本现象，不应与最终正确率合并。

|---|---:|---:|---:|---:|
| Qwen3 | 3,744 | 3,666 | 78 | 0 |

Phase407 的 GLM4 FP16 非有限退化没有在本轮 bfloat16 正式数据中复现。这证明运行精度资格门有效，但不能把精度修复解释为语言机制进展。

Qwen3 和 GLM4 长时采集各发生一次 CUDA/PyTorch 原生 `139` 退出，分别已封存 2,044 和 615 行。逐条断点恢复后完成全部分母，键无重复。DS7B 一次完成。原生退出属于工程稳定性问题，不改变已封存响应。

## 七、接口级客观差异

Qwen3 规则推理三个接口的对齐双射分别为：

```text

holder_name：83/96
reach_truth_vector：60/96
```

Qwen3 语法三个接口为：


但 `sentence_completion` 解析注册表仍接受单独的 `is/are/was/were`，与 `be_form` 全部重叠，因此 `95/96` 不能解释为完整句子接口已经稳定。

## 八、协议硬伤和证据边界

### 1. 原预注册未被完全满足

机器注册表完成了唯一键、别名冲突、坐标映射和解析器合同测试，但没有记录“两名独立规则审阅者一致”。因此本轮是冻结机器合同上的正式实验，不是完整人工双审闭合。

### 2. 历史因素没有执行

本轮历史固定为 `fixed_empty`。早期 Phase408 预注册中的等义历史、无关历史、冲突历史和当前覆盖历史没有进入分母。即使行为留出为正，也不能直接授权物理路径；本轮实际候选为零，历史门同样未开放。

### 3. 语法接口存在别名重叠

`be_form` 与 `sentence_completion` 都接受单独 be-form。下一版必须让句子接口只接受完整的 `be-form + adjective + boundary`，并将单独 be-form 记为格式不完整，而不是成功。

### 4. 知识正序和逆序共享响应词表

`entity_value_order` 与 `reverse_entity_value_order` 使用相同的六个值排列作为响应集合。这个重叠本身不是错误，因为研究目标正是比较同一响应坐标集合上的排列；但它不能提供两个独立内容词表的额外验证。

### 5. 严格组门容易被单条件失败阻断

本轮完整组要求 24 个条件全部可分。这是预注册的严格验证门，应保持 `0/108` 正式结果；同时必须报告 883 个局部可分条件，避免把严格组负结果误写成所有局部结构都不存在。下一版应预先区分“接口内状态可分门”和“跨接口协变门”，不能继续用一个总门掩盖失败位置。

### 6. 外部响应不是内部状态

所有响应类别都来自外部解析。没有采集激活、注意力 K/V、MLP 通道、神经元或合法计算边，故本轮对物理图谱的新增只能是观测证据节点。

### 7. 小模型限制

三个小模型可能使用粗糙、模型特异或高度上下文依赖的实现。DS7B 知识接口的大量未解析尤其可能混合能力不足、指令遵循和模板不适配。该因素限制外推范围，但不能用来撤销正式负结果。

## 九、对语言编码机制的谨慎更新

可确认的新拼图：

1. 状态可分性和标签对齐已经在数据结构与分析中真正分开；
2. bfloat16 运行资格消除了本轮 GLM4 非有限路径；
3. 部分模型、语言族和接口存在大量局部双射响应；
4. 完整非恒等重标记极少，且没有跨表面与词汇复现；
5. 当前有限响应分区不能作为跨模型统一语言状态。

不能确认：

```text
模型内部存在已定位的接口算子；
观察到的双射就是信息保留的物理证明；
知识、规则和语法共享同一编码布局；
任何注意力头、MLP 通道或神经元承载该结构；
线性端点公式可以闭合真实语言过程；
语言编码机制或智能理论已经完成。
```

当前更合适的研究对象不是单个静态标签，而是条件化响应过程：

```text
E_m(s, c) = 注册状态进入、退出、句界和停止组成的事件轨迹
```

但这个式子目前只是下一轮的测量对象，不是已经发现的数学理论。

## 十一、下一阶段与自动执行判断

Phase409 需要继续，但当前不应自动运行新模型。先完成不加载模型的协议重建：

1. 将最终标签改为事件自动机，保留“进入允许状态后又退出”的过程；
2. 为每个查询建立两套独立规则引擎：直接闭式解码和穷举有限世界解码，两者逐案例一致；
3. 修复语法完整句接口，不再接受单独 be-form；
4. 加入当前状态、等义前文、无关前文、冲突前文和当前覆盖五类历史合同；
5. 先按接口独立验证状态可分，再在双方通过时计算接口变换，不把三接口失败压成一个总门；
6. 使用全新语义组和词汇包，冻结发现、校准、行为留出和物理留出；
7. 只有三模型在独立历史行为留出上保持同一响应过程结构，才另行注册内部物理定位协议。

当前自动模型执行为 `false`。原因是 Phase408 跨模型门为 `0/3`，且新动态对象、历史分母和独立规则审计尚未冻结。继续在旧分母上扩大样本，只会更精确地重复同一测量失败。

## 十二、通俗说明

这次把“答错”拆开看以后，发现三个模型并不是所有地方都混乱。比如 Qwen3 在很多规则题接口里，三个状态都能稳定区分；但是只要换一组表述、词汇或接口，就总有一处缺失或塌缩，三个模型更没有共同规律。

所以现在可以确定的是：旧方法把不少局部结构看见了，但还没有找到能跨条件搬运的统一语言状态。下一步不是立即扫描神经元，而是先把“模型回答过程”本身定义得更严谨，再加入真正独立的历史条件。只有这一步通过，神经元级图谱才有可靠的目标可追。
