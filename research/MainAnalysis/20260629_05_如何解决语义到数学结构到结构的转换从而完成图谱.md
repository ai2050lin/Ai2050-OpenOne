# 二、关键问题：语义不能直接定位，必须先变成“功能指纹”

当前最大错误风险是：把“语义”当成一个向量去找。

更正确的路线是：

```text
语义不是一个点；
语义是一个功能指纹。
```

也就是说，“苹果”的数值表达不应该定义为某个隐藏状态，而应该定义为：

```text
在一组标准任务中，哪些组件对苹果相关预测产生稳定因果效应。
```

例如对“苹果”建立任务组：

```text
苹果是什么类别？ -> 水果
苹果是什么颜色？ -> 红色 / 绿色
苹果能吃吗？ -> 能
苹果长在哪里？ -> 树上
苹果和香蕉是什么关系？ -> 都是水果
苹果和锤子是什么关系？ -> 不同类别
```

然后测每个神经组件对这些任务的因果贡献。

这时“苹果”不再是一个点，而是一个向量 / 张量：

$$
\Phi(\text{apple})
==================

[
E(u_1,\text{apple},r_1),
E(u_2,\text{apple},r_1),
...,
E(u_i,\text{apple},r_j)
]
$$

其中：

$$
E(u,o,r)
========

\Delta \ell(y_{o,r})
$$

含义是：

```text
组件 u 被干预后，
对象 o 在关系 r 下的正确答案分数变化。
```

这才是语义到数值的第一步。

## 五、当前最准确的机制图像

当前不能说：

```text
模型内部已经存在可直接读出的“苹果语义点”。
```

更准确的说法是：

```text
模型在显式关系任务中形成了对象相关的条件化因果纤维；
这束纤维能弱分离语义域；
但它主要依赖记录格式、注意力分配和读出几何，
还没有证明是自然语义自身的不变量。
```

## 六、硬伤

```text
1. profile records 可能贡献了很大格式结构。
2. direct score 强，但可能只是 readout geometry，不一定是语义机制。
3. route release 单独较弱，说明路线动力学还没有被真正抓住。
4. object/relation token source 单独较弱，说明“词元就是入口”的假设不成立。
5. 跨模型相关偏弱，小模型偏差必须继续保留。
```

核心问题：


如果保持，说明语义—数值接口更接近自然语言编码机制。

如果消失，说明当前图谱主要是格式条件图谱，而不是自然语义图谱。
