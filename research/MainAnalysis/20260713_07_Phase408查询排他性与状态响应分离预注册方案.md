# Phase408：查询合同排他性与状态-响应分离预注册方案

时间：2026-07-13 06:16 HDT（UTC-09:00）

## 一、启动理由

Phase407 已经完成事件地平线账本，但九个模型×语言族单元均未达到发现门，严格跨模型候选为 `0/3`。失败中同时混有四类不同对象：

```text
模型没有形成注册响应；
模型形成了另一个合法响应；
接口改变了状态到答案的离散映射；
运行精度产生非有限退化。
```

因此 Phase408 不能直接扩大 Phase407 样本，也不能进入激活、注意力头、通道或神经元扫描。下一步先修复“题目是否唯一”和“状态信息是否等于答案正确”这两个测量问题。

## 二、阶段目标

Phase408 只解决三个可核验问题：

1. 每个查询是否只有一个注册语义答案；
2. 同一状态的响应映射是否能跨表面稳定复现；
3. GLM4 的运行合同是否能排除非有限长输出路径。

本阶段不以闭合、单神经元定位或跨模型统一公式为目标。

## 三、A 门：查询合同排他性

每个候选查询必须先离线登记四个集合：

```text
A_allow：唯一注册答案；
A_reject：明确错误答案；
A_ambiguous：语言上同样成立、不能用于判错的答案；
A_unparsed：当前规范化器无法可靠归类的输出。
```

一个查询只有同时满足以下条件才可进入模型测试：

```text
|A_allow| = 1；
A_allow 与 A_reject 不相交；
两名独立规则审计者对唯一答案结论一致；
解析器单元测试覆盖允许、拒绝、歧义和未解析边界；
不同表面不改变唯一语义答案；
接口只改变回答形式，不改变被询问的关系。
```

语法族必须改为唯一槽位任务。不能再把 `is`、`has been`、进行式或其他合法谓词同时允许，却只把一个辅助词登记为成功。

## 四、B 门：状态信息与响应映射分离

对每个条件单元继续定义：

```text
P_c : s -> r，c = (model, group, surface, interface, history)
```

先按客观形状分为：

```text
identity；
complete_nonidentity_permutation；
collapse；
missing。
```

再独立计算答案是否符合查询。禁止把“非恒等置换”直接记为错误，也禁止把“目标序列分数更高”直接记为自然回答正确。

接口映射候选的最低门为：

```text
四个表面中至少 4/4 得到同一完整映射；
当前轮与前轮等义状态得到同一映射；
前轮无关内容不能改变映射；
前轮冲突但当前轮明确覆盖时，以当前轮为准；
在校准组重新计算后保持同一映射。
```

只有通过这些门，才允许把响应分区升级为“接口变换候选”；仍不能称为内部执行算子。

## 五、C 门：运行资格

每个模型按 `qwen3 -> GLM4 -> DS7B` 顺序独立加载，CUDA、batch=1、确定性贪心。正式运行前冻结跨族、接口、历史和长输出压力案例，并重复两次。

资格条件：

```text
输出逐 token 完全一致；
原始 logits 全部有限；
处理后分数全部有限；
EOS/H48 终止事件可重复；
规范化响应可重复；
显存释放后再加载下一个模型。
```

GLM4 需要在同一密封资格子集上比较 float16 与 bfloat16。选择规则必须在正式数据前冻结：优先使用无非有限路径且输出可重复的精度；若两者均有非有限路径，则 Phase408 正式三模型执行不启动。

## 六、新分母设计

Phase407 的 30 组/族全部只作历史证据，不得回收为 Phase408 正式分母。Phase408 需重新生成语义、实体、顺序和表面组合，并做字符串与语义键双重去重。

建议先执行小型合同门，再决定是否扩展：

```text
合同审计：每族 8 组，不加载模型；
运行资格：每模型 32 个密封案例，重复两次；
预发现：每族 4 组，只检查查询排他性和响应分区；
正式发现：仅在 A/B/C 三门全部通过后冻结；
校准、行为留出、物理留出：在正式发现门通过前保持密封。
```

预发现不是正式证据，不能与 Phase407 合并计算成功率。

## 七、停止规则

满足任一条件立即停止，不进入物理研究：

1. 任一语言族存在无法消除的多合法答案；
2. 任一模型资格案例出现非有限路径；
3. 响应映射不能跨四表面稳定；
4. 历史无关控制显著改变映射；
5. 三模型没有共同通过同一语言族的功能校准。

只有三模型在全新校准分母上通过同一族，才允许另行注册物理路径实验。任何物理实验都必须沿合法计算边，不能把静态端点表直接 patch 成“自然状态”。

## 八、自动执行判断

Phase408 的协议设计应自动继续，本文件已经完成第一版冻结边界；正式模型测试当前仍不启动。原因不是计算资源不足，而是 A 门所需的唯一答案表、歧义表和解析器测试尚未形成机器可审计注册表。直接运行只会重复 Phase407 的测量混合。

下一项工程任务是生成查询合同注册表及其单元测试，通过后再执行 32 例/模型的 CUDA 资格，不应直接跑大分母。
