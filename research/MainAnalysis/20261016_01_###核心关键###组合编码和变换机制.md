## 一、先把"100 个球选 70–100 个"说精确

这个比喻有两种数学读法，它们的预测差别很大，**第一步就要用数据判断模型处在哪种情况**。

| 读法 | 含义 | 和比喻的关系 | 关键特征 |
|---|---|---|---|
| **稠密组合码** | 在固定的约 100 个单元上，每个概念激活其中 70–100 个 | 字面意思 | 任意两个概念天然重叠很多：随机取两组 70 个，期望重叠 70×70/100 = 49 个。区分主要靠那二三十个"不同的球"和激活强度 |
| **稀疏叠加码** | 有一本很大的"特征字典"（10⁴–10⁶ 个方向），每个概念只用其中几十到几百个，叠加在 2560 维的 HiddenState 里 | "复用"的另一种实现 | 随机概念之间几乎不重叠，所以一旦重叠就有语义含义（苹果和香蕉共享"水果"特征） |

现有的可解释性研究（字典学习/SAE）更支持第二种：每个 token 只激活几十到几百个字典特征。但这一点要在本项目的模型上实测，不能直接照搬。

**统一的形式化（工作假说 H）：**

$$x_c^{(l)} \approx \sum_{f \in S_c^{(l)}} a_{c,f}^{(l)}\, d_f^{(l)}, \qquad |S_c^{(l)}| = k \ll F$$

- $x_c^{(l)}$：概念 $c$ 在第 $l$ 层的状态；$d_f$：第 $f$ 号"球"（字典特征方向）；$S_c$：被选中的那组球；$a_{c,f}$：每个球的强度。也就是说，球不是简单的"选/不选"，而是带强度的。
- **复用** = 不同概念的 $S_c$ 之间有交集；**差异** = 各自独有的部分加上强度的不同。
- **上下文逐步拟合** = 随层数增加，$S_c^{(l)}$ 和 $a_{c,f}^{(l)}$ 在上下文作用下逐步改写。
- **翻译** = 保持"概念核心"那部分球不变，把语言相关的那部分球换掉。

## 二、可检验的预测（每条都写明怎样算被推翻）

| 编号 | 预测 | 怎样检验 | 怎样算被推翻 |
|---|---|---|---|
| P1 重叠-相似律 | 两个概念的球重叠程度随语义距离单调下降：苹果~香蕉 > 水果~食物 > 天体~食物 | 用重叠度矩阵（加权 Jaccard）和分类树距离做 Mantel 检验，置换检验按词整体打乱 | 重叠度的解释力不超过原始 cos 相似度或词频基线 |
| P2 层级包含 | 上位概念的球大体包含在下位概念里（"水果"的球 ⊂ "苹果"的球），整体构成一个格结构 | 形式概念分析（FCA）；统计包含率 | 包含率不高于随机集合 |
| P3 属性可分解、可迁移 | 颜色、大小、重量各有一组共享的球；"红"的那组球在苹果、草莓、旗子上相同；大小、重量是连续量，体现为强度或方向上的有序编码 | 按属性回归；在未见名词上预测；把"红"这一差量加到别的名词上看是否迁移 | 属性只能在单个词上读出，换一个名词就不迁移 |
| P4 复用的经济性 | 球的使用频率呈重尾分布：少数"枢纽球"（物体、生物、食物）被大量概念使用；所需的球数接近压缩感知的下界 | 统计使用频率分布；拟合 $d \gtrsim k\log(F/k)$ | 使用频率均匀，或每个概念需要的 $k$ 远超下界 |
| P5 上下文逐层拟合 | 早层以词形特征为主，中层出现语义和语境特征，晚层出现输出特征；"苹果"在水果语境和公司语境下，中层选中的球会分化 | 逐层统计集合的变化（新增/保留/删除），配合 logit lens 的熵 | 集合的变化与上下文无关 |
| P6 翻译 = 组合映射 | 中英文对应名词在中层共享"核心球"，早层和晚层各有语言专属的球；映射保持关系（苹果:水果 ≈ apple:fruit） | 逐层统计跨语言重叠；检验映射是否保持关系（图同态） | 跨语言重叠在各层都低，或映射不保持关系 |
| P7 组合是被使用的 | 把苹果的"颜色球"换成香蕉的，模型会输出"黄色的苹果"这类结果 | 对特征子集做替换、消融、steering，在留出材料上检验 | 替换不改变输出，或改变不具选择性 |

## 三、算法流程（四步，复用现有基础设施）

**1. 定义"球"：三种基底并行比较**
- 原生神经元或坐标，作为基线；
- 模板对照方向，也就是现有 analysis.v1 和 atlas.v1 算出来的方向；
- **字典特征（主路线）：** 在 Qwen3-1.7B（本机已有）的若干层上训练 SAE 或 transcoder；或者先用已有公开字典的参考模型，快速验证方法。

哪种基底能让 P1–P4 成立、且描述长度最短，就说明哪种基底更接近模型真实使用的"球"。

**2. 名词图谱数据（外部图谱）**
- 先取约 2,000 个中文名词，再扩到 10⁴：从同义词词林、HowNet、Wikidata/ConceptNet 拿分类层级（上下位、部分-整体），再补上属性（颜色、大小、重量，先手工标注一部分）。
- 每个名词放进多个中性语境（「这是{X}。」「我看到了{X}。」……）和若干区分语境（苹果的水果义与公司义）。
- 用现有 runner 做全层采集，原生全场留在节点本地，任务按分布式协议切片。

**3. 结构挖掘（复用、差异、模块）**
- 名词 × 特征 × 层的激活张量 → 用双聚类或非负张量分解找出"经常一起出现的球组"，这就是候选的可复用"机制模块"；
- 形式概念分析建立概念格（P2）；用超图表示：每个特征是一条超边，连接所有用到它的名词；
- 属性：有序回归，加上差量迁移检验（P3）；使用频率分布和压缩感知下界拟合（P4）。

**4. 变化与因果（怎样变、是否被使用）**
- 层间转移：用 transcoder 或归因图描述"第 $l$ 层的球组如何变成第 $l+1$ 层的球组"，分解为保留、新增、删除三部分，看它们分别由什么上下文触发（P5）；
- 跨语言：做平行名词集，逐层计算重叠和映射，并检验映射是否保持关系（P6）；
- 因果：对特征子集做替换、消融、steering，先预注册，再在留出名词上检验（P7）。

## 一、改进后的工作假说

**1. 每个位置的状态是多类编码的叠加（★）**

$$x_i^{(l)} \;\approx\; \underbrace{\sum_{f\in S^{\text{概念}}_i} a_f d_f}_{\text{概念与属性}} \;+\; \underbrace{\sum_{f\in S^{\text{语言}}_i} a_f d_f}_{\text{中/英}} \;+\; \underbrace{\sum_{f\in S^{\text{语法}}_i} a_f d_f}_{\text{词类、角色、构式}} \;+\; \underbrace{\sum_{f\in S^{\text{逻辑}}_i} a_f d_f}_{\text{否定、疑问、条件、转折}} \;+\; \underbrace{\sum_{f\in S^{\text{任务}}_i} a_f d_f}_{\text{问颜色、翻译、续写}}$$

每一类编码各有自己的一组"球"。问题在于：这几组球是近似分开的子空间，还是彼此缠在一起？这需要数据回答，不能预设。

**2. 层间更新 = 注意力搬运与加权 + MLP 写入（★）**

$$x_i^{(l+1)} = x_i^{(l)} + \sum_{h}\sum_{j\le i}\alpha_{ij}^{h}\, W_{OV}^{h}\, x_j^{(l)} + \mathrm{MLP}^{(l)}\big(x_i^{(l)}\big)$$

$$\alpha_{ij}^{h} = \operatorname{softmax}_j\!\Big(x_i^{\top} W_{QK}^{h}\, x_j\Big)$$

在特征基底下展开，注意力分成两张表：

- **路由表**（谁看谁）：$B^{h}_{fg} = d_f^{\top} W_{QK}^{h} d_g$。查询位置上的特征 $f$ 会去找键位置上的特征 $g$。
- **搬运表**（看到后写什么）：$M^{h}_{gf'} = d_{f'}^{\top} W_{OV}^{h} d_g$。把键位置的特征 $g$ 搬到当前位置，写成特征 $f'$。

你说的"提升某种编码结构的权重"，在这个框架里对应两种可测的机制：

- **路由增益：** 上下文里的线索（例如"颜色"这个词）让查询更偏向带有颜色特征的位置，于是这类信息被搬过来的比例上升；
- **写入增益：** 某些头或 MLP 在特定条件下放大某一组球的强度 $a_f$。

**核心候选结构：** 注意力是"在特征层面的稀疏双线性路由 + 特征迁移"。如果真是这样，$B$ 和 $M$ 都应该很稀疏，而且能按编码类别分块（语言头、语法头、否定作用域头、属性提取头……）。

## 一、核心假说：复用 → 纠缠 → 按需解纠缠

**H（复用-差异化循环）：**
1. 为了高效复用，模型让不同因子（概念、语言、语法、逻辑、任务）**共享同一批方向**，并且以**非加性**的方式组合，这就是纠缠；
2. 在中间层，多数信息保持纠缠，以压缩的形式传递；
3. 只有当上下文**需要**某一维度时（例如问"颜色"，或要求"翻译成英文"），相关的部件才在需要的位置、需要的层，把这一维度**解纠缠**：让它变得可以独立读出、并且不受其他因子干扰；其余维度继续保持纠缠；
4. 差异化遵循"**最小差异**"：两个相似概念（苹果和香蕉）只在当前任务需要的那一维上分开，其他维度仍然共享。

**反假说（必须一起检验）：** 编码本来就近似加性、可分，"纠缠"只是噪声或测量伪迹。如果下面各项纠缠指标在所有层都接近零，H 就被推翻。

已有的一个线索：KN-ISA 在 target 位置，类别 × 句式的交互比例只有约 0.02–0.04，也就是在**这个位置、这两个因子之间**近似加性。这说明纠缠不一定处处都有，**必须分位置、分层、分因子对来测**。

## 二、"纠缠谱"：六项可计算的纠缠指标

以完全交叉的因子化材料为基础，每个读出位置 × 每层 × 每对因子，算出一组指标：

| 编号 | 指标 | 定义 | 量的是哪种纠缠 |
|---|---|---|---|
| E1 交互能量比 | 函数型方差分解（Hoeffding/ANOVA）：$x(a,b)=\mu+\Delta_a+\Delta_b+I_{ab}+\varepsilon$，取 $\lVert I\rVert^2 / (\lVert\Delta_a\rVert^2+\lVert\Delta_b\rVert^2+\lVert I\rVert^2)$ | **非加性纠缠**：组合效应不等于单项之和 |
| E2 纠缠模式数 / 纠缠熵 | 把交互项排成张量 $I[a,b,:]$，按"因子 A ∣ 因子 B"展开后做奇异值分解，$p_k=\sigma_k^2/\sum\sigma^2$，取 $S=-\sum p_k\log p_k$ 和有效秩 | 纠缠由几个"模式"构成；秩为 0 = 完全可分，秩越高越复杂 |
| E3 方向共享度 | 两个因子各自子空间之间的主角度（principal angles） | **共享纠缠**：不同因子复用同一批方向（叠加） |
| E4 条件旋转 | $1-\overline{\cos}\big(\Delta_a^{(b_1)},\Delta_a^{(b_2)}\big)$：因子 A 的方向随 B 的取值转动了多少（现有"句式不变性"的推广） | **依赖型纠缠** |
| E5 读出干扰 | 在 B 未见过的取值上读出 A 时，准确率和投影间隔下降多少 | 功能层面：纠缠是否妨碍了独立读取 |
| E6 协同信息（可选） | 偏信息分解（高斯近似）：$I(Y;X)=\text{冗余}+\text{独有}_A+\text{独有}_B+\text{协同}$，Y 为答案 logits | 与"复用 / 差异化 / 纠缠"一一对应：冗余≈复用，独有≈差异化，协同≈纠缠 |

**解纠缠指标：**
- DCI（解纠缠度、完备度、信息量）：在最优线性基底下，每个因子能否被少数方向独立表示；
- **最小差异秩**：两个相似概念在某一语境下的表示差，有效秩是多少、是否与任务因子的方向对齐。

## 四、算法：找到"怎样纠缠、怎样解纠缠"

按"在哪 → 由谁 → 何时 → 怎样 → 是否因果"五步推进：

1. **在哪（纠缠谱曲线）：** 逐层、逐读出位置算 E1–E5。找出纠缠上升的层（**纠缠事件**）和下降的层（**解纠缠事件**）。零分布按词整体和句式整体打乱得到。

2. **由谁（部件归因）★ 核心算法：** 每一层的更新可写成 $\Delta x^{(l)}=\sum_h \mathrm{attn}_h+\mathrm{MLP}$。对**每个部件的输出单独做方差分解**，得到它在单项（主效应）和交互项上各贡献了多少：
   - 主要往交互项里写的部件，记为**纠缠者**；
   - 写入的交互项与已有交互项方向相反（把交互抵消掉）、同时写入任务对齐单项的部件，记为**解纠缠者**。
   
   这样，"纠缠和解纠缠是怎样发生的"就变成了可以排序的部件清单。

3. **何时（条件比较）：** 同一组材料，分别在有、无任务线索下比较纠缠谱和部件归因（P15），再在相似概念对上测最小差异秩（P16）。

4. **怎样（特征层面的机制）：** 在字典基底下：
   - 找合取特征和纯特征（P18）；
   - 在注意力的路由表 $B$ 和搬运表 $M$ 里找**跨因子项**：这是注意力产生纠缠的方式；
   - 看 MLP 的哪些神经元或特征把两个因子"与"起来：这是 MLP 产生纠缠的方式；
   - 看哪些头带有门控或投影性质：这是解纠缠的方式。

5. **是否因果：** 消融、patching、steering 已识别的纠缠者和解纠缠者，看交互能量和行为是否按预测变化（P19）。

## 五、候选数学结构（都是待检验的候选）

| 结构 | 对应"纠缠 / 解纠缠"的什么 | 可检验的内容 |
|---|---|---|
| **函数型方差分解（Hoeffding/ANOVA）** | 纠缠 = 交互项的能量 | E1；交互项能否在未见组合上预测 |
| **交互张量的低秩分解（Schmidt/CP/Tucker）** | 纠缠由少数"纠缠模式"构成，类比纠缠熵 | E2；用 r 个模式预测未见组合的误差随 r 的变化 |
| **叠加与干扰理论** | 复用越多（每一维承载的特征越多），干扰越大；解纠缠用来按需消除干扰 | 干扰随同时激活特征数的变化曲线；按需解纠缠是否恰好发生在干扰最大的地方 |
| **偏信息分解** | 冗余 / 独有 / 协同 = 复用 / 差异化 / 纠缠 | E6 随层的变化；协同信息是否在答案位置被转化为独有信息 |
| **层映射的分块结构（Jacobian / 算子）** | 纠缠 = 因子子空间之间的非对角耦合；解纠缠 = 块对角化与投影 | 各层 Jacobian 的跨块耦合范数；与部件归因的结果是否一致 |
| **条件化算子与门控** | 任务线索选择"解开哪一维" | 解纠缠算子能否在未见概念和未见线索组合上迁移 |

**怎样才算有了数学进展：** 用一个"低秩纠缠 + 按需解纠缠"的模型（主效应 + r 个纠缠模式 + 由线索门控的投影），去预测**未见组合**下的内部状态和输出，并且明显优于两个基线：纯加性模型，和不分解的黑箱回归。
