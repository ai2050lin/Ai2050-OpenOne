# 当前整个数学体系的总览

当前数学体系可以概括成一句话：

```text id="m5tquk"
语言编码不是“概念向量存储”，而是：
上下文字段形成语义方向，
中层通过多步路由和 MLP（多层感知机）微偏置绑定语义，
末层通过 RMSNorm Gain（均方根归一化增益）定义目标-竞争读出通道，
最后由 target（目标）和 competitor（竞争项）的相对差值形成可读意义。
```

也就是：

```text id="avj53x"
语言意义 =
上下文字段
→ 条件化路由
→ 分布式绑定
→ 增益门控读出
→ 目标/竞争项重排
→ token（词元）输出
```

目前最稳的统一理论应叫：

```text id="lqfxza"
条件化三层路由—增益读出理论
```

它不是一个单公式理论，而是一个**分层数学体系**。每一层解决不同问题：

```text id="vk3uxr"
第一层：表示如何形成？
第二层：语义如何绑定和传输？
第三层：语义如何被读出并变成输出倾向？
```

# 一、最小核心公式

如果只保留当前最可靠的核心公式，就是这一条：

```text id="3l013r"
ΔD_c ≈ α · <v_c, q_c> / rms(h)
```

其中：

```text id="s0sxxs"
v_c = h_rich - h_neutral
q_c = g ⊙ [W_U(t_c) - W_U(comp_c)]
```

通俗解释：

```text id="1rsxft"
v_c：
上下文诱导出的类别语义方向。

q_c：
RMSNorm Gain（均方根归一化增益）加权后的目标-竞争读出通道。

ΔD_c：
增强或削弱这个语义方向后，DCF（决策对比函数）发生的变化。

α：
干预强度。

rms(h)：
hidden state（隐藏状态）的整体范数尺度。
```

一句话解释：

```text id="cekzq8"
一个语义方向能不能影响输出，取决于它在增益加权读出通道 q_c 上投影有多大。
```

这就是 Phase 502-503（第502-503阶段）最核心的因果闭环。

# 二、完整数学体系分为三层

## 第一层：上下文字段形成

这一层回答：

```text id="4ond0e"
词元进入模型后，如何被角色、构式、操作符重新编码？
```

公式是：

```text id="tmtemd"
H_l(s)
=
I_l(x_s)
+
R_l(role_s)
+
C_l(T)
+
O_l(op)
+
X_l(x_s, role_s, T, op)
+
U_l
```

含义如下：

```text id="wpgyj2"
H_l(s)：第 l 层、第 s 位点的 hidden state（隐藏状态）

I_l(x_s)：token identity（词元身份），例如 apple（苹果）这个词本身

R_l(role_s)：role（角色）编码，例如主体、客体、属性位、答案位

C_l(T)：construction（构式）编码，例如 “is a type of” 这种句式框架

O_l(op)：operator（操作符）编码，例如 not（否定）、can（情态）、if（条件）

X_l：交互项，例如角色和构式互相影响

U_l：未解析残差
```

这层的核心思想是：

```text id="uq5t7x"
同一个词元在不同句子里不是同一个内部表示。
```

例如 apple（苹果）在下面两个句子中，内部状态不同：

```text id="tyznjk"
The apple is a fruit.
The apple is not a tool.
```

因为它进入了不同的构式、关系、操作符环境。

## 第一层的关键发现

也就是：

```text id="abfjdt"
Role（角色）
Construction（构式）
Operator（操作符）
```

这三类结构不是噪声，而是模型内部语言编码的重要组成。

### 2. DS7B（深度求索7B）有特殊的 R/C 抵消结构

DS7B（深度求索7B）中：

```text id="jrgm8r"
R ≈ -C
```

也就是角色信号和构式信号互相抵消。

这说明不同模型的内部策略不同：

```text id="t7ov4k"
Qwen3（通义千问3）：角色和构式较正交，多维协调
GLM4（智谱GLM4）：角色和构式较正交，但更保守
DS7B（深度求索7B）：构式强控制，通道窄但因果强
```

# 三、第二层：语义绑定与条件化路由

这一层回答：

```text id="1z4rfw"
上下文字段中的信息，如何变成可用的语义绑定？
```

这里有两套机制。

---

## 机制 A：MLP（多层感知机）微偏置绑定

核心公式：

```text id="w8mxhm"
B_c
=
Σ_L Σ_i
cproj_{L,i,c}
·
Δact_{L,i}
```

解释：

```text id="mwzldx"
B_c：
类别 c 的 binding（绑定）信号。

L：
layer（层）。

i：
MLP（多层感知机）中间通道编号。

cproj：
某个 MLP 通道对目标-竞争方向的投影。

Δact：
在不同条件下，这个通道激活的变化。
```

这个公式说的是：

```text id="yze8x5"
语义绑定不是一个大方向突然出现，
而是大量 MLP 通道上的微小偏置积分出来的。
```

也就是：

```text id="br2r0g"
很多通道每个只贡献一点点，
但加起来形成稳定的语义绑定。
```

这解释了为什么过去寻找单个“概念神经元”经常失败。

---

## gate/up（门控/上投影）分工

MLP（多层感知机）内部还可以拆成：

```text id="z8t8e9"
Δact = gate_driven + up_driven
```

其中：

```text id="qhlb6k"
gate_driven：
由 gate（门控）变化导致的激活差异。

up_driven：
由 up projection（上投影）变化导致的激活差异。
```

跨模型差异：

```text id="8ba2p2"
Qwen3（通义千问3）：up（上投影）更主导语义差异
DS7B（深度求索7B）：up（上投影）也较重要
GLM4（智谱GLM4）：gate（门控）更主导
```

所以第二层不是单一机制，而是模型可以用不同方式实现 binding（绑定）。

---

## 机制 B：条件化多步路由

原来 GPT5 路线（第五代GPT路线）假设：

```text id="83q1bx"
A_answer ≈ W · R_pre
```

意思是：

```text id="77z5g7"
用一个线性矩阵 W，把 pre-answer（答案前）状态映射到 answer（答案位置）状态。
```

但 Phase 504-505（第504-505阶段）显示这个假设失败：

```text id="bwcwq0"
W·R_pre（岭回归预答案转移）在末层和关键层预测完整 answer hidden state（答案隐藏状态）时，R²（决定系数）全为负。
```

所以现在要修正为：

```text id="dmguso"
W·R_pre 不是全局线性映射；
它最多是某些层、某些位点、某些模板下的局部线性近似。
```

更准确的公式是：

```text id="z1is1m"
V_c^{ans}
=
Φ_{c,T}
(
{H_l(s)}_{(l,s) ∈ Ω(c,T)}
)
```

解释：

```text id="46cln7"
V_c^{ans}：
答案位置的类别语义场。

Φ：
条件化非线性路由函数。

Ω(c,T)：
类别 c 和模板 T 对应的有效层/位点窗口。
```

如果用局部线性近似，可以写成：

```text id="ypooxv"
V_c^{ans}
≈
Σ_{(l,s,λ)∈Ω(c,T)}
β_{l,s,λ}
·
W_{c,T}^{l,s,λ}
·
P_{l,s}(H_l(s))
```

其中：

```text id="4sr0x5"
l：layer（层）
s：site（位点）
λ：scale（尺度）
β：该窗口的权重
P：提取该位点状态的投影函数
```

这条公式的含义是：

```text id="tqxnja"
语义不是从一个位置线性搬到另一个位置，
而是通过多个层、多个位点、多个尺度的条件化路由逐步形成。
```

前两层最后会形成答案位置的类别语义方向。

目前最稳的实验估计是：

```text id="h889g7"
v_c^{ans}
=
h_rich^{ans}
-
h_neutral^{ans}
```

通俗解释：

```text id="8u9e09"
v_c 是“类别丰富句子”和“中性句子”在答案位置隐藏状态的差。
```

例如：

```text id="6278g4"
rich prompt（类别丰富提示）：
The apple is a type of fruit.

neutral prompt（中性提示）：
The apple is a thing.
```

那么：

```text id="k4rxdq"
v_fruit = h_rich - h_neutral
```

这会尽量去掉：

```text id="7tvzks"
apple（苹果）本身
句子格式
通用残差信号
位置状态
```

保留：

```text id="is8czb"
apple 被解释为 fruit（水果）时形成的语义方向。
```

注意：

```text id="dm0lcy"
v_c 不是 W·R_pre 的直接结果；
v_c 是上游字段、MLP 微偏置、注意力路由、构式条件共同形成后的答案位置语义方向。
```

# 五、第三层：RMSNorm Gain（均方根归一化增益）门控读出

第三层回答：

```text id="vylwii"
答案位置已经有了语义方向，模型如何把它读成输出分数？
```

---

## 1. 原始目标-竞争方向

```text id="97s57t"
w_D = W_U(t_c) - W_U(comp_c)
```

解释：

```text id="d8w5dm"
W_U：
unembedding（反嵌入）矩阵，也就是把隐藏状态投到词表分数的矩阵。

t_c：
target token（目标词元），例如 fruit（水果）。

comp_c：
competitor tokens（竞争项词元），例如 tool（工具）、object（物体）等。
```

所以：

```text id="rdp1k7"
w_D 表示“目标比竞争项更强”的读出方向。
```

---

## 2. 增益加权读出方向

```text id="7ka18q"
q_c = g ⊙ w_D
```

其中：

```text id="835ccy"
g：
RMSNorm Gain（均方根归一化增益）。

⊙：
逐维相乘。
```

通俗解释：

```text id="0o9vc4"
w_D 是原始读出方向；
q_c 是模型真正使用的有效读出通道。
```

Phase 498-503（第498-503阶段）说明：

```text id="eh6rlq"
Gain（增益）通常不大幅旋转方向；
但会改变不同维度的读出强度。
```

所以 gain（增益）不是创造语义，而是选择性读出语义。

## 3. DCF（决策对比函数）

完整状态读出公式是：

```text id="yo387g"
D_c(h)
=
<h_pre^{ans}, q_c>
/
rms(h_pre^{ans})
```

解释：

```text id="g7yqgr"
D_c：
目标相对竞争项的分数差。

h_pre^{ans}：
答案位置、RMSNorm（均方根归一化）之前的隐藏状态。

q_c：
增益加权目标-竞争读出通道。

rms(h)：
隐藏状态整体尺度。
```

通俗说：

```text id="ay27a2"
DCF = 隐藏状态在目标-竞争读出通道上的投影，再除以整体范数。
```

# 六、因果变化公式

如果我们人为加入一点类别语义方向：

```text id="z9rjvc"
h' = h + α v_c
```

那么 DCF（决策对比函数）的变化近似是：

```text id="ugahgy"
ΔD_c
≈
α · <v_c, q_c> / rms(h)
-
D_c · α · <h, v_c> / (d · rms(h)^2)
```

这个公式有两项。

---

## 第一项：投影项

```text id="ni5tcb"
α · <v_c, q_c> / rms(h)
```

解释：

```text id="trncjs"
你加进去的语义方向 v_c，
在有效读出通道 q_c 上有多少投影。
```

如果投影大，DCF（决策对比函数）变化大。

---

## 第二项：范数项

```text id="kpyc37"
- D_c · α · <h, v_c> / (d · rms(h)^2)
```

解释：

```text id="20q99l"
加入 v_c 后，隐藏状态整体范数可能变化；
RMSNorm（均方根归一化）会重新缩放整个状态；
这个缩放也会影响 DCF。
```

但 Phase 502-503（第502-503阶段）说明：

```text id="lr7a8i"
第一项绝对主导，第二项通常很小。
```

所以最常用简化式是：

```text id="9jf5pt"
ΔD_c ≈ α · <v_c, q_c> / rms(h)
```

这就是当前最核心的因果公式。

# 七、parallel/perp（平行/正交）实验说明了什么？

把 v_c 分成：

```text id="0gjc2t"
v_para = Proj_{q_c}(v_c)
v_perp = v_c - v_para
```

解释：

```text id="2b60zi"
v_para：
v_c 在 q_c 上的平行成分。

v_perp：
v_c 中和 q_c 正交的部分。
```

Phase 503（第503阶段）中 matched-norm（匹配范数）干预显示：

```text id="91eb15"
v_para 有效；
v_perp 几乎无效；
random（随机方向）无效。
```

这说明：

```text id="haf7h9"
语义方向不是整条都能被读出；
只有落在 q_c 读出通道上的部分才能影响输出。
```

这就是当前体系最强的因果证据之一。

# 八、T/C 双模：目标增强和竞争压制

DCF（决策对比函数）本质是：

```text id="b0l0kr"
D = T - C
```

其中：

```text id="umg3nw"
T：target（目标）logit（词表分数）
C：competitor（竞争项）logit（词表分数）
```

所以变化是：

```text id="deq8ko"
ΔD = ΔT - ΔC
```

这说明 DCF（决策对比函数）上升有两种方式。

---

## 方式1：T-主导，目标增强

例如 emotion（情绪）、animal（动物）：

```text id="5p26bn"
目标项上升更多，
所以 DCF 上升。
```

这叫：

```text id="3rauws"
target-driven（目标驱动）
```

---

## 方式2：C-主导，竞争压制

例如 fruit（水果）、clothing（衣物）、action（动作）：

```text id="eqqoit"
目标项可能只小幅上升，甚至下降；
但竞争项下降更多，
所以 DCF 仍然上升。
```

这叫：

```text id="wtacmv"
competitor-suppression（竞争项压制）
```

这个发现非常重要，因为它说明：

```text id="si2h3n"
模型输出语义不一定是把正确答案推高；
很多时候是把错误解释压下去。
```

# 九、token（词元）级输出还没有完全闭合

DCF（决策对比函数）不是最终输出。

最终 token（词元）分数是：

```text id="08dpye"
logit_y
=
LMHead[
    RMSNorm(h_pre^{ans})
]_y
+
G_surface(y,T,S)
```

其中：

```text id="mprfnb"
LMHead：
词表头。

G_surface：
surface gate（表面门控），包括 set writer（集合写入器）、格式门控、候选集合约束等。
```

这解释了为什么 GPT5 路线（第五代GPT路线）中出现：

```text id="5l2neg"
DCF 恢复了，但 category_argmax_rate（类别词最大值率）仍然为 0。
```

因为：

```text id="tdji7m"
读出层恢复 ≠ 具体 token 输出闭合。
```

还需要 surface gate（表面门控）和 set writer（集合写入器）。

把所有层合起来，可以写成：

```text id="z9cgja"
ReadableMeaning_c(x,T)
```


其中：


# 十一、用一句最通俗的话讲完整体系

```text id="jlbyex"

再经过表面输出门控变成具体词元。
```

# 十二、当前体系的状态：哪些已经强，哪些还弱？

## 已经比较强的部分


```text id="s3zuhz"
6. 跨语言、组合语义、否定、关系推理还没有完全纳入。
```

# 十三、当前理论的最终版本

当前最合理的理论名称：

```text id="yr98k0"
条件化三层路由—增益读出理论
```

最终表述：

```text id="2xqv9y"
语言编码不是静态概念向量，也不是单一线性转移矩阵。

语言首先在每层形成由词元身份、语法角色、句式构式和操作符组成的上下文字段。
然后，中间层通过注意力路由、MLP 微偏置积分、层位/位点/尺度条件化传播，把这个上下文字段转化为答案位置的语义方向。
最后，答案位置的语义方向通过 RMSNorm Gain 定义的目标-竞争读出通道被读取，形成 DCF。
不同类别可以通过目标增强或竞争压制显化语义。
DCF 之后还需要经过 surface gate 和 set writer 才能闭合到具体 token 输出。
```

最短公式版：

```text id="mrmf3h"
语言意义
≈
<
h_rich^{ans} - h_neutral^{ans},
g⊙[W_U(target)-W_U(competitor)]
>
/
rms(h_pre^{ans})
```

但这个公式只描述末端读出。完整系统还要加上：

```text id="9fmrqu"
h_rich^{ans} - h_neutral^{ans}
=
Φ(
R/C/O 上下文字段,
MLP 微偏置,
多步路由,
竞争抑制
)
```

所以完整版本是：

```text id="4lzfxy"
语言意义
≈
<
Φ(H_{RCO}, MLP_microbias, Route, Suppressor),
g⊙(W_U(target)-W_U(competitor))
>
/
rms(h)
```

这就是当前整个数学体系的核心。
