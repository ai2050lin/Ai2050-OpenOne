# 一、物理学和生物学的数学对象为什么不同？

## 1. 物理学偏向守恒量

经典物理最成功的对象通常是：

```text
粒子
场
能量
动量
角动量
电荷
对称性
作用量
哈密顿量
拉格朗日量
```

物理学常见形式是：

[
\delta S = 0
]

或者：

[
\frac{dQ}{dt}=0
]

其中 (Q) 是守恒量。

物理学之所以容易理论化，一个关键原因是：

```text
物理系统常常可以抽象为：
低维状态变量
固定规则
封闭或近封闭系统
明确边界条件
可重复实验
对称性
守恒律
```

---

## 2. 生物学偏向维持、修复、复制和适应

生命系统的核心不是守恒，而是：

```text
维持边界
维持状态范围
维持功能
修复损伤
适应扰动
复制自身
改变自身结构
调控环境交互
```

生命系统不是简单满足：

[
\frac{dQ}{dt}=0
]

而更像满足：

[
x(t)\in \mathcal{V}
]

其中：

```text
x(t)：
  生物系统当前状态。

\mathcal{V}：
  viability set（可生存状态集合）。
```

也就是说，生命的“守恒量”不是某个固定数值，而是：

```text
系统状态长期停留在可生存区域中。
```

这可以叫：

```text
可生存域不变量
```

# 二、生物学真正需要的不变量是什么？

我认为生物系统的候选不变量不是能量，也不是结构，而是：

```text
边界可维持性
+
功能可闭合性
+
扰动后可恢复性
+
复制后可延续性
```

可以合成一个总不变量：

```text
生命闭合不变量
```

数学写成：

[
\mathcal{I}_{life}
==================

\left(
\mathcal{B},
\mathcal{V},
\mathcal{F},
\mathcal{R},
\mathcal{G}
\right)
]

其中：

```text
\mathcal{B}：
  boundary structure（边界结构），例如细胞膜、组织边界、身体边界、神经系统输入输出边界。

\mathcal{V}：
  viability domain（可生存域），系统状态允许波动但不能离开该区域。

\mathcal{F}：
  functional closure（功能闭合），系统功能链条能够闭合，例如代谢闭合、感知-行动闭合、免疫闭合。

\mathcal{R}：
  repairability（可修复性），系统受扰动后能回到可行状态。

\mathcal{G}：
```

这个不变量不是常数，而是一个**结构保持条件**。

也就是说：

[
\mathcal{I}*{life}(t)

\mathcal{I}*{life}(t+\Delta t)
]

不是说每个分子不变，而是说：

```text
边界仍在；
功能仍能闭合；
状态仍在可生存域内；
系统仍能修复和生成。
```

这比传统守恒量更适合生物学。

# 三、为什么传统数学难以描述生物？

因为传统数学常把系统写成：

[
\frac{dx}{dt}=f(x)
]

但生命系统更像：

[
\frac{dx}{dt}
=============

f(x,e,b,m,g,\theta,t)
]

其中：

```text
x：
  内部状态。

e：
  环境状态。

b：
  边界状态。

m：
  记忆 / 历史状态。

g：
  基因 / 发育约束。

\theta：
  可变参数，例如调控网络、突触权重、表观遗传状态。

t：
  时间。
```

更重要的是，生命系统会改变自己的 (f)：

[
f_{t+\Delta t}
\neq
f_t
]

这就是生物学比物理学难的地方：

```text
物理系统通常状态变，规则不变；
生命系统状态变，规则也在慢时间尺度上变。
```

所以需要把系统写成双层动力学：

[
\frac{dx}{dt}=f_\theta(x,e)
]

[
\frac{d\theta}{dt}=g_\phi(x,e,\mathcal{L})
]

其中：

```text
x：
  快变量，例如神经活动、代谢浓度、蛋白构象。

\theta：
  慢变量，例如连接强度、基因表达、调控参数、形态结构。

\mathcal{L}：
  系统的生存 / 预测 / 功能误差。
```

# 四、候选新理论：边界维持—功能闭合—多尺度生成理论

这个理论的核心假设是：

```text
生命系统不是由守恒量定义，
而是由多尺度状态在边界内维持功能闭合的能力定义。
```

---

## 1. 系统状态

定义生命系统状态：

[
X(t)
====

\left[
x_1(t),
x_2(t),
\dots,
x_n(t)
\right]
]

它包含多个尺度：

```text

  蛋白质、RNA、代谢物。

细胞尺度：
  膜电位、基因表达、细胞周期。

组织尺度：
  细胞排列、机械力、信号场。

器官尺度：

行为尺度：
  感知、动作、环境交互。

进化尺度：
  基因频率、选择压力、群体结构。
```

可以写成：

[
X(t)
====

{X^{(m)}(t)}_{m=1}^{M}
]

其中 (m) 表示尺度。

---

## 2. 边界

生命系统必须有边界：

[
\mathcal{B}(t)
]

边界不是静态墙，而是选择性耦合界面：

[
\mathcal{B}(t):
E(t)
\leftrightarrow
X(t)
]

它决定：

```text
什么进入系统；
什么被排出；
哪些信息被感知；
哪些行动作用于环境。
```

细胞膜、免疫边界、血脑屏障、皮肤、感觉器官、神经输入输出，都属于边界。

---

## 3. 可生存域

定义可生存域：

[
\mathcal{V}
===========

\left{
X:
c_i^{-}
\leq
\phi_i(X)
\leq
c_i^{+},
\quad
i=1,\dots,k
\right}
]

其中：

```text
\phi_i(X)：
  生物状态指标，例如 pH、温度、ATP、离子浓度、蛋白折叠状态、神经兴奋度。

c_i^{-}, c_i^{+}：
  可生存范围。
```

生命系统的基本约束是：

[
X(t)\in \mathcal{V}
]

但不是永远固定在一点，而是在可生存域中动态波动。

---

## 4. 功能闭合

功能不是单个输出，而是一个因果环：

[
F_1
\rightarrow
F_2
\rightarrow
\dots
\rightarrow
F_k
\rightarrow
F_1
]

例如：

```text
代谢闭合：
  营养摄取 -> 能量生成 -> 蛋白合成 -> 酶维持 -> 营养摄取

神经闭合：
  感觉输入 -> 内部状态 -> 动作输出 -> 环境改变 -> 新感觉输入

免疫闭合：
  抗原识别 -> 信号扩增 -> 清除 -> 记忆 -> 后续识别
```

定义功能闭合误差：

[
\mathcal{E}_{closure}
=====================

\left|
F_{k}(X)
--------

F_{1}(X)
\right|
]

生命系统需要：

[
\mathcal{E}_{closure}<\epsilon
]

# 五、统一生命作用量

物理学有最小作用量。生物学也可以构造一个“生命作用量”，但它不是最小能量，而是最小化多种失败风险。

定义：

[
\mathcal{A}_{life}
==================

\int_{0}^{T}
\left[
\lambda_V D_{\mathcal{V}}(X(t))
+
\lambda_B D_{\mathcal{B}}(X(t))
+
\lambda_F \mathcal{E}*{closure}(X(t))
+
\lambda_E E*{cost}(X(t))
+
\lambda_P \mathcal{E}*{pred}(X(t))
+
\lambda_R \mathcal{E}*{repair}(X(t))
\right]dt
]

其中：

```text
D_\mathcal{V}：
  离开可生存域的距离。

D_\mathcal{B}：
  边界破坏程度。

\mathcal{E}_{closure}：
  功能闭合误差。

E_cost：
  能量代价。

\mathcal{E}_{pred}：
  预测误差。

\mathcal{E}_{repair}：
  修复误差。

\lambda：
  各项权重。
```

生命系统的轨迹近似满足：

[
X^*(t)
======

\arg\min_X
\mathcal{A}_{life}
]

这不是说生命有意识地最小化这个量，而是：

```text
能长期存在的生命系统，必然表现得像在降低这些失败风险。
```

这个思想与 Free Energy Principle（自由能原理）有亲缘关系，但我这里加入了更明确的：

```text
边界项；
功能闭合项；
修复项；
多尺度生成项；
竞争抑制项。
```

自由能原理把生命和认知描述为最小化变分自由能、最大化模型证据或降低惊讶度；其支持者用 Markov blanket（马尔可夫毯）描述内部状态、外部状态、感知状态和行动状态的分隔与耦合。这个思路很有启发，但也常被批评过于抽象，难以直接给出具体机制。因此新的框架需要把自由能类思想具体化为“边界、闭合、修复、生成、竞争”的可测项。([arXiv][3])

物理中对称性给出守恒律。

生命中更重要的是：

```text
如何在不对称、开放、损耗、噪声、突变中维持功能。
```

所以生命的不变量不是对称性本身，而是：

```text
功能闭合结构在扰动下保持。
```

```text
发育历史；
表观遗传；
学习；

进化路径；
组织损伤史。
```

所以状态必须带有记忆：

[
X(t)
====

F(X(t-1),M(t),E(t))
]

其中 (M(t)) 是历史记忆。

---

## 4. 物理系统变量通常预设，生命系统变量会变

在物理中，变量通常一开始就定义好了。

生命系统中，变量本身会出现或消失：

```text
新细胞类型；
新突触；
新蛋白复合体；
新行为模式；
新生态位。
```

所以数学对象应该允许状态空间改变：

[
\mathcal{S}*{t+\Delta t}
\neq
\mathcal{S}*{t}
]

这也是现有数学难处理生命的原因之一。

[
x^*

这里：

# 八、用这个理论解释线虫神经系统

```text
环境反馈
本体感觉
行为状态
```

所以应写成多模块闭合：

[
X
=

(N,S,M,B,E)

```text
N：

S：
```

[

[
\dot{B}=f_B(B,M,E)

[

形成闭环：

[
S
\rightarrow
N
\rightarrow
M
\rightarrow
B
\rightarrow

这与近期 C. elegans（线虫）建模趋势一致：仅有连接组不够，需要把神经、肌肉、身体力学和反馈整合成多模块系统。modWorm（模块化线虫模型）这类工作就把细胞内动力学、突触动力学、肌肉钙、肌肉力、身体姿态和本体反馈集成到一个系统中，以模拟行为。([arXiv][5])

所以线虫的核心不变量不是连接矩阵，而是：

```text
感知—神经—肌肉—身体—环境闭环可维持。
```

数学上：

[
\mathcal{E}_{loop}
==================

\left|
S_{t+\Delta t}
--------------

f_S(f_B(f_M(f_N(S_t))))
\right|
]

系统需要：

[
\mathcal{E}_{loop}<\epsilon
]
