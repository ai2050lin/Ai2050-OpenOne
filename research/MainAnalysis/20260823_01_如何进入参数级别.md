# 一、项目现在究竟走到了哪里

C153–C155 是一个重要转折。

## 1. C153：第一次前瞻预测了晚层关系场的运动

C153在全新材料上，对类型关系的六个角色、2560个坐标、q24–q33十步变化进行预测，得到：

* 总体中位余弦：`0.833528`
* 相对误差：`0.552722`
* 十个检查点全部通过冻结预测门
* 错角色、错坐标控制明显更差
* 但预测对象是成对正负样本形成的半差分场：

[
X_q=\frac12(H_q^+-H_q^-)
]

这说明某种晚层条件响应动力学可以预测，但没有证明模型自然运行时内部真的保存一个叫 (X_q) 的变量。

## 2. C154：这个预测场能够强烈控制输出

C154把预测出的完整六角色场写入，得到：

* 预测补丁中位输出增益：`33.009834`
* donor目标选择率：`0.90625`
* 反向、错角色、错坐标控制明显较弱

这是很强的因果可控性。

但它有一个决定性硬伤：

[
X_{31}=\frac12(H_{31}^+-H_{31}^-)
]

本身已经同时使用了真实正例 donor 和负例 recipient。也就是说，实验把答案方向的一大部分直接交给了算法。

因此它证明的是：

> 使用真实反事实对构造的全场方向，可以强烈操纵模型。

它没有证明：

> 模型能够仅根据当前单个输入，自然计算出这个关系方向。

而且没有分开测试：

[
2X_{31},\qquad 2\widehat Y_{31},\qquad
2(X_{31}+\widehat Y_{31})
]

所以还不知道输出控制主要来自原始 donor 差分，还是来自新学到的增量预测器。

## 3. C155：同一方向在宽层窗口都能调用

相同方向注入 q24–q34 全部产生正增益，而且 q24 的增益 `40.557747`，反而高于冻结的 q32 增益 `33.009834`。

因此不能说 q31→q32 是这套机制的自然形成位置。

更严格的解释是：

> 后半段网络在很宽的状态窗口内，都能响应这个人工写入方向。

这更像找到了一只“通用遥控器”，还不是找到了遥控器信号在机器内部自然产生、传递和读取的线路。

## 4. 当前证据闭合度

| 机制问题          | 当前状态            |
| ------------- | --------------- |
| 是否观察到稳定关系响应场  | 是               |
| 是否跨新材料复现      | 是               |
| 是否能预测晚层场运动    | 是，限成对差分和六角色     |
| 是否能控制输出       | 是，限donor条件化全场补丁 |
| 是否找到自然单输入生成机制 | 没有              |
| 是否找到唯一形成层     | 没有，局部身份门失败      |
| 是否找到单坐标齿轮     | 没有              |
| 是否证明必要性       | 未测试             |
| 是否证明组合律       | 未测试             |
| 是否跨模型         | 未测试             |

所以最准确的阶段判断是：

[
\boxed{
\text{观察、复现、预测、人工控制已经取得进展；}
\quad
\text{自然生成、局部齿轮、必要性、组合律尚未破解。}
}
]

# 二、为什么余弦和大块替换已经到达上限

## 1. 余弦只回答“整体方向像不像”

两个2560维场余弦很高，可能来自：

* 许多坐标共同稳定；
* 少数大幅坐标支配；
* Yes/No输出准备；
* 相同提示骨架；
* LayerNorm造成的共同方向；
* 真正关系机制；
* 上述因素的混合。

它无法告诉我们：

> 第731坐标的变化，是由哪个token、哪个上一层坐标、在什么上下文条件下驱动的。

## 2. Top-K只给“位置名单”，不给齿轮啮合关系

即使某256个坐标双向干预有效，也不知道：

* 它们彼此是否协作；
* 谁驱动谁；
* 是否只是同一大信号的多个影子；
* 是否存在促进与抵消；
* 换一个上下文后是否由另一组坐标承担同一功能。

## 3. 大块替换混合了太多变量

完整角色或完整差分场写入同时改变成千上万个激活值。输出改变只能说明这个整体是有效控制量，不能定位内部传输结构。

这就像把汽车整个变速箱换掉，发现速度变化了，却仍不知道哪两个齿轮在啮合。

## 4. 纯观察也不可能唯一恢复因果齿轮

这是一个必须正视的可识别性边界：

> 如果既不看attention、MLP和权重，也不允许梯度或任何形式的微小干预，仅观察自然HiddenState轨迹，就不可能唯一确定坐标间的因果线路。

不同内部传输图可以产生相同的观测轨迹。

因此新路线不能完全拒绝干预，而应把“粗暴语义替换”改成“微小编码刺激下的系统辨识”。微干预只是测量仪器，最后的机制结论必须来自可预测、可重复的传输图。

# 三、新的核心算法：全状态条件关系图谱辨识

建议把新算法称为：

[
\boxed{\text{全状态条件关系图谱辨识}}
]

它同时建立两张图。

## 1. 语言关系图

[
\mathcal G_L=(V_L,E_L)
]

节点是实体、事件、属性或命题，边是语言关系：

* agent、patient
* like、eat
* is-a、part-of
* before
* negation、scope
* contrast
* translation
* coreference
* hierarchy

例如“我喜欢吃苹果”的实验者语义图可以写成：

```text
我 ──experiencer──> 喜欢
我 ──agent────────> 吃
苹果 ─patient─────> 吃
吃事件 ─content───> 喜欢
```

这只是实验设计图，不预设模型内部使用同样的符号结构。

## 2. HiddenState因果传输图

[
\mathcal G_H=(V_H,E_J,E_B)
]

每个节点定义为：

[
v=(q,t,j)
]

其中：

* (q)：层间检查点；
* (t)：token或角色位置；
* (j)：激活坐标。

一阶有向边：

[
J_q[(t',k)\leftarrow(t,j)]
==========================

\frac{\partial H^{q+1}*{t',k}}
{\partial H^q*{t,j}}
]

表示：

> q层某token的第j坐标轻微变化，会如何影响下一检查点某token的第k坐标。

二阶超边：

[
B_q[(u,v)\rightarrow w]
=======================

\frac{\partial^2 H^{q+1}_w}
{\partial H^q_u\partial H^q_v}
]

表示：

> 两个坐标必须同时出现，才会驱动第三个坐标。

这才接近“齿轮啮合”，而不是坐标名单。

# 四、怎么测出这张图：正交微扰层析

完整因果矩阵极大，不能逐坐标暴力扫描。应采用类似网络分析仪的编码刺激。

## 1. 不再搬运donor，而是发送微小正交测试信号

对完整token×坐标状态 (Z_q) 加入微小正交编码 (v_k)：

[
Z_q^{\pm}=Z_q\pm\varepsilon v_k
]

记录下一检查点变化：

[
J_qv_k
\approx
\frac{
\Phi_q(Z_q+\varepsilon v_k)
---------------------------

\Phi_q(Z_q-\varepsilon v_k)
}{2\varepsilon}
]

(v_k) 可以采用Hadamard或平衡随机符号模式。一次刺激可以同时编码大量坐标，随后从多组响应中反演传输结构。

这与旧方法的区别是：

* 旧方法：搬进一个大型语义答案方向；
* 新方法：发送不携带答案的微小测试码；
* 旧方法：观察最终logit有没有变化；
* 新方法：恢复下一检查点每个token、每个坐标的传输关系。

## 2. 分离线性边和非线性协作

用对称刺激估计一阶传输，用组合刺激估计二阶协作：

[
B_q[u,v]
\approx
\frac{
\Phi(H+\varepsilon u+\varepsilon v)
-\Phi(H+\varepsilon u-\varepsilon v)
-\Phi(H-\varepsilon u+\varepsilon v)
+\Phi(H-\varepsilon u-\varepsilon v)
}{4\varepsilon^2}
]

不能穷举全部坐标对。实际采用三级筛选：

1. 随机编码层析，找到可能的传输区域；
2. 在候选区域内恢复稀疏边或低秩块；
3. 只对重复出现的坐标群检查二阶、三阶超边。

## 3. 不预设“稀疏”或“低维”

一次性比较多个动力学模型：

* 对角坐标模型；
* token内坐标混合；
* 跨token传输；
* 低秩模型；
* 稀疏加低秩模型；
* 状态门控模型；
* 二阶超图模型；
* 关系条件混合模型。

以未参与建模的新刺激、新词汇和新组合上的预测能力裁决，而不是看训练拟合或余弦。

# 五、主要评价指标也必须更换

余弦可以保留为辅助图示，但不能再做核心机制门。

核心指标应变为：

## 1. 逐坐标带符号预测误差

[
E_{\mathrm{coord}}
==================

\frac{
\sum_{t,j}
|\widehat{\Delta H}*{t,j}-\Delta H*{t,j}|
}{
\sum_{t,j}|\Delta H_{t,j}|
}
]

它要求数值、符号和幅度都正确，不能靠整体方向蒙混。

## 2. 多步自然滚动误差

从冻结的早期真实状态开始，只给一次初始状态：

[
\widehat Z_{q+1}=\widehat\Phi_q(\widehat Z_q)
]

后续不能每层重新读取真实未来HiddenState。否则只是逐层校正，不是动力学模型。

## 3. recipient-only反事实生成

模型只能看到当前单个状态和要求施加的关系编辑：

[
\widehat Z_q(x\oplus\rho)
=========================

T_{\rho,q}(Z_q(x))
]

测试时禁止读取目标donor状态。

这是下一阶段最关键的资格门。做不到这一点，就仍然只是运输已经给出的差分，不是生成关系机制。

## 4. 局部因果选择性

对图谱预测的重要边进行：

* 微量写入；
* 删除；
* 符号反转；
* 剂量曲线；
* 删除后救援；
* 错token；
* 错角色；
* 错关系；
* 错层；
* 等能随机控制；
* 自由生成副作用检查。

只有预测边的局部作用可重复，而控制边没有相同作用，才能称为齿轮。

## 5. 组合泛化

真正的语言机制必须预测没有训练过的排列，而不是记住已有条件：

[
T_{\rho_2\circ\rho_1}
\stackrel{?}{\approx}
T_{\rho_2}\circ T_{\rho_1}
]

这才是从“现象图谱”进入“语言数学”的核心门。

# 六、如何破解具体语言模式

## 1. “我喜欢吃苹果”

不要只比较整句HiddenState，而是把它作为嵌套组合问题。

候选结构：

[
\mathrm{LIKE}
\big(
\mathrm{我},
\mathrm{EAT}(\mathrm{我},\mathrm{苹果})
\big)
]

大规模正交改变：

* experiencer：我/你/其他实体；
* 内嵌agent：我吃/你吃；
* attitude：喜欢/讨厌/声称；
* action：吃/买/看；
* patient：苹果/香蕉/其他类别；
* 否定；
* 语序；
* 主动/被动；
* 指代；
* “但是”等后续修正；
* 一层、两层和更深嵌套。

先分别辨识：

[
T_{\mathrm{EAT}},\quad
T_{\mathrm{LIKE}},\quad
T_{\mathrm{agent}},\quad
T_{\mathrm{patient}}
]

再用没有见过的组合检验：

[
T_{\mathrm{LIKE(EAT)}}
\stackrel{?}{\approx}
T_{\mathrm{LIKE}}
\circ
T_{\mathrm{EAT}}
]

如果简单顺序复合失败，再测试“带插槽的组合”：

[
T_{\mathrm{LIKE}}
[\mathrm{experiencer},\mathrm{content}]
]

这类结构如果稳定，更接近operad式的嵌套组合，而不是普通向量相加。

## 2. “但是”

保持两个命题内容不变，只改变连接方式：

* A，并且B；
* A，但是B；
* 虽然A，B；
* B，但是A；
* A，所以B；
* 单独A、单独B。

重点不问“是不是转折”，而是辨识：

> “但是”出现后，A侧状态对后续边界的传输边如何被削弱，B侧传输边如何被增强或重新加权。

对应对象不是“但是向量”，而是门控变换：

[
J_q^{\mathrm{but}}(Z)
---------------------

J_q^{\mathrm{and}}(Z)
]

如果跨内容、跨释义重复，才得到转折模式的齿轮结构。

## 3. 翻译

分别辨识：

[
T_{\mathrm{EN\rightarrow FR}},
\quad
T_{\mathrm{FR\rightarrow ZH}},
\quad
T_{\mathrm{EN\rightarrow ZH}}
]

然后测试：

[
T_{\mathrm{FR\rightarrow ZH}}
\circ
T_{\mathrm{EN\rightarrow FR}}
\stackrel{?}{\approx}
T_{\mathrm{EN\rightarrow ZH}}
]

再测试近似逆：

[
T_{\mathrm{FR\rightarrow EN}}
\circ
T_{\mathrm{EN\rightarrow FR}}
\stackrel{?}{\approx}I
]

若只对部分语义类型成立，就说明翻译不是一个统一旋转，而是关系条件化的算子族。

## 4. 苹果—水果—食物—物体

需要三条并行分支：

* 人工新词图：排除训练记忆；
* 自然知识图：苹果—水果—食物—物体；
* 反事实图：提示中临时改变类别关系。

苹果的研究对象不是某个坐标，而是它的关系生态：

[
\mathcal E(\mathrm{apple})
==========================

{
(\rho,b,T_\rho(\mathrm{apple},b))
}_{b,\rho}
]

包含：

* 同类；
* 上位；
* 属性；
* 功能；
* 部分；
* 相似；
* 对立；
* 使用情境。

核心组合检验是：

[
T_{\mathrm{fruit\rightarrow food}}
\circ
T_{\mathrm{apple\rightarrow fruit}}
\stackrel{?}{\approx}
T_{\mathrm{apple\rightarrow food}}
]

还要测试：

* 换成banana是否保持同一关系传输图；
* 全部节点重命名后是否保持功能图；
* 自然知识与反事实提示冲突时使用哪张图；
* 有捷径边和无捷径边时组合机制是否改变。

# 七、可能出现的数学结构是什么

当前最有希望的并不是“固定语义流形”，而是：

[
\boxed{\text{状态依赖、类型化、可部分组合的关系算子系统}}
]

它包含：

* 对象：上下文中的角色状态；
* 算子：关系编辑或关系传输；
* 门控：当前上下文决定调用哪个算子；
* 物理实现：token—坐标有向图和高阶超边；
* 复用：跨关系重复的传输图模体；
* 差分：关系特异的门、边权、角色和形成时钟；
* 条件化：相同模体随上下文改变权重或组合方式。

几种数学候选应由实验结果选择：

| 如果观察到的规律       | 合适数学候选      |
| -------------- | ----------- |
| 可逆关系变换和稳定逆元    | 群或群胚        |
| 只有类型兼容时才能组合    | 范畴/半群胚      |
| 句法插槽和嵌套组合稳定    | Operad      |
| 高阶坐标必须协同       | 张量超图        |
| 局部坐标图可拼接但全局不统一 | 丛或层结构       |
| 只有状态依赖局部线性     | 非线性动力系统/算子场 |

目前没有一个候选获得证据资格。尤其不能从高余弦、八个置换或宽层调用，直接宣布群论、流形或拓扑。

# 八、统一理论不改名，但数学主体应升级

理论仍叫：

**条件化输出场闭合理论**

组织原则仍是：

**复用—差分—条件化（RDC）**

建议把统一机制式升级为：

[
Z_0=E_\theta(x)
]

[
Z_{q+1}
=======

\mathcal T_q
\left(
Z_q;\mathcal G_L(x)
\right)
]

局部齿轮展开为：

[
\delta Z_{q+1}
==============

J_q(Z_q,\mathcal G_L)\delta Z_q
+
\frac12B_q(Z_q,\mathcal G_L)
[\delta Z_q,\delta Z_q]
+\cdots
]

RDC不预设简单相加，而写为：

[
\mathcal T_q
============

\mathcal C_q
\left(
\mathcal T_q^{\mathrm{reuse}},
\mathcal D_{q,\rho},
g_q(Z_q,\mathcal G_L)
\right)
]

最终输出：

[
y=O_\kappa(Z_L)
]

全局双图谱公式为：

[
\boxed{
\Pi_x:
\mathcal G_L(x)
\longrightarrow
\mathcal G_H(x)
}
]

其中：

[
\mathcal G_H(x)
===============

\big(
{(q,t,j)},
E_J(x),
E_B(x)
\big)
]

通俗地说：

```text
语言关系图
    │
    │  上下文条件映射 Π

token × layer × coordinate 因果超图

    ▼
truth / task state
    ▼
输出协议与全词表竞争
```

# 十、最终判断

当前项目已经证明：

> HiddenState中确实存在可重复、可预测、可强控制的条件关系响应场。

但尚未证明：

> 模型自然地用哪些单坐标齿轮生成、传输并组合这些关系。

下一步真正需要的突破不是“更好的余弦”，也不是“再换一个K”，而是：

[
\boxed{
\text{从向量相似性研究}
\rightarrow
\text{全token激活坐标因果图谱}
\rightarrow
\text{关系算子}
\rightarrow
\text{未见组合预测}
}
]

如果最终发现稳定的类型化组合律、逆变换、插槽组合或高阶守恒关系，那么新数学确实可能出现；如果没有这些规律，提前使用群论、流形、拓扑，只会给尚未破解的现象换一个更华丽的名字。

最关键的一句话是：

> “精密齿轮”不是第731坐标本身，而是第731坐标在特定token、层、关系和上下文中，对其他坐标产生的带符号、可预测、可组合的因果作用。

这才是下一阶段应该完整测绘的对象。
