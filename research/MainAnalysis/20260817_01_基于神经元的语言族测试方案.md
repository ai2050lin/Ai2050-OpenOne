回答：

结论先说：

> 研究确实应该从 Hidden State 级别继续深入到 MLP 神经元、attention 运输单元、神经元联盟和参数组级别；但“复杂关系编码必然对应单个参数”并不成立。

需要先修正三个关键概念：

1. `2560` 是每个 token 的 Hidden State 维度，是动态激活变量，不是 2560 个模型参数。Qwen3-4B 实际有约 40 亿个权重参数。

\boxed{

\text{跨层跨位置的状态运输}

\mathrm{family@3/15}

\mathrm{query/boundary}

\mathrm{output}.

# 一、为什么有限维状态可以处理极多语言关系

模型并不是在 2560 个槽位里逐条存放：

* 苹果属于水果；
* 苹果不同于动物；
* 苹果具有颜色；
* 苹果可以食用；
* 苹果出现在某种句法角色中。

更可能的方式是：同一套参数实现一个可复用的条件变换规则。

[
H_{\ell+1,p}
============

\Phi_{\ell,p}
\left(
H_{\ell,\le p};
c,\theta
\right).
]

同一个“苹果”在不同上下文中会形成不同状态：

[
H_{\ell,p}(\text{苹果是水果})
\neq
H_{\ell,p}(\text{苹果公司发布产品}).
]

所以模型不是用一个静态坐标列举所有意义，而是把：

* 当前 token；
* 前文对象；
* 被测试关系；
* 查询；
* 输出要求；

组合成一个动态状态。

更准确的说法是：

[
\text{概念}
\approx
\text{大量预测关系的可复用压缩摘要}.
]

语言的组合能力主要来自：

* 权重共享；
* 非线性神经元；
* attention 的条件寻址；
* 多层状态转换；
* 多 token 状态矩阵；
* 自回归反复调用同一网络。

因此“有限参数如何处理近乎无限语言关系”的答案不应是“一条关系一个参数”，而应是：

> 有限参数实现了可重复使用的关系计算程序，具体关系由输入激活模式临时实例化。

# 二、什么才算“神经元级分析”

必须区分五个层级。

| 层级                                | 对象                           | 是否可直接叫神经元 | 主要问题                      |
| --------------------------------- | ---------------------------- | --------: | ------------------------- |
| Residual coordinate               | (H_{\ell,p,i})               |      不严格是 | 坐标可旋转，单维语义不稳定             |
| MLP 中间单元                          | (z_{\ell,p,j})               |    最接近神经元 | 有独立非线性和写回向量               |
| Attention head                    | 整个 head                      |      功能模块 | 内部通道仍可旋转                  |
| Attention source→destination edge | 某 head 从 token (q) 向 (p) 的贡献 |      运输单元 | 同时依赖 QK 寻址和 OV 内容         |
| Weight parameter                  | (W_{ij})                     |     不是神经元 | 跨所有 token、上下文共享，单参数效应通常很小 |

真正适合首先分析的是：

1. MLP 神经元；
2. attention head 的源—目标运输贡献；
3. 这些单元组成的因果联盟；
4. 最后才是联盟背后的参数行、列和单个权重。

# 三、MLP 神经元如何写入 Hidden State

以 Qwen 的 gated MLP 为例，简化公式为：

[
g_{\ell,p}=W_{\mathrm{gate}}^\ell\widetilde H_{\ell,p},
]

[
u_{\ell,p}=W_{\mathrm{up}}^\ell\widetilde H_{\ell,p},
]

[
z_{\ell,p,j}
============

\operatorname{SiLU}(g_{\ell,p,j})
,u_{\ell,p,j},
]

[
M_{\ell,p}
==========

# W_{\mathrm{down}}^\ell z_{\ell,p}

\sum_j
W_{\mathrm{down},:,j}^\ell
z_{\ell,p,j}.
]

对第 (j) 个 MLP 神经元，它写入 residual stream 的完整向量是：

[
v_{\ell,p,j}
============

W_{\mathrm{down},:,j}^\ell z_{\ell,p,j}.
]

这比只看神经元激活值 (z_j) 更重要。

因为两个神经元可以有相似激活，却通过不同的 (W_{\mathrm{down}}) 写向完全不同的状态方向。

因此一个完整的 MLP 神经元功能单元应定义为：

[
\mathcal N_{\ell,j}
===================

\left(
W_{\mathrm{gate},j:},
W_{\mathrm{up},j:},
W_{\mathrm{down},:j},
z_{\ell,j}
\right).
]

# 四、Attention 应该分析什么

仅看 attention weight 不够。

简化后的某个 attention head 从源位置 (q) 向目标位置 (p) 的运输贡献是：

[
C_{\ell,h,p\leftarrow q}
========================

\alpha_{\ell,h,pq}
W_O^{\ell,h}
W_V^{\ell,h}
\widetilde H_{\ell,q}.
]

其中：

* (\alpha)：决定读谁，更接近寻址；
* (W_V/W_O)：决定运输什么，更接近负载；
* (p\leftarrow q)：说明从哪个 token 送到哪个 token。

C056 已经指出：

[
\mathrm{family@3/15}
\rightarrow
\mathrm{query/boundary}.
]

所以新的白盒问题应该是：

> 在第 3–15 层之间，哪些 attention head 的哪些 `query←family` 边，把 family 源状态的有效成分运输到了 query 或 boundary？

应分别测试：

1. 只替换 attention pattern；
2. 只替换 value payload；
3. 替换完整 head 输出；
4. 只替换 `family→query` 这一条源—目标贡献；
5. 替换错误 family、错误 token 或 status 贡献作负控。

只有第 4 种最接近精确的信息运输边。

# 五、神经元级相对编码指标

沿用此前四格设计，对 MLP 神经元定义：

[
I_{\ell,j}^{ab}
===============

z_{\ell,j}^{aa}
-z_{\ell,j}^{ab}
-z_{\ell,j}^{ba}
+z_{\ell,j}^{bb}.
]

对神经元写入向量定义：

[
V_{\ell,j}^{ab}
===============

v_{\ell,j}^{aa}
-v_{\ell,j}^{ab}
-v_{\ell,j}^{ba}
+v_{\ell,j}^{bb}.
]

它回答：

> 这个神经元的激活或写入，是否包含“目标 × 被测家族”的非加性交互？

但非零仍不够，因为 generic truth、输出极性也可能产生二阶交互。

还要比较六类或更多 family-pair：

[
\operatorname{Identity}_{\ell,j}
================================

\Pr
\left[
\operatorname{argmax}*c
\cos(V*{\ell,j},\mu_{\ell,j,c})
=c_{\mathrm{true}}
\right].
]

并要求：

* 跨新目标词；
* 跨表面；
* 跨整家族留出；
* 击败置换标签；
* 击败 explicit-status；
* 击败词面相同但关系不同的控制。

# 六、真正关键的是因果神经元测试

观察到神经元激活不等于它被自然计算使用。

对神经元集合 (S)，至少需要四类测试。

## 1. 必要性

在 clean 输入中，把候选神经元换成 matched corrupt 状态：

[
N(S)
====

## m_{\mathrm{clean}}

m!\left(
\operatorname{do}
(z_S^{\mathrm{clean}}\leftarrow z_S^{\mathrm{corrupt}})
\right).
]

如果 (N(S)>0)，说明移除该联盟会损害正确行为。

---

## 2. 充分性

在 corrupt 输入中写入 clean 神经元状态：

[
U(S)
====

m!\left(
\operatorname{do}
(z_S^{\mathrm{corrupt}}\leftarrow z_S^{\mathrm{clean}})
\right)
-------

m_{\mathrm{corrupt}}.
]

这和 C056 的 whole-state patch 相同，但只写入指定神经元。

---

## 3. 选择性

[
\operatorname{Sel}(S)
=====================

## U_{\mathrm{correct}}(S)

\max
\left(
U_{\mathrm{wrong\ identity}}(S),
U_{\mathrm{wrong\ relation}}(S),
U_{\mathrm{status}}(S),
U_{\mathrm{random}}(S)
\right).
]

正确联盟必须击败错误联盟，不能只是通用输出推动器。

---

## 4. 救援

先阻断完整 C056 源状态，使行为受损；再只恢复候选神经元：

[
R(S)
====

## m_{\mathrm{restore}(S)}

m_{\mathrm{blocked}}.
]

这是最关键的一步：

> 如果完整 family 状态被破坏后，只恢复少量神经元就能重新恢复 C056 级联，那么这些神经元才是 whole-state 因果作用的候选物理实现。

---

# 七、如何从近万个 MLP 神经元中找到真正联盟

逐个穷举全部神经元、全部参数不可行，而且会造成严重多重选择。

建议采用三条路线并行，避免预设编码一定稀疏。

## 路线 A：稀疏神经元假说

如果少量神经元承担主要作用：

1. 观察所有神经元的二阶 interaction；
2. 按跨词、跨表面、跨 family 的重复性排序；
3. 对候选单神经元执行必要性和充分性；
4. 测试前 (k) 个神经元的累积效果；
5. 在独立 lockbox 上验证。

适合发现少量高影响单元。

---

## 路线 B：冗余联盟假说

如果单个神经元可被其他神经元替代，单神经元 ablation 可能全部无效。

需要使用分组干预：

1. 把 MLP 神经元按冻结规则划为若干组；
2. 整组 corrupt/clean interchange；
3. 找出有因果效应的组；
4. 对有效组递归二分；
5. 对最终候选做组合测试；
6. 测试 leave-one-out 和 leave-group-out。

这是一种因果层级搜索，不是 PCA。

它不会把维度投影到低维空间，而是直接干预真实神经元。

---

## 路线 C：稠密编码假说

如果关系作用分布在大量弱神经元中：

1. 不要求单神经元显著；
2. 按完整写入向量与 C056 clean–corrupt 方向的贡献排序；
3. 比较随机 (k) 单元与高贡献 (k) 单元；
4. 测量随联盟规模增长的因果恢复曲线；
5. 检查是否存在明确的容量相变。

定义：

[
F(k)
====

\operatorname{CausalEffect}
\left(
\text{前 }k\text{ 个神经元}
\right).
]

如果 (F(k)) 平滑增长且需要数千神经元，说明编码是稠密的；如果在几十个单元处突然跃迁，说明存在较紧凑的联盟。

三条路线必须全部运行，不能因为单神经元路线失败就宣布“没有神经机制”。

# 八、神经元之间的组合效应

关系编码很可能不是单神经元效应的线性相加。

对两个神经元：

[
\operatorname{Syn}(i,j)
=======================

\Delta m_{{i,j}}
-\Delta m_{{i}}
-\Delta m_{{j}}.
]

对联盟：

[
\operatorname{Syn}(S)
=====================

\Delta m_S
-\sum_{j\in S}\Delta m_{{j}}.
]

可能出现：

* 两个神经元单独无效，联合有效；
* 一个负责 family identity，一个负责 truth gating；
* 一个负责寻址，一个负责内容写入；
* 多个神经元形成冗余备份；
* 错误组合产生通用输出方向。

所以最终研究对象更可能是：

[
\boxed{
\text{输入条件化的神经元联盟}
}
]

而不是一个“苹果神经元”。

# 九、从神经元进一步下降到参数级

找到因果神经元后，才能分析其物理参数。

对 MLP 神经元 (j)，参数组是：

[
\Theta_{\ell,j}
===============

\left{
W_{\mathrm{gate},j:},
W_{\mathrm{up},j:},
W_{\mathrm{down},:j}
\right}.
]

可分成三条测试：

1. `gate` 行控制这个神经元何时打开；
2. `up` 行决定输入内容；
3. `down` 列决定它向 residual 写什么。

分别执行：

* 参数清零；
* 参数缩放；
* clean/corrupt 参数组交换；
* 保范数随机旋转控制；
* 只替换 `down` 写入方向；
* 只替换 gate/up 的条件选择。

单参数 (W_{ij}) 的严格有限差分是：

[
E_{ij}(\delta)
==============

## Q(F_{\theta+\delta e_{ij}}(x))

Q(F_\theta(x)).
]

但单参数效应可能低于 BF16 分辨率。因此应：

* 先找到因果神经元；
* 再测试行、列和小参数块；
* 最后才测试块内单个权重；
* 使用多个预注册扰动幅度；
* 在高精度 shadow block 中校准基线一致性。

单权重失败不能反证该权重参与，因为多个参数可能共同补偿。

# 十、基于 C056 的精确拆解路线

不应重新扫描全模型寻找热点，而应沿已经确认的路径分段拆解。

## 段 1：embedding → family@3

研究第 0–3 层：

* 哪些 MLP 神经元产生 clean–corrupt family 差分；
* 哪些 attention head 引入上下文条件；
* embedding 关系几何能否预测这些神经元的激活；
* correct family 与 wrong identity 的差异最早在哪些单元出现。

## 段 2：family@3 → query@15

研究第 3–15 层：

* 哪些 head 从 family token 向 query token 运输内容；
* 哪些 MLP 神经元重新编码 family 信息；
* 阻断哪些单元会使 C056 下游恢复消失；
* 只恢复哪些单元可以恢复 query 状态。

## 段 3：family@15 → query@27

这是第二条已确认路线：

* 判断它是第一条路径的持续传播；
* 还是第 15 层重新形成的新状态；
* 比较同一神经元联盟是否继续存在；
* 检查 `river__sport` 弱子组是否使用不同联盟。

## 段 4：query/boundary → 输出

C056 尚未证明 query 是中介。

应执行：

1. family 源正确 patch；
2. 确认输出被恢复；
3. 把候选 query 神经元重新改回 corrupt；
4. 看输出恢复是否消失；
5. 对 boundary 神经元重复。

这样才能定位真正的 handoff。

# 十二、什么结果才算“找到神经元语言编码机制”

# 一、问题一：先做大型 Campaign，还是先做神经元组

## 最佳选择：把神经元组嵌入大型 Campaign

不建议现在直接从 2560 个维度里挑一组“高响应神经元”，原因有四个。

### 1. 可读层不一定是因果层

C053 在 layer 27 得到很强的跨家族可读候选，但 C054、C055 证明 layer 27 单点和同层联盟没有选择性充分性。

C056 反而发现：

[
\mathrm{family@3/15}
]

是有效因果源。

这说明如果先根据“哪里看起来最强”选择神经元组，很容易选择晚层输出准备状态，而不是上游控制状态。

---

### 2. 神经元组必须由语言模式定义，而不是只由数值大小定义

某些维度变化很大，可能只是：

* token identity；
* 真假方向；
* yes/no 输出极性；
* 模板；
* surface；
* 候选顺序。

真正需要的组应该满足：

* 同一关系跨词复现；
* 同一关系跨表面复现；
* 整家族留出仍成立；
* 错误关系不激活同一模式；
* status 和通用真值不能冒充；
* 干预后产生选择性效果。

这需要先建立完整语言条件矩阵。

---

### 3. 神经元组可能稀疏，也可能稠密

如果一开始只搜索少量高分维度，就预设了稀疏编码。

实际可能有三种结构：

1. 少量关键坐标；
2. 多组冗余坐标；
3. 大量弱坐标组成的稠密模式。

大型 Campaign 应同时保留三条路线，不能因为单坐标路线失败就停止。

---

### 4. 当前已经有足够明确的搜索锚点

现在不是从零开始观察。

C056 已经给出：

[
\mathrm{family@3}
\quad\text{和}\quad
\mathrm{family@15}
]

两个有限条件域内的因果源。

因此新 Campaign 可以：

* 全层观察；
* 重点解析 `family@3/15`；
* 用 `family@27` 和 query 路线作为已知负参照；
* 直接测试哪些 Hidden-State 坐标组能够保留 whole-state 因果效果。

所以正确方案不是“再观察几百期再做神经元组”，而是：

> 一个父 Campaign 内，先完成全场观察，按冻结规则形成神经元组候选，随后自动进入组级因果竞赛。

# 二、必须先澄清“神经元组”指什么

如果不读取 Attention 和 MLP，那么 2560 维 Hidden State 中的“神经元组”更准确地说是：

> **状态坐标组**或**功能通道组**。

设：

[
H_{\ell,r}
==========

(h_{\ell,r,1},\ldots,h_{\ell,r,2560}).
]

一个组是：

[
S\subseteq{1,\ldots,2560},
]

对应：

[
H_{\ell,r,S}.
]

它是训练后固定模型中的真实 residual 坐标集合，可以直接干预，但要保留一个限制：

> residual 坐标具有基底依赖性，因此这个组首先是 Qwen 当前参数坐标系中的功能组，不应立即称为跨模型通用语义神经元。

真正跨模型比较时，应比较这些组产生的功能响应，而不是比较坐标编号。

# 三、建议建立的核心数据对象

新 Campaign 的核心不应是二维图，而应是一个完整响应张量。

设语言条件 (c) 包含：

* 目标词；
* relation/family；
* relation 类型；
* 真假；
* surface；
* query；
* 输出接口；
* 分区。

保存：

[
X_{c,\ell,r,i}
==============

H_{\ell,\phi_c(r),i}(x_c).
]

其中：

* (c)：语言条件；
* (\ell)：层；
* (r)：角色；
* (i)：Hidden-State 坐标。

对于 clean–corrupt 对：

[
R_{c,\ell,r,i}
==============

## H_{\ell,r,i}^{\mathrm{clean}}

H_{\ell,r,i}^{\mathrm{corrupt}}.
]

对于四格关系：

[
I_{q,\ell,r,i}
==============

## H_{aa,\ell,r,i}

## H_{ab,\ell,r,i}

H_{ba,\ell,r,i}
+
H_{bb,\ell,r,i}.
]

因此每个坐标 (i) 都有自己的语言响应签名：

[
s_{\ell,r,i}
============

\left(
I_{1,\ell,r,i},
I_{2,\ell,r,i},
\ldots,
I_{K,\ell,r,i}
\right).
]

这就是发现神经元组的基础。

它不做 PCA，不把 2560 维压缩成几个主成分，而是保留每一个原始坐标在所有语言模式下的完整反应。

# 四、语言模式族应该怎样设计

不能只测试“苹果是不是水果”，而应构造多层语言关系矩阵。

## 1. 纵向知识层级

对同一个目标，测试不同层级关系：

[
\text{成员}
\rightarrow
\text{近邻家族}
\rightarrow
\text{上位类}
\rightarrow
\text{更大对象域}
\rightarrow
\text{错误对象域}.
]

例如结构上区分：

* 正确直接类别；
* 同上位类的错误类别；
* 跨上位类类别；
* 完全无关类别。

具体词必须经过人工语义审查，避免“水果/植物”等日常分类与科学分类冲突。

---

## 2. 横向关系类型

至少分开：

* member-of；
* subtype-of；
* part-of；
* has-property；
* used-for；
* agent–action；
* spatial；
* temporal；
* cause；
* contrast；
* modifier/scope。

这样可以判断某个组编码的是：

* 通用关系；
* membership 特有结构；
* 某个具体 family；
* 真假判断；
* 输出协议。

---

## 3. 三类关键对照

### 语义相同、词面不同

用于检验跨表面与同义表达。

### 词面相同、语义关系不同

用于排除纯 token identity。

### 真假相同、关系类型不同

用于排除 generic truth 和输出极性。

# 五、神经元组发现不应依赖单一算法

建议一次冻结四条组发现路线，全部运行。

## 路线 A：稳定坐标组

对每个坐标计算：

* 跨词方向一致性；
* 跨 surface 一致性；
* 跨 family 一致性；
* confirmation 重复性；
* active-over-status；
* correct-over-wrong relation。

按“最差分区效果”而不是总体均值排序。

形成嵌套组：

[
S_{16}\subset S_{32}\subset S_{64}\subset
S_{128}\subset S_{256}\subset S_{512}\subset S_{1024}.
]

这些数字是未来合同可采用的候选规模网格，不代表已有实验结果。

这样可以得到“因果效果随组大小变化”的曲线，而不是揭盲后挑一个最漂亮的规模。

---

## 路线 B：响应模式社区

对两个坐标 (i,j)，比较它们在全部语言条件中的响应：

[
A_{ij}
======

\operatorname{corr}
\left(
s_{\ell,r,i},
s_{\ell,r,j}
\right).
]

如果一组坐标在：

* 新词；
* 新 family；
* 新 surface；

中都呈现相同响应结构，就形成一个候选社区。

这不是降维：每个节点仍是原始 Hidden-State 坐标，只是根据语言响应关系组成图。

社区只能用于生成候选，最终证据仍来自对原始坐标组的因果干预。

---

## 路线 C：随机平衡因果分组

为了避免稳定排序只找到高幅度坐标，可以预先生成多套平衡随机分组。

例如让每个坐标：

* 出现在相同数量的测试组中；
* 与不同坐标组合；
* 接受 clean、corrupt、wrong 和 self 干预。

如果某些坐标经常出现在有效组中，可以进一步拆分。

这类似因果 group testing，但不把状态投影到低维空间。

---

## 路线 D：稠密累积路线

如果所有小组都很弱，但大组逐渐恢复 C056 效应，说明编码可能是稠密的。

定义：

[
F(k)
====

\frac{
\Delta m_{S_k}
}{
\Delta m_{\mathrm{all\ 2560}}
}.
]

其中：

* (F(k)\approx1)：该组恢复了大部分 whole-state 效果；
* 小 (k) 即达到高值：较紧凑；
* 随 (k) 缓慢增长：稠密；
* 单组低、两个组联合突增：存在组合协同。

即使最终结论是“至少需要上千维”，也是重要结构结果，而不是失败。

---

# 六、围绕 C056 设计组级因果实验

C056 已经证明完整 `family@3/15` 状态有效。

现在可以把完整状态分成：

[
H_{\ell,\mathrm{family}}
========================

H_{\ell,\mathrm{family},S}
\oplus
H_{\ell,\mathrm{family},\bar S}.
]

## 1. 组级充分性

在 corrupt recipient 中，只写入候选组：

[
H'_{\ell,f,S}
=============

H^{\mathrm{clean}}_{\ell,f,S},
]

[
H'_{\ell,f,\bar S}
==================

H^{\mathrm{corrupt}}_{\ell,f,\bar S}.
]

测量：

[
U(S)
====

## m(\operatorname{do}(S\leftarrow S_{\mathrm{clean}}))

m_{\mathrm{corrupt}}.
]

并计算它恢复了完整 C056 效果的多少：

[
C_{\mathrm{whole}}(S)
=====================

\frac{U(S)}{U({1,\ldots,2560})}.
]

---

## 2. 组级必要性

在 clean 输入中，只把组 (S) 改成 corrupt：

[
H'_{\ell,f,S}
=============

H^{\mathrm{corrupt}}_{\ell,f,S}.
]

定义：

[
N(S)
====

## m_{\mathrm{clean}}

m(\operatorname{do}(S\leftarrow S_{\mathrm{corrupt}})).
]

如果充分性和必要性都成立，这个组的证据明显强于“可读”。

---

## 3. 组级选择性

比较：

[
U_{\mathrm{correct}}(S),
\quad
U_{\mathrm{wrong\ identity}}(S),
\quad
U_{\mathrm{wrong\ relation}}(S),
\quad
U_{\mathrm{status}}(S),
\quad
U_{\mathrm{random}}(S).
]

选择性定义为：

[
\operatorname{Sel}(S)
=====================

## U_{\mathrm{correct}}(S)

\max_j U_j^{\mathrm{control}}(S).
]

只有正确关系组显著更强，才能称为关系候选。

---

## 4. 组与补集分账

必须同时测试：

* 只写 (S)；
* 只写 (\bar S)；
* 写 (S\cup\bar S)，即完整状态；
* 阻断 (S)；
* 阻断 (\bar S)。

可能出现：

* (S) 足够，补集无效：紧凑候选；
* (S) 与补集都有效：冗余；
* 两者单独无效，联合有效：协同；
* 只有大部分维度联合有效：稠密编码。

---

## 5. 组间协同

[
\operatorname{Syn}(S_1,S_2)
===========================

## U(S_1\cup S_2)

## U(S_1)

U(S_2).
]

如果：

[
U(S_1)\approx0,\qquad
U(S_2)\approx0,\qquad
U(S_1\cup S_2)\gg0,
]

说明两个组可能分别承担：

* relation identity；
* truth gating；
* surface/context binding；
* output compilation。

# 七、RDC 在神经元组层面的具体检验

可以把组候选分成三类，但不能预设它们正交。

## 1. 共享关系组 (S_G)

跨多个 family 和 relation pair 都重复。

预测：

* 能广泛推动共同关系判断；
* 不一定区分具体 family identity。

## 2. 类型差分组 (S_{T_\rho})

对具体 relation 或 family-pair 有选择性。

预测：

* correct relation 有效；
* wrong relation 不能等价恢复；
* 单独可能不足，需要与 (S_G) 联合。

## 3. 条件组 (S_J)

更依赖：

* surface；
* query；
* interface；
* truth polarity；
* candidate order。

预测：

* 改变输出编译或表面适配；
* 不应冒充关系身份。

候选模型是：

[
H_{\ell,r}
==========

H_{\mathrm{base}}
+
H_{S_G}
+
H_{S_{T_\rho}}
+
H_{S_J}
+
\epsilon.
]

关键实验为：

[
S_G,\quad
S_{T_a},\quad
S_G\cup S_{T_a},\quad
S_G\cup S_{T_b},\quad
S_J.
]

致命预测是：

* (S_G) 提供共享关系能力；
* (S_{T_a}) 提供本类型增量；
* 错误 (S_{T_b}) 不能替代；
* (S_G\cup S_{T_a}) 最接近完整状态效果。

\Gamma_S
========

\left(
(3,\mathrm{family},S_3),
(15,\mathrm{query},S_{15}),

否则可能是平行传播或其他未登记位置在起作用。

# 九、词嵌入怎样进入神经元组分析

词嵌入不应只用来画聚类图，而应作为 Hidden-State 组响应的前置预测变量。

## 1. Embedding 相对关系核

[
K_E(i,j)
========

1-\cos(E_i,E_j).
]

需要控制：

* 字符形态；
* token 长度；
* 词频；
* tokenizer；
* 固定标签置换。

---

## 2. Hidden-State 组关系核

对于组 (S)：

[
K_{H,S}(c,c')
=============

1-\cos
\left(
R_{c,S},
R_{c',S}
\right).
]

比较：

[
\operatorname{sim}(K_E,K_{H,S})
-------------------------------

\operatorname{sim}
\left(
K_E,
PK_{H,S}P^\top
\right).
]

但吸取 C037 的教训：裸相似高不够，必须超过置换、字符和词频控制。

---

## 3. 真正重要的继承问题

不是：

> embedding 与 hidden group 是否长得像？

而是：

> embedding 的相对关系结构，能否在未见 family 上预测哪些 Hidden-State 组会被激活，以及这些组的因果作用？

可以登记三类指纹：

[
\Gamma_E(w)
===========

\text{embedding 相对关系指纹},
]

[
\Gamma_H(w,c)
=============

\text{Hidden-State 组响应指纹},
]

[
\Gamma_P(w,c)
=============

\text{未来输出分布变化指纹}.
]

真正目标是检验：

[
\Gamma_E
\longrightarrow
\Gamma_H
\longrightarrow
\Gamma_P.
]

其中第二个箭头必须包含组级因果证据。

# 十一、停止规则如何修改

采用路线级淘汰：

[
\operatorname{Fail}(r_i)
\Rightarrow
\operatorname{Eliminate}(r_i).
]

不采用：

[
\operatorname{Fail}(r_i)
\Rightarrow
\operatorname{CloseCampaign}.
]

例如：

* 稀疏组失败，继续稠密组；
* 社区组失败，继续随机因果分组；
* `family@3` 组失败，继续 `family@15`；
* membership 失败，不影响已经冻结的 part-of 分支；
* embedding kernel 失败，不取消 Hidden-State 因果组；
* 数值相机失败，只隔离该干预分支。

父 Campaign 只在以下情况结束：

1. 至少找到一个独立重复的选择性因果神经元组；

2. 全部预注册组路线运行完毕，得到稀疏、冗余或稠密结构的明确判决；

3. 计算预算耗尽，但必须输出完整候选排名和负结果地图。

# 十二、这种路线能得到什么层级的结论

## 如果发现小组

可以说：

> 当前模型在该关系任务中存在较紧凑的 Hidden-State 功能坐标组。

## 如果只有大组有效

可以说：

> 当前关系状态是高维稠密编码，不能压缩为少量功能坐标。

## 如果多个组可互换

可以说：

> 当前机制存在冗余等价联盟。

## 如果共享组与类型组联合有效

可以说：

> RDC 的“共享复用＋关系差分＋上下文条件化”获得了组级因果支持。

## 如果没有任何固定组跨材料迁移

可以说：

> 编码可能高度上下文化、旋转或由动态事件路径定义，而不是固定坐标联盟。

这些都是重要结构结果，不需要强求唯一、最小、完整闭合。

# 最终回答

## 1. 应该先做哪个

[
\boxed{\text{先启动观察优先的大型 Campaign，但把神经元组作为 Campaign 的核心中段。}}
]

不是先观察很多期再做组，也不是直接挑组，而是：

[
\text{全维观察}
\rightarrow
\text{冻结规则生成组}
\rightarrow
\text{组级因果竞赛}
\rightarrow
\text{跨层组路径}
\rightarrow
\text{独立验证}.
]

## 2. 神经元组应围绕什么设计

核心数据对象应是：

[
\boxed{
\text{语言模式条件}
\times
\text{embedding 相对关系}
\times
\text{层}
\times
\text{角色}
\times
\text{2560 原始坐标}.
}
]

核心算法应是：

* 不降维的坐标响应签名；
* 稳定组、社区组、随机因果组和稠密组并行；
* C056 `family@3/15` 因果锚点；
* 组级充分性、必要性、选择性和救援；
* 组与补集、组间协同；
* 跨层中介阻断；
* 整家族和整关系类型留出。

Attention/MLP 可以暂时不分析。只要能找到稳定、选择性、可迁移且具有因果作用的 Hidden-State 组，就已经能够建立一个清晰的功能编码理论。

之后若还要回答“这些组由哪些具体权重实现”，再进入 Attention/MLP；在此之前，词嵌入—Hidden-State 场确实是更简洁、更高信息密度、也更适合寻找语言关系规律的主路线。
