## 二、总体结论

两份方案的共同主线正确，但不能原样执行。

最应该保留的原则是：

> 不预设语言机制的函数形式，先临摹真实计算，再从重复、可预测和可干预的结构中归纳规则。

最需要纠正的表述是“完全不使用公式”。真正可执行的版本应当是：

> 不预设语言机制公式；必须预先冻结架构恒等式、坐标定义、执行合同、证据门和停止规则。

两份方案和附件仍遗漏了 Phase429（阶段429）最严重的协议硬伤：旧物理门的多数类基线已经在 96 个留出组上全部通过，但协议仍要求候选在组级成功率上至少提高 0.10。这个门不论使用问题词元还是真实提示终端，都不可能通过。

因此，下一步不能直接开始“全位置、全组件、全模型、全向量”的大规模记录，也不能只把观察位置从问题末词元改到提示终端。最可行路线是一个收缩后的 Phase430（阶段430）：

1. 先把预测目标改为类别均衡、真实可区分的“模型最终选择来源1还是来源2”；
2. 再注册真实提示终端和自然生成时间；
3. 先验证记录器能精确重建模型自己的下一词元分数；
4. 只在已经通过行为资格的 Qwen3（通义千问3）候选上建立最小位置-时间图谱；
5. GLM4（智谱GLM4）和 DS7B（深度求索7B）只做同一记录器的执行与坐标校准，不把未通过行为资格的数据解释为语言机制；
6. 先记录组件级紧凑账本，再按冻结事件窗口保存全向量；
7. 本阶段不进入密封、因果、头、通道或单神经元扫描。

### 2. 对 0/96 的正确解释

Phase429（阶段429）的后验审计已经确认：注册坐标是问题跨度最后词元，问题后面还有输出指令和模板边界，所以它不是生成第一个词元的真实终端状态。

这只允许得到两个结论：

1. 旧坐标不能被解释为“提示终端答案状态”；
2. 旧坐标上的固定零符号读出在 96 个留出组上失败。

它不能直接证明：

1. 真实提示终端一定能成功；
2. 失败完全由位置错误导致；
3. 问题词元完全不包含答案信息；
4. 内容运输路径不存在或已经存在。

### 3. 旧预测门在结构上不可通过

旧协议把 `natural target-first event（自然目标首先出现事件）` 作为条件标签，并把“每组至少 8/10 条件预测正确”作为组成功。校准集得到的多数类标签为真，留出集多数类基线达到 96/96 组成功。

旧门同时要求：

$$
\Delta G
=
G_{\mathrm{physical}}
-
G_{\mathrm{majority}}
\ge 0.10
$$

但：

$$
G_{\mathrm{majority}}=1,
\qquad
G_{\mathrm{physical}}\le 1
$$

所以：

$$
\Delta G\le 0<0.10
$$

即使物理预测器完美，旧门最多也只能和多数类基线持平，无法解锁密封集。这是协议目标和聚合单位错误，不是模型机制负结果。

0/96 仍然是旧读出本身的负结果，但“密封未解锁”不能再被当作该读出独有的失败，因为任何读出都无法满足旧改进门。

## 四、对《完全不使用公式的图谱方案》的审计

### 1. 正确且应该保留的部分

1. 不再把线性方向、固定神经元、固定层段或单一运输公式作为语言机制先验。
2. 明确区分临摹、发现、留出预测、合法干预、恢复和规则归纳。
3. 只沿真实计算图建立边，避免把相关性直接画成因果边。
4. 先从组件、位置和时间形成粗图，再考虑头、通道和神经元。
5. 引入状态碰撞和状态充分性检查，要求相同候选状态在相同未来条件下产生一致结果。
6. 要求公式最后出现，只用于压缩已经通过预测和因果验证的离散规则。
7. 明确允许真实机制高度条件化、分布式和可补偿，不强迫得到简短闭合公式。

这些原则与 Phase278-429（阶段278-429）连续出现的负结果一致，也符合当前“全局物理图谱优先、闭合第二”的研究排序。

### 2. 不完整或不可直接执行的部分

#### 2.1 “完全不使用公式”在工程上不成立

记录器必须使用架构恒等式检查自己是否忠实：

$$
r_{l+1,p}
=
r_{l,p}
+a_{l,p}
+m_{l,p}
+\epsilon_{l,p}
$$

坐标、对照、恢复、留出和停止门也必须有精确定义。禁止的是预设“语言是什么”的公式，不是禁止数学测量。

#### 2.2 “所有位置、所有组件、所有全向量”成本失控

以 Phase429（阶段429）的 3840 个条件、Qwen3（通义千问3）的 36 层、17 个位置或生成时刻、2560 维隐藏状态和半精度为下界，一个向量字段约需要：

$$
3840\times36\times17\times2560\times2
\approx 12.0\ \mathrm{GB}
$$

七个向量字段已经约为 84 GB。附件的新分母还包含四个任务块、多个分割和更多来源写入，实际很容易进入数百 GB，而且这还没有包含注意力矩阵、头、MLP（多层感知机）中间维度和自然生成缓存。

Phase429（阶段429）现有 426 MB 物理开放数据主要是单一查询坐标的组件摘要，不能据此推断全迹成本很低。

#### 2.3 标签盲化缺少“匿名分层”

发现器不能读取正确答案和任务名称，但合同、接口、模板和执行上下文不能被直接丢弃。否则无示例与交叉示例、不同接口、不同生成历史会被混入同一分布。

正确做法是：

1. 将上下文替换为匿名条件编号；
2. 先在同一匿名条件层内发现结构；
3. 再测试结构能否跨匿名条件保持；
4. 最后解盲解释条件差异。

#### 2.4 “重复子图”还没有可操作定义

绝对神经元编号、绝对层号、幅度和词元位置都可能不同。方案没有说明重复是指：

1. 相同边类型；
2. 相同事件顺序；
3. 相同来源选择；
4. 相同干预响应；
5. 还是相同输出结果。

在定义和负对照冻结前，重复子图算法会把常见架构形状误当语言机制。

#### 2.5 递归因果二分不保证找到真实单元

架构写入可加，不代表行为因果效应可加。正负补偿、归一化、注意力竞争和门控都会使联合删除效果不等于单元效果之和。

因此，因果下钻不能只分成左右两半后保留“更有效”的一半。出现强交互时，必须保留耦合组，登记联合必要性、冗余和补偿关系，而不能强行追到单神经元。

#### 2.6 文档阶段编号与真实历史冲突

文件末尾称其已经作为 Phase429（阶段429）追加，并使用了 Windows（视窗系统）本地路径。真实 Phase429（阶段429）是独立观察接口、完全交叉路线和架构查询路径审计。该尾注只能视为文档生成痕迹，不能作为研究历史证据。

## 五、对《方案分析审核改进》的审计

### 1. 正确的改进

1. 加入行为资格门，避免对行为不成立的任务解释内部物理量。
2. 加入位置-时间坐标审计，修复问题词元和真实提示终端的混淆。
3. 把执行同构独立出来，固定批大小、填充、精度、注意力实现和 KV cache（键值缓存）。
4. 把公式分成架构恒等式、证伪门和语言假设。
5. 强化盲化，避免答案、任务名和历史候选泄漏。
6. 强调上下文不变性和跨模型功能对齐，而不是直接比较神经元编号。
7. 要求因果二分前检查交互，方向上比原方案更谨慎。

### 2. 仍需修正的硬伤

#### 2.1 把“坐标不合法”写成“坐标导致失败”过强

Phase429（阶段429）证明终端解释无效，但没有证明真实终端会通过。位置错误、预测目标错误、组级门不可通过以及读出形式过窄可以同时存在。

#### 2.2 错过了多数类基线 96/96 的不可通过门

这是比位置错误更先要修的协议问题。若标签与聚合门不变，换位置也不能解锁下一阶段。

#### 2.3 “1/3模型、1/2合同、1/4任务”不是冻结分母

真实口径应是：

1. Qwen3（通义千问3）和 GLM4（智谱GLM4）有观察接口授权；
2. DS7B（深度求索7B）没有行为授权；
3. 八个候选审计元组中只有一个 Qwen3（通义千问3）元组得到物理授权；
4. 没有同一候选元组跨两个模型通过。

把任务、合同、候选和模型分母混成一个比例，会掩盖失败发生在哪一级。

#### 2.4 Phase430（阶段430）重新做全面行为审计会重复 Phase428-429（阶段428-429）

当前已经有一个合格窗口。最经济的下一步不是再次遍历所有任务，而是先用这个窗口校准正确坐标和记录器。工具通过后，再把同一协议扩到更多任务和模型。

#### 2.5 “至少两个模型通过才允许任何物理记录”过严

跨模型通用机制声明确实至少需要两个模型，但模型特异物理图谱可以在一个合格模型上建立，只要明确标记：

```text
model_specific = true
cross_model = false
causal = false
```

否则研究会因为模型接口差异而永远无法校准物理仪器。

#### 2.6 固定交互阈值和跨模型相关阈值没有校准依据

`tau=0.3`、幅度相关大于 0.5、相对深度差小于 0.15 都是新的手工公式。它们可以作为待校准占位符，不能直接作为科学通过门。阈值应从负对照、重复运行误差和执行实现误差中冻结。

#### 2.7 用行为区分度搜索功能坐标有标签泄漏风险

可以在坐标校准集上比较候选位置，但必须先冻结候选坐标列表、比较规则和选择方式，再把选中的坐标用于独立物理留出。不能在留出集上选择“最像答案”的位置。

#### 2.8 文件引用的部分跨路线数值缺少本文件中的证据定位

例如 GLM（智谱路线）Phase633（阶段633）的相消比例不能直接替代当前 GPT5（生成式预训练变换器5）路线的模型内控制。它可作为风险提示，但 Phase430（阶段430）的交互门必须用本阶段自己的重复运行和负对照校准。

## 六、附件 Phase430（阶段430）草案的评价

### 1. 正确部分

1. 把物理图谱从“层”升级为“来源角色、位置、层、生成时间、组件”的自然计算面。
2. 将问题末词元、输出指令、模板边界和真实提示终端分开注册。
3. 区分提示预填充和自然生成时间。
4. 分开来源1、来源2、选择器、问题和输出指令写入。
5. 将内容、接口和停止事件分账。
6. 明确物理观察不等于因果，并继续关闭头、通道和神经元扫描。

### 2. 必须修改部分

1. 旧预测目标和旧组级基线不能继续使用。
2. `R²（决定系数）>0` 与 `Delta R²（决定系数增量）>0.10` 不是当前二元或多类别来源选择任务的自然证据门。
3. 固定 MAD（中位绝对偏差）标准化可用于显示，但不能替代原始值、成对差分和守恒账本。
4. “所有注册位置、每层、所有向量”在新分母下成本过高，应改为渐进式多分辨率记录。
5. 真实提示终端不是所有任务唯一的功能状态。它首先是生成首词元的合法架构坐标，是否承载完整机制需要独立验证。
6. 目标与相反词元的反嵌入方向是有标签观察器，不能混入标签盲化发现通道。
7. 助手边界和提示末端在不同聊天模板中可能重合或由多个特殊词元组成，必须保存实际词元编号和偏移，不能只保存角色名称。
8. `t=0` 必须定义清楚。建议定义为“提示预填充完成后、生成第一个自然词元之前的分数状态”，不要再额外复制一份同一终端隐藏状态。

## 七、修正后的研究原则

建议把路线正式命名为：

> 无预设语言机制模型的渐进式自然计算图谱。

公式分为四类：

| 类别 | 是否预设 | 用途 |
|---|---|---|
| 架构恒等式 | 必须 | 检查记录器有没有忠实记录模型 |
| 坐标与执行恒等 | 必须 | 确认记录状态确实产生注册的下一词元分数 |
| 证据和停止门 | 必须 | 防止后验修改标签、阈值和分母 |
| 语言机制公式 | 暂不预设 | 只能在重复预测和因果结果后归纳 |

语言机制发现的顺序应冻结为：

```text
行为资格
-> 执行与坐标身份
-> 架构守恒
-> 无标签物理事件账本
-> 独立留出预测
-> 匹配对照特异性
-> 密封复现
-> 合法干预与恢复
-> 组件交互图
-> 必要时下钻到头、通道或神经元
-> 离散规则
-> 最后才压缩为理论公式
```

## 八、最可行的下一阶段

# Phase430（阶段430）：预测目标修复与最小位置-时间自然计算图谱

### 1. 阶段目标

本阶段只回答四个问题：

1. 什么状态真正产生自然生成第一个词元的分数；
2. 来源1与来源2的竞争在哪些位置、层和生成时刻留下可复现差异；
3. 这些差异能否在类别均衡的独立留出上预测模型实际选择；
4. 差异是否超过匹配负对照。

本阶段不回答：通用语言机制、跨模型同构、完整生成闭合、因果载体或单神经元位置。

### 2. 分母与数据分割

保持 Phase429（阶段429）唯一合格元组：

```text
model: qwen3
candidate: language_action_dual_route_candidate
contract: no_examples
control: language_action_stable_result_control
```

数据规则：

1. Phase429（阶段429）开放校准数据只能作为探索参考；
2. Phase429（阶段429）密封数据继续不读；
3. 新建 96 个坐标校准语义组和 96 个物理留出语义组；
4. 每组保持 5 种路线乘 2 种角色，并同时生成候选和匹配对照；
5. 新物理条件总量为 `96 x 2 x 5 x 2 x 2 = 3840`；
6. 来源1与来源2作为实际输出选择必须在每个分割中严格各占一半；
7. 输出既不是来源1也不是来源2时登记为 `other（其他）`，禁止事后删除；
8. 词汇、来源顺序、选择器顺序和模板表面形式成对交换。

行为资格标签与物理预测标签必须分开：

```text
behavior_qualified:
  候选是否按该条件的规则完成内容、接口和停止

physical_prediction_target:
  模型实际首先选择 source_1、source_2 或 other
```

这样多数类基线不再因为“每个条件都有自己的正确目标”而接近恒真。

### 3. 三模型执行与坐标校准

按照 CUDA（统一计算设备架构）顺序运行 Qwen3（通义千问3）、GLM4（智谱GLM4）、DS7B（深度求索7B），每次只加载一个模型并在切换前释放显存。

三模型都执行记录器身份测试，但只有 Qwen3（通义千问3）合格候选进入语言物理解释。GLM4（智谱GLM4）和 DS7B（深度求索7B）输出标记为 `instrument_only（仅仪器）`。

每个模型保存：

1. 模型与词元器版本散列；
2. 完整输入词元编号；
3. 来源1、来源2、选择器、问题、输出指令和助手边界的实际偏移；
4. 最后一个非填充输入词元；
5. 批大小、填充方向、精度、注意力实现和 KV cache（键值缓存）设置；
6. 提示预填充和自然续跑的执行散列。

定义：

```text
g = 0:
  提示预填充完成后，由真实提示终端状态产生第一个自然词元分数

g = k, k >= 1:
  已自然生成 k 个词元后，由当前最后词元状态产生第 k+1 个词元分数
```

坐标身份门必须验证：

1. 捕获的终层隐藏状态经过模型原生归一化和输出头后重建原生分数；
2. 重建后的首选词元与模型原始前向完全一致；
3. cache（缓存）与 no-cache（无缓存）在注册条件下得到相同首选词元；
4. 批大小改变不改变注册行为标签；
5. 数值误差阈值由重复运行误差冻结，不手工指定宽松常数。

身份门失败时只修复工具，不解释内部机制。

4. 来源后选择器末端；

### 5. 渐进式记录，而不是一次全迹

## 十、对小模型偏差的处理

当前三个模型较小，其内部结构可能比高能力模型更粗糙，也可能通过模板记忆、词元捷径和冗余补偿完成任务。现阶段应采用双重约束：

1. 小模型负结果不能直接推出自然语言不存在对应机制；
2. 小模型局部正结果也不能直接上升为大脑或通用智能理论。

因此，Qwen3（通义千问3）候选只能命名为“模型特异人工合同路径”。跨模型、跨合同和跨任务复现以前，不进入统一智能理论主体。
