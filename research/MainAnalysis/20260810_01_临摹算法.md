# 十二、那么这个“核心临摹算法”究竟应该怎样设计？

我建议不要再设计成某一个 PCA（主成分分析）、SAE（稀疏自编码器）或者 patch 算法。

真正核心应该是一套固定的**编译流程**。

可以继续使用已经形成的名字：

# 条件因果脉络临摹算法

它不是新理论，只是测量算法。

我建议它固定由下面九步构成。

1. **语言模式编译。** 把外部模式 (p) 拆成内容、关系、操作、语法、上下文、表面形式等因素，自动生成 active（有效）、matched-null（匹配空对照）、surface-only（纯表面）、semantic-neighbor（语义近邻）以及未见组合样本。

2. **行为资格。** 对每个模型先测 (B_m)。如果模型本身不能稳定实现这个模式，停止，不进行 hidden scan（隐藏态扫描）。

3. **语义角色对齐。** 不按绝对 token position（词元位置）比较，而把所有输入映射成 entity（实体）、relation（关系）、value（值）、query（查询）、boundary（边界）等功能角色。

4. **标准干预登记表。** 对这些角色定义固定 intervention registry（干预登记表） (\mathcal R)：读取、删除、交换、阻断、写入、救援等。

5. **完整响应张量。** 对每个模式记录：
   [
   R_p(r,\ell,c,u)
   ]
   其中 (r) 是功能角色，(\ell) 是深度/功能阶段，(c) 是上下文，(u) 是干预。这里同时记录 residual、Attention、MLP、全词表 margin 和生成行为。

6. **扣除公共壳层。** 使用匹配差分，而不是原始激活：
   [
   R^{specific}_p
   =
   R^{active}_p-R^{null}_p
   ]
   进一步使用 surface 与 semantic-neighbor 估计表面和语义近邻干扰。

7. **商化成机制脉络。** 不把原始 layer/head 作为身份，而定义：
   [
   \boxed{
   \Gamma_{\mathcal R}(p;S,c)
   =
   [
   u\mapsto\Delta Q(p;S,c,u)
