## 2. 模式内部脉络定义

每个模式 (P_i) 的内部脉络定义为：

$$
\boxed{
\mathrm{Trace}(P_i)
===================

{
T_i,
G_i,
W_i,
R_i,
C_i,
O_i,
B_i
}
}
$$

其中：

```text id="jgxcd9"
T_i = TriggerTrace（触发脉络）
G_i = GateProductTrace（门控乘积脉络）
W_i = ResidualWriteTrace（残差写入脉络）
R_i = ReadoutTrace（读出脉络）
C_i = CompetitorTrace（竞争脉络）
O_i = OutputRolloutTrace（输出展开脉络）
B_i = ClosureTrace（闭合脉络）
```

## 3. 模式族共享机制与差分机制

每个模式族不是孤立的。

统一公式：

$$
\boxed{
P_i
===

P_{\mathrm{shared}}
+
\Delta P_i
}
$$

其中共享部分：

$$
\boxed{
P_{\mathrm{shared}}
===================

\mathrm{PromptPattern}
+
\mathrm{GateUpProduct}
+
\mathrm{ResidualWrite}
+
\mathrm{ReadoutCompetition}
}
$$

差分部分：

$$
\boxed{
\Delta P_i
==========

\Delta \mathrm{Trigger}_i
+
\Delta \mathrm{StateWrite}_i
+
\Delta \mathrm{CompetitorField}_i
+
\Delta \mathrm{Rollout}_i
+
\Delta \mathrm{Closure}_i
}
$$

这就是后续统计的核心。

我们不是只问：

```text id="u66qff"
某个模式有没有一个方向？
```

而是问：

```text id="2a5ww2"
这个模式和其他模式共享哪些内部路径？
它在哪些路径上发生差分？
它失败时被哪个竞争机制接管？
```
