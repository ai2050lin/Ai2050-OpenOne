## 二、Phase430（阶段430）附件中正确的部分

### 1. 真实输出边界必须独立校准

模型原生下一词元分数的合法坐标是实际提示终端，而不是人为指定的问题末端。Phase431（阶段431）在三个模型上建立了终端重建、缓存和批形状身份账本。

### 2. 行为资格和物理预测必须拆开

行为资格回答“模型是否完成任务合同”，物理预测回答“内部状态是否预测模型实际选择了哪个来源”。Phase431（阶段431）不再把规范答案当作恒真的物理标签。

### 3. `other（其他）` 必须保留

自然输出既未选择来源1也未选择来源2时登记为 `other（其他）`，不能删除。Phase432（阶段432）由此客观显示：

```text

GLM4：443/2560 other；
DS7B：2474/2560 other。
```

### 4. 标签盲发现和有标签观察器必须分账

Phase431（阶段431）的窗口冻结不读取行为标签；看过留出标签后的失败图谱只允许生成下一阶段候选，不能回头重开旧门。

### 5. 全分母紧凑账本优于无选择全向量保存

Phase431（阶段431）保存全层残差、注意力来源分区和少量投影；Phase432（阶段432）只保存三个选择前位置的全层有符号裕量。Phase432 的完整结果约 75 MB，而 Phase431 的来源分区账本约 1.1 GB，说明分层存储策略可行。

## 三、需要修正的部分

### 1. `g1/g2` 的时间方向错误

首个注册来源已经在 `g1` 对应词元中出现，因此：

$$
g1,g2 \notin \operatorname{Past}(Y_{\mathrm{first\ source}})
$$

它们可以用于研究答案形成后的传播，不能用于预测首个来源选择。Phase431（阶段431）没有重选冻结窗口，也没有重开 G4（门4）。

### 2. 盲事件分数缺少行为特异性

Phase431（阶段431）冻结的四个最高分窗口全部位于第1层：

```text
L1 / g1
L1 / g2
L1 / instruction_end
L1 / question_end
```

它们在独立留出上全部投票为 `source_2`，平衡准确率只有 `0.50`。高非平稳性主要反映通用输入或生成边界，而不是候选语言机制。

### 3. `abs(cosine)` 不能直接命名为抵消

Phase431（阶段431）用注意力和 MLP（多层感知机）夹角绝对值构造一个事件量。绝对值会把同向和反向写入合并：

$$
|\cos(a,m)|=1
$$

既可能表示强协同，也可能表示强抵消。后续必须同时保存符号、范数和净写入，不能只保存绝对夹角。

### 4. 提示终端不是完整机制的默认唯一坐标

提示终端是合法输出边界，但准确输出读出只能证明状态已进入输出坐标系，不能证明知识如何形成、关系如何绑定或推理如何完成。

### 5. Phase432（阶段432）的行为门和物理比较路线不完全对齐

Phase432（阶段432）的主物理比较只使用：

```text
source_only / query_only / consistent
```

冻结的 H0（门H0）却要求稳定对照在五条路线全部通过，包括 `conflict（冲突）`。12 个失败组全部集中于：

```text

```

这说明对照并非真正“冲突不变”。由于该要求已经预注册，不能在看到结果后删除冲突路线，H0 必须判失败。

对来源首词元 $x_1,x_2$，定义：

$$
D_{\ell,p}
=\left\langle
\operatorname{Norm}(r_{\ell,p}),

## 十、围绕知识、推理和语法的反思

### 1. 知识网络

本轮人工双路线任务只表明“哪个来源项将被输出”可以在晚层终端状态中读出。来源项 `X...` 与 `Y...` 的首词元已经不同，模型可能只需形成一个简单二元输出选择。它没有证明对象属性、类别层级或知识复用网络的位置。

### 2. 推理能力

候选任务包含选择器与角色映射，但没有多步中间结论、反事实分支或证明链。当前结果最多定位一个绑定后的输出状态，不足以说明推理步骤如何复用或差异化。

### 3. 语法系统

输出合同被压缩为一个项目后停止，几乎没有句法生成压力。结果不能解释主谓一致、依存关系、长距离约束或标点结构。

### 4. 三者的统一

提示终端晚层可能是知识、推理和语法共同使用的输出竞争接口，但不能因为三类任务都最终经过输出头，就把该位置命名为统一语言工作空间。需要在每一类行为合格后比较它们进入终端竞争前的不同形成路径。

不再追求另一次简单末端高准确率，而是回答：

```text
来源关系在什么位置和层开始进入输出接口？
这个形成事件是否早于答案首词元？
它是否在候选中发生角色翻转，而在行为合格对照中保持不变？
```

## 2. 去除首词元捷径

来源1和来源2必须共享相同首词元和尽可能长的公共前缀，例如：

```text
item-common-...-alpha
item-common-...-beta
```

主目标改为完整多词元事件或首个分叉词元，不再使用 `X` 对 `Y` 的首词元方向。

## 3. 行为与物理分母严格对齐

候选和对照只在完全相同的可评分路线进入主门。冲突路线单独作为压力测试，不再一边排除物理比较、一边阻断主行为门。

## 4. 模板边界细分

在以下真实词元上建立选择前路径：

```text
问题末端
输出指令内部关键词元
助手模板开始
助手模板结束
真实提示终端
```

重点观察 Qwen3 第24-29层，但层集合必须在校准集冻结，留出和密封阶段禁止扩大。

## 5. 双通道特征

无标签通道记录：

```text
块写入突变
来源注意力质量
有符号注意力/MLP夹角
净写入与绝对写入
模板边界状态变化
```

有标签观察器只在冻结窗口检验完整序列分叉事件。

## 6. 证据门

```text
P0：候选与对照在完全相同主分母行为合格；
P1：坐标、缓存和批形状身份通过；
P2：共享前缀后的分叉事件可在独立留出预测；
P3：候选角色翻转、对照保持不变；
P4：密封复现；
P5：只在P0-P4通过后做聚合块级因果交换。
```

## 7. 跨模型策略

不再要求 GLM4 和 DS7B 使用 Qwen3 的人工合同。先分别建立各模型能够稳定完成的等价行为合同，再比较相对层、位置角色和事件顺序。行为不合格模型只保留仪器图，不进入语言机制分母。

## 8. 停止规则

1. 共享首词元后准确率消失：登记首词元输出捷径；
2. 只有提示终端最终层可读：登记末端接口状态，不做上游机制声明；
3. 候选和对照共同翻转：登记通用输出竞争；
4. 行为门失败：密封集不读；
5. 密封失败：不做因果；
6. 聚合因果失败：不进入神经元扫描。

## 十四、自动继续判断

Phase431（阶段431）与 Phase432（阶段432）已经连续自动完成，当前阶段目标已闭合到正式停止门。Phase432 的密封集因预注册 H0（门H0）失败而必须保持未读，不能在同一阶段继续补门或修改对照。

Phase433（阶段433）需要更换来源词元结构、行为对照和主预测事件，属于新实验对象，不是当前阶段的自动续跑。因此本轮应在停止门结束，不读取密封数据，不执行因果或神经元测试。下一次模型执行应从 Phase433 的全新冻结协议开始。

## 十五、通俗总结

这两轮先把“摄像机放在哪里”弄对了，又发现一件很具体的事：Qwen3 在回答前、提示最后一个词元附近，到第26层时已经基本决定输出 X 还是 Y；在问题句末端和输出指令末端却看不到同样清楚的选择。

这很有价值，但还不是语言机制。因为 X 和 Y 的第一个词就不同，模型可能只是提前准备好了一个简单输出按钮。更严格的对照又在冲突条件下失败，所以密封试卷不能打开。

下一步要让两个答案共享开头，只在后面的词元分叉，再沿着问题、指令、助手模板和提示终端追踪这个分叉何时形成。只有这种更难的选择也能在密封数据和因果交换中成立，才开始接近真正的关系绑定路径。
