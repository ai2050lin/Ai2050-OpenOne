## 三、为什么说现有范式碰到了天花板

现有方法是「对照模板 → 均值差方向 → 线性探针 → 沿方向写入 → DLA」。它在第 1、3、7、9、10 号拼图上很成功，但反复撞到五类现象。这些现象都在提示：基本单元选错了。

1. **能读出 ≠ 能写入。** 真值从第 8–10 层起一直到最后一层都能读出（0.96–0.99），却只在 16–22 层这个窄窗口里能写入。颜色属性也一样：读到第 36 层，写到第 24 层就截止。一个表示并不是一直「有效」，只在某段被下游读取的时间里起作用。
2. **同一个变量有多个表示。** 句末的「这句话真不真」和答案位置的「要回答对还是错」近乎正交（cos ≤ 0.3）。表示按「谁来读」组织，而不是按概念组织。
3. **冗余分布。** 前 10 个头只占一半作用，要到 80% 需要 32–40 个头。消融这 10 个头时下降是选择性的（是随机头的 2.5–36 倍），但上下文仍以 86–100% 胜出。
4. **线性高估。** 写入串扰的实测幅度只有线性预测的 1/3–1/6，系统中有饱和或门控。
5. **条件靠路由起作用，而不是靠叠加向量。** 提问范围改变的是注意力分配，不是在残差流里加一个方向。

由此得出的范式判断是：我们一直在问**「概念 X 存在哪里」**（以状态为中心），而数据更像在回答**「变量 X 在什么条件下，被谁从哪里搬到哪里、由谁读出」**（以流动为中心）。清晰的结构如果存在，很可能在后一个层面。

## 四、新的基本单元：「通道」（新设计，未执行）

### 4.1 定义

一个**通道**由五个部分组成：

| 组成 | 含义 | 已有例子 |
| --- | --- | --- |
| 变量 | 被搬运的内容 | 颜色、真值、范围…… |
| 源 | 写入位置 × 写入层窗 | 实体 token，第 0–24 层 |
| 路由 | 哪些头族、由什么条件门控（QK） | 后段约 10 个核心头加冗余头，按范围门控 |
| 读者 | 读出位置 × 读出层窗 | 答案位置，第 26–35 层 |
| 转换 | 读者把它变成什么 | 颜色 logit 差 |

现有拼图可以直接改写成通道。例如：

- **仲裁：** 上下文颜色词 → 后段搬运头（按范围门控）→ 答案位置 → 颜色 logit。
- **截止层：** 截止的层，可能就是最后一个读者读取的层。

### 4.2 它可能带来的突破：可证伪的强预测

- **P1 截止 = 读者时刻。** 某属性的最后可写层，等于从实体位置读取该属性的最后一个头所在层（误差 ±2 层）。如果成立，「截止层」就从现象升级为由通道决定的规律，而且可以从注意力图直接预测，不必做写入扫描。
- **P2 通道词汇复用。** 不同任务族（属性问答、仲裁、真值判断、翻译）共用少量通道类型，例如「实体属性读取」「上下文复制」「范围门控」。这是「复用差分」在机制层面的版本：共享的是通道，差异在于门控条件和源。
- **P3 头级拼装保真度。** 用「条件 → 注意力分配 → 值向量 → logit」拼出的预测，在留出集上的保真度高于现有图谱（现在是 0.68–0.74）。英文 Qwen 当前只有 0.33。这是 AGENTS.md 定义的可度量「破解」程度。
- **P4 跨模型不变量。** 两个模型的坐标不能直接比较，但通道图可以比较：相对深度窗口、头族规模、门控位置。目前已经看到的候选不变量包括：写入窗在相对深度 0.35–0.55，搬运头在后 1/3 层，γ ≈ −1，含水先于颜色截止。

## 二、候选数学结构（待检验的假设）

### S1 模式吸引子：「整体都是代码」由什么保证

**假设：** 每个位置的残差流里有一个低维的「模式状态」 $m_t$，由注意力把前文各位置的模式加权搬过来：

$$m_t \approx \sum_{j<t}\alpha_{tj}\,P_m W_{OV}\,x_j,\qquad P_m W_{OV} P_m \text{ 在模式子空间上近似保持方向}$$

若成立，模式就是这个递推的**稳定不动点**：前文全是代码时，每一步都把代码模式再写一遍，偶尔一个歧义 token 也拉不回来。

**可测的量：**
- **持续半衰期：** 在位置 t 扰动模式方向后，影响在后续 k 个 token 上的衰减速度。
- **切换阈值与滞回：** 代码 → 注释 → 代码时，切换需要多强的信号，切回来是否更容易。

### S2 注意力打分的双线性分块

**假设：** 注意力打分 $s_{ij}=x_i^\top W_{QK}x_j$ 可以近似分解成几个子空间块：

$$s_{ij}\approx \underbrace{m_i^\top A\,m_j}_{\text{风格匹配}}+\underbrace{g_i^\top B\,g_j}_{\text{语法结构（括号、主谓）}}+\underbrace{c_i^\top C\,c_j}_{\text{内容复制}}+\text{位置项}+\text{交叉项}$$

**可测的量：** 在因子化材料上，各块对注意力打分方差的解释份额，以及据此把头分成「风格维持 / 语法 / 内容复制 / 位置」几类。

### S3 词表分区偏置：风格怎样落到下一个词

**假设：** 模式状态经 unembedding 之后，成为一个低秩的 logit 偏置 $b_m=W_U P_m h$。它近似一张「软掩码」：代码模式抬高代码 token、压低汉字。

**可测的量：** 模式方向在 unembedding 上的投影能否区分词表类别（代码符号、英文词、汉字、论文用语），用 AUC 衡量。

### S4 融合 = 专家乘积（product of experts）

**假设：** 下一个词的对数概率在各维度上近似可加：

$$\log p(w\mid\text{前文})\approx \ell_{\text{嵌入}}(w)+\ell_{\text{风格}}(w)+\ell_{\text{逻辑}}(w)+\ell_{\text{语法}}(w)+\ell_{\text{内容}}(w)-\log Z$$

各项由不同的头群和 MLP 单元写出。

- 可加的部分就是可以拆开解释的部分。
- 不可加的交互项，标出「真正发生融合的地方」。我预期这类融合主要出现在 MLP 门控和 QK 门控处。

### S5 代码的结构变量

**假设：** 括号深度、缩进层级、变量绑定（标识符在后文被正确引用）这些量，由注意力实现为计数器或指针。
- **计数器：** 均匀注意力对前文括号求平均，深度表现为比例。
- **指针：** 内容复制头指回定义该变量的位置。

### 材料设计

- **平行四件套：** 同一算法或事实分别写成中文说明、英文说明、论文风格段落、带注释的 Python 代码。可由文法生成，也可人工整理后冻结。
- **切换语料：** 代码里的中文 / 英文注释、论文里的公式和代码块、中文里夹带英文术语。
- **自然语料：** 用于 MF-v6 的留出检验，不参与发现。
- **切分：** 按内容条目做发现集 / 确认集 / 锁箱切分，同一内容的四种风格放在同一划分里，防止近重复泄漏。

### 复用已有代码

- **可直接复用：** 逐头 DLA（int8 也适用的 $W_O$ 提取）、注意力采集、沿方向写入的钩子、`steer_verdict`、A / B 选格确认、`assembly.v1` 的 KL 与恢复比例。
- **需新增：** 路径修补、QK 分块分解、持续半衰期估计。
- 新模块按惯例放进 `shared/dist_protocol/`，判据写死在 `CRITERIA` 中，并配植入找回与负对照测试。
