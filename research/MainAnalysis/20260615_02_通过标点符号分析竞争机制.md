# 4. 现在应该如何把它纳入理论？

当前理论必须从：

```text id="87t8la"
语义支持 → 候选选择 → 表面生成
```

升级为：

```text id="e7dwro"
多路径并行竞争模型
```

更准确的结构是：

```text id="z90mvt"
object / relation / template
对象 / 关系 / 模板
        ↓
context field
上下文字段
        ↓
semantic path
语义路径
        ↓
candidate meaning
候选意义

同时：

template / syntax / position
模板 / 句法 / 位置
        ↓
format path
格式路径
        ↓
punctuation / space / option / continuation
标点 / 空格 / 选项 / 续写

最后：

semantic path + format path + continuation path + tokenization path
语义路径 + 格式路径 + 续写路径 + 分词路径
        ↓
LM head competition
语言模型头竞争
        ↓
next token
下一个词元
```

所以最新公式应该写成：

```text id="i45pe8"
token*
=
argmax_v [
  y_semantic(v)
  + y_format(v)
  + y_syntax(v)
  + y_continuation(v)
  + y_tokenization(v)
]
```

其中：

```text id="70qlwe"
y_semantic(v):
  语义路径给某个词元的支持

y_format(v):
  格式路径给空格、冒号、选项标签、换行等词元的支持

y_syntax(v):
  句法路径对冠词、介词、标点、短语开头的支持

y_continuation(v):
  局部续写路径对“自然接下去”的支持

y_tokenization(v):
  分词器和词频造成的偏置
```

这比之前只看 semantic support（语义支持）更完整。

