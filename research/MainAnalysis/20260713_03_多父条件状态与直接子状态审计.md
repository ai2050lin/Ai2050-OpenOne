## 一、结论先行

对用户给出的“内部大概率存在高效结构”和 Phase401 后续方案的总体判断是：**存在内部计算结构这一弱命题成立，但从正确输出直接推出“大脑语言结构还原、紧凑因果状态商或算子代数”并不成立。Phase401 的证据分级基本正确，提出的四类抽象父状态则必须先改写为计算图上可执行的张量父节点。**

Phase402 已经完成这一步，并依次在 Qwen3、GLM4、DS7B 上执行：

1. 冻结六个任务面、`144` 个平行组、`6912` 个行为案例；语义正确 `5585/6912`。
2. 只有角色填槽和条件存在满足发现、校准、物理留出的三分割行为门，进入内部追踪的案例为 `1152`。
3. 把前缀到查询接收者的真实注意力 K/V 位置划分为四个互斥且守恒的父分区：来源内容、来源结构、查询局部、剩余前缀。
4. 三模型全部父分区重放账本为 `3328/3328`，最大空子集注意力重放相对误差不超过 `0.008925387`。
5. 发现集覆盖 `576` 个模型案例、全部 `16` 个父分区子集和九类真值/控制操作，保留 `2875392` 条配对指标和 `179712` 条组层子集聚合指标。
6. `13728` 个联合组层子集中，真实响应门通过 `5909` 个；同时超过最佳包含单父的有 `641` 个；独立排除全部适用控制的有 `18` 个；三门同时通过的局部单元只有 `8` 个。
7. 这 `8` 个单元全部属于早层 `source_structure + query_local` 子集：Qwen3 为 `0`，GLM4 为 `1`，DS7B 为 `7`。
8. 模型级候选为 `0`，双模型部分复现为 `0`，跨模型候选为 `0`。
9. 因此校准 `288` 例、物理留出 `288` 例均未使用；传播、终端生成、自然必要性、联合因果和神经元扫描均未授权。

本阶段最严格的正结果是：

\[
\boxed{
\text{来源结构与查询局部状态在少量早层存在联合局部响应迹象}
}
\]

最严格的否定边界是：

\[
\boxed{
\text{四分区直接子状态候选}=0\text{ 个模型级候选}=0\text{ 个跨模型候选}
}
\]

因此：

\[
\boxed{
\text{局部联合响应}\neq\text{可移植语言父状态}\neq\text{完整语言机制}
}
\]

## 二、对原始判断的审计

### 1. 正确部分

以下判断可以保留：

- 三个模型能稳定完成部分知识、关系和格式任务，说明权重与运行状态中必然存在实现这些行为的计算过程；
- 只搜索单神经元、单头、单层或单位置，可能错过联合形成、分布式写入和跨层补偿；
- 静态端点集合不能自动视为动态因果状态；
- 观测相似、可预测和因果可搬运必须分开；
- 研究单位应从“高分节点”升级为计算图合法的多父状态与后续事件链；
- 小模型可能更粗糙、更依赖字面位置和补偿通道，负结果不能直接外推到大模型或大脑。

### 2. 不能成立的强推论

“模型能正确生成”只能推出：

\[
\exists C_\theta(X),\quad Y=f(C_\theta(X)),
\]

即存在某种实现输出的计算。它不能单独推出：

\[
C_\theta\text{ 是紧凑的、唯一的、可读的、与大脑同构的。}
\]

也不能推出：

\[
\text{当前观测可构成因果状态商或稳定算子代数。}
\]

原因包括：

- 同一输入输出函数可以有多种内部实现；
- 分布式表示可能依赖大量互相补偿的坐标；
- 小模型可能依赖训练语料、分词和模板捷径；
- 能被线性读出、能被预测和能被干预控制不是同一证据等级；
- 当前实验只覆盖有限任务面和三个小模型，不具有脑结构同构证据。

因此“大脑语言结构还原”目前仍是研究动机，不是实验结论。

### 3. 对 Phase401 后续方案的修正

原方案提出内容、结构、查询、历史四类父状态，方向合理，但这些首先是语义标签，不是可直接干预的张量。

Phase402 将其操作化为：

```text
source_content：来源实体和值词元位置；
source_structure：来源区域中除内容词元外的结构词元；
query_local：查询实体、查询结构词元和接收者自身；
remaining_prefix：接收者之前尚未归类的提示词元。
```

四类位置互斥，且并集覆盖接收者之前的全部位置。需要特别收紧：在首个答案词元之前并不存在“已生成历史”，所以 `remaining_prefix` 只能称为剩余提示前缀，不能称为生成历史状态。

## 三、冻结实验合同

### 1. 行为分母

六个任务面为：

```text
entity_attribute_binding；
role_filling；
coreference_resolution；
two_step_composition；
conditional_presence；
number_agreement。
```

每个任务面 `24` 个候选组，每组 `16` 个完整析因条件，三个模型：

\[
6\times24\times16\times3=6912.
\]

候选组在生成前分为发现、校准、物理留出 `12/6/6`。每个任务面只有在三个模型上拥有至少 `6/3/3` 个完整组时才进入内部追踪，禁止跨分割补组。

### 2. 多父子集

令四类父分区为：

\[
P=\{C,S,Q,R\},
\]

分别表示来源内容、来源结构、查询局部、剩余前缀。枚举全部：

\[
2^4=16
\]

个子集，包含空集重放控制。

对供体 (d)、接收者 (r)、层 (l)、查询位置 (q) 和父子集 (U\subseteq P)，使用接收者查询与掩码，只替换 (U) 内的供体 K/V：

\[
A^{cf}_{l,q,U}=Attn_l\left(
Q^r_{l,q},
K^{r\leftarrow d}_{l,U},
V^{r\leftarrow d}_{l,U},
Mask^r_q
\right).
\]

本阶段直接子节点只有查询位置注意力输出 (A_{l,q})。没有把 MLP、层输出或最终生成伪装成同一条直接边。

### 3. 基础状态指标

令自然供体、自然接收者和反事实直接子状态分别为 (v_d,v_r,v_{cf})：

\[
\Delta_n=v_d-v_r,\qquad
\Delta_i=v_{cf}-v_r.
\]

方向余弦：

\[
D=\cos(\Delta_i,\Delta_n).
\]

状态恢复率：

\[
R=1-\frac{\|v_{cf}-v_d\|_2}{\|v_d-v_r\|_2}.
\]

配对门要求自然差异足够大、(D\ge0.6)、(R\ge0.2)。组层子集还必须满足：

```text
信息配对率 >= 0.75；
配对通过率 >= 0.75；
中位恢复率 >= 0.25；
联合子集至少包含两个父分区；
相对最佳包含单父的中位恢复增量 >= 0.10；
相对最佳包含单父的通过率增量 >= 0.20；
对每一项适用控制分别满足恢复和通过率增量；
禁止把多个控制取平均后过门。
```

### 4. 控制合同

正式操作包含真实关系和八类控制：

```text
同目标错误顺序；
错误接收者角色；
错误语义时刻；
错误深度；
来源内容角色置换；
同内容错误结构；
确定性随机自然供体；
绝对质量相同的符号置换。
```

其中符号置换只是测量控制，不是计算图合法的 K/V 父节点补丁。内容置换只适用于含来源内容的子集，结构控制只适用于含来源结构的子集；不适用控制被明确记录并从该门中排除。

| DS7B | 28 | 896 | 896 | 0.008925387 |

第一次 GLM4 账本运行曾有 `13/1280` 行失败。原因不是模型机制，而是重放代码先把 Q/K 提升到 float32 再做矩阵乘法，与模型原生执行路径不一致。代码修正为先按原生 dtype 完成 QK，再以 float32 做 softmax，随后按 Qwen3、GLM4、DS7B 的顺序重新运行全部账本。阈值没有放宽，失败结果没有混入正式分母。

账本通过只说明当前重算器可以复现直接注意力子状态：

\[
\boxed{\text{仪器合格}\neq\text{父状态机制成立}}
\]

- 该子集是最小充分状态；
- 该子集控制最终答案；
- Qwen3 具有相同结构；
- 两个任务共享同一个跨模型机制；
- 已找到自然语言路径；
- 可以继续定位具体头、通道或神经元。

## 八、协议硬伤与局限

### 1. 小数阈值产生了离散歧义

冻结值为：

\[
r_{min}=0.666666667.
\]

在六组分母上：

\[
4/6=0.666666666\ldots<0.666666667,
\]

所以实际需要 `5/6`，不是原意可能指向的 `4/6`。本轮按冻结值执行，没有事后改为 `2/3`。这不会改变跨模型结论，因为 Qwen3 为零，且不存在双模型候选；但下一阶段必须直接冻结整数计数，不能再用近似小数表达离散门。

### 2. 四类分区仍然过粗

`source_structure` 和 `query_local` 各自包含多个不同功能词元。通过 `S0110` 不能说明真正有效的是哪一个父事件，也不能说明它表示抽象“结构”和“查询”。

### 3. 只测了一个直接子节点

本轮只重算同层查询注意力输出，没有跟踪：

```text
同层 MLP 转换；
下一层写入；
跨层继续传播；
终端读出；
自然生成答案；
必要性或充分性。
```

因此当前负结果关闭的是“四分区、同层、直接查询注意力子节点”这一具体假设，不是所有动态多父机制。

### 4. 指标量大不等于独立证据多

`2875392` 条配对指标共享案例、层、子集和控制。科学独立单位首先是预注册平行组，不应把配对行数当作数百万个独立样本。

### 5. 任务覆盖仍不完整

六个任务面只剩两个进入内部分析。知识绑定因校准组不足退出，指代因发现组不足退出，两步推理和数量语法完全没有合格组。当前不能称为九族语言图谱的全覆盖验证。

### 6. 小模型因素只能限制外推，不能消解本轮结果

模型小、结构粗糙可能导致跨模型同构更弱，也可能使位置和模板效应更强。但不能因为结果为负，就事后把所有失败都归因于模型规模。本轮对这三个指定模型和冻结合同的结论仍然成立。

## 九、理论进展

### 1. 可以保留的拼图

- 模型内部存在可重放的实际父子计算；
- 单来源粗补丁不够特异，联合父状态是合理搜索方向；
- 来源结构与查询局部在少量早层出现联合迹象；
- 静态端点集合和单层线性方向不足以代表完整机制；
- 研究对象应进一步升级为按真实计算顺序组织的多阶段事件链。

### 2. 仍不能登记的理论

当前没有证据登记：

```text
因果状态商；
跨任务稳定算子；
知识、推理、语法统一代数；
大脑语言结构还原；
最小充分状态；
完整语言路径；
单神经元因果闭合。
```

完整语言路径仍为 `0/72`，单神经元因果路径仍为 `0/72`。不同分母不能相加成一个科学完成百分比；如果保留约 `23%` 的项目管理估计，本阶段不应因大量配对指标而上调。

## 十、下一阶段方案

当前四分区直接子假设已经按停止规则关闭，不能继续使用校准或物理留出，也不能转入神经元扫描。

下一阶段应先完成新合同，再决定是否运行模型：

### 任务 A：修复合同表达

```text
全部离散门使用整数计数；
提示前缀与生成历史分开；
直接子门、传播门、终端语义门分开；
每项控制的适用对象在采集前冻结；
保持 batch=1、无 padding 和原生 dtype。
```

### 任务 B：把父分区改为阶段事件

候选不再是四个宽静态分区，而是合法计算顺序中的事件链：

```text
来源注意力读取；
来源/关系的 MLP 写入；
查询位置整合；
跨层传播；
终端读出。
```

只有相邻事件通过实际父子重算，才登记为物理边。

### 任务 C：重新建立任务分母

使用全新平行组，至少分别确保知识绑定、两步组合和语法一致有可用发现/校准/物理留出。任务不合格时先修行为设计，不能用其他任务代替。

### 任务 D：严格升级顺序

```text
仪器账本
→ 发现集阶段事件链
→ 模型内独立组稳定性
→ 三模型同构候选
→ 冻结校准
→ 独立物理留出
→ 传播与终端生成
→ 自然必要性/充分性
→ 头、通道、神经元定位。
```

当前只授权新协议设计，不授权自动运行下一轮模型。原因不是需要人工挑结果，而是下一阶段改变了因果对象和数据合同；直接沿用 Phase402 数据或放宽门槛会破坏独立验证。

## 十二、通俗说明

这轮把一句很抽象的话变成了可测试问题：答案形成时，是不是要把“来源内容、来源结构、查询上下文、其他前缀”一起放进网络，下一步才会按正确方向变化？

结果是，少数早层确实出现了“来源结构和查询上下文一起换，比只换一个更有效”的现象；但这种现象主要集中在 DS7B，Qwen3 完全没有，而且在同一模型的独立样本里也不够稳定。所以现在只能把它画成淡色的局部迹象，不能画成贯穿网络的语言线路，更不能继续放大到具体神经元。

下一步真正值得做的不是继续扩大同一种补丁，而是沿计算发生的顺序，分别寻找“读取、写入、查询整合、传播、读出”这些阶段怎样接起来。只有这条链在新样本和三个模型中都能复现，并能改变自然答案，才有资格接近语言编码机制。
