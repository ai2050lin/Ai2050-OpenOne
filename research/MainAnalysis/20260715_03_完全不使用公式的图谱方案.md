# 二、需要修正的两个地方

## 1. 不能预设机制公式，但必须预设测量规则

“完全不预设任何公式”过于绝对。

不能预设的是：

- 语言一定是线性的；
- 每种概念对应固定神经元；
- 机制一定沿单条路径传播；
- 三个模型使用相同坐标；
- 激活越大越重要；
- Attention 就是路由、MLP 就是知识存储。

必须预先固定的是：

- Transformer 的真实计算依赖；
- 残差、Attention 和 MLP 的数值守恒；
- 模型原生 dtype 和执行方式；
- 发现、校准、密封和因果数据分割；
- 正负对照；
- 候选淘汰条件。

否则算法可以从海量数据中“发现”任何想看到的结构。

## 2. 大量统计不等于机制破解

大量数据只能帮助找到重复现象：

\[
\text{稳定相关}
\not\Rightarrow
\text{因果规则}
\]

真正的路线应当是：

\[
\boxed{
\text{盲发现}
\rightarrow
\text{未见预测}
\rightarrow
\text{合法干预}
\rightarrow
\text{恢复}
\rightarrow
\text{规则归纳}
\rightarrow
\text{公式压缩}
}
\]

# 四、系统架构

## 1. 数据生成器

每种语言现象必须包含多个独立变化轴：

- 词汇变化
- 对象变化
- 关系变化
- 顺序变化
- 句法变化
- 模板变化
- 接口变化
- 历史变化
- 正确与错误条件
- 短文本与长文本
- 单步与多步生成

例如关系绑定不能只有：

```text
Alice owns a red box.
What color is Alice's box?
```

还应包括：

```text
Bob owns a blue key.
The green cup belongs to Carol.
David gave Eva a yellow disk.
The object nearest Frank is purple.
```

并构造匹配反例、角色交换、无关历史、顺序变化和新词汇。

数据必须分为：

```text
discovery       发现集
calibration     校准集
behavior_holdout 行为留出
sealed_holdout  密封物理留出
causal_holdout  因果留出
cross_model     跨模型复本
```

---

## 2. 原始计算记录器

不首先压缩成范数、最大值或 top-k。

至少记录：

- 所有位置的 residual stream（残差流）
- 实际 Q/K/V
- Attention probability（注意力概率）
- 每个头的来源到接收写入
- MLP gate、up、product
- MLP 通道写回
- LayerNorm 输入输出
- 全词表竞争
- 每个生成时刻
- KV cache
- EOS、改口、句界、截断等事件

基本要求是原生精度守恒：

\[
h_{l+1}=h_l+a_l+m_l
\]

这里的公式不是语言假说，只是确认记录器没有漏掉真实计算。

---

## 3. 标签盲化发现器

发现阶段禁止读取：

- 语言模式族名称；
- 正确答案；
- 历史候选层；
- 已知颜色神经元；
- 人工功能标签。

发现器只看到：

```text
模型
层
组件
来源位置
接收位置
生成时刻
真实向量
计算图父子关系
匿名案例组
```

它寻找：

- 重复出现的分叉；
- 多条路径的汇合；
- 持续写入；
- 方向反转；
- 补偿路径；
- 候选竞争突变；
- 生成时间上的阶段切换。

这样可以减少“因为我们在找颜色，所以看什么都像颜色”的确认偏差。

# 五、脉络发现算法

## 第一步：建立事件

每个事件记录为：

```text
Event {
  model
  layer
  component
  source_positions
  receiver_position
  generation_step
  vector_reference
  parent_events
  execution_contract
}
```

## 第二步：建立合法局部图

只根据真实计算图建立边：

```text
source residual → K/V
K/V + attention probability → head write
head writes → attention output
attention output + residual → MLP input
MLP channel writes → layer output
layer output → next layer
```

不能因为两个向量相似就画因果箭头。

## 第三步：寻找重复子图

对匿名案例比较：

- 事件类型是否相同；
- 分叉和汇合顺序是否相同；
- 是否出现在相对相近的深度；
- 是否能预测后续事件；
- 是否明显强于匹配控制。

跨模型不要求神经元编号相同，只要求功能响应结构相同。

---

# 六、如何寻找有效神经元

不能按激活值排序。正确流程是从组件子图逐层下钻。

## 第一级：组件组

先确定哪个局部组件组对行为有必要性。

例如：

```text
Layer 18–21
source-to-query Attention
+ query MLP rewrite
```

## 第二级：守恒分区

把全部头或 MLP 通道按固定、与结果无关的方式分组：

```text
二分
四分
八分
固定哈希分片
```

逐组执行：

- 删除；
- 恢复；
- 错组替换；
- 与其他组联合删除。

## 第三级：递归缩小

某组通过因果门后继续二分：

```text
全部通道
→ 左半有效
→ 左半的右半有效
→ 继续缩小
```

这类似因果二分搜索，不依赖激活峰值。

## 第四级：单神经元审计

单神经元必须同时通过：

```text
自然必要性
恢复有效
错误神经元无效
跨词汇复现
跨模板复现
低副作用
独立留出
```

如果单神经元删除无效、神经元组删除有效，应接受“分布式协同”结论，而不是强行寻找一个核心神经元。

# 七、状态充分性检验

候选脉络不能只解释当前状态，还必须预测未来。

给定候选子图状态 \(Z_t\)，测试它能否预测：

- 下一层写入；
- 下一生成步事件；
- 候选排名变化；
- 正确答案分支；
- 停止或继续；
- 完整自然生成结果。

最关键的碰撞检验是：

```text
找到两个候选状态看起来相同的案例
检查它们未来是否相同
```

如果：

\[
Z_t^{(1)}\approx Z_t^{(2)}
\]

但：

\[
Y_{t+1}^{(1)}\neq Y_{t+1}^{(2)}
\]

说明候选状态遗漏了必要信息，必须扩充来源、位置、历史、时间或组件，而不能靠放宽阈值宣布成功。

---

# 八、因果验证器

候选必须依次通过：

1. 自然状态损伤  
2. 错误来源控制  
3. 错误角色控制  
4. 错误位置控制  
5. 错误时间控制  
6. 错误深度控制  
7. 正确状态恢复  
8. donor 状态交换  
9. 中介恢复  
10. 非目标能力副作用检查  

例如候选路径被删除后答案 margin 下降，但错误深度删除同样下降，就不能证明深度特异性。

如果恢复候选后行为没有恢复，也不能证明找到了正确机制对象。

---

# 九、规则如何从数据中浮现

当多个事件子图通过密封预测和因果验证后，不立即拟合高级公式，而先建立离散规则表：

```text
条件状态 A + 查询角色 X
→ 打开候选集合 C1
→ 激活来源路径 P3
→ 查询端发生重写 R2
→ 候选 y 胜出
```

进一步寻找：

- 哪些路径在不同任务中复用；
- 哪些路径根据接口分叉；
- 哪些组件可以互相补偿；
- 哪些事件必须按顺序出现；
- 哪些状态变化是可逆的；
- 哪些状态是任务特异的；
- 哪些结构跨模型功能同构。

最后得到的可能不是单个方程，而是：

```text
条件状态机
有类型事件图
动态路由表
局部转换规则集合
```

# 十、公式应放在最后

只有规则经过因果验证后，才比较哪种表示最简洁：

- 离散状态转移表；
- 分段线性规则；
- 布尔条件；
- 有限状态机；
- 小型程序；
- 简单代数关系；
- 局部动力学方程。

公式的角色应该是：

\[
\boxed{
\text{压缩已发现规则}
}
\]

而不是：

\[
\boxed{
\text{预先规定模型必须符合什么}
}
\]

如果一个公式不能预测密封数据，也不能指导干预和恢复，它就只是描述性拟合。

# 十一、建议的六个大阶段

**阶段一：全迹基础设施**

完成三模型统一、原生精度、可恢复的事件账本。

**阶段二：无标签脉络发现**

在关系绑定、字段抽取、指代和数一致四类稳定任务上，使用数百个独立组发现动态子图。

**阶段三：密封未来预测**

冻结候选，在完全未见词汇、模板、历史和接口上预测后续事件与自然行为。

**阶段四：组件级因果闭合**

执行损伤、控制、恢复和中介实验。没有组件级闭合，不进入神经元搜索。

**阶段五：真实神经元定位**

使用守恒分区和递归因果二分搜索，寻找头、通道和神经元协同集合。

**阶段六：规则归纳与理论压缩**

比较不同任务之间的复用、分叉和补偿结构，最后建立数学表达和智能理论。

# 最严格结论

你的路线比“继续寻找一个闭合公式”更合理，但应改写为：

> **不预设语言机制的函数形式；预先冻结真实计算图、测量合同和证伪规则。通过大规模标签盲化数据发现重复动态子图，再用独立预测、密封留出、合法干预和恢复确认规则，最后用最简单的数学结构压缩规则。**

这条路线也必须允许一个不那么浪漫、但科学上重要的结果：

> 真实语言机制可能是高度条件化、分布式且可补偿的，短期内不存在远小于完整模型状态的统一闭合公式。
