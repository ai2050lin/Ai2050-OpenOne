# Phase407：事件地平线条件响应核与接口迁移审计

时间：2026-07-13 06:05 HDT（UTC-09:00）

## 一、对输入分析的审计

Phase406 外部审计的主要方向正确：单个下一词元不能代表完整语言响应，未来查询、输出接口、历史位置和停止行为必须进入实验条件。基于这一判断，本阶段接受了以下改进：

1. 用条件化短序列替代单词元状态读出；
2. 为知识绑定、规则推理和语法约束分别设计两个接口；
3. 比较同一语义状态位于当前轮和前一轮时的响应；
4. 将跨表面、跨接口、跨历史、短序列语义和完整响应门分开；
5. 使用全新语义组，冻结发现、校准、行为留出和物理留出；
6. 三模型全部通过功能门后，才允许物理映射。

原方案仍有六处必须收紧：

1. 不能在语义首次出现时停止生成，也不能令 `tau* = min(tau_semantic, tau_boundary, tau_stop)`；
2. 必须一直生成到模型 EOS 或 H48，并分别记录三个事件；
3. H48 内未出现的事件属于右删失，不能自动解释为永远不会出现；
4. top-k、归一化量和目标/反例序列分数只是压缩证据，不是完整生成核；
5. 预先列出的端点状态转换不是模型实际执行的内部算子；
6. 当前轮与前一轮两个历史条件不能代表全部生成历史。

因此，输入分析整体正确，但原有措辞对“自然终点”“生成核”“状态算子”和“历史完整性”说得过强。本阶段已经按更严格口径执行。

## 二、测量对象与公式

对模型 `m`、语义状态 `s`、表面形式 `u`、接口 `i`、历史方式 `h` 和机器执行合同 `mu`，自然响应记为：

```text
Y ~ K_m(. | s, u, i, h, mu)
```

本阶段没有恢复完整的 `K_m`，只记录确定性贪心轨迹、逐步压缩概率账本和两个标准续写分数。

外部语义规范化器记为 `N_i`：

```text
R_m(s,u,i,h) = N_i(Y)
```

三个事件分别定义为：

```text
tau_semantic = 首次形成完整注册语义状态的步数
tau_boundary = tau_semantic 之后首次出现合法句界的步数
tau_stop     = 首次生成模型 EOS 的步数
```

三者独立记录。生成只由 `EOS` 或 `H48` 终止，任何较早事件都不截断轨迹。

每个条件单元的离散响应映射为：

```text
P_c : s -> N_i(Y),    c = (m, group, u, i, h)
```

它被客观分为四类：恒等映射、完整非恒等置换、状态塌缩、缺失。完整非恒等置换只能说明注册响应之间存在系统映射，不能直接称为正确语义或内部算子。

## 三、冻结协议

### 1. 分母

每个语言族冻结 30 个全新语义组：

```text
发现 12；校准 6；行为留出 6；物理留出 6。
```

三个族分别有 4、2、4 个状态；每个状态使用 4 个表面、2 个族特异接口、2 个历史方式和 3 个模型。

```text
全阶段冻结案例：14,400
正式发现案例：5,760
条件响应单元：1,728
正式组：108
```

### 2. 执行合同

```text
设备：CUDA
模型顺序：qwen3 -> GLM4 -> DS7B
batch：1
padding：无
attention：eager
生成：确定性贪心
最大生成：48 token
终止：模型 EOS 或 H48
```

每个模型先运行 24 个冻结资格案例，每例重复两次。三个模型均为 `24/24` 精确重复，总计 72 个唯一案例、144 次资格运行。

### 3. 正式门

每个组分别计算：

```text
表面门：每个 状态×接口×历史 单元至少 3/4 表面正确；
接口门：每个 状态×历史 至少 3/4 表面在两个接口上同时正确；
历史门：每个 状态×接口 至少 3/4 表面在两种历史上同时正确；
序列门：知识 56/64，推理 28/32，语法 56/64；
完整响应门：知识 48/64，推理 24/32，语法 48/64。
```

一个模型族必须至少 `9/12` 个发现组分别通过表面、接口、历史和序列门。三模型都通过同一族后，才能消费校准集。

### 1. 总体


## 五、响应分区的新拼图

对 1,728 个条件响应单元进行离散映射审计：

```text
注册恒等映射：894
完整非恒等置换：43
注册状态塌缩：302
缺失映射：489
```

43 个完整非恒等置换主要表现为：

```text
green_yellow <-> yellow_green
green_green、yellow_yellow 保持不变
```

这说明部分知识接口会系统性改变有序槽位的读出方向，而不是随机答错。然而，432 个跨表面映射组中只有 141 个在四个表面上完全稳定；稳定组包括 128 个恒等、8 个塌缩和 5 个缺失，没有稳定的完整非恒等置换。

所以当前证据支持：条件会改变响应映射形状；不支持：已经发现可迁移的稳定接口算子。

## 六、数值和合同硬伤

### 1. GLM4 数值退化

GLM4 有 129 个案例出现非有限原始 logits；这些案例全部生成到 H48，全部出现连续感叹号退化。首次非有限发生在第 1 步的有 97 例。最大集中单元是语法 `syntax_completion × prior_turn_carried_state`，共 72 例。

这是一条模型和运行精度特异的数值路径，不能解释成语言状态失败。正式协议按预注册规则将其判为无效成功，但报告必须单列。

### 2. 语法合同不排他

2,304 个语法案例中有 1,106 个没有形成注册状态。其中特别值得注意：

```text
466 例生成 has been / have been / had been 或进行式 be；
217 例在未被正式解析时仍出现目标 be 字面量；
175 例只出现目标 be 而没有其他注册 be 字面量。
```

模型生成 `has been`、`have been` 或其他合法谓词，并不直接说明它缺乏主谓一致能力。当前语法提示把“注册目标不命中”和“语法能力失败”混在了一起，因此语法负结果只能约束本协议，不能外推为模型内部没有语法结构。

### 3. 解析器边界

正式失败可拆为：

```text
无完整注册语义：1,109
注册语义错误：582
非有限路径：129
歧义或后续修订：2
其他显式反转类：3
```

外部解析器是保守观察器，不是模型内部状态读出。未解析响应不能全部算作模型不知道答案；正式门仍保持原结果，诊断只用于暴露测量下界。

## 七、对语言编码机制的谨慎更新

本阶段最可靠的新认识不是“发现了状态”，而是“状态不能脱离未来条件和接口定义”。同一个输入世界状态在不同接口、历史位置和表面上形成不同响应映射，且标准续写偏好与自然生成并不等价。

可以保留以下有限表述：

```text
模型内部存在足以支持大量正确响应的条件信息；
外部读出的响应关系具有恒等、置换、塌缩和缺失等离散形状；
这些形状目前不能跨表面、跨接口、跨历史和跨模型稳定迁移。
```

不能保留以下强表述：

```text
已经找到完整语言状态；
已经找到接口变换算子；
已经定位知识、推理或语法的物理路径；
已经找到头、通道或神经元级语言编码；
当前线性或端点公式已经闭合。
```

## 九、Phase408 分阶段方案

下一阶段需要做，但不能直接沿用 Phase407 分母执行。建议分成三个小门，逐门验证后再扩大：

### A. 查询合同排他性审计

1. 每个族构造只能落入一个注册语义槽的自然回答合同；
2. 语法任务把“目标辅助词”与“任意合法谓词续写”分开；
3. 在看到模型结果前，冻结允许答案、拒绝答案、歧义答案和解析测试；
4. 对每个接口做人工规则审计，证明题目本身没有多个同样合法的答案。

### B. 状态信息与答案正确性分离

1. 继续记录恒等、置换、塌缩和缺失，而不是只记录正确/错误；
2. 只有跨四表面稳定的映射才进入接口候选；
3. 完整非恒等置换不能直接算正确，但可作为待验证接口变换；
4. 增加历史内容控制：同轮、前轮等义、前轮无关内容、前轮冲突后明确覆盖；
5. 不使用静态端点差分冒充模型执行算子。

### C. 新运行资格与新分母

1. 为 GLM4 增加跨族、接口、历史和长输出压力资格；
2. 资格必须拒绝非有限路径，不能只检查重复性；
3. 比较 float16 与 bfloat16 的同案例输出合同后再冻结运行精度；
4. 使用全新发现/校准/行为/物理语义组；
5. 只有三模型功能校准通过后，才允许内部激活、物理映射和神经元级研究。

Phase408 的协议设计应自动继续，但正式模型执行尚未授权：它需要新的任务合同、新分母和新的数值资格，不能把 Phase407 的失败样本直接改写后重跑。

## 十一、通俗结论

模型大多数时候能答对，不代表我们已经找到一个可搬运、可跨接口、可跨历史、可跨模型复用的“语言状态”。Phase407 把答案过程拆开后发现：正确内容很多，但换一种问法、把事实放到前一轮，或换一个模型，响应映射就可能改变；有时甚至会稳定地把两个槽位反过来。

所以当前最需要破解的不是某个神经元，而是先把“模型知道了什么”“问题要求它怎么回答”“答案通过哪个接口输出”三件事分开。只有这三层在新合同下稳定，继续追踪内部物理路径才有可信意义。
