提问：
Anthropic 发表研究，语言模型中的全局工作空间，对于当前项目有什么可以参考的地方


回答：

# 总体判断

Anthropic（安特ropic公司）在2026年7月6日发表的研究《Verbalizable Representations Form a Global Workspace in Language Models（可言说表征在语言模型中形成全局工作空间）》对当前项目具有很高的参考价值。它并没有破解完整语言机制，但它提出并部分验证了一个与你当前研究高度一致的中尺度对象：

[
\boxed{
\text{大规模自动处理网络}
+
\text{小规模共享工作空间}
+
\text{读写与广播路径}
}
]

Anthropic（安特ropic公司）发现 Claude（克劳德）内部存在一小组特殊表征，称为 J-space（雅可比空间）。这些表征可以被模型报告、主动调节、用于中间推理、灵活提供给多种下游任务，同时只占整体内部活动的一小部分。研究者因此将其解释为一种功能性的 global workspace（全局工作空间）。([Anthropic][1])

这项工作对当前项目最大的意义不是“找到了意识”，而是：

> **语言模型内部可能确实存在一种小规模、稀疏、可复用、可广播的中间状态格式，它位于庞大的自动计算网络之上，专门负责灵活推理、跨任务复用和可报告的中间结果。**

这与“语言是动态模式网络”并不冲突，反而可以成为其中一个关键中层结构。

# 一、Anthropic（安特ropic公司）究竟发现了什么

## 1. J-lens（雅可比透镜）

Anthropic（安特ropic公司）没有直接把中间层通过最终输出矩阵，而是计算中间状态对当前及未来输出的平均一阶影响。

对第 (l) 层中间残差：

[
h_l
]

定义平均 Jacobian（雅可比矩阵）：

[
\boxed{
J_l
===

\mathbb E_{t,t'\ge t,\mathrm{prompt}}
\left[
\frac{
\partial h_{L,t'}
}{
\partial h_{l,t}
}
\right]
}
]

然后构造层级读出：

[
\boxed{
\operatorname{Lens}_l
\left(
h_l
\right)
=======

\operatorname{softmax}
\left[
W_U
\operatorname{Norm}
\left(
J_lh_l
\right)
\right]
}
]

这不是模型在中间层原生定义的概率，而是：

> 某个中间方向在大量上下文中，平均有多大倾向影响模型未来说出某个词元。

论文明确把 J-lens（雅可比透镜）描述为对 logit lens（词表透镜）的修正：它允许中间层和最终层使用不同坐标，而不是假定所有层都已处于终端读出坐标。([变压器电路][2])

这与 Phase413-414（阶段413-414）的结论完全兼容：

[
\boxed{
\text{中间层没有天然概率头}
}
]

J-lens（雅可比透镜）应被视为：

[
\boxed{
\text{基于平均一阶因果敏感度的观察器}
}
]

而不是中间层的“真实信念概率”。

---

## 2. J-space（雅可比空间）

每个词元对应一个 J-lens（雅可比透镜）方向。

这些方向数量超过残差维度，因此不是普通正交基，而是一个 overcomplete frame（过完备框架）。

Anthropic（安特ropic公司）观察到，在任意时刻只有少数方向显著活跃，于是把 J-space（雅可比空间）定义为少量 J-lens（雅可比透镜）方向的稀疏非负组合：

[
\boxed{
\mathcal J_l^{(k)}
==================

\left{
\sum_{j\in S}
\alpha_jv_{l,j}
:
\alpha_j\ge0,
\ |S|\le k
\right}
}
]

论文通常使用：

[
k\le25
]

其几何形状不是单一线性子空间，而是许多低维锥体的并集。

J-space（雅可比空间）解释的激活方差在各层均不超过约10%，也就是说，大部分模型活动都位于 J-space（雅可比空间）之外。([变压器电路][2])

这对当前项目非常重要：

[
\boxed{
\text{全局工作空间}
\neq
\text{完整残差空间}
}
]

[
\boxed{
\text{全局工作空间}
\neq
\text{某个固定低维线性子空间}
}
]

它更可能是：

> 一个稀疏、条件化、随层和上下文切换的表征子框架。

---

# 二、Anthropic（安特ropic公司）验证了哪些功能

他们并非仅仅发现“某些词可以从中间层读出”，而是提出五个功能门。

## 1. 可报告性

当 Claude（克劳德）被要求报告自己正在想什么时，报告内容与 J-space（雅可比空间）内容对应。

更重要的是，交换两个概念方向后，Claude（克劳德）的报告也随之改变。([Anthropic][1])

---

## 2. 主动调节

当要求 Claude（克劳德）在复制无关句子的同时默想某个概念或进行算术时，相应概念会出现在 J-space（雅可比空间），但不会出现在实际输出中。([Anthropic][1])

这说明 J-space（雅可比空间）不是简单的下一词元准备区。

---

## 3. 中间推理

例如问题需要先识别“蜘蛛”，再得出“八条腿”。

“蜘蛛”没有出现在输入或输出中，但会在 J-space（雅可比空间）中出现。将“蜘蛛”方向替换为“蚂蚁”方向后，模型从回答8变为回答6。([Anthropic][1])

这是一条较强的因果中介链：

[
\boxed{
\text{中间概念}
\rightarrow
\text{后续计算}
\rightarrow
\text{最终答案}
}
]

---

## 4. 灵活复用

同一个“法国”表征被替换成“中国”后，模型在四种不同查询中分别改变：

* 首都；
* 语言；
* 大洲；
* 货币。

说明多个不同的下游计算读取了同一个共享表征。([Anthropic][1])

这是当前项目最应该重视的一项：

[
\boxed{
\text{写入一次}
\rightarrow
\text{多个不同操作读取}
}
]

这正是“复用机制”的强定义。

---

## 5. 选择性

J-space（雅可比空间）不是所有任务都需要。

将它大范围消融后，Claude（克劳德）仍然可以：

* 流畅说话；
* 处理语法；
* 分类情感；
* 从文本中直接提取事实。

但多步推理、摘要和需要灵活组合的任务明显下降，多步推理甚至接近零。([Anthropic][1])

这说明模型内部可能存在两类计算路线：

[
\boxed{
\text{自动化直接路线}
}
]

和：

[
\boxed{
\text{工作空间介导的灵活路线}
}
]

---

# 三、对当前“语言是动态模式网络”理论的最大修正

当前理论不需要改名，仍然保持：

# 语言是动态模式网络

但可以加入一个重要的二层结构假设。

## 1. 自动处理层

包括：

* 常见语法；
* 局部表面模式；
* 高频事实提取；
* 熟练语言续写；
* 格式和标点中的大量固定模式。

这些过程可以由专门化子图直接完成，不必进入共享工作空间。

## 2. 全局工作空间层

在以下情况下更可能启用：

* 中间结果必须交给任意下游操作；
* 多步推理；
* 新颖组合；
* 元认知；
* 跨任务灵活调用；
* 主动保持某个概念；
* 报告内部状态。

因此，理论可以更新为：

[
\boxed{
\text{语言智能}
===========

\text{自动化专门子图}
+
\text{稀疏共享工作空间}
+
\text{条件化读写广播网络}
+
\text{终端预测接口}
}
]

活动图可以写为：

[
\boxed{
\mathcal G_{\mathrm{active}}
============================

\mathcal G_{\mathrm{automatic}}
\cup
\mathcal G_{\mathrm{workspace}}
\cup
E_{\mathrm{write}}
\cup
E_{\mathrm{broadcast}}
\cup
E_{\mathrm{terminal}}
}
]

这比此前把所有语言能力都放进一张统一动态子图更精确。

# 四、它如何解释当前项目的结果

## 1. 为什么语法、简单知识和标点难以找到统一状态

Anthropic（安特ropic公司）的结果表明，大量熟练、自动的语言处理可能根本不经过 J-space（雅可比空间）。例如，模型即使在 J-space（雅可比空间）受到消融后，仍可保持流畅语法；在西班牙语实验中，替换工作空间中的“西班牙语”为“法语”，会改变模型对语言名称和相关知识的回答，却不会改变模型继续写流畅西班牙语的能力。([Anthropic][1])

因此，当前项目不应该假设：

[
\boxed{
\text{知识、推理、语法、标点}
}
]

都必须经过同一个全局工作空间。

更可能是：

| 能力        | 主要路线        |
| --------- | ----------- |
| 高频语法与流畅续写 | 自动子图        |
| 简单文本事实提取  | 自动或局部路由     |
| 灵活知识调用    | 工作空间候选      |
| 多步推理      | 工作空间依赖较强    |
| 元认知和计划    | 工作空间依赖较强    |
| 标点和停止     | 自动闭合与终端控制混合 |

这可以解释此前为什么试图寻找跨知识、推理、语法的统一静态状态长期失败。

---

## 2. 为什么 Phase420（阶段420）找到来源写入，却没有行为增量预测

Phase420（阶段420）发现：

[
G_{\mathrm{source}}=1
]

但：

[
G_{\mathrm{prediction}}=0
]

一种可能解释是：

> 来源写入只是把内容输送到查询位置，但只有其中投影到共享工作空间或当前决策子空间的部分，才真正参与灵活决策。

当前测量的是完整来源写入：

[
e_{l,h,q\leftarrow r}
]

真正需要测试的可能是其 workspace-aligned（工作空间对齐）分量：

[
\boxed{
e^{\mathcal J}_{l,h,q\leftarrow r}
==================================

\operatorname{Proj}*{\mathcal J_l}
\left(
e*{l,h,q\leftarrow r}
\right)
}
]

以及非工作空间分量：

[
\boxed{
e^{\perp\mathcal J}_{l,h,q\leftarrow r}
=======================================

## e_{l,h,q\leftarrow r}

e^{\mathcal J}_{l,h,q\leftarrow r}
}
]

可能只有：

[
e^{\mathcal J}
]

能够增量预测需要灵活选择的行为，而完整写入范数受到大量自动或无关内容污染。

这应成为下一阶段最重要的新变量。

---

## 3. 为什么全部来源坐标都在晚层

Anthropic（安特ropic公司）发现 J-space（雅可比空间）具有明显的层级区间：大约在模型深度三分之一后开始形成，在接近输出前结束；最后几层转入直接驱动输出的“运动表征”状态。([变压器电路][2])

Phase420（阶段420）选择出的48个来源坐标全部位于晚层，可能意味着它们主要捕捉：

* 工作空间到终端接口的运输；
* 终端读出；
* 候选竞争；
* 输出准备。

而不是：

* 工作空间最初形成；
* 知识和关系首次绑定；
* 推理中间结果生成。

因此，当前全局图谱需要明确分成：

[
\boxed{
\text{工作空间形成带}
}
]

[
\boxed{
\text{工作空间广播带}
}
]

[
\boxed{
\text{终端运动带}
}
]

不能只追踪晚层最大行为相关点。

# 五、对当前 MLP（多层感知机）研究的直接启发

Anthropic（安特ropic公司）发现，在工作空间层段中，MLP（多层感知机）对 J-space（雅可比空间）对齐方向的放大远高于随机方向和单神经元输出方向，中间层最高约达到随机方向的十倍；最后几层又下降。([变压器电路][2])

这与当前项目的结果形成有价值的对照。

Phase420（阶段420）发现早中层存在普遍的注意力—MLP（多层感知机）反向补偿，但未发现行为预测增益。

下一步不应只比较：

[
\Delta h^{\mathrm{attn}}
]

和：

[
\Delta h^{\mathrm{MLP}}
]

的几何关系，而应比较 MLP（多层感知机）对不同方向族的局部增益。

对自然状态 (x) 和单位方向 (v)，定义局部 Jacobian（雅可比）增益：

[
\boxed{
G_{l}^{\mathrm{MLP}}
\left(
v;x
\right)
=======

\frac{
\left|
J_{\mathrm{MLP},l}(x)v
\right|*2
}{
\operatorname{Median}*{r\sim\mathrm{iso}}
\left|
J_{\mathrm{MLP},l}(x)r
\right|_2
+\varepsilon
}
}
]

比较以下方向族：

1. J-space（雅可比空间）候选方向；
2. 历史来源写入方向；
3. 当前来源写入方向；
4. SAE（稀疏自编码器）高工作空间对齐方向；
5. 普通 MLP（多层感知机）通道输出方向；
6. 随机旋转控制方向；
7. 各向同性随机方向。

如果只有工作空间对齐方向被跨案例、跨任务显著放大，才接近“共享广播格式”。

# 六、对注意力头研究的直接启发

Anthropic（安特ropic公司）没有只找“注意力大的头”，而是使用两个结构指标定义 broadcast head（广播头）。

## 1. 增益

对方向集合 (P)：

[
\boxed{
G_H(P)
======

\mathbb E_{v\in P}
\left[
|W_{OV}^{H}v|
\right]
}
]

并相对于随机方向归一化。

## 2. 标签保持

不仅要放大方向，还要保持概念身份。

可定义：

[
\boxed{
L_H(v_i)
========

\operatorname{MRR}
\left[
\cos
\left(
W_{OV}^{H}v_i,
v_j
\right)
\right]_{j}
}
]

如果一个头只是把所有工作空间方向混成同一个方向，它有增益却没有标签保持。

Anthropic（安特ropic公司）发现一小组注意力头对 J-space（雅可比空间）方向同时具有较高增益和标签保持，而对随机旋转方向、普通神经元方向和低对齐 SAE（稀疏自编码器）方向没有同样结构。([变压器电路][2])

这对 Phase420（阶段420）的启发是：

> 不能只寻找历史来源写入最大的头，应寻找既能运输工作空间方向，又能保持内容身份的头。

当前项目可定义：

[
\boxed{
B_H
===

\min
\left(
\operatorname{rankscore}
\left(
G_H
\right),
\operatorname{rankscore}
\left(
L_H
\right)
\right)
}
]

再从高 (B_H) 的头中寻找：

* 历史来源广播头；
* 当前证据广播头；
* 查询整合广播头。

当前项目的闭合门主要是：

* 行为；
* 预测；
  -物理；
* 因果；
* 中介。

模型能否在被询问时报告 (\mathcal W) 中的内容？

G_{\mathrm{report}}

[
G_{\mathrm{modulation}}

G_{\mathrm{reasoning}}

[
G_{\mathrm{flexibility}}

[
G_{\mathrm{selectivity}}

## 6. 广播结构门

是否存在比控制方向更广泛的读写连接？

[
G_{\mathrm{broadcast}}

新的工作空间候选门可以写为：

G_{\mathrm{workspace}}

G_{\mathrm{report}}

G_{\mathrm{flexibility}}

这比“某个方向在多个任务中激活”严格得多。

# 八、当前项目应该怎样具体引入 J-lens（雅可比透镜）

## 1. 先把它定位为观察器

必须明确：

[
\boxed{
\text{J-lens（雅可比透镜）}
\in
E^{\mathrm{observer}}
}
]

而不是：

[
E^{\mathrm{compute}}
]

或者：

[
E^{\mathrm{causal}}
]

它是基于平均一阶敏感度构造的观察坐标。

---

## 2. 为三个模型分别估计层级 Jacobian（雅可比）映射

[
\boxed{
J_{m,l}
=======

\mathbb E_{\mathcal D_m}
\left[
\frac{
\partial h_{m,L,t'}
}{
\partial h_{m,l,t}
}
\right]
}
]

训练语料应至少分成：

* 发现上下文；
* 校准上下文；
* 留出上下文。

必须检查：

* 样本数量收敛；
* 任务分布变化；
* 接口变化；
* 模型架构变化；
* 基础模型与指令模型变化。

---

## 3. 形成词元方向

对于词元 (v)：

[
\boxed{
j_{m,l,v}
=========

\left(
W_{U,m}J_{m,l}
\right)_v
}
]

然后检查当前激活对这些方向的投影。

---

## 4. 稀疏分解

对中间状态 (h_l)，求解：

[
\boxed{
\min_{\alpha\ge0}
\left|
h_l
---

\sum_v\alpha_vj_{l,v}
\right|_2^2
+
\lambda|\alpha|_0
}
]

实际可使用受限贪心或稀疏近似算法。

输出：

* 活跃词元概念；
* 稀疏占用数；
* 工作空间解释率；
* 面板外残差；
* 跨层概念轨迹。

---

## 5. 不能只使用单词元概念

Anthropic（安特ropic公司）也明确承认 J-lens（雅可比透镜）主要限于对应单词元的概念，很多重要概念是多词元短语。J-space（雅可比空间）的稀疏阈值 (k) 也具有一定任意性，过完备方向的分解并不唯一。([变压器电路][2])

当前项目应直接扩展到语义事件方向：

[
\boxed{
j_{l,E}
=======

\nabla_{h_l}
\log
P(E\mid x)
}
]

其中 (E) 可以是：

* “蜘蛛”概念；
* 某个关系；
* 某个推理中间状态；
* 某个语法特征；
* 某个停止事件。

这比单词元空间更适合当前项目的知识、推理和语法框架。

# 九、对 Phase421（阶段421）应如何调整

应保留该计划，但加入一个新的核心分解。

## 1. 完整来源写入

[
E_{\mathrm{source}}
]

## 2. 工作空间对齐来源写入

[
\boxed{
E_{\mathrm{source}}^{\mathcal J}
================================

\operatorname{Proj}*{\mathcal J_l}
E*{\mathrm{source}}
}
]

## 3. 非工作空间来源写入

[
\boxed{
E_{\mathrm{source}}^{\perp\mathcal J}
=====================================

## E_{\mathrm{source}}

E_{\mathrm{source}}^{\mathcal J}
}
]

然后比较三个预测模型：

[
B
]

[
B+E_{\mathrm{source}}
]

[
B+E_{\mathrm{source}}^{\mathcal J}
]

[
B+E_{\mathrm{source}}^{\perp\mathcal J}
]

若：

[
\boxed{
\Delta R^2
\left(
E_{\mathrm{source}}^{\mathcal J}
\right)

>

\Delta R^2
\left(
E_{\mathrm{source}}
\right)
}
]

而：

[
\boxed{

\left(
E_{\mathrm{source}}^{\perp\mathcal J}
\right)

}
]

才能说来源信息中有一个共享可用格式，更接近工作空间。

# 十、最值得设计的实验

## 实验一：自动任务与灵活任务配对

使用完全相同的知识内容，设计：

### 自动任务

直接续写：

> 巴黎是法国的首都。法国的首都是……

### 灵活任务

询问：

> 这个国家的货币是什么？

或者：

> 这个国家属于哪个大洲？

若同一“法国”状态只有在灵活任务中进入 J-space（雅可比空间），而自动续写绕过它，将高度复现 Anthropic（安特ropic公司）的选择性结果。

---

## 实验二：同一状态多下游复用

建立一个共享中间实体状态：

[
z_{\mathrm{France}}
]

然后分别要求：

* 首都；
* 货币；
* 语言；
* 大洲；
* 国旗颜色。

在同一层、同一位置，将：

[
z_{\mathrm{France}}
]

替换为：

[
z_{\mathrm{China}}
]

如果多个下游任务都同步改变，并且错误控制无效，就构成真正的灵活复用证据。

---

## 实验三：推理中间状态交换

例如：

> 会织网的动物有多少条腿？

中间状态是：

[
\text{蜘蛛}
]

将其替换为：

[
\text{蚂蚁}
]

测试后续答案是否从8变为6。

当前项目此前大量补丁失败，关键区别在于：

> 不再补整层残差或任意来源状态，而只交换经过功能资格的工作空间坐标。

---

## 实验四：语法是否绕过工作空间

使用：

* 熟练主谓一致；
* 新颖嵌套语法；
* 需要显式比较的语法判断；
* 需要报告语法规则的任务。

比较工作空间消融的影响。

预测是：

[
\boxed{
\text{熟练生成受影响较小}
}
]

[
\boxed{
\text{显式报告和新颖组合受影响较大}
}
]

如果成立，将解释当前语法图谱为何一直难以形成统一状态。

# 十一、Anthropic（安特ropic公司）研究的主要限制

## 1. J-lens（雅可比透镜）仍是线性化观察器

它使用平均一阶 Jacobian（雅可比矩阵）：

[
J_l
]

真实模型运行是非线性、条件相关的。

平均映射可能抹掉：

* 任务特异 Jacobian（雅可比）；
* 查询角色差异；
* 历史依赖；
* 接口依赖；
* 局部相变。

所以当前项目应同时测：

[
\boxed{
J_l^{\mathrm{global}}
}
]

和：

[
\boxed{
J_l^{\mathrm{conditional}}
\left(
f,q,i,h
\right)
}
]

---

## 2. J-space（雅可比空间）分解不唯一

方向过完备且非正交，稀疏组合可能有多个近似解。

不能把某次分解出的25个词元直接当成模型唯一内部思想。

---

## 3. 只覆盖可言说内容

自动处理、非语言几何状态、绑定、位置、语法和控制信息可能完全位于 J-space（雅可比空间）之外。

因此 J-space（雅可比空间）不是完整语言编码空间。

---

## 4. 不是完整的人类全局工作空间

Anthropic（安特ropic公司）明确指出，Transformer（变换器）没有人脑式的明显专门模块和循环回返；Claude（克劳德）的工作空间在一次前馈深度过程中演化，而不是依赖脑中的循环动力学。竞争性“点燃”也尚未得到清楚证明。([变压器电路][2])

---

## 5. 主要证据来自 Claude（克劳德）系列

论文虽然在不同 Claude（克劳德）规模上验证关键结果，并提供开放模型代码和演示，但当前项目仍必须在：

* Qwen3（通义千问3）；
* GLM4（智谱语言模型4）；
* DS7B（深度求索7B）；

独立复制。

小模型可能：

* 没有明显工作空间；
* 工作空间层段较窄；
* 使用更多自动化捷径；
* 表征更不稳定；
* 无法形成跨任务灵活复用。

因此，失败不能直接否定大型模型的工作空间结构。

# 十二、对当前项目最重要的理论升级

Anthropic（安特ropic公司）的研究最值得加入当前理论的，不是“模型具有意识”，而是以下结构：

[
\boxed{
\text{自动专门处理}
\rightleftarrows
\text{稀疏共享工作空间}
\rightarrow
\text{多个下游操作}
}
]

更新后的“语言是动态模式网络”可以写为：

[
\boxed{
\mathfrak L
===========

\left(
\mathcal G_{\mathrm{automatic}},
\mathcal W,
E_{\mathrm{write}},
E_{\mathrm{broadcast}},
\mathcal O,
\mathcal K
\right)
}
]

其中：

* (\mathcal G_{\mathrm{automatic}})：自动化专门子图；
* (\mathcal W)：稀疏共享工作空间；
* (E_{\mathrm{write}})：写入工作空间的路径；
* (E_{\mathrm{broadcast}})：从工作空间向外广播的路径；
* (\mathcal O)：下游知识、推理、语法和控制操作；
* (\mathcal K)：终端未来生成核。

一次具体运行：

[
\boxed{
\mathcal G_{\mathrm{active}}
============================

\mathcal G_{\mathrm{automatic}}(s,c)
\cup
\mathcal W(s,c)
\cup
E_{\mathrm{write}}(s,c)
\cup
E_{\mathrm{broadcast}}(s,c)
}
]

# 十三、对当前项目的直接结论

Anthropic（安特ropic公司）的研究对当前项目提供了四个关键答案。

## 1. 整体结构可能确实存在

但它可能不是一个统一的全局语言网络，而是：

[
\boxed{
\text{大量自动子图}
+
\text{少量共享工作空间}
}
]

---

## 2. 复用的核心可能不是同一神经元

而是：

[
\boxed{
\text{同一稀疏中间表征}
\rightarrow
\text{多个不同下游操作}
}
]

“法国”表征可以被不同任务读取，就是比“同一神经元多次激活”更强的复用定义。

---

## 3. 差异化来自是否进入工作空间

相同知识可能在：

* 自动续写中绕过工作空间；
* 显式报告中进入工作空间；
* 灵活推理中进入工作空间；
* 语法流畅生成中绕过工作空间。

因此，同一知识在不同任务中走不同物理路径是合理的。

---

## 4. 当前最应该寻找的不是统一历史头

而是：

[
\boxed{
\text{哪些来源写入进入了共享工作空间}
}
]

[
\boxed{
\text{哪些注意力头负责保持并广播这些内容}
}
]

[
\boxed{
\text{哪些多层感知机负责放大或重构工作空间方向}
}
]

[
\boxed{
\text{哪些自动任务完全绕过工作空间}
}
]

# 最终判断

Anthropic（安特ropic公司）的研究与当前项目高度互补。

当前项目已经较强地恢复了：

* 自然物理图谱；
* 来源—查询写入；
* 注意力—多层感知机—残差结构；
* 终端竞争区域。

Anthropic（安特ropic公司）提供的关键缺失对象是：

[
\boxed{
\text{一种稀疏、可言说、可广播、可灵活复用的共享中间格式}
}
]

它可能正是连接：

[
\text{来源运输}
]

与：

[
\text{灵活行为}
]

之间缺失的中尺度状态。

因此，当前项目最值得借鉴的不是直接接受“Claude（克劳德）具有全局工作空间”的结论，而是复制其证据链：

[
\boxed{
\text{发现候选表征}
\rightarrow
\text{报告}
\rightarrow
\text{主动调节}
\rightarrow
\text{推理中介}
\rightarrow
\text{多任务复用}
\rightarrow
\text{自动任务绕过}
\rightarrow
\text{广播结构}
\rightarrow
\text{因果闭合}
}
]

如果这一证据链能在 Qwen3（通义千问3）、GLM4（智谱语言模型4）和 DS7B（深度求索7B）中部分复现，它将成为目前最有希望把“语言是动态模式网络”从宏观工作假设推进为中尺度机制理论的路线。
