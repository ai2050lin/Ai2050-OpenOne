## 一、为什么当前方式很难突破

当前研究不是实验数量不足，而是缺少三个核心环节。

### 1. 没有固定的“结构搜索空间”

此前不断在方向、神经元、子空间、频谱、通道、纤维、轨迹、状态、响应等对象之间切换。

每个对象都能解释一部分现象，但没有一个统一算法回答：

> 在所有可能的结构中，哪一种能够以最小复杂度预测最多的未知结果？

因此，项目一直在积累观察，却没有系统压缩观察。

### 2. 实验主要在回答“这个解释有没有硬伤”

而不是回答：

> 哪个候选机制比其他机制更能预测下一批从未运行过的实验？

结果就是每个 Phase 都能提高证据纪律，却很少缩小核心机制的候选空间。

### 3. 当前统一公式过于宽泛

“条件化输出场闭合理论”可以很好地组织变量，但其中的状态、算子和条件函数都没有被唯一辨识。

因此它现在更适合作为：

[
\boxed{\text{实验测量框架}}
]

而不是已经具有预测能力的解释理论。

应当暂时冻结这个理论，不再继续增加模块和变量。下一次理论升级必须来自某个结构成功预测未知实验，而不是来自对已知结果的重新表述。

# 二、热力图路线是正确的，但不能画原始激活热力图

直接画神经元激活、注意力权重或者隐藏状态范数，极易看到伪轮廓：

* 层归一化会制造带状结构；
* 词元位置会制造对角线；
* 神经元重新排序会改变图案；
* 色标范围会制造热点；
* 模板差异会压过语义差异；
* 注意力权重不等于实际因果运输。

因此，应当画的不是“模型哪里亮了”，而是：

[
\boxed{\text{某个实验因素改变后，未来功能响应在哪里、何时、以何种形式改变}}
]

## 应建立六类响应热力图

| 图谱      | 横纵轴              | 单元格数值            | 要寻找的结构         |
| ------- | ---------------- | ---------------- | -------------- |
| 层—词元轨迹图 | 层 × 词元位置或生成步     | 候选余量、前缀余量、序列概率变化 | 阶段边界、形成轨迹、相变位置 |
| 源—接收运输图 | 源位置 × 接收位置       | 状态交换或路径阻断的因果效应   | 信息从哪里流向哪里      |
| 因素—组件图  | 内容、角色、关系、操作 × 组件 | 匹配反事实的差分效应       | 功能模块和复用模式      |
| 干预—读出图  | 干预类型 × 行为读出      | 七类或更多类型化响应       | 选择性、双重分离和冗余    |
| 协议交换图   | 供体协议 × 接收协议 × 事件 | 内容与格式的分别变化       | 内容—协议分离或交织     |
| 跨模型响应图  | 模型事件 × 模型事件      | 功能响应签名相似度        | 功能同构，而非坐标对齐    |

每张图都必须同时提供：

* 固定色标；
* 匹配随机对照；
* 标签置换零分布；
* 自助法置信区间；
* 原始顺序和聚类顺序；
* 观察图、梯度图和真实干预图的对照。

热力图负责“临摹轮廓”，但轮廓应从数值张量中由算法识别，不能只靠人眼看图。

# 三、真正需要开发的是“结构发现器”

建议把全部结果组织成一个多维响应张量：

[
\mathcal R[
\text{模型},
\text{世界},
\text{内容因素},
\text{协议},
\text{计算事件},
\text{干预},
\text{读出},
\text{生成时间}
].
]

其中每个元素表示：

[
\mathcal R
==========

## Q!\left(F_{\ge e}(\operatorname{do}_I(H_e))\right)

Q!\left(F_{\ge e}(H_e)\right).
]

然后不再直接问“哪个神经元编码苹果”，而是问：

> 能否找到一个尽可能小的结构 (Z_e)，预测整个未来响应张量？

定义：

[
Z_e=f_M(H_e),
]

[
\widehat{\mathcal R}
====================

g_M(Z_e,I,Q,c,\pi),
]

[
\widehat Z_{e+1}
================

T_M(Z_e,u_e).
]

对每种候选结构 (M)，比较：

[
\boxed{
J(M)
====

L_{\mathrm{未知样本}}
+
L_{\mathrm{未知干预}}
+
L_{\mathrm{多步轨迹}}
+
\lambda,DL(M)
}
]

其中 (DL(M)) 是结构的描述长度。

这意味着，真正的核心结构必须同时满足：

[
\boxed{
\text{核心结构}
===========

\text{压缩}
\cap
\text{预测}
\cap
\text{干预}
\cap
\text{组合}
\cap
\text{迁移}
}
]

只在热力图上漂亮、只在训练数据上重建得好、只能够读取答案，都不算核心结构。

## 结构发现算法应包括

1. **变化点检测**：寻找浅层、中层、深层和生成步之间的真实阶段边界。

2. **双向聚类**：同时聚类实验因素和组件，寻找重复出现的功能模块。

3. **张量分解**：判断响应是否可以分解为内容、角色、协议、操作和时间等少数因子。

4. **稀疏联盟搜索**：寻找能够预测联合删除和救援结果的最小组件组合。

5. **结构化预测瓶颈**：压缩隐藏状态，但要求压缩结果预测未来行为和干预响应。

6. **图结构和路径模体发现**：寻找反复出现的源—路由—接收—写入模式。

7. **主动实验选择**：自动寻找不同候选机制预测差异最大的干预，而不是平均分配实验。

无限制的深度网络只能作为预测上限，不能被当成解释模型，否则只是用另一个黑箱拟合原黑箱。

# 四、不要设立一个假说，而要建立“候选机制竞赛”

建议至少同时检验以下七种机制族。

| 候选机制     | 独特预测               | 决定性实验                   |
| -------- | ------------------ | ----------------------- |
| 固定方向编码   | 相同因素在不同上下文中沿稳定方向变化 | 冻结方向后预测未知上下文，并做方向性干预    |
| 层间旋转子空间  | 坐标变化，但低维系数和转移关系保持  | 只用前半层或部分任务学习映射，预测未知层和任务 |
| 稀疏因果联盟   | 少数组件联合构成功能单位       | 联合删除、最小性、正确救援、错误救援失败    |
| 内容—角色因子化 | 内容和当前角色可以分别交换      | 内容供体加接收者角色的交叉交换         |
| 内容—协议分离  | 内容能跨短答、句式、自然输出迁移   | 供体内容改变而接收者格式保持          |
| 条件化路由图   | 查询和角色决定特定源—接收路径    | 路径阻断、错误源重定向和接收者选择性测试    |
| 预测动力状态   | 小状态能预测多步未来和未知干预    | 多层、多词元滚动预测和反事实响应预测      |
| 操作代数     | 查询切换、否定、绑定交换能够组合   | 从单操作预测从未训练的双操作和顺序交换     |

还必须保留一个合法的零假说：

> 不存在跨协议、跨任务的紧凑全局状态；模型只存在局部、条件化、阶段特定的计算模体。

如果所有紧凑结构都失败，就应该接受这个结论，而不是继续换层、换提示、换对象寻找正结果。

# 五、第二条路线应升级为“正交测试矩阵”

大量测试只有经过正交设计才有意义，否则只是大规模重复。

测试矩阵至少包含以下轴：

* 内容：对象、类别、属性、关系、绑定；
* 角色：源、查询、接收者、干扰项、答案；
* 操作：直接读取、反向查询、交换、否定、比较、多跳；
* 表达：裸短答、固定句式、自然句式、同义改写、多语言；
* 输出：候选评分、前缀树、全词表生成、完整序列、结束词元；
* 事件：层、位置、注意力、MLP（多层感知机）、生成步、缓存；
* 干预：删除、交换、放大、路径阻断、随机同范数、错误绑定；
* 模型：Qwen3、GLM4、DeepSeek。

不必运行完整笛卡尔积。可以采用覆盖阵列，保证：

* 所有二阶因素组合都被覆盖；
* 内容×角色×协议等关键三阶组合全部覆盖；
* 每个核心判断都有匹配反事实组；
* 每个主要单元有足够样本估计置信区间。

材料应同时包含：

1. 可完全控制的关系世界；
2. 与其结构匹配的自然概念世界，例如苹果—水果—颜色—属性网络。

这样既保留因果控制，又避免人工任务相机替代真实语言对象。

# 六、如何实现“一次性否决”

每条路线在运行前必须形成一份“生死合同”：

1. 明确定义它声称存在的数学对象；
2. 明确适用范围；
3. 写出至少三个与其他路线不同的预测；
4. 指定最强零假说；
5. 冻结主要指标和阈值；
6. 冻结必要分区；
7. 冻结失败后的结论；
8. 规定重新开启路线的条件。

建议采用相对门槛，而不是任意绝对准确率。例如：

[
G_M
===

\frac{L_{\mathrm{null}}-L_M}
{L_{\mathrm{null}}-L_{\mathrm{oracle}}}.
]

初始可以规定：

* 未知未来响应预测达到可预测上限的 (80%)；
* 干预方向正确率的置信区间下界超过 (80%)；
* 跨协议效果至少保留同协议效果的 (70%)；
* 在每个必需分区分别通过，不能靠总体平均掩盖失败；
* 描述长度至少比查表式模型缩小一个数量级。

具体阈值可先用一次小规模校准确定，但必须在正式数据运行前冻结。

最终只有三种裁决：

* **全局幸存**：能跨对象、协议、操作和模型预测；
* **局部机制**：只在特定阶段或任务内成立；
* **范围内否决**：独特预测在封存测试中失败。

一旦否决，不允许通过换一层、换一个提示或删掉失败分区重新开启。只有提出数学上不同、并且提前预测旧失败原因的新机制，才能重新立项。

# 七、推荐的下一轮不是 Phase 1236，而是一场完整战役

建议直接启动“全局结构辨识战役”，分为六个批次。

## 批次一：冻结实验宇宙

固定：

* 同一批潜在世界；
* 因素轴；
* 三个模型；
* 提示、解码、评价合同；
* 候选机制；
* 生死门槛；
* 封存测试集。

按潜在世界划分发现集和封存集，不能随机拆分句子，否则同一事实会泄漏。

## 批次二：全域低成本扫描

一次记录：

* 所有层；
* 所有关键位置；
* 注意力与 MLP 增量；
* 候选余量；
* 完整序列概率；
* 实际生成轨迹；
* 缓存与结束行为。

这一阶段不做大规模通道扫描，只建立全局轮廓。

## 批次三：生成响应图谱

建立上述六类热力图，并用变化点、双向聚类、张量分解和路径聚类自动提取模体。

这一阶段允许反复探索，但只能使用发现集，所有结果都只能用于生成假说。

## 批次四：结构化模型竞赛

让固定方向、旋转子空间、稀疏联盟、因子绑定、条件路由和预测状态等模型同时拟合同一张响应张量。

每个候选必须输出：

* 未知样本预测；
* 未知干预预测；
* 最容易与其他候选区分的实验；
* 自己的失败条件。

## 批次五：主动选择决定性干预

选择候选机制分歧最大的几千组匹配干预，一次性运行。

原来建议的“短答—固定句式—自然句式双向交换”，在这里仍然有价值，但它只是检验“内容—协议分离”的一组决定性实验，不再承担整个下一阶段的方向。

## 批次六：封存验证与集体淘汰

在没有参与结构发现的：

* 新世界；
* 新改写；
* 新组合；
* 新干预；
* 跨模型折叠；

上运行一次。

最多允许一到两个机制进入后续因果闭环。其余机制正式归档，不再反复测试。

# 最终判断

你的方向是正确的。真正的问题不是实验不够多，而是此前的实验没有被组织成一次“全局结构辨识问题”。

最关键的转变应当是：

[
\boxed{
\text{从逐 Phase 解释已知现象}

\text{让多个结构模型竞争预测未知干预}

热力图负责发现轮廓，结构化算法负责压缩轮廓，主动实验负责放大候选之间的差异，封存测试负责一次性淘汰。

下一步不应再问“Phase 1236 测哪一个点”，而应直接建立：

[
\boxed{
\text{响应张量}
+
\text{多通道全局图谱}
+
\text{结构发现器}
+
\text{候选机制竞赛}
+
\text{一次性生死测试}
}
]

只有某种结构能在实验运行前预测未知样本、未知干预、未知组合和跨模型响应时，项目才算第一次真正接近语言编码机制的核心。
