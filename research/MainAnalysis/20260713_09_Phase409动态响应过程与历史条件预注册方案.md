# Phase409：动态响应过程与历史条件预注册方案

时间：2026-07-13 08:44 HDT（UTC-09:00）

## 一、启动依据

Phase408 的 `2,592` 个条件单元中有 `883` 个能够区分全部注册状态，但没有任何正式组在三接口、四表面和两词汇复本上同时稳定。发现跨模型候选为 `0/3`，所有下游门已关闭。

因此 Phase409 不继续扩大旧分母，也不进入神经元扫描。新阶段先解决三个测量问题：

1. 最终标签丢失了“先形成允许响应、随后又修改”的过程；
2. 历史内容没有进入 Phase408 分母；
3. 不同接口的独立性和完整格式没有被充分审计。

## 二、阶段目标

Phase409 的目标是验证：

```text
同一有限语义状态是否产生可复现的响应事件过程；
该过程是否在等义表面、独立词汇和历史放置下保持结构；
接口变化是否对应稳定的外部过程变换；
冲突历史是否按当前明确事实被覆盖。
```

本阶段不以物理路径、神经元定位或智能理论闭合为直接目标。

## 三、测量对象

### 1. 响应事件自动机

对生成前缀 `Y_1:t` 定义外部解析状态：

```text
q_t in {
  no_registered_response,
  format_incomplete,
  allowed_response,
  rejected_response,
  ambiguous_response,
  boundary_reached,
  model_stopped
}
```

同时保存正交的 `response_role`：`current`、`prior`、`current_and_prior`、
`other_registered` 或 `none`。这样 `h3` 的冲突分支不会被硬塞进普通正确/错误二分。

记录整个有限事件序列：

```text
E_m(s,c) = ((q_1,t_1), ..., (q_k,t_k))
```

重复停留状态压缩，只保留状态变化、句界和停止事件。`H48` 未观察到的事件继续登记为右删失。

### 2. 最终响应与过程分开

必须同时保存：

```text
final_semantic_class
first_registered_event
first_allowed_event
allowed_exit_event
boundary_event
stop_event
event_transition_sequence
```

禁止用最终标签覆盖中间状态，也禁止把事件过程直接称为模型内部状态机。

## 四、双规则引擎审计

每个案例必须由两套独立实现给出同一唯一答案：

1. `direct_solver`：按任务闭式规则直接计算；
2. `enumerative_solver`：穷举有限世界中全部状态，筛选满足事实和查询的唯一状态。

离线 A 门：

```text
direct_solver == enumerative_solver
除 h3 外，允许语义状态恰好一个；h3 必须恰好登记当前/先前两个冲突分支
允许、拒绝、歧义和未解析集合不相交
每个别名只属于一个接口内响应类
完整解析器正例、反例、歧义和边界测试全部通过
新提示与 Phase403-408 的模型提示哈希不重复
```

任一案例失败就从注册表中删除并重新生成；模型加载前冻结最终总分母。

## 五、三个语言族的接口修复

### 1. 知识绑定

保留三槽六排列，但将接口拆成：

```text
按实体顺序给值；
按指定值逐项给唯一拥有者；
对单个实体回答唯一值。
```

第三个接口的单次查询只有三种值，不能独立区分六种排列。因此其正式门禁单位是
`entity_0 + entity_1 + entity_2` 三个查询角色的联合响应签名；单角色多对一是合同性质，
不得记为模型状态塌缩。

正序和逆序排列可以保留为同一响应坐标集合上的变换测试，但不能同时充当两个独立内容词表复本。

### 2. 规则推理

优先保留 Phase408 中三个模型均出现局部可分单元的：

```text
holder_ordinal
holder_name
```

`reach_truth_vector` 继续作为高压接口，但不再要求它与前两个接口在同一个总门中全部通过。先独立判断每个接口是否可分，再判断通过接口之间的变换。

### 3. 语法约束

三个接口改为互不混淆的完整合同：

```text
be_form：只接受一个 be-form；
feature_pair：只接受 number + tense 两字段；
sentence_completion：必须接受 be-form + adjective + 句界。
```

`sentence_completion` 中单独出现 be-form 记为 `format_incomplete`，不能再作为允许响应。

## 六、历史条件

每个已通过接口内可分门的案例，加入五种历史条件：

```text
h0 current_only
h1 prior_equivalent_state
h2 prior_irrelevant_content
h3 prior_conflicting_state
h4 prior_conflict_then_current_explicit_override
```

预期关系在模型运行前冻结：

```text
h0、h1、h2 应保留相同最终语义；
h3 用于测量冲突竞争，不预设必然正确；
h4 必须以当前明确覆盖状态为准。
```

历史条件既记录最终标签，也记录事件过程是否出现额外冲突、修订和延迟。

## 七、分层门禁

### A 门：接口内状态可分

对每个模型、组、接口、表面、词汇复本和历史条件，独立检查：

```text
P_c : S -> R
```

是否完整单射。一个接口失败不能自动令同组其他接口失效。

### B 门：表面和词汇复现

只有同一接口映射在所有冻结表面和两个独立词汇复本中相同，才形成接口内候选。

### C 门：接口过程变换

仅对同时通过 B 门的接口对计算外部变换：

```text
T_i_to_j = P_j o inverse(P_i)
```

发现组冻结候选后，校准组只检验同一 `T`，不得重新选择置换。

### D 门：历史复现

候选必须在 `h0/h1/h2/h4` 保持预注册语义关系，并把 `h3` 的竞争过程单独报告。历史门不能与接口门相互补偿。

### E 门：三模型和行为留出

三个模型必须在全新校准和行为留出中通过同一语言族、同一接口对和同一历史关系，才允许另行注册物理定位协议。

## 八、样本与执行原则

最终数量由去重后的机器注册表计算，但必须满足：

```text
每语言族发现组不少于 12；
校准、行为留出和物理留出各不少于 6；
每组至少 4 个结构表面、2 个独立词汇复本；
重要正结果再用翻倍的全新组复验；
三个模型严格 qwen3 -> GLM4 -> DS7B 串行；
先资格、后发现，失败分割不消费后续留出。
```

采集器继续逐条断点落盘。生成循环应改为增量处理当前步 logits，避免同时保存 `generate()` 的整段 raw logits 和 processed scores 后再复制；先在密封资格集证明新旧实现逐 token 完全一致，才可替换正式执行器。

## 九、固定输出格式

建议新 schema 为 `83.x`，至少包含：

```text
protocol.json
query_contract_registry.jsonl
rule_engine_agreement.json
execution_qualification/{model}.json
collection/{split}/{model}.jsonl
event_process_cells.jsonl
interface_pair_maps.jsonl
history_relation_audit.jsonl
failure_axes.jsonl
stage_summary.json
evidence_nodes.jsonl
evidence_edges.jsonl
```

客户端只显示聚合事件过程、接口候选和门禁，不显示未通过物理验证的头、通道或神经元。

## 十、停止规则

满足任一条件停止模型扩展：

1. 双规则引擎不一致；
2. 解析别名跨接口产生未声明冲突；
3. 任一模型资格案例不重复或出现非有限值；
4. 发现集没有接口内稳定候选；
5. 校准不能复现冻结映射；
6. 三模型不能在同一接口对和历史关系上共同通过。

停止后只允许更新失败图谱和测量设计，不允许消费物理留出。
