一，路线分析
	当前AI和AGI（人脑）的区别：
		1，实时学习，人脑可以不停的接受新信息。
		2，准确理解，比如可以准确理解某个数学概念，或者其他人的想法。
		3，系统思维，把所有知识形成一个系统，然后基于系统分析各种问题。
		这三个看起来是不同的特性，本质都是源于深度神经网络和人脑的结构差距，产生的结果。一旦弥补了这个差距，AI就可以达到人类水平，甚至超过人类。

	要实现通用人工智能，现在有几个主要路线：
		1，类脑路线，要收集人脑大量数据，解决人脑神经信号极为复杂的难题。
		2，深度神经网络，人脑结构极为高效，接近物理学中的最优解，深度神经网络要达到人脑的结构效率，可能有一些难度。
		3，逆向工程，对深度神经网络进行逆向工程，分析为什么可以具备语言能力。

	为什么逆向工程路线是最有可行性的?
		1，语言是人脑的产物，有非常特殊的数学结构，ai生图，ai编程都是这个结构的体现。
		2，深度神经网络通过训练，部分提取了语言的数学结构，所以具备了语言能力。
		3，通过分析深度神经网络，通过消融等测试，尝试找到语言背后的数学原理。
	语言体现了人脑神经网络的很多特性，是理解智能的关键入口，如果能从编码角度理解语言原理，就可能完成智能理论，实现AGI了。

	既然这个路线可行，为什么各个AI公司进展有限，因为语言背后的原理可能和现有认知不一样，是一种非常特殊的结构。
	要破解这个结构，需要三个步骤：
		1，对深度神经网络进行充分研究，分析内部结构和运行机制是什么样的，积累大量数据。
		2，使用各种数学工具，比如统计、流形拓扑等多个维度进行分析，积累大量拼图。
		3，结合大量拼图、人脑研究、智能理论框架，三个方面的投影还原这个结构。
	随着这方面的研究越来越多，迟早会达到临界点，如果全球大量资源投入，两三年之内甚至更快都是有可能的。
	既然这个路线可行，为什么各个AI公司进展有限，因为语言背后的原理可能和现有认知不一样，是一种非常特殊的结构。要破解这个结构，需要逆向分析积累大量拼图碎片，加上人脑特性和智能理论框架，像拼图游戏一样还原这个结构，这应该是现在最可行的路线，随着这方面的研究越来越多，迟早会达到临界点，这个时间可能不会很远了。



二，语言分析
	语言的三个核心要素：
		网络知识
		逻辑推理
		语法规则

	多层次系统化的知识网络：
		包含大量概念，比如苹果，太阳，石头，水，头发。
		包括大量属性，比如苹果的颜色，味道。
		包含层级系统，比如苹果抽象为水果、食物、物体等等。
		各种特征和概念属性形成了一个多维度的知识网络，这个网络极为强大和高效，同时完美解决了维度灾难问题。

	逻辑推理，包含了各种不同的模式，完成各种任务：
		比如理解、分析、推理等逻辑能力
		比如翻译、诗歌、代码等任务
		比如但是、因此、总结、反思等功能
		
		模式中，包含了一套逻辑体系：
			进行基于某些条件进行分析推理，解决知识网络受限无穷组合问题，比如：
			深度思考能力，在最前面形成某种高级模式。
			语言方面：翻译能力，续写，优化等。
			算数，近义词，反义词
		模式中，包含了完整的语法：
			有名词，形容词，动词，代词，介词，副词等类型，每种都是不同的使用方式
			有大量不同的句式模板，可以灵活的根据情况替代使用
			多层次的系统结构，比如段落，字词等

	系统层面：
		神经网络系统包含了多个维度，可以完美融合运行，形成分层控制系统： 
			风格维度（聊天/论文/诗歌）
			逻辑维度（上下文逻辑推理）
			语句维度（语法结构）

		系统实现了不可能三角，极为强大，又极为高效：
			1，提取各种特征，比如文字图片声音味道等不同维度，没有维度灾难问题。
			2，知识网络，多层级多维度的知识系统，可以描述真实世界的各种事物。
			3，极为高效，任意信息和关联，都可以快速查找，快速修改。
			
		其他特性：
			在词嵌入中，国王 + 王后 - 男性 = 女性，说明词嵌入中有某种数学结构。
			名词，动词，形容词，副词，介词，代词是完全不同的机制，都在一个网络中，说明网络有某种兼容性。
			在大脑中，神经网络基于3d空间，形成一种极为高效的编码结构，在深度网络中，大量参数形成某种结构进行处理，根据风格，逻辑，语法得到下一个词。都说明背后有某种数学结构。
			大脑神经网络的编码，同时具备了复用能力，比如很多水果具有相同特征，但是每种又有单独特征，是如何通过编码实现这种高效结构的。

	关键猜想：
		大脑中的脉冲天然是最小传送量原理，所以系统极为高效，叠加路径即编码原理，就会导致及时学习和全局稳态同时实现，而核心可能是在脉冲神经网络的3d空间拓扑网络结构上。
		在深度神经网络中，所有神经元都参与运算，但是在不同风格，不同逻辑，不同语法下，每次都能生成一个合适的词，说明语言中某种东西具有全局唯一性，而且这种唯一性应该具有数学特性。
		大脑的寻路和编码机制，是一体的， 也就是说，神经信号传导到某个神经组织，和 语义语法编码 两者是一体的， 而 语义的关键，在于差异性，比如 苹果通过图像味道区别其他水果和食物，形成自己的编码， 翻译 通过 中文到英文，区别于其他的润色等模式，形成自己的编码。

	以上所有特性，都是一套编码机制的产物，现在的核心目标，就是分析这套编码机制，在神经元和参数级别是怎么形成的。



三，编码机制

	流程：
		1，对象进入上下文
		2，形成语义场
		3，选择内部路线
		4，恢复目标支持
		5，进入候选答案集合
		6，选择具体说法
		7，生成词元或短语
	核心特性：
		相对编码，
		语言关系，分成静态关系、条件激活关系、方向性关系
		复用和差分，复用和差分机制已经初步出现
		token identity（词元身份）和 functional role（功能角色）可以分解
		上下文门控已经被验证

	难点：
		相对编码，语言不是固定编码，所以没有固定轴，无法找到苹果，香蕉的精确神经组织。
		复用和差异，所有概念都由复用和差异构成，比如苹果的概念，既有水果复用部分，也有苹果本身的差异编码。翻译英语和翻译法文，同样复用了大量路由和模式。大脑使用极为高效的神经网络塑造了这种复用和差异的网络。
		内容和路由，内容和路由机制是否复用，还是并行机制，需要进一步分析。
		模式和预测，逻辑的本质，就是不同模式形成的优先级的组合，叠加模式的动态特性，可以进行预测。
		语言完美的融合和平衡了以上四者，形成了极为高效的编码机制，同时具备了功能和效率，模糊和精确的多种能力。
	
	对于逆向破解深度神经网络如何具备语言能力的研究，目前，所有建立语言理论的尝试都失败了，所有建立不变量和数学理论的尝试也失败了，目前看最可行的还是先系统的破解编码机制，先知道是什么样的，然后研究为什么是这样的。
	破解编码机制的核心是复用和差异化在神经元级别是什么样的，比如 不同水果是如何复用和差异化的，翻译英文和法文是如何复用和差异化的。
	从大脑角度看，这种复用和差异化，既保证了准确的区分各种概念的特征，又在保存和推理上极为高效，同时接近完美的平衡了两者，是理解神经网络的核心关键。  
	现在需要研究，在整个神经网络中，各种不同的概念和功能在神经元级别，如何实现复用和差异化。同时在整个神经网络层面，所有概念的分布是什么样的，所有功能的编码路径是什么样的，都是如何复用和差异化的。
	
	进度：
		语言编码：
			 语言编码 = 内容绑定 + 关系选择 + 操作变换 + 作用范围 + 候选竞争 + 范数调制 + 路径路由
		否定机制：
			1. 否定不是简单方向。
			2. 否定必须绑定作用范围。
			3. 否定在不同语言中有中层对齐迹象。
			4. 双重否定、局部否定、范围否定不能用线性向量解释。
			5. 操作符机制更像状态变换，而不是概念存储。
		绑定机制：
			1. baseline binding（基线绑定）真实存在。
			2. value prior（属性值先验）不能完全解释绑定。
			3. binding（绑定）在模型后半段形成明显增强。
			4. MLP（多层感知机）在很多模型中承担主要计算。
			5. target / competitor（目标项 / 竞争项）分解揭示了兼容性梯度。
			6. correct / incorrect（正确 / 错误）存在镜像对称。
			7. L1_category（类别方向）有时能打开关系空间。
			8. L2_obj_cat（对象-类别方向）有时提供额外选择性，但高度依赖数据和模型。
		中心点机制：
			1. 纯 category（类别）不是基本编码单元。
			2. global centroid（全局中心方向）太粗。
			3. L1_category（类别方向）有时有效，但多数是粗粒度关系空间激活器。
			4. 原始 L2_obj_cat（对象-类别方向）有严重数据泄漏风险。
			5. L2_crossfit（交叉拟合对象-类别方向）在部分模型层中确实有额外信息。
			6. L3_pair（单样本方向）太细，容易造成离流形扰动。
			7. damage_ratio（分布损伤比）是判断方向是否干净的关键指标。
		范数机制
			置信度、强度、读出可见性	
		位置路由机制

	关键猜想：
		语言的编码机制可能是相对编码，不是固定编码，含义不是固定语义轴，而且相对位置构成的整个网络结构。
		深度神经网络的每个layer是全计算的，不同的词嵌入会激活不同的参数，放大或者缩小某些神经元参数，进行路径和预测的现在。
		目前一直都是统计算法，而有些较小差异的编码机制，可能统计上是一样的，统计方法像是隔靴挠痒，需要新的算法可以直接破解具体编码机制

	关键问题：
		1，脑是相对编码，不是固定编码，而且有大量抽象和复用，关键的核心是，大脑如何决定哪些概念和功能之间，如何复用，如何差异化，实现功能和效率的完美平衡点。
			通过极为高效的可塑性机制，在大量的使用中，经过外部世界的反馈，自动收敛为平衡。
		2，从相对编码角度分析，大脑是怎么形成世界整体认知的。
			根据大脑的高效的可塑性机制，自动进行关联和形成层次化结构，形成世界整体认知
		3，从词嵌入到layer，类似钥匙和门控机制，是怎么实现风格逻辑语法三个层级的融合生成的。
			关键问题，结合了层次化优先级，以及叠加原理， 形成了融合生成能力
		4，逻辑的本质，是不同的模式的组合和优先级，那么编码机制是什么样的，比如肯定和否定，翻译英语和翻译法语 根据当前研究进展，分析以上问题的答案是什么。
			关键问题，不同模式的本质，也是复用和差异化，形成某些模式进行预测。
		5，脉冲神经网络如何形成注意力机制，这是破解大脑智能的核心关键入口。
			注意力机制的核心是建立网络连接和连接权重，  脉冲神经网络是如何形成这种网络连接和权重关系的，这应该是破解脉冲神经网络的核心关键，请尝试进行分析

	神经网络同时具备了相对编码，复用差异，路由内容三种特性，如何破解这三者，建立形式化框架，是破解语言能力的关键



四，数学理论：
	第一性原理：
		不变量
			未确定
		公式
			Conditional Relational Recoding Formula（条件化关系因子图公式）
			Δh(o,r,v)
			=
			I(o)
			+ R(r)
			+ V(v)
			+ G(o,r)
			+ H(o,r,v)
			+ Cmp(o,r,v)
			+ N(o,r,v)
			+ P(o,r,v)
			+ ε

			I(identity，身份)				这个词本身是什么，例如 open、light、apple
			R(role，角色)					它在句子中充当什么，例如名词、动词、形容词、主语、宾语
			F(frame，句框)					它所在的句型环境
			C(construction，构式)			句式/语法框架、整体句法结构表征
			O(operator，操作符)				not、never、must、can 等逻辑或情态操作
			S(scope，作用范围)				操作符作用到哪里
			N(norm，范数)					向量模长：表征该成分的信号强度
			P(position，位置)

			Δh_l(o,r,v | context, rule, feedback)		第 l 层中，对象 o、关系 r、属性值 v 的编码，由多个可复用基础结构 φ_k 动态组合而成；
			=
			Σ_k w_{l,k}(context, rule, feedback)		每个结构的调用强度 w_k 由上下文、规则、反馈决定；
			· φ_{l,k}(I,R,V,G,H,P)
			+
			N_l											表示范数/增益调制；
			+
			ε_l											表示还没建模的结构和噪声。
