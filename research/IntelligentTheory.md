

智能理论






研发路线：
    DNN语言结构分析 -> 脑编码机制 -> 智能的数学统一理论 -> 即使学习模型测试



一，路线分析
	当前AI和AGI（人脑）的区别：
		1，实时学习，人脑可以不停的接受新信息。
		2，准确理解，比如可以准确理解某个数学概念，或者其他人的想法。
		3，系统思维，把所有知识形成一个系统，然后基于系统分析各种问题。
		这三个看起来是不同的特性，本质都是源于深度神经网络和人脑的结构差距，产生的结果。一旦弥补了这个差距，AI就可以达到人类水平，甚至超过人类。

	要实现通用人工智能，现在有几个主要路线：
		1，类脑路线，要收集人脑大量数据，解决人脑神经信号极为复杂的难题。
		2，深度神经网络，人脑结构极为高效，接近物理学中的最优解，深度神经网络要达到人脑的结构效率，可能有一些难度。
		3，逆向工程，对深度神经网络进行逆向工程，分析为什么可以具备语言能力。

	为什么逆向工程路线是最有可行性的?
		1，语言是人脑的产物，有非常特殊的数学结构，ai生图，ai编程都是这个结构的体现。
		2，深度神经网络通过训练，部分提取了语言的数学结构，所以具备了语言能力。
		3，通过分析深度神经网络，通过消融等测试，尝试找到语言背后的数学原理。
	语言体现了人脑神经网络的很多特性，是理解智能的关键入口，如果能从编码角度理解语言原理，就可能完成智能理论，实现AGI了。

	既然这个路线可行，为什么各个AI公司进展有限，因为语言背后的原理可能和现有认知不一样，是一种非常特殊的结构。
	要破解这个结构，需要三个步骤：
		1，对深度神经网络进行充分研究，分析内部结构和运行机制是什么样的，积累大量数据。
		2，使用各种数学工具，比如统计、流形拓扑等多个维度进行分析，积累大量拼图。
		3，结合大量拼图、人脑研究、智能理论框架，三个方面的投影还原这个结构。
	随着这方面的研究越来越多，迟早会达到临界点，如果全球大量资源投入，两三年之内甚至更快都是有可能的。
	既然这个路线可行，为什么各个AI公司进展有限，因为语言背后的原理可能和现有认知不一样，是一种非常特殊的结构。要破解这个结构，需要逆向分析积累大量拼图碎片，加上人脑特性和智能理论框架，像拼图游戏一样还原这个结构，这应该是现在最可行的路线，随着这方面的研究越来越多，迟早会达到临界点，这个时间可能不会很远了。



二，语言特性分析
	语言的三个核心要素：
		网络知识
		逻辑推理
		语法规则

	多层次系统化的知识网络：
		包含大量概念，比如苹果，太阳，石头，水，头发。
		包括大量属性，比如苹果的颜色，味道。
		包含层级系统，比如苹果抽象为水果、食物、物体等等。
		各种特征和概念属性形成了一个多维度的知识网络，这个网络极为强大和高效，同时完美解决了维度灾难问题。

	逻辑推理，包含了各种不同的模式，完成各种任务：
		比如理解、分析、推理等逻辑能力
		比如翻译、诗歌、代码等任务
		比如但是、因此、总结、反思等功能
		
		模式中，包含了一套逻辑体系：
			进行基于某些条件进行分析推理，解决知识网络受限无穷组合问题，比如：
			深度思考能力，在最前面形成某种高级模式。
			语言方面：翻译能力，续写，优化等。
			算数，近义词，反义词
		模式中，包含了完整的语法：
			有名词，形容词，动词，代词，介词，副词等类型，每种都是不同的使用方式
			有大量不同的句式模板，可以灵活的根据情况替代使用
			多层次的系统结构，比如段落，字词等

	系统层面：
		神经网络系统包含了多个维度，可以完美融合运行，形成分层控制系统： 
			风格维度（聊天/论文/诗歌）
			逻辑维度（上下文逻辑推理）
			语句维度（语法结构）

		系统实现了不可能三角，极为强大，又极为高效：
			1，提取各种特征，比如文字图片声音味道等不同维度，没有维度灾难问题。
			2，知识网络，多层级多维度的知识系统，可以描述真实世界的各种事物。
			3，极为高效，任意信息和关联，都可以快速查找，快速修改。
			
		其他特性：
			在词嵌入中，国王 + 王后 - 男性 = 女性，说明词嵌入中有某种数学结构。
			名词，动词，形容词，副词，介词，代词是完全不同的机制，都在一个网络中，说明网络有某种兼容性。
			在大脑中，神经网络基于3d空间，形成一种极为高效的编码结构，在深度网络中，大量参数形成某种结构进行处理，根据风格，逻辑，语法得到下一个词。都说明背后有某种数学结构。
			大脑神经网络的编码，同时具备了复用能力，比如很多水果具有相同特征，但是每种又有单独特征，是如何通过编码实现这种高效结构的。

	关键猜想：
		大脑中的脉冲天然是最小传送量原理，所以系统极为高效，叠加路径即编码原理，就会导致及时学习和全局稳态同时实现，而核心可能是在脉冲神经网络的3d空间拓扑网络结构上。
		在深度神经网络中，所有神经元都参与运算，但是在不同风格，不同逻辑，不同语法下，每次都能生成一个合适的词，说明语言中某种东西具有全局唯一性，而且这种唯一性应该具有数学特性。
		大脑的寻路和编码机制，是一体的， 也就是说，神经信号传导到某个神经组织，和 语义语法编码 两者是一体的， 而 语义的关键，在于差异性，比如 苹果通过图像味道区别其他水果和食物，形成自己的编码， 翻译 通过 中文到英文，区别于其他的润色等模式，形成自己的编码。

	以上所有特性，都是一套编码机制的产物，现在的核心目标，就是分析这套编码机制，在神经元和参数级别是怎么形成的。



三，语言编码机制

		当前最重要的总判断：
			语言编码不是一个固定语义轴系统，也不是简单的 token 向量存储系统，而是“相对状态 + 条件化变换 + 候选竞争 + 读出门控”的动态系统。
			一个词、对象、属性或规则是否起作用，不能只看它在某层有没有方向投影，还要看：
				1，它处在什么位置；
				2，它被什么上下文激活；
				3，它经过哪些层的 attention / MLP update；
				4，它是否进入候选集合；
				5，它是否改变 target / competitor 的相对排序；
				6，它是否能在生成层面改变输出。

		完整流程：
			1，对象进入上下文，形成对象身份 I 和位置 P。
			2，句式、角色、规则、关系共同形成当前语义场。
			3，模型选择内部路线：检索路线、属性路线、关系路线、否定路线、格式路线、生成策略路线。
			4，关系或规则把对象重编码为状态，例如 object-category、object-relation-value、category-relation-value。
			5，状态进入候选集合，候选之间形成 common activation 和 candidate-specific ranking。
			6，范数、RMSNorm、final norm weight、格式维度、策略门共同决定读出可见性。
			7，输出层在候选族中选择 winner，生成词元或短语。

		核心编码模块：
			1，相对编码：
				概念不是固定坐标点，而是在任务、模板、位置、候选集合中的相对差异。
				“苹果”不是一根固定轴，而是在水果、食物、颜色、味道、对象身份等关系中的组合状态。
			2，身份 I 与角色 R：
				token identity 和 functional role 可以被分解。早期 Phase 301-303 的 R/F 分解有伪影，后来通过 construction、norm、position 修正。
			3，构式 C 与格式 F：
				句式/格式不是噪声。它既能污染语义方向，也能作为路径控制信号。GLM4 中格式污染尤其明显，DS7B 较低。
			4，操作符 O 与作用域 S：
				否定不是形式逻辑中的“取反函数”，更像语义极性偏移和状态变换。not、never、no、n't 有层次化关系；作用域会改变方向效果。
			5，关系 Rl 与属性/值 V：
				属性、类别、功能、连续属性都不是单一方向。连续属性表现为静态知识锚定 + 规则上下文调制 + 候选词读出。
			6，绑定 B：
				对象-属性、对象-类别、对象-关系-值绑定真实存在，但不是 embedding 预存，主要由 transformer 层计算产生。
			7，候选竞争 Cmp：
				模型不是直接生成“正确答案”，而是在候选族内重排 target、old top-wrong、generic、echo、format token 等竞争项。
			8，范数与读出门 N/G：
				范数不是单纯置信度。它会影响读出可见性、final norm gate、格式门、候选压缩和符号翻转。
			9，路径路由 Path：
				同一语义任务会按不同 prompt 走不同路线。projection peak 不一定是 causal node，路径需要用因果等级图谱表示。
			10，条件化状态变换 T：
				最新 Phase 594 说明，candidate-specific ranking 更像 layer-to-layer conditional transformation 的产物，而不是一个可单点移植的 residual 向量。

		已经确认的关键拼图：
			1，语言编码 = 内容绑定 + 关系选择 + 操作变换 + 作用范围 + 候选竞争 + 范数调制 + 路径路由 + 条件化状态变换。
			2，否定方向具有因果效应，但不是逻辑否定；双重否定、弱否定、局部否定高度依赖词对和模型。
			3，关系网络在中间层保留，但属性/功能关系的“上下文激活”早期被高估，平行模板后只有 modest 效应。
			4，binding 在后半段增强，embedding 对 binding_item 的贡献接近 0，transformer 层是主要来源。
			5，MLP 经常承担 binding、属性、候选排序、值路径的主要计算，但 attention 负责检索、路由、格式和部分边界写入。
			6，类别边界不是单层写入，而是跨层累积；存在支持层、反对层、末层释放、共享语义抑制和读出接口。
			7，正交成分不一定是“前体”，很多时候是刹车/抑制/调节项；移除它会释放边界。
			8，final RMSNorm 和 norm weight 可以造成 margin 符号翻转；少量维度可能主导格式门。
			9，规则检索电路存在，但检索不自动等于推理；两跳组合的瓶颈主要是错误中间类别或关系使用不稳定。
			10，Phase 593 证明 projection node 不能直接升级为 causal patch node；Phase 594 进一步指向 component update 和条件化变换。

		最新机制图：
			对象 o，关系 r，候选值 v 进入上下文后，模型先形成多个位置状态：
				query_object / query_relation / query_category / rule_value / rule_relation / prompt_last。
			这些位置不是等价的：
				query_relation 更像关系路径节点；
				rule_value 更像值排序生成节点；
				prompt_last 更像汇聚和读出节点。
			以 DS7B 最新结果为例：
				rule_value L26 是最强 transition point；
				rule_value L26 的 MLP update 几乎复现 outgoing specific_margin；
				query_relation L19 的 MLP update 是 relation-path ranking signal 候选；
				prompt_last L26 有强 common activation，但不是最干净的生成源。

		当前最严格的限制：
			1，很多结果仍是 projection-level evidence，不等于因果修复。
			2，单点 residual patch 往往失败，说明状态不是可简单加法移植对象。
			3，候选 embedding 不正交，common/specific 分解会泄漏。
			4，样本簇差异很大，均值强不代表所有样本都正向。
			5，三模型编码策略差异极大，不能把 Qwen3、GLM4、DS7B 的某个现象轻易提升为通用理论。



四，智能理论
		智能定义：
			智能是一个系统在持续输入中形成相对状态网络，并能根据目标、上下文和反馈，对世界对象、关系、规则、候选行动进行重编码、选择和修正的能力。
			更通俗地说，智能不是“存了多少知识”，而是能否把当前问题放进正确的关系网络里，找到可执行路径，并在竞争答案中选出最合适的一个。

		智能系统的构成：
			1，特征提取层：
				从文字、图像、声音、动作中提取对象和差异。
			2，相对编码层：
				把对象放进关系网络，而不是给每个对象固定标签。
			3，绑定层：
				把对象、属性、类别、关系、值绑定成可操作状态。
			4，路径路由层：
				根据任务选择检索、推理、翻译、解释、生成、规划等路线。
			5，条件化变换层：
				在每一步根据上下文改变状态更新规则。
			6，候选竞争层：
				生成多个可能答案或行动，并比较 target / competitor。
			7，反馈学习层：
				根据错误和新信息修改路径权重、候选优先级、关系强度。

		从当前模型看，现代 DNN 已经具备：
			1，大规模相对编码；
			2，局部绑定；
			3，关系检索；
			4，候选竞争；
			5，一定程度的条件化变换；
			6，复杂的范数/读出门控。

		但还缺少：
			1，稳定实时学习；
			2，可控的中间状态传递；
			3，可验证的多跳组合闭环；
			4，抗格式/echo/policy gate 干扰的语义读出；
			5，真正可编辑、可因果定位的关系图谱。

		AGI 的关键突破方向：
			不是简单扩大模型，而是找到“相对编码 + 条件化变换 + 可塑性更新”的基本结构。
			如果能把当前 DNN 中隐含的状态变换图谱变成可读、可修、可学习的结构，就可能接近人脑的实时学习和系统思维。

		智能水平的初步判据：
			1，能否形成稳定关系网络；
			2，能否在新规则下重编码旧知识；
			3，能否把一步检索结果变成下一步查询状态；
			4，能否在候选竞争中稳定压过错误竞争项；
			5，能否在不破坏旧知识的情况下局部学习新关系；
			6，能否跨模板、跨语言、跨模态保持同一关系结构；
			7，能否解释和修复自己的错误路径。


五，数学体系：
		第一性原理：
			目前最接近第一性原理的表述是：
				智能系统不是存储孤立概念，而是在上下文中把对象、关系、规则、候选、目标函数重编码为可读出的相对状态。
				语言能力来自大量可复用基础结构的条件化组合，而不是单一全局语义坐标。

		基本状态公式：
			第 l 层、位置 p 的隐藏状态可以写为：

				h_l(p) =
					I_l(p)
					+ R_l(p)
					+ F_l(p)
					+ C_l(p)
					+ O_l(p)
					+ S_l(p)
					+ K_l(p)
					+ B_l(p)
					+ Q_l(p)
					+ N_l(p)
					+ ε_l(p)

			含义：
				I(identity)：对象或 token 身份。
				R(role)：词在句中的功能角色。
				F(frame)：局部句框和表面格式。
				C(construction)：整体构式/语法结构。
				O(operator)：not、never、must、should 等操作符。
				S(scope)：操作符作用范围。
				K(knowledge anchor)：对象的静态知识锚定，例如 desert-hot、ice-cold。
				B(binding)：对象-属性、对象-类别、对象-关系-值绑定。
				Q(candidate competition)：候选集合中的 target/competitor/common/specific 排序状态。
				N(norm/gain)：范数、RMSNorm、final norm weight、读出增益。
				ε：未建模项、噪声、模板特异项、离流形扰动。

		条件化关系重编码公式：
			对于对象 o、关系 r、候选值 v：

				Δh_l(o,r,v | x) =
					I_l(o)
					+ R_l(r)
					+ V_l(v)
					+ G_l(o,r)
					+ H_l(o,r,v)
					+ Cmp_l(o,r,v)
					+ N_l(o,r,v)
					+ Path_l(x)
					+ ε_l

			其中：
				G(o,r)：对象和关系形成的门控项。
				H(o,r,v)：三元绑定或高阶交互项。
				Cmp(o,r,v)：候选竞争项，决定 correct value 是否超过 old top-wrong。
				Path(x)：由上下文 x 决定的路径项，包括 prompt、表格、规则、位置。

		层间变换公式：
			最新 Phase 594 后，需要把静态状态公式升级为变换公式：

				h_{l+1}(p) = h_l(p)
					+ A_l(h_l, x, p)
					+ M_l(h_l, x, p)

				ΔQ_{l→l+1}(p) =
					Proj_candidate(h_{l+1}^{repair}(p) - h_{l+1}^{base}(p))
					-
					Proj_candidate(h_l^{repair}(p) - h_l^{base}(p))

			其中：
				A_l 是 attention update；
				M_l 是 MLP update；
				ΔQ 是候选排序在层间增强或减弱的量。

			关键解释：
				如果 ΔQ 主要来自 M_l，说明 ranking 是 MLP 条件化更新生成的；
				如果 ΔQ 主要来自 A_l，说明 ranking 由注意力检索/路由生成；
				如果 incoming 已经很强，说明该位置是 carry 或汇聚点；
				如果 outgoing 强但 patch 无效，说明它可能只是 projection node，不是可移植因果节点。

		候选竞争公式：
			对候选集合 V={v1...vn}：

				score_i = e(v_i) · h
				common = mean_i(score_i)
				specific_i = score_i - common
				margin_correct = specific_correct - specific_old_wrong

			正确输出需要：
				1，候选族被整体激活，即 common 足够高；
				2，correct-specific 超过 old-top-wrong-specific；
				3，格式/echo/generic/policy gate 不抢占输出；
				4，final norm/readout 不发生符号翻转。

		类别边界公式：
			类别边界不是单一方向，而是：

				Boundary_c =
					Σ_l Write_l(c)
					- Σ_l Brake_l(c)
					+ Release_final(c)
					+ Readout_gain(c)

			含义：
				Write：投影写入、MLP/attention 支持项；
				Brake：共享语义抑制、反对层、正交调节项；
				Release_final：末层释放或刹车解除；
				Readout_gain：RMSNorm、final norm weight、W_U 接口。

		连续属性公式：
			连续属性不是纯等级轴：

				logit(candidate | object, context)
					= W_U(candidate) · [K(object) + M(context) + T(object, context)]

			其中：
				K(object)：静态知识锚定；
				M(context)：规则上下文调制；
				T(object, context)：层间变换；
				W_U(candidate)：候选词读出。

			已知修正：
				规则可以改写几何，但存在非对称反转；
				候选词语义特异性会强烈影响测量；
				非对称反转不能简单由 W_U 范数解释，根源更可能在内部对象锚定深度。

		因果证据等级：
			Level 1：相关/距离/聚类证据。
			Level 2：projection node，能读出目标方向或候选排序。
			Level 3：transition node，层间 update 产生或增强目标信号。
			Level 4：component causal node，attention/MLP/head/channel patch 改变 margin。
			Level 5：hidden causal repair node，最小隐藏状态修补能改变 winner。
			Level 6：generation closure，真实生成输出稳定改变，并通过随机/范数/模板对照。

			当前最新结论：
				Phase 592 找到的是 Level 2 projection nodes；
				Phase 593 未能升级为 Level 5；
				Phase 594 把方向推进到 Level 3 transition evidence；
				下一步必须寻找 Level 4 component causal node。





六，研究阶段历史记录
		阶段一：基础方向分解与操作符机制（Phase 301-312）
			核心任务：
				分解 identity、role、frame、construction、operator、scope、norm、position。
			重要进展：
				1，早期 R/F 分解发现伪影，后来改为 full factorial 与 construction/position/norm 分解。
				2，DS7B 出现高范数共享主方向 + 微小差分读取，Qwen3/GLM4 更接近正交子空间。
				3，否定 O(not) 有稳定因果效应，但与反义词替换不同。
				4，O/R/C/S 子空间不能只看 cosine，必须看输出映射和单位因果效力。
			核心成果：
				提出两类编码架构：正交子空间编码 vs 共享主方向 + 差分读取。

		阶段二：关系网络、上下文激活与否定修正（Phase 313-321）
			核心任务：
				分析 W_U 读出、关系保持、属性/功能/否定关系、随机基线和模板控制。
			重要进展：
				1，W_U 本身不解释所有差分放大，中间层存在复杂放大。
				2，模型保留人类语义关系网络，但属性/功能关系需要上下文或模板支持。
				3，Phase 317 修正早期过强结论：属性上下文激活只有 modest 效应。
				4，否定是语义极性偏移，不是严格逻辑取反。
			核心成果：
				语言关系不是静态表，而是条件激活的相对关系网络，但条件门控弱于最初预期。

		阶段三：绑定机制、层归因与 MLP 主导路径（Phase 322-365）
			核心任务：
				研究对象-属性绑定、slot、temperature、interaction、层归因、attention vs MLP。
			重要进展：
				1，binding 由 transformer 层形成，embedding 几乎不贡献。
				2，层归因给出数学精确分解，输出替换法被证明过粗。
				3，MLP 在多个模型中承担 binding 的主要计算，但 attention 也参与路由和中介。
				4，interaction term、value prior、context-gated binding 被反复校正。
			核心成果：
				绑定不是单点存储，而是跨层计算产生的对象-关系-值兼容性梯度。

		阶段四：范数、类别中心、连续属性与规则调制（Phase 366-414）
			核心任务：
				分析范数掩蔽、RMSNorm、类别中心、连续属性、规则强度、候选词读出。
			重要进展：
				1，范数可以掩蔽方向，RMSNorm 会重映射信息。
				2，纯 category centroid 太粗，cross-fit 和 damage_ratio 成为判断方向干净程度的关键。
				3，连续属性表现为静态知识锚定 + 规则调制 + 候选词读出。
				4，规则可以改写几何，但存在非对称反转。
				5，W_U 范数不能解释非对称反转，根源更可能在内部锚定。
			核心成果：
				提出“对象知识锚定 × 上下文调制 × 候选词读出”的连续属性框架。

		阶段五：自然运输、关系槽位、类别边界和读出接口（Phase 415-499）
			核心任务：
				研究虚构对象、自然运输方向、属性中介、类别边界、shared/private 通道、RMSNorm 读出接口。
			重要进展：
				1，属性与类别之间有中介关系，但不是全部由类别解释。
				2，关系槽位会私有化绑定态，对象解锁门控影响 shared/private 分离。
				3，类别边界是跨层累积，不是单层写入。
				4，存在支持层、反对层、共享语义抑制、末层释放。
				5，final RMSNorm 和 gain 维度可导致符号翻转和候选重排。
			核心成果：
				类别边界公式被修正为：投影写入 - 正交抑制 + 末层读出。

		阶段六：正交语义场、轨迹价值与生成策略门（Phase 500-567）
			核心任务：
				统一 GLM5/GPT5 路线，研究 orthogonal semantic field、trajectory、path value、generation closure、paraphrase gate、scaffold route。
			重要进展：
				1，语义支持可以存在于读出正交空间，最终通过接口转移到可读出方向。
				2，trajectory/path value 可以影响生成，但受策略门、格式、脚手架强烈控制。
				3，label-forbidden paraphrase 暴露出语义恢复与输出策略分离。
				4，route restore、wrong donor、object binding、prototype generation 显示生成不是简单语义读出。
			核心成果：
				提出“语义状态”和“生成策略门”分离：知道答案不等于能按要求生成答案。

		阶段七：Norm gate、路径瓶颈与格式/echo 机制（Phase 568-574）
			核心任务：
				追踪 pre-layer source、final norm gate、norm weight 维度、path bottleneck、format gate、echo suppression。
			重要进展：
				1，关键语义状态在 L20-L22 左右形成，L28 更像读出接口。
				2，final norm weight 而非 RMS 归一化本身，可造成 margin 符号翻转。
				3，少量 norm weight 维度可主导格式门。
				4，echo suppression 只能减少 echo，不必然提升 clean semantic output。
			核心成果：
				读出瓶颈被拆成：语义状态、格式门、echo 路径、norm gate、clean output policy。

		阶段八：闭合语义微世界与检索-推理闭包（Phase 575-583）
			核心任务：
				构造闭合微世界，隔离 object-category、object-relation-value、规则检索、两跳组合、yes/no 极性读出。
			重要进展：
				1，对象和类别状态可线性解码，但对象/类别子空间不正交，简单类别交换没有输出效果。
				2，三模型存在规则检索注意力头，category-copy 头更具因果性。
				3，单步检索可达高准确，但组合推理存在中间类别错误、关系使用不稳、yes-bias 等问题。
				4，Phase 581 修正 Phase 580 的 prompt bug，组合推理不是 0%，但仍有 gap。
				5，GLM4/DS7B 在参数化 yes/no 负例上有强 yes-bias。
			核心成果：
				明确检索不等于推理；组合瓶颈主要在中间状态选择和极性读出，而不是简单缺少检索。

		阶段九：状态门修复、值候选竞争与条件化变换图谱（Phase 584-594）
			核心任务：
				研究固定网络中是否能通过 state gate、hidden patch、distributed relation-filter、value winner competition、ranking atlas 修复错误。
			重要进展：
				1，polarity-format gate 出现 hidden causal repair，但 relation-filter/value gate 修复困难。
				2，value winner 竞争不是“有正确候选即可”，关键是 correct-specific 是否压过 old top-wrong。
				3，Phase 592 建立 relation-specific ranking factor atlas，但只能标为 projection evidence。
				4，Phase 593 证明 atlas projection node 不能直接通过单点 residual patch 修复 winner。
				5，Phase 594 发现 candidate-specific ranking 可在 layer-to-layer transition 中增强，DS7B rule_value L26 的 MLP update 是当前最强候选生成点。
			核心成果：
				最新理论从“静态方向 patch”升级为“条件化状态变换图谱”：正确值排序更像某些层/位置/组件根据上下文生成的 update，而不是可直接移植的向量。

		总阶段性结论：
			目前最可靠的完整理论体系是：
				语言智能 = 相对编码网络 + 对象知识锚定 + 关系/规则检索 + 条件化状态变换 + 候选竞争 + 范数/格式/策略读出门。
			最关键的新瓶颈是：
				从 Level 3 transition evidence 推进到 Level 4 component causal node，并最终达到 Level 6 generation closure。
