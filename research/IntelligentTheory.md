
# 智能理论

## 研发路线：
	1，人脑通过极高的可塑性形成了语言能力，LLM通过注意力+自回归机制+大量语言材料训练，部分还原了语言背后的数学结构。
	2，如果能破解LLM内部语言的编码机制，就可以了解大脑是怎么具备语言能力的，进而可以破解大脑神经网络的机制，完成智能理论，实现AGI。
    


## 一，路线分析
	当前AI和AGI（人脑）的区别：
		1，实时学习，人脑可以不停的接受新信息。
		2，准确理解，比如可以准确理解某个数学概念，或者其他人的想法。
		3，系统思维，把所有知识形成一个系统，然后基于系统分析各种问题。
		这三个看起来是不同的特性，本质都是源于深度神经网络和人脑的结构差距，产生的结果。一旦弥补了这个差距，AI就可以达到人类水平，甚至超过人类。

	要实现通用人工智能，现在有几个主要路线：
		1，类脑路线，要收集人脑大量数据，解决人脑神经信号极为复杂的难题。
		2，深度神经网络，人脑结构极为高效，接近物理学中的最优解，深度神经网络要达到人脑的结构效率，可能有一些难度。
		3，逆向工程，对深度神经网络进行逆向工程，分析为什么可以具备语言能力。

	为什么逆向工程路线是最有可行性的?
		1，语言是人脑的产物，有非常特殊的数学结构，ai生图，ai编程都是这个结构的体现。
		2，深度神经网络通过训练，部分提取了语言的数学结构，所以具备了语言能力。
		3，通过分析深度神经网络，通过消融等测试，尝试找到语言背后的数学原理。
	语言体现了人脑神经网络的很多特性，是理解智能的关键入口，如果能从编码角度理解语言原理，就可能完成智能理论，实现AGI了。

	既然这个路线可行，为什么各个AI公司进展有限，因为语言背后的原理可能和现有认知不一样，是一种非常特殊的结构。
	要破解这个结构，需要三个步骤：
		1，对深度神经网络进行充分研究，分析内部结构和运行机制是什么样的，积累大量数据。
		2，使用各种数学工具，比如统计、流形拓扑等多个维度进行分析，积累大量拼图。
		3，结合大量拼图、人脑研究、智能理论框架，三个方面的投影还原这个结构。
	随着这方面的研究越来越多，迟早会达到临界点，如果全球大量资源投入，两三年之内甚至更快都是有可能的。
	既然这个路线可行，为什么各个AI公司进展有限，因为语言背后的原理可能和现有认知不一样，是一种非常特殊的结构。要破解这个结构，需要逆向分析积累大量拼图碎片，加上人脑特性和智能理论框架，像拼图游戏一样还原这个结构，这应该是现在最可行的路线，随着这方面的研究越来越多，迟早会达到临界点，这个时间可能不会很远了。



## 二，语言特性分析
	语言的三个核心要素：
		网络知识
		逻辑推理
		语法规则

	多层次系统化的知识网络：
		包含大量概念，比如苹果，太阳，石头，水，头发。
		包括大量属性，比如苹果的颜色，味道。
		包含层级系统，比如苹果抽象为水果、食物、物体等等。
		各种特征和概念属性形成了一个多维度的知识网络，这个网络极为强大和高效，同时完美解决了维度灾难问题。

	逻辑推理，包含了各种不同的模式，完成各种任务：
		比如理解、分析、推理等逻辑能力
		比如翻译、诗歌、代码等任务
		比如但是、因此、总结、反思等功能
		
		模式中，包含了一套逻辑体系：
			进行基于某些条件进行分析推理，解决知识网络受限无穷组合问题，比如：
			深度思考能力，在最前面形成某种高级模式。
			语言方面：翻译能力，续写，优化等。
			算数，近义词，反义词
		模式中，包含了完整的语法：
			有名词，形容词，动词，代词，介词，副词等类型，每种都是不同的使用方式
			有大量不同的句式模板，可以灵活的根据情况替代使用
			多层次的系统结构，比如段落，字词等

	系统层面：
		神经网络系统包含了多个维度，可以完美融合运行，形成分层控制系统： 
			风格维度（聊天/论文/诗歌）
			逻辑维度（上下文逻辑推理）
			语句维度（语法结构）

		系统实现了不可能三角，极为强大，又极为高效：
			1，提取各种特征，比如文字图片声音味道等不同维度，没有维度灾难问题。
			2，知识网络，多层级多维度的知识系统，可以描述真实世界的各种事物。
			3，极为高效，任意信息和关联，都可以快速查找，快速修改。
			
		其他特性：
			在词嵌入中，国王 + 王后 - 男性 = 女性，说明词嵌入中有某种数学结构。
			名词，动词，形容词，副词，介词，代词是完全不同的机制，都在一个网络中，说明网络有某种兼容性。
			在大脑中，神经网络基于3d空间，形成一种极为高效的编码结构，在深度网络中，大量参数形成某种结构进行处理，根据风格，逻辑，语法得到下一个词。都说明背后有某种数学结构。
			大脑神经网络的编码，同时具备了复用能力，比如很多水果具有相同特征，但是每种又有单独特征，是如何通过编码实现这种高效结构的。

	关键猜想：
		大脑中的脉冲天然是最小传送量原理，所以系统极为高效，叠加路径即编码原理，就会导致及时学习和全局稳态同时实现，而核心可能是在脉冲神经网络的3d空间拓扑网络结构上。
		在深度神经网络中，所有神经元都参与运算，但是在不同风格，不同逻辑，不同语法下，每次都能生成一个合适的词，说明语言中某种东西具有全局唯一性，而且这种唯一性应该具有数学特性。
		大脑的寻路和编码机制，是一体的， 也就是说，神经信号传导到某个神经组织，和 语义语法编码 两者是一体的， 而 语义的关键，在于差异性，比如 苹果通过图像味道区别其他水果和食物，形成自己的编码， 翻译 通过 中文到英文，区别于其他的润色等模式，形成自己的编码。

	以上所有特性，都是一套编码机制的产物，现在的核心目标，就是分析这套编码机制，在神经元和参数级别是怎么形成的。



## 三，语言编码机制

### 1，编码分析
		当前最重要的总判断：
			语言编码不是一个固定语义轴系统，也不是简单的 token 向量存储系统，而是“相对状态 + 条件化变换 + 候选竞争 + 读出门控”的动态系统。
			一个词、对象、属性或规则是否起作用，不能只看它在某层有没有方向投影，还要看：
				1，它处在什么位置；
				2，它被什么上下文激活；
				3，它经过哪些层的 attention / MLP update；
				4，它是否进入候选集合；
				5，它是否改变 target / competitor 的相对排序；
				6，它是否能在生成层面改变输出。

		完整流程：
			1，对象进入上下文，形成对象身份 I 和位置 P。
			2，句式、角色、规则、关系共同形成当前语义场。
			3，模型选择内部路线：检索路线、属性路线、关系路线、否定路线、格式路线、生成策略路线。
			4，关系或规则把对象重编码为状态，例如 object-category、object-relation-value、category-relation-value。
			5，状态进入候选集合，候选之间形成 common activation 和 candidate-specific ranking。
			6，范数、RMSNorm、final norm weight、格式维度、策略门共同决定读出可见性。
			7，输出层在候选族中选择 winner，生成词元或短语。

		核心编码模块：
			1，相对编码：
				概念不是固定坐标点，而是在任务、模板、位置、候选集合中的相对差异。
				“苹果”不是一根固定轴，而是在水果、食物、颜色、味道、对象身份等关系中的组合状态。
			2，身份 I 与角色 R：
				token identity 和 functional role 可以被分解。早期 Phase 301-303 的 R/F 分解有伪影，后来通过 construction、norm、position 修正。
			3，构式 C 与格式 F：
				句式/格式不是噪声。它既能污染语义方向，也能作为路径控制信号。GLM4 中格式污染尤其明显，DS7B 较低。
			4，操作符 O 与作用域 S：
				否定不是形式逻辑中的“取反函数”，更像语义极性偏移和状态变换。not、never、no、n't 有层次化关系；作用域会改变方向效果。
			5，关系 Rl 与属性/值 V：
				属性、类别、功能、连续属性都不是单一方向。连续属性表现为静态知识锚定 + 规则上下文调制 + 候选词读出。
			6，绑定 B：
				对象-属性、对象-类别、对象-关系-值绑定真实存在，但不是 embedding 预存，主要由 transformer 层计算产生。
			7，候选竞争 Cmp：
				模型不是直接生成“正确答案”，而是在候选族内重排 target、old top-wrong、generic、echo、format token 等竞争项。
			8，范数与读出门 N/G：
				范数不是单纯置信度。它会影响读出可见性、final norm gate、格式门、候选压缩和符号翻转。
			9，路径路由 Path：
				同一语义任务会按不同 prompt 走不同路线。projection peak 不一定是 causal node，路径需要用因果等级图谱表示。
			10，条件化状态变换 T：
				最新 Phase 594 说明，candidate-specific ranking 更像 layer-to-layer conditional transformation 的产物，而不是一个可单点移植的 residual 向量。

		已经确认的关键拼图：
			1，语言编码 = 内容绑定 + 关系选择 + 操作变换 + 作用范围 + 候选竞争 + 范数调制 + 路径路由 + 条件化状态变换。
			2，否定方向具有因果效应，但不是逻辑否定；双重否定、弱否定、局部否定高度依赖词对和模型。
			3，关系网络在中间层保留，但属性/功能关系的“上下文激活”早期被高估，平行模板后只有 modest 效应。
			4，binding 在后半段增强，embedding 对 binding_item 的贡献接近 0，transformer 层是主要来源。
			5，MLP 经常承担 binding、属性、候选排序、值路径的主要计算，但 attention 负责检索、路由、格式和部分边界写入。
			6，类别边界不是单层写入，而是跨层累积；存在支持层、反对层、末层释放、共享语义抑制和读出接口。
			7，正交成分不一定是“前体”，很多时候是刹车/抑制/调节项；移除它会释放边界。
			8，final RMSNorm 和 norm weight 可以造成 margin 符号翻转；少量维度可能主导格式门。
			9，规则检索电路存在，但检索不自动等于推理；两跳组合的瓶颈主要是错误中间类别或关系使用不稳定。
			10，Phase 593 证明 projection node 不能直接升级为 causal patch node；Phase 594 进一步指向 component update 和条件化变换。

		最新机制图：
			对象 o，关系 r，候选值 v 进入上下文后，模型先形成多个位置状态：
				query_object / query_relation / query_category / rule_value / rule_relation / prompt_last。
			这些位置不是等价的：
				query_relation 更像关系路径节点；
				rule_value 更像值排序生成节点；
				prompt_last 更像汇聚和读出节点。
			以 DS7B 最新结果为例：
				rule_value L26 是最强 transition point；
				rule_value L26 的 MLP update 几乎复现 outgoing specific_margin；
				query_relation L19 的 MLP update 是 relation-path ranking signal 候选；
				prompt_last L26 有强 common activation，但不是最干净的生成源。

		Phase 595-707 后的最新更新：
			这之后的研究把问题从“哪个 residual 位置能修复 value gate”推进到“answer-start 读出端、源词元贡献、注意力头、输出通道、完整短语似然之间如何共同决定生成路线”。
			最新最严格的判断是：
				语言编码仍然不是固定语义向量，但也不能简单说某个 source channel ensemble 携带了可迁移的 donor value identity。
				更准确地说，当前观察到的是：
					目标 prompt residual / local context 负责锁定 target identity；
					answer-start 附近的注意力和通道集合负责改变 value/prose route competition；
					format / terse / answer_line / self_last 等协议状态决定答案能不能以短值形式被读出；
					完整短语层面仍有 prose explanation 与 value phrase 的竞争。

			因此，当前语言编码机制应写成：
				语言输出 = 目标上下文身份锚定 + 源贡献路线增益 + 格式协议状态 + 候选短语竞争 + 读出/生成门。

			对原有“候选竞争 + 读出门控”理论的修正：
				1，winner 不只是在单个 next-token logit 上产生，还要经过完整 phrase likelihood 和自然生成路线筛选。
				2，attention head 不是语义神经元本身，更像源路径聚合器；channel / neuron 才更接近局部编码颗粒度，但仍需要因果验证。
				3，source-restricted channel ensemble 可以稳定改变 value 路线，但目前不能证明它携带跨样本可迁移的 donor identity。
				4，完整短语审计显示 donor phrase 很少成为 winner，说明 cross-case donor patch 通常不是在注入 donor value phrase。
				5，prose phrase 经常获胜，说明 readout likelihood 到自然短答案生成之间仍有 generation gate。

			最新机制图更新为：
				target prompt residual / local context
					-> answer_start 的源词元组合 target_value + answer_line + self_last
					-> L23-L27 附近的关键 attention heads
					-> source-restricted positive channels
					-> W_O / readout route gain
					-> value phrase / prose phrase / continuation 的竞争
					-> final generation gate。

			其中 source-restricted channel ensemble 当前应分解为：
				G_route：值回答路线增益；
				P_format：短答格式/协议状态；
				E_target_context：目标上下文身份锁定；
				V_identity_local：尚未完全定位的局部身份项。

			这意味着：
				当前已经找到“路线/读出底座”的强因果证据；
				还没有完全找到“可迁移语义身份代码”的最小因果单元。

		Phase 708-851 后的最新更新：
			这之后的研究把“机制图谱”从局部读出通道继续推进到全局齿轮图谱。附件中的 Phase 20-848 历史分析已经被部分吸收，但原文件仍停留在“条件化相对状态—生成场闭合”的主框架，对“状态-路线-齿轮-边界-闭合图谱”的吸收不够完整。

			最重要的修正是：
				语言编码机制不能只写成状态轨迹进入生成场；
				还必须写成带证据等级的全局齿轮图谱。

			当前更准确的机制图应写成：

				input tokens / prompt protocol
					-> state variables:
						identity / role / frame / operator / scope / binding
					-> route variables:
						semantic / object / category / format / echo / protocol / blocker
					-> gear functions:
						reader / router / carrier / writer / rewriter / suppressor / gate
					-> conditional gate:
						macro prompt gate
						+ meso protocol/sign gate
						+ micro residual_projection/blocker gate
					-> boundary transition:
						token boundary / answer-class boundary / span boundary / rollout boundary
					-> closure:
						full-vocabulary blocker cleared
						+ exact-natural consistency
						+ natural generation rollout。

			Phase 850-851 的最严格结果是：
				qwen3 residual_projection_combo 进入 L5 strong-edge holdout candidate；
				qwen3 internal_strength_combo 是弱 L5 candidate；
				qwen3 blocker_field_combo 只能算 L4 partial candidate；
				DS7B blocker_field_combo 只有 L3 in-sample only；
				GLM4 当前为 L0 untriggered，因为没有 strong-edge 样本。

			这说明：
				当前最接近语言编码机制的对象，不是单个神经元、head、channel 或语义方向；
				而是能跨 object / prompt 预测 strong-edge 的 gate edge。

			因此，当前语言编码机制应升级为：
				语言输出 = 预测充分相对状态 + 全局齿轮图谱 + 条件化路线门控 + 全词表竞争闭合 + 自然生成一致性。

				条件化状态转移算子、动态路由图。

### 2，语言模式图谱
		最新总判断：
			语言模式图谱不是“结果展示表”，而是逆向分析语言机制的主数据结构。
			它要回答四个问题：
				1，某类语言能力属于哪个模式族；
				2，这个模式族在模型内部走什么物理路径；
				3，哪些路径只是相关信号，哪些路径具有因果必要性；
				4，这条路径能否在自然生成中形成干净闭合。

		图谱的基本对象不是单个神经元、单个 head、单个 MLP 层，也不是单个 token margin。
		它的基本对象是：

			PatternPath(x,m)

		其中 x 是样本，m 是模型。

		完整路径应记录：

			prompt / context
				-> state variables
				-> route variables
				-> component path
				-> readout competition
				-> protocol / rollout gate
				-> closure gate
				-> evidence level
				-> claim registry

		九大语言模式族：

			1，content_knowledge：对象、属性、类别、知识回答。
			2，output_protocol：短答、JSON、列表、解释、格式协议。
			3，reasoning_constraint：规则、约束、推理步骤、禁止条件。
			4，syntax_structure：句法、词性、语序、结构模板。
			5，language_action：翻译、总结、改写、续写、命令执行。
			6，cross_lingual：跨语言映射、语言切换、双语对齐。
			7，readout_competition：target / stop / continue / prose / echo / wrong token 竞争。
			8，state_drift：状态漂移、解释漂移、格式漂移、对象漂移。
			9，closure：语义完成、停止执行、继续路径抑制、自然生成稳定。

		注意：
			九大族是当前工作分类，不是已经证明的完备语言分类。
			必须加入 open-set 检验：

				open_set_tasks -> auto_label_family -> known / mixed / unknown

			如果 unknown_family_rate > 5%，说明九大族不能冻结。
			如果 mixed_family_rate > 15%，说明某些模式族过粗或存在强耦合。
			如果某个 family-model 的样本数 < 100，该格只能标记为 exploratory，不能进入强机制结论。
			成熟阶段应把每个 family 扩充到至少 200-500 条高质量样本，否则方向估计和跨模型一致性都不稳定。

		全链路字段：

			behavior：外部回答是否满足任务。
			readout：目标 token / 短语、stop、continue、prose、wrong token 的读出竞争。
			layer_path：路径在哪些层出现、增强、衰减或反转。
			component_path：attention / MLP / residual / norm / W_U 的组件贡献。
			causal：干预后是否按预期改变 margin、winner 或 rollout。
			compensation：抑制某路径后是否被其他路径接管。
			rollout：自然生成后续是否漂移、解释化、重复或继续。
			closure：是否满足闭合硬判据。
			semantic_eval：短语级、span 级、语义级判断，而不是只看单 token。
			cross_model_consistency：跨 qwen3 / GLM4 / DS7B 是否一致，矛盾是否模型特异。
			nonlinear_coupling：多 writer / 多组件是否存在非线性耦合，不能用线性叠加解释。
			claim_id：对应的机制主张编号。
			evidence_level：L0-L8 证据等级。

		主表公式：

			Atlas(f,m)
				=
				[
					Cases,
					Behavior,
					Readout,
					LayerPath,
					ComponentPath,
					CausalAudit,
					CompensationPath,
					Rollout,
					Closure
				]

		路径签名：

			PathSignature(x,m)
				=
				[
					State,
					DominantLayers,
					AttentionRoute,
					MLPWrite,
					Compensation,
					ReadoutWinner,
					ProtocolGate,
					ClosureQuality
				]

		机制主张登记：

			Claim(c)
				=
				[
					ClaimID,
					Scope,
					EvidenceLevel,
					PositiveEvidence,
					NegativeEvidence,
					CounterExamples,
					NextTest
				]

			没有进入 claim registry 的结论，只能算观察记录，不能作为机制理论。

		证据等级：

			L0：假设。
			L1：行为现象。
			L2：readout 可读出。
			L3：层路径稳定。
			L4：组件归因。
			L5：低副作用因果必要性。
			L6：受控充分性。
			L7：rollout 稳定。
			L8：clean closure。

		标准化因果干预协议：

			为了避免把分布外强干预误判成机制证据，所有高价值候选都应按统一干预协议审计：

				zero ablation；
				half scaling；
				mean replacement；
				random same norm；
				permutation control；
				cross-sample patch；
				multi-layer window patch；
				direction add；
				direction remove；
				attention+MLP combined patch；
				negative family control。

			方向增强：

				h' = h + λ v_hat

			方向移除：

				h' = h - (h · v_hat) v_hat

			证据解释：
				zero ablation 适合定位，但副作用大；
				half scaling / mean replacement 更适合做低副作用因果审计；
				random same norm 用于排除“只是范数变化”的伪因果；
				cross-sample patch 用于检查路径是否可跨样本迁移；
				negative family control 用于确认该机制不是所有任务通用扰动。

		图谱完成度评分：

			Score_base(x)
				=
				0.10B(x)
				+ 0.10R(x)
				+ 0.15L(x)
				+ 0.20C(x)
				+ 0.25I(x)
				+ 0.10G(x)
				+ 0.10K(x)

			其中：
				B：behavior；
				R：readout；
				L：layer path；
				C：component path；
				I：intervention / causal；
				G：rollout / protocol gate；
				K：closure quality。

			封顶规则：

				Score_atlas(x)
					=
					min(
						Score_base(x),
						Cap_I(x),
						Cap_C(x),
						Cap_K(x)
					)

			如果 I(x) < 0.30，则 Score_atlas(x) <= 0.50。
			如果 C(x) < 0.30，则 Score_atlas(x) <= 0.60。
			如果 K(x) < 0.30，则 Score_atlas(x) <= 0.65。
			如果 semantic_eval 未通过，则不能标记为 high_quality_candidate。
			如果 cross_model_conflict 为 true，则不能汇总为 global mechanism，只能标记为 model_specific_mechanism。

		闭合硬判据：

			Closure(x)
				=
				SemanticDone(x)
				∧ StopWins(x)
				∧ ContinueSuppressed(x)
				∧ RolloutStable(x)

			只有四项同时成立，才能标记为 closed。
			否则只能标记为 mapped_partial、path_candidate_not_closed 或 high_quality_candidate_not_closed。

			其中 semantic_eval 不能只依赖字符串匹配或第一个 token margin。
			至少应包括：
				1，完整短语似然；
				2，span / alias 接受度；
				3，协议一致性；
				4，高质量候选的人工抽样复核。

			只有 semantic_eval 通过，闭合判据才有意义。

		跨模型一致性：

			X(f)
				=
				1
				-
				N_disagree(f)
				/
				N_models(f)

			如果 qwen3 / DS7B 支持某路径，但 GLM4 反向，不能取平均。
			应记录为：

				cross_model_conflict: true
				mechanism_scope: model_specific
				next_test: compensation_path_audit

		非线性耦合审计：

			Δ_linear = Σ_i ΔM_i

			Δ_actual = M(h + Σ_i p_i) - M(h)

			如果：

				|Δ_actual - Δ_linear| > ε

			则标记：

				nonlinear_coupling: true

			说明这条路径不能用单 writer 线性贡献解释。

		前向预测验证：

			图谱不能只回顾性整理历史数据，必须能预测 heldout 样本。
			给定未见过的样本 x，图谱应预测：

				dominant_layers；
				component_path；
				readout_winner；
				closure_gate；
				failure_type。

			预测公式：

				P_hat(x,m)
					=
					AtlasPredict(
						family(x),
						mode(x),
						model(m),
						prompt_features(x)
					)

			验证：

				Acc_path
					=
					N(P_hat_path = P_path)
					/
					N_heldout

			只有预测显著高于随机基线，图谱才开始具备理论解释力。

## 四，智能理论
		智能定义：
			智能是一个系统在持续输入中形成相对状态网络，并能根据目标、上下文和反馈，对世界对象、关系、规则、候选行动进行重编码、选择和修正的能力。
			更通俗地说，智能不是“存了多少知识”，而是能否把当前问题放进正确的关系网络里，找到可执行路径，并在竞争答案中选出最合适的一个。

		智能系统的构成：
			1，特征提取层：
				从文字、图像、声音、动作中提取对象和差异。
			2，相对编码层：
				把对象放进关系网络，而不是给每个对象固定标签。
			3，绑定层：
				把对象、属性、类别、关系、值绑定成可操作状态。
			4，路径路由层：
				根据任务选择检索、推理、翻译、解释、生成、规划等路线。
			5，条件化变换层：
				在每一步根据上下文改变状态更新规则。
			6，候选竞争层：
				生成多个可能答案或行动，并比较 target / competitor。
			7，反馈学习层：
				根据错误和新信息修改路径权重、候选优先级、关系强度。

		从当前模型看，现代 DNN 已经具备：
			1，大规模相对编码；
			2，局部绑定；
			3，关系检索；
			4，候选竞争；
			5，一定程度的条件化变换；
			6，复杂的范数/读出门控。

		但还缺少：
			1，稳定实时学习；
			2，可控的中间状态传递；
			3，可验证的多跳组合闭环；
			4，抗格式/echo/policy gate 干扰的语义读出；
			5，真正可编辑、可因果定位的关系图谱。

		AGI 的关键突破方向：
			不是简单扩大模型，而是找到“相对编码 + 条件化变换 + 可塑性更新”的基本结构。
			如果能把当前 DNN 中隐含的状态变换图谱变成可读、可修、可学习的结构，就可能接近人脑的实时学习和系统思维。

		根据最新语言模式图谱进展，智能理论需要补充一层“机制图谱层”：
			智能不是只形成隐藏状态，也不是只输出正确答案；
			智能系统必须能把内部状态组织成可预测、可验证、可干预、可复用的机制图谱。

		更新后的智能系统分层：
			1，输入表征层：
				把 token、图像、声音、动作等输入转为初始状态。
			2，相对状态层：
				把对象、关系、角色、格式、目标放入上下文关系网络。
			3，路径路由层：
				根据任务选择 semantic / object / category / format / protocol / blocker 等路线。
			4，组件执行层：
				由 attention、MLP、residual、norm、W_U 共同完成寻址、搬运、写入、抑制和读出。
			5，竞争闭合层：
				在 target、competitor、stop、continue、prose、echo、format token 中完成竞争。
			6，机制图谱层：
				把上述过程登记为 PatternPath、Claim、EvidenceLevel 和 ClosureGate。
			7，预测验证层：
				用 heldout 样本检验图谱是否能预测路径和失败类型。
			8，可塑性更新层：
				在不破坏已有路径的情况下，局部修改 claim、路径权重和闭合门。

		因此，智能的更严格定义应更新为：
			智能是一个系统在持续输入中形成相对状态网络，并把状态网络组织成可预测、可验证、可干预的机制图谱；
			它能在候选竞争中选择行动，在失败后定位路径缺口，并通过局部更新改善未来预测和闭合。

		当前 DNN 的差距也要相应更新：
			1，能生成大量正确答案，但内部机制图谱不可直接读写。
			2，能形成相对状态，但缺少稳定 claim registry。
			3，能通过训练吸收新知识，但推理时缺少低副作用局部编辑。
			4，能在许多任务上自然闭合，但 stop / continue / prose / echo 竞争仍不可控。
			5，能在部分样本上显示因果路径，但跨模型一致性、非线性耦合和 heldout 预测仍不足。

		智能水平的初步判据：
			1，能否形成稳定关系网络；
			2，能否在新规则下重编码旧知识；
			3，能否把一步检索结果变成下一步查询状态；
			4，能否在候选竞争中稳定压过错误竞争项；
			5，能否在不破坏旧知识的情况下局部学习新关系；
			6，能否跨模板、跨语言、跨模态保持同一关系结构；
			7，能否解释和修复自己的错误路径。

		最新增加的判据：
			8，能否把内部机制登记为可复查的 claim。
			9，能否给每条机制路径标注 L0-L8 证据等级。
			10，能否在跨模型矛盾时识别 model_specific_mechanism。
			11，能否识别线性叠加失效和非线性耦合。
			12，能否在 heldout 样本上预测 dominant_layers、component_path、readout_winner 和 closure_gate。


## 五，数学体系：
		第一性原理：
			目前最接近第一性原理的表述是：
				智能系统不是存储孤立概念，而是在上下文中把对象、关系、规则、候选、目标函数重编码为可读出的相对状态。
				语言能力来自大量可复用基础结构的条件化组合，而不是单一全局语义坐标。

		基本状态公式：
			第 l 层、位置 p 的隐藏状态可以写为：

				h_l(p) =
					I_l(p)
					+ R_l(p)
					+ F_l(p)
					+ C_l(p)
					+ O_l(p)
					+ S_l(p)
					+ K_l(p)
					+ B_l(p)
					+ Q_l(p)
					+ N_l(p)
					+ ε_l(p)

			含义：
				I(identity)：对象或 token 身份。
				R(role)：词在句中的功能角色。
				F(frame)：局部句框和表面格式。
				C(construction)：整体构式/语法结构。
				O(operator)：not、never、must、should 等操作符。
				S(scope)：操作符作用范围。
				K(knowledge anchor)：对象的静态知识锚定，例如 desert-hot、ice-cold。
				B(binding)：对象-属性、对象-类别、对象-关系-值绑定。
				Q(candidate competition)：候选集合中的 target/competitor/common/specific 排序状态。
				N(norm/gain)：范数、RMSNorm、final norm weight、读出增益。
				ε：未建模项、噪声、模板特异项、离流形扰动。

		条件化关系重编码公式：
			对于对象 o、关系 r、候选值 v：

				Δh_l(o,r,v | x) =
					I_l(o)
					+ R_l(r)
					+ V_l(v)
					+ G_l(o,r)
					+ H_l(o,r,v)
					+ Cmp_l(o,r,v)
					+ N_l(o,r,v)
					+ Path_l(x)
					+ ε_l

			其中：
				G(o,r)：对象和关系形成的门控项。
				H(o,r,v)：三元绑定或高阶交互项。
				Cmp(o,r,v)：候选竞争项，决定 correct value 是否超过 old top-wrong。
				Path(x)：由上下文 x 决定的路径项，包括 prompt、表格、规则、位置。

		层间变换公式：
			最新 Phase 594 后，需要把静态状态公式升级为变换公式：

				h_{l+1}(p) = h_l(p)
					+ A_l(h_l, x, p)
					+ M_l(h_l, x, p)

				ΔQ_{l→l+1}(p) =
					Proj_candidate(h_{l+1}^{repair}(p) - h_{l+1}^{base}(p))
					-
					Proj_candidate(h_l^{repair}(p) - h_l^{base}(p))

			其中：
				A_l 是 attention update；
				M_l 是 MLP update；
				ΔQ 是候选排序在层间增强或减弱的量。

			关键解释：
				如果 ΔQ 主要来自 M_l，说明 ranking 是 MLP 条件化更新生成的；
				如果 ΔQ 主要来自 A_l，说明 ranking 由注意力检索/路由生成；
				如果 incoming 已经很强，说明该位置是 carry 或汇聚点；
				如果 outgoing 强但 patch 无效，说明它可能只是 projection node，不是可移植因果节点。

		候选竞争公式：
			对候选集合 V={v1...vn}：

				score_i = e(v_i) · h
				common = mean_i(score_i)
				specific_i = score_i - common
				margin_correct = specific_correct - specific_old_wrong

			正确输出需要：
				1，候选族被整体激活，即 common 足够高；
				2，correct-specific 超过 old-top-wrong-specific；
				3，格式/echo/generic/policy gate 不抢占输出；
				4，final norm/readout 不发生符号翻转。

		类别边界公式：
			类别边界不是单一方向，而是：

				Boundary_c =
					Σ_l Write_l(c)
					- Σ_l Brake_l(c)
					+ Release_final(c)
					+ Readout_gain(c)

			含义：
				Write：投影写入、MLP/attention 支持项；
				Brake：共享语义抑制、反对层、正交调节项；
				Release_final：末层释放或刹车解除；
				Readout_gain：RMSNorm、final norm weight、W_U 接口。

		连续属性公式：
			连续属性不是纯等级轴：

				logit(candidate | object, context)
					= W_U(candidate) · [K(object) + M(context) + T(object, context)]

			其中：
				K(object)：静态知识锚定；
				M(context)：规则上下文调制；
				T(object, context)：层间变换；
				W_U(candidate)：候选词读出。

			已知修正：
				规则可以改写几何，但存在非对称反转；
				候选词语义特异性会强烈影响测量；
				非对称反转不能简单由 W_U 范数解释，根源更可能在内部对象锚定深度。

		源词元贡献和通道集合公式：
			Phase 699-707 后，需要把注意力头和通道贡献分开写。对第 l 层、第 h 个注意力头、第 c 个输出通道，源词元集合 g 对 answer-start 的贡献可以近似写成：

				C_g(l,h,c | x)
					=
					Σ_{t∈g}
						α_{l,h}(answer_start,t | x)
						· V_{l,h,c}(t | x)

			其中：
				α 是 answer-start 对源词元 t 的注意力权重；
				V 是该源词元在对应 head/channel 上写入的 value contribution；
				g 可以是 target_value、answer_line、self_last、all_source 等源词元组。

			如果要找“促进短值答案而不是解释性 prose 的通道”，可以定义差分贡献：

				D(l,h,c)
					=
					[
						C_{combo}^{terse}(l,h,c)
						-
						C_{combo}^{short}(l,h,c)
					]
					·
					⟨ W_O(l,h,c), d_{value-prose} ⟩

			正向源限制通道集合为：

				U_{source}^{+}
					=
					{
						(l,h,c)
						|
						D(l,h,c) > 0
						且通过 random / holdout / degradation 对照
					}

					+

			其中 V_identity_local 目前还没有被单独剥离出来。

		QK/V 因子分解公式：
			比较 research/IntelligentTheory.md 与 research/IntelligentTheory_20260628.md 后，最合理的更新是保留 20260628 版的非线性理论体系，同时补回 QK/V 因子分解。

					Σ_{t∈g}

						·
						V_{l,h,c}(t | x)

					Σ_{t∈g}

					ΔC_{QK}

				ΔC_QK：寻址改变，即 answer_start 改变“看哪里”。
				ΔC_V：内容改变，即被看的源词元内部表示改变。

## 六，非线性理论体系

	为什么需要单独的非线性理论体系：
		早期研究（Phase 301-594）主要用线性子空间、方向投影、activation patching 分析语言编码。
		但大量证据表明，语言编码的核心机制不能用线性叠加描述：
			1，Phase 27 发现属性条件依赖但线性可分 —— 局部线性、全局非线性。
			2，Phase 34 发现所有方向在 Jacobian 链中被快速旋转 —— 不存在贯穿全模型的稳定方向。
			3，Phase 39 发现 RMSNorm 在小扰动下掩盖各向异性，存在临界值 α*。
			4，Phase 141 发现语言算子非交换，形成非交换代数。
			5，Phase 301-312 发现 DS7B 的 full_delta 因果效力≈0 但分量 R_only 强 —— 非线性抵消。
			6，Phase 633 发现多 writer 线性叠加 restore 不超单 writer —— softmax 归一化墙。
		因此，非线性理论体系是理解语言编码机制的核心，不是附属。

	6.1 流形拓扑基础（Phase 20-22, 141）

		核心事实1：语言流形极低维
			dim(M_language) ≈ 65-75 << d_model ≈ 2560-4096
			参与率 PR ≈ 2-5%
			含义：大部分 R^d 方向是冗余的，语言只使用 2-5% 的维度。
			这是整个微分几何框架的基础 —— 如果 hidden state 在极低维流形上运动，
			那么 Jacobian、向量场、联络等微分几何工具才有意义。

		核心事实2：语法角色是共享语义流形上的纤维结构
			语言表示不是"语义 + 正交语法轴"，而是"共享语义流形 + 低维语法纤维"：
				h_role(x) = M_l(x) + δ_role(x)
			其中 M_l(x) 是共享语义流形坐标，δ_role 是角色特异纤维偏移。
			切空间分析：
				nsubj-poss 共享切空间（d_G ≈ 0.001）→ 同一语义角色
				amod 切空间与 nsubj/dobj 近正交 → 修饰语是独立子空间
			流形是弯曲的：
				geodesic 距离 > euclidean 距离
				amod 的 geo/eucl factor ≈ 2.0 → 流形弯曲最大

		核心事实3：属性编码矩阵的列不正交
			Phase 27 修正模型：
				h = b + A @ v(c) + ε
			其中 v(c) 是概念属性向量，A 是属性编码矩阵。
			关键：A 的列不正交！
				cos(A[:,edible], A[:,color_red]) ≈ 0.5
			这解释了：
				条件解耦失败：d(edible|红色) ≠ d(edible|绿色)，因为 A 的列不正交
				线性可分：线性边界存在（h = A@v + ε）
				局部线性/全局非线性：同类概念 v 相近，A@v 在局部线性；跨类 v 差异大，全局非线性
			与信息论的联系：A 的列不正交 → 属性间有信息冗余 → 率失真理论 → 过完备字典

	6.2 Jacobian 链与扰动传播（Phase 32-34）

		这是从"找方向"到"测算子"的范式转换。

		Jacobian 链定义：
			δ_{l+k} ≈ J_{l+k-1} · J_{l+k-2} · ... · J_l · δ_l
		其中 J_l = ∂h_{l+1}/∂h_l 是第 l 层的 Jacobian 矩阵。

		核心发现1：算子一致性 —— 模型间差异
			Qwen3/GLM4：全层 CV < 0.15 → Jacobian 近似 input-independent → 近似线性算子
			DS7B：中间层（L6-L21）CV > 0.3 → Jacobian 显著 input-dependent → 非线性算子
			含义：在 Qwen3/GLM4 中梯度方向接近全局因果方向；在 DS7B 中不是。

		核心发现2：旋转放大器模型
			||J · δ|| > ||δ||（放大 4-25 倍）
			但 cos(J · δ, δ) → 0.1（方向被强烈旋转）
			无论注入 probe 方向、lm_head 方向还是 random 方向，经过几层传播后方向都大幅旋转。
			cos(original, delta) 从 ~0.9 降到 ~0.1。
			结论：不存在贯穿全模型的稳定方向 —— 语义是 Jacobian 链对信号的变换结果，不是 h 中的某个方向。

		核心发现3：lm_head 方向是真正的因果管道
			lm_head_edible 方向对 edible logit 的效应远超 probe 方向（5-9 倍）。
			即使在浅层注入，lm_head 方向也有效。
			因果路径：h → Jacobian 链 → h_{L-1} → W_U → logit
			W_U 定义"读出方式"（哪些维度被映射到 logit）
			Jacobian 链定义"传播方式"（信号如何从 h_l 到 h_{L-1}）
			两者共同决定因果。

		核心发现4：组合传播的非线性
			扰动被指数放大：ε=0.01 的扰动经过 8 层传播后范数增大 10-600 倍。
			语法约束组合的 nl_ratio（非线性比）随层深递增：
				早期层几乎线性（nl_ratio ≈ 0.11-0.19）
				深层强非线性（nl_ratio ≈ 0.73-0.92）
			不同约束类型组合机制不同：
				否定+被动：早期近乎线性（0.99）→ 正交约束
				否定+时态：从一开始非线性（0.65）→ 交互作用
			约束越多，非线性越强：三重组合深层 nl_ratio ≈ 0.78-0.89。
			结论：语法约束不是简单叠加，而是通过非线性算子交互。

	6.3 RMSNorm-Jacobian 动力学（Phase 39）

		理论模型：
			δh^{l+1} = D_norm · J_l · δh^l
		其中：
			D_norm（归一化层）：投影 + 缩放，在 h 正交子空间中近似各向同性
			J_l（Jacobian）：各向异性放大器，margin 方向被放大 50-75 倍

		RMSNorm 的 Jacobian：
			J_norm = g/||x|| · (I - x x^T / ||x||^2)
		这是投影矩阵：沿 x 方向 kill 扰动，在正交子空间中等效。
		关键：Norm 不是纯各向同性投影器，而是"方向依赖投影器"。

		三个可证伪预测及验证：
			P1: 存在 α* 临界值
				α < α* → 各向同性（RMSNorm 掩盖各向异性）
				α > α* → 各向异性显现
				验证：α* ≈ 0.001-0.005，三模型一致 ✓
			P2: 更多 RMSNorm 层 = 更强方向掩盖
				验证：r(n_norms, DER) = -0.895, p = 0.04 ✓
				从 L7 的 7x 到 L27 的 56x，方向效应随注入深度急剧增强。
			P3: 绕过 norm = 更强 DER
				验证：raw sensitivity 放大 6-11x，但 DER 比率效应不一致（部分确认）

		结构对齐 vs 功能对齐：
			结构对齐（Spectral）：Jacobian top direction 对齐 W_U[top_tok]（3-4x）—— 弱但真实
			功能对齐（Functional）：margin 方向被强烈放大（65x）—— 强
			为什么增益最高 ≠ 谱结构指向？
				Jacobian top singular vector 最大化 ||Jx||（总输出范数）
				margin 方向最大化 W_U[top]·Jx - W_U[second]·Jx（特定 1-D 投影）
				这是不同的优化目标。
			结论：训练产生了两种对齐，结构对齐弱，功能对齐强。

	6.4 非线性算子与非交换代数（Phase 141）

		核心事实1：V_not 是非线性算子
			V_not(h) = h(not(x)) - h(x) 是否定算子。
			方向一致性 < 0.5 → 不是平移算子
			h 相关性 0.33-0.39 → V_not(h) 强烈依赖 h → 流形有曲率
			结论：排除了"语言 = 向量加法"假设，证实了"语言 = 非线性算子"假设。

		核心事实2：语言算子非交换
			使用 scope 歧义句构造真正的交换子 [A,B] = AB - BA：
				[ALL, NOT] ≠ 0："不是所有" vs "所有都不"
				[ALWAYS, NOT] ≠ 0："不总是" vs "总是不"
				[SOME, NOT] ≠ 0："没有一些" vs "有些不"
			非交换比例：100%（Qwen3 27/27，GLM4 24/24）
			SOME_NOT 相对交换子最大（≈1.0）→ 存在量词与否定最不兼容
			结论：语言算子形成非交换代数，不是简单线性空间。

		数学含义：
			语言操作不能用简单的向量加法描述。
			操作顺序影响结果（[A,B] ≠ 0），需要用非交换算子代数刻画。
			这与量子力学的数学结构有形式相似性，但不应过度物理隐喻。

	6.5 非线性抵消与差分读取（Phase 301-312）

		核心现象：DS7B 的非线性抵消
			full_delta 因果效力 ≈ 0（+0.008）
			但 R_only 因果效力 = +0.177
			→ 分量 > 整体！说明 activation patching 的非线性效应。
			→ R 方向命中了更敏感的子空间，full_delta 中的 C 成分经后续层变换后产生反向效果。

		两种编码架构的因果验证：
			架构A（Qwen3/GLM4）：正交子空间编码
				R ⊥ C ⊥ O，cos < 0.3
				O_clean_R ≈ O_not，单位因果效力相近
				直接映射：各功能方向独立影响输出
				机制：分布式编码，各功能有独立子空间
			架构B（DS7B）：共享主方向 + 差分读取
				cos(O, R) ≈ -0.99（高度重叠）
				O_clean_R/O_not 范数比 = 0.11，但单位因果效力 × 114
				差分映射：高范数共享成分无因果，低范数差分被高增益读取
				机制：1 维压缩 + 差分放大，功能区分依赖微小残差

		完整数学模型：
			h_l(token) = I_l(token) + R_l(role)·α_R(l) + C_l(construction)·α_C(l) + O_l(operator)·α_O(l) + interactions + U_l
			架构A：R⊥C⊥O, α≈1, 直接因果
			架构B：R≈-O, α_R >> α_O, 因果由 δ = O - Proj_R(O) 决定
			因果效力 = ||W_U · δ|| / ||δ||
				架构A：δ≈O，因果效力中等
				架构B：δ 仅 11% 范数，但因果效力 × 114

		关键洞察：
			非线性抵消意味着"整体 ≠ 部分之和"。
			在 DS7B 中，方向投影看到的"主成分"可能恰恰是无因果的共享成分，
			真正起作用的是被高增益读取的微小差分。
			这直接挑战了所有基于"方向投影强度"的因果推断。

	6.6 SiLU 非线性分解（Phase 342-347）

		W_down 通道投影 50/50 对称：
			正通道比例 ≈ 50.03%，负通道 ≈ 49.97%（三模型一致）
			投影平衡比 ≈ 1.000，范数平衡比 ≈ 1.000
			含义：W_down 列向量对任意方向 d 呈精确 50/50 对称，
			没有哪个方向被系统性偏好。
			这是"平衡放大"的根本原因 —— 不是训练结果，而是 W_down 的结构性质。

		SiLU 非线性只占 13-17%：
			交互项的 ~85% 来自线性交叉效应（gate_diff × up_diff 的组合）
			SiLU 非线性只贡献交互项的 13-17%
			含义：交互不是来自 SiLU 的弯曲，而是 gate 和 up 同时变化时的"乘积效应"

		微偏置模型：
			微偏置 ≈ Σ_i channel_proj[i] × Δact[i]
			其中 Δact[i] = SiLU(gate_c[i])·up_c[i] - SiLU(gate_r[i])·up_r[i]
			因为 channel_proj 正负完美对称，微偏置完全取决于激活差异 Δact 在正负通道上的不对称性。

	6.7 softmax 竞争归一化（Phase 632-713，最新）

		这是当前最关键的非线性瓶颈。

		线性差分场公式（Phase 632 提出）：
			M_prefix = dot(W[prefix] - W[competitor], h_final)
			ΔM_prefix ≈ Σ_writers dot(W[prefix] - W[competitor], Δh_writer)
		假设：多 writer 的差分贡献可以线性叠加。

		Phase 633 的失败：
			top12 restore 没有超过 top1。
			这强烈暗示非线性耦合使线性叠加失效。
			多 writer 线性叠加碰到了 softmax 的归一化墙。

		深层问题：
			Transformer 的真实算子：softmax 注意力（非线性竞争）+ MLP（逐 token 非线性）+ 残差（线性）
			理论的线性差分框架只抓住了残差的线性部分，
			没有描述 softmax 归一化导致的竞争性相变。
			softmax 归一化使"寻址"本质是概率竞争，不是线性加权。
			"复用骨架"在不同条件下不是简单线性叠加，而是概率分布的重新归一化。

		突破方向：从线性差分场升级为 pre-softmax 概率竞争场
			把 ΔM ≈ Σ<·, Δh_w> 改写为以 attention logit（pre-softmax）为变量的差分，
			验证"多 writer 在 pre-softmax 上线性叠加，经 softmax 后非线性放大"能否解释 top12 < top1。

	6.8 非线性理论体系统一公式

		流形约束：
			dim(M_language) ≈ 65-75 << d_model
			h_role(x) = M_l(x) + δ_role(x)
			h = b + A @ v(c) + ε,  A 的列不正交

		Jacobian 链传播：
			δ_{l+k} ≈ J_{l+k-1} · ... · J_l · δ_l
			||J·δ|| > ||δ||（放大）但 cos(J·δ, δ) → 0.1（旋转）
			δh^{l+1} = D_norm · J_l · δh^l
			J_norm = g/||x|| · (I - x x^T / ||x||^2)

		非线性算子：
			V_op(h) = h(op(x)) - h(x),  V_op 依赖 h（流形有曲率）
			[A, B] = AB - BA ≠ 0（非交换代数）

		非线性抵消：
			因果效力 = ||W_U · δ|| / ||δ||
			δ = O - Proj_R(O)（差分读取）
			架构B：δ 仅 11% 范数，但因果效力 × 114

		MLP 非线性分解：
			微偏置 ≈ Σ_i channel_proj[i] × Δact[i]
			Δact[i] = SiLU(gate_c[i])·up_c[i] - SiLU(gate_r[i])·up_r[i]
			SiLU 非线性贡献 13-17%，线性交叉贡献 85%

		softmax 竞争：
			P(x_{t+1} | x_{≤t}) = softmax(W_U h_{L,t})
			ΔM_prefix ≈ Σ_writers <W_prefix - W_competitor, Δh_w>（线性近似，在 softmax 墙前失效）
			完整形式需要 pre-softmax logit 空间的差分（尚未建立）

	6.9 非线性理论的硬伤与边界

		1，Jacobian 数值不稳定（Phase 141）
			eps=1e-4 可能太小，末层出现异常极大值（>10^6）。
			需要改用 autograd 或增大 eps。

		2，流形维数估计的上界问题
			PR=67-75 是基于 200 个句子的估计，句子不够多样时 PR 可能被低估。
			需要 >500 句子验证。

		3，DS7B 的非线性来源不明
			DS7B 中间层 CV > 0.3 可能是 8bit 量化的 artifact，也可能是模型架构差异。
			需要对比 8bit vs 16bit 的 DS7B。

		4，交换子实验的句子差异
			AB 和 BA 不仅是算子顺序不同，句子本身也不同。
			差异可能来自句子结构而非纯粹算子非交换性。

		5，lm_head 方向的"强效应"可能是 trivial 的
			W_U 直接连接 h 和 logit → 沿 W_U 方向扰动当然直接影响 logit。
			这不是"发现了因果机制"，只是确认了模型的基本计算图。

		6，线性差分场与 softmax 归一化的冲突尚未解决
			Phase 633 的 top12 < top1 失败指向 softmax 归一化墙，
			但 pre-softmax 概率竞争场的数学形式尚未建立。

		7，跨模型非线性差异巨大
			Qwen3/GLM4 近似线性算子，DS7B 非线性算子。
			不能把一个模型的非线性结论直接提升为通用理论。

	6.10 语言模式图谱中的非线性耦合审计

		最新图谱方案必须把非线性作为显式字段，而不是事后解释失败。
		原因是：
			1，component_path 可能显示某个 writer 正向贡献很强；
			2，causal patch 后整体效果却可能很弱或反向；
			3，多 writer 组合不一定超过单 writer；
			4，softmax 竞争、RMSNorm、MLP gate/up 乘积和补偿路径都会破坏线性可加假设。

		因此，每条高价值路径都要记录：

			nonlinear_coupling
			nonlinear_gap
			linear_prediction
			actual_combined_effect
			compensation_path
			score_cap_reason

		线性预测：

			Δ_linear
				=
				Σ_i
				ΔM_i

		实际组合：

			Δ_actual
				=
				M(h + Σ_i p_i)
				-
				M(h)

		非线性缺口：

			NonlinearGap
				=
				|
					Δ_actual
					-
					Δ_linear
				|

		判定：

			NonlinearCoupling
				=
				1[
					NonlinearGap > ε
				]

		如果 NonlinearCoupling = 1，则：
			1，不能把单个 writer 的贡献解释为完整机制；
			2，不能把 component_path 高分直接升级为 causal closure；
			3，必须进入 compensation_path_audit；
			4，评分需要触发 score_cap；
			5，claim registry 中必须登记 negative evidence 或 counterexample。

		对智能理论的含义：
			智能系统不是线性功能模块的相加，而是条件化路径在竞争场中的非线性协调。
			真正的机制图谱必须描述：
				哪些路径能单独起效；
				哪些路径必须组合；
				哪些组合被 softmax / norm / protocol gate 抵消；
				哪些路径被抑制后会被补偿路径接管。

		因此，非线性理论不再只是“为什么 patch 失败”的解释，
			而是语言模式图谱的质量控制层。


## 七，行业进展：机械可解释性的外部证据与项目约束（截至 2026 年 8 月 13 日）

### 7.1 结论与证据口径

截至 2026 年 8 月 13 日，OpenAI、Google DeepMind、Anthropic 的公开原始研究不支持“深度神经网络逆向分析已经被信息论证明不可能”。更准确的行业结论是：

1. 神经元不是稳定的基本语义单元，单个神经元经常同时承载多个特征；
2. Superposition（叠加）是真实现象，但没有公开的“参数翻倍导致解释复杂度必然平方增长”定律；
3. 在限定任务、提示和干预范围内，可以找到可验证的局部特征、电路、运输路径和几何结构；
4. 发现表示不等于解释计算，重构输出也不等于恢复真实机制；
5. 当前的主要困难是分解不唯一、跨层跨位置分布、替代模型不忠实，以及自然语言缺少内部算法真值；
6. 三家公司仍在持续推进机械可解释性，并没有用输出监督、安全红队或思维链监控取代内部逆向研究。

本章节只纳入与权重、隐藏状态、神经元、注意力头、特征、电路、训练数据影响和因果干预直接相关的公开研究。纯输出行为评估、一般安全评估和单纯思维链监控不作为“内部机制已经被破解”的证据。

### 7.2 三家公司的研究路线

| 机构 | 路线演化 | 已建立的能力 | 仍然存在的边界 |
| --- | --- | --- | --- |
| OpenAI | 多模态神经元 → 自动解释神经元 → 大规模 SAE 特征字典 → 特征因果干预 → 权重稀疏电路 | 能在有限对象上发现、命名和干预局部方向，并开始从训练阶段提高电路可解释性 | SAE 不能完整重构模型，许多特征难以命名，局部方向不是完整计算电路 |
| Google DeepMind | Tracr 真值实验室 → 图式重绑定 → AtP* 因果定位 → Gated/JumpReLU SAE → Gemma Scope 1/2 | 建立已知真值校准器、规模化定位方法和覆盖多模型多层的开放显微镜 | 编译模型不等于自由训练模型；候选特征和定位结果仍不能自动说明算法 |
| Anthropic | Transformer 电路语言 → 叠加与单义特征 → 跨层转码器和归因图 → QK/OV 与多跳路径 → 流形和全局工作区 | 建立从局部表示到跨层运输、几何操作和面向未来输出子空间的连续研究链 | 完整电路图仍然昂贵、复杂且不唯一；高质量替代模型仍可能机制不忠实 |

代表性公开入口：

- [OpenAI Research](https://openai.com/research/)
- [Google DeepMind Research](https://deepmind.google/research/)
- [Anthropic Transformer Circuits Thread](https://transformer-circuits.pub/)

三条路线共同说明：必须把“发现候选表示”“定位因果组件”“解释跨层计算”“验证机制忠实性”当作四个不同阶段，不能用其中任何一个阶段替代完整闭环。

### 7.3 行业已经积累的十四块机制拼图

1. 残差流是跨组件共享的通信总线；
2. 注意力的 QK 决定读取位置，OV 决定搬运内容；
3. 归纳头能够实现特定重复模式的复制；
4. 神经元普遍混义；
5. 稀疏特征可以叠加，潜在特征数可以超过物理维度；
6. SAE 可以恢复大量比原神经元更单义的候选方向；
7. 特征字典依赖训练数据、稀疏度、宽度和目标函数，因此不是唯一坐标系；
8. 同一概念或功能状态可以跨层、跨位置和跨注意力头分布；
9. 注意力运输路径和局部计算必须联合研究；
10. 多跳推理在局部案例中存在可干预的中间状态；
11. 模型经常同时使用多条启发式路径和补偿路径；
12. 离散特征与连续流形可能是同一内部结构在不同尺度上的描述；
13. 存在较小的、面向未来输出且容易被下游读写的可言说工作区；
14. 高质量重构和准确输出预测不保证恢复了真实计算机制。

这些拼图支持下列暂定的综合过程：

$$
\text{稀疏特征叠加}
\rightarrow
\text{上下文条件路由}
\rightarrow
\text{跨层、跨位置运输}
\rightarrow
\text{临时程序}
\rightarrow
\text{部分状态进入未来输出工作区}.
$$

这与 RDC（复用—差分—条件化）原则相容，但 RDC 目前仍是需要继续反证和确认的组织假设，不能写成已经证明的通用定律。

### 7.4 对三个悲观判断的裁决

#### 7.4.1 “可解释复杂度存在平方增长定律”

没有在三家公司公开原始研究中找到普适的参数平方定律。现有证据只能说明：完整覆盖可能需要极大的特征字典，局部归因图可能极其复杂，成本会随模型和任务扩大。它们不能推出机械可解释性在信息论上不可能。

#### 7.4.2 “流形和特征大多是推理副产品”

特征可视化确实可能产生欺骗性图像，相关性和漂亮几何也可能是虚影。但正确结论是增加自然输入复核、因果干预、替换、路径删除、反向救援和分布外预测，而不是把所有流形或特征都判定为副产品。

#### 7.4.3 “顶尖实验室已经放弃内部逆向”

公开事实与该判断相反：OpenAI 在推进权重稀疏电路和特征因果研究；DeepMind 在扩展 Gemma Scope 工具链；Anthropic 继续研究跨层电路、流形、自然语言自编码器和全局工作区。行为监督、思维链监控和安全审计是互补路线，不是对机械可解释性的替代。

### 7.5 对智能理论基本假设的更新

#### 1，LLM 部分恢复了语言背后的数学结构

得到部分支持。归纳头、模板重绑定、跨语言抽象、多跳事实路径、计数流形和工作区都表明模型形成了结构化计算。但“部分恢复”不等于存在唯一语言本体，也不等于已经找到完整编码坐标系。

#### 2，破解 LLM 可以直接推出人脑语言机制

当前不成立。LLM 可以提供稀疏分布式表示、条件路由、预测学习、流形编码和工作区等候选计算原理；但 Transformer 与大脑在递归结构、局部学习规则、感觉运动闭环、神经调质、持续记忆和物理约束上差异巨大。因此只能提出可实验检验的类比，不能直接从 LLM 推导大脑机制。

#### 3，概念是网络关系的总和

与现有证据相容，但原表述过强。概念确实具有相对关系、上下文条件、多位置分布、多层运输和面向下游输出的功能作用；同时还可能包含局部方向、连续流形、门控状态和具体词形。不能把全部编码简化为纯图拓扑。

#### 4，模式复用与差分编码

共享特征、模板电路、归纳机制和跨语言抽象支持模式复用；Crosscoder 等方法也能区分共享与差异特征。但差分部分不必然更纯、更准确，因为特征预算竞争也可能让模型独占特征更加混义。

#### 5，每个词占据独特生态位

静态词嵌入版本过强。token 的真实作用取决于当前位置、上下文、语法角色、注意力来源、任务和后续生成状态。词嵌入适合作为静态先验，不能作为破解语言编码的基本单元。

### 7.6 基本研究对象：多事件未来响应等价类

行业进展与当前项目的负结果共同要求：研究对象从单词、单神经元、单方向和单事件隐藏态，升级为给定上下文与干预集合下的多事件功能状态。

设事件集合为：

$$
E=
\{
\text{source},
\text{query},
\text{table-key},
\text{table-value},
\text{answer-boundary},
\text{KV-cache}
\}.
$$

多事件状态束为：

$$
H_E=\{H_e:e\in E\}.
$$

在任务族 $\mathcal T$、上下文 $c$、干预集合 $I_S$ 和读出集合 $Q$ 下，未来响应场定义为：

$$
\mathcal R_{\mathcal T}^{c}(H_E)
=
\left\{
Q\left(F_{\ge E}^{c}(\operatorname{do}(I_S),H_E)\right)
-
Q\left(F_{\ge E}^{c}(H_E)\right)
\right\}_{S\subseteq E,I,Q}.
$$

功能等价类定义为：

$$
H_E\sim_{\mathcal T,c,\varepsilon}H'_E
\Longleftrightarrow
d\left(
\mathcal R_{\mathcal T}^{c}(H_E),
\mathcal R_{\mathcal T}^{c}(H'_E)
\right)\leq\varepsilon.
$$

相机的最低可识别性条件为：

$$
O_E(H)=O_E(H')
\Longrightarrow
\mathcal R_{\mathcal T}^{c}(H)
\approx
\mathcal R_{\mathcal T}^{c}(H').
$$

如果两个样本的观测相同但未来响应不同，说明当前观测对象不是充分统计量，不能通过继续增加解码器复杂度掩盖对象错误。

### 7.7 下一阶段的大任务

1. **已知真值机制基准**：在 Tracr 编译模型和自由训练小 Transformer 中同时覆盖一跳复制、两跳查表、三跳组合、并行冗余路径、叠加特征和连续计数流形；
2. **竞争对象冻结比较**：参数量匹配地比较单事件全局相机、条件化单事件相机、多事件加性相机、门控多事件超图和局部程序轨迹模型；
3. **机制忠实性门**：不仅预测输出，还要匹配局部 Jacobian、小幅与大幅干预、路径删除、替换、反向救援、冗余路径联合删除和分布外响应；
4. **预训练模型确认顺序**：先利用 Gemma Scope 2 的 SAE、Transcoder 和 CLT 提出候选节点，再到 Qwen3 等独立模型家族完成因果确认；
5. **三层全局图谱**：使用“静态词汇先验 → 上下文功能状态 → 多事件因果运输路径”，节点由未来响应等价类定义，边由干预响应变化定义，联合效应用超边表示；
6. **严格停止条件**：如果冻结样本中仍不能同时通过 direct、code、未见映射、未见模板、自然生成和至少两个模型家族复现，应停止当前观测对象，而不是继续堆叠非线性层或降低阈值。

### 7.8 最终判断

行业已经证明：模型内部不是无结构噪声；局部结构可以被发现、干预并在有限条件下解释；从局部结构到完整语言机制仍有巨大缺口。

行业尚未证明：存在唯一完整语义字典；SAE 特征就是模型真实源码；解释复杂度必然平方爆炸；逆向工程在信息论上不可能；LLM 机制可以直接推出大脑和 AGI。

因此，当前项目有继续研究的必要，但研究目标必须收缩为可终止、可反证的多事件机制实验。真正需要寻找的不再是静态热点，而是跨上下文、跨干预和跨模型仍保持未来功能响应的机制不变量。
