# 待测试的神经元解释

每条是一个神经元（匿名编号）的职能解释。请只根据解释文字写测试文本。

- M000：叙述政治/事件句中主语之后、即将引出核心谓语动作处激活，如“to【elect】”“【於】某地即位”“主席的【提名】”，及称呼后接问句处
- M001：专有名词、人名或数字被切成多个子词时，在词内续接子词处激活，如Anastas【ius】、Alex【ios】、snow【drop】、“1【2】th”
- M002：描述某处藏匿、庇护或滋生东西（细菌、敌人、罪犯）的语境中，在“藏匿/shelter/harbor/haven/庇护所/滞留”等动词或名词处激活
- M003：试卷或复习材料中题型说明处激活，尤其“多选/多项选择/Multiple Choice”中的“选/Choice”，以及题型说明后题号“1.”
- M004：编程或技术教程中示例代码、命令行和标识符里的示例名称处激活，如echo字符串、Alias /test/、TestWinRT、print(name)
- M005：在可测量的生理或物理指标名称上激活，尤其“心率/脉率”中的“率”，以及pH、流速、班额、condition number等量名
- M006：机构或个人表态将来可能采取行动的语境中，在“考虑/consider/不排除/may/will/looking into”等表示待定意向的词处激活
- M007：一方代替或接替另一方承担责任、债务或职能的语境中激活，如保证人“代为履行”、take over、接手、kinsman purchase/redemption
- M008：数据结构“树”相关文本中激活，在节点、叶子、叶数、遍历、搜索等二叉树术语处，中英文均可
- M009：描述重新/再次进行某操作或状态更新的步骤性文本中激活，如“come back and refresh”“重新定义”、AVL树更新平衡因子
- M012：反复讨论某个名词性论题（如“白马非马”“two envelope problem”）时，在该论题核心名词或多token专名的后续部分激活
- M013：两类分立模式：年表中年份后的制表符空白处，以及法律文本“一般【保证】”中的“保证”
- M014：比较或对照结构的引导处激活，如unlike、like、相较於、与X相比、相对于，在比较介词及其对象位置
- M015：数学中阶次与曲率相关术语处激活，尤其“二阶导数”的“阶/导”、债券“凸性”、半正定、二次规划
- M016：动词或谓语后紧接的介词/补足成分处激活，如died【of】、caused【by】、according【to】、“【依据】课程标准”
